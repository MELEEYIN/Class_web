练 1先自己做，再展开答案

求 y″ − 4y′ + 13y = 0 的通解。

展开答案与解析

解　写特征方程 r² − 4r + 13 = 0，判别式 Δ = 16 − 52 = −36 < 0；
求根 r = 4 ± 6i2 = 2 ± 3i，即 α = 2，β = 3；
共轭复根对应 y = e2x(C1cos 3x + C2sin 3x)。

Δ < 0 不要就此停手：把根整理成 α ± βi，再套 eαx(C1cos βx + C2sin βx)。β 取虚部前面的系数 3，不是 3i；α 是实部 2，两条指数都别落。

练 2先自己做，再展开答案

求 y″ + 6y′ + 9y = 0 满足 y(0) = 1、y′(0) = 0 的特解。

展开答案与解析

解　特征方程 r² + 6r + 9 = 0，即 (r + 3)² = 0，r = −3 是二重根；
二重根的通解要乘 x：y = (C1 + C2x)e−3x；
由 y(0) = C1 = 1；求导 y′ = [C2 − 3(C1 + C2x)]e−3x，由 y′(0) = C2 − 3 = 0 得 C2 = 3；
所以 y = (1 + 3x)e−3x。

重根时第二个解必须乘 x，写成 C1e−3x + C2e−3x 其实只有一个常数，初值一定定不出来；求 y′ 时把 (C1 + C2x) 当一个整体用乘积法则，别只对 e−3x 求导。
