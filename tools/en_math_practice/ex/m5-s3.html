练 1先自己做，再展开答案

求 ∫04dx1 + √x。

展开答案与解析

解　令 t = √x，则 x = t²、dx = 2t dt；上下限跟着换：x = 0 时 t = 0，x = 4 时 t = 2；
原式 = ∫022t1 + t dt = 2∫02 (1 − 11 + t) dt；
积分并代入上下限：2[(2 − ln 3) − (0 − ln 1)] = 2(2 − ln 3)，所以结果是 4 − 2ln 3。

换元必须同时换限：t 的限是 0 到 2，不是 0 到 4。换完就在 t 上算到底，不要回代成 x，否则限极容易写回原样。

练 2先自己做，再展开答案

求 ∫−11 (x + √(1 − x²))² dx。

展开答案与解析

解　先展开：(x + √(1 − x²))² = x² + 2x√(1 − x²) + (1 − x²) = 1 + 2x√(1 − x²)；
其中 2x√(1 − x²) 是奇函数（奇函数 × 偶函数），在对称区间 [−1, 1] 上的积分为 0；
于是原式 = ∫−11 1 dx = 1 − (−1)，所以结果是 2。

看到对称区间先查奇偶性再动手：展开后那个带根号的项是奇函数，直接消掉，只剩一个常数积分；硬算根号项又慢又容易丢负号。
