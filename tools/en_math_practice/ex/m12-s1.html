练 1先自己做，再展开答案

计算 ∬Σ(x² + y²) dS，其中 Σ 是锥面 z = √(x² + y²) 被平面 z = 1 截下的部分。

展开答案与解析

解　把 Σ 投影到 xOy 面，投影域 D：x² + y² ≤ 1（锥面在 z = 1 处半径为 1）；
zx = x/√(x² + y²)，zy = y/√(x² + y²)，于是 dS = √(1 + zx² + zy²) dxdy = √2 dxdy；
原式 = √2 ∬D(x² + y²) dxdy = √2 ∫02πdθ ∫01r³ dr = √2 · 2π · 14 = √2π2。

锥面的面积元素是常数 √2 dxdy，最常见的错是漏乘；另外投影域由「z = 1 处的半径」确定，不能写成 0 ≤ r ≤ z。
