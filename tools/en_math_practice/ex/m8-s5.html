练 1先自己做，再展开答案

(1) 把 yOz 面上的曲线 y² = 2z 绕 z 轴旋转一周，求所得曲面方程并指出曲面类型；(2) 指出 x² + y² = 4 与 x²/4 + y²/9 = 1 各表示什么曲面。

展开答案与解析

解　第一步，绕 z 轴旋转时 z 不变，把被旋转的 y 换成 ±√(x² + y²)：(√(x² + y²))² = 2z，得 x² + y² = 2z；
第二步，它可写成 z = x² + y²2，是顶点在原点、开口朝 z 轴正向的 旋转抛物面；
第三步，x² + y² = 4 缺字母 z，母线平行于 z 轴，是 圆柱面（半径 2）；
第四步，x²/4 + y²/9 = 1 同样缺 z，是母线平行 z 轴的 椭圆柱面。

柱面只看「缺哪个字母」，母线就平行哪条轴；旋转面则看绕谁转——绕 z 轴才把 y 换成 √(x² + y²)，换成别的变量对就转错了轴。

练 2先自己做，再展开答案

判断下列方程各表示什么曲面：① x² + y²/4 − z²/9 = 1；② x² + y²/4 − z²/9 = −1；③ z = x²/4 − y²/9；④ x² + y² − z² = 0。

展开答案与解析

解　第一步，① 三个平方项系数两正一负、右端为 1，是 单叶双曲面（腰在 z 轴方向上张开）；
第二步，② 把负号项移到右边看，实质是「一正两负且右端为 1」，是 双叶双曲面，两张叶分别在上、下两侧；
第三步，③ 关于 z 是一次的、关于 x 与 y 是二次且符号相反，是 双曲抛物面（马鞍面）；
第四步，④ 移项得 x² + y² = z²，即 z = ±√(x² + y²)，是顶点在原点、半顶角 45° 的 圆锥面。

「两正一负」的符号法则只适用于三个平方项都齐、右端为非零常数的方程；③ 这种缺 z² 的一次方程是抛物面，④ 右端为 0 时退化成锥面，两者都不能套符号法则。
