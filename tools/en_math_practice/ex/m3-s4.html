练 1先自己做，再展开答案

求 f(x) = x3 − 3x2 + 1 的单调区间、凹凸区间与拐点。

展开答案与解析

解　第一步，定义域为全体实数，f′(x) = 3x2 − 6x = 3x(x − 2)，令 f′ = 0 得 x = 0 与 x = 2；
第二步，分区间判号：x < 0 时 f′ > 0，0 < x < 2 时 f′ < 0，x > 2 时 f′ > 0，所以单增区间为 (−∞,0) 与 (2,+∞)，单减区间为 (0,2)；
第三步，f″(x) = 6x − 6，令 f″ = 0 得 x = 1；x < 1 时 f″ < 0（凸），x > 1 时 f″ > 0（凹），f″ 在 x = 1 两侧变号，故拐点在 x = 1；
第四步，f(1) = 1 − 3 + 1 = −1，拐点为 (1,−1)。

拐点是曲线上的点，必须写成坐标 (1,−1)，只答 x = 1 要扣分；f″ = 0 只是「嫌疑点」，还得验证两侧确实变号。
