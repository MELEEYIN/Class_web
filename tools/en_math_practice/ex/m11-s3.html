练 1先自己做，再展开答案

计算 ∮L (2x − y + 4) dx + (5y + 3x − 6) dy，其中 L 是以 (0, 0)、(3, 0)、(3, 2) 为顶点的三角形边界，取正向。

展开答案与解析

解　P = 2x − y + 4，Q = 5y + 3x − 6，二者都是多项式，在平面上有一阶连续偏导；L 分段光滑、闭、取正向，格林公式的三个条件齐备；
先算偏导差：∂Q∂x − ∂P∂y = 3 − (−1) = 4，是常数，于是 原式 = ∬D 4 dxdy；
D 为直角三角形，面积 = 12 × 3 × 2 = 3，故原式 = 4 × 3 = 12。

被积函数是常数时，二重积分就是「常数 × 面积」，考的是能不能把面积算对；若 L 的方向是顺时针，最后还要补一个负号。

练 2先自己做，再展开答案

计算 ∮L x dy − y dxx2 + y2，其中 L 为椭圆 4x2 + y2 = 1 的正向。

展开答案与解析

解　P = −yx2 + y2，Q = xx2 + y2，在原点处无定义，L 的内部含这个奇点，直接套格林公式是错的；
以原点为心作足够小的圆 C: x2 + y2 = ε2（取逆时针），在 L 与 C 围成的环形区域上 ∂Q∂x = ∂P∂y，由多连通区域的格林公式得 ∮L − ∮C = 0，即 ∮L = ∮C；
在 C 上取 x = εcosθ，y = εsinθ，则 x dy − y dx = ε2dθ，x2 + y2 = ε2，被积函数恰为 1，故原式 = ∫02π dθ = 2π。

偏导相等只在单连通区域上才等价于「环积分为 0」：闭曲线不套住原点结果是 0，一套住就是 2π；挖洞时内边界取顺时针，符号就藏在这一步。
