练 1先自己做，再展开答案

设 f(x) = x（−π < x < π），以 2π 为周期，求它的傅里叶级数。

展开答案与解析

解　f(x) = x 是奇函数，奇函数在对称区间上的积分为 0，故 a0 = 0，an = 0，只算 bn；
bn = 1π ∫−ππ x sin nx dx = 2π ∫0π x sin nx dx，分部积分得 ∫0π x sin nx dx = (−1)n+1 πn，所以 bn = 2(−1)n+1n；
所以 x = Σn=1∞ 2(−1)n+1n sin nx = 2(sin x − sin 2x2 + sin 3x3 − …)，−π < x < π。

奇函数直接用「只含 sin 项」省掉两个积分；注意 (−1)n+1 的符号别丢，它决定级数在 x 接近 π 时的振荡形状。

练 2先自己做，再展开答案

设 f(x) = x2（−π ≤ x ≤ π），以 2π 为周期，把它展开成傅里叶级数，并由此求 Σn=1∞ 1n2。

展开答案与解析

解　f(x) = x2 是偶函数，故 bn = 0，只算 a0 与 an；
a0 = 1π ∫−ππ x2 dx = 2π23，an = 1π ∫−ππ x2 cos nx dx = 4(−1)nn2；
所以 x2 = π23 + Σn=1∞ 4(−1)nn2 cos nx，−π ≤ x ≤ π；
令 x = π，左边为 π2，右边 cos nπ = (−1)n，得 π2 = π23 + 4Σn=1∞ 1n2，故 Σ 1/n2 = π26。

偶函数只含 cos 项，省掉 bn；用级数求和的关键是挑一个让 cos nx 变成 1 或 (−1)n 的点，x = π 最省事。
