练 1先自己做，再展开答案

将 f(x,y) = ln(1 + x + y) 在点 (0,0) 处展开到二阶，并写出皮亚诺余项。

展开答案与解析

解　把 x + y 看成一个整体 u，用一元展开 ln(1 + u) = u − u²2 + o(u²)（u → 0）；
代入 u = x + y，u² = x² + 2xy + y²，且 ρ → 0 时 u → 0、u² 与 ρ² 同阶，所以 o(u²) 可写成 o(ρ²)；
故 f(x,y) = x + y − ½(x² + 2xy + y²) + o(ρ²)，其中 ρ = √(x² + y²)。

交叉项 2xy 不能漏：二阶项是 ½(h∂x + k∂y)²f，展开后 2hk·fxy 这一项总在；只分别按 x、y 展开一元式子就会把它丢掉。
