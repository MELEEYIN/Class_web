练 1先自己做，再展开答案

设 f(x,y) = x² + xy + y²，求它在点 P(1,1) 处沿方向 l = (1,2) 的方向导数，并指出函数增长最快的方向与最大方向导数。

展开答案与解析

解　梯度 grad f = (fx, fy) = (2x + y, x + 2y)，在 P 点为 (3, 3)；
l 不是单位向量，先单位化：|l| = √5，el = (1/√5, 2/√5)，故方向导数 = grad f · el = 3 + 6√5 = 9√5 / 5；
沿梯度方向 (1,1)/√2 增长最快，最大方向导数就是 |grad f| = 3√2。

方向必须单位化，直接拿 (1,2) 去点乘会得到 9，正好大了 √5 倍；另外梯度给出的是方向与最大变化率，不是某点的函数值。
