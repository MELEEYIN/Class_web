练 1先自己做，再展开答案

求 limx→0 ex − 1 − xx2。

展开答案与解析

解　第一步，x → 0 时分子、分母都趋于 0，是 0/0 型，且两函数在 0 的去心邻域内可导，可用洛必达；
第二步，求导一次得 ex − 12x，仍为 0/0 型，继续用；
第三步，再求导得 ex2，此时已不是未定式，直接代入 x = 0，极限为 12。

洛必达每用一次都要回头确认「现在还是未定式吗」；这题也能用 ex = 1 + x + x2/2 + o(x2) 一步出答案，两种方法都该会。

练 2先自己做，再展开答案

求 limx→+∞ x1/x。

展开答案与解析

解　第一步，这是 ∞0 型，不能直接用洛必达；设 y = x1/x，两边取对数得 ln y = ln xx；
第二步，x → +∞ 时 (ln x)/x 是 ∞/∞ 型，用洛必达得 1/x1 → 0；
第三步，所以 ln y → 0，由指数函数的连续性得 y → e0 = 1。

∞0、00、1∞ 这三种幂指型一律先取对数，化成 0·∞ 或 ∞/∞，再决定用洛必达还是等价替换。
