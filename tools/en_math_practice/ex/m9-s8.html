练 1先自己做，再展开答案

求函数 f(x,y) = x³ + y³ − 3xy 的极值。

展开答案与解析

解　令 fx = 3x² − 3y = 0，fy = 3y² − 3x = 0，得 y = x² 且 x = y²，联立解得驻点 (0,0) 与 (1,1)；
二阶偏导 A = fxx = 6x，B = fxy = −3，C = fyy = 6y；
在 (0,0)：AC − B² = −9 < 0，不是极值；在 (1,1)：AC − B² = 27 > 0 且 A = 6 > 0，取极小值 f(1,1) = −1。

两个驻点方程要联立，只解其中一个会漏点；AC − B² = 0 的情形判别法失效，需要另用定义或高阶项讨论。

练 2先自己做，再展开答案

求 f(x,y,z) = x + 2y + 3z 在球面 x² + y² + z² = 1 上的最大值与最小值。

展开答案与解析

解　构造拉格朗日函数 L = x + 2y + 3z + λ(x² + y² + z² − 1)，令 Lx = 1 + 2λx = 0、Ly = 2 + 2λy = 0、Lz = 3 + 2λz = 0；
三式说明 x : y : z = 1 : 2 : 3，设 x = t，y = 2t，z = 3t，回代约束得 14t² = 1，t = ±1/√14；
比较两点函数值：最大值为 √14，在 (1,2,3)/√14 处取到；最小值为 −√14，在反方向取到。

乘数法解出的可疑点必须回代约束方程，否则得到的是空间里的点而不是球面上的点；两个候选点都要算函数值再比较。
