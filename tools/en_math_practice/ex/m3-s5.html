练 1先自己做，再展开答案

求 f(x) = x − 32x2/3 的极值。

展开答案与解析

解　第一步，定义域为全体实数，f′(x) = 1 − x−1/3 = x1/3 − 1x1/3：x = 1 时 f′ = 0 是驻点，x = 0 时 f′ 不存在但 f 连续，两类点都要查；
第二步，判号：x < 0 时 f′ > 0，0 < x < 1 时 f′ < 0，x > 1 时 f′ > 0，故在 x = 0 处左正右负，取极大值 f(0) = 0；
第三步，在 x = 1 处左负右正，取极小值 f(1) = 1 − 32 = −12（也可用第二充分条件：f″(x) = 13x−4/3，f″(1) = 13 > 0，故为极小）。

极值点未必是驻点：x = 0 处导数不存在，却是极大值点。只解 f′ = 0 会漏掉它，这是本题最大的坑。

练 2先自己做，再展开答案

求内接于半径为 R 的圆的矩形面积的最大值。

展开答案与解析

解　第一步，设矩形在第一象限的顶点为 (x,y)，则 x2 + y2 = R2（x,y > 0），面积 S = (2x)(2y) = 4xy；
第二步，由约束消元得 y = √(R2 − x2)，于是 S(x) = 4x√(R2 − x2)，0 < x < R；
第三步，S′(x) = 4(R2 − 2x2)√(R2 − x2)，令 S′ = 0 得 x = R√2，此时 y = R√2，矩形为正方形；
第四步，x 越过 R/√2 后 S′ 由正变负，故为最大值，Smax = 4 · R√2 · R√2 = 2R2。

应用题先把目标函数写成单变量再求导；最后要回代约束看实际意义（这里是正方形），别只报一个 R/√2 就结束。
