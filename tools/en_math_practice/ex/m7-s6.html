练 1先自己做，再展开答案

已知 y1 = x 是方程 y″ − 2xy′ + 2x²y = 0（x > 0）的一个解，求它的通解。

展开答案与解析

解　先验算：y1 = x 时 y1′ = 1，y1″ = 0，代入得 0 − 2x + 2x = 0，确实是解；
设 y = xu(x)，则 y′ = u + xu′，y″ = 2u′ + xu″，代入方程后含 u 的项全部抵消，只剩 xu″ = 0；
故 u″ = 0，u = C1 + C2x，回代得 y = C1x + C2x²；
再用朗斯基行列式确认线性无关：W = x·2x − 1·x² = x² ≠ 0，所以这确实是通解。

已知一个解求通解，标准做法是设 y = u(x)·y1 降阶，二阶降成一阶；直接猜出第二个解 x² 更快，但要验算并说明它与 y1 不成比例（W ≠ 0），否则只能算「一个解」。
