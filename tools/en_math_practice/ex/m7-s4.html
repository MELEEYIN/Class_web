练 1先自己做，再展开答案

求一阶线性方程 y′ − 2xy = x ex² 的通解。

展开答案与解析

解　已是标准形 y′ + P(x)y = Q(x)，其中 P = −2x，Q = x ex²，故 ∫P dx = −x²，e−∫P dx = ex²；
套通解公式：y = ex²[ ∫ x ex²·e−x²dx + C ] = ex²[ ∫ x dx + C ]；
积分得 y = ( x²2 + C )ex²。

公式里乘在外面的因子是 e−∫P dx，被积的那一份才是 e∫P dx，两个别抄反。本题的 ex² 与 e−x² 正好抵消，是出题人故意凑的，不是巧合。

练 2先自己做，再展开答案

求方程 y′ = 1x + y 的通解（提示：把 x 看成 y 的函数）。

展开答案与解析

解　右端把 x、y 搅成一块，直接分离不了，两边取倒数得 dxdy = x + y，即 dxdy − x = y——这是以 x 为未知函数的一阶线性方程；
此时 P = −1，Q = y，∫P dy = −y，套公式 x = ey[ ∫ y e−ydy + C ]；
分部积分 ∫ y e−ydy = −(y + 1)e−y，所以 x = Cey − y − 1，即 x + y + 1 = Cey。

看到 y′ = 1/(x + y) 这种「y 被搅进分式」的题，别硬凑分离变量：把 x 当未知函数、两边取倒数，它立刻变成一阶线性。这是最常被漏掉的换元方向。
