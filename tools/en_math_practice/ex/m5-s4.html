练 1先自己做，再展开答案

求 ∫0+∞ x e−x dx。

展开答案与解析

解　无穷限要先写成极限：原式 = limb→+∞∫0b x e−x dx，不能把 +∞ 直接代进原函数；
分部积分得 ∫ x e−x dx = −(x + 1)e−x，所以 ∫0b x e−x dx = 1 − (b + 1)e−b；
b → +∞ 时 (b + 1)e−b → 0（指数压过多项式），故原式 = 1 − 0，结果是 1。

反常积分的第一步永远是「先当正常积分算，再对端点取极限」，顺序颠倒必错；(b + 1)e−b 是 ∞ · 0 型，写成 (b + 1)/eb 用洛必达也看得出极限为 0。

练 2先自己做，再展开答案

求 ∫01 ln x dx。

展开答案与解析

解　这是无界函数反常积分，瑕点在 x = 0（ln x → −∞），写成 limε→0+∫ε1 ln x dx；
分部积分得 ∫ ln x dx = x ln x − x，所以 ∫ε1 ln x dx = −1 − (ε ln ε − ε)；
ε → 0+ 时 ε ln ε → 0、ε → 0，故原式 = −1，结果是 −1。

算出负数不代表算错：ln x 在 (0, 1) 上恒为负，带符号的面积就是负的。关键一步是基本极限 ε ln ε → 0，漏掉它就会把收敛误判成发散。
