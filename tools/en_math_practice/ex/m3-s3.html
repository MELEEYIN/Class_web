练 1先自己做，再展开答案

求 limx→0 cos x − e−x²/2x4。

展开答案与解析

解　第一步，分母是 x4，两个函数都展到 x4：cos x = 1 − x22 + x424 + o(x4)；
第二步，对 eu = 1 + u + u22 + o(u2) 取 u = −x2/2，得 e−x²/2 = 1 − x22 + x48 + o(x4)；
第三步，两式相减，1 与 −x2/2 两项抵消，只剩 (124 − 18)x4 = −x412 + o(x4)，故原式 = −112。

泰勒求极限的关键是阶数「够用」：这题前两项都抵消，必须展到 x4，只展到 x2 会算出 0 这个错答案。

练 2先自己做，再展开答案

用二次多项式 P2(x) = 1 + x + x22 近似 e0.1，并估计误差。

展开答案与解析

解　第一步，写出带拉格朗日余项的展开：ex = 1 + x + x22 + eξx36，其中 ξ 介于 0 与 x 之间；
第二步，取 x = 0.1，得 P2(0.1) = 1 + 0.1 + 0.005 = 1.105；
第三步，估计余项：|R2(0.1)| = eξ · 0.0016 < 3 · 0.0016 = 0.0005（因 0 < ξ < 0.1 时 eξ < e < 3），所以 e0.1 ≈ 1.105，误差不超过 0.0005（实际约 0.00017）。

余项里的 ξ 求不出来，只能「估」：拿 ξ 所在区间上 eξ 的最大值把它放大。佩亚诺余项只能用来求极限，估误差必须用拉格朗日余项。
