练 1先自己做，再展开答案

判别级数 Σn=1∞ n!nn 的敛散性。

展开答案与解析

解　这是正项级数，通项含 n!，优先用比值法，记 un = n!nn；
un+1un = (n+1)! · nnn! · (n+1)n+1 = nn(n+1)n = 1(1 + 1/n)n；
取极限得 ρ = 1e < 1；
所以级数 收敛。

比值法最后一定要算极限，别停在 (1 + 1/n)n；分子分母约分时把 (n+1)! 拆成 (n+1)·n! 是关键一步。ρ = 1 时比值法失效，要改用比较法或积分判别法。

练 2先自己做，再展开答案

判别级数 Σn=2∞ 1n ln n 的敛散性。

展开答案与解析

解　取 un = 1n ln n = f(n)，其中 f(x) = 1x ln x 在 [2, +∞) 上非负且单调递减，可用积分判别法；
∫2+∞ 1x ln x dx = limb→+∞ (ln ln b − ln ln 2) = +∞，广义积分发散；
所以原级数 发散。

陷阱在这里：1n ln n 比 1n 还小，却照样发散，因为它不是 n 的幂次，p-级数这一招根本套不上；只能靠积分判别法（或与 1/n 比较）。
