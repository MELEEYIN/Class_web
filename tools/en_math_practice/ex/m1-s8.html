练 1先自己做，再展开答案

求 f(x) = x² − 1x² − 3x + 2 的间断点，并指出它们的类型。

展开答案与解析

解　分母分解为 (x − 1)(x − 2)，可疑点是 x = 1 与 x = 2；
x = 1：约分后 f(x) = x + 1x − 2，limx→1 f(x) = 2−1 = −2，极限存在，故 x = 1 是可去间断点（补充定义 f(1) = −2 即可连续）；
x = 2：分子为 3 ≠ 0、分母趋于 0，limx→2 f(x) = ∞，故 x = 2 是无穷间断点（第二类）。

分子分母同时为零的点先约分再看极限，别一见到分母为零就判无穷间断；可去与无穷的差别就在约分后极限是否存在。

练 2先自己做，再展开答案

设 f(x) = {
√(1 + x) − 1x　(x > 0)，
a + x　(x ≤ 0) } 在 x = 0 处连续，求常数 a。

展开答案与解析

解　先算右极限，分母有理化：√(1 + x) − 1x = 1√(1 + x) + 1 → 12；
左极限与函数值相等：f(0) = a，左极限也是 a；
连续要求左极限 = 右极限 = 函数值，即 a = 12，所以 a = 12。

分段点连续必须三条都写全；右极限直接代入是 0/0，先有理化再取极限，这一步漏了整题没分。
