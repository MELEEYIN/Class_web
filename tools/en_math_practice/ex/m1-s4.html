练 1先自己做，再展开答案

求曲线 y = x² + 1x − 1 的所有渐近线。

展开答案与解析

解　① 垂直：分母零点 x = 1，此处分子 1 + 1 = 2 ≠ 0，limx→1 f(x) = ∞，故 x = 1 是垂直渐近线；
② 斜：k = limx→∞ f(x)x = limx→∞ x² + 1x² − x = 1，b = limx→∞ [f(x) − x] = limx→∞ x + 1x − 1 = 1，故 y = x + 1；
③ 水平：x → ∞ 时 f(x) → ∞，水平渐近线不存在；
所以两条渐近线是 x = 1 与 y = x + 1。

先做一次多项式除法 f(x) = x + 1 + 2x − 1，斜渐近线和垂直渐近线一眼可见；水平渐近线与斜渐近线不可能同时存在。

练 2先自己做，再展开答案

求曲线 y = 2x² + 3x² − 1 的所有渐近线。

展开答案与解析

解　分母 x² − 1 有两个零点 x = 1 与 x = −1，分子在这两点都等于 5 ≠ 0，
所以 x = 1 与 x = −1 都是垂直渐近线（两条，不能只查一条）；
再算无穷远处：limx→±∞ 2x² + 3x² − 1 = 2，两侧是同一条水平渐近线 y = 2；
又因 k = limx→∞ f(x)x = 0，不存在斜渐近线。答案：x = 1、x = −1、y = 2。

分母有几个零点就逐个查几个；本题的陷阱是只查出 x = 1 就收手。另外分子分母同次，水平渐近线两侧相同，不必分开算。
