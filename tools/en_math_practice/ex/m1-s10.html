证明方程 x³ + x − 1 = 0 在区间 (0, 1) 内有且仅有一个根。

展开答案与解析

解　令 f(x) = x³ + x − 1，它是多项式，在闭区间 [0, 1] 上连续；
端点值 f(0) = −1 < 0，f(1) = 1 + 1 − 1 = 1 > 0，f(0)·f(1) < 0，由零点定理，存在 ξ ∈ (0, 1) 使 f(ξ) = 0，即根存在；
又 x³ 与 x 在 [0, 1] 上都严格单调增加，故 f(x) 严格单调增加，最多只有一个零点，即根唯一；
综上，方程在 (0, 1) 内有且仅有一个根。

「有且仅有」必须写两步：零点定理管存在，单调性管唯一；只算出 f(0)·f(1) < 0 只能得一半分。
