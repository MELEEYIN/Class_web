练 1先自己做，再展开答案

求 ∫ (x² + 1)/(x(x − 1)) dx。

展开答案与解析

解　分子分母同为二次，先看次数：分子次数不小于分母，必须做多项式除法把它降成真分式。
除法：x² + 1 = (x² − x)·1 + (x + 1)，所以 (x² + 1)/(x(x − 1)) = 1 + (x + 1)/(x(x − 1))；
拆真分式：设 (x + 1)/(x(x − 1)) = Ax + Bx − 1，去分母得 x + 1 = A(x − 1) + Bx，令 x = 0 得 A = −1，令 x = 1 得 B = 2；
逐项积分：原式 = ∫dx − ∫dx/x + 2∫dx/(x − 1) = x − ln|x| + 2ln|x − 1| + C。

假分式不先除，直接设 A、B 去解系数永远解不出来；求 A、B 用「代特殊值」比展开比较系数快得多。

练 2先自己做，再展开答案

求 ∫ (x + 2)/(x² + 2x + 5) dx。

展开答案与解析

解　分母判别式 4 − 20 < 0，在实数上不可约，走「分子凑导数 + 配方」两步：
配方：x² + 2x + 5 = (x + 1)² + 4；
凑导数：分母的导数是 2x + 2，而 x + 2 = (1/2)(2x + 2) + 1，于是
原式 = 12∫(2x + 2)/(x² + 2x + 5)dx + ∫dx/((x + 1)² + 4) = 12ln(x² + 2x + 5) + 12arctanx + 12 + C。

不可约二次因子不能拆成两个一次项，只能拆成「ln 型 + arctan 型」；用 ∫du/(u² + a²) = (1/a)arctan(u/a) 时，那个 1/a 是最常丢的分。
