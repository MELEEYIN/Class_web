练 1先自己做，再展开答案

求幂级数 Σn=1∞ n xn 的和函数 S(x)，并写出它的收敛域。

展开答案与解析

解　先求收敛域：R = limn→∞ |nn+1| = 1，端点 x = ±1 时通项分别为 n 与 (−1)nn，都不趋于 0，发散，故收敛域为 (−1, 1)；
在 (−1, 1) 内由几何级数 Σn=0∞ xn = 11 − x，两边逐项求导得 Σn=1∞ n xn−1 = 1(1 − x)2；
两边同乘 x，得 S(x) = x(1 − x)2，且 −1 < x < 1。

套路是「求导凑几何级数，求出和后乘 x 或再积分还原」；这里乘 x 是为了把 xn−1 调回 xn。逐项求导后半径不变，但端点必须重新判。
