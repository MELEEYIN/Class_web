练 1先自己做，再展开答案

把 f(x) = 12 + x 展开成 x 的幂级数，并写出成立的范围。

展开答案与解析

解　先提出 12，凑成 11 − t 的形状：12 + x = 12 · 11 + x/2；
用 11 − t = Σn=0∞ tn（|t| < 1），取 t = −x2，得 f(x) = 12 Σn=0∞ (−x2)n = Σn=0∞ (−1)n xn2n+1；
成立条件为 |x/2| < 1，即 |x| < 2；
所以 f(x) = Σn=0∞ (−1)n2n+1 xn，|x| < 2。

间接法的固定动作：先把常数项提出来，把分母写成 1 − t 的样子再代公式。写完展开式一定要顺手标明成立范围，漏写条件要扣分。

练 2先自己做，再展开答案

把 ln(1 + x) 展开成 x 的幂级数（用间接法），并说明两个端点的收敛情况。

展开答案与解析

解　由 11 + x = Σn=0∞ (−1)n xn（|x| < 1），在收敛区间内可以逐项积分；
两边从 0 到 x 积分：ln(1 + x) = Σn=0∞ (−1)n xn+1n + 1 = Σn=1∞ (−1)n−1 xnn；
端点 x = 1：得交错级数 Σ (−1)n−1n，收敛；端点 x = −1：得 −Σ 1n，发散；
所以 ln(1 + x) = Σn=1∞ (−1)n−1 xnn，−1 < x ≤ 1。

积分下限取 0，是为了让常数项恰好等于 ln 1 = 0；逐项积分后收敛域可能扩大，端点一定要单独代回原级数判一次。
