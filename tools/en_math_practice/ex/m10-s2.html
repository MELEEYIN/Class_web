练 1先自己做，再展开答案

计算 ∫01dx∫x1ey²dy。

展开答案与解析

解　内层 ∫ey²dy 不是初等积分，先把上下限翻译成区域：0 ≤ x ≤ 1，x ≤ y ≤ 1，重写成 0 ≤ y ≤ 1，0 ≤ x ≤ y；
交换次序后 原式 = ∫01dy∫0yey²dx = ∫01y ey²dy，内层对 x 积分把 ey² 当常数提出；
而 ∫y ey²dy = ½ey²，代入上下限得 ½(e − 1)。
所以结果是 e − 12。

交换次序必须先重画区域，不能把上下限直接对调；这里交换的目的就是让 ey² 先被对 x 的积分乘出 y，从而凑成可积的 y ey²。

练 2先自己做，再展开答案

计算 ∬D(x2 + y2)dxdy，其中 D 由 x2 + y2 ≤ 2x 确定。

展开答案与解析

解　配方得 (x − 1)2 + y2 ≤ 1，是过原点的圆，被积函数又含 x2 + y2，改用极坐标：x2 + y2 = r2，dxdy = r dr dθ；
边界 x2 + y2 = 2x 即 r = 2cos θ，圆在右半平面，故 −π/2 ≤ θ ≤ π/2，0 ≤ r ≤ 2cos θ；
于是 原式 = ∫−π/2π/2dθ∫02cos θr3dr = ∫−π/2π/24cos4θ dθ，再用偶次幂公式 ∫0π/2cos4θ dθ = 3π/16 得 4 · 2 · 3π/16 = 3π/2。
所以结果是 3π2。

圆不过原点时 r 的上限是 θ 的函数 2cos θ，写成常数就错了；θ 的范围由区域张角决定，这个圆整个在右半平面，所以是 −π/2 到 π/2。
