练 1先自己做，再展开答案

求均匀半圆薄片 D: x2 + y2 ≤ 4，y ≥ 0 的质心，面密度为常数 ρ。

展开答案与解析

解　ρ 为常数，质量 m = ρS = 2πρ；D 关于 y 轴对称，故 x̄ = 0，只需算纵坐标；
ȳ = (1/m)∬Dy ρ dxdy = (1/2π)∫0πdθ∫02r sin θ · r dr，ρ 与 m 中的 ρ 相消；
其中 ∫0πsin θ dθ = 2，∫02r2dr = 8/3，故 ȳ = (1/2π)·2·(8/3) = 8/(3π)。
所以结果是质心为 (0, 83π)。

半圆板的质心不在圆心，而在 ȳ = 4R/(3π) 处；这里是 R = 2 得 8/(3π) ≈ 0.85。求质心一定先看对称性，能省掉一半积分。

练 2先自己做，再展开答案

求球面 z = √(1 − x2 − y2) 被柱面 x2 + y2 = x 所截下部分的面积。

展开答案与解析

解　被截部分在 xOy 面上的投影是 D: x2 + y2 ≤ x，曲面为上半球，zx = −x/z，zy = −y/z，故 √(1 + zx2 + zy2) = 1/√(1 − x2 − y2)；
换成极坐标：柱面为 r = cos θ，D 是 −π/2 ≤ θ ≤ π/2，0 ≤ r ≤ cos θ，面积元中的 r 正好与 dxdy 的 r 合成 r dr dθ；
内层 ∫0cos θr/√(1 − r2)dr = 1 − |sin θ|，于是 A = ∫−π/2π/2(1 − |sin θ|)dθ = π − 2。
所以结果是面积 π − 2。

曲面面积是 ∬√(1 + zx2 + zy2)dxdy，别漏根号；r 的上限来自柱面 x2 + y2 = x 即 r = cos θ，写成 1 就把整道题做错了。
