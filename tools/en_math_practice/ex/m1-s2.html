练 1先自己做，再展开答案

用数列极限的定义证明 limn→∞ 3n + 12n − 1 = 32。

展开答案与解析

解　先算出差的绝对值并放大：
|an − 32| = |6n + 2 − 6n + 32(2n − 1)| = 54n − 2 ≤ 52n（n ≥ 1 时成立）；
对任意 ε > 0，取 N = ⌊52ε⌋ + 1，则当 n > N 时 52n < ε，从而 |an − 32| < ε；
由定义得 limn→∞ 3n + 12n − 1 = 32。

证定义的套路是「先放大、再解 n」：把含 n 的部分放大成好解的形式，N 只要能找到一个就行，不必求最小的那个。

练 2先自己做，再展开答案

求 limn→∞ (1√(n² + 1) + 1√(n² + 2) + … + 1√(n² + n))。

展开答案与解析

解　和式一共 n 项，每项的分母都在 √(n² + 1) 与 √(n² + n) 之间，于是
n√(n² + n) ≤ Sn ≤ n√(n² + 1)；
两端分子分母同除 n：左端 = 1√(1 + 1/n) → 1，右端 = 1√(1 + 1/n²) → 1；
由夹逼准则得原式 = 1。

含 n 项和先数清项数（这里是 n 项，所以放缩后要乘 n）；两端都能直接算出极限才叫夹逼，若只一端收敛就没法用。
