练 1先自己做，再展开答案

求由曲线 y = x² 与直线 y = x + 2 所围成的平面图形的面积 A，并求该图形绕 x 轴旋转所得旋转体的体积 V。

展开答案与解析

解　联立 y = x² 与 y = x + 2，得 x² − x − 2 = 0，交点为 x = −1、x = 2，且在 (−1, 2) 内 x + 2 > x²；
A = ∫−12(x + 2 − x²)dx = [12x² + 2x − 13x³]−12 = 92；
绕 x 轴旋转用垫圈法，外半径 R = x + 2，内半径 r = x²：
V = π∫−12[(x + 2)² − x⁴]dx = π[13x³ + 2x² + 4x − 15x⁵]−12 = 72π5；
所以面积 A = 92，体积 V = 72π5。

先解交点定上下限，再判断区间内谁在上面；垫圈法是被挖掉的那条曲线给内半径，写成 R² − r²，不要用 (R − r)²。

练 2先自己做，再展开答案

求心形线 r = a(1 + cos θ)（a > 0）所围平面图形的面积 A。

展开答案与解析

解　图形关于极轴 θ = 0 对称，先算 0 ≤ θ ≤ π 的那一半，再乘 2；
扇形微元 dA = 12r²dθ，故 A = 2 · 12∫0πa²(1 + cos θ)²dθ = a²∫0π(1 + 2cos θ + cos²θ)dθ；
其中 ∫0πcos θ dθ = 0，∫0πcos²θ dθ = π2；
所以 A = a²(π + 0 + π2) = 3πa²2。

两个坑：扇形微元的 ½ 不能漏；只积 0 到 π 算的是半个图形，必须乘 2，或者干脆积 0 到 2π，别半途而废。
