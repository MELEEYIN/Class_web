练 1先自己做，再展开答案

计算 ∬Σx³ dydz + y³ dzdx + z³ dxdy，其中 Σ 是球面 x² + y² + z² = 1 的外侧。

展开答案与解析

解　Σ 是闭曲面且取外侧，三个函数在球体内有一阶连续偏导，满足高斯公式的三个条件；
先算散度：Px + Qy + Rz = 3x² + 3y² + 3z² = 3(x² + y² + z²)；
原式 = ∭Ω3(x² + y² + z²) dV = 3∫02πdθ ∫0πdφ ∫01r⁴ sin φ dr = 3 · 4π · 15 = 12π5。

闭曲面 + 外侧是「直接用高斯」的信号；球坐标的体积元素是 r² sin φ dr dφ dθ，被积函数里的 r² 乘上去正好成 r⁴。

练 2先自己做，再展开答案

计算 ∬Σx² dydz + y² dzdx + z² dxdy，其中 Σ 是上半球面 z = √(a² − x² − y²) 的上侧（a 为正常数）。

展开答案与解析

解　Σ 不闭，补上底面 Σ1：z = 0（x² + y² ≤ a²）取下侧，则 Σ + Σ1 围成闭区域 Ω 且取外侧；
散度 div F = 2x + 2y + 2z，由对称性 ∭Ωx dV = ∭Ωy dV = 0，而 ∭Ωz dV = ∫02πdθ ∫0π/2dφ ∫0ar³ sin φ cos φ dr = πa⁴4，故 ∭Ω(2x + 2y + 2z) dV = 2 · πa⁴4 = πa⁴2；
在 Σ1 上 z = 0，dz = 0，只剩 dxdy 项而 z² = 0，所以 ∬Σ1 = 0；
因此原式 = πa⁴2 − 0 = πa⁴2。

补面后一定记得减去补面上的积分，别默认它是 0——这题恰好因为 z = 0 且被积项含 z² 才为 0；若换成 z dxdy 就得另算。
