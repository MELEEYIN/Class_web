练 1先自己做，再展开答案

由方程 x2 + xy + y2 = 3 确定隐函数 y = y(x)，且 y(1) = 1，求 y′(1) 与 y″(1)。

展开答案与解析

解　两边对 x 求导（把 y 看成 x 的函数）：2x + y + xy′ + 2yy′ = 0；
代入 x = 1、y = 1 得 3 + 3y′ = 0，所以 y′(1) = −1；
上式再对 x 求导：2 + 2y′ + xy″ + 2(y′)2 + 2yy″ = 0；
代入 x = 1、y = 1、y′ = −1 得 2 + 3y″ = 0，所以 y″(1) = −23。

求二阶导要对「含 y′ 的一阶方程」整体再求导，y′ 也是 x 的函数，不能当常数。

练 2先自己做，再展开答案

设参数方程 x = t − sin t，y = 1 − cos t（t ≠ 2kπ），求 d2ydx2。

展开答案与解析

解　先求一阶导：dydx = sin t1 − cos t = cot t2；
再对 t 求导，并除以 dx/dt：d2ydx2 = −½csc2(t/2)1 − cos t；
用 1 − cos t = 2sin2(t/2) 化简，得 −14sin4(t/2)。

二阶导的公式是 (d/dt)(dy/dx) 再乘 1/(dx/dt)，忘掉最后的除法就会少一个 1 − cos t。
