练 1先自己做，再展开答案

设 f(x) = x2，用导数定义求 f′(2)，并写出曲线 y = x2 在点 (2, 4) 处的切线方程。

展开答案与解析

解　先算函数增量：Δy = f(2 + Δx) − f(2) = (2 + Δx)2 − 4 = 4Δx + (Δx)2；
再算差商并取极限：ΔyΔx = 4 + Δx，所以 f′(2) = limΔx→0 (4 + Δx) = 4；
切线斜率 k = f′(2) = 4，切线为 y − 4 = 4(x − 2)，即 y = 4x − 4。

定义法固定三步：写增量、算差商、取极限；Δx 没约掉之前不能令 Δx = 0。

练 2先自己做，再展开答案

设 f(x) = x2（x ≤ 1），f(x) = ax + b（x > 1）。已知 f(x) 在 x = 1 处可导，求常数 a、b。

展开答案与解析

解　可导必连续，由连续性得 f(1) = 1 = a + b；
左导数 f′₋(1) = limx→1⁻x2 − 1x − 1 = 2；
右导数 f′₊(1) = limx→1⁺ax + b − 1x − 1 = limx→1⁺ a = a；
左右导数相等得 a = 2，再由 a + b = 1 得 b = −1，即 a = 2，b = −1。

分段点先保证连续、再比较左右导数；只写 a + b = 1 而不比导数，就会漏掉一个条件。
