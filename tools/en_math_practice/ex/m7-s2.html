练 1先自己做，再展开答案

求可分离变量方程 y′ = ex+y 满足 y(0) = 0 的特解，并写出解成立的区间。

展开答案与解析

解　把右端拆开：y′ = ex·ey，两边同除 ey（它恒不为 0，不会丢解）得 e−ydy = exdx；
两边积分：−e−y = ex + C，常数只写一个；
代入 y(0) = 0：−1 = 1 + C，得 C = −2，即 e−y = 2 − ex；
取对数化成显式：y = −ln(2 − ex)，由 2 − ex > 0 得 x < ln 2。

除的是 ey 这种恒正的因子，所以不丢解；若除的是 y、1 − y 这类会取零的因子，必须单独检查被除式 = 0 对应的常数解。最后别忘了写出 x < ln 2 这个区间。
