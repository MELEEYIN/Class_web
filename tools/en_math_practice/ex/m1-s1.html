练 1先自己做，再展开答案

求函数 y = √(x − 1) + 1x − 3 + ln(5 − x) 的定义域。

展开答案与解析

解　三个限制条件逐个卡：
偶次根号内不小于零，得 x ≥ 1；
分母不为零，得 x ≠ 3；
对数真数大于零，得 x < 5；
三条同时成立，取交集得定义域 [1, 3) ∪ (3, 5)。

定义域永远是「列条件 → 取交集」；最容易丢的是 x = 3 这个洞，以及端点的开闭（1 取得到，5 取不到）。

练 2先自己做，再展开答案

判断 f(x) = ln1 − x1 + x 的奇偶性，并写出它的定义域。

展开答案与解析

解　先看定义域：真数大于零，即 1 − x1 + x > 0，解得 −1 < x < 1，区间关于原点对称，可以谈奇偶性；
再算 f(−x) = ln1 + x1 − x，它正好是 ln1 − x1 + x 的倒数，而倒数的对数等于对数的相反数，所以 f(−x) = −f(x)；
结论：f 是 奇函数，定义域 (−1, 1)。

判奇偶第一步永远是看定义域是否关于原点对称，不对称就直接下结论「非奇非偶」，不用再算 f(−x)。
