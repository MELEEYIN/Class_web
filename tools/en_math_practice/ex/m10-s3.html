练 1先自己做，再展开答案

计算 ∭Ωz dV，其中 Ω 由旋转抛物面 z = x2 + y2 与平面 z = 4 围成。

展开答案与解析

解　区域含 x2 + y2，用柱坐标：z = r2，dV = r dr dθ dz；两曲面交线 r2 = 4，得 0 ≤ θ ≤ 2π，0 ≤ r ≤ 2，r2 ≤ z ≤ 4；
于是 原式 = ∫02πdθ∫02r dr∫r24z dz = 2π∫02r · (16 − r4)/2 dr；
= π∫02(16r − r5)dr = π(32 − 32/3)。
所以结果是 64π3。

先画 xOy 面上的投影圆，再让 z 从抛物面爬到平面；r 的上限来自两张曲面的交线，不是抛物面顶点的高度 4。

练 2先自己做，再展开答案

计算 ∭Ωz2dV，其中 Ω 是上半球 x2 + y2 + z2 ≤ 1，z ≥ 0。

展开答案与解析

解　区域是球，被积函数含 z2，用球坐标：z = ρ cos φ，dV = ρ2sin φ dρ dφ dθ，上半球对应 0 ≤ θ ≤ 2π，0 ≤ φ ≤ π/2，0 ≤ ρ ≤ 1；
被积式化为 ρ2cos2φ · ρ2sin φ = ρ4cos2φ sin φ，三个变量可分离；
原式 = ∫02πdθ · ∫0π/2cos2φ sin φ dφ · ∫01ρ4dρ = 2π · ⅓ · ⅕。
所以结果是 2π15。

φ 是从 z 轴正向量起的角，上半球是 0 到 π/2 而不是 0 到 π；雅可比里那个 sin φ 不能漏，漏了就少一个因子。
