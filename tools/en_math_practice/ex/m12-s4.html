练 1先自己做，再展开答案

用斯托克斯公式计算 ∮Γ(z − y) dx + (x − z) dy + (y − x) dz，其中 Γ 是平面 x + y + z = 1 与三个坐标面的交线，从 z 轴正向看去取逆时针方向。

展开答案与解析

解　P = z − y，Q = x − z，R = y − x，旋度 rot F = (Ry − Qz, Pz − Rx, Qx − Py) = (2, 2, 2)；
取 Σ 为平面被 Γ 围成的三角形，取上侧，单位法向量 n = (1, 1, 1)/√3，正好与 Γ 的逆时针方向成右手法则；
原式 = ∬Σ(rot F · n) dS = ∬Σ6√3dS = 2√3 · SΣ，而三角形边长为 √2，面积 SΣ = √32；
所以原式 = 2√3 · √32 = 3。

用斯托克斯公式方向最要命：Γ 的绕向与 n 必须成右手法则，取反则整题差一个负号；当 rot F · n 是常数时，曲面积分退化成「常数 × 曲面面积」。
