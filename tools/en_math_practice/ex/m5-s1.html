练 1先自己做，再展开答案

求极限 limn→∞( 1n + 1 + 1n + 2 + … + 12n )。

展开答案与解析

解　每一项都提出 1n 当 Δx：1n + k = 1n · 11 + k/n，于是原式 = limn→∞1nΣk=1n11 + k/n；
这是 f(x) = 11 + x 在 [0, 1] 上的和式极限，其中 Δx = 1/n、xk = k/n，所以它等于定积分 ∫01dx1 + x；
原函数是 ln(1 + x)，由牛顿-莱布尼茨公式 ∫01dx1 + x = ln 2 − ln 1 = ln 2，所以结果是 ln 2。

认和式极限只看两个特征：能不能凑出 1/n 当 Δx、k/n 当 x。分母是 n + k 时先把 1/n 提出来写成 1/(1 + k/n)，不提出来的话它既不是 Δx 也不是函数值。

练 2先自己做，再展开答案

设 I = ∫01 e−x² dx，证明 1e < I < 1，并证明存在 ξ ∈ (0, 1) 使 I = e−ξ²。

展开答案与解析

解　f(x) = e−x² 在 [0, 1] 上连续且单调递减，所以最小值 m = e−1 = 1e、最大值 M = e0 = 1；
由估值定理 m(b − a) ≤ ∫ab f dx ≤ M(b − a)，取 a = 0、b = 1 得 1e ≤ I ≤ 1；又 f 不是常数，两端等号都取不到，故 1e < I < 1；
由积分中值定理，存在 ξ ∈ [0, 1] 使 I = f(ξ)(1 − 0) = e−ξ²；而 f 严格递减、I 严格介于 1/e 与 1 之间，对应的 ξ 只能落在开区间内，即 ξ ∈ (0, 1)。

估值定理给的是「最小值 × 区间长」到「最大值 × 区间长」这个夹子，不是平均值；中值定理里的 ξ 就是让 f(ξ) 正好等于平均高度的那一点，先求出 f(ξ) 的范围才定得出 ξ 的范围。
