一、这节解决什么问题

前面学的定积分是「在直线上累加」，二重积分是「在平面上累加」。工程上还常要沿一条弯曲的线累加：一根线密度不均匀的细铁丝有多重？把它分成 n 小段，第 i 段长记为 Δsi，密度近似取该段上一点 (ξi, ηi) 处的值 ρ(ξi, ηi)，则质量约等于 Σρ(ξi, ηi)Δsi。让每段都缩到零，这个和的极限就是「沿弧长累加」。被积函数取 1 时它退化为弧长，取线密度时它给出质量。这就是对弧长的曲线积分（第一类曲线积分）的来源。

二、定义与性质

定义：设 L 是 xOy 面上一条光滑（或分段光滑）的曲线弧，函数 f(x, y) 在 L 上有界。把 L 任意分成 n 小段，第 i 段弧长记 Δsi，在其上任取一点 (ξi, ηi)，作和 Σf(ξi, ηi)Δsi。令 λ 为各小段弧长的最大值，若 λ→0 时该和式的极限存在，且与分法、取点方式都无关，则称之为 f 沿 L 的对弧长的曲线积分，记 ∫L f(x, y) ds。当 f 在 L 上连续时这个积分一定存在。

关键一点：Δsi 是弧长，恒为正，所以积分与 L 的走向无关，∫AB f ds = ∫BA f ds。这是它与第二类曲线积分最根本的区别。

性质与定积分类似：线性性；对弧段可加（L 分成 L1、L2 则积分相加）；保序性（f≤g 时 ∫f ds ≤ ∫g ds）；绝对值不等式 |∫f ds| ≤ ∫|f| ds；特取 f≡1 得 L 的弧长。几何意义：f≥0 时，积分值等于以 L 为准线、高为 f(x, y) 的「曲边柱面」面积。

再强调一句物理含义：把 L 看成一根线密度为 ρ(x, y) 的细线，则 m = ∫Lρ ds 就是它的质量。若密度为常数 ρ0，质量退化为 ρ0 乘弧长，与「质量等于密度乘体积（长度）」的直观一致。

三、怎么算：参数化

设 L 由参数方程 x=φ(t), y=ψ(t)（α≤t≤β）给出，φ、ψ 有连续导数且不同时为零。一小段弧长近似等于弦长：Δs ≈ √((Δx)2 + (Δy)2) = √(φ′2(t) + ψ′2(t)) Δt，写成微分形式即 ds = √(φ′2 + ψ′2) dt。于是

∫L f(x, y) ds = ∫αβ f(φ(t), ψ(t)) √(φ′2 + ψ′2) dt

注意下限 α 必须小于上限 β：ds 是正的量，化成定积分后不能靠「颠倒上下限」把负号消掉。

严格一点说，由拉格朗日中值定理，第 i 小段的弧长可写成 Δsi = √(φ′2(τi) + ψ′2(τi)) Δti，其中 τi 介于该段两端参数之间；再由 f 的连续性与定积分的定义，和式的极限恰好是上面那个定积分。这也说明了为什么要求 φ、ψ 有连续导数：只有导数连续，被积函数才连续，积分才一定存在。

四种常用特例：① y=y(x)，a≤x≤b 时 ds=√(1+y′2)dx；② x=x(y)，c≤y≤d 时 ds=√(1+x′2)dy；③ 极坐标 r=r(θ)，θ1≤θ2 时 ds=√(r2 + r′2)dθ；④ 空间曲线 x=x(t), y=y(t), z=z(t) 时 ds=√(x′2+y′2+z′2)dt。另有一个省力技巧：对称性。若 L 关于 y 轴对称而 f 关于 x 为奇函数，则积分为 0；f 关于 x 为偶函数则等于半弧段上积分的 2 倍。

四、例题

例 1 计算 ∫L √y ds，L 为抛物线 y=x2 上从 (0,0) 到 (1,1) 的一段。

解 以 x 为参数，y=x2，y′=2x，故 ds=√(1+4x2)dx，x 从 0 到 1。在 L 上 y=x2≥0，所以 √y=|x|=x。于是
原式 = ∫01 x√(1+4x2) dx。
令 u=1+4x2，du=8x dx，x:0→1 对应 u:1→5：
原式 = (1/8)∫15 u1/2 du = (1/8)·(2/3)u3/2|15 = (1/12)(5√5 − 1)。

提醒：把 √y 化成 x 时要看清弧段上 x 的符号，若弧段跨到第二象限，必须写 |x| 并分段。

例 2 计算 ∫L (x2 + y2) ds，L 为圆周 x2 + y2 = a2。

解 参数化 x=a cos t，y=a sin t，0≤t≤2π。此时 x′=−a sin t，y′=a cos t，
ds = √(a2sin2t + a2cos2t) dt = a dt。
被积函数在 L 上恒等于 a2，于是原式 = ∫02π a2·a dt = 2πa3。
验算：圆周长 2πa 乘常数 a2，正是 2πa3，结果合理。

例 3 计算 ∫L z ds，L 为螺旋线 x=a cos t，y=a sin t，z=kt，0≤t≤2π（a 为正数）。

解 这是空间曲线。x′=−a sin t，y′=a cos t，z′=k，故
ds = √(a2sin2t + a2cos2t + k2) dt = √(a2 + k2) dt。
原式 = √(a2+k2) ∫02π kt dt = k√(a2+k2)·(2π)2/2 = 2π2k√(a2+k2)。

五、与后文的联系、易错提醒

第一类是「无方向的累加」，后面用它算质量、质心、转动惯量与弧长。第二类引入方向之后，两者由 ∫L P dx + Q dy = ∫L (P cos α + Q cos β) ds 沟通（cos α、cos β 为切向量的方向余弦）。

易错点：① 化成定积分后随手把上下限倒过来「凑正」——不允许，第一类的限必须从小到大；② 忘记乘 √(x′2+y′2)，把 dx 当成 ds；③ 被积函数含 √y、√(1−x2) 一类式子时丢绝对值；④ 误以为 AB 与 BA 差一个负号——那是第二类而不是第一类。

一、这节解决什么问题

第一类只累加「大小」，不管方向。但功是有方向的：变力 F 把质点沿曲线 L 从 A 推到 B，做的功等于力在位移方向上的分量乘位移。把 L 分成小段，第 i 段位移向量 Δri=(Δxi, Δyi)，力近似取为 F(ξi, ηi)=(P, Q)，则该段功 ΔWi ≈ P(ξi, ηi)Δxi + Q(ξi, ηi)Δyi。求和取极限就得到 W = ∫L P dx + Q dy。这里 Δxi 可正可负，方向信息就藏在 dx、dy 的符号里。日常也能体会：把箱子沿直路推一段与沿弯道绕一圈，后者可能白费力气却净功为零，原因正是每小段位移方向不同、正负相消。

二、定义、方向性与两类积分的关系

定义：设 L 是从点 A 到点 B 的有向光滑曲线弧，P(x, y) 在 L 上有界。分割、取点同上，若 ΣP(ξi, ηi)Δxi 在 λ→0 时的极限存在且与分法、取点无关，则称之为 P 沿 L 对坐标 x 的曲线积分，记 ∫L P(x, y) dx；同理有 ∫L Q(x, y) dy。两者之和 ∫L P dx + Q dy 称为第二类曲线积分。P、Q 连续且 L 光滑时存在。

向量形式：记 F=(P, Q)，dr=(dx, dy)，则积分为 ∫L F·dr。若 τ=(cos α, cos β) 是 L 上与走向一致的单位切向量，则

∫L P dx + Q dy = ∫L (P cos α + Q cos β) ds

这条式子把两类积分接了起来：第二类等于第一类再乘方向余弦，两者的差别全在 cos α、cos β 的符号上。

方向性：记 L− 为 L 的反向弧，则 ∫L− P dx + Q dy = −∫L P dx + Q dy，因为每个 Δxi 都变号。这是第二类最容易丢分的地方。若 L 是闭曲线，常记 ∮L；对平面区域 D 的边界，规定正向为逆时针方向（沿边界前进时 D 在左手边），顺时针为负向。

三、怎么算：参数化

设 L：x=φ(t), y=ψ(t)，起点对应 t=α，终点对应 t=β（不要求 α 小于 β），则

∫L P dx + Q dy = ∫αβ [P(φ(t), ψ(t)) φ′(t) + Q(φ(t), ψ(t)) ψ′(t)] dt

这个公式的妙处是：下限一定写起点、上限一定写终点，方向自动由 α、β 的大小关系承担，不必再另加负号。特例：y=y(x)、x 从 a 到 b 时 dy=y′dx，原式化为 ∫ab[P(x, y(x)) + Q(x, y(x))y′(x)]dx；x=x(y) 同理。若 L 是分段光滑的闭曲线，就按各段的走向逐段参数化，保证每一段的上下限都是「本段起点到本段终点」，再把结果相加；切不可为图省事把整圈的参数统一写成从小到大，那样方向就丢了。

例 1 计算 ∫L (x2 − 2xy) dx + (y2 − 2xy) dy，L 为抛物线 y=x2 上从 A(−1,1) 到 B(1,1) 的一段。

解 取 x 为参数，y=x2，dy=2x dx，x 从 −1 到 1（起点在左，终点在右）。
被积式 = (x2 − 2x·x2)dx + (x4 − 2x·x2)·2x dx = (x2 − 2x3 + 2x5 − 4x4)dx。
原式 = ∫−11(x2 − 2x3 − 4x4 + 2x5)dx。
奇次项在对称区间上积分为 0，只剩偶次项：
原式 = 2∫01(x2 − 4x4)dx = 2(1/3 − 4/5) = 2·(−7/15) = −14/15。

例 2 计算 ∮L x dy − y dx，L 为圆 x2 + y2 = a2 的正向（逆时针）。

解 参数化 x=a cos t，y=a sin t，t 从 0 到 2π（t 增大即逆时针，正是正向）。
dx=−a sin t dt，dy=a cos t dt，于是
x dy − y dx = a cos t·a cos t dt − a sin t·(−a sin t)dt = a2(cos2t + sin2t)dt = a2 dt。
原式 = ∫02π a2 dt = 2πa2。
顺带得到一个几何结论：该圆面积 A = (1/2)∮x dy − y dx = πa2。这正是用曲线积分求面积的一般公式。

例 3 计算 ∫L y dx，其中 L 分别取：(1) 从 (0,0) 到 (1,1) 的直线段；(2) 折线 (0,0)→(1,0)→(1,1)。

解 (1) L：y=x，x 从 0 到 1，dx=dx，∫01 x dx = 1/2。
(2) 第一段 y=0（x 从 0 到 1），被积函数为 0，积分为 0；第二段 x=1 为常数，dx=0，积分也为 0。合计 0。
两条路径端点相同，结果却不同（1/2 与 0），说明第二类曲线积分一般与路径有关。

那么什么时候与路径无关？这一问正是第三节格林公式要回答的，例 3 就是它的引子。

四、常考套路与易错提醒

套路：见到「功」「环流量」「沿曲线做的功」，一律往第二类上想，先定方向再参数化；被积式若恰好是某个函数的全微分，直接代端点，能省掉整段积分。两类积分的换算公式与闭合曲线的正向约定，都是第三节的前置知识。

易错点：① 反向忘记变号；② 参数化时把上下限按「从小到大」写，而不是「起点到终点」；③ 分段曲线漏算某一段，或某一段的方向写反；④ 把 ∮ 的顺时针当作正向；⑤ 两类混用——第一类写 ds 且无方向，第二类写 dx、dy 且有方向，不能互换着套公式。

一、这节解决什么问题

沿闭曲线做第二类积分，若老老实实分段参数化，往往又长又易错。格林公式给出一条捷径：沿闭曲线一圈的积分，等于曲线所围区域内部某个量累加的结果。它把「边界上的积分」换成「区域上的二重积分」，地位相当于一元积分里的牛顿—莱布尼茨公式。

直观理解：设 (P, Q) 是平面向量场，量 ∂Q/∂x − ∂P/∂y 刻画该点附近「微小旋转」的强弱。把区域切成许多小格子，每个小格子边界上的环流相加时，相邻格子的公共边被来回各走一次、方向相反、正好抵消，最后只剩下最外圈边界上的环流。这就是公式的几何含义：内部抵消，边界留存。

二、定理（格林公式）与三个条件

设闭区域 D 由分段光滑的闭曲线 L 围成，函数 P(x, y)、Q(x, y) 在 D 上具有一阶连续偏导数，则

∮L P dx + Q dy = ∬D ( ∂Q∂x − ∂P∂y ) dxdy

其中 L 取正向（逆时针，即沿 L 前进时 D 在左侧）。三个条件缺一不可：① L 是分段光滑的闭曲线；② L 取正向，取负向则整体加负号；③ P、Q 在 D 上有一阶连续偏导，有奇点必须先挖掉。

三、证明思路

先设 D 是 X 型区域：a≤x≤b，φ1(x)≤y≤φ2(x)。对含 P 的那一项先对 y 积分：

∬D ∂P∂y dxdy = ∫ab [P(x, φ2(x)) − P(x, φ1(x))] dx

右边恰是 −∮L P dx：沿上边界 y=φ2(x) 要从右向左（x 从 b 到 a）才是正向，贡献 −∫abP(x, φ2)dx；沿下边界 y=φ1(x) 从左向右是正向，贡献 +∫abP(x, φ1)dx。两者相加正是上式取负。于是 ∬∂P/∂y dxdy = −∮P dx。

同理，把 D 看成 Y 型区域（左边界 ψ1(y)、右边界 ψ2(y)），可得 ∬∂Q/∂x dxdy = ∮Q dy。两式相减即得格林公式。一般区域用辅助线把它切成若干 X 型、Y 型小块，内部辅助线上的积分方向相反、成对抵消，结论仍然成立。

四、三个用法

用法一：正向闭曲线化为二重积分。

例 1 计算 ∮L (x2 − y) dx + (y2 + x) dy，L 为椭圆 x2/a2 + y2/b2 = 1 的正向。

解 P = x2 − y，Q = y2 + x，于是 ∂Q/∂x = 1，∂P/∂y = −1，差为 2（常数，与点无关）。
三项条件都满足：L 是光滑闭曲线、取正向、P、Q 在全平面有连续偏导。
由格林公式，原式 = ∬D 2 dxdy = 2·(椭圆面积) = 2·πab = 2πab。

关键是 ∂Q/∂x − ∂P/∂y 恰为常数，曲线积分便一步变成「常数乘面积」。

用法二：曲线不闭就补线。补一段（通常取直线段）使整体闭合，对闭曲线用格林公式，再减去补线上的积分。

例 2 计算 ∫L (exsin y − y) dx + (excos y − 1) dy，L 为上半圆周 (x−1)2 + y2 = 1 上从 A(2,0) 到 B(0,0) 的一段。

解 补上 x 轴上从 B(0,0) 到 A(2,0) 的直线段 L1。则 L 与 L1 首尾相接，围成上半圆盘 D，且沿 L 从 A 走到 B、再沿 L1 从 B 回到 A，恰好是逆时针正向。
P = exsin y − y，Q = excos y − 1，故 ∂Q/∂x = excos y，∂P/∂y = excos y − 1，差为 1。
格林公式：∮L+L1 = ∬D 1 dxdy = (1/2)π·12 = π/2。
在 L1 上 y=0，dy=0，P = ex·0 − 0 = 0，故 ∫L1 = 0。
所以原式 = π/2 − 0 = π/2。

补线时最要紧的是方向：补出的线段与 L 合起来必须绕成逆时针，否则格林公式要加负号。

用法三：有奇点就挖洞。在奇点周围作一个小闭曲线，在两条曲线之间的多连通区域上用格林公式（此时内边界须取顺时针），把难算的外边界换成好算的内边界。

例 3 计算 ∮L x dy − y dxx2 + y2，L 为包围原点的任意一条分段光滑正向闭曲线。

解 记 P = −y/(x2+y2)，Q = x/(x2+y2)，它们在原点无定义。当 (x, y) 不为原点时，
∂Q/∂x = (y2 − x2)/(x2+y2)2，∂P/∂y = (y2 − x2)/(x2+y2)2，两者相等。
取小圆 Lε：x2+y2=ε2（ε 充分小，整个落在 L 内部），在 L 与 Lε 围成的环形区域上用格林公式。该环形的外边界是 L（逆时针），内边界须取顺时针，即 −Lε，于是 ∮L − ∮Lε = ∬(0) dxdy = 0，即 ∮L = ∮Lε。
在 Lε 上取 x=εcos t，y=εsin t，t 从 0 到 2π，则分母恒为 ε2，而 x dy − y dx = ε2dt，故 ∮Lε = ∫02π dt = 2π。
所以原式 = 2π，与 L 的形状、大小都无关。

这就是「挖洞」的威力：偏导相等的区域里，环量只由被围住的奇点决定。

五、路径无关与求原函数

设 G 是单连通区域（没有洞），P、Q 在 G 内有一阶连续偏导。以下四条等价：

  1. 对 G 内任意闭曲线 C，∮C P dx + Q dy = 0；
  2. 积分与路径无关，只与起点、终点有关；
  3. 存在 u(x, y) 使 du = P dx + Q dy，即 P dx + Q dy 是全微分；
  4. 在 G 内恒有 ∂P∂y = ∂Q∂x。

证明是链条式的：①⇒② 把两条路径首尾相接拼成闭曲线；②⇒③ 固定起点 (x0, y0)，令 u(x, y)=∫(x0,y0)(x,y)P dx + Q dy，再验证 ux=P、uy=Q；③⇒④ 由混合偏导相等 uxy=uyx；④⇒① 直接用格林公式。

求原函数 u 的实用办法是沿折线积分：先水平后竖直，

u(x, y) = ∫x0x P(x, y0) dx + ∫y0y Q(x, y) dy + C

例如 P=2xy、Q=x2 时 ∂P/∂y=2x=∂Q/∂x 在全平面成立，取起点 (0,0) 得 u=∫0x0 dx + ∫0yx2dy = x2y + C，验算 ux=2xy、uy=x2 均吻合。

六、易错提醒

① 顺时针用格林公式必须加负号；② 不闭就补线，算完要减掉补线那一段，别把补线当成本题答案；③ 有奇点不挖洞直接用格林，结论会错（上面例 3 若硬算二重积分得 0，正确答案是 2π）；④ 偏导相等只是路径无关在单连通区域内的充要条件，区域有洞时不足以推出无关，这是概念题的高频陷阱。

一、这节解决什么问题

前两节讲清了「两类曲线积分怎么算」，这一节回答「用来算什么」。物理与几何中有四类量可以直接写成曲线积分：变力做功、流速场的环流量、曲线构件的质量与质心（及转动惯量）、平面区域的面积。判断标准很简单：与方向有关的用第二类，与方向无关的用第一类。

二、变力做功

设质点在力 F=(P(x,y), Q(x,y)) 作用下沿有向曲线 L 从 A 运动到 B，则所做的功

W = ∫L P dx + Q dy

理由：小段位移 dr=(dx, dy)，该段功为 F·dr = P dx + Q dy，累加取极限即得。若 F 是保守力（存在势函数 u 使 P dx + Q dy = du），则 W = u(B) − u(A)，只与首末位置有关，沿任意闭曲线一周做功为 0——这正是第三节「路径无关」的物理含义。反过来，若力场有旋（∂Q/∂x ≠ ∂P/∂y），沿闭曲线走一圈的功一般不为零，这一圈功就是环量。

例 1 设 F=(x2, xy)，质点沿抛物线 y=x2 从 (0,0) 移到 (1,1)，求 F 所做的功。

解 W = ∫L x2 dx + xy dy。取 x 为参数，y=x2，dy=2x dx，x 从 0 到 1：
W = ∫01 [x2 + x·x2·2x] dx = ∫01 (x2 + 2x4) dx = 1/3 + 2/5 = 11/15。

先检验是否保守：∂P/∂y = 0，∂Q/∂x = y，不相等，所以功与路径有关，必须沿指定曲线算。

三、环流量

设 (P, Q) 是流速场，沿闭曲线 L 的积分 ∮L P dx + Q dy 称为该场沿 L 的环流量（环量），它度量流体沿闭合路径「绕圈」的强弱。若 L 取正向，格林公式给出

∮L P dx + Q dy = ∬D ( ∂Q∂x − ∂P∂y ) dxdy

即环量等于区域内「旋度」的累加。当 ∂Q/∂x − ∂P/∂y 恒为 0 时，无旋场沿任何闭曲线的环量都为 0。再细一层看：把闭曲线所围区域缩向一点，环量除以面积在面积趋于零时的极限恰好是 ∂Q/∂x − ∂P/∂y，这个量称为环量面密度（旋度的 z 分量），所以格林公式也可读作「边界环量等于内部环量面密度的面积分」。

例 2 求速度场 F=(−y, x) 沿圆 x2+y2=a2 正向的环流量。

解 环量 = ∮L −y dx + x dy。参数化 x=a cos t，y=a sin t，t 从 0 到 2π：
−y dx + x dy = (−a sin t)(−a sin t)dt + a cos t·a cos t dt = a2 dt，
环量 = ∫02π a2 dt = 2πa2。
用格林公式校验：∂Q/∂x − ∂P/∂y = 1 − (−1) = 2，环量 = 2·πa2 = 2πa2，一致。

这个场就是「绕原点匀速旋转」的流场，沿任意以原点为心的圆环量都与半径平方成正比，越大越「转得动」。

四、质量、质心与转动惯量

设 L 是线密度为 ρ(x, y) 的曲线构件，则

m = ∫L ρ ds　　x̄ = 1m ∫L xρ ds　　ȳ = 1m ∫L yρ ds

对 x 轴、y 轴与原点的转动惯量分别为 Ix = ∫L y2ρ ds、Iy = ∫L x2ρ ds、IO = ∫L (x2+y2)ρ ds。全部用第一类，因为质量、矩、惯量都与方向无关。式中 ∫xρ ds、∫yρ ds 分别称为构件对 y 轴、对 x 轴的静矩，质心公式就是「静矩除以总质量」；当 ρ 为常数时 ρ 在分子分母中约掉，质心只由曲线的几何形状决定。

例 3 求半径为 a 的上半圆周（线密度 ρ=1）的质心。

解 参数化 x=a cos t，y=a sin t，0≤t≤π，ds=a dt。
m = ∫0π a dt = πa。
x̄ = (1/πa)∫0π a cos t·a dt = (1/πa)·a2[sin t]0π = 0（由关于 y 轴的对称性也能直接看出）。
ȳ = (1/πa)∫0π a sin t·a dt = (1/πa)·a2[−cos t]0π = (1/πa)·2a2 = 2a/π。
故质心为 (0, 2a/π)。

细圆弧的质心不在弧上，而在对称轴上，与半径之比为 2/π≈0.637，比半圆的质心 4a/(3π) 更靠上。

五、用曲线积分求面积

取 P=−y/2、Q=x/2，则 ∂Q/∂x − ∂P/∂y = 1，由格林公式得

A = 12 ∮L x dy − y dx

（等价地 A = ∮L x dy = −∮L y dx，L 均取正向）。它的几何含义很直白：把边界上「半径扫过的面积微元」绕一圈累加，正好铺满整个区域。这条公式对参数方程给出的曲线特别方便。例如椭圆 x=a cos t，y=b sin t：x dy − y dx = ab dt，故 A = (1/2)∫02πab dt = πab。

六、常考套路与易错提醒

套路：看到「功」「环流量」先判第二类、先定方向；看到「质量／质心／转动惯量」用第一类；看到「闭曲线围成面积」用 (1/2)∮x dy − y dx；若被积式恰为全微分，做功只与端点有关，直接代端点，能省掉大段计算。

易错点：① 求功时方向弄反，功整体变号；② 求质心忘了除以总质量 m，只写了 ∫xρ ds；③ 转动惯量 Ix 用的是 y2（到 x 轴距离的平方），别把 x、y 写反；④ 面积公式要求 L 取正向，顺时针算出来是负值；⑤ 环流量是第二类，别误用 ds。
