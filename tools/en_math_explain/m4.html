一、这节解决什么问题

微积分的前半程一直在做同一件事：给定函数，求它的导数。可现实里的问题常常倒着问。一辆车沿直线行驶，速度表读出 v(t) = 3t2，问它从出发到 t 时刻一共走了多远；一条曲线上每一点的切线斜率是 f(x)，问这条曲线到底长什么样。前者要的是 s(t)，满足 s′(t) = v(t)；后者要的是 y，满足 y′ = f(x)。共同点是：已知导数，反求原来的函数。这个反问题就是本章要造的工具，叫不定积分，它是求导的逆运算，地位相当于算术里的减法、乘法里的除法。

几何上先有个印象：如果 F 是一条满足条件的曲线，那么把 F 上下平移得到的每一条曲线，在同一横坐标处的切线斜率都一样。所以答案从来不是一个函数，而是一整族平行曲线。这个「族」的概念，就是后面那个常数 C 的来源。

二、原函数与不定积分

定义 1（原函数）设 f 在区间 I 上有定义。如果存在函数 F，使得对每一个 x ∈ I 都有

F′(x) = f(x)

就称 F 是 f 在 I 上的一个原函数。

三个词要抠清楚：「一个」，说明原函数通常不止一个；「区间」，说明必须整段成立，只在个别点成立不算；「F′ = f」，方向不能反，是 F 求导出 f，不是 f 求导出 F。

定理 1（原函数存在定理）若 f 在区间 I 上连续，则 f 在 I 上必有原函数。

这条定理只保证存在，不告诉你它长什么样——所以后面三节全部在讲「怎么找」。条件里的「连续」也不能删：含有第一类间断点的函数没有原函数，因为导数虽然不一定连续，却一定具有介值性（达布定理），跳跃型间断点做不到这一点。

定理 2（原函数的结构）若 F 是 f 的一个原函数，则 f 的全体原函数恰好是 F(x) + C，其中 C 取遍全体实数。

证明思路设 G 也是 f 的原函数，则 (G − F)′ = f − f = 0。由拉格朗日中值定理的推论，导数在区间上恒为零的函数必为常数，故 G − F ≡ C。反过来，对 F(x) + C 求导仍然得 f，所以它们确实全是原函数。两句话合起来，正好说明了为什么答案里必须写 C。

定义 2（不定积分）f 的全体原函数称为 f 的不定积分，记作

∫ f(x) dx = F(x) + C

记号里，f(x) 叫被积函数，f(x)dx 叫被积表达式，x 叫积分变量，C 叫积分常数。∫ 不要理解成「一条式子」，要理解成一个集合：它交出的是整族曲线。所以严格地说，∫f(x)dx 是一个函数族，不是一个函数，这正是它和定积分的本质区别。

三、性质

（1）线性性质若 ∫ f dx、∫ g dx 都存在，α、β 为常数，则

∫ [αf(x) + βg(x)] dx = α∫ f(x) dx + β∫ g(x) dx

它只承诺两件事：常数因子可以提到积分号外，和与差可以拆成两个积分。乘积没有对应公式，∫ fg dx 与 ∫ f dx · ∫ g dx 毫无关系，这是初学者最常见的错觉。所以一碰到乘积，必须先变形（展开、拆项、凑微分、分部），绝不能「分开积」。同理，积分号里也不能随便加常数：∫ (x + 1) dx ≠ ∫ x dx + 1，加号里的 1 必须老老实实跟着积。

（2）与求导互逆

( ∫ f(x)dx )′ = f(x)，　d( ∫ f(x)dx ) = f(x)dx
∫ F′(x) dx = F(x) + C，　∫ dF(x) = F(x) + C

先积后导，原样还原；先导后积，差一个常数。这个不对称很关键，它是不定积分不能像导数那样「直接代数运算」的原因。

（3）基本积分表把求导公式反过来读一遍，就是积分表。例如由 ( xα+1/(α+1) )′ = xα（α ≠ −1）得到幂函数公式；α = −1 时分母为零，这一格失效，而 (ln|x|)′ = 1/x 正好补上，所以要单列一条 ∫ dx/x = ln|x| + C。绝对值千万不能丢：x 取负值时 ln x 根本没有定义，而 1/x 在负数段是有定义的。

表里十几条（幂函数、1/x、ex、ax、sin、cos、sec2、csc2、1/(1 + x2)、1/√(1 − x2)、sec x、csc x）必须默写到条件反射的程度，因为本章所有技巧的终点，都是把被积函数「整成表里的样子」。

四、例题

例 1 求 ∫ ( 3x2 − 2/x + 5ex − 1/(1 + x2) ) dx。

解 都是基本表里的项，用线性性质逐项拆开。
第一项：∫ 3x2 dx = 3 · x3/3 = x3。
第二项：∫ 2·(1/x) dx = 2 ln|x|，系数 2 是提出去的常数，不是被积函数的一部分。
第三项：∫ 5ex dx = 5ex。
第四项：∫ dx/(1 + x2) = arctan x。
合并，只在最后写一个 C：
原式 = x3 − 2ln|x| + 5ex − arctan x + C

四道小题各写一个 C 是错的，常数只需一个；但每一项的符号、系数、绝对值一个都不能错。

例 2 已知 f′(x) = 3x2 + 1，且曲线 y = f(x) 经过点 (1, 4)，求 f(x)。

解 第一步，先求全体原函数（不管初始条件）：
f(x) = ∫ (3x2 + 1) dx = x3 + x + C
第二步，用「曲线过点 (1, 4)」定常数：令 x = 1，则
f(1) = 1 + 1 + C = 4，得 C = 2。
所以 f(x) = x3 + x + 2。

这类题的标准两步是「先积出带 C 的通解，再代点定 C」。顺序不能反：先代点就丢了 C，等于假设 C = 0。

例 3 求 ∫ tan2x dx。

解 表里没有 tan2，不能硬套。先做恒等变形，用 tan2x = sec2x − 1：
∫ tan2x dx = ∫ (sec2x − 1) dx = ∫ sec2x dx − ∫ dx
两项都在表里：
= tan x − x + C

「先变形、再查表」是全章的通用起手式。同类的还有 1 = sin2x + cos2x、cos 2x 的倍角公式、分子加减一项凑分母的导数。

五、易错提醒与后文联系

  • 漏写 + C。不定积分的结果是函数族，不是单个函数，漏 C 直接扣分。
  • 把 1/x 积成 ln x。正确写法是 ln|x|，负半轴就靠这个绝对值。
  • 把 ∫f·g 拆成 ∫f · ∫g。乘积没有分配律，必须先变形。
  • 以为任何函数都有原函数。连续才有；谈原函数之前先确认函数在区间上连续。
  • 初始条件忘代。给了点、给了 f(0) 这类信息，就是用来定 C 的，不代等于没做完。

这一节只解决了「被积函数正好在表里」的情形。可考试给的偏偏不在表里——复合的、带根号的、两类函数相乘的。于是下一节造第一件工具：换元，把陌生的积分改写成表里的积分。

一、为什么必然会有换元法

基本积分表只覆盖那十几个基本初等函数。但实际给出的被积函数往往是复合的，比如 ∫ 2x ex² dx。表里只有 ∫ eu du = eu + C，没有 e 的 x2 次方这一项。可你注意到，被积函数里那个 2x 恰好是 x2 的导数——这不是巧合，而是复合函数求导的必然产物：

[ F(φ(x)) ]′ = F′(φ(x)) · φ′(x)

链式法则多产生一个「内层导数」因子 φ′(x)。把这条公式倒着读，就是换元积分法。所以换元法的本质不是新技巧，而是「认出链式法则留下的脚印」。

二、第一类换元法（凑微分）

定理 3设 f 有原函数 F，φ 可导，则

∫ f(φ(x)) φ′(x) dx = F(φ(x)) + C

证明对右端求导，用链式法则：[F(φ(x))]′ = F′(φ(x))·φ′(x) = f(φ(x))·φ′(x)，正好是被积函数。故右端是左端被积函数的一个原函数，等式成立。证明只有一行，难的是用：要能把 φ′(x)dx 认出来，凑成微分 dφ(x)，整个积分就变成 ∫ f(u) du 的标准形状。

常用凑法清单（缺系数就乘一个、外面除回来）

  • x dx = ½ d(x2)，一般地 xn dx = d(xn+1)/(n + 1)
  • dx/x = d(ln|x|)；dx/x2 = −d(1/x)
  • ex dx = d(ex)；ax dx = d(ax)/ln a
  • cos x dx = d(sin x)；sin x dx = −d(cos x)；sec2x dx = d(tan x)
  • dx/(1 + x2) = d(arctan x)；dx/√(1 − x2) = d(arcsin x)
  • dx/√x = 2d(√x)；dx/(2√x) = d(√x)

记法一句话：谁的导数在旁边，就把谁塞进 d 里。凑的时候乘进去的常数，必须在外面对应除回来，这一步最容易漏。

三、第二类换元法（主动换 x）

如果被积函数里有一坨很难受的结构（根号、分母次数很高、指数是分式），那就反过来——不等它凑，主动把 x 写成 t 的函数。

定理 4设 x = ψ(t) 单调、可导且 ψ′(t) ≠ 0，又设 f(ψ(t))ψ′(t) 有原函数 Φ(t)，则

∫ f(x) dx = Φ( ψ−1(x) ) + C

为什么非要「单调」：只有单调才存在反函数 ψ−1，最后才能把 t 换回 x。这正是易错点「换元后必须回代」的根源——不定积分没有上下限，没法像定积分那样换个限就完事，只能靠反函数走回来。

三种三角代换是被根号逼出来的，不是硬背的：

  • 见到 √(a2 − x2)，令 x = a sin t，因为 1 − sin2t = cos2t，根号一开就消失；
  • 见到 √(a2 + x2)，令 x = a tan t，用 1 + tan2t = sec2t；
  • 见到 √(x2 − a2)，令 x = a sec t，用 sec2t − 1 = tan2t。

回代技巧：不要去套反三角公式。画一个直角三角形，把 t 当一个锐角，按 sin t = x/a 把对边标成 x、斜边标成 a，邻边自然是 √(a2 − x2)；sin t、cos t、tan t 直接读出来就是 x 的式子。这一步能省掉大量三角变形，考场上尤其值钱。

倒代换：当分母次数明显高于分子、又带根号时，令 x = 1/t 往往一步到位，典型是 ∫ dx/(x2√(x2 + 1)) 和 ∫ dx/(x√(x2 − 1))。根式代换则专治 √(ax + b) 型：令 t = √(ax + b) 把根号整体消掉，例如令 t = √x 得 ∫ dx/(1 + √x) = 2√x − 2ln(1 + √x) + C。

四、例题

例 1 求 ∫ x ex² dx。

解 观察：x2 的导数是 2x，被积函数里有个 x，差一个常数 2。
令 u = x2，则 du = 2x dx，即 x dx = ½ du。
于是
原式 = ½ ∫ eu du = ½ eu + C = ½ ex² + C
验算：(½ ex²)′ = ½ ex² · 2x = x ex²，与被积函数一致。

那个 ½ 是「凑」的代价：d(x2) = 2x dx，所以 x dx 只能凑成 ½d(x2)。少写这个 ½ 是本节最高频的失分点。

例 2 求 ∫ dx/√(x2 + a2)（a > 0）。

解 根号是 √(a2 + x2) 型，用 x = a tan t，t ∈ (−π/2, π/2)。此时 dx = a sec2t dt，且 √(x2 + a2) = a sec t（因为 sec t > 0）。
代入化简：
原式 = ∫ a sec2t dt / (a sec t) = ∫ sec t dt = ln|sec t + tan t| + C
回代。画直角三角形：tan t = x/a，故对边 x、邻边 a、斜边 √(x2 + a2)，于是 tan t = x/a，sec t = √(x2 + a2)/a。代入得
ln| (√(x2 + a2) + x)/a | + C = ln( x + √(x2 + a2) ) + C
后一步把常数 −ln a 并进了 C 里，这是允许的，因为 C 本来就是任意常数。

最后那个「把 −ln a 吞进 C」的动作很常用，但要说清楚：定积分里不能这么干，不定积分里可以，因为常数项本来就不确定。

例 3 求 ∫ dx/(x2√(x2 + 1))（x > 0）。

解 分母次数远高于分子，且有根号，用倒代换。令 x = 1/t（t > 0），则 dx = −dt/t2，且
x2 = 1/t2，√(x2 + 1) = √(1 + t2)/t
分母 = (1/t2)·√(1 + t2)/t = √(1 + t2)/t3。
代入：
原式 = ∫ (−dt/t2) · t3/√(1 + t2) = −∫ t dt/√(1 + t2)
此时分子 t 正好是 1 + t2 导数的一半，凑微分：
= −½ ∫ d(1 + t2)/√(1 + t2) = −√(1 + t2) + C
回代 t = 1/x：
= −√(1 + 1/x2) + C = −√(x2 + 1)/x + C

倒代换的威力在于「次数翻转」：原本 x 在分母上是二次加根号，换成 1/t 之后 t 跑到了分子上，结构立刻变简单。换完记得把 t 换回 x。

五、套路与易错

  • 换完必须回代。不定积分没有积分限可换，最后一定要把 t 换回 x，否则答案不算完成。
  • 忘乘/忘除常数。凑微分时 x dx = ½d(x2) 这种系数调整必须对称。
  • 三角函数代换忘限定范围。x = a sin t 要取 t ∈ [−π/2, π/2] 才能保证 cos t ≥ 0、开根号不出绝对值。
  • 根号开出来要带绝对值。√(x2) = |x|，不是 x。

换元法解决的是「复合」和「根号」。但还有一类被积函数是两类不同函数相乘，比如 x ex、ln x、exsin x，凑微分凑不出来。下一节用乘积求导法则来解决它们。

一、这节解决什么问题

换元法能处理复合和根号，但有一类积分它束手无策：被积函数是两类不同函数相乘，而且乘得「不配套」。比如 ∫ x ex dx，x 和 ex 之间没有导数关系，凑不出微分；再比如 ∫ ln x dx，连乘积都不是，可表里也没有 ln x 这一项。这类积分要用分部积分法。

思路来源很朴素：乘积求导法则 (uv)′ = u′v + uv′ 里出现了两个乘积，把其中一个移项，就得到积分的对称公式。这是「把难积的项，换成好积的项」。

二、公式与推导

由微分公式 d(uv) = u dv + v du，移项得

u dv = d(uv) − v du

两边同时取不定积分（左边正好是 ∫ d(uv) = uv），即得

∫ u dv = uv − ∫ v du

这就是分部积分公式。它可以等价地写成 ∫ u(x)v′(x) dx = u(x)v(x) − ∫ u′(x)v(x) dx。注意：公式本身没有降低难度，它只是把「积 u·dv」换成了「积 v·du」。用它的前提是后者比前者好积。这个判断，就是选 u 的全部学问。

三、u 怎么选：反对幂指三

选 u 的两条标准：求导后要变简单（这样 du 变小），剩下的 dv 要容易积（这样 v 立刻能写出）。两条往往冲突，于是有经验顺序：

反三角 → 对数 → 幂 → 指数 → 三角（口诀「反对幂指三」）

排在前面的当 u。理由：反三角和对数函数求导后都变成有理式或根式，确实「变简单」了；而指数和三角函数无论求导积分多少次还是自己，最适合当 dv 反复消耗。幂函数居中，视对方而定。

四种常见类型

  • 降次型（幂 × 指数／三角）：∫ xnex dx、∫ xnsin x dx。取幂作 u，每分部一次幂次降一，做 n 次收工。
  • 只含对数／反三角：∫ ln x dx、∫ arctan x dx。把 dv 取成 dx（即 v = x），u 就是 ln x 或 arctan x。
  • 循环型：∫ exsin x dx、∫ sec3x dx。分部两次后原积分重新出现，移项解方程。
  • 递推型：In = ∫ sinnx dx 这类，用分部建立 In 与 In−2 的关系。

四、例题

例 1 求 ∫ x2ex dx。

解 幂 × 指数，取幂作 u，降次。第一次：令 u = x2，dv = exdx，则 du = 2x dx，v = ex。
原式 = x2ex − ∫ ex·2x dx = x2ex − 2∫ x ex dx
对 ∫ x ex dx 再来一次：u = x，dv = exdx，得 x ex − ∫ ex dx = x ex − ex。
代回：
原式 = x2ex − 2(x ex − ex) + C = ex(x2 − 2x + 2) + C
验算：[ex(x2 − 2x + 2)]′ = ex(x2 − 2x + 2) + ex(2x − 2) = exx2，正确。

几次分部后，收尾处的常数要一起并进 C；括号一定要展开检查，否则容易漏符号。

例 2 求 ∫ ln x dx。

解 被积函数只有 ln x 一项，看起来无从下手。办法是把 dv 取成 dx：令 u = ln x，dv = dx，则 du = dx/x，v = x。
原式 = x ln x − ∫ x · (1/x) dx = x ln x − ∫ dx = x ln x − x + C
验算：(x ln x − x)′ = ln x + x·(1/x) − 1 = ln x，正确。

「只含 ln 或反三角」时，dv = dx 是唯一出路，这个套路要形成条件反射。同理 ∫ arctan x dx = x arctan x − ½ln(1 + x2) + C。

例 3 求 ∫ exsin x dx。

解 指数与三角「地位相当」，取谁都行，关键是两次都取同一类。记原积分为 I。
第一次：令 u = sin x，dv = exdx，则 du = cos x dx，v = ex：
I = exsin x − ∫ excos x dx
第二次，对后一项仍取三角作 u：u = cos x，dv = exdx，则 du = −sin x dx：
∫ excos x dx = excos x + ∫ exsin x dx = excos x + I
代回：
I = exsin x − excos x − I
把 −I 移到左边：2I = ex(sin x − cos x)，故
I = ½ ex(sin x − cos x) + C

循环型的关键是「认出来」：第二次分部后 I 重新出现，就要停手移项，绝不能再分下去，否则会无限循环。移项后别忘了除以 2，常数在最后补。

五、常考套路与易错

  • u 选错会越算越长。比如 ∫ x ln x dx 若取 u = x，则 du = dx、v = ½x2，得到 ½x2ln x − ½∫ x dx 也能算，但若遇到 ∫ x2ln x dx，取错方向会让幂次一路升上去，永远积不完。判断标准只有一条：分部后的 ∫v du 是否比原积分更简单。
  • 循环型忘记移项或忘记除以 2。
  • 分部后 ∫v du 积不出来，说明 u 选反了，退回去换一种选法，不要硬撑。
  • 多次分部时符号串联错误。每分部一次带一个负号，建议每步单独写一行再代入，别一步跨两级。

补充：递推型怎么写。以 In = ∫ secnx dx（n ≥ 3）为例，先把一次 sec2x 拆出来作 dv：In = ∫ secn−2x d(tan x)，分部得 In = secn−2x tan x − (n − 2)∫ secn−2x tan2x dx，再用 tan2x = sec2x − 1，右边就出现 In 与 In−2 的关系，移项即得递推式。套路是固定的：拆出一个平方因子当 dv，剩下的升次项用恒等式压回去。

还有一点要习惯：分部与换元经常连着用。碰到 ∫ e√x dx 这种，先令 t = √x 换成 ∫ 2t et dt，再分部；顺序反了会难算得多。

分部积分把「乘积」这一大类打通了，但它每次分部都会把问题往「有理函数」的方向推——∫ x arctan x dx 分部一次就变成有理函数积分。所以本章的最后一节，是把有理函数这一「兜底类型」彻底解决。

一、这节解决什么问题

前三节给了两类工具：换元、分部。它们各有局限，但有一个共同点——都在把问题往同一个方向推：化成一个有理函数的积分。比如分部之后出现 ∫ dx/(x2 + 1)，三角代换之后出现 ∫ dt/(1 + t2)，都是有理函数。

这一节要说明一件让人安心的事：任何有理函数都能积出来，而且方法固定、不需要灵感。所谓有理函数，就是两个多项式的商 P(x)/Q(x)。它不像 e−x² 那样「积不出来」（那类函数的原函数不是初等函数），有理函数是初等函数世界里的「封闭类」。所以这一节是整章的收口，也是考试里最稳的得分点。

二、第一步：先看次数

定义若分子次数小于分母次数，称 P/Q 为真分式；否则称为假分式。

规则：遇到假分式（分子次数 ≥ 分母次数），必须先做多项式长除法，把它拆成

P(x)/Q(x) = 多项式 + 真分式

多项式部分直接逐项积分，剩下的真分式才做部分分式分解。不能跳这一步：部分分式分解的公式只对真分式成立，对假分式硬拆，待定系数会解不出来（方程个数与未知数个数对不上）。这就是易错点里「假分式先除」的由来。

三、第二步：分母分解到实系数不可约

先把分母 Q(x) 在实数范围内彻底分解，只可能剩下两种因子：

  • 一次因子 (x − a)k；
  • 不可约二次因子 (x2 + px + q)m，其中 p2 − 4q < 0（判别式为负，不能再用实根拆开）。

分解规则（这是本节唯一需要背的东西）：

  • 每个 (x − a)k 贡献 k 项：A1/(x − a) + A2/(x − a)2 + … + Ak/(x − a)k；
  • 每个 (x2 + px + q)m 贡献 m 项：每项分子是一次式 Bjx + Cj，分母是 (x2 + px + q)j。

系数用待定系数法求：通分后比较同次幂的系数（解线性方程组），或者给 x 赋几个特殊值（尤其是分母的根）直接算出部分系数。两种方法可以混用，赋特殊值通常更快。

关键提醒：分解之前必须确认分母已经分解到实系数不可约。若把 x2 − 1 当成不可约二次因子写 (Bx + C)/(x2 − 1)，虽然形式上也对，但系数解出来会出现矛盾——因为它其实能继续拆成 (x − 1)(x + 1)。

四、第三步：两类基本积分

分解完，只剩四种形状的项，全都有固定解法：

  • ∫ A/(x − a) dx = A ln|x − a| + C；
  • ∫ A/(x − a)k dx = A(x − a)1−k/(1 − k) + C（k ≥ 2）；
  • ∫ (Ax + B)/(x2 + px + q) dx：先配方，再拆成两项——一项凑成 ln（分子配出分母的导数 2x + p），一项凑成 arctan；
  • 重二次因子 (x2 + px + q)m（m ≥ 2）：先配方换元成 ∫ dt/(t2 + c2)m，再用递推公式降 m。

最核心的一条是第三项。以 x2 + px + q 为例，配方得 (x + p/2)2 + c2，其中 c2 = q − p2/4 > 0。然后把分子写成

Ax + B = (A/2)(2x + p) + (B − Ap/2)

前半部分正好是分母导数的倍数，积出 ln；后半部分是常数，配方后积出 arctan。

五、例题

例 1 求 ∫ (x3 + 1)/(x2 − 1) dx。

解 分子三次、分母二次，是假分式，先做多项式除法：
x3 + 1 = x(x2 − 1) + (x + 1)
所以
(x3 + 1)/(x2 − 1) = x + (x + 1)/(x2 − 1)
再把真分式的分母分解：x2 − 1 = (x − 1)(x + 1)，分子正好含因子 x + 1，约掉：
(x + 1)/(x2 − 1) = 1/(x − 1)
于是
原式 = ∫ x dx + ∫ dx/(x − 1) = x2/2 + ln|x − 1| + C

先除、再约、后积——三步的顺序不能颠倒。约分这一步别漏，否则会白白多算一遍待定系数。

例 2 求 ∫ (x + 1)/(x2 − 3x + 2) dx。

解 分子一次、分母二次，已是真分式。分母分解：x2 − 3x + 2 = (x − 1)(x − 2)，两个不同一次因子，设
(x + 1)/[(x − 1)(x − 2)] = A/(x − 1) + B/(x − 2)
去分母：x + 1 = A(x − 2) + B(x − 1)。
赋特殊值：令 x = 1，左边 2，右边 A(−1)，得 A = −2；令 x = 2，左边 3，右边 B(1)，得 B = 3。
所以
原式 = ∫ [ −2/(x − 1) + 3/(x − 2) ] dx = −2ln|x − 1| + 3ln|x − 2| + C

赋特殊值比比较系数快得多，尤其分母是互异一次因子时。但要注意：赋的值必须在定义域内验证过，且每项只能定一个系数。

例 3 求 ∫ (x + 3)/(x2 + 2x + 5) dx。

解 分母判别式 4 − 20 = −16 < 0，不可约，无法再拆一次因子。这是「一次分子 + 不可约二次分母」型，配方 + 拆项。
配方：x2 + 2x + 5 = (x + 1)2 + 4，分母导数为 2x + 2。
把分子凑成分母导数的倍数加常数：
x + 3 = ½(2x + 2) + 2
于是拆成两个积分：
原式 = ½∫ (2x + 2)dx/(x2 + 2x + 5) + 2∫ dx/[(x + 1)2 + 4]
第一个用凑微分：½ ln(x2 + 2x + 5)（真分式且分母恒正，可省绝对值）。
第二个套表 ∫ du/(u2 + a2) = (1/a)arctan(u/a)，此处 u = x + 1，a = 2：
2 · (1/2) arctan((x + 1)/2) = arctan((x + 1)/2)
合并：
原式 = ½ln(x2 + 2x + 5) + arctan((x + 1)/2) + C

「配出分母导数」是这一型的固定动作：分子先写成 (A/2)(分母导数) + 常数，一个 ln 一个 arctan，缺一不可。外面那个 1/a 也常被漏掉。

六、可化为有理函数的类型与易错

有些被积函数看着不像有理函数，但换元后就是，这类题在考试里常与本节合并出现：

  • 根式型：含 √(ax + b) 或 (ax + b)1/n，令 t = √(ax + b) 或 t = (ax + b)1/n，把根号整体消掉；若同时出现 √[n](ax + b) 与 √[m](ax + b)，取 n、m 的最小公倍数作根指数。
  • 三角有理式：只含 sin x、cos x 的有理式，令 t = tan(x/2)（万能代换），则 sin x = 2t/(1 + t2)、cos x = (1 − t2)/(1 + t2)、dx = 2dt/(1 + t2)，一定化为有理函数。万能代换万能但计算量大，能凑微分时优先凑微分。

易错清单

  • 假分式不先除就分解，方程个数不够，系数解不出。
  • 分母没分解到底，把可约二次当不可约，或漏掉重因子的高次项。
  • 重因子只写一项，如 (x − 1)2 必须写 A/(x − 1) + B/(x − 1)2 两项。
  • 把 1/(x2 − a2) 直接套 arctan 公式。arctan 公式对应的是「加号」x2 + a2；减号必须拆成 (1/2a)[1/(x − a) − 1/(x + a)]，积出对数。
  • 漏 + C、漏绝对值、漏 1/a，这三样在本节出现频率最高。

学完这四节，整章的地图就完整了：查表 → 凑微分 → 换元 → 分部 → 有理函数。拿到一个积分，先扫一眼能不能查表，再判断属于哪一类，最后才动笔。这个判断顺序，比任何一条公式都重要。
