一、这节解决什么问题

矩形面积好算，可"一边是曲线"的图形就不好算。设 f(x) 在 [a,b] 上非负，由曲线 y=f(x)、x 轴及直线 x=a、x=b 围成的图形叫曲边梯形。求它的面积只有一条路：以直代曲。把 [a,b] 切成很多小段，每段上曲线几乎不变，就用一个小矩形顶替那条曲边条；切得越细误差越小，细到"最大段长趋于零"，小矩形面积之和的极限就是曲边梯形面积。定积分就是把这个极限用记号固化下来——它的本质是和式的极限，是一个数，不是函数。

二、定义：分割、近似、求和、取极限

设 f(x) 在 [a,b] 上有界。

  1. 分割：插入分点 a = x0 < x1 < … < xn = b，第 i 段长 Δxi = xi − xi−1，记 λ = max{Δx1, …, Δxn}。
  2. 近似代替：在第 i 段任取 ξi ∈ [xi−1, xi]，以 f(ξi)Δxi 作那一小条面积的近似。
  3. 求和：Sn = Σ f(ξi)Δxi。
  4. 取极限：若 λ → 0 时 Sn 的极限存在，且与分法、与 ξi 的取法都无关，则称 f 在 [a,b] 上可积，并记 ∫ab f(x) dx = limλ→0 Σ f(ξi)Δxi。

三个要害：是 λ → 0 而不是 n → ∞，等分只是取极限的一种方式；ξi 任意取，正说明可积是函数本身的性质；f 有界是可积的必要条件。

三、可积的充分条件

定理 1　若 f(x) 在 [a,b] 上连续，则 f 在 [a,b] 上可积。

定理 2　若 f(x) 在 [a,b] 上有界，且只有有限个第一类间断点（左右极限都存在的跳跃或可去间断点），则 f 可积。推论：单调有界函数可积。

注意：有界只是必要条件；狄利克雷函数（有理点取 1、无理点取 0）即不可积。为方便，规定 ∫aa f dx = 0，∫ab f dx = −∫ba f dx。

四、七条性质

  1. 线性：∫(αf + βg) dx = α∫f dx + β∫g dx。
  2. 区间可加：∫ab = ∫ac + ∫cb，c 在区间内、外都成立（靠上面的符号约定）。
  3. 保号性：f ≥ 0 ⟹ ∫ ≥ 0；进而 f ≤ g ⟹ ∫f ≤ ∫g。
  4. 绝对值不等式：|∫ab f dx| ≤ ∫ab |f| dx。
  5. 估值定理：m ≤ f ≤ M ⟹ m(b−a) ≤ ∫ab f dx ≤ M(b−a)。
  6. 积分中值定理：f 连续 ⟹ ∃ξ ∈ [a,b]，使 ∫ab f dx = f(ξ)(b−a)。
  7. 几何意义：∫ 是各块面积的代数和，x 轴上方取正、下方取负。

中值定理的证明只需两行：由估值定理 m ≤ 1b−a∫ab f dx ≤ M，中间这个数夹在最小值与最大值之间，再由连续函数的介值定理，必有 ξ 使 f(ξ) 等于它。所以"平均值 × 长度 = 积分值"，这就是函数平均值概念的来源。

五、例题

例 1　用定义计算 ∫01 x dx。

解　把 [0,1] n 等分，取右端点 ξi = i/n，则 Sn = Σ (i/n)(1/n) = 12(1 + 1n)。n → ∞ 时 λ = 1/n → 0，Sn → 1/2；f(x)=x 连续可积，极限与分法无关，得 ∫01 x dx = 12。

例 2　求 limn→∞ 1n[sinπn + sin2πn + … + sinnπn]。

解　1/n 就是 Δx，kπ/n 就是采样点 x。把它写成 1π·Σ sin(kπn)·πn，方括号里正是 f(x)=sin x 在 [0,π] 上等分、取右端点的和式。故原式 = 1π∫0π sin x dx = 1π[−cos x]0π = 2π。

识别标志：见到 1/n 与 k/n 并存的"步长 + 采样点"结构，先凑比例因子再定区间。

例 3　比较 ∫01 e−x dx 与 ∫01 e−x² dx 的大小。

解　在 [0,1] 上 x ≥ x²，eu 单调增，故 e−x ≤ e−x²（(0,1) 内严格小）。由保号性得 ∫01 e−x dx < ∫01 e−x² dx。

六、与后文的联系

本节只回答了"是什么"，还没回答"怎么算"——按定义算和式极限，除多项式外几乎无路。下一节的牛顿-莱布尼茨公式给出通道：求原函数、代端点。在此之前，两件工具够用：和式极限写成定积分、用性质比较大小或估值。

  • λ → 0 与 n → ∞ 不是一回事，只有等分时才同步；∫ab f(x)dx 中 x 是哑变量，写成 f(t)dt 完全一样。
  • 保号性只能正推：∫ ≥ 0 推不出 f ≥ 0；f 连续且 ∫ = 0 才能断言 f ≡ 0。
  • 中值定理要"连续"这个条件，仅有可积不够。

一、这节解决什么问题

按定义算定积分要和式再取极限，除极少数函数外算不动。有没有捷径？注意：曲边梯形面积随右端点移动而变，是个函数；对它求导，导数恰是被积函数本身。这就把"面积"与"原函数"接上了。而同一函数的两个原函数只差常数，代两端点相减时自动消掉——这就是牛顿-莱布尼茨公式，整章枢纽，也是微积分基本定理。

二、变上限积分与原函数存在定理

定义　设 f 在 [a,b] 上可积，令 Φ(x) = ∫ax f(t) dt，x ∈ [a,b]，称 Φ 为变上限积分。t 是积分变量（哑变量），x 是上限，出现在积分号外，二者切勿混同。

定理（原函数存在定理）　若 f 在 [a,b] 上连续，则 Φ(x) 在 [a,b] 上可导，且 Φ′(x) = f(x)。即：连续函数必有原函数，Φ 就是其中一个。

证明思路分三步：

  1. 算增量：ΔΦ = Φ(x+Δx) − Φ(x) = ∫xx+Δx f(t) dt，这一步用的是区间可加性。
  2. 用中值定理：上式 = f(ξ)Δx，其中 ξ 介于 x 与 x+Δx 之间。
  3. 取极限：ΔΦΔx = f(ξ)，当 Δx → 0 时 ξ → x，再由 f 连续得 f(ξ) → f(x)，故 Φ′(x) = f(x)。

"f 连续"这个条件只在最后一步用：把 f(ξ) 换成 f(x)。若仅有可积，结论不成立。

三、变限求导的一般公式

当上下限都是 x 的函数时，先拆成两个变上限积分，再用复合函数求导：

ddx ∫φ(x)ψ(x) f(t) dt = f(ψ(x))·ψ′(x) − f(φ(x))·φ′(x)。

结构记法：上限代入乘上限导数，减去下限代入乘下限导数。下限为常数时后一项为 0；被积函数里若还含 x，必须先把它提到积分号外（见例 2）。

四、牛顿-莱布尼茨公式

定理　设 f 在 [a,b] 上连续，F 是 f 在 [a,b] 上的任一原函数，则

∫ab f(x) dx = F(b) − F(a) = [F(x)]ab。

证明：由上面定理，Φ 是 f 的原函数；F 也是。两个原函数之差为常数，设 F(x) − Φ(x) ≡ C。令 x = a，因 Φ(a) = 0，得 C = F(a)。再令 x = b：F(b) − Φ(b) = F(a)，即 Φ(b) = F(b) − F(a)，此即所求。

公式把"和式的极限"彻底换成了"求原函数 + 代端点"。注意它要求 f 在 [a,b] 上连续（或分段连续且原函数在分界点连续），否则要拆区间。

五、例题

例 1　设 F(x) = ∫0x² sin t² dt，求 F′(x)。

解　上限是 x²，按变限公式，被积函数中的 t 要整体换成上限 x²，再乘上限的导数 2x：F′(x) = sin(x²)²·(x²)′ = sin(x⁴)·2x = 2x sin(x⁴)。两个替换——换被积变量、乘上限导数——最容易漏掉一个。

例 2　设 F(x) = ∫0x (x−t)f(t) dt，f 连续，求 F″(x)。

解　被积函数含 x，先把 x 提出积分号：F(x) = x∫0x f(t) dt − ∫0x t f(t) dt。求导（第一项用乘积法则）：F′(x) = ∫0x f(t) dt + x f(x) − x f(x) = ∫0x f(t) dt。再求导得 F″(x) = f(x)。注意两个 x f(x) 恰好抵消，这是本题的设计。

不能直接对 (x−t)f(t) 用变限公式——公式只适用于被积函数不含 x 的情形。

例 3　求 limx→0 ∫0x ln(1+t) dtx²。

解　x → 0 时分子 → 0，分母 → 0，属 0/0 型。用洛必达法则，分子求导用变限公式（把上限 x 代入）：= limx→0 ln(1+x)2x = limx→0 x2x = 12。

变限积分配洛必达是固定搭配，几乎必考。

六、常考套路与易错

  • 三个套路：变限积分求导；变限积分 + 洛必达求极限；把 N-L 用于分段函数（按分界点拆区间）。
  • 上限是复合函数（如 x²、sin x）时，务必"代入 + 乘导"两步都做。
  • 被积函数含 x 时先分离，不能套变限公式。
  • 用 N-L 前确认 f 在 [a,b] 上连续；若 f 在 c 处有间断，要 ∫ac + ∫cb 分开算。
  • Φ(x) 与 f(x) 的关系是"导与逆"：Φ′ = f，但 Φ 未必等于某个具体初等函数，别硬求。

一、换元为什么必须换限

不定积分换元后要"回代"成 x 的表达式，因为答案是一个函数；定积分是数，只由 f 在 [a,b] 上的取值决定，与积分变量用什么字母无关。所以换元时把上下限一并换成 t 的对应值，算完直接得数，不必回代。这是两者最大的差别，也是最常扣分处——换了元不换限，答案必错。

二、换元公式

定理　设 f 在 [a,b] 上连续，x = φ(t) 在 [α,β] 上有连续导数，且 φ(α) = a、φ(β) = b，φ 的值域含于 [a,b]，则

∫ab f(x) dx = ∫αβ f(φ(t))·φ′(t) dt。

三个要点：φ 只要求"端点对上、值域不越界"，不要求单调、不要求一一对应；实际计算时习惯取单调的 φ；公式从左到右是"换元"，从右到左是"凑微分"。

三、对称性、周期性与华里士公式

对称区间：若 f 在 [−a,a] 上连续，则 f 为奇函数时 ∫−aa f dx = 0；f 为偶函数时 ∫−aa f dx = 2∫0a f dx。证法：拆成 ∫−a0 + ∫0a，前者令 x = −t。更一般地有 ∫−aa f dx = ∫0a [f(x) + f(−x)] dx。

周期函数：f 以 T 为周期时，∫aa+T f dx = ∫0T f dx——长度为一个周期的积分与起点无关。

对称变换：形如 ∫0π x f(sin x) dx 的题，令 x = π − t，可得 ∫0π x f(sin x) dx = π2∫0π f(sin x) dx，把讨厌的因子 x 消掉。

华里士公式　记 In = ∫0π/2 sinnx dx = ∫0π/2 cosnx dx（n 为非负整数）。分部积分得递推：In = n−1n In−2，配合 I0 = π/2、I1 = 1，得

In = (n−1)!!n!!（n 为奇数）；　In = (n−1)!!n!!·π2（n 为偶数）。

推导只需一步：In = ∫0π/2 sinn−1x d(−cos x)，分部后得 In = (n−1)∫0π/2 sinn−2x cos²x dx = (n−1)(In−2 − In)，移项即得递推式。

四、分部积分公式

∫ab u dv = [uv]ab − ∫ab v du。与不定积分的唯一差别是：边界项必须代值，不能留成 uv + C。例：∫01 x ex dx = [x ex]01 − ∫01 ex dx = e − (e − 1) = 1。

五、例题

例 1　求 ∫04 dx1 + √x。

解　令 √x = t，则 x = t²，dx = 2t dt；x: 0 → 4 对应 t: 0 → 2。于是原式 = ∫02 2t1+t dt = 2∫02(1 − 11+t) dt = 2[ t − ln(1+t) ]02 = 4 − 2ln3。这里换了元就换了限，最后直接得数，没有回代。

例 2　求 ∫0π/2 sin5x dx。

解　n = 5 为奇数，用华里士公式：I5 = 4!!5!! = 4·25·3·1 = 815。

公式只对 0 到 π/2 的纯 sinn 或 cosn 成立；n 为偶数时别忘再乘 π/2；若是 sin3x cos2x，要先用 sin²x = 1 − cos²x 化成同一个函数再降幂。

例 3　求 I = ∫0π x sin x1 + cos²x dx。

解　令 x = π − t，则 sin x = sin t，cos²x = cos²t，dx = −dt，x: 0 → π 对应 t: π → 0。代入并把上下限换回升序：I = ∫0π (π−t) sin t1 + cos²t dt = π∫0π sin t1+cos²t dt − I。于是 2I = π∫0π sin x1+cos²x dx。再令 u = cos x（du = −sin x dx，x: 0 → π 对应 u: 1 → −1）：∫0π sin x1+cos²x dx = ∫−11 du1+u² = [arctan u]−11 = π2。故 2I = π·π2，即 I = π²4。

套路：被积函数含 x，且其余部分是 x 的偶对称（或 π 对称）函数，就用 x → π − t 造出与原式相同的一项，相加除以 2。

六、易错提醒

  • 换元必换限；若忘记把 dx 也换成 φ′(t)dt，答案一样会错。
  • 对称性只在对称区间且函数有相应奇偶性时可用，区间不对称就别用。
  • 华里士公式的区间固定是 [0, π/2]，上下限一变，公式失效，要先用对称性或周期性化过去。
  • 分部积分的边界项要代值；选 u 的顺序遵循"反、对、幂、指、三"，u 取的应是求导后变简单的那个。

一、这节解决什么问题

前面要求区间有限、函数有界。可实际问题里两样都会破：面积可延伸到无穷远（如 y = 1/x² 向右无限延伸），函数也可在端点附近冲到无穷（如 y = 1/√x 在 0 附近）。这类积分还能算吗？能，办法是先按正常积分算到有限处，再取极限。有趣的是，无限大的面积可能是有限的：∫1∞ dxx² = 1，而 ∫1∞ dxx 是无穷——收敛与否，看函数衰减得够不够快。

二、无穷限反常积分

定义　设 f 在 [a, +∞) 上连续，称 ∫a+∞ f(x) dx = limb→+∞ ∫ab f(x) dx，若右端极限存在且有限，称积分收敛，否则称发散。下限为 −∞ 同理。

对 ∫−∞+∞，须任取 c 拆成 ∫−∞c + ∫c+∞，两段都收敛才算收敛。

例：∫1+∞ dxx² = limb→+∞ [−1x]1b = limb→+∞(1 − 1b) = 1。

三、无界函数的反常积分（瑕积分）

若 f 在 a 的右邻域内无界，a 称为瑕点，定义 ∫ab f(x) dx = limε→0⁺ ∫a+εb f(x) dx。瑕点在 b 端、或在内部 c 处，做法相同：内部瑕点必须拆成 ∫ac + ∫cb，两块都收敛才算收敛。

为什么非要拆？因为 limε→0⁺ (∫−1−ε dxx + ∫ε1 dxx) = 0，但 ∫−11 dxx 其实发散——两个无穷大恰好抵消，那是柯西主值，不是积分值。

四、两个 p-积分（判敛的尺子）

p ≠ 1 时，∫1b x−pdx = b1−p − 11 − p。p > 1 时 1 − p < 0，b1−p → 0，极限为 1/(p−1)；p < 1 时 b1−p → +∞，发散；p = 1 时 ∫1b dxx = ln b → +∞，发散。于是

∫1+∞ dxxp 收敛 ⟺ p > 1；而 ∫01 dxxp 收敛 ⟺ p < 1。

两把尺子方向相反，这是最容易记混的一处。原因很直观：趋向无穷时，分母的幂次越大衰减越快，所以 p 要大；趋向 0 时，分母的幂次越大爆得越猛，所以 p 要小。

五、比较判别法

设 f、g 在 [a, +∞) 上非负连续，且 f(x) ≤ g(x)。则：∫g 收敛 ⟹ ∫f 收敛；∫f 发散 ⟹ ∫g 发散（"大的收敛，小的必收敛；小的发散，大的必发散"）。

极限形式更好用：若 limx→+∞ f(x)g(x) = l，当 0 < l < +∞ 时二者同敛散。实战做法：抓 f 的主部（x → ∞ 时留下最高阶项，x → 0 时留下最低阶项），与 p-积分比阶。

六、例题

例 1　求 ∫0+∞ x e−x dx。

解　先算到有限上限 b，分部积分：∫0b x e−xdx = [−x e−x]0b + ∫0b e−xdx = −b e−b + (1 − e−b)。令 b → +∞，由洛必达 b e−b → 0，故原式 = 0 + 1 = 1。

例 2　判断 ∫1+∞ dxx√(x²+1) 的敛散性。

解　x → +∞ 时 1x√(x²+1) ~ 1x²。取 g(x) = 1/x²，则 limx→+∞ f(x)g(x) = limx→+∞ x√(x²+1) = 1。由极限比较判别法同敛散，而 ∫1+∞ dxx² 中 p = 2 > 1，收敛，故原积分收敛。判敛不必求值。

例 3　判断 ∫01 dx√(x(1−x)) 的敛散性，若收敛求其值。

解　x = 0 与 x = 1 都是瑕点，取 c = 1/2 拆开分别判。x → 0⁺ 时 √(x(1−x)) ~ √x，被积函数 ~ 1/√x，p = 1/2 < 1 收敛；x → 1⁻ 时同阶于 1/√(1−x)，也收敛，故整体收敛。

求值：令 x = sin²t，t ∈ [0, π/2]，dx = 2 sin t cos t dt，且 √(x(1−x)) = √(sin²t cos²t) = sin t cos t。代入得 ∫0π/2 2 sin t cos tsin t cos t dt = ∫0π/2 2 dt = π。

拆开时只需判"每一块是否收敛"；求值时可整体用一个换元，没必要求两次极限。

七、易错提醒

  • 不能把 +∞ 直接代入原函数：先写 limb→+∞ 算有限端点，再取极限，顺序颠倒会出假结果。
  • 两个 p-积分方向相反：无穷限要 p > 1 才收敛，瑕点要 p < 1 才收敛。
  • 内部瑕点必须拆，两块都收敛才算收敛，抵消出的 0 不算数。
  • 比较判别法只对非负函数成立；有正有负时先加绝对值，或直接按定义算。判敛题只要结论，不必硬求原函数。
