一、这节解决什么问题

一元函数 y = f(x) 只有一个自变量，点只能从左、右两侧逼近；可现实里的量往往同时依赖好几个因素：房间的温度 T 取决于位置 (x, y) 与时间 t，矩形的面积 S = xy 取决于长和宽，山坡的高度 h 取决于脚下的经度与纬度。把这类"多个输入、一个输出"的对应关系抽象出来，就得到多元函数。几何上，二元函数 z = f(x, y) 的图形是空间中的一张曲面，定义域则是 xOy 平面上的一块平面点集。本节只做两件事：把"平面上的集合"说清楚，把"点无限接近"这件事在二维里重新定义一遍——后面偏导、全微分、可微性的定义全都长在这个定义上。

二、平面点集：邻域、开集、区域

设 P₀(x₀, y₀) 是平面上一点，δ > 0。称点集

U(P₀, δ) = { P : |P P₀| < δ }

为 P₀ 的 δ 邻域（一个开圆盘）；挖掉圆心后称为去心邻域，记作 0 < |P P₀| < δ。要习惯"去心"三个字：极限只关心 P 靠近 P₀ 的过程，与 P 在 P₀ 处取什么值毫无关系。

几个基本概念：若存在 δ 使 U(P₀, δ) 整个含于 E，则 P₀ 是 E 的内点；若 P₀ 的任何邻域内既有 E 的点、又有不属于 E 的点，则 P₀ 是 E 的边界点。若 E 的每一点都是内点，称 E 为开集；开集且任意两点可用 E 内的折线相连（连通），称开区域，简称区域；开区域连同它的全部边界点，称闭区域。若存在正数 M 使 E 含于以原点为心、M 为半径的圆内，则称 E 有界。

这套名词不是装饰。一元里"连续函数在闭区间上必有最大值最小值"这条定理，靠的正是"闭"与"有界"；多元的最值定理一字不改地搬过来，条件也是"有界闭区域"。所以做题前先看定义域是开是闭，往往决定最值到底能不能取到。

三、二重极限：定义与三个要害

定义　设 f 在 P₀ 的某去心邻域内有定义，A 为常数。若对任意 ε > 0，总存在 δ > 0，使得当 0 < √((x − x₀)² + (y − y₀)²) < δ 时恒有 |f(x, y) − A| < ε，则称当 P → P₀ 时 f 的极限为 A，记

lim(x,y)→(x₀,y₀) f(x, y) = A　或　limP→P₀ f(P) = A。

与一元相比，三处不同必须记牢：

  1. 逼近方式任意。P 可以沿直线、抛物线、螺旋线趋于 P₀，路径有无穷多条，必须"所有路径都趋于同一个 A"才算极限存在。这一条既是难点，也是最好用的工具——只要两条路径给出不同结果，就能判死刑。
  2. 与 f(P₀) 无关。P₀ 可以不在定义域内，f(P₀) 可以没有定义，极限照样可能存在。
  3. 累次极限不是二重极限。limx→x₀ limy→y₀ f 是先后两次一元极限，它存在并不保证二重极限存在；反过来二重极限存在时，累次极限也未必存在。二者只在附加条件下才一致，所以"先代 y 再代 x"不能当作求二重极限的通用方法。

四、两个判定工具

路径法（用来否定）。取一条路径（如 y = kx、y = kx²、x = y²）算出一个与 k 有关的极限；k 一变结果就变，或某条路径的极限不存在，立刻断定二重极限不存在。常见顺序是先试 y = kx；若结果与 k 无关，再试 y = kx²，因为二次曲线能逃过直线检测。

极坐标法（用来肯定）。令 x = x₀ + r cos θ，y = y₀ + r sin θ，则 P → P₀ 等价于 r → 0⁺。若能把 f 写成 f = A + g(r, θ)，且 |g(r, θ)| ≤ φ(r) 对一切 θ 成立、φ(r) → 0，则极限为 A。关键在"对 θ 一致"：只验证每个固定 θ 下趋于 A 是不够的。

五、连续

若 limP→P₀ f(P) = f(P₀)，则称 f 在 P₀ 连续。多项式、有理式在分母不为零处、初等函数在其定义域内都连续；需要单独讨论的只有两类点：分母为零的点，以及分段函数的分界线。一元连续函数的四则运算与复合运算保连续，多元完全一样。

有界闭区域上的连续函数具有三条性质：有界性（存在 M 使 |f| ≤ M）、最值性（必取得最大值与最小值）、介值性（取到两个函数值之间的一切值）。第八节"有界闭区域上求最值"的整套流程之所以敢说"最值一定存在"，靠的就是这里的极值性定理。

六、例题

例 1　求 lim(x,y)→(0,0) x²yx² + y²。

解　先看分母：x² + y² 是二阶，分子是三次，直觉上应当趋于 0。严格做法是放大。
因为 0 ≤ x² ≤ x² + y²（x, y 不同时为零），所以 x²x² + y² ≤ 1。于是
0 ≤ |x²yx² + y²| = |y| · x²x² + y² ≤ |y|，
而 (x, y) → (0, 0) 时 |y| → 0。由夹逼准则，原极限 = 0。
（也可用极坐标：x²y/(x² + y²) = r cos²θ sin θ，其绝对值 ≤ r → 0，且与 θ 无关。）

本题的关键是"把不确定的部分放大成一个只与 |y| 有关的量"。分子次数高于分母的齐次分式，首选这一招。

例 2　证明 lim(x,y)→(0,0) xyx² + y² 不存在。

解　沿直线 y = kx（x ≠ 0）趋近原点，此时
f(x, kx) = k x²(1 + k²) x² = k1 + k²，
极限值只与 k 有关。取 k = 1 得极限 12；取 k = 0（即沿 x 轴）得极限 0。两条路径给出不同结果，故二重极限不存在。

"路径不同、结果不同"就足够，不必穷举。反过来不成立：验证一百条路径结果相同，也不能证明极限存在。

例 3　设 f(x, y) = xyx² + y²（(x, y) ≠ (0, 0)），f(0, 0) = 0，讨论 f 在原点是否连续。

解　连续要求 lim(x,y)→(0,0) f(x, y) = f(0, 0) = 0。由例 2，左端极限根本不存在，更谈不上等于 0，故 f 在原点不连续。
顺带指出：这个函数沿 x 轴、y 轴都恒等于 0，两条坐标轴方向"看着很好"，斜方向却一塌糊涂——这正是二元连续性比一元复杂的地方，也是下一节"偏导存在推不出连续"的伏笔。

判断分段函数在分界线上的连续性，标准动作三步：算函数值、算二重极限、比较二者。分界线上的每一点都要单独处理。

七、与后文的联系与易错提醒

  • 本节的极限语言是后面一切定义的模板：偏导数是沿坐标轴方向的特殊一元极限，可微性是关于 ρ = √(Δx² + Δy²) 的二重极限，方向导数是沿射线的一元极限。定义读不通时，回到本节重读往往就通了。
  • 易错 1：把累次极限当成二重极限。题目写的是 lim(x,y)→(0,0)，就不许先代 y 再代 x。
  • 易错 2：只算两条路径结果相同就断言极限存在。路径法只能否定，不能肯定。
  • 易错 3：忘记"去心"，把 f(P₀) 混进极限过程。

一、这节解决什么问题

曲面 z = f(x, y) 上取定一点 M₀(x₀, y₀, z₀)，过 M₀ 有无数条曲线。最简单的问法是：只沿平行于 x 轴的方向走，高度变化多快？把 y 冻结在 y₀，曲面被平面 y = y₀ 截出一条平面曲线，这条曲线在 M₀ 处切线的斜率，就是 f 对 x 的偏导数。所以偏导数就是"控制其他变量不动、只看一个变量"的变化率——它比全微分好算，却也因此丢掉了很多信息，这一点下一节会算总账。

二、定义与求法

定义　设 z = f(x, y) 在 P₀(x₀, y₀) 的某邻域内有定义，若极限

fx(x₀, y₀) = limΔx→0 f(x₀ + Δx, y₀) − f(x₀, y₀)Δx

存在，则称此极限为 f 在 P₀ 处对 x 的偏导数，记作 fx(x₀, y₀)、∂z/∂x 或 zx。同理

fy(x₀, y₀) = limΔy→0 f(x₀, y₀ + Δy) − f(x₀, y₀)Δy。

若 f 在区域 D 内每一点都有偏导，就得到偏导函数 fx(x, y)、fy(x, y)，习惯上仍简称为偏导数。求法只有一句：对 x 求偏导时，把 y 当作常数，一元的所有求导公式、四则法则、复合法则照用不误。对 y 求偏导时把 x 当常数。

三、几何意义

fx(x₀, y₀) 是曲面与平面 y = y₀ 的交线 Cx 在 M₀ 处切线对 x 轴的斜率，即该切线与 x 轴正向夹角的正切；fy(x₀, y₀) 则是曲面与平面 x = x₀ 的交线在 M₀ 处切线的斜率。注意"斜率"是相对于 x 轴（或 y 轴）而言的，不是空间直线的方向余弦；两条切线一般不是同一条直线，它们张成的平面才是下一节要讲的切平面。

四、高阶偏导与混合偏导

偏导仍是 x, y 的函数，可以继续求偏导，得四个二阶偏导：

fxx = ∂²z/∂x²，fxy = ∂²z/∂y∂x，fyx = ∂²z/∂x∂y，fyy = ∂²z/∂y²。

记号约定：fxy 表示先对 x、再对 y 求导，即 fxy = (fx)y。关于两个混合偏导是否相等，有定理：

定理　若 fxy 与 fyx 都在区域 D 内连续，则在 D 内 fxy = fyx。

所以考试中只要函数是初等函数（在定义域内偏导连续），两个混合偏导可以放心地当成相等，先对谁求导方便就选谁。但这只是充分条件：连续性去掉以后，二者可以不相等，例 3 就是一个标准反例。

五、一个必须先说清的坑

偏导存在，只保证"沿两条特殊方向"的一元函数可导，完全不涉及其他方向，甚至不涉及该点是否连续。仍取例 2 的函数 f = xy/(x² + y²)，补充 f(0, 0) = 0。因为沿 x 轴 f ≡ 0，有

fx(0, 0) = limΔx→0 f(Δx, 0) − f(0, 0)Δx = 0，同理 fy(0, 0) = 0，

两个偏导都存在，可上一节已证 f 在原点不连续。可见"偏导存在 ⟹ 连续"是假命题，这个反例要背下来。另外，分段函数在分界线上求偏导，必须回到定义，不能对分段表达式直接求导再代点——因为分界点附近函数根本不由那一段表达式决定。

六、例题

例 1　设 z = xy（x > 0），求 zx、zy。

解　对 x 求偏导时 y 是常数，这是幂函数：
zx = y xy−1。
对 y 求偏导时 x 是常数，这是指数函数：
zy = xy ln x。

同一个函数，对 x 看是幂函数、对 y 看是指数函数，两套公式各用一次，绝不冲突。这类题专治"一个公式套到底"。

例 2　设 z = arctan(y/x)，验证 zxx + zyy = 0。

解　先求一阶偏导。由链式法则
zx = 11 + (y/x)² · (−yx²) = −yx² + y²，
zy = 11 + (y/x)² · 1x = xx² + y²。
再求二阶：把 zx = −y(x² + y²)−1 对 x 求导，
zxx = −y · (−1)(x² + y²)−2 · 2x = 2xy(x² + y²)²；
把 zy = x(x² + y²)−1 对 y 求导，
zyy = x · (−1)(x² + y²)−2 · 2y = −2xy(x² + y²)²。
两式相加得 zxx + zyy = 0，验证完毕。

这就是拉普拉斯方程。求二阶偏导时把一阶结果写成负幂，再乘内层导数，比硬套商法则快得多，也不容易丢负号。

例 3　设 f(x, y) = xy(x² − y²)x² + y²（(x, y) ≠ (0, 0)），f(0, 0) = 0。求 fxy(0, 0) 与 fyx(0, 0)。

解　两个偏导都要在原点用定义算。先算 fx(0, y)（y ≠ 0）：
fx(0, y) = limΔx→0 f(Δx, y) − f(0, y)Δx
= limΔx→0 y(Δx² − y²)Δx² + y² = y(0 − y²)y² = −y。
又 fx(0, 0) = 0（沿 x 轴 f ≡ 0）。于是
fxy(0, 0) = limΔy→0 fx(0, Δy) − fx(0, 0)Δy = limΔy→0 −ΔyΔy = −1。
对称地，fy(x, 0) = x，fy(0, 0) = 0，故
fyx(0, 0) = limΔx→0 fy(Δx, 0) − fy(0, 0)Δx = limΔx→0 ΔxΔx = 1。
所以 fxy(0, 0) = −1 ≠ 1 = fyx(0, 0)，两个混合偏导不相等。

原因不在公式，而在条件：这个函数的 fxy、fyx 在原点不连续，定理的充分条件不满足。凡"验证混合偏导相等"的题，只要函数是初等的（偏导连续），直接写"因偏导连续故相等"即可。

七、易错提醒

  • 偏导存在推不出连续，反例见正文；考试常用它出判断题。
  • 求 fx 时把 y 当常数，但代值时 y 仍是变量，别把 y 顺手代成某个数。
  • 分界线上（分母为零、分段拼接处）求偏导，一律回到定义，写成极限再算。
  • fxy 与 fyx 的次序按"先写先求"理解，写答案时保留自己用的约定；求 zxy 忘不掉的前提是二者连续时相等。

一、这节解决什么问题

一元函数有 dy = f′(x)dx：增量 Δy 可以拆成"线性主部 + 比 Δx 高阶的无穷小"，于是能用切线代替曲线做近似。多元函数的增量 Δz 依赖 Δx 与 Δy 两个方向，情形复杂得多，但想法完全一样：能不能用 Δx、Δy 的一个线性式去近似 Δz，误差比两点间距离更高阶？能，就叫可微。先看一个原型：矩形面积 A = xy，长宽各增 Δx、Δy 后

ΔA = (x + Δx)(y + Δy) − xy = yΔx + xΔy + ΔxΔy。

前两项是线性的，最后一项 ΔxΔy 相对于 ρ = √(Δx² + Δy²) 是二阶小量，可以并入 o(ρ)。所以 dA = yΔx + xΔy，这就是全微分最早的样子。

二、定义

定义　设 z = f(x, y) 在 P₀(x₀, y₀) 的某邻域内有定义，若

Δz = f(x₀ + Δx, y₀ + Δy) − f(x₀, y₀) = AΔx + BΔy + o(ρ)，ρ = √(Δx² + Δy²)，

其中 A、B 只与 P₀ 有关而与 Δx、Δy 无关，则称 f 在 P₀ 可微，并称线性主部 AΔx + BΔy 为 f 在 P₀ 的全微分，记作 dz，即 dz = AΔx + BΔy。由于自变量的增量等于其微分，Δx = dx、Δy = dy，习惯写成

dz = A dx + B dy。

这个定义的要害是"o(ρ)"：误差必须比 ρ 更高阶，仅仅"误差趋于 0"是不够的（那只是连续）。

三、两个定理

定理 1（可微的必要条件）　若 f 在 P₀ 可微，则 f 在 P₀ 的偏导数存在，且 A = fx(P₀)、B = fy(P₀)；从而 dz = fxdx + fydy。并且 f 在 P₀ 连续。

证明思路　在定义式中令 Δy = 0，则 ρ = |Δx|，

f(x₀ + Δx, y₀) − f(x₀, y₀) = AΔx + o(|Δx|)，

两边除以 Δx 再令 Δx → 0，得 A = fx(P₀)。B = fy(P₀) 同理。至于连续，只需注意 Δz = AΔx + BΔy + o(ρ) → 0。逆命题都不成立：偏导存在推不出可微（例 2），连续更推不出可微。

定理 2（可微的充分条件）　若 f 的偏导数 fx、fy 在 P₀ 的某邻域内存在，且在 P₀ 连续，则 f 在 P₀ 可微。

证明（分步）　把 Δz 拆成两段，每段只让一个变量动：

Δz = [f(x₀ + Δx, y₀ + Δy) − f(x₀, y₀ + Δy)] + [f(x₀, y₀ + Δy) − f(x₀, y₀)]。

第一个方括号里 y 固定为 y₀ + Δy，对 x 用一元拉格朗日中值定理，得 fx(ξ, y₀ + Δy)Δx，ξ 介于 x₀ 与 x₀ + Δx 之间；第二个方括号同理得 fy(x₀, η)Δy，η 介于 y₀ 与 y₀ + Δy 之间。由 fx、fy 在 P₀ 连续，可写成

fx(ξ, y₀ + Δy) = fx(P₀) + α，fy(x₀, η) = fy(P₀) + β，

其中 Δx → 0、Δy → 0 时 α → 0、β → 0。于是

Δz = fx(P₀)Δx + fy(P₀)Δy + αΔx + βΔy，

而 |αΔx + βΔy| / ρ ≤ |α| + |β| → 0，即 αΔx + βΔy = o(ρ)。故 f 在 P₀ 可微。证毕。

四、怎么判定"不可微"

若偏导已存在，就把定义式当判据：计算

limρ→0 Δz − [fx(P₀)Δx + fy(P₀)Δy]ρ，

极限为 0 则可微；极限不存在或不为 0，就不可微。实操上常取一条特殊路径（如 Δy = Δx）代入，若得到非零常数，即可断定不可微。三者关系要背成一张图：偏导连续 ⟹ 可微 ⟹（连续 且 偏导存在），三个箭头一个都不能反向。

五、例题

例 1　设 z = x²y + y³，求 dz，并写出在点 (1, 1) 处的全微分。

解　先求两个偏导：zx = 2xy，zy = x² + 3y²。二者都是多项式，处处连续，故 f 处处可微，且
dz = 2xy dx + (x² + 3y²) dy。
在 (1, 1) 处代入偏导的值（不是 z 的值）：zx(1, 1) = 2，zy(1, 1) = 4，所以
dz = 2dx + 4dy。

初等函数在定义域内偏导连续，直接写"可微"即可，不必每次回到定义验证。易错点是把 z(1, 1) = 2 当成系数代进去。

例 2　设 f(x, y) = xy√(x² + y²)（(x, y) ≠ (0, 0)），f(0, 0) = 0。问 f 在原点是否可微？

解　第一步，用定义求偏导。因 f(Δx, 0) ≡ 0，
fx(0, 0) = limΔx→0 f(Δx, 0) − f(0, 0)Δx = 0，同理 fy(0, 0) = 0。
第二步，写出 Δz：
Δz = f(Δx, Δy) − f(0, 0) = Δx Δyρ，ρ = √(Δx² + Δy²)。
第三步，按判据算比值：
Δz − 0·Δx − 0·Δyρ = Δx ΔyΔx² + Δy²。
取路径 Δy = Δx，该比值恒等于 12；取路径 Δy = 2Δx，比值为 25。极限不存在，故 f 在原点不可微。

这个函数在原点连续、两个偏导都存在，却仍不可微——它说明"连续 + 偏导存在"推不出可微。判断不可微时，只需一条路径给出非零常数就够。

例 3　用全微分近似计算 (1.02)1.97。

解　取 f(x, y) = xy，P₀ = (1, 2)，Δx = 0.02，Δy = −0.03。
f(1, 2) = 1；fx = y xy−1，fx(1, 2) = 2；fy = xy ln x，fy(1, 2) = 0。
由 f(P₀ + ΔP) ≈ f(P₀) + fxΔx + fyΔy，得
(1.02)1.97 ≈ 1 + 2 × 0.02 + 0 × (−0.03) = 1.04。
（精确值约 1.0397，误差在千分之一量级，说明线性近似够用。）

基地选在"好算的点"，Δx、Δy 由题目给出，代完就结束。注意 fy(1, 2) = 0 不是算错，而是 ln 1 = 0。

六、与后文联系与易错

  • dz = zxdx + zydy 是本章所有公式的母版：链式法则由它推出，隐函数求导由它变形，方向导数是它除以 ρ 取极限，曲面切平面是它的几何实现（第六节会看到切平面方程 z − z₀ = fxΔx + fyΔy 正是全微分）。
  • dz 是 Δz 的线性主部，不是 Δz 本身；两者相差 o(ρ)。
  • "偏导连续"是可微的充分条件而非必要条件，存在可微但偏导不连续的函数，所以不能用"偏导不连续"去否定可微。
  • o(ρ) 中的 ρ 是两点间距离 √(Δx² + Δy²)，不是 |Δx| + |Δy|，虽然二者同阶。

一、这节解决什么问题

一元复合函数有链式法则 dy/dx = f′(u)·u′(x)，一层一层乘下去就行。多元的情形多了一种可能：中间变量不止一个，而且每个中间变量都可能同时依赖好几个自变量，于是"乘"变成了"乘完再相加"。典型场景：z = f(u, v)，而 u、v 又都是 x、y 的函数，问 z 对 x 的偏导是多少。答案是所有路径上各段偏导之积的总和——这句话比任何公式都好用。

二、定理（链式法则）

定理　设 z = f(u, v) 在对应点 (u, v) 处可微，u = u(x, y)、v = v(x, y) 的偏导数存在，则复合函数 z = f(u(x, y), v(x, y)) 的偏导数存在，且

∂z/∂x = ∂f/∂u · ∂u/∂x + ∂f/∂v · ∂v/∂x，　∂z/∂y = ∂f/∂u · ∂u/∂y + ∂f/∂v · ∂v/∂y。

证明思路　f 可微意味着 Δz = fuΔu + fvΔv + o(ρ)，ρ = √(Δu² + Δv²)。两边同除以 Δx。第一、二项分别给出 fu·(Δu/Δx) 与 fv·(Δv/Δx)，令 Δx → 0 就得到两个乘积项；关键是余项 o(ρ)/Δx → 0，因为 ρ ≤ |Δu| + |Δv|，而 |Δu/Δx|、|Δv/Δx| 都趋于有限的偏导值，所以 o(ρ)/Δx = (o(ρ)/ρ)·(ρ/Δx) → 0。条件里"f 可微"不能省，这一条常被忽略。

树状图　从 z 出发画变量依赖树：z 连到 u、v，u、v 再连到 x、y。规则有三条：一条从 z 到 x 的路径对应一个乘积项（各段偏导相乘）；有几条路径就有几项；所有路径相加。有几个中间变量，就有几项相加，这是检查漏项的最快办法。

把这套规则推广到一般情形：设 z = f(u₁, u₂, …, um)，而每个 ui 都是 x₁, x₂, …, xn 的函数，则

∂z/∂xj = Σi=1m (∂f/∂ui)(∂ui/∂xj)，j = 1, 2, …, n。

公式虽长，含义仍是"所有路径求和"，所以画图永远比背公式可靠。

三、四种常见形态

  • 一元套多元（全导数）：z = f(u, v)，u = u(t)，v = v(t)，则 dz/dt = fuu′(t) + fvv′(t)。因为最终只有一个自变量，用 d 不用 ∂，叫全导数。
  • 多元套多元：正文定理的情形，写出两条偏导公式即可。
  • 混合型：z = f(u, x, y)，其中 u = u(x, y)。这时 z 对 x 求偏导要算两条路径：一条经由 u，一条是 x 作为 f 的第三个自变量直接出现，故 zx = fuux + fx（后一个 fx 是"把 u 当常数、对第三个位置求偏导"）。这一型最容易漏掉直接项。
  • 抽象函数：f 没有具体表达式时，用 f1′、f2′ 表示对第 1、2 个位置求偏导，f12″ 表示先对第 1 位置、再对第 2 位置求偏导。求高阶时必须记住 f1′ 仍是 u、v 的函数，还要继续链式展开。

四、例题

例 1　设 z = f(x² − y², exy)，其中 f 具有连续偏导，求 zx、zy。

解　令 u = x² − y²，v = exy，则 z = f(u, v)
ux = 2x，uy = −2y；vx = y exy，vy = x exy。
按链式法则，有两条路径，故两项相加：
zx = f1′ · 2x + f2′ · y exy；
zy = f1′ · (−2y) + f2′ · x exy。

先把 u、v 的四个偏导一次算齐，再往公式里填，比边写边算可靠。f1′、f2′ 后面不必再写 (u, v)，但要清楚它们仍是 u、v 的函数。

例 2　设 z = f(x + y, xy)，f 具有二阶连续偏导，求 zxy。

解　令 u = x + y，v = xy。
zx = f1′ · 1 + f2′ · y = f1′ + y f2′。
再对 y 求导，注意 f1′ 与 f2′ 都依赖 u、v，仍要链式：
(f1′)y = f11″ · 1 + f12″ · x；
(y f2′)y = f2′ + y(f21″ · 1 + f22″ · x)。
合并，并用 f21″ = f12″：
zxy = f11″ + x f12″ + f2′ + y f12″ + xy f22″
= f11″ + (x + y) f12″ + xy f22″ + f2′。

三处易错：乘积 y f2′ 求导时别把 f2′ 当常数（要用乘积法则，产生 f2′ 这一项）；f1′ 对 y 求导要走链式；最后一项是 xy f22″ 而不是 y f22″。

例 3　设 z = uv，u = et，v = sin t，求 dz/dt。

解　这是全导数。u′(t) = et，v′(t) = cos t，于是
dz/dt = ∂z/∂u · du/dt + ∂z/∂v · dv/dt = v et + u cos t
= et sin t + et cos t = et(sin t + cos t)。

也可先把 z = et sin t 代进去直接对 t 求导，结果一致。全导数题两条路都行，但中间变量多于两个时，链式法则明显省力。

五、易错与常考套路

  • 漏项是头号错误。动笔前先画树，数清从 z 到自变量的路径条数，写完对照一遍；对称的树结构里，对 x 有几条路径，对 y 通常也该有几条，数目对不上就是漏了。
  • 抽象函数的 f1′ 是函数不是常数，再求导必须继续链式；f12″ 与 f21″ 在二阶偏导连续时相等。
  • z = f(u, x) 这类"中间变量与自变量同名"的题，务必分清哪个 x 是位置、哪个是变量，必要时换成 z = f(u, s) 再代 s = x，能避免张冠李戴。
  • 本节与下一节的关系：隐函数求导公式 zx = −Fx/Fz 就是把 F(x, y, z(x, y)) ≡ 0 用本节链式法则求导得到的，所以链式法则是隐函数一节的地基。

一、这节解决什么问题

圆的方程 x² + y² = 1 能解出 y = ±√(1 − x²)，于是 y 对 x 求导不成问题。但绝大多数方程解不出来：ez − xyz = 0、z³ − 3xyz = a³，谁也写不出 z = z(x, y) 的显式表达式。可实际计算又偏偏需要 zx、zy。隐函数求导定理回答的正是这件事：不必解出 z，只要 F 的偏导满足条件，z 就自动是 (x, y) 的可微函数，而且它的偏导能由 F 的偏导直接算出。

二、一个方程的隐函数定理

定理　设 F(x, y, z) 在点 P₀(x₀, y₀, z₀) 的某邻域内有连续偏导数，且

F(x₀, y₀, z₀) = 0，　Fz(x₀, y₀, z₀) ≠ 0，

则在该邻域内方程 F(x, y, z) = 0 唯一确定一个连续可微的隐函数 z = z(x, y)，满足 z(x₀, y₀) = z₀，且

zx = − FxFz，　zy = − FyFz。

推导　把 z = z(x, y) 代回方程，得到关于 x、y 的恒等式 F(x, y, z(x, y)) ≡ 0。两边对 x 求偏导（此时 y 视为常数，z 是 x 的复合函数，用上一节链式法则）：

Fx · 1 + Fy · 0 + Fz · zx = 0，

因 Fz ≠ 0，解出 zx = −Fx/Fz。对 y 同理得 zy = −Fy/Fz。记忆要点：负号来自"移项"，分母永远是 Fz（被求的那个变量的偏导），分子是 F 对相应自变量的偏导。平面情形 F(x, y) = 0 时，dy/dx = −Fx/Fy，是同一个公式降一维。

条件 Fz ≠ 0 不是摆设：F = z² − x² − y² 在原点处 Fz = 0，那里方程确定不了唯一的 z（上半球与下半球在赤道处交汇），公式自然失效。定理里"某邻域内唯一确定"这半句也要读懂：唯一性是局部的，出了那个邻域，同一个方程完全可能确定另一支函数，所以隐函数求导的结果总是"在满足条件的那一支上成立"。至于可微性，则是由 F 连续可偏导加上 Fz ≠ 0 一起保证的，缺一不可。

三、方程组与雅可比行列式

设方程组 F(x, y, u, v) = 0，G(x, y, u, v) = 0 确定 u = u(x, y)，v = v(x, y)。条件是把"Fz ≠ 0"换成雅可比行列式不为零：

J = ∂(F, G)∂(u, v) = FuGv − FvGu ≠ 0。

把两个方程分别对 x 求偏导，得到以 ux、vx 为未知量的线性方程组：

Fuux + Fvvx = −Fx，　Guux + Gvvx = −Gx。

用克莱姆法则解得

ux = − ∂(F, G)/∂(x, v)∂(F, G)/∂(u, v)，　vx = − ∂(F, G)/∂(u, x)∂(F, G)/∂(u, v)。

记法与一个方程完全一致：分母是"对因变量组"的雅可比，分子把要求导的那个因变量换成自变量 x，前面加负号。对 y 求导时把 x 换成 y 即可。

四、例题

例 1　设 z = z(x, y) 由 z³ − 3xyz = a³ 确定，求 zx、zy。

解　令 F = z³ − 3xyz − a³，则
Fx = −3yz，Fy = −3xz，Fz = 3z² − 3xy。
当 z² − xy ≠ 0 时，
zx = − −3yz3(z² − xy) = yzz² − xy，
zy = − −3xz3(z² − xy) = xzz² − xy。

求 Fx 时 y、z 都当常数，所以 −3xyz 对 x 求偏导得 −3yz，别把 z 也当变量再乘 zx——那是"对恒等式求导"，与"求 F 的偏导"是两件事，混起来就会多出项。

例 2　设 z = z(x, y) 由 x² + y² + z² = 4z 确定，求 zx 与 zxx。

解　令 F = x² + y² + z² − 4z，则 Fx = 2x，Fz = 2z − 4，故
zx = − 2x2z − 4 = x2 − z。
对 zx = x(2 − z)−1 再对 x 求偏导，注意 z 是 x 的函数：
zxx = (2 − z)−1 + x · (−1)(2 − z)−2 · (−zx)
= 12 − z + x zx(2 − z)²
= 12 − z + x²(2 − z)³ = (2 − z)² + x²(2 − z)³。

二阶隐函数求导的标准流程：先求出一阶（结果里含 z），再对一阶结果求导，遇到 z 就乘 zx，最后把一阶结果代回去。绝不能把 zx 里的 z 当常数。

例 3　设 u = u(x, y)，v = v(x, y) 由方程组 xu − yv = 0，yu + xv = 1 确定，求 ux、vx。

解　令 F = xu − yv，G = yu + xv − 1。先算各偏导：
Fu = x，Fv = −y，Fx = u；Gu = y，Gv = x，Gx = v。
雅可比 J = FuGv − FvGu = x·x − (−y)·y = x² + y² ≠ 0（原点除外），条件满足。
对 x 求偏导得线性方程组
x ux − y vx = −u，　y ux + x vx = −v。
由克莱姆法则：
ux = (−u)·x − (−y)(−v)x² + y² = − ux + yvx² + y²，
vx = x(−v) − (−u)yx² + y² = uy − xvx² + y²。
若需化成只含 x、y 的形式，可由原方程解出 u = y/(x² + y²)、v = x/(x² + y²)，代入得 ux = −2xy/(x² + y²)²，vx = (y² − x²)/(x² + y²)²。

两个方程的题，与其背雅可比公式，不如直接写那两行线性方程再解——更不容易错。答案里允许保留 u、v，除非题目要求只含 x、y。

五、易错提醒

  • 负号不能丢，分母是 Fz 不是 Fx。写答案前默念一遍"分子分母、负号、除以谁"。
  • Fz = 0 的点要先排除；题目问"在哪些点能确定隐函数"，答案就是 Fz ≠ 0 的点集。
  • 对恒等式求导与求 F 的偏导是两件事：前者 z 是函数，后者 z 是独立变量。混淆就会多出 zx 项。
  • 二阶偏导记得回代一阶结果，并把 z 的依赖关系保留完整，否则答案里会混进 x、y、z 之外的东西。
  • 方程组的雅可比 J = 0 处要单独讨论，那里隐函数组可能不存在或不唯一；一般题目只需在答完时注明"在 J ≠ 0 处成立"。

一、这节解决什么问题

一元微分学里，f′(x₀) 就是曲线 y = f(x) 在 x₀ 处切线的斜率，切线把曲线"局部拉直"。到了空间里，对象变成曲线和曲面，问题也随之分成两半：曲线的切线和曲面的切平面。它们的答案都只依赖一个东西——向量。曲线要靠"切向量"，曲面要靠"法向量"，而曲面的法向量恰好就是梯度，于是第六、七两节在这里接上了头。

先建立一条总纲：切线是过该点、方向为切向量的直线；法平面是过该点、以切向量为法向量的平面；切平面是过该点、以法向量为法向量的平面；法线是过该点、方向为法向量的直线。四件东西，两两配对，剩下全是代公式。

二、空间曲线的切线与法平面

设曲线由参数方程给出：x = x(t)，y = y(t)，z = z(t)，在 t₀ 对应点 M₀(x₀, y₀, z₀)。若 x′(t₀)、y′(t₀)、z′(t₀) 存在且不全为零，则该点的切向量为

T = (x′(t₀), y′(t₀), z′(t₀))，

切线方程为

x − x₀x′(t₀) = y − y₀y′(t₀) = z − z₀z′(t₀)，

法平面（过 M₀ 且与切线垂直的平面）方程为

x′(t₀)(x − x₀) + y′(t₀)(y − y₀) + z′(t₀)(z − z₀) = 0。

两种常见变体：若曲线写成 y = y(x)，z = z(x)，就把 x 当参数，切向量取 T = (1, y′(x₀), z′(x₀))；若曲线是两个曲面的交线 F(x, y, z) = 0，G(x, y, z) = 0，则它的切向量同时垂直于两个曲面的法向量，取叉积

T = ∇F × ∇G = (Fx, Fy, Fz) × (Gx, Gy, Gz)。

再补一种情形：若曲线用一般式给出，但两个方程里某个变量容易解出（例如能写成 y = y(x)、z = z(x)），就把 x 当参数，切向量 (1, y′, z′) 比叉积更省力。叉积只在"两个方程都不好解"时才动用。

三、曲面的切平面与法线

设曲面由 F(x, y, z) = 0 给出，M₀ 在曲面上，且 ∇F(M₀) ≠ 0，则曲面在 M₀ 有切平面，法向量就是梯度

n = (Fx(M₀), Fy(M₀), Fz(M₀))，

切平面为 Fx(x − x₀) + Fy(y − y₀) + Fz(z − z₀) = 0，法线为

x − x₀Fx = y − y₀Fy = z − z₀Fz。

为什么法向量是梯度（推导）　在曲面上过 M₀ 任取一条曲线 r(t) = (x(t), y(t), z(t))，它满足 F(r(t)) ≡ 0。两边对 t 求导，用链式法则得

Fxx′(t) + Fyy′(t) + Fzz′(t) = ∇F · r′(t) = 0。

即曲面上任意曲线的切向量都与 ∇F 垂直。所有切线都垂直于同一个向量，自然共面，这张平面就是切平面。也正因为如此，"曲面有切平面"等价于"F 在该点可微且梯度非零"。

若曲面写成 z = f(x, y)，令 F = f(x, y) − z，则 ∇F = (fx, fy, −1)，也可整体乘 −1 取 n = (−fx, −fy, 1)。此时切平面化为

z − z₀ = fx(x₀, y₀)(x − x₀) + fy(x₀, y₀)(y − y₀)，

右端正是全微分 fxΔx + fyΔy——第三节说"可微就是曲面局部有切平面"，到此得到几何印证。

四、例题

例 1　求曲线 x = t，y = t²，z = t³ 在 t = 1 处的切线与法平面。

解　t = 1 时点为 (1, 1, 1)。求导得 x′ = 1，y′ = 2t，z′ = 3t²，故切向量
T = (1, 2, 3)。
切线：x − 11 = y − 12 = z − 13。
法平面：1·(x − 1) + 2·(y − 1) + 3·(z − 1) = 0，即 x + 2y + 3z = 6。

法平面用点法式，法向量就是切向量；切线的分母是切向量的三个分量，顺序与 x、y、z 一一对应。

例 2　求曲面 z = x² + y² 在点 (1, 1, 2) 处的切平面与法线。

解　fx = 2x，fy = 2y，在 (1, 1) 处 fx = 2，fy = 2，故法向量可取
n = (−2, −2, 1)（或 (2, 2, −1)）。
切平面：2(x − 1) + 2(y − 1) − (z − 2) = 0，化简得 2x + 2y − z − 2 = 0。
法线：x − 12 = y − 12 = z − 2−1。

先验证点是否在曲面上（1² + 1² = 2，成立）。用 (2, 2, −1) 与 (−2, −2, 1) 写出的方程只差一个负号，是同一张平面。

例 3　求曲面 x² + 2y² + 3z² = 21 上平行于平面 x + 4y + 6z = 0 的切平面。

解　令 F = x² + 2y² + 3z² − 21，法向量 n = (2x, 4y, 6z)。
"切平面平行于已知平面"意味着两法向量共线，故存在 λ 使
(2x, 4y, 6z) = λ(1, 4, 6)，即 x = λ/2，y = λ，z = λ。
代入曲面方程：λ²/4 + 2λ² + 3λ² = 21，即 (21/4)λ² = 21，得 λ = ±2。
λ = 2 时切点为 (1, 2, 2)，由点法式得切平面 x + 4y + 6z = 21；
λ = −2 时切点为 (−1, −2, −2)，切平面为 x + 4y + 6z = −21。
故所求为 x + 4y + 6z = ±21（两个答案，别丢）。

"平行"用向量共线处理，系数乘 λ；代回曲面方程定 λ；二次方程通常出两组解，对应曲面两侧各一张平行的切平面。

五、易错提醒

  • z = f(x, y) 的法向量是 (fx, fy, −1)，不是 (fx, fy, 1)；写成 (−fx, −fy, 1) 等价。
  • 切点必须满足曲面方程，先代一遍再动笔，能挡掉一半的计算错误。
  • 切线方程分母为零时不能硬写比例式，应改用参数式 （x, y, z）= M₀ + tT。
  • 本节与第七节的分工：切平面的法向量是梯度，下一节把梯度看作"方向导数最大的方向"，同一对象两种解读。

一、这节解决什么问题

偏导数 fx 只回答"沿 x 轴正方向走，函数变化多快"，fy 只回答 y 方向。可人在山坡上不会只朝正东或正北走，随便挑个方向迈一步，坡度是多少？这就是方向导数。有了它自然会追问：这么多方向里，哪个方向上升最快？最快有多快？答案就是梯度——一个向量，既指明方向，又给出最大变化率。工程上的"梯度下降"、地图上的"最陡上升路线"，都是这一节的直接应用。

二、方向导数的定义

设 l 是从 P₀ 出发的射线，el = (cos α, cos β, cos γ) 是与 l 同向的单位向量（α、β、γ 是它的方向角，满足 cos²α + cos²β + cos²γ = 1）。定义

∂f∂l |P₀ = limt→0⁺ f(P₀ + tel) − f(P₀)t，

为 f 在 P₀ 沿 l 方向的方向导数。注意 t → 0⁺：只沿射线正方向趋近，所以沿相反方向的方向导数一般不等于它的相反数（这是与偏导不同的地方）。

定理　若 f 在 P₀ 可微，则 f 在 P₀ 沿任一方向 l 的方向导数都存在，且

∂f∂l = fxcos α + fycos β + fzcos γ。

二维情形 β = π/2 − α，公式化为 ∂f/∂l = fxcos α + fysin α。

证明　由 f 可微，取 Δx = t cos α，Δy = t cos β，Δz = t cos γ，则 ρ = |t|，

f(P₀ + tel) − f(P₀) = fxt cos α + fyt cos β + fzt cos γ + o(t)。

两边除以 t（t > 0）再令 t → 0⁺，即得公式。条件"可微"不可省：只有偏导存在时，这个公式可能不成立。

三、梯度与三条结论

称向量

grad f = (fx, fy, fz) = ∇f

为 f 在 P₀ 的梯度。于是方向导数可写成内积形式

∂f∂l = ∇f · el = |∇f| cos θ，

其中 θ 是 ∇f 与 el 的夹角。由此立刻得到三条结论：

  1. 沿梯度方向（θ = 0）方向导数最大，最大值为 |∇f|，即"梯度方向是函数增长最快的方向，梯度的模是最大变化率"。
  2. 沿负梯度方向（θ = π）方向导数最小，最小值为 −|∇f|，这是下降最快的方向。
  3. 与梯度垂直的方向（θ = π/2）方向导数为 0，即沿等值线（等值面）f = C 的切向走，函数值瞬时不变。

几何上，∇f 垂直于等值线/等值面并指向 f 增大的一侧。把等高线想成一圈圈套着的闭合曲线，梯度就是一支支垂直穿过这些曲线、由低处指向高处的箭头——登山者若只认地图，沿着这些箭头走就是最省力的上升路线。

四、例题

例 1　求 f = x² + y² + z² 在点 (1, 1, 1) 沿方向 l = (2, 2, 1) 的方向导数。

解　先单位化：|l| = √(4 + 4 + 1) = 3，故
el = (2/3, 2/3, 1/3)。
再求梯度：∇f = (2x, 2y, 2z)，在 (1, 1, 1) 处 ∇f = (2, 2, 2)。
于是
∂f∂l = 2·23 + 2·23 + 2·13 = 103。

最容易错的一步是忘记单位化。若直接拿 (2, 2, 1) 去点乘，答案会是 10，正好是正确值的 3 倍——倍数就是 |l|。

例 2　设 f = x²yz，求在点 (1, 1, 1) 处方向导数的最大值与取得最大值的方向。

解　∇f = (2xyz, x²z, x²y)，在 (1, 1, 1) 处 ∇f = (2, 1, 1)。
方向导数最大值 = |∇f| = √(4 + 1 + 1) = √6，
取得最大值的方向就是梯度方向，单位向量为 (2, 1, 1)/√6。
（顺带：最小值 −√6，方向 −(2, 1, 1)/√6；方向导数为 0 的方向垂直于 (2, 1, 1)。）

"最大值/最小值/为零"三类问法都归到 θ 的取值，不必重新算方向导数。题目若问"沿哪个方向增加最快"，答方向即可，别再画蛇添足写数值。

例 3　设 f = x² + 2y²，在点 (1, 1) 处沿哪个方向的方向导数为 0？

解　∇f = (2x, 4y)，在 (1, 1) 处 ∇f = (2, 4)。
设所求单位方向为 (cos α, sin α)，方向导数为
2cos α + 4sin α = 0，即 tan α = −12。
取 (cos α, sin α) = ±(2, −1)/√5，即沿 (2, −1)/√5 或 (−2, 1)/√5 方向方向导数为 0。
（这两个方向正切于过该点的等值线 x² + 2y² = 3。）

这是"逆问题"：已知方向导数求方向。通用做法是设单位方向、列出内积方程，再补上 cos²α + sin²α = 1 归一化，答案通常成对出现（正反两个方向）。

五、易错提醒

  • 方向必须单位化。题目给向量 (a, b, c) 时先除以它的模，否则结果差一个 |l| 倍。
  • 公式 ∂f/∂l = ∇f · el 以 f 可微为前提；只在一点偏导存在时不保证成立。
  • 梯度是向量，方向导数是数，答题时别把两者写成同一种对象。
  • "增长最快"是 ∇f 方向，"减小最快"是 −∇f 方向；梯度本身指向函数值增大的一侧，与切平面一节的法向量是同一个向量。

一、这节解决什么问题

一元函数求极值：先令 f′(x) = 0 找驻点，再看二阶导数符号。多元照搬前一半没问题——极值点处偏导都为零；后一半却翻了倍：曲面在某点附近既可能"碗口朝上"（极小）、"碗口朝下"（极大），也可能像马鞍一样一升一降（鞍点，不是极值）。只看 fxx 的符号判断不了，必须同时看 fxy。这就引出本节的主角：二阶偏导组成的判别式 AC − B²。

二、定义与必要条件

定义　若存在 δ > 0，使 P₀ 的 δ 邻域内一切 P 都有 f(P) ≤ f(P₀)（或 ≥），则称 f 在 P₀ 取得极大值（或极小值），P₀ 称为极值点。极值是局部概念，只与该点附近比较，与远处无关。

定理（必要条件）　若 f 在 P₀ 可微且取得极值，则 fx(P₀) = fy(P₀) = 0，即 P₀ 是驻点。

要当心两点：其一，驻点未必是极值点（下面例 1 的 (0, 0) 就是鞍点）；其二，不可导的点也可能是极值点，例如 z = √(x² + y²) 在原点，偏导不存在却取极小值 0。所以求极值的完整搜捕范围是"驻点 + 偏导不存在的点"。

三、充分条件与判别式

定理（充分条件）　设 f 在 P₀ 的某邻域内有二阶连续偏导，且 fx(P₀) = fy(P₀) = 0。记

A = fxx(P₀)，B = fxy(P₀)，C = fyy(P₀)，Δ = AC − B²。

  1. Δ > 0：P₀ 是极值点，且 A > 0 时为极小值，A < 0 时为极大值；
  2. Δ < 0：P₀ 不是极值点（鞍点）；
  3. Δ = 0：判别法失效，需用更高阶的项判断（第九节泰勒公式）。

为什么是这样　由二元泰勒公式（取 h = Δx，k = Δy）

Δf = f(P₀ + ΔP) − f(P₀) = 12(A h² + 2B hk + C k²) + o(ρ²)。

极值问题归结为二次型 Q = A h² + 2B hk + C k² 的符号。由配方

Q = 1A[(A h + B k)² + (AC − B²)k²]（A ≠ 0 时），

可见：A > 0 且 AC − B² > 0 时 Q 恒正，Δf > 0，是极小值；A < 0 且 AC − B² > 0 时 Q 恒负，是极大值；AC − B² < 0 时沿两个特征方向 Q 异号，Δf 有正有负，是鞍点。这就是判别式的全部来历，不必死记。

四、条件极值与拉格朗日乘数法

求 z = f(x, y) 在约束 φ(x, y) = 0 下的极值，思路是"把约束乘一个待定系数加进目标函数"，化为无条件问题：

L(x, y, λ) = f(x, y) + λφ(x, y)，

然后解方程组

Lx = fx + λφx = 0，　Ly = fy + λφy = 0，　Lλ = φ(x, y) = 0。

得到的 (x, y) 是可疑点，再比较各点函数值（或由实际意义判断）。几何解释：极值点处目标函数的等值线与约束曲线相切，两曲线法向量平行，即 ∇f = −λ∇φ，这正是前两式的向量形式。若有两个约束 φ = 0、ψ = 0，就引两个乘数：L = f + λφ + μψ，解 Lx = Ly = Lλ = Lμ = 0。

五、有界闭区域上的最值

连续函数在有界闭区域上必取得最大值与最小值（第一节的最值定理）。求法三步：

  1. 求区域内部的驻点及偏导不存在的点，算出函数值；
  2. 求边界上的最值：边界是曲线时化为一元函数，或用拉格朗日乘数法；边界由几段组成时逐段处理，别忘了角点；
  3. 把所有候选值放在一起比较，最大者即最大值，最小者即最小值。

注意极值与最值是两回事：极值是局部的，最值是整体的；最大值可能在边界上取得，而边界点通常不是驻点。

六、例题

例 1　求 f(x, y) = x³ + y³ − 3xy 的极值。

解　fx = 3x² − 3y，fy = 3y² − 3x。令二者为零：
y = x² 且 x = y²，代入得 x = x⁴，即 x(x³ − 1) = 0，故 x = 0 或 x = 1。
驻点为 (0, 0) 与 (1, 1)。
再算二阶偏导：fxx = 6x，fxy = −3，fyy = 6y。
在 (0, 0)：A = 0，B = −3，C = 0，Δ = 0 − 9 = −9 < 0，不是极值点。
在 (1, 1)：A = 6，B = −3，C = 6，Δ = 36 − 9 = 27 > 0，且 A = 6 > 0，故为极小值，f(1, 1) = 1 + 1 − 3 = −1。

求驻点时要把两个方程联立到底，别只解出一个。判完 Δ 还要看 A 的符号才能区分极大极小；Δ < 0 时直接写"非极值"，不必再看 A。

例 2　设 x + y + z = a（a > 0，x, y, z > 0），求 xyz 的最大值。

解　这是条件极值。令
L = xyz + λ(x + y + z − a)，
则 Lx = yz + λ = 0，Ly = xz + λ = 0，Lz = xy + λ = 0，Lλ = x + y + z − a = 0。
前三个方程给出 yz = xz = xy = −λ。因 x, y, z > 0，可用 yz = xz 两边除以 z 得 x = y；同理由 xz = xy 得 y = z。故 x = y = z。
代入约束：3x = a，x = a/3。
可疑点只有一个，由实际意义（正数之积在约束下有上界）知它必为最大值点，最大值为
(a/3)³ = a³/27。

这题的结果就是三元均值不等式：几何平均不超过算术平均。解 λ 方程组时善用"两两相减/相除"消元，比硬解快得多；最后要用实际意义或比较法确认是最大值。

例 3　用铁皮做一个体积为 V 的无盖长方体水箱，问长、宽、高各为多少时用料最省？

解　设底面长 a、宽 b，高 c，则 V = abc，表面积（无盖）S = ab + 2ac + 2bc。
由 V = abc 得 c = V/(ab)，代入：
S(a, b) = ab + 2Vb + 2Va，a > 0，b > 0。
Sa = b − 2Va² = 0，Sb = a − 2Vb² = 0。
由第一式 b = 2V/a²，代入第二式 a = 2V/b² = 2V·a⁴/(4V²) = a⁴/(2V)，得 a³ = 2V，a = (2V)1/3。
于是 b = a，c = V/a² = a/2。
驻点唯一，且 a, b → 0⁺ 或 → +∞ 时 S → +∞，故该驻点就是最小值点：
底面为边长 (2V)1/3 的正方形，高为它的一半时用料最省。

应用题的收尾必须交代"为什么是最小"：常见理由是驻点唯一 + 边界处函数值趋于无穷（或由实际意义），不能只写"解得驻点故为最小"。

七、易错提醒

  • 驻点不等于极值点；偏导不存在的点也可能是极值点，两类都要搜。
  • Δ = AC − B² 中 B 是 fxy，配方里出现的是 2B，别把系数弄错；算 Δ 前先把三个二阶偏导都在该点算准。
  • 条件极值必须把 Lλ = 0（即约束方程）一起解，只解前两个方程得到的点可能根本不在约束曲线上。
  • 有界闭区域求最值，边界不能漏；边界是一段曲线时，把它参数化成一元问题往往比拉格朗日更快。

一、这节解决什么问题

一元泰勒公式把 f(x) 在 x₀ 附近写成多项式加余项，一阶截断给出切线近似，二阶截断给出极值判别。多元的情形多了方向：不仅要沿 x 方向展开，还要同时沿 y 方向展开，于是增量成了有序对 (h, k)。本节要回答三件事：二元函数怎样展开成多项式、展开式怎么快速写出来、它凭什么能补上 AC − B² = 0 时的判别空白。可以把它看成第三节（一阶近似）与第八节（二阶判别）的统一升级。

二、二元泰勒公式

定理　设 f 在 P₀(x₀, y₀) 的某邻域内有直到 n + 1 阶的连续偏导数，(x₀ + h, y₀ + k) 在该邻域内，则

f(x₀ + h, y₀ + k) = Σm=0n 1m!(h ∂∂x + k ∂∂y)m f(x₀, y₀) + Rn，

其中拉格朗日余项为

Rn = 1(n + 1)!(h ∂∂x + k ∂∂y)n+1 f(x₀ + θh, y₀ + θk)，0 < θ < 1。

算子怎么展开　把 (h∂x + k∂y)m 按二项式定理展开，每一项都是"系数 × h 的幂 × k 的幂 × 相应阶偏导"：

(h∂x + k∂y)m f = Σi=0m Cmi hi km−i ∂mf∂xi∂ym−i。

写出前几阶就够用了：

  • 零阶：f(x₀, y₀)；
  • 一阶：fxh + fyk，这就是全微分，即线性近似；
  • 二阶：12(fxxh² + 2fxyhk + fyyk²)，正是第八节判别式里的那个二次型。

余项有两种写法：只关心"误差是比 ρn 高阶的无穷小"时，用佩亚诺形式 Rn = o(ρn)，展开题写这一种最省事；要估计误差的具体大小时，才用上面带 θ 的拉格朗日形式。两者不能混着写。

三、推导：化成一元泰勒

证明的关键是"沿一条直线走"，把二元问题压成一元问题。固定 (h, k)，令

φ(t) = f(x₀ + th, y₀ + tk)，t ∈ [0, 1]。

则 φ(0) = f(P₀)，φ(1) = f(x₀ + h, y₀ + k)。由链式法则逐次求导：

φ′(t) = fxh + fyk = (h∂x + k∂y)f，

φ″(t) = fxxh² + 2fxyhk + fyyk² = (h∂x + k∂y)²f，

一般地 φ(m)(t) = (h∂x + k∂y)m f(x₀ + th, y₀ + tk)。对 φ 在 t = 0 处用一元泰勒公式（带拉格朗日余项），再令 t = 1，就得到本节的定理。这个证法也解释了"算子"记号为什么合理：它就是把对 t 的求导翻译回对 x、y 的偏导。

四、例题

例 1　把 f(x, y) = excos y 在 (0, 0) 处展开到三阶。

解　逐阶算偏导在 (0, 0) 的值：
f = excos y → 1；fx = excos y → 1；fy = −exsin y → 0；
fxx = excos y → 1；fxy = −exsin y → 0；fyy = −excos y → −1；
fxxx → 1；fxxy → 0；fxyy → −1；fyyy → 0。
三阶项用算子算最省事：
(x∂x + y∂y)³f = x³fxxx + 3x²y fxxy + 3xy² fxyy + y³ fyyy
= x³ · 1 + 0 + 3xy² · (−1) + 0 = x³ − 3xy²。
于是
excos y = 1 + x + 12(x² − y²) + 16(x³ − 3xy²) + o(ρ³)，ρ = √(x² + y²)。

三项注意：展开式的每一项都要除以 m!（三阶除以 6，不是 3）；交叉项的系数来自二项式系数 C31 = 3；余项写 o(ρ³) 时 ρ 是 √(x² + y²)，不是 x + y。

例 2　把 f(x, y) = x² + xy + y² 在 (1, 1) 处展开。

解　令 x = 1 + h，y = 1 + k。先算各阶偏导在 (1, 1) 的值：
f = 3；fx = 2x + y → 3；fy = x + 2y → 3；
fxx = 2，fxy = 1，fyy = 2；三阶及以上偏导全为 0。
代入公式：
f = 3 + 3h + 3k + 12(2h² + 2hk + 2k²) = 3 + 3h + 3k + h² + hk + k²。
校验：直接展开 (1 + h)² + (1 + h)(1 + k) + (1 + k)²，结果一致。

多项式在任意点展开后仍是同次多项式，展开式有限、没有余项，是检验公式是否记对的最好练习题。

例 3　说明 AC − B² = 0 时为什么要看高阶项：判别 f = x²y² 与 g = x³ 在原点是否取极值。

解　两者在原点都满足 fx = fy = 0，且二阶偏导全为 0，故 A = B = C = 0，Δ = 0，判别法失效，只能回到定义。
对 f = x²y²：因平方非负，f(x, y) ≥ 0 = f(0, 0) 对一切 (x, y) 成立，故原点取极小值 0。
对 g = x³：沿 y = 0 看，g(x, 0) = x³ 在 x > 0 时为正、x < 0 时为负，原点任何邻域内函数值有正有负，故不取极值。
两例说明：Δ = 0 时二阶信息不足，必须考察三阶、四阶项。f 的首个非零项是四次的 x²y²（恒非负），g 的首个非零项是三次的 x³（变号），极值与否由此决定。

考试中遇到 Δ = 0，标准答法是"判别法失效，另用定义或高阶项讨论"，直接写"是极值"或"不是极值"都要给出理由。

五、与前后文的联系及易错

  • 一阶截断就是第三节的全微分（线性近似），二阶截断就是第八节的极值判别，本节是它们的统一来源。
  • 算子展开的二项式系数 Cmi 与 1/m! 都不能漏，这是最常见的扣分点。
  • h、k 是增量，不是新变量；写余项时 ρ = √(h² + k²)，且 θ 依赖于 h、k，不能当常数。
  • 三类用途：把函数在一点附近近似成多项式（近似计算）、求复杂的极限（分子分母各展开后比阶）、判断极值（看首个非零项）。动笔前先想清楚要哪一用，再决定展到几阶——求极限一般展到分母的最低阶，判极值要看第一个不为零的项。
  • 近似计算时一阶公式 f ≈ f(P₀) + fxh + fyk 精度不够就上二阶，误差量级由余项给出。
