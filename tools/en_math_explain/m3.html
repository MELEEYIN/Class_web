一、这一节要解决什么问题

先看一个日常现象：一辆车 8:00 从 A 地出发，9:00 到达 120 km 外的 B 地，全程平均速度是 120 km/h。司机中途可能加速到 140，也可能堵车降到 60，但只要速度是连续变化的（没有瞬间跳变），就一定存在某一时刻，速度表恰好指着 120。这个时刻没法预先指出，但它的存在是确定的。中值定理说的就是这件事：平均变化率必在某一点被瞬时变化率取到。

几何上更直观：画出曲线弧 AB，把 A、B 连成一条割线，则弧上必有一点，其切线平行于这条割线。罗尔定理是割线水平时的特例：两端等高，中间必有水平切线。这一节的全部内容，就是把这句话在越来越弱的条件下说严格。

二、费马引理：极值点处切线水平

费马引理　设 f 在 x₀ 的某邻域内有定义，在 x₀ 处可导。若对该邻域内一切 x 都有 f(x) ≤ f(x₀)（即 x₀ 为极大值点），则 f′(x₀) = 0；极小值点同理。

证明只用左右导数。当 Δx > 0 时 f(x₀ + Δx) ≤ f(x₀)，差商 ≤ 0，令 Δx→0⁺ 得右导数 f′₊(x₀) ≤ 0；当 Δx < 0 时，分母为负而分子非正，差商 ≥ 0，令 Δx→0⁻ 得左导数 f′₋(x₀) ≥ 0。可导意味着左右导数相等，于是只能等于 0。

两个前提都不能少：端点处只谈单侧导数，没有这个结论；f(x) = |x| 在 0 处取极小但不可导，也就没有 f′(0) = 0。这个引理本身用处不大，它的全部价值在于——它是罗尔定理证明中唯一需要「动脑」的一步。

三、罗尔定理

罗尔定理　若 f 满足三个条件：（1）在闭区间 [a,b] 上连续；（2）在开区间 (a,b) 内可导；（3）f(a) = f(b)，则至少存在一点 ξ ∈ (a,b)，使 f′(ξ) = 0。

证明思路分两步，这条主线必须记牢。第一步，闭区间上连续的函数必取得最大值 M 与最小值 m（最值定理）。第二步，若 M = m，则 f 恒为常数，f′(x) ≡ 0，任取 ξ 即可。若 M > m，注意 f(a) = f(b)，最大值与最小值不可能都在端点处取到（否则两端函数值同为 M 又同为 m，与 M > m 矛盾），故 M 与 m 中至少有一个是在 (a,b) 内部取得的。设这个内点为 ξ，则 ξ 是极值点且 f 在 ξ 可导，由费马引理得 f′(ξ) = 0。

三个条件是用来「卡」的，各举一例：f(x) = x 在 [0,1] 上不满足 f(a) = f(b)，结论不成立；f(x) = |x| 在 [−1,1] 上不满足可导，弧上没有水平切线；若区间是开区间且函数在端点附近无界（如 1/x 型的挖洞），连续性条件失效，同样不行。

四、拉格朗日中值定理

拉格朗日中值定理　若 f 在 [a,b] 上连续、(a,b) 内可导，则存在 ξ ∈ (a,b)，使

f(b) − f(a) = f′(ξ)(b − a)，即 f(b) − f(a)b − a = f′(ξ)

它是罗尔的推广：把「两端等高」换成「用一条斜线把两端连起来」。所以证明办法就是把这根斜线减掉，造一个两端等高的函数。令

F(x) = f(x) − f(a) − f(b) − f(a)b − a(x − a)

则 F 在 [a,b] 连续、(a,b) 可导，且 F(a) = 0，F(b) = f(b) − f(a) − [f(b) − f(a)] = 0。由罗尔定理，存在 ξ 使 F′(ξ) = 0，即 f′(ξ) = [f(b) − f(a)]/(b − a)。

写成「有限增量」形式更常用：f(x + Δx) − f(x) = f′(ξ)Δx，其中 ξ 介于 x 与 x + Δx 之间。注意 ξ 依赖 Δx，不能当成常数搬来搬去。三个推论后面证不等式全靠它们：在区间 I 上 f′(x) ≡ 0，则 f 为常数；f′ > 0 则严格增，f′ < 0 则严格减；若 |f′(x)| ≤ M，则 |f(x) − f(y)| ≤ M|x − y|。

五、柯西中值定理

柯西中值定理　若 f、g 在 [a,b] 上连续、(a,b) 内可导，且 g′(x) ≠ 0（x ∈ (a,b)），则存在 ξ ∈ (a,b)，使

f(b) − f(a)g(b) − g(a) = f′(ξ)g′(ξ)

条件 g′ ≠ 0 自动保证了 g(b) ≠ g(a)（否则由罗尔定理 g′ 在内部有零点），所以分母有意义。证明完全平行：令

F(x) = f(x) − f(a) − f(b) − f(a)g(b) − g(a)[g(x) − g(a)]

则 F(a) = F(b) = 0，用罗尔定理即得。把 g(x) = x 代回去就退回拉格朗日，所以柯西是拉格朗日的「参数化」版本：它比较的是两个函数在同一点处变化率之比。这正是下一节洛必达法则的理论来源——洛必达本质上就是让区间端点 a 与 x 合并，把柯西定理取极限。

六、辅助函数：看见结论就知道造什么

考试里的证明题，九成是「证明存在 ξ 使某个含 f(ξ)、f′(ξ) 的式子成立」。套路是：把 ξ 换成 x，移项成等式，再把它认成某个 F′(x) = 0。常见对照如下：

  • 要证 f′(ξ) = 0：取 F(x) = f(x)，直接用罗尔定理。
  • 要证 f′(ξ) + k f(ξ) = 0：取 F(x) = ekxf(x)，因为 F′ = ekx[f′ + kf]。
  • 要证 f′(ξ) − k f(ξ) = 0：取 F(x) = e−kxf(x)。
  • 要证 ξ f′(ξ) + f(ξ) = 0：取 F(x) = x f(x)，因为 F′ = f + x f′。
  • 要证 ξ f′(ξ) − f(ξ) = 0：取 F(x) = f(x)/x。
  • 要证 f′(ξ) + 2ξ f(ξ) = 0：取 F(x) = ex²f(x)。

记法是：看到 f′ 与 f 的线性组合，就想 e 的指数；看到 ξ 乘 f′ 再加 f，就想 x 乘 f。乘上去的因子必须恒不为零，这样 F′(ξ) = 0 才能约掉它、推出括号为零。

七、例题

例 1　证明：当 x > 0 时，x1 + x < ln(1 + x) < x。

解　在 [0, x] 上对 f(t) = ln(1 + t) 用拉格朗日中值定理。f 在 [0,x] 连续、在 (0,x) 内可导，f′(t) = 1/(1 + t)，于是存在 ξ ∈ (0,x)，使
ln(1 + x) − ln 1 = 11 + ξ·x
因为 0 < ξ < x，所以 11 + x < 11 + ξ < 1。两边同乘 x > 0，得
x1 + x < ln(1 + x) < x。

两边都被卡住，这种「双侧估计」很常考。关键是把 1/(1 + ξ) 中的 ξ 夹在 0 与 x 之间再放缩，绝不要去解 ξ。

例 2　设 0 < a < b，f 在 [a,b] 上连续、(a,b) 内可导。证明存在 ξ ∈ (a,b)，使 f(b) − f(a) = ξ f′(ξ) lnba。

解　结论右边出现了 ln(b/a)，这是极明确的信号：取 g(x) = ln x。g 在 [a,b] 上连续、(a,b) 内可导，且 g′(x) = 1/x ≠ 0。对 f 与 g 用柯西中值定理，存在 ξ ∈ (a,b)，使
f(b) − f(a)ln b − ln a = f′(ξ)1/ξ = ξ f′(ξ)
而 ln b − ln a = ln(b/a)，两边同乘即得结论。

识别信号：结论里有 ln(b/a) 就配 g = ln x，有 b² − a² 就配 g = x²，有 arctan b − arctan a 就配 g = arctan x。分母不再是 b − a 时，八成要用柯西。

例 3　设 f 在 [0,1] 上连续、(0,1) 内可导，且 f(0) = f(1) = 0。证明存在 ξ ∈ (0,1)，使 f′(ξ) + 2ξ f(ξ) = 0。

解　结论是 f′ + 2x f 的形状，对应因子 e∫2x dx = ex²。令
F(x) = ex² f(x)
则 F 在 [0,1] 上连续、(0,1) 内可导，且 F(0) = e⁰f(0) = 0，F(1) = e·f(1) = 0。由罗尔定理，存在 ξ ∈ (0,1) 使 F′(ξ) = 0。而
F′(x) = ex²[f′(x) + 2x f(x)]
因 eξ² 恒不为零，故 f′(ξ) + 2ξ f(ξ) = 0。

最后一步靠的正是「因子恒正才能约掉」。若构造的是 x f(x)，就必须保证 x ≠ 0，所以题目给的区间不能含 0 作为内点。

八、与后文的联系与易错提醒

这一节的四个定理是一条链：费马 → 罗尔 → 拉格朗日 → 柯西，后一个是前一个的推广，每步只放宽一点条件。它往下接三处：柯西定理取极限就是洛必达法则；拉格朗日定理加上「二阶导」就是泰勒公式（n = 0 的泰勒就是拉格朗日）；单调性判定（第四节）的证明也直接来自拉格朗日定理。

易错有三：一是把 ξ 当常数，写成 f′(ξ) = 常数后再对 x 求导；二是忘记验证三个条件，尤其是「开区间可导」——遇到带绝对值、分段点的函数，先看可导性；三是混淆存在性与唯一性，中值定理只保证存在，题目问「唯一」时必须另加单调性论证。做题时建议先写「因为 f 在 [a,b] 连续、在 (a,b) 可导」这一句，条件写全了，分就稳了。

一、为什么 0/0 不能直接算

两个无穷小之比，结果取决于谁更快趋于零：x/x → 1，x²/x → 0，x/x² → ∞。三者的分子分母都趋于 0，答案却完全不同。可见「0/0」只是一个记号，不是数，它本身不含任何信息，必须比较两者的阶才能定值。

比较阶最顺手的工具是导数。在 a 附近，f(x) ≈ f′(a)(x − a)，g(x) ≈ g′(a)(x − a)，两式相除，(x − a) 被约掉，只剩 f′(a)/g′(a)。这就是洛必达法则的全部直觉：函数之比的极限，等于导数之比的极限。

二、定理的精确表述

洛必达法则（0/0 型）　设
（1）limx→a f(x) = 0，limx→a g(x) = 0；
（2）在 a 的某去心邻域内 f′(x)、g′(x) 存在，且 g′(x) ≠ 0；
（3）limx→a f′(x)g′(x) = A（A 为有限数或 ±∞），
则 limx→a f(x)g(x) = A。

∞/∞ 型只需把条件（1）换成 f、g 都趋于 ∞，结论完全相同。x→a⁺、x→a⁻、x→∞ 各情形都成立；数列极限也可用（把 n 换成连续变量 x）。

三、证明思路：柯西定理取极限

补定义 f(a) = g(a) = 0，则 f、g 在 a 处也连续。对 a 附近的 x，在 [a,x]（或 [x,a]）上用柯西中值定理：存在 ξ 介于 a 与 x 之间，使

f(x)g(x) = f(x) − f(a)g(x) − g(a) = f′(ξ)g′(ξ)

当 x→a 时 ξ→a，右端趋于 A，左端就是所求，证毕。这里藏着洛必达的「软肋」：它只保证「若导数比的极限存在，则原极限等于它」，反过来不成立。所以条件（3）必须单独验证，不能想当然。

四、六种未定式与转化

能直接用的只有 0/0 与 ∞/∞ 两种。其余四种必须先变形，这是洛必达题的真正难点：

  • 0·∞　把其中一个因子写成倒数放进分母，化成 0/0 或 ∞/∞。选谁进分母有讲究：谁求导后更简单就让谁下去。常见选择是把 ln x 留在分子（因为 (1/x)′ 很干净），把幂函数放到分母。
  • ∞ − ∞　通分（分式之差）、有理化（根式之差）、或提取公因子，先化成商，再用洛必达。
  • 1∞、00、∞0　都是幂指函数，一律先取对数。设 y = fg，则 ln y = g ln f，指数型立刻降级成 0·∞，再化成分式。最后别忘了把答案取回指数：lim y = elim ln y。

五、使用纪律

  1. 先验型，再动笔。没确认是 0/0 或 ∞/∞ 就求导，是扣分第一名。例如 limx→0 x + 1x + 2 = 12，分子分母都不趋于零，直接代入即可，求导反而错。
  2. 每求一次导，回头看一眼是否仍是未定式；不是就停手，直接代值。
  3. 能化简先化简。约掉非零因子、先用等价无穷小替换乘除因子，再洛必达，计算量常能减一半。但等价替换只对乘除因子有效，加减项里替换必须谨慎。
  4. 失效就换法。若 lim f′/g′ 不存在（含振荡），洛必达给不出任何结论，原极限却可能存在。典型例子：limx→∞ x + sin xx = 1，但导数比 1 + cos x 的极限不存在。此时应回到夹逼或直接做除法：原式 = 1 + sin x / x → 1。另外，若求导后越变越复杂（如含 ex²、高阶幂），立刻改用泰勒公式。

六、例题

例 1　求 limx→0 tan x − xx³。

解　x→0 时分子分母都趋于 0，是 0/0 型。用一次洛必达：
limx→0 sec²x − 13x²
用恒等式 sec²x − 1 = tan²x，得 limx→0 tan²x3x²。此时不必再洛必达，用等价无穷小 tan x ~ x，得 tan²x ~ x²，故原式 = 1/3。

若硬做第二次洛必达：分子导数为 2sec²x tan x，分母为 6x，再用 tan x ~ x，同样得 2x/(6x) = 1/3。两种走法都要会，考场上选省事的那条。

例 2　求 limx→0⁺ x ln x。

解　这是 0·∞ 型（x→0⁺ 时 x→0，ln x→−∞），不能直接用。把 x 写成 1/(1/x) 放进分母：
limx→0⁺ ln x1/x
化为 ∞/∞ 型。洛必达一次：分子导数 1/x，分母导数 −1/x²，比值为
1/x−1/x² = −x → 0
故原极限为 0。

注意方向：如果反过来把 ln x 放进分母（写成 x/(1/ln x)），求导会得到一个更乱的式子，越做越繁。0·∞ 型「让谁下去」是成败关键。

例 3　求 limx→0 1sin x − 1x。

解　这是 ∞ − ∞ 型，先通分：
x − sin xx sin x
化为 0/0 型。用等价无穷小：分母 x sin x ~ x²；分子 x − sin x ~ x³/6。故原式 ~ (x³/6)/x² = x/6 → 0。

若不用等价无穷小，就洛必达两次：一次得 (1 − cos x)/(sin x + x cos x)，仍是 0/0；再导得 sin x/(2cos x − x sin x) → 0/2 = 0。两个办法答案一致，但泰勒或等价无穷小快得多。

例 4　求 limx→0 (1 + x)1/x。

解　这是 1∞ 型。设 y = (1 + x)1/x，取对数：
ln y = ln(1 + x)x
x→0 时这是 0/0 型，洛必达一次：1/(1 + x)1 → 1，故 ln y → 1，于是 y → e1 = e。

1∞ 型的答案一定形如 eA，先把 A 求出来再取指数，千万别把 A 直接当答案。这是最经典的「两个重要极限」之一，用洛必达验证最省事。

七、与后文的联系与易错提醒

洛必达是「急救包」而不是「万能药」：能立刻判断型、求导后变简单的，用它最快；遇到振荡、求导变复杂、或需要精确到某阶的，交给下一节的泰勒公式。两者的分工要清楚——洛必达看趋势，泰勒看阶数。

易错集中在四点：一是没验型就求导；二是一路求导不回头，最后算出一个不是未定式的式子还继续导；三是忘了 0·∞、∞ − ∞、1∞ 需要先转化；四是在 lim f′/g′ 不存在时错误地断言「原极限不存在」。记住：洛必达失效只说明「此路不通」，不说明「极限不存在」。

一、从切线到抛物线

用 f(x₀) + f′(x₀)(x − x₀) 近似 f，只在 x₀ 附近一小段靠谱，因为直线不会弯。想让它弯，就加一个二次项；还想更贴合，就继续加三次、四次项。一路加下去得到的是一条多项式——而多项式是唯一能只靠加减乘就算出精确值的函数。泰勒公式回答的就是：用多项式模仿一个函数，每一阶该配多大的系数，剩下的误差有多大。

一个具体感受：sin x 在原点附近几乎等于 x，但 x 稍大就有偏差；加上 −x³/6 后，在 x = 1 处已经准到小数点后四位。这就是「阶数越高越像」的量化版本。

二、系数是怎么定出来的

设 Pn(x) = a₀ + a₁(x − x₀) + a₂(x − x₀)² + … + an(x − x₀)n，要求 Pn 与 f 在 x₀ 处的函数值及各阶导数全部相等。令 x = x₀，所有含 (x − x₀) 的项消失，得 a₀ = f(x₀)；两边求一次导再令 x = x₀，得 a₁ = f′(x₀)；求两次导，二次项贡献出 2a₂，得 a₂ = f″(x₀)/2!；一般地，求 k 次导后只剩 k!ak = f(k)(x₀)，于是

ak = f(k)(x₀)k!

阶乘不是天上掉下来的，是求导 k 次时从 (x − x₀)k 里滚出来的 k(k − 1)…1。理解了这一点，六个展开式就不必死记系数。

三、两个定理：两种余项，两种用途

泰勒中值定理一（佩亚诺余项）　若 f 在 x₀ 处有 n 阶导数，则当 x→x₀ 时

f(x) = Σk=0n f(k)(x₀)k!(x − x₀)k + o((x − x₀)n)

它只断言余项是比 (x − x₀)n 高阶的无穷小，不指出 ξ 在哪，所以只能用于求极限，不能用来估计误差。

泰勒中值定理二（拉格朗日余项）　若 f 在含 x₀ 的开区间 (a,b) 内有 n + 1 阶导数，则对任意 x ∈ (a,b)，存在 ξ 介于 x₀ 与 x 之间，使

f(x) = Pn(x) + f(n+1)(ξ)(n+1)!(x − x₀)n+1

余项是一个「具体的值」，虽然 ξ 未知，但只要知道 f(n+1) 的界，就能给出误差上界——所以估计误差与证明不等式用它。当 n = 0 时它退化成拉格朗日中值定理，可见泰勒是拉格朗日的推广。

四、证明思路

佩亚诺余项：令 Rn(x) = f(x) − Pn(x)，由构造方式知 Rn(x₀) = R′n(x₀) = … = Rn(n)(x₀) = 0。对 Rn(x)/(x − x₀)n 反复用洛必达（等价地反复用柯西定理）n − 1 次，分子最后剩下 Rn(n−1)(x) − Rn(n−1)(x₀)，再用导数定义即知其趋于 0，故 Rn = o((x − x₀)n)。

拉格朗日余项：对 Rn(x) 与 (x − x₀)n+1 反复用柯西定理 n + 1 次，每次在端点 x₀ 处的值都为零，最后一步得

Rn(x)(x − x₀)n+1 = f(n+1)(ξ)(n+1)!

移项即得。注意每用一次柯西，ξ 都可能换一个，最后停在某个介于 x₀ 与 x 之间的 ξ 上。

五、六条必背的麦克劳林展开

以下都取 x₀ = 0，考试基本只考这六个，必须能默写：

ex = 1 + x + x²2! + … + xnn! + o(xn)

sin x = x − x³3! + x⁵5! − … + (−1)nx2n+1(2n+1)! + o(x2n+1)

cos x = 1 − x²2! + x⁴4! − … + (−1)nx2n(2n)! + o(x2n)

ln(1 + x) = x − x²2 + x³3 − … + (−1)n−1xnn + o(xn)

(1 + x)α = 1 + αx + α(α − 1)2!x² + … + α(α − 1)…(α − n + 1)n!xn + o(xn)

11 − x = 1 + x + x² + … + xn + o(xn)　（|x| < 1）

记忆要点：ex 全是加号、系数是 1/n!；sin 只取奇次且符号交替；cos 只取偶次且符号交替；ln(1 + x) 的分母是 1、2、3 而不是阶乘，符号从第二项起交替；最后两条其实是同一个等比求和公式的正反两用。

六、展开到几阶才够

两条原则就够了。第一，看分母：分母是 xn，就展到 xn，低一阶结论必错。第二，看抵消：两项相减时，要展到「第一个不抵消的项」为止。例如 (tan x − sin x)/x³，两者首项都是 x，抵消；下一项 tan x 贡献 x³/3，sin x 贡献 −x³/6，相减得 x³/2，不再抵消，故展到 x³ 已足够。

最致命的错误是：在加减运算里各自使用等价无穷小替换。x − sin x 若换成 x − x = 0，就把真正的最低阶 x³/6 整个扔掉了。等价替换只在乘除因子中安全；出现加减，必须展开到不抵消的那一阶。

七、例题

例 1　求 limx→0 cos x − e−x²/2x⁴。

解　分母是 x⁴，故每个函数都展到 x⁴。
cos x = 1 − x²2 + x⁴24 + o(x⁴)
对 e−x²/2，令 u = −x²/2，用 eu = 1 + u + u²/2 + o(u²)：
e−x²/2 = 1 − x²2 + x⁴8 + o(x⁴)
两式相减，1 与 −x²/2 都抵消，剩
(cos x − e−x²/2) = (124 − 18)x⁴ + o(x⁴) = −x⁴12 + o(x⁴)
故原式 = −1/12。

注意 u²/2 = x⁴/8 这一步不能漏——正是这一项决定了系数。若只把 eu 展到 u，余项就是 o(x²)，不够用。这就是「展到第一个不抵消的项」的含义。

例 2　证明：当 x > 0 时，ex > 1 + x + x²2 + x³6。

解　用带拉格朗日余项的泰勒公式，取 n = 3、x₀ = 0：存在 ξ ∈ (0,x)，使
ex = 1 + x + x²2! + x³3! + eξ4!x⁴
因为 ξ > 0，所以 eξ > 1 > 0，而 x⁴ > 0，故余项严格大于 0，于是
ex > 1 + x + x²2 + x³6。

证不等式时只需要「余项的符号」，不需要 ξ 的具体位置——这正是拉格朗日余项存在的意义。若用佩亚诺余项，只能得到 o(x³)，符号未知，证不出严格大于。

例 3　求 limx→0 1x² − 1sin²x。

解　先通分：
sin²x − x²x² sin²x
由 sin x = x − x³/6 + o(x³)，平方得
sin²x = x² − x⁴3 + o(x⁴)
故分子 sin²x − x² = −x⁴/3 + o(x⁴)；分母 x² sin²x = x²·x² + o(x⁴) = x⁴ + o(x⁴)。相除得
−x⁴/3x⁴ → −13
故原式 = −1/3。

把 (x − x³/6)² 展开时，中间项 2·x·(−x³/6) = −x³/3 就是全部来源，x⁶ 项属于 o(x⁴) 可以不管。这类题用洛必达要做六七次，泰勒两步到位。

八、与后文的联系与易错提醒

泰勒公式是本章的制高点：洛必达是它的「一阶特例」，中值定理是它的「零阶特例」，而下一节判断极值的第二充分条件本质上也是泰勒展开到二阶。学完它，极限、误差、不等式三类题都有了统一武器。

三个高频错误：一是阶数不够，分母 x⁴ 却只展到 x²，余项写 o(x²) 就下结论；二是加减中滥用等价替换，把 x − sin x 算成 0；三是余项类型用错，求极限用佩亚诺、证不等式用拉格朗日，两者不能互换。做题前先问自己一句：这题要的是「极限值」还是「大小关系」？答案立刻分明。

一、直观理解

导数刻画的是瞬时变化率，所以它的符号天然对应函数在往哪儿走：f′ > 0 的地方，x 增大时曲线上升；f′ < 0 的地方下降。二阶导刻画的是「变化率自己怎么变」，对应曲线往哪边弯：f″ > 0 时斜率在增大，曲线向上翘，像开口向上的抛物线；f″ < 0 时向下弯。

用开车打比方：f′ 是速度（前进还是倒车），f″ 是方向盘（往左打还是往右打）。拐点就是打方向换边的那一瞬间。这一节要做的，就是把「上升下降」和「往哪边弯」这两件事，用导数的符号精确判定，并据此画图。

二、单调性定理

定理　设 f 在 [a,b] 上连续，在 (a,b) 内可导。
（1）若在 (a,b) 内 f′(x) > 0，则 f 在 [a,b] 上严格单调增加；
（2）若在 (a,b) 内 f′(x) < 0，则 f 在 [a,b] 上严格单调减少。

证明　任取 x₁ < x₂ ∈ [a,b]，在 [x₁,x₂] 上用拉格朗日中值定理：存在 ξ ∈ (x₁,x₂)，使 f(x₂) − f(x₁) = f′(ξ)(x₂ − x₁)。由于 x₂ − x₁ > 0 且 f′(ξ) > 0，得 f(x₂) > f(x₁)，故严格增。减的情形同理。

条件可以放宽：f′(x) ≥ 0 且 f′ 在任何子区间上不恒为零，结论仍是严格增。这就解释了为什么 f(x) = x³ 在 0 处虽有 f′(0) = 0，整体仍严格增——个别点导数为零不妨碍单调性。

求单调区间的标准流程：
① 写出定义域，这一步最容易被忽略，也是错误的头号来源；
② 求 f′(x) 并化简，尽量因式分解，便于判号；
③ 找出 f′(x) = 0 的点，以及 f′(x) 不存在的点；
④ 用这些点把定义域切成若干区间，每段内代入一个试验点判断 f′ 的符号。

写法提醒：单调区间必须是定义域内的区间。若定义域被间断点分开（如 f(x) = 1/x 在 x = 0 处断开），要写成 (−∞,0) 和 (0,+∞) 两个区间，中间用逗号或「和」连接，不要写成并集符号。因为并集只表示「这些点合在一起」，并不保证函数在并集上整体单调（1/x 在整个并集上显然不是单调的）。

三、凹凸性与拐点

定义　设 f 在区间 I 上连续。若对 I 上任意两点 x₁、x₂，曲线弧总位于弦的下方，即

f(x₁ + x₂2) < f(x₁) + f(x₂)2

则称曲线在 I 上是凹的（也叫凹向上、下凸）；若弧位于弦的上方，则称凸的（凸向上、上凸）。

教材的约定要记牢：f″ > 0 是凹（下凸），f″ < 0 是凸（上凸）。不同教材的中文用词可能正好相反，做题时以「f″ 的符号 + 曲线在切线上方还是下方」这套几何描述为准，别只背一个中文字。

判定定理　若在 (a,b) 内 f″(x) > 0，则曲线在 (a,b) 内是凹的；若 f″(x) < 0，则是凸的。

证明思路（用泰勒一步到位）：任取 x₀ ∈ (a,b)，把 f 在 x₀ 处展开到一阶并带拉格朗日余项：

f(x) = f(x₀) + f′(x₀)(x − x₀) + f″(ξ)2!(x − x₀)²

右端前两项正是曲线在 x₀ 处的切线。当 f″ > 0 时余项恒大于 0，所以 f(x) 恒大于切线值——曲线整体跑到了切线上方，这就是「凹」的几何含义。f″ < 0 时同理在切线下方。

拐点　连续曲线上凹与凸的分界点称为拐点。判定步骤：① 求 f″；② 找出 f″ = 0 的点与 f″ 不存在的点；③ 逐点检查左右两侧 f″ 是否变号；④ 只有变号的点才是拐点，且拐点要写成坐标 (x₀, f(x₀))，只写 x₀ 是错的。

两个反例必须记住。f(x) = x⁴ 在 0 处 f″(0) = 0，但两侧 f″ 都为正，不是拐点；f(x) = x1/3 在 0 处 f″ 不存在，但两侧符号相反，是拐点。所以「f″ = 0」既不是拐点的充分条件，也不是必要条件，唯一的标准是「两侧变号」。

四、三个常见用途

  • 证明不等式：移项构造 F(x)，证明 F 单调，再用端点值定符号。这是最常用的套路。
  • 比较大小：把两个数看成同一个函数在两点处的函数值，由单调性传递大小关系。
  • 讨论方程根的个数：单调性保证「至多一个」，零点定理（介值定理）保证「至少一个」，两者合起来就是「恰有一个」。

五、例题

例 1　求 f(x) = x³ − 3x 的单调区间、凹凸区间与拐点。

解　定义域为全体实数。f′(x) = 3x² − 3 = 3(x − 1)(x + 1)，零点为 x = ±1。按 ±1 分三段判号：
x < −1 时 f′ > 0，递增；−1 < x < 1 时 f′ < 0，递减；x > 1 时 f′ > 0，递增。
再看二阶导：f″(x) = 6x，零点为 x = 0。x < 0 时 f″ < 0，曲线为凸（上凸）；x > 0 时 f″ > 0，曲线为凹（下凸）。x = 0 两侧变号，故 (0, f(0)) = (0, 0) 是拐点。

结论汇总：增区间 (−∞,−1) 与 (1,+∞)，减区间 (−1,1)；凸区间 (−∞,0)，凹区间 (0,+∞)；拐点 (0,0)。注意凹凸用的是二阶导，别和单调性混在一起。

例 2　证明：当 x > 0 时，x − x²2 < ln(1 + x)。

解　令 F(x) = ln(1 + x) − x + x²/2，只需证 F(x) > 0（x > 0）。求导：
F′(x) = 11 + x − 1 + x = 1 − (1 + x) + x(1 + x)1 + x = x²1 + x
当 x > 0 时 F′(x) > 0，故 F 在 [0,+∞) 上严格增。又 F(0) = ln 1 − 0 + 0 = 0，所以 x > 0 时 F(x) > F(0) = 0，即 ln(1 + x) > x − x²/2。

这类题的关键是「移项造 F，让 F(0) = 0」，然后只需证 F 单调增。若 F′(x) 的符号不好判断，可再求一次导（即用 F″）辅助判号——这正是凹凸性的用处。

例 3　证明方程 x = cos x 在 (0,1) 内有且仅有一个实根。

解　令 f(x) = x − cos x，在 [0,1] 上连续。先证「至少一个」：f(0) = 0 − 1 = −1 < 0，f(1) = 1 − cos 1 > 0（因 cos 1 < 1），由零点定理，存在 x₀ ∈ (0,1) 使 f(x₀) = 0。
再证「至多一个」：f′(x) = 1 + sin x。对一切 x 有 sin x ≥ −1，故 f′(x) ≥ 0，且等号只在孤立点成立，因此 f 在 [0,1] 上严格增，零点唯一。

「存在性用零点定理、唯一性用单调性」是证明根的唯一性的固定两段式，缺一段都要扣分。写严格增时要说清「f′ ≥ 0 且不恒为零」，不能只写 f′ ≥ 0 就下严格结论。

六、与后文的联系与易错提醒

单调性判定是下一节求极值的基础：第一充分条件说的就是「f′ 左正右负」，本质上是把单调性用在 x₀ 的两侧。凹凸性则接上泰勒公式与函数作图：知道了升降、极值、凹凸、拐点、渐近线，一条曲线就画全了。

四个易错点：一是不求定义域就分区间，导致把不在定义域内的点当成分界点；二是单调区间用并集符号连接；三是把 f″ = 0 一律当成拐点，忘了验两侧变号；四是把凹凸和单调混淆——f 递增与 f 是凹是凸毫无关系，一个看一阶导，一个看二阶导，必须分开写。

一、直观理解：局部最高点与全局最高点

山坡上有许多小丘和小谷。站在某个小丘顶上，你比附近任何一点都高，但未必比远处的山峰高——这就是「极值」与「最值」的区别：极值是局部概念，只跟一个邻域内的点比；最值是整体概念，要跟整个区间内的点比。一个函数可以有多个极大值，而且某个极大值还可能小于另一个极小值。

生活中的版本：某商店把单价定为 p 时利润最大，这个 p 是「极值点」；但如果价格有上限、有成本约束，真正能取到的最优价格还要在闭区间上比较，那才是「最值」。

二、定义

定义　设 f 在 x₀ 的某邻域 U(x₀, δ) 内有定义。若对一切 x ∈ U(x₀, δ) 都有 f(x) ≤ f(x₀)，则称 f(x₀) 为 f 的极大值，x₀ 为极大值点；若都有 f(x) ≥ f(x₀)，则称为极小值。

三点注意：邻域必须是双侧的，所以端点不谈极值；极值点是 x 坐标，极值是函数值，问「极值点」要答 x₀，问「极值」要答 f(x₀)；极大值不一定大于极小值，两者只是各自邻域内的「老大」和「老小」。

三、必要条件：极值只可能藏在两类点里

定理（必要条件）　若 f 在 x₀ 处可导且取得极值，则 f′(x₀) = 0。这正是第一节的费马引理。

逆命题不成立：f(x) = x³ 在 0 处 f′(0) = 0，但 0 的两侧函数都在增，0 不是极值点。反过来，极值也可能出现在不可导点：f(x) = |x| 在 0 处不可导，却是极小值点。

于是得到一条极重要的结论：极值的可疑点 = 驻点（f′ = 0 的点）∪ 不可导点。求极值时这两类必须都找出来，漏掉不可导点是常见失分点。

四、两个充分条件

第一充分条件（看 f′ 的符号变化）　设 f 在 x₀ 处连续，在 x₀ 的某去心邻域内可导：
（1）x < x₀ 时 f′(x) > 0，x > x₀ 时 f′(x) < 0，则 f(x₀) 为极大值；
（2）左负右正，则 f(x₀) 为极小值；
（3）两侧同号，则 f(x₀) 不是极值。

理由很直接：左增右减，x₀ 就是「山顶」；左减右增，就是「谷底」；一直增或一直减，就没有转折。这条条件对不可导点同样适用，是适用范围最广的一条。

第二充分条件（看 f″ 的符号）　设 f′(x₀) = 0，f″(x₀) ≠ 0：
（1）f″(x₀) < 0，则 f(x₀) 为极大值；（2）f″(x₀) > 0，则 f(x₀) 为极小值。

证明（用导数定义，非常漂亮）：由 f′(x₀) = 0，

f″(x₀) = limx→x₀ f′(x) − f′(x₀)x − x₀ = limx→x₀ f′(x)x − x₀

若 f″(x₀) < 0，由极限的保号性，在 x₀ 的某去心邻域内该比值 < 0。于是当 x < x₀ 时分母为负，故 f′(x) > 0；当 x > x₀ 时分母为正，故 f′(x) < 0。左正右负，由第一充分条件知 f(x₀) 为极大值。

失效情形：f″(x₀) = 0 时第二条件什么也说不出来。f(x) = x³ 在 0 处 f′ = f″ = 0，不是极值；f(x) = x⁴ 在 0 处 f′ = f″ = 0，却是极小值。此时必须回到第一充分条件，看 f′ 的符号。

五、闭区间上的最值

闭区间上连续的函数一定取得最大值与最小值（最值定理），而且只可能在以下三类点取到：驻点、不可导点、区间端点。所以标准做法是：求出全部可疑点，逐个算出函数值，再比大小。

注意不是「先求极值再挑最大的」。端点的函数值完全可能比所有极值都大，漏掉端点就是漏掉正确答案。

六、应用题的标准流程

  1. 设变量，写出目标函数，即要最大或最小的那个量。
  2. 写出约束条件，用它把目标函数化成一元函数。
  3. 确定自变量的实际取值范围，如长度 > 0、角度落在 (0, π/2)。
  4. 求导、找驻点。若在范围内只有一个驻点，且实际问题必有最值，则该驻点就是所求，不必再验证二阶导。
  5. 作答时带上单位，并看清题目问的是「最大值是多少」还是「取得最大值时条件是什么」。

七、例题

例 1　求 f(x) = x³ − 3x 的极值。

解　f′(x) = 3x² − 3 = 3(x − 1)(x + 1)，驻点为 x = ±1，无不可导点。f″(x) = 6x。
在 x = −1：f′(−1) = 0，f″(−1) = −6 < 0，故 f(−1) = −1 + 3 = 2 为极大值；
在 x = 1：f′(1) = 0，f″(1) = 6 > 0，故 f(1) = 1 − 3 = −2 为极小值。

用第二充分条件最快。若改用第一条件：x < −1 时 f′ > 0，−1 < x < 1 时 f′ < 0，故 −1 处取极大；1 的两侧由负变正，取极小。结论一致。

例 2　求 f(x) = x2/3(x − 3) 的极值。

解　先展开求导：f(x) = x5/3 − 3x2/3，故
f′(x) = 53x2/3 − 2x−1/3 = 5x − 63x1/3
令 f′ = 0 得驻点 x = 6/5；x = 0 处 f′ 不存在，但 f 在 0 处有定义，故两类可疑点都要查。
判号：x < 0 时分子 5x − 6 < 0、分母 3x1/3 < 0，比值 > 0，递增；0 < x < 6/5 时分子 < 0、分母 > 0，比值 < 0，递减；x > 6/5 时两者同为正，比值 > 0，递增。
所以 x = 0 处左增右减，取极大值 f(0) = 0；x = 6/5 处左减右增，取极小值
f(65) = (65)2/3(65 − 3) = −95(65)2/3

本题的价值在于 x = 0：它不在 f′ = 0 的解里，只出现在分母为零处。若只解 f′ = 0，就会漏掉这个极大值。这是「不可导点也可能是极值点」最典型的例子。

例 3　用铁皮做一个无盖圆柱形容器，容积为 V，问底面半径取多少时用料最省（即表面积最小）？

解　设底面半径为 r，高为 h。由体积条件 V = πr²h 得 h = V/(πr²)。表面积（有底无盖）为
S = πr² + 2πrh = πr² + 2Vr，r > 0
求导：S′(r) = 2πr − 2V/r²。令 S′ = 0，得 πr³ = V，即
r = (Vπ)1/3
又 S″(r) = 2π + 4V/r³ > 0，故该点为极小值点。由于在 (0,+∞) 内只有一个驻点，且实际问题必有最小表面积，所以它就是最小值点。此时
h = Vπr² = πr³πr² = r
即底面半径等于高时用料最省。

应用题的三个易漏点全在这一题里：定义域 r > 0、用约束消元化成一元、以及「唯一驻点 + 实际意义」代替二阶导验证。最后别忘回答「半径等于高的圆柱」，而不只是甩出一个 r 的表达式。

八、与后文的联系与易错提醒

极值是本章的落点：单调性用来定「升降」，极值条件用来定「转折」，最值再在转折与端点中挑出全局最优。再往后（不定积分与定积分应用）求最大利润、最小成本、最优尺寸，用的都是这一套流程。

四个高频错误：一是只解 f′ = 0，漏掉不可导点；二是把驻点当极值点，忘了 x³ 型反例；三是闭区间求最值漏掉端点；四是应用题不写定义域，或求出驻点后不说明它为什么是最值。记住一句话：可疑点找全，比较之后再下结论。
