一、直观引入：无穷多个数能相加吗

《庄子》说「一尺之棰，日取其半，万世不竭」。每天取走剩下的一半，取走的长度依次是 12、14、18……这样无穷多个数加起来，结果到底是 1，还是一个「永远差一点」的东西？有限个数相加我们毫无困难，无穷多个数相加就必须先回答：这个「和」指什么。

更麻烦的是，直觉在这里会失灵。把 1 与 −1 交替相加：1 − 1 + 1 − 1 + …。如果两个一组加括号，得 (1 − 1) + (1 − 1) + … = 0；如果从第二项开始加括号，得 1 + (−1 + 1) + (−1 + 1) + … = 1。同一串数算出两个不同的值，说明这串数的「和」根本不存在，问题出在「无穷多个数相加」这句话本身还没有定义。

解决的办法很朴素：不去直接定义无穷和，而是先算有限和，再看有限和有没有极限。这就把级数问题转化成了数列极限问题——这正是上册极限理论的直接应用。

二、定义：级数收敛就是部分和数列收敛

给定数列 u1, u2, …, un, …，把形式上的和

Σn=1∞ un = u1 + u2 + … + un + …

叫做常数项级数（简称级数），un 叫做它的通项或一般项。注意此时它只是一个记号，还没有值。

截取前 n 项，得到一个普通的有限和，称为部分和：

Sn = u1 + u2 + … + un = Σk=1n uk

当 n 依次取 1, 2, 3, … 时，Sn 构成一个数列 {Sn}，称为部分和数列。

定义　若部分和数列 {Sn} 有极限 S（S 为有限常数），则称级数 Σun 收敛，并称 S 为该级数的和，记 Σn=1∞ un = S；若 {Sn} 没有极限，则称级数发散。

这个定义要读出三层意思。第一，「和」是一个极限，不是加法，所以写 Σn=1∞ un 的时候可以放心把它当成一个数来参与运算。第二，Sn 只是近似值，前面的有限项再多也不能「等于」S。第三，由此自然引出余项 rn = S − Sn = un+1 + un+2 + …，收敛时必有 rn → 0，这是后面估计误差的工具。

三、两把标尺：几何级数与 p-级数

几何级数（等比级数）是唯一能直接求和的一类。设 a ≠ 0，公比 q，则

Sn = a + aq + aq2 + … + aqn−1 = a1 − qn1 − q　(q ≠ 1)

逐种情形讨论：当 |q| < 1 时 qn → 0，故 Sn → a1 − q，收敛；当 |q| > 1 时 qn 无界，Sn 无界，发散；当 q = 1 时 Sn = na → ∞，发散；当 q = −1 时 Sn 在 a 与 0 之间来回跳动，无极限。于是

Σn=1∞ aqn−1 收敛 ⟺ |q| < 1，且此时和为 a1 − q

代入 a = 12, q = 12 得 12 + 14 + … = 1，庄子的问题有了严格答案。

第二个标尺是 p-级数 Σ1np。其中 p = 1 时叫调和级数 Σ1n，它发散，证明用分组法：

13 + 14 > 12，　15 + … + 18 > 12，　19 + … + 116 > 12

每 2k 项合起来都不小于 1/2，所以 S2m > 1 + m2 → ∞，部分和无界。当 p < 1 时 1np > 1n，更加发散；p > 1 的收敛性第二节用积分判别法给出。合并成一句：

Σ1np 收敛 ⟺ p > 1

这两条结论本身不复杂，但它们是后面所有比较判别法的「标准件」，必须能脱口而出。

四、基本性质

  • 线性性　若 Σun = S、Σvn = T 都收敛，则 Σ(aun + bvn) = aS + bT。注意「收敛 + 发散 = 发散」，但「发散 + 发散」可能收敛（如 Σ1n 与 Σ(−1n)）。
  • 有限项无关　去掉、增加或改变级数的有限项，不改变敛散性，只可能改变和的值。所以判敛时可以随手丢掉前面几项。
  • 加括号　收敛级数任意加括号后仍收敛且和不变，因为加括号后的部分和是原部分和数列的一个子列。反之不成立：(1 − 1) + (1 − 1) + … 收敛于 0，原级数却发散。
  • 必要条件　收敛 ⟹ un → 0。理由是 un = Sn − Sn−1 → S − S = 0。逆命题不真，调和级数就是反例。实际使用中用它更常用的逆否形式：通项不趋于 0 ⟹ 发散。

五、例题

例 1　判别级数 Σn=1∞ 1n(n + 1) 的敛散性，若收敛求出和。

解　通项不能直接求和，先裂项：un = 1n(n + 1) = 1n − 1n + 1。于是

Sn = (1 − 12) + (12 − 13) + … + (1n − 1n + 1) = 1 − 1n + 1

相邻项两两抵消（这叫裂项相消），只剩首尾。令 n → ∞ 得 Sn → 1，故级数收敛，和为 1。

裂项是少数能直接求出部分和的通项类型，见到分母是两个相邻因式之积就该想到它。Σ1n(n + 2) 一类，裂项后剩下的是隔一项的两列，需要具体算，不能照搬「首尾相消」。

例 2　判别级数 Σn=1∞ n2n + 1 的敛散性。

解　先看通项：limn→∞ n2n + 1 = 12 ≠ 0。由收敛的必要条件（逆否），级数发散。

这类题千万不要动笔去「比较」「求积分」，通项不趋 0 一步就结束。反过来说，只有确认了通项趋于 0，才值得往下用判别法。

例 3　求级数 Σn=0∞ 3 · (−12)n 的和。

解　这是首项 a = 3、公比 q = −12 的几何级数，|q| = 12 < 1，收敛。由公式

S = a1 − q = 31 + 1/2 = 2

用几何级数公式时先确认 |q| < 1，再代公式；另外要看清级数是从 n = 0 还是 n = 1 开始，首项 a 不同，结果会差一个 q 倍。

六、与后文的联系

本节只解决了「什么是收敛」和两类特殊级数。实际遇到的级数几乎都不能直接求和，所以判断敛散只能靠充分条件，这就是第二节到第三节的任务。而全章的逻辑起点在这里：所有判别法都建立在「部分和数列」这个定义之上，所有判别法的第一条检查都是「通项是否趋于 0」。常见套路有三：裂项求和（考定义）、用必要条件判发散（考 un 的极限）、化为几何级数求和（考公式）。易错点是：把「通项趋于 0」当判据、把「加括号后收敛」当原级数收敛、忘记去掉有限项不改变敛散性而白算半天。

一、正项级数为什么好办

若 un ≥ 0，则部分和满足 Sn+1 = Sn + un+1 ≥ Sn，即 {Sn} 单调不减。上册的单调有界准则说：单调不减数列收敛 ⟺ 有上界。于是立刻得到全节的根：

定理（正项级数判别原理）　正项级数收敛 ⟺ 它的部分和数列有上界。

这条原理本身不能直接用来判敛（上界往往写不出来），但它是所有判别法的共同来源：比较判别法比的就是「有没有上界」，比值法与根值法找的是「用几何级数当上界」，积分判别法比的是「用广义积分当尺子」。理解了这一点，就不必死记硬背五条判别法，而是知道每一条在估计什么。

二、比较判别法

基本形式　设存在 N，当 n > N 时 0 ≤ un ≤ vn，则

（1）若 Σvn 收敛，则 Σun 收敛；（2）若 Σun 发散，则 Σvn 发散。

证明：（1）由 un ≤ vn 得 Σk=1n uk ≤ Σk=1n vk ≤ Σk=1∞ vk，部分和有上界，由原理收敛；（2）是（1）的逆否命题。口诀：大的收敛则小的收敛，小的发散则大的发散。

极限形式（做题主要用这个）　设 un > 0, vn > 0，limn→∞ unvn = c，则

  • 0 < c < +∞：两级数同敛散（un 与 vn 同阶）；
  • c = 0：Σvn 收敛 ⟹ Σun 收敛（un 比 vn 小得多）；
  • c = +∞：Σvn 发散 ⟹ Σun 发散。

用法是「抓主部」：把 un 里的低阶项全部丢掉，只看决定阶的那一项，取 vn = 1np。例如 n2n3 + 1 ~ 12n2，取 vn = 1n2，c = 12，故收敛。

三、比值法与根值法

比值判别法（达朗贝尔）　设 un > 0，limn→∞ un+1un = ρ，则 ρ < 1 收敛，ρ > 1 发散，ρ = 1 时本方法失效。

证明思路（ρ < 1）：取 q 满足 ρ < q < 1，则存在 N，当 n ≥ N 时 un+1/un ≤ q，连乘得

un ≤ uN qn−N　(n ≥ N)

右边是收敛的几何级数，由比较判别法原级数收敛。ρ > 1 时从某项起 un 递增，通项不趋于 0，发散。

根值判别法（柯西）　设 un > 0，limn→∞ n√un = ρ，判据与比值法完全相同。证明一样：ρ < 1 时 un ≤ qn，被几何级数控制。

怎么选？出现 n!、an、nn、连乘积，相邻项一定能大量约分，用比值法；通项整体是一个 n 次幂（如 (n2n + 1)n），开 n 次方后立刻干净，用根值法。两者都是「与几何级数比」，所以对 1/np 这种多项式阶的通项必然失效（ρ = 1），这是理论上的必然，不是技巧问题。

四、积分判别法

设 f(x) 在 [1, +∞) 上连续、非负、单调递减，un = f(n)，则

Σn=1∞ un 与 ∫1+∞ f(x)dx 同敛散

证明思路：由单调性，在 [k, k+1] 上 f(k+1) ≤ f(x) ≤ f(k)，积分得

f(k+1) ≤ ∫kk+1 f(x)dx ≤ f(k)

对 k 从 1 到 n−1 求和，得 Σk=2n f(k) ≤ ∫1n f(x)dx ≤ Σk=1n−1 f(k)。不等式两头互相控制，一边有界另一边也有界，故同敛散。

它专治「非幂次」的通项：1n ln n、1n ln2n、1n2 + 1 这类，比较法要么难找标尺，要么找不到合适的 p-级数。

五、例题

例 1　判别 Σn=1∞ 12n2 + 3n + 5 的敛散性。

解　正项级数。抓主部：分母最高次是 2 次，故取 vn = 1n2。计算

limn→∞ unvn = limn→∞ n22n2 + 3n + 5 = 12

极限为有限正数，两式同敛散。而 Σ1/n2 是 p = 2 > 1 的 p-级数，收敛，故原级数收敛。

抓主部时只看 n 的最高次：分子次数与分母次数之差就是 p。差为 1 时（如 12n + 3）恰好落在 p = 1 的发散边界，此时要小心判断。

例 2　判别 Σn=1∞ n!nn 的敛散性。

解　含 n!，首选比值法。记 un = n!nn，则

un+1un = (n+1)! nnn! (n+1)n+1 = nn(n+1)n = 1(1 + 1/n)n

取极限，分母趋于 e，故 ρ = 1e < 1，级数收敛。

约分的关键一步是把 (n+1)! 拆成 (n+1)·n!，同时把 (n+1)n+1 拆成 (n+1)·(n+1)n，约掉 n! 与那个 (n+1)。最后一定要把 (1 + 1/n)n 的极限算出来，它是 e，不能停在原式。

例 3　判别 Σn=2∞ 1n ln n 的敛散性。

解　取 f(x) = 1x ln x，在 [2, +∞) 上连续、非负、单调递减，可用积分判别法。计算

∫2+∞ 1x ln x dx = limb→+∞ [ln ln b − ln ln 2] = +∞

广义积分发散，故原级数发散。

这个例子最能说明「通项趋 0 不等于收敛」：1n ln n 比 1n 还小，照样发散。改用 1n ln2n，积分得 1/ln 2 有限，就收敛了——ln n 的指数决定敛散。

六、常考套路与易错

看到级数先做三件事：看通项是否趋于 0；看通项结构（含阶乘、含 n 次幂、是分式、含 ln）；选判别法。经验顺序是：能抓主部就用极限比较法（最通用），含阶乘或指数用比值法，整体幂次用根值法，非幂次用积分法，都不行再回到不等式比较。易错点有四个：ρ = 1 时误判为收敛（其实是失效，必须换法）；比较法的不等号方向搞反（小的收敛推不出大的收敛）；极限比较法中 vn 选错阶，导致 c = 0 或 ∞ 却强行下结论；对含参数的级数忘记讨论参数范围。此外，正项级数的判别法一律不能直接用于一般项级数，必须先取绝对值，这是第三节的内容。

一、直观引入：符号交替带来的抵消

正项级数的部分和只增不减，要么收敛到某个数，要么一路涨上去；一旦允许项取负号，部分和就可以上下摆动，而摆动本身会产生抵消，使级数在没有任何衰减到「足够快」的情况下也能收敛。最典型的例子是

1 − 12 + 13 − 14 + … = ln 2

它各项的绝对值构成调和级数，是发散的；可加上交替符号以后居然收敛到一个具体的数（这个等式第五节会由 ln(1 + x) 的展开式给出）。这说明研究任意项级数时，「取绝对值」和「不取绝对值」会得到完全不同的结论，而这恰好是本节的两个核心概念：绝对收敛与条件收敛。

二、交错级数与莱布尼茨判别法

形如

Σn=1∞ (−1)n−1 un = u1 − u2 + u3 − …　(un > 0)

的级数称为交错级数。

定理（莱布尼茨判别法）　若数列 {un} 满足（1）un ≥ un+1（n ≥ N，单调递减）；（2）limn→∞ un = 0，则交错级数收敛，且其和 S 满足 S ≤ u1，余项满足 |rn| ≤ un+1。

证明　先看偶部分和。把相邻两项配成一组：

S2n = (u1 − u2) + (u3 − u4) + … + (u2n−1 − u2n)

每个括号非负，故 S2n 单调不减。再换一种配对：

S2n = u1 − (u2 − u3) − … − (u2n−2 − u2n−1) − u2n ≤ u1

于是 S2n 单调不减且有上界 u1，由单调有界准则收敛，设 S2n → S。再看奇部分和：S2n+1 = S2n + u2n+1，由条件（2）它也趋于 S。两个子列同极限，故 Sn → S，级数收敛。又因 S 总夹在相邻两个部分和之间，|S − Sn| ≤ un+1，这就是余项估计。

三、绝对收敛与条件收敛

定义　对任意项级数 Σun：若 Σ|un| 收敛，称 Σun 绝对收敛；若 Σun 收敛但 Σ|un| 发散，称 Σun 条件收敛。

定理　绝对收敛的级数必收敛。

证明　由 0 ≤ un + |un| ≤ 2|un| 及比较判别法，Σ(un + |un|) 收敛；而

Σun = Σ(un + |un|) − Σ|un|

是两个收敛级数之差，故收敛。逆命题不成立：Σ(−1)n−1/n 收敛，但绝对值级数是调和级数，发散，所以它是条件收敛的。这个定理的意义在于：判断任意项级数，先试绝对值级数，因为绝对值级数是正项级数，第二节全套工具都能上。

四、判敛流程（四步，形成条件反射）

  1. 看通项：若 un 不趋于 0，由必要条件直接判发散，结束。
  2. 判绝对值级数 Σ|un|：用比较、比值、根值、积分诸法。若收敛，则原级数绝对收敛，结束。
  3. 绝对值发散，再看是否交错：验证 {un} 单调递减且趋于 0，用莱布尼茨得条件收敛。
  4. 都不行（如 Σsin nn）：用狄利克雷判别法或阿贝尔判别法，或直接分析部分和。

五、例题

例 1　讨论 Σn=1∞ (−1)n−1√n 的敛散性，并指出是绝对收敛还是条件收敛。

解　先判绝对值级数：Σ1√n = Σ1n1/2，这是 p = 1/2 < 1 的 p-级数，发散。

再判原级数：un = 1√n 单调递减（分母增大），且 limn→∞ 1√n = 0，两个条件都满足，由莱布尼茨判别法收敛。

收敛但绝对值级数发散，故为条件收敛。

这道题是全章最高频的模板题，必须能一遍写对。注意「先绝对值，后交错」的顺序：绝对值收敛就一步到位说绝对收敛，不必再验证单调性。

例 2　讨论 Σn=1∞ (−1)n nn2 + 1 的敛散性。

解　绝对值级数 Σnn2 + 1，与 1n 相比：limn→∞ n/(n2 + 1)1/n = 1，同敛散，而 Σ1/n 发散，故绝对值级数发散。

再验证单调性：设 f(x) = xx2 + 1，则 f′(x) = 1 − x2(x2 + 1)2 < 0　(x > 1)，故 n ≥ 2 时 un 单调递减；又 un → 0。由莱布尼茨，级数收敛，且为条件收敛。

「单调递减」不能只凭肉眼说「显然」。分式型通项一律求导（或作差 un+1 − un）来证，写一句「由 f′(x) < 0 知单调递减」即可得分。

例 3　讨论 Σn=1∞ (−1)nn2 的敛散性。

解　绝对值级数 Σ1/n2 是 p = 2 > 1 的 p-级数，收敛，故原级数绝对收敛，当然也收敛。

绝对收敛时不必再验莱布尼茨条件，写了反而显得没抓住主次。但反过来，只说「收敛」是不够的，题目问绝对 / 条件时必须明确表态。

六、常考套路与易错提醒

考试只有三种问法：判敛散、判绝对还是条件、求近似和（用 |rn| ≤ un+1 估误差）。三个易错点必须记牢。第一，莱布尼茨的两个条件缺一不可，单调性不验证就下结论是典型失分；反例是 un 取 1/n（n 为奇数）、1/n2（n 为偶数），通项趋于 0 但不单调，级数实际发散。第二，条件收敛级数不能重排：黎曼定理说，条件收敛级数经过重排可以收敛到任意指定的数，甚至发散；也不能随意加括号改变和。第三，只有交错级数才能用莱布尼茨，通项符号不规则时（如 sin n）要另想办法。这些结论在第四节判幂级数端点和第七节判傅里叶级数收敛时都会再用一次。

一、直观引入：从常数项到函数项

前面研究的级数，每一项都是数。如果把通项乘上 xn，得到

Σn=0∞ an xn = a0 + a1x + a2x2 + …

每给定一个具体的 x，它就退化成一个常数项级数，敛散与否取决于 x 的大小。比如 Σxn 在 |x| < 1 时收敛、在 |x| ≥ 1 时发散。于是核心问题变成：哪些 x 使级数收敛？答案的形态出奇地整齐——一个以原点为中心的区间，叫作收敛域。

二、阿贝尔定理：收敛域为什么是区间

定理（阿贝尔）　若 Σanx0n 在 x0 ≠ 0 处收敛，则对一切满足 |x| < |x0| 的 x，级数绝对收敛；若在 x1 处发散，则对一切 |x| > |x1| 的 x，级数发散。

证明　由 Σanx0n 收敛知通项 anx0n → 0，故有界：存在 M，使 |anx0n| ≤ M。于是对 |x| < |x0|，令 q = |x/x0| < 1，

|anxn| = |anx0n| · |xx0|n ≤ M qn

右端是收敛的几何级数，由比较判别法，Σ|anxn| 收敛。后半句是前半句的逆否命题。

由阿贝尔定理，存在唯一的 R（0 ≤ R ≤ +∞）使得 |x| < R 时绝对收敛、|x| > R 时发散，称为收敛半径，(−R, R) 称为收敛区间。端点 x = ±R 是「临界点」，可能收敛也可能发散，必须单独判。

三、求收敛半径的两个公式

对标准形 Σan(x − x0)n（把 x0 平移到原点即 Σanxn）：

R = limn→∞ |anan+1|　或　R = 1limn→∞ n√|an|

两式来源于把比值法、根值法用在 Σ|anxn| 上：比值法要求 |an+1x|/|an| → |x|/R < 1，即 |x| < R。所以要理解公式，不要背公式。

第一个公式在 an = 0（缺项）时不能用，因为分子分母可能出现零。例如 Σx2n，奇数项系数全为 0。此时有两个办法：令 t = x2 化为 Σtn，先求 t 的收敛范围再换回 x；或者直接对整项用比值法，令 |un+1un| → ρ 再解 ρ < 1。

四、求收敛域的三步

  1. 求 R（或直接对整项用比值法解不等式）；
  2. 写出开区间，例如 (x0 − R, x0 + R)；
  3. 把两个端点分别代入原级数，化回常数项级数逐个判敛，最后写出收敛域。

第 3 步是幂级数题最固定的送分点，也是最大的失分点：只写开区间要扣一半分。

五、和函数的分析性质

设 Σanxn 的收敛半径为 R > 0，和函数为 S(x)，则 S(x) 在 (−R, R) 内连续，并可逐项求导与逐项积分：

S′(x) = Σn=1∞ n an xn−1，　∫0x S(t)dt = Σn=0∞ ann + 1 xn+1

两式的收敛半径仍为 R（这是幂级数的特权，一般函数项级数没有）。但端点的收敛性会变：Σxn 在 x = −1 发散，逐项积分后 Σxn+1/(n+1) 在 x = −1 收敛（交错调和）。所以写和函数时，定义域要用原级数的收敛域，不能拿求导后的级数去扩大范围。

六、例题

例 1　求 Σn=1∞ xnn 的收敛域。

解　这里 an = 1/n，

R = limn→∞ |anan+1| = limn→∞ n + 1n = 1

开区间为 (−1, 1)。端点：x = 1 时级数为 Σ1/n，调和级数，发散；x = −1 时为 Σ(−1)n/n，交错且 1/n 单调递减趋于 0，收敛。故收敛域为 [−1, 1)。

答案是半开半闭区间，这种「不对称」正是端点必须单判的原因。

例 2　求 Σn=1∞ (x − 2)nn · 3n 的收敛域。

解　记 t = x − 2，an = 1/(n·3n)，

R = limn→∞ (n+1)3n+1n·3n = 3

故 |x − 2| < 3，即 −1 < x < 5 内绝对收敛。端点：x = −1 时 t = −3，级数为 Σ(−1)nn，交错收敛；x = 5 时 t = 3，级数为 Σ1/n，发散。收敛域为 [−1, 5)。

中心不在原点的题，先把 x − x0 整体当 t 处理，最后再平移回去，能避免符号错误。

例 3　求 Σn=0∞ n! xn 的收敛域。

解　用比值法判绝对收敛：|un+1||un| = (n+1)|x| → +∞　(x ≠ 0)，只要 x ≠ 0，比值就大于 1，级数发散；x = 0 时每项为 0，级数收敛。

故 R = 0，收敛域是单点集 {0}。

R = 0 与 R = +∞ 都是正常答案。反过来 Σxn/n! 的 R = +∞，收敛域是整个数轴，逐项求导积分照样成立。

七、常考套路与易错

幂级数这一节的题，八成是「求收敛域」，两成是「已知收敛域反求参数」。套路固定：求 R → 写开区间 → 端点代入 → 结论。易错点集中在四处：漏判端点；缺项级数硬套 R = lim|an/an+1|；把「收敛区间」与「收敛域」混为一谈（前者是开区间，后者含端点信息）；逐项求导后用新的收敛域代替原收敛域。下一节要反过来用：已知展开式，通过逐项求导、积分得到新的展开式，那里的合法性正是本节的性质保证的。

一、直观引入：把函数换成多项式

上册学过泰勒公式：函数在一点附近可以用多项式逼近。如果把这个多项式的次数取到无穷，就成了幂级数。一旦函数被写成幂级数，求导、积分、近似计算、解微分方程全都变成对多项式逐项操作——这是级数理论最实用的出口。

问题是：任何一个函数都能这样展开吗？系数怎么定？展开式唯一吗？本节回答这三个问题，并给出五个必须背熟的展开式。

二、泰勒级数：系数唯一与收敛条件

设 f(x) 在 x0 的某邻域内能展开成幂级数

f(x) = Σn=0∞ an(x − x0)n

则逐项求导 n 次后令 x = x0，得 f(n)(x0) = n! an，即

an = f(n)(x0)n!

这说明展开式若存在则唯一，且系数由 f 在一点处的各阶导数决定。用这组系数写出的级数叫 f 的泰勒级数（x0 = 0 时叫麦克劳林级数）。

但「写出泰勒级数」不等于「它收敛到 f」。把 f 与其 n 次泰勒多项式之差记为余项 Rn(x)，则

f 能展开成泰勒级数 ⟺ limn→∞ Rn(x) = 0

这个条件在收敛区间内成立，才是展开合法的依据。直接法就是「算系数 + 验余项」，实际很少用，因为求高阶导数往往算不动。

三、五个必须脱口而出的展开式

11 − x = 1 + x + x2 + … = Σn=0∞ xn　(|x| < 1)

ex = Σn=0∞ xnn!　(−∞ < x < +∞)

sin x = Σn=0∞ (−1)nx2n+1(2n + 1)!　(−∞ < x < +∞)

cos x = Σn=0∞ (−1)nx2n(2n)!　(−∞ < x < +∞)

ln(1 + x) = Σn=1∞ (−1)n−1xnn = x − x22 + x33 − …　(−1 < x ≤ 1)

(1 + x)α = 1 + αx + α(α − 1)2!x2 + …　(|x| < 1)

第一式是全章的「母式」，其余都可以由它通过代换、求导、积分得到。注意 ln(1 + x) 的收敛域左端开、右端闭，这个细节常在端点讨论题里出现。

四、间接法：三种基本动作

既然展开式唯一，就不必每次都用泰勒公式，只要把待求式变形成已知式即可。手段只有三类：

  • 代换　把 x 换成 −x、x2、2x、x − 1 等，收敛域随之变换；
  • 四则运算　乘常数、加减、乘除多项式，两个级数相加减时收敛域取交集；
  • 逐项求导 / 逐项积分　对已知展开式操作，收敛半径不变，端点需另判。

做完全部变形，最后补一句「由展开式的唯一性，此即所求」，答案才算完整。

五、例题

例 1　把 f(x) = 12 + x 展开成 x 的幂级数。

解　先提常数，把分母化成 1 − t 的形状：

12 + x = 12 · 11 + x/2 = 12 · 11 − (−x/2)

对 t = −x/2 用母式，得

12 + x = 12 Σn=0∞ (−x2)n = Σn=0∞ (−1)nxn2n+1　(|x| < 2)

收敛域由 |t| < 1 即 |x/2| < 1 解出，不能照抄 |x| < 1。端点 x = ±2 时通项不趋于 0，故开区间就是最终答案。

例 2　用积分法推出 ln(1 + x) 的展开式，并讨论端点 x = 1。

解　在母式中令 x → −x：11 + x = Σn=0∞ (−1)nxn　(|x| < 1)。两边从 0 到 x 逐项积分：

ln(1 + x) = ∫0x 11 + t dt = Σn=0∞ (−1)nxn+1n + 1 = Σn=1∞ (−1)n−1xnn　(|x| < 1)

端点 x = 1：右边是 1 − 1/2 + 1/3 − …，交错且 1/n 递减趋于 0，收敛；左边 ln 2 有限，故展开式在 x = 1 也成立。端点 x = −1：右边为 −Σ1/n，发散。最终 −1 < x ≤ 1。

逐项积分后一定要回代端点重判，这正是第四节「端点可能变」的具体体现。同时得到著名等式 ln 2 = 1 − 1/2 + 1/3 − …。

例 3　把 f(x) = e−x2 展开成幂级数，并写出 ∫01 e−x2dx 的级数表示。

解　在 et = Σtn/n! 中令 t = −x2：

e−x2 = Σn=0∞ (−1)nx2nn!　(−∞ < x < +∞)

在 [0, 1] 上逐项积分（收敛域是整个数轴，合法）：

∫01 e−x2dx = Σn=0∞ (−1)nn!(2n + 1)

这个积分没有初等原函数，只有级数表示——它是「用级数做积分」的标准范例。取前几项即可得近似值，误差由交错级数余项控制，这是第六节的内容。

六、常考套路与易错

题型只有三种：直接展开（给函数求级数）、反求（给级数求和函数，第六节）、求某点的高阶导数（用 an = f(n)(0)/n! 反推）。易错点：写完级数忘写收敛区间；把 1/(2 + x) 这类直接套 |x| < 1；两个展开式相加不取收敛域交集；逐项积分或求导后不重判端点。另外，含 x2 的代换要保持级数只含偶次项，不要「补」出奇次项。

一、直观引入：级数是台「变形机器」

第五节解决的是「函数 → 级数」，本节反过来：给一个幂级数，求它的和函数。表面上是求和，实质上是变形——把陌生的级数通过逐项求导或逐项积分，变成熟悉的几何级数，算出结果后再按相反方向还原。所以这一节不考新定理，考的是对「操作顺序」的判断。

二、求和函数的五步法

  1. 先求收敛域。和函数只在收敛域内成立，这一步不能省，也是最后答案的组成部分。
  2. 看系数决定动作：系数含 n（或 n 的幂），说明它是求导「长出来」的，应当先积分把它消掉；系数含 1/n、1/(n + 1)，说明它是积分「长出来」的，应当先求导。
  3. 凑成母级数 Σtn 的形状（t 可以是 x、x2、x/2 等），必要时提出常数因子或补项。
  4. 用公式求和：Σn=0∞ tn = 11 − t。
  5. 还原并写定义域：把第 2 步的操作反向做一遍，注明 |x| < R。

这套流程之所以合法，是因为第四节已证明：在收敛区间内逐项求导、逐项积分不改变收敛半径。

三、母级数与常用派生结果

Σn=0∞ xn = 11 − x　(|x| < 1)

对它逐项求导：Σn=1∞ n xn−1 = 1(1 − x)2，两边乘 x 得

Σn=1∞ n xn = x(1 − x)2　(|x| < 1)

对它逐项积分：Σn=1∞ xnn = −ln(1 − x)；再乘除 x 可得 Σn=0∞ xnn + 1 = −ln(1 − x)x。再对 Σnxn 的式子求导，还能得到 Σn2xn 一类。把这两条派生式记住，大半题目就是「认出它属于哪一类」。

四、例题

例 1　求 Σn=1∞ n xn 的和函数。

解　第一步，收敛半径：an = n，R = limn→∞ nn + 1 = 1；x = ±1 时通项 nxn 不趋于 0，发散。故收敛域为 (−1, 1)。

第二步，系数是 n，先积分：设 S(x) = Σnxn，则在 (−1,1) 内

∫0x S(t)dt = Σn=1∞ n tn+1n + 1

这样并不能直接求和，说明「先积分」不是机械照搬。更省力的做法是先拆出已知式：由 Σxn = 11 − x 求导得 Σn xn−1 = 1(1 − x)2，两边乘 x：

S(x) = x Σn xn−1 = x(1 − x)2　(|x| < 1)

关键判断：nxn 可以看成 x · (xn)′，因此不必真去积分再还原，「乘 x 凑出导数」更快。做题时先看系数能否拆成 n 与 xn 的组合，别急着套流程。

例 2　利用例 1 求数项级数 Σn=1∞ n2n 的和。

解　这是例 1 的和函数在 x = 12 处的值，而 x = 1/2 落在收敛区间 (−1, 1) 内，可以代入：

Σn=1∞ n2n = S(12) = 1/2(1 − 1/2)2 = 2

这类「先求和函数、再代点」的题是本章最常见的计算题。代点前必须确认该点在收敛域内；若在端点，还得单独讨论收敛性（如用阿贝尔定理说明和函数在端点单侧连续）。

例 3　求 Σn=0∞ (n + 1)xn 的和函数，并求 Σn=0∞ n + 13n。

解　注意 Σn=0∞ (n + 1)xn = (Σn=0∞ xn+1)′ = (x1 − x)′，故

Σn=0∞ (n + 1)xn = 1(1 − x)2　(|x| < 1)

取 x = 13（在收敛区间内），得 Σn=0∞ n + 13n = 1(2/3)2 = 94。

「先求和函数，再代值」比直接凑数项级数快得多。注意 (x1 − x)′ 这一步把 xn+1 的导数 (n+1)xn 恰好还原了系数，这是「凑导数」的典型。

五、近似计算

级数的第二个用途是算数值。思路是把函数展开，取前几项作近似，再用余项估误差。两种常用估计：交错级数用 |rn| ≤ un+1（莱布尼茨型，最简单）；一般幂级数用拉格朗日余项 |Rn(x)| ≤ M|x − x0|n+1(n + 1)!。

例 4　用级数计算 ln 1.2，精确到 10−4。

解　取 x = 0.2，由 ln(1 + x) = x − x22 + x33 − x44 + …，各项依次为

0.2，−0.02，0.002667，−0.0004，0.000064，…

这是交错级数，余项不超过下一项的绝对值。取前 4 项，余项 ≤ 0.000064 < 10−4，满足精度；于是

ln 1.2 ≈ 0.2 − 0.02 + 0.002667 − 0.0004 = 0.1823

要说明「为什么取到这里就够」——必须写出余项估计，只给数值不给误差说明是常见扣分点。x 越接近 0 收敛越快，所以算 ln 1.2 比算 ln 5 合适得多（后者要先变形）。

六、微分方程的幂级数解

对变系数方程，初等解法往往失效，但设 y = Σn=0∞ anxn 代入、比较同次幂系数，一定能得到系数的递推关系。步骤是：设解 → 求导代入 → 同次幂合并 → 比较系数得递推 → 由初始条件定出前几项 → 写出级数（能认出来就写成初等函数）。

例 5　求 y″ + y = 0，y(0) = 1，y′(0) = 0 的幂级数解。

解　设 y = Σn=0∞ anxn，则 y″ = Σn=0∞ (n + 2)(n + 1)an+2xn。代入方程并合并同次幂：

Σn=0∞ [(n + 2)(n + 1)an+2 + an] xn = 0

比较系数得 an+2 = −an(n + 1)(n + 2)。由初值 a0 = 1, a1 = 0，递推得 a2 = −1/2, a3 = 0, a4 = 1/24, a5 = 0，即

y = 1 − x22! + x44! − … = cos x

比较系数时要把所有级数的下标统一成同一个 xn，这是最容易出错的地方；认出结果是 cos x 后要写一句「与已知初等解一致」作验证。

七、常考套路与易错

本节三类题：求和函数（必考）、数项级数求和（由和函数代点）、近似计算或级数解（偶考）。易错点：漏写收敛域；求导与积分方向搞反（含 n 先积分、含 1/n 先求导，但要先看能否直接凑导数，如例 1）；代点时没检查该点是否在收敛域内；近似计算不写误差估计；解微分方程时没把下标对齐导致递推写错。最后提醒一句：和函数的定义域永远由原级数决定，逐项求导或积分后范围可能变大，不能用扩大后的范围。

一、直观引入：为什么用正弦和余弦

幂级数在一点附近逼近函数，是「局部」的工具；但如果研究对象本身是周期现象——琴弦的振动、交流电、热传导中的温度分布——我们希望用来表示它的「积木」也具有同样的周期。最简单的周期函数就是 sin nx 与 cos nx，它们的周期都是 2π/n 的整数倍，叠加起来仍是 2π 周期。傅里叶的断言是：相当广的一类 2π 周期函数，都能写成这种叠加。

与幂级数相比，这里没有「在一点展开」的概念，系数由整个区间上的积分决定。这件事之所以可行，全靠三角函数系的正交性。

二、三角函数系的正交性

函数系 1, cos x, sin x, cos 2x, sin 2x, …, cos nx, sin nx, … 在 [−π, π] 上满足：任意两个不同函数的乘积在该区间上积分为零；而每个函数与自身相乘的积分为

∫−ππ 1 dx = 2π，　∫−ππ cos2nx dx = ∫−ππ sin2nx dx = π

正交性的来源是积化和差公式：cos mx cos nx = [cos(m+n)x + cos(m−n)x]/2，在一个整周期上积分都为零。这套「正交 + 归一」的结构，和线性代数里的正交基完全同构，系数公式就是「投影」。

三、傅里叶系数公式的推导

设 f(x) 以 2π 为周期，且可展开为

f(x) = a02 + Σn=1∞ (ancos nx + bnsin nx)

并且可以逐项积分。两边在 [−π, π] 上积分，所有三角函数项积分为 0，只剩常数项：

∫−ππ f(x)dx = a02 · 2π ⟹ a0 = 1π∫−ππ f(x)dx

两边乘 cos kx 再积分，由正交性只剩 ak 那一项：∫−ππ f cos kx dx = akπ，故

an = 1π∫−ππ f(x)cos nx dx　(n = 1, 2, …)

同理乘 sin kx 积分，得

bn = 1π∫−ππ f(x)sin nx dx　(n = 1, 2, …)

注意常数项写成 a0/2 而不是 a0，这样 a0 的公式与 an 完全统一（形式上也对 n = 0 成立）。a0/2 恰好是 f 在一个周期上的平均值，这是理解它的最好角度。

四、狄利克雷收敛定理

狄利克雷条件　设 f 以 2π 为周期，若它在一个周期内（1）连续，或只有有限个第一类间断点；（2）只有有限个极值点，则 f 的傅里叶级数处处收敛，且和函数为

  • 在连续点 x 处，和等于 f(x)；
  • 在间断点 x 处，和等于 f(x−) + f(x+)2（左右极限的平均值）；
  • 在 x = ±π 处，和等于 f(−π+) + f(π−)2。

所以傅里叶级数不一定收敛到 f 本身，它收敛到 f 的「修正版」：间断点被拉到中点。这也是为什么写展开式时用 ~（或明确写出和函数的取值）而不直接写等号。

五、奇偶性与正弦 / 余弦级数

若 f 是奇函数，则 f cos nx 是奇函数，在对称区间上积分为 0，故所有 an = 0，只剩正弦项，称为正弦级数。若 f 是偶函数，则 f sin nx 是奇函数，所有 bn = 0，只剩余弦项，称为余弦级数。这一条能省掉一半积分，做题必须先看奇偶性。

若 f 只定义在 (0, π) 上，可以自由选择延拓方式：作奇延拓（周期 2π）得正弦级数，bn = 2π∫0π f(x)sin nx dx；作偶延拓得余弦级数，a0 = 2π∫0π f(x)dx，an = 2π∫0π f(x)cos nx dx。系数前变成 2/π，是因为区间长度减半、被积函数为偶函数使积分加倍，两处因子恰好抵消后还剩 2。

六、周期为 2l 的一般情形

作换元 t = πx/l，把 [−l, l] 映成 [−π, π]，所有公式里的 nx 换成 nπx/l，1/π 换成 1/l：

an = 1l∫−ll f(x)cosnπxldx，　bn = 1l∫−ll f(x)sinnπxldx

口诀：1/π 换成 1/l，nx 换成 nπx/l，积分区间换成 [−l, l]。周期为 2l 时 a0 也一样换成 1/l 乘积分。照搬 1/π 是最常见的错。

七、例题

例 1　把 f(x) = x（−π < x < π）展开成傅里叶级数。

解　f 是奇函数，故 an = 0（n = 0, 1, 2, …），只算 bn，且可用 2/π 倍的半区间积分：

bn = 2π∫0π x sin nx dx

分部积分，取 u = x, dv = sin nx dx：∫0π x sin nx dx = [−x cos nxn]0π + 1n∫0π cos nx dx。第二项 = [sin nx/n2]0π = 0，第一项 = −π cos nπn = π(−1)n+1n。故

bn = 2(−1)n+1n，　x = Σn=1∞ 2(−1)n+1n sin nx　(−π < x < π)

令 x = π/2，左边为 π/2，右边 sin(nπ/2) 只在 n 为奇数时取 ±1，化简得 π4 = 1 − 13 + 15 − …

奇函数必先看出 an = 0，否则要白算两个积分。分部积分时 cos nπ = (−1)n 要写出来，不要留成 cos nπ。另外 x = ±π 处级数和为 0，不等于 f 的值，所以展开区间写开区间。

例 2　把 f(x) = x2（−π ≤ x ≤ π）展开成傅里叶级数，并由此求 Σ1/n2。

解　f 是偶函数，故 bn = 0。先算常数项：

a0 = 2π∫0π x2dx = 2π23

再算 an，两次分部积分：∫0π x2cos nx dx = [x2sin nxn + 2x cos nxn2 − 2 sin nxn3]0π = 2π(−1)nn2，故

an = 2π·2π(−1)nn2 = 4(−1)nn2

于是

x2 = π23 + Σn=1∞ 4(−1)nn2 cos nx　(−π ≤ x ≤ π)

令 x = π，得 π2 = π23 + 4Σn=1∞ 1n2，解得

Σn=1∞ 1n2 = π26

这是傅里叶级数最经典的应用：用级数算 π2/6。代点时选使 cos nπ = (−1)n 与 (−1)n 相乘全为正的 x，才能得到同号级数，这需要事先想清楚。

例 3　把 f(x) = π − x（0 < x < π）展开成正弦级数。

解　作奇延拓，则 an = 0，bn = 2π∫0π (π − x)sin nx dx。分别算两个积分：

∫0π π sin nx dx = π(1 − (−1)n)n，　∫0π x sin nx dx = π(−1)n+1n

相减得 ∫0π (π − x)sin nx dx = πn，故 bn = 2n，即

π − x = Σn=1∞ 2n sin nx　(0 < x < π)

奇延拓后 f 在 x = 0 处值为 0，而原函数 π − x 在 0 处为 π，所以展开区间只能写 (0, π)，端点不在等式内。这是延拓类题目必然涉及的细节。

八、常考套路与易错

题型：给 f 求展开式（含奇偶简化、延拓、求系数）、给级数求和（代特殊点得 π2/6 一类）、判断和函数在间断点的值。易错点：常数项写成 a0 而不是 a0/2；周期为 2l 时忘了把 1/π 改成 1/l；间断点、端点不取平均值而直接写 f(x)；正弦、余弦级数前面漏掉 2 倍的因子；延拓后在端点处级数和为 0（正弦）或平均值（余弦），与 f 的端点值可能不等，区间要写开区间。掌握这一节，也就完成了从「离散求和」到「连续展开」的最后一跳。
