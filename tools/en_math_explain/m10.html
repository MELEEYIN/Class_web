先看一个具体问题。设有一块空间形体，它的底是 xOy 面上一个有界闭区域 D，顶是一张曲面 z = f(x, y)（设 f ≥ 0 且连续），侧面是以 D 的边界曲线为准线、母线平行于 z 轴的柱面。这样的形体叫曲顶柱体。若顶是平的，体积就是"底面积 × 高"；可顶是弯的，每处的高都不一样，初等几何的公式全部失效。二重积分正是为算这个体积而发明的。

思路还是"以直代曲"：把底面 D 切成 n 小块，小块足够小时曲面几乎平了，就用一根平顶小柱体去顶替它；把所有小平顶柱体的体积加起来，再让分割无限变细取极限。这就是定积分"分割、近似、求和、取极限"四步法在二维上的翻版。

一、定义：四步法

把 D 任意分成 n 个小区域 Δσ1, …, Δσn（Δσi 既表示第 i 块，也表示它的面积）。在第 i 块上任取一点 (ξi, ηi)，作乘积 f(ξi, ηi)Δσi，求和

Σi=1n f(ξi, ηi)Δσi

记 λ 为各小块直径（块内任意两点距离的最大值）中的最大者。若当 limλ→0 时该和式的极限存在，且与 D 的分法、与点 (ξi, ηi) 的取法都无关，就称此极限为 f(x, y) 在 D 上的二重积分，记作 ∬D f(x, y) dσ，也写作 ∬D f(x, y) dxdy。

两点必须说清：可积的充分条件是 f 在有界闭区域 D 上连续；几何意义是当 f ≥ 0 时，积分值等于以 D 为底、以 z = f(x, y) 为顶的曲顶柱体体积；当 f 变号时，它是上下两块体积的代数和。特别地取 f ≡ 1 得 ∬D dσ = S，即 D 的面积。

二、性质：五条要背熟

  • 线性：∬D [αf + βg] dσ = α∬D f dσ + β∬D g dσ。
  • 区域可加：用一条曲线把 D 分成 D1, D2，则积分等于两块之和。求积分时按"分段描述"拆区域，依据就是它。
  • 保号：f ≤ g ⟹ ∬D f dσ ≤ ∬D g dσ；由此得 |∬D f dσ| ≤ ∬D |f| dσ。
  • 估值：设 m ≤ f ≤ M（m, M 是 f 在 D 上的最小、最大值），S 为 D 的面积，则 mS ≤ ∬D f dσ ≤ MS。
  • 中值定理：f 连续时，存在 (ξ, η) ∈ D，使 ∬D f dσ = f(ξ, η) · S。它由连续函数的介值性立得：(1/S)∬D f dσ 夹在 m 与 M 之间。

三、对称性：把一半的积分直接判零

设 D 关于 x 轴对称，且 f(x, −y) = −f(x, y)（关于 y 为奇），则 ∬D f dσ = 0。理由：上下两半的积分值互为相反数，相加为零。若 f 关于 y 是偶函数，则积分等于上半部分的两倍。关于 y 轴对称时把 x、y 互换同理。两个条件必须同时成立，缺一不可。

例 1　利用几何意义求 ∬D √(R² − x² − y²) dσ，其中 D: x² + y² ≤ R²。

解　被积函数 z = √(R² − x² − y²) 正是上半球面，区域 D 是它的底圆。故积分等于上半球体的体积：V = 12 · 43πR³ = 23πR³，不必硬积。

看到"被积函数就是某张常见曲面的方程"时，先想几何意义，比硬算快得多。

例 2　设 D: x² + y² ≤ 1，比较 I1 = ∬D (x² + y²) dσ 与 I2 = ∬D √(x² + y²) dσ 的大小。

解　在 D 上记 u = x² + y²，则 0 ≤ u ≤ 1。当 0 ≤ u ≤ 1 时恒有 u ≤ √u，即 x² + y² ≤ √(x² + y²)，等号仅在 u = 0 或 u = 1 处成立（零面积集）。由保号性逐点比较后积分，得 I1 < I2。

比较大小的套路：先逐点判号，再用保号性；不要没判号就直接写"小于"。

例 3　计算 ∬D (x³ + y²) dσ，D: x² + y² ≤ 1。

解　拆成两项。D 关于 y 轴对称而 x³ 关于 x 为奇，故 ∬D x³ dσ = 0。
第二项：D 还关于直线 y = x 对称，把 x 与 y 互换后积分值不变，故 ∬D y² dσ = ∬D x² dσ = 12∬D(x² + y²) dσ。
极坐标算这个公共值：∫02π dθ ∫01 r² · r dr = 2π · 14 = π2，故原式 = π4。

圆域上算 x²、y² 的积分，统一化成 (x² + y²)/2 再上极坐标，比分别积分省一半功夫。

本节只是"定性"的一节：定义划定了对象，性质提供了不靠计算就能判断的工具。下一节才把定义兑现成可操作的算法——把二重积分化成两次定积分，也就是"累次积分"。路径只有一条：先选坐标系（直角或极），再把区域写成不等式，最后按次序积两遍。

定义只能算体积，不能算出具体的数。∬D f dσ 是一个"二维的极限"，怎么落地？答案是降维：固定一个变量、先对另一个变量积一次，再把所有"竖条"的贡献累加。两次一元定积分，就得到二重积分的值。这条定理叫富比尼（Fubini）定理，即化二重积分为累次积分。

一、直角坐标：X 型与 Y 型

X 型区域：D = {(x, y) | a ≤ x ≤ b, φ1(x) ≤ y ≤ φ2(x)}，即用垂直于 x 轴的直线去穿，穿入点、穿出点各在一张曲线上，且只有两个交点。此时若 f 连续、φ1, φ2 连续，则

∬D f(x, y) dσ = ∫ab dx ∫φ1(x)φ2(x) f(x, y) dy

右端是先对 y 积、后对 x 积：里层把 x 当常数，积完只剩 x 的函数，外层再对 x 积。上下限次序不能颠倒，因为里层上下限依赖外层变量。

Y 型区域：D = {(x, y) | c ≤ y ≤ d, ψ1(y) ≤ x ≤ ψ2(y)}，则

∬D f(x, y) dσ = ∫cd dy ∫ψ1(y)ψ2(y) f(x, y) dx

既非 X 型也非 Y 型的区域，切几块分别套公式，再用区域可加性相加。判断标准：画图，看平行于坐标轴的直线与边界是否始终只有两个交点。

二、极坐标：那个 r 从哪来

令 x = r cos θ, y = r sin θ，则 x² + y² = r²，而面积元要换。用 r = 常数（同心圆）与 θ = 常数（射线）把区域打成小格，一个小格的两条边长分别是 dr 与 r dθ，故

dσ = r dr dθ, 即 ∬D f(x, y) dxdy = ∬D′ f(r cos θ, r sin θ) · r dr dθ

严格说这个 r 是变换的雅可比行列式的绝对值：J = ∂(x, y)/∂(r, θ) = r，一般公式是 dxdy = |J| dr dθ。漏掉 r 是本章第一失分点，一定要在写下 dr dθ 的同一秒把 r 写上。

定限两步走：先定 θ——看区域在极点周围张开多大角；再定 r——固定 θ 引一条射线，穿入点到穿出点就是 r 的上下限。圆域、扇形、圆环、含 x² + y² 的题优先极坐标。

例 1　计算 ∬D xy dσ，D 由 y = x 与 y = x² 围成。

解　先求交点：x = x² 得 x = 0, 1，故 D: 0 ≤ x ≤ 1, x² ≤ y ≤ x，是 X 型。
里层：∫x²x y dy = 12(x² − x⁴)（把 x 当常数，对 y 积）。
外层：原式 = ∫01 x · 12(x² − x⁴) dx = 12∫01(x³ − x⁵) dx = 12(14 − 16) = 124。

里层积完必须"消掉 y"；若还剩 y，多半是上下限写错了。

例 2　计算 I = ∫01 dx ∫x1 e−y² dy。

解　e−y² 没有初等原函数，硬积这条路走不通，必须交换次序。
第一步，还原区域：原式给的是 X 型描述 0 ≤ x ≤ 1, x ≤ y ≤ 1，即由 y = x、y = 1、x = 0 围成的三角形。
第二步，换成 Y 型描述：y 从 0 走到 1；固定 y 时 x 从 0（y 轴）走到 y（直线 x = y），即 0 ≤ y ≤ 1, 0 ≤ x ≤ y。
第三步，重写：I = ∫01 dy ∫0y e−y² dx = ∫01 y e−y² dy = −12e−y²|01 = 12(1 − e−1)。

交换次序的标准三步：还原不等式 → 重画区域 → 换方向重写。绝不能只把两个积分号上下限对调。

例 3　计算 ∬D (x² + y²) dσ，D: x² + y² ≤ 2x。

解　配方：(x − 1)² + y² ≤ 1，是以 (1, 0) 为心、半径 1 的圆，且过极点。
极坐标下 x² + y² = r²，边界的圆变成 r² ≤ 2r cos θ，即 r ≤ 2 cos θ（r ≠ 0 时）。
定限：区域在右半平面且关于 x 轴对称，θ 从 −π2 到 π2；对固定 θ，射线从极点穿入（r = 0）到圆周穿出（r = 2cos θ）。
故 ∬D(x² + y²) dσ = ∫−π/2π/2 dθ ∫02cos θ r² · r dr = ∫−π/2π/2 (2cos θ)⁴4 dθ = 4∫−π/2π/2 cos⁴θ dθ。
用偶函数对称性：= 8∫0π/2 cos⁴θ dθ = 8 · 34 · 12 · π2 = 3π2。

过极点的圆，极坐标方程必为 r = 2a cos θ 或 r = 2a sin θ 的形状；用 cos 型时 θ 的范围跨原点两侧，别只写 0 到 π。

到这里二重积分已经"能算"了，剩下的是熟练度：选坐标系与写上下限（画图 + 穿线法）。下一节把同一套思想升到三维：多一个变量，就多一层积分，也多两套常用坐标（柱、球）。

二重积分累积在"面"上，三重积分累积在"体"上。最直接的物理原型是质量：一块占有空间区域 Ω 的物体，体密度 ρ(x, y, z) 随点变化，总质量怎么求？把 Ω 切成 n 个小块，小块充分小时密度近似为常数，质量约等于 ρ · ΔV；加起来再取极限，就得到三重积分。

一、定义

把 Ω 任意分成 n 个小区域 ΔV1, …, ΔVn（同时表示体积），在第 i 块任取 (ξi, ηi, ζi)，作和 Σi=1n f(ξi, ηi, ζi)ΔVi，令 λ 为各小块直径的最大者。若 limλ→0 存在且与分法、取点无关，则称之为 f 在 Ω 上的三重积分：

∭Ω f(x, y, z) dV = ∭Ω f(x, y, z) dxdydz

f 在闭区域上连续即可积。取 f ≡ 1 得 ∭Ω dV = V，即体积。

二、直角坐标：两条路线

投影法（先 z 后 xy）：把 Ω 投影到 xOy 面得 D，过 D 内每点作平行于 z 轴的直线，穿入点在下曲面 z1(x, y)、穿出点在上曲面 z2(x, y)，则

∭Ω f dV = ∬D dσ ∫z1(x, y)z2(x, y) f(x, y, z) dz

适用条件：投影区域内每点的竖线与边界恰交两点。此时"先对 z 积"最省事，上下限就是两张曲面。

截面法（先 xy 后 z）：固定 z，用水平面去截 Ω，得截面 Dz；让 z 从 c 扫到 d，则

∭Ω f dV = ∫cd dz ∬Dz f(x, y, z) dσ

若 f 只依赖 z，或截面 Dz 的面积 S(z) 好求（旋转体最典型），截面法一步到位：∭ f(z) dV = ∫cd f(z)S(z) dz。

三、柱坐标与球坐标

柱坐标：在 xOy 面上用极坐标、z 不变，x = r cos θ, y = r sin θ, z = z，体积元

dV = r dr dθ dz

竖向拉伸不改变"水平面积元 r dr dθ"，所以仍带 r。适用于圆柱、圆锥、旋转抛物面围成的区域。

球坐标：x = ρ sin φ cos θ, y = ρ sin φ sin θ, z = ρ cos φ，其中 ρ 是到原点的距离，φ 是与 z 轴正方向的夹角（0 ≤ φ ≤ π），θ 是与 x 轴正向的夹角（0 ≤ θ ≤ 2π）。体积元

dV = ρ² sin φ dρ dφ dθ

记忆法：取 ρ 到 ρ + dρ 的球壳、φ 到 φ + dφ 的锥面、θ 到 θ + dθ 的半平面，交出一个小"曲边长方体"，三边长为 dρ、ρ dφ、ρ sin φ dθ，相乘即得。φ 是从 z 轴量起，不是从 xOy 面量起，写错整题崩。

例 1　计算 ∭Ω z dV，Ω 由旋转抛物面 z = x² + y² 与平面 z = 1 围成。

解　投影法。投影区域是交线所在的圆：x² + y² ≤ 1；竖线自 z = x² + y² 穿入、自 z = 1 穿出，故 Ω: x² + y² ≤ 1, x² + y² ≤ z ≤ 1。
用柱坐标：∭ z dV = ∫02π dθ ∫01 r dr ∫r²1 z dz。
里层：∫r²1 z dz = 12(1 − r⁴)。
中层：12∫01(r − r⁵) dr = 12(12 − 16) = 16。外层乘 2π 得 π3。

被积函数含 x² + y²、区域是旋转体 ⟹ 柱坐标；dV 里的 r 漏了，答案正好差一半。

例 2　计算 ∭Ω (x² + y² + z²) dV，Ω: x² + y² + z² ≤ 1。

解　球体 + 被积函数是 ρ² 型，用球坐标。区域：0 ≤ ρ ≤ 1, 0 ≤ φ ≤ π, 0 ≤ θ ≤ 2π；被积函数 x² + y² + z² = ρ²。
原式 = ∫02π dθ ∫0π sin φ dφ ∫01 ρ² · ρ² dρ。
三个一元积分相乘：2π · [−cos φ]0π · 15 = 2π · 2 · 15 = 4π5。

球坐标下若三个变量的限互相独立、被积函数可分离，就拆成三个一元定积分相乘。

例 3　用截面法求 ∭Ω z dV，Ω 为上半球体 x² + y² + z² ≤ R², z ≥ 0。

解　固定 z ∈ [0, R]，水平截面是圆盘 x² + y² ≤ R² − z²，面积 S(z) = π(R² − z²)。
被积函数只含 z，故
∭Ω z dV = ∫0R z · π(R² − z²) dz = π(R²z²2 − z⁴4)|0R = πR⁴4。

若用投影法，投影是圆盘 x² + y² ≤ R²、竖线自 z = 0 穿到 z = √(R² − x² − y²)，里层积完会出现根式，明显更难。

联系与套路：整套内容的骨架是"坐标变换 = 换元 + 乘雅可比"。二重积分的 r、柱坐标的 r、球坐标的 ρ² sin φ 是同一件事在不同维数下的表现。下一节的应用公式都是"密度 × 微元"再积分，难点不在公式，而在把微元写对。

重积分本身不是目的，它是把"按面积或体积分布的量"加总起来的工具。这一节列的五样东西——体积、质量、质心、转动惯量、曲面面积——都遵循同一个模板：

总量 = ∬D（面密度）dσ 或 ∭Ω（体密度）dV

所以真正要练的不是背公式，而是"给一个物理量，写出它的微元"。下面逐个说清每个量的微元是怎么来的。

一、五个量的公式与来源

  • 体积：曲顶柱体，V = ∬D [z上(x, y) − z下(x, y)] dσ。微元是"底面积 dσ × 高差"，高差就是同一竖线上两曲面的差。用三重积分时更省事：V = ∭Ω dV。
  • 质量：m = ∬D ρ(x, y) dσ（薄片，ρ 为面密度）或 m = ∭Ω ρ(x, y, z) dV（立体，ρ 为体密度）。微元就是"密度 × 微元体积"。
  • 质心：由力矩平衡，x̄ = 1m∭Ω xρ dV，ȳ = 1m∭Ω yρ dV，z̄ = 1m∭Ω zρ dV。均匀物体（ρ 为常数）时 ρ 可约掉，只剩"体积重心"。先看对称性：均匀物体若有对称面，质心必在该面上，对应坐标直接为零。
  • 转动惯量：绕 z 轴为 Iz = ∬D(x² + y²)ρ dσ（薄片）或 Iz = ∭Ω(x² + y²)ρ dV（立体）。关键是"点到轴的距离平方"：到 z 轴的距离是 √(x² + y²)；到 x 轴的是 √(y² + z²)；到 y 轴的是 √(x² + z²)。别把"绕 z 轴"写成 x² + z²。
  • 曲面面积：曲面 z = z(x, y) 在 D 上的部分，A = ∬D √(1 + zx² + zy²) dσ。

曲面面积公式值得推一遍：在 (x, y) 处取切平面，其法向量为 (−zx, −zy, 1)，单位法向量的第三分量为 cos γ = 1/√(1 + zx² + zy²)，其中 γ 是法向量与 z 轴的夹角。曲面微元 dA 投影到 xOy 面得 dσ = dA · cos γ，所以 dA = dσ / cos γ = √(1 + zx² + zy²) dσ。这就是"斜的面积等于投影除以夹角余弦"，完全类比平面几何里 S投 = S cos γ。

例 1　求旋转抛物面 z = x² + y² 在圆盘 D: x² + y² ≤ 1 上那部分的面积。

解　zx = 2x，zy = 2y，故 √(1 + zx² + zy²) = √(1 + 4x² + 4y²) = √(1 + 4r²)。
换成极坐标（面积元记得带 r）：
A = ∫02π dθ ∫01 √(1 + 4r²) · r dr = 2π · 18 · 23(1 + 4r²)3/2|01 = π6(5√5 − 1)。

若曲面方程给成 x = x(y, z) 或 y = y(x, z)，把公式里的变量轮换即可（如 √(1 + xy² + xz²)），投影面也要相应改。

例 2　求均匀上半球体 x² + y² + z² ≤ R², z ≥ 0 的质心。

解　由关于 yOz 面、zOx 面的对称性，质心在 z 轴上，故 x̄ = ȳ = 0，只需算 z̄。
体积 V = 23πR³。分子用例 3（上一节）的截面法结果：∭Ω z dV = πR⁴4。
于是 z̄ = πR⁴/42πR³/3 = 3R8。

质心题先做对称性判断，能把三元降成一元；剩下的就是"分子一个三重积分 + 分母一个体积"，两者都算对即可。

例 3　求均匀圆盘 x² + y² ≤ R²（面密度为常数 ρ）绕 z 轴的转动惯量，以及与质量、半径的关系。

解　绕 z 轴的距离平方是 x² + y² = r²，故
Iz = ∬D(x² + y²)ρ dσ = ρ∫02π dθ ∫0R r² · r dr = ρ · 2π · R⁴4 = 12ρπR⁴。
又质量 m = ρπR²，所以 Iz = 12mR²，正是力学里熟知的圆盘公式，可作验算。

算完转动惯量不妨用"I = mk²"的常见结论核对量纲与系数，k 是回转半径，量纲必为"质量 × 长度²"。

总结与提醒：这一章的题，八成的时间花在"把区域写成正确的不等式"和"把微元写对"上，真正的积分运算反而机械。四条底线请记牢：极坐标的 r、球坐标的 ρ² sin φ 一个都不能漏；交换次序必重画区域；对称性要求区域与函数同时满足；转动惯量看的是"到轴的距离平方"。与后续内容的联系：本章的化重积分为累次积分，是下一章曲线积分、曲面积分里"参数化 + 定积分"的直接前身；而格林公式、高斯公式则把这里的"区域上的积分"与"边界上的积分"联系起来，届时回看本章的"区域描述"，会有更清楚的整体图景。
