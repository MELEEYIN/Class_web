一、这节解决什么问题

中学里我们会算矩形、三角形、圆的面积，也会算柱体、锥体的体积。可只要边界变成曲线，比如抛物线 y = x2 与 y = 2 − x2 围出的那块地，初等公式就全部失效了。定积分给出的正是这类「曲边图形」的统一度量办法，四个字：分割、近似、求和、取极限。本节所有公式都从同一个想法长出来：把要求的量切成无数小片，让每一小片细到几乎就是规则图形，写出它的微元，再积分累加。

为什么可以这样？因为小片足够细时，曲边在小范围内几乎是直的，用直边代替曲边产生的误差是比 dx 更高阶的无穷小，积分取极限后被「抹平」。这句话是元素法能成立的根本理由，也是判断「微元写对没有」的标准。

二、元素法的精确表述

设所求量 Q 与区间 [a, b] 有关。若它满足下面两条，就可以写成定积分：

  • 可加性：区间分成两段时，量也相加，即 Q[a, b] = Q[a, c] + Q[c, b]。面积、体积、功、压力都满足。
  • 微元性：在任一小区间 [x, x + dx] 上，部分量能写成 ΔQ = f(x)dx + o(dx)，其中 f 在 [a, b] 上连续。

则 Q = ∫ab f(x)dx。注意条件里的「o(dx)」不能省：如果误差和 dx 同阶，累加之后不会消失，公式就是错的。

三、本节六条公式及其条件

  • 直角坐标面积：设 f, g 在 [a, b] 上连续，则两曲线与 x = a、x = b 围成的面积 A = ∫ab |f(x) − g(x)|dx。上下限取交点，谁在上面不影响结果，绝对值会自动处理。
  • 极坐标面积：曲线 r = r(θ) 在 [α, β] 上与两条射线围成的扇形面积 A = 12∫αβ r2(θ)dθ。理由是扇形微元 dA = 12r2dθ：把 dθ 那一小条看成半径 r、圆心角 dθ 的扇形。
  • 旋转体体积：曲边梯形绕 x 轴旋转，V = π∫ab y2dx（圆盘法，微元是厚 dx、半径 y 的薄圆盘）；若区域夹在 y = Y(x) 与 y = y(x) 之间，则 V = π∫ab (Y2 − y2)dx（垫圈法）。
  • 柱壳法：曲边梯形（0 ≤ a ≤ x ≤ b，y = f(x) ≥ 0）绕 y 轴旋转，V = 2π∫ab x f(x)dx。微元是半径 x、高 f(x)、厚 dx 的薄壁圆筒，展开后是长 2πx、宽 dx、高 f(x) 的长方体。
  • 弧长：s = ∫ab √(1 + y′2)dx；参数方程 x = x(t), y = y(t) 时为 s = ∫αβ √(x′2 + y′2)dt；极坐标 r = r(θ) 时为 s = ∫αβ √(r2 + r′2)dθ。三者其实是同一个弧微分 ds = √(dx2 + dy2) 的三种写法。
  • 旋转曲面面积：S = 2π∫ab |y|√(1 + y′2)dx = 2π∫ab |y|ds。被积函数是「周长 2π|y| 乘弧长微元 ds」。
  • 平均值：f 在 [a, b] 上的平均值 f̄ = 1b − a∫ab f(x)dx。它来自积分中值定理：连续函数必能取到平均值。

四、两个容易被问倒的推导

1. 弧微分为什么是 √(dx2 + dy2)。在曲线上一小段两端 M(x, y)、M′(x + dx, y + dy)，弦长 √(dx2 + dy2)。当 dx → 0 时，弦长与弧长之比趋于 1，两者之差是 dx 的高阶无穷小，所以用弦长做微元合法。再提出 dx，得 ds = √(1 + y′2)dx。

2. 旋转曲面面积为什么用 ds 而不是 dx。这是本节最典型的错。把一小段曲线绕 x 轴旋转，得到的是一个圆台，其侧面积是 π(y1 + y2)·l，其中 l 是母线长，也就是弧长微元 ds，不是水平宽度 dx。所以 dS = 2πy·ds。若误写成 2πy·dx，算出来的是「投影面积」而非曲面面积，斜线越陡错得越多。

五、例题

例 1　求 y = x2 与 y = 2 − x2 所围图形的面积。

解　第一步，求交点：令 x2 = 2 − x2，得 x2 = 1，即 x = ±1，交点为 (−1, 1) 与 (1, 1)。

第二步，判断上下位置。在 (−1, 1) 内取 x = 0：x2 = 0，2 − x2 = 2，故抛物线 y = 2 − x2 在上，y = x2 在下，被积函数取 (2 − x2) − x2 = 2 − 2x2。

第三步，积分：A = ∫−11 (2 − 2x2)dx = [2x − 23x3]−11。代入上限得 2 − 23 = 43，代入下限得 −2 + 23 = −43，相减得 A = 83。

提醒　区域关于 y 轴对称，可写成 2∫01(2 − 2x2)dx 验证，结果一致。若两曲线在区间内部再次相交，必须按交点分段，因为上下位置会在交点处交换。

极坐标的变式：心形线 r = a(1 + cos θ)（a > 0）所围面积，取 θ ∈ [0, 2π]，A = 12∫02π a2(1 + cos θ)2dθ = a22∫02π(1 + 2cos θ + cos2θ)dθ。用 ∫02πcos θ dθ = 0、∫02πcos2θ dθ = π，得 A = a22(2π + π) = 3πa22。极坐标题的关键是先把 r 的取值区间定对，再套 12。

例 2　设平面图形由 y = x2、y = 0、x = 1 围成，求它绕 y 轴旋转所得旋转体的体积。

解　用柱壳法。竖着切：在 x 处取厚 dx 的竖条，绕 y 轴转出的薄壁圆筒半径是 x，高是 x2，于是 dV = 2πx·x2dx，x 从 0 到 1。

V = 2π∫01 x3dx = 2π·14 = π2。

验算（垫圈法，改对 y 积分）：图形在 y ∈ [0, 1] 上左边界 x = √y、右边界 x = 1，绕 y 轴的外半径 R = 1、内半径 r = √y，故 V = π∫01 (1 − y)dy = π(1 − 12) = π2。两法一致。

提醒　柱壳法的半径必须是「到旋转轴的距离」。绕 y 轴是 x；若绕 x = a 转，半径写成 |x − a|，并且要注意 x < a 时圆筒在轴左侧，别把半径写成 a − x 后再丢负号。

例 3　求摆线 x = a(t − sin t)、y = a(1 − cos t)（a > 0）一拱 t ∈ [0, 2π] 的弧长。

解　先求导：x′ = a(1 − cos t)，y′ = a sin t。

再算 x′2 + y′2 = a2[(1 − cos t)2 + sin2t] = a2(1 − 2cos t + cos2t + sin2t) = 2a2(1 − cos t)。

用半角公式 1 − cos t = 2sin2t2，得 √(x′2 + y′2) = 2a|sint2|。在 [0, 2π] 上 sint2 ≥ 0，绝对值可直接去掉。

于是 s = ∫02π 2a sint2 dt = 2a[−2cost2]02π = 2a(2 + 2) = 8a。

提醒　摆线一拱的水平长度是 2πa，弧长 8a 比它大，量级合理。开方后出现 |sin(t/2)| 时，要看积分区间决定能否去绝对值；若区间跨过使根号内为零的点，必须分段。

六、常考套路与易错提醒

  • 先画图、先求交点。上下限来自交点，而不是题目给的数字。图形大致画出来，上下位置一目了然，能避免大量返工。
  • 选对积分变量。同一题对 x 积分要分段、对 y 积分一次成功，就该换变量；体积题在圆盘法与柱壳法之间挑「少分段」的那个。
  • 极坐标面积别漏 12，也别把 r 的区间写反；对称图形可只算一半再乘 2，但乘之前要确认对称性真的成立。
  • 旋转面面积用 ds，体积用 dx。这两者混用是本节最高频的错误。
  • 本节是元素法的「几何训练场」，下一节把它原封不动搬到物理量上：功、压力、引力、质心、转动惯量，微元的写法完全同构。掌握了「切—近似—积」，两节就一起通了。

一、这节解决什么问题

物理里很多量不是「力乘距离」这么简单：弹簧拉伸过程中力一直在变；把一池水抽到池口，不同深度的水要提升的高度不一样；闸门上不同深度的压强也不同。这些量的共同点是被积的因子随位置连续变化，初等公式只能处理「常力、常压强」，处理不了它们。定积分的元素法正好补上这一块：把物体切成薄片，在薄片内把变化的量当常数，写出微元，再积分。

本节的全部工作就是练一件事：为每个物理量写出正确的微元，并定对上下限。公式本身很好记，难的是坐标系怎么取、微元里的「距离」到底是谁。

二、五类问题的微元与公式

  • 变力做功：力 F(x) 沿 x 轴作用，物体从 a 移到 b，则 W = ∫ab F(x)dx。微元 dW = F(x)dx 就是「位移 dx 上力几乎不变」。特例：弹簧服从胡克定律 F = kx（x 为伸长量），从自然长度拉到 λ 做功 W = ∫0λ kx dx = 12kλ2。
  • 抽水做功：设容器中水的自由面为深度 0、x 轴竖直向下，容器在深度 x 处的水平截面积为 A(x)，要把水抽到高度 H（H ≤ 0 时即抽到池口之上），则 W = ∫ab ρg A(x)(H − x)dx，其中 ρg A(x)dx 是薄层水的重量，(H − x) 是它要提升的竖直距离。若抽到池口（H = 0），因子就是 −x，即深度本身。
  • 水压力：竖直放置的薄板，取 y 轴竖直向下、水面为原点，深度 h 处板宽 L(h)，则 P = ∫ab ρg h L(h)dh。依据是帕斯卡定律：深度 h 处压强 p = ρgh，微元面积 dA = L(h)dh，故 dP = p·dA。
  • 引力：质量 m 的质点与线密度 λ 的细杆（沿 x 轴，x ∈ [a, b]），质点在 (0, 0)，则 F = ∫ab k m λx2dx。微元是「把 dx 段看成质点」，dm = λdx，距离为 x。若质点在杆的中垂线上，还要把 dF 分解，垂直于杆的分量互相抵消，只剩沿杆方向的分量再积分。
  • 质心与形心：平面薄片（面密度 ρ 为常数）的质心 x̄ = ∫x dA∫dA、ȳ = ∫y dA∫dA，其中 ∫dA 就是面积。常数面密度约掉了，所以均匀薄片的质心与形心重合。有对称轴时，质心必在对称轴上，只需算一个坐标。
  • 转动惯量：I = ∫ r2dm，r 是质量元到转轴的垂直距离。先写清转轴，再写 dm（细杆 dm = λdx，薄片 dm = ρ·dA），最后把 r 用积分变量表示。

三、坐标系怎么取：三条经验

物理应用题的失分，八成不是算错，而是坐标系取坏了。三条经验：① 让「变化的量」成为积分变量，比如抽水取深度、水压力取深度；② 让边界变成简单的数，水面取 0、池底取 H；③ 让被积函数尽量简单，水压力把 y 轴放在水面，压强就直接是 ρgy，不用写 ρg(h0 + y)。

上下限的确定方法：画出容器或薄板的剖面图，标出「要算的那一层」在最上和最下时的位置，就是积分限。抽水题是水面的深度到池底的深度；水压力题是板顶到板底的深度。

四、例题

例 1　圆柱形水池底面半径 R = 2 m、深 H = 5 m，池内盛满水。把水全部抽到池口，需做功多少？（取 ρ = 1000 kg/m3，g = 9.8 m/s2）

解　取水面为深度原点、x 轴竖直向下。在深度 x 处取厚 dx 的水平薄层，它是半径 R、高 dx 的圆盘，体积 πR2dx，重量 ρgπR2dx。该层到池口的高度差是 x，故微元 dW = ρgπR2x dx。

水深从 0 到 H，故 W = ρgπR2∫0H x dx = ρgπR2·H22。

代入数据：W = 1000 × 9.8 × π × 4 × 252 = 4.9 × 105π ≈ 1.54 × 106 J。

提醒　常见错误是把提升高度写成 H（当成整池水都在池底）或写成 H − x（那是抽到池底下方，方向反了）。判断办法：池口附近的水几乎不用提升，所以因子在 x = 0 处应为 0，x 最合适。

例 2　一半圆形闸门半径 R，直径与水面齐平，垂直放置。求闸门一侧所受的水压力。

解　取水面为原点、y 轴竖直向下，则闸门占据 y ∈ [0, R]，在深度 y 处的水面宽度为 L(y) = 2√(R2 − y2)（这是圆 x2 + y2 = R2 在该高度处的弦长）。

压强 p = ρgy，微元面积 L(y)dy，故 dP = ρg y·2√(R2 − y2)dy。

积分：P = 2ρg∫0R y√(R2 − y2)dy。令 u = R2 − y2，du = −2y dy，则 ∫ y√(R2 − y2)dy = −12∫ u1/2du = −13(R2 − y2)3/2。

代入上下限：[−13(R2 − y2)3/2]0R = 0 − (−13R3) = R33，故 P = 23ρgR3。

提醒　若闸门不是从水面开始，而是圆心在水深 h0 处，则压强因子要写成 ρg(h0 + y)，积分变成两项；这时用「压力等于形心处压强乘面积」的结论 P = ρg·hC·A 更快，可用来验算。

例 3　求半径 R 的均匀半圆形薄片（直径在 x 轴上，位于上半平面）的形心纵坐标 ȳ。

解　区域关于 y 轴对称，故 x̄ = 0，只算 ȳ。面积 A = πR22。

分子 ∫ y dA：把薄片横着切成宽 2√(R2 − y2)、高 dy 的横条，则 ∫ y dA = ∫0R y·2√(R2 − y2)dy = 2R33（这个积分与例 2 完全相同）。

故 ȳ = 2R3/3πR2/2 = 4R3π。因 4/(3π) ≈ 0.42，形心在半圆「偏低」处（靠近直径），符合直觉。

提醒　只有均匀薄片才能用面积代替质量；若面密度 ρ(y) 随位置变化，分子分母都要带上 ρ，不能约掉。另外转动惯量 I = ∫r2dm 里的 r 是到转轴的距离，不是到原点的距离，写微元前先把轴定下来。

五、与后文的联系 · 常考套路

  • 本节是元素法的第二次演练。几何节练「切面积、切体积」，物理节练「切质量、切薄层」，方法完全同构：选变量 → 取微元 → 写近似 → 定上下限 → 积分。后面的微分方程、多元积分里的物理应用，仍是这套动作。
  • 四步答题模板：建系并写明变量含义 → 画出微元并写出 dW、dP、dF 或 dm → 写出积分式与上下限 → 计算并带单位。评分时「微元写对」通常占大头，算错只是小扣分。
  • 抽水与闸门是最高频的两类，几乎年年出现。抽水题抓「薄层重量 × 提升距离」，闸门题抓「压强 × 条带面积」，两句话就能起手。
  • 易错三连：① 深度方向取反（水面在上、x 向下时，提升距离是 x 而不是 H − x）；② 忘了 ρg 或漏乘 g；③ 把「宽度函数」写成常数（圆形、三角形闸门的宽度随深度变，必须写成 L(h)）。
  • 善用结论验算：水压力 P = ρg·hC·A（hC 为形心深度），质心 ȳ = ∫y dAA，两者互为工具；半圆 ȳ = 4R/(3π)、半圆闸门 P = 2ρgR3/3 建议直接记住，选择填空题能省一半时间。
