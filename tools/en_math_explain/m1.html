一、先把「函数」这两个字钉死

中学里说「y 随 x 变化」，这句话在微积分里不够用，因为它没交代「怎么变」。教材把它钉成一个对应关系：设 D 是一个非空数集，若对 D 中每一个 x，按某个法则 f 都有唯一确定的 y 与之对应，则称 f 是定义在 D 上的函数，记作 y = f(x)，x ∈ D。D 叫定义域，全体函数值构成的集合叫值域。

把它想成一台自动售货机：投进去的 x 是硬币，吐出来的 y 是饮料。合格的机器要满足两条——每投必出（定义域里每个 x 都有对应）、只出一瓶（唯一性）。机器内部怎么运作，就是「对应法则」。所以判断两个函数是不是同一个，只看两件事：定义域、对应法则；字母写成 t 还是 x、叫 f 还是 g，都不算数。

二、定义域：五道关卡，按顺序卡完取交集

求定义域是本章唯一「纯机械」的活儿，但也是丢分最多的地方。把五个条件背成一条流水线：

  • 分母不为零：1/g(x) 要求 g(x) ≠ 0；
  • 偶次根号内非负：√(g(x)) 要求 g(x) ≥ 0；
  • 对数真数为正：ln g(x) 要求 g(x) > 0；
  • arcsin、arccos 的括号内落在 [−1, 1]：−1 ≤ g(x) ≤ 1；
  • tan 的角不等于 π/2 + kπ，cot 的角不等于 kπ。

每条只贡献一个不等式，最后全部取交集。有一个动作千万不能做：先化简再卡条件。例如 y = (x² − 1)/(x − 1)，先约成 x + 1 再求定义域，就得到「全体实数」，错了。原式分母要求 x ≠ 1，正确的定义域是 x ≠ 1。约分改变定义域，这在后面判断间断点时还会再咬你一次。

三、「两个函数相同」的判据，以及 ln x² 与 2ln x

两个函数相同，必须定义域相同并且对应法则相同，缺一不可。教材的经典反例是 y = ln x² 与 y = 2 ln x：前者定义域是 x ≠ 0，后者是 x > 0；在 x < 0 时前者有值、后者没定义，所以是两个不同的函数。同理 y = x 与 y = √(x²) 也不同（后者等于 |x|，法则不同）。

四、复合与分解：由外向内剥洋葱

由几个函数套起来得到的 y = f[g(x)] 叫复合函数，u = g(x) 是内层，y = f(u) 是外层。复合不是随便套的，必须内层的值域落在外层的定义域内，否则式子在某处就没意义。分解的动作是「由外向内」：拿到 y = ln sin(2x + 1)，最外层是 ln u，往内是 u = sin v，再往内是 v = 2x + 1。后面讲复合函数求导、求积分，靠的就是这个剥法。

五、反函数：解出来、换字母、看对称

若 y = f(x) 在定义域上是一一对应（严格单调就够），则可反解出唯一的 x，记 x = f−1(y)。求反函数三步：① 由 y = f(x) 解出 x；② 把 x 与 y 互换字母；③ 写出反函数的定义域（正好是原函数的值域）。两个必须记住的事实：f−1[f(x)] = x，且 y = f(x) 与 y = f−1(x) 的图形关于直线 y = x 对称。反函数的定义域 = 原函数的值域，这条在求值域时特别好用。

六、奇偶性、周期性、有界性：三条「形状」性质

奇偶性：定义域必须关于原点对称，这是前提。f(−x) = f(x) 为偶函数（图形关于 y 轴对称），f(−x) = −f(x) 为奇函数（关于原点对称）。奇函数若在 0 处有定义，则必有 f(0) = 0——这条可以直接用来快速排除选项。乘法的规律：奇 × 奇 = 偶，奇 × 偶 = 奇，偶 × 偶 = 偶。周期性：存在 T ≠ 0 使 f(x + T) = f(x)，最小的正 T 叫最小正周期。sin x、cos x 是 2π，tan x、cot x 是 π；而 sin ωx 的周期是 2π/|ω|，ω 越大周期越短。所以把 sin x 换成 sin 2x，周期由 2π 压到 π；但别反过来说 sin 2x 的周期是 2π——2π 只是它的一个周期，不是最小的。有界性：存在 M > 0 使区间上恒有 |f(x)| ≤ M。sin x、cos x、arctan x 在 R 上有界；1/x 在 (0, 1) 内无界（越靠近 0 越大）。注意有界性必须指明区间，脱离区间谈有界没有意义。

例 1　求 f(x) = √(2 − x) + ln(x − 1) + arcsinx − 32 的定义域。

解　逐条卡：
根号：2 − x ≥ 0，即 x ≤ 2；
对数：x − 1 > 0，即 x > 1；
反正弦：−1 ≤ (x − 3)/2 ≤ 1，即 1 ≤ x ≤ 5。
三者取交集：1 < x ≤ 2，定义域为 (1, 2]。

易错在 arcsin 那一步：它是 −1 ≤ 括号内 ≤ 1，不是「括号内 ≥ 0」；另外交集时别忘了 x > 1 是开、x ≤ 2 是闭，端点归属要写清。

例 2　判断 f(x) = ln(x + √(1 + x²)) 的奇偶性。

解　先看定义域：对任意 x 有 √(1 + x²) > |x|，所以 x + √(1 + x²) > 0 恒成立，定义域是 R，关于原点对称，可以谈奇偶。
计算 f(−x) = ln(−x + √(1 + x²))。分子有理化：
(−x + √(1 + x²)) · (x + √(1 + x²)) = (1 + x²) − x² = 1，
故 −x + √(1 + x²) = 1/(x + √(1 + x²))，于是
f(−x) = ln1x + √(1 + x²) = −ln(x + √(1 + x²)) = −f(x)。
所以 f 是奇函数。

手法是「有理化造出倒数」：把根式减根式变成分式，取对数后正好出负号。这个函数是反双曲正弦，后面求导、求积分会反复出现。

例 3　求 y = 2x1 + 2x 的反函数。

解　先解出 x：由 y(1 + 2x) = 2x 得 2x(1 − y) = y，即 2x = y/(1 − y)，故 x = log2y1 − y。
交换字母得 y = log2x1 − x，定义域 0 < x < 1。
验算：原函数值域正是 (0, 1)（因为 2x > 0，分式恒在 0 与 1 之间），与反函数定义域一致。

最后一步「验算值域」不是多余的：反函数的定义域就是原函数的值域，两边对不上说明前面解错了。

七、这节和后文的关系

定义域决定了后面所有极限的「可讨论范围」；奇偶性、周期性决定了图形只要画一半或者一个周期；有界性在第五节比较无穷小、第十节最值定理里都要用。判断「两个函数是否相同」的思维，会在讲等价无穷小（第七节）时以另一种形式重现：能不能换，先看范围。

易错提醒：① 求定义域先卡条件、后化简；② 谈奇偶性前先看定义域是否对称，不对称的直接「非奇非偶」；③ 反函数别忘写定义域。

一、从「割圆术」说起：极限不是算出来大概是几

刘徽用正多边形逼近圆：正六边形、正十二边形、正二十四边形……边数越多，多边形越像圆，但永远不是圆。数列的极限就是把这个「越来越像」讲成一句可以被检验的话。数列 {an} 不过是按自然数排好队的一串数：a1, a2, a3, …。问它「趋于什么」，问的是当 n 无限变大时，an 与某个定数 a 的距离能不能要多少小有多少小。

二、ε–N 定义：把「要多少小有多少小」写成不等式

定义　设 {an} 为一数列，a 为常数。若对任意给定的 ε > 0，总存在正整数 N，使得当 n > N 时，都有

|an − a| < ε，

则称数列 {an} 收敛于 a，记作 limn→∞ an = a。

读法要读出三层意思。第一，ε 是任意的：别人给你多小的 ε 你都得接住，0.1 行、0.0001 也行。第二，N 是依赖 ε 的：ε 越小，N 一般越大，所以 N 不能事先定死，只能「对每个 ε 找一个」。第三，只要 n 超过 N，后面无穷多项全都落进 (a − ε, a + ε) 这个 ε 邻域。几何意义一句话：a 的任意 ε 邻域之外，至多只有有限项。这句话是判断「不收敛」的利器——如果某个区间外还有无穷多项，就不收敛。

三、用定义证极限：倒着找 N，正着写

课本例题看着玄，其实就两步。第一步（草稿）：从目标不等式出发倒推，把 |an − a| < ε 解成 n > φ(ε)。手法是「放大分母、缩小分子」，把含 n 的式子换成一个更简单的、只含 n 一次方的上界。第二步（正写）：对任给 ε > 0，取 N = [φ(ε)]（取整），则当 n > N 时，把上面的放大过程反向抄一遍，得到 |an − a| < ε。注意正写时 N 必须用方括号取整，且要写「当 n > N 时」而不是「当 n ≥ N 时」——虽然差别不大，但按定义写最稳。

四、收敛数列的四条性质

（1）唯一性：极限若存在则唯一。反证：假设 an → a 又 an → b，a ≠ b，取 ε = |a − b|/2，两个邻域互不相交，而 n 充分大时 an 要同时落进两个邻域，矛盾。

（2）有界性：收敛必有界。取 ε = 1，存在 N 使 n > N 时 |an| < |a| + 1；前 N 项只有有限个，取 M = max{|a1|, …, |aN|, |a| + 1} 即可。反过来不成立：有界不一定收敛，{(−1)n} 有界但发散。所以「有界」只是收敛的必要条件，考试里常拿它做排除。

（3）保号性：若 a > 0，则存在 N，当 n > N 时 an > 0。证明取 ε = a/2，则 an > a − a/2 = a/2 > 0。注意方向：由极限的符号推出项的符号，不能倒过来。但有反过来的弱版本：若从某项起 an ≥ 0，则 a ≥ 0（不能写 > 0）。

（4）子列同极限：若 an → a，则任一子列 ank → a。因为 nk ≥ k，k 一大，nk 更大。这条最常用的用法是反着用：只要找出两个子列极限不同（比如奇数项趋于 1、偶数项趋于 −1），原数列必发散。

五、无穷小乘有界：一个便宜好用的工具

定理　若 {an} 是无穷小（即 an → 0），{bn} 有界，则 {anbn} 也是无穷小。证明只用一句：设 |bn| ≤ M，则 |anbn| ≤ M|an|，右边趋零。典型例子 (1/n)·sin n → 0：1/n 是无穷小，sin n 被 1 卡住。凡是「无穷小 × 震荡因子」的题，一律走这条路，不要去算 sin n 到底是多少。

六、单调有界准则：递推数列的唯一通用入口

准则　单调增加且有上界的数列必收敛；单调减少且有下界的数列必收敛。它的价值在于：不需要事先知道极限是多少，就能断定极限存在。而对递推数列 an+1 = f(an)，这往往是唯一的路。标准三步：① 用数学归纳法证有界（猜一个界，比如 2）；② 作差 an+1 − an 判单调（或作商，注意正负）；③ 既然收敛，设极限为 A，对递推式两边取极限解方程，再把不合理的根舍掉（比如负数、或与界矛盾的那个）。

还有几条要背熟的常用结论：|q| < 1 时 qn → 0；n1/n → 1；a1/n → 1（a > 0）；nk/an → 0（a > 1，幂函数跑不过指数函数）；ln n / n → 0。这几条在第五节、第六节会当「已知」直接用。

例 1　用定义证明 limn→∞ 3n + 12n − 1 = 32。

解　先做草稿（放大）：
|3n + 12n − 1 − 32| = |2(3n + 1) − 3(2n − 1)2(2n − 1)| = 52(2n − 1)。
因为 n ≥ 1 时 2n − 1 ≥ n，所以上式 ≤ 52n。令 52n < ε，得 n > 52ε。
正式写：对任给 ε > 0，取 N = [52ε]，则当 n > N 时 n > 5/(2ε)，从而 |3n + 12n − 1 − 32| ≤ 52n < ε。由定义，极限为 3/2。

放大那一步的关键是「分母变小、分数变大」，把 2n − 1 换成 n。别把保住等号方向搞反。

例 2　求 limn→∞ sin nn。

解　1/n → 0 是无穷小；|sin n| ≤ 1，{sin n} 有界。由「无穷小 × 有界仍为无穷小」，(sin n)/n → 0。

常见错误是写 sin n → 0——sin n 根本不收敛，它在 [−1, 1] 里来回跳。结论对，理由错，一步扣光。

例 3　证明 an = 1 + 12² + 13² + … + 1n² 收敛。

解　单调：an+1 − an = 1/(n+1)² > 0，故单调增加。
有界：当 k ≥ 2 时 1k² < 1k(k − 1) = 1k − 1 − 1k，裂项相加得
an < 1 + (1 − 12) + (12 − 13) + … + (1n − 1 − 1n) = 2 − 1n < 2。
单调增加且有上界 2，由准则知 {an} 收敛（其极限为 π²/6 ≈ 1.645，但本题不需要求出来）。

「裂项放缩」是估界的标准动作：把 1/k² 放大成 1/k(k−1)，分母拆开就能逐项抵消。用准则证收敛，本来就不必知道极限值。

易错提醒：① ε–N 里 N 必须依赖 ε，写成常数 N 就错了；② 有界是收敛的必要条件，不能拿来证明收敛；③ 保号性只能从极限推项，不能从项推严格大于；④ 递推数列求出两个根时，必须用有界性、单调性、非负性舍掉一个。

一、从「一个方向」到「四面八方」

数列只有一个跑法：n 一路往无穷大走。函数不一样，自变量可以由左边贴近 x0，也可以由右边贴近，还可以一路往正无穷、负无穷跑，甚至两边都跑。所以第三节要把上一节的 ε–N 扩写成两套语言：一套管「靠近某一点」，一套管「跑向无穷远」。这两套定义是本章后面所有定理的地基，但考试更爱考的是它们的推论——左右极限和抓大头。

二、x → x₀ 的极限：ε–δ 与「去心」邻域

定义　设函数 f 在点 x0 的某个去心邻域内有定义。若存在常数 A，对任意 ε > 0，总存在 δ > 0，使得当

0 < |x − x0| < δ

时，都有 |f(x) − A| < ε，则称 x → x0 时 f(x) 以 A 为极限。

三个细节必须抠。其一，「去心」：0 < |x − x0| 把 x = x0 本身排除在外。这意味着极限存在与否、等于几，与 f 在 x₀ 处有没有定义、定义成什么，完全无关。这为后面「可去间断点补一个值就连续」埋好了伏笔。其二，δ 依赖 ε，ε 是任给的。其三，与数列的 N 不同，δ 是正数不是整数，所以不用取整。

三、x → ∞ 的极限：ε–X

定义　若对任意 ε > 0，存在 X > 0，使得当 |x| > X 时都有 |f(x) − A| < ε，则称 x → ∞ 时 f(x) → A。这里的 |x| > X 是双侧写法，等价于 x > X 或 x < −X。若只要 x > X，就写成 x → +∞；只要 x < −X，写成 x → −∞。三个记号不能混用：x → ∞ 要求两侧都趋于同一个 A；只证了一侧不等于证了双侧。

四、左右极限：极限存在的「双门卫」

左极限记 f(x0−) 或 f(x0 − 0)，条件改成 x0 − δ < x < x0；右极限记 f(x0+)，条件改成 x0 < x < x0 + δ。核心定理：

limx→x₀ f(x) = A ⟺ f(x0−) = f(x0+) = A。

于是「极限不存在」被拆成两种可操作的情形：左右都存在但不相等（跳跃），至少一侧不存在（比如趋于无穷）。三类题必须两边都算：分段函数在分界点；含 |x − a| 的式子（去掉绝对值要分正负）；含取整 [x] 的式子（在整数点两侧取值不同）。只代入一侧就下结论，是这一节最典型的失分。

五、局部保号与局部有界

局部保号性：若 limx→x₀ f(x) = A > 0，则存在去心邻域，在其中 f(x) > 0。证明取 ε = A/2，则 f(x) > A − A/2 = A/2 > 0。它说明「极限的符号可以遗传给附近的值」，是后面证不等式、证根存在的常用工具。局部有界性：若 x → x0 时极限存在，则 f 在 x0 的某去心邻域内有界。取 ε = 1，则 |f(x)| < |A| + 1。注意这两个性质都是「局部」的，只管一小段邻域，不管整个定义域。

六、x → ∞ 的抓大头

有理式在无穷远处的极限，只看分子分母的最高次项，其余全可以扔：

  • 分子分母同次：极限 = 最高次项系数之比；
  • 分子次数低：极限 = 0；
  • 分子次数高：极限 = ∞（不存在）。

原理是分子分母同除最高次幂，让所有低次项都变成「常数 / xk」这种趋于零的东西。含根式时先同除最高次幂，再小心把 x 从根号里拿出来时要不要加负号——这正是 x → +∞ 与 x → −∞ 经常给出不同答案的根源。

例 1　设 f(x) = x − 1（x < 0），f(x) = 0（x = 0），f(x) = x + 1（x > 0），讨论 x → 0 时的极限。

解　分界点在 0，必须两侧分别用不同的表达式。
左极限：x → 0− 时用 x − 1，得 f(0−) = −1。
右极限：x → 0+ 时用 x + 1，得 f(0+) = 1。
左右都存在但 −1 ≠ 1，故 limx→0 f(x) 不存在（属于跳跃型）。

注意 f(0) = 0 这个信息在求极限时完全没用——极限与函数在该点的取值无关。

例 2　分别求 limx→+∞ (√(x² + x) − x) 与 limx→−∞ (√(x² + x) + x)。

解　（1） 有理化：√(x² + x) − x = (x² + x) − x²√(x² + x) + x = x√(x² + x) + x。分子分母同除 x（此时 x > 0，x = √(x²)）：1√(1 + 1/x) + 1 → 12。
（2） 令 t = −x → +∞，则 x = −t，√(x² + x) = √(t² − t)，原式 = √(t² − t) − t = −t√(t² − t) + t = −1√(1 − 1/t) + 1 → −12。

第（2）问最容易错的地方是直接把 √(x²) 当成 x：x < 0 时其实 √(x²) = −x。用换元 t = −x 把负方向转成正方向，是最不容易翻车的写法。

例 3　求 limx→1 [x]，其中 [x] 表示不超过 x 的最大整数。

解　取整函数在整数点两侧取值不同。
左极限：x → 1− 时 0.9 < x < 1，[x] = 0，故左极限为 0。
右极限：x → 1+ 时 1 < x < 1.1，[x] = 1，故右极限为 1。
左右不相等，极限不存在。

同类的还有 |x|/x 在 0 处（左 −1、右 1）、符号函数 sgn x 在 0 处。凡是「分段定义隐藏在符号里」的，都要按左右两套解析式算。

易错提醒：① x → ∞ 不是 x → +∞，两侧要分别看；② 从根号里提出 x 时先判断正负；③ 极限与函数值无关，别拿 f(x0) 去凑极限。

一、望远镜里的星星：趋零的变量，不是很小的数

用望远镜看远处的塔，越走越远，塔在视野里越来越小，但塔本身高度一点没变——变小的是「视角」，是一个随距离变化、可以任意接近零的量。这就是无穷小的原型：无穷小是一个以 0 为极限的变量，不是「很小的数」。所以 0.000001 不是无穷小，它就是个常数；而 1/n、sin x（当 x → 0）、x − 1（当 x → 1）都是无穷小。

二、定义与那条「A + α」定理

定义　若 limx→x₀ α(x) = 0（或 x → ∞），则称 α(x) 为当 x → x₀ 时的无穷小。

定理　limx→x₀ f(x) = A ⟺ f(x) = A + α(x)，其中 α 是无穷小。证明只一步：令 α(x) = f(x) − A，则 |f(x) − A| < ε 与 |α(x)| < ε 是同一句话。这条定理把「求极限」翻译成「做分解」：任何一个有极限的量，都能拆成「极限值 + 一个趋零的尾巴」。它在第五节证明四则运算法则时是主力工具。

性质（都带「有限个」三个字）：有限个无穷小之和仍是无穷小；有限个无穷小之积仍是无穷小；无穷小 × 有界量仍是无穷小；常数与无穷小之积仍是无穷小。注意第三条是「有界」，不是「有极限」——sin(1/x) 在 0 附近没有极限，但它有界，配上 x 就有 x sin(1/x) → 0。还有一条要记：0 是唯一的常数无穷小。

三、无穷大：记号，不是数

定义　若对任意 M > 0，总存在相应时刻之后使 |f(x)| > M，则称 f(x) 为无穷大，记 limx→x₀ f(x) = ∞。这里必须强调：∞ 不是数，它是一句「绝对值可以要多大有多大」的缩写。所以 ∞ − ∞、∞/∞、0 · ∞ 都不能当成算术来算，它们是不定式，必须变形。倒数关系：在同一变化过程中，若 f ≠ 0，则 f 为无穷大 ⟺ 1/f 为无穷小。这条把两类问题互相转化，做题时很省事。

无界 ≠ 无穷大，这是最容易混的一对。无穷大要求「最终一直很大」，无界只要求「存在任意大的点」。反例：f(x) = x sin x 在 (0, +∞) 上。取 x = 2kπ + π/2，f = x 可以任意大，所以无界；但取 x = kπ，f = 0，它一次又一次回到 0，永远不满足「最终 |f| > M」，所以不是无穷大。无穷大 ⟹ 无界，反过来不成立。

四、曲线的渐近线：三类，各有各的算法

（1）垂直渐近线：若 limx→a⁺ f(x) = ∞ 或 −∞（一侧就够），则 x = a 是垂直渐近线。可疑点：分母的零点、对数的真数零点、tan 的极点。（2）水平渐近线：若 limx→+∞ f(x) = b，则 y = b；x → −∞ 单独算，两侧的 b 可以不同，也可以一侧有一侧没有。（3）斜渐近线：先算斜率 k = limx→∞ f(x)x，要求 k 存在、有限且 k ≠ 0；再算截距 b = limx→∞ [f(x) − kx]，则 y = kx + b。

三者的关系要说清：斜渐近线是「一般情形」，水平是 k = 0 的退化情形。所以算的时候先算 k：k 存在且为 0，就是水平；k 存在且非零，就再算 b 得斜渐近线；k 不存在（比如趋于无穷），就没有斜渐近线。同一侧不可能既有水平又有斜的，因为 k 只能有一个值。垂直渐近线则完全可以和它们共存。

例 1　求曲线 y = x² + 1x − 1 的所有渐近线。

解　垂直：分母零点 x = 1。x → 1+ 时分子 → 2 > 0、分母 → 0+，故 y → +∞；x → 1− 时 y → −∞。所以 x = 1 是垂直渐近线。
斜：k = limx→∞ x² + 1x(x − 1) = 1（抓大头）。
b = limx→∞ [x² + 1x − 1 − x] = limx→∞ x + 1x − 1 = 1。
所以 y = x + 1 是斜渐近线（两侧同一条，因为两侧极限相同）。

验算弧线关系：做除法 x² + 1 = (x − 1)(x + 1) + 2，即 y = x + 1 + 2/(x − 1)，尾巴 2/(x − 1) → 0，一眼看出渐近线是 y = x + 1。会做多项式除法，斜渐近线不用算极限。

例 2　求 y = x + arctan x 的渐近线。

解　无分母、无对数，没有垂直渐近线。
k = limx→∞ x + arctan xx = limx→∞ (1 + arctan xx) = 1（因为 arctan x 有界）。
两侧分别算 b：
x → +∞：b = limx→+∞ arctan x = π2，得 y = x + π/2；
x → −∞：b = limx→−∞ arctan x = −π2，得 y = x − π/2。
两条斜渐近线，右侧一条、左侧一条。

这是「两侧 b 不同」的标准例子。只写一条就错了一半。凡是含 arctan、含根号、含 |x| 的函数，都要把 +∞ 与 −∞ 分开算 b。

例 3　说明 f(x) = x sin x 在 (0, +∞) 内无界，但不是无穷大。

解　无界：取 xk = 2kπ + π/2，则 f(xk) = 2kπ + π/2 → +∞。对任意 M > 0 都能找到点使 f > M，故无界。
不是无穷大：取 xk = kπ，则 f(xk) = 0。无论 X 取多大，总有 x > X 使 f(x) = 0，不满足「最终 |f| > M」，所以不是无穷大。

判「不是无穷大」的通用手法：构造一列点让函数值不增大（回到 0、或趋于某个有限数）。判「无界」则构造一列点让它冲上去。两个方向用两列不同的点，是这个题型的定式。

易错提醒：① 无穷小是变量不是小数，0 是唯一常数无穷小；② 「无界」不能推出「无穷大」；③ 求斜渐近线必须先验 k ≠ 0，k = 0 时要回到水平渐近线的写法；④ 垂直渐近线只要一侧趋于 ∞ 就成立。

一、极限为什么能「进」运算里

前两节把极限定义清楚了，但真要靠定义一个个证，谁也受不了。所以必须证明一批「运算规则」：只要每个部分的极限都存在，整体的极限就等于各部分极限做同样的运算。有了这套规则，求极限就变成算术——先代入，代不进去就变形，变完再代入。这一节的全部技术，都围绕「代不进去怎么办」展开。

二、四则运算法则及其证明思路

定理　设 limx→x₀ f(x) = A，limx→x₀ g(x) = B（两个极限都必须存在），则

limx→x₀ [f(x) ± g(x)] = A ± B，limx→x₀ [f(x)g(x)] = AB，且当 B ≠ 0 时 limx→x₀ f(x)g(x) = AB。

证明思路（只写乘积，其余同理）：由上一节的定理，写 f = A + α，g = B + β，其中 α, β 是无穷小。于是 fg = AB + (Aβ + Bα + αβ)。括号里三项：Aβ 是常数乘无穷小，Bα 同理，αβ 是无穷小乘无穷小，三者都是无穷小，它们的和仍是无穷小。所以 fg = AB + 无穷小，即 fg → AB。商的证明多一步：先证 1/g → 1/B，再用乘积。

这个证明说明了一件重要的事：法则的每一项都在用「有界 × 无穷小」。所以前提「极限存在」不能省——lim (sin x − sin x) 你当然可以算成 0，但如果你写成 lim sin x − lim sin x 就毫无意义，因为 lim sin x 在 x → ∞ 时不存在。拆开之前，先确认每一块都收敛。

推论：法则可推广到有限个函数；常数因子可提出 lim [c f] = cA；正整数次幂 lim fn = An；方根 lim n√f = n√A（A ≥ 0，偶次根号要求 A ≥ 0）。

三、代入优先，然后只盯七种不定式

因为初等函数在定义点连续（第九节会证），所以拿到极限先直接代入。代入结果只有两类：能算出确定的数（包括 0），那就结束了；算出七种不定式，才需要变形。七种是：00、∞∞、∞ − ∞、0 · ∞、1∞、00、∞0。前三节练过的「抓大头」管 ∞/∞，有理化管 ∞ − ∞ 里的根式，本节补上 0/0 的三种手法。

0/0 的三板斧：① 因式分解，约掉造成零的因子（x − a）；② 有理化，含根号时乘共轭，把「根号减根号」变成「分式」；③ 等价无穷小，含 sin、tan、ln、e 的优先用它（下一节展开讲）。三条按顺序试，绝大多数题前三步之内一定出来。

四、复合函数的极限：把 lim 搬进函数

定理　若 limx→x₀ g(x) = u0，且 f 在 u0 处连续，则 limx→x₀ f[g(x)] = f(u0) = f[limx→x₀ g(x)]。通俗说：外层连续时，极限可以穿过函数符号。这条是「先算内层、再代外层」的依据，第九节会再正式讲一遍。要注意条件：外层必须在 u0 处连续；如果外层不连续（比如 f = [u] 取整），就不能随便穿。

五、幂指函数：一律化到 e 的指数上

uv 这种底数和指数都在动的式子，不能分别求极限。标准动作是恒等变形

uv = ev ln u（要求 u > 0），

于是 lim uv = elim (v ln u)（指数函数连续，极限可以搬进 e 的指数）。这样 1∞、00、∞0 全都被统一成「指数上的乘积极限」，而 v ln u 往往是 0 · ∞ 或 ∞ · 0，再化成 0/0 或 ∞/∞ 即可。这条是通法，下一节的「1∞ 速算公式」只是它的快捷方式。

例 1　求 limx→3 x² − 9x − 3。

解　代入得 0/0，属不定式。分子因式分解：x² − 9 = (x − 3)(x + 3)，约去零因子 x − 3（因 x → 3 时 x ≠ 3，约分合法）：
limx→3 (x − 3)(x + 3)x − 3 = limx→3 (x + 3) = 6。

「约去零因子合法」这句话要会讲：极限是去心邻域里的事，x ≠ 3，所以除法有意义。这就是第三节「去心」二字的回报。

例 2　求 limx→0 √(1 + x) − 1x。

解　代入得 0/0。乘共轭有理化：
√(1 + x) − 1x = (1 + x) − 1x[√(1 + x) + 1] = 1√(1 + x) + 1 → 12。

有理化的通用写法是「上下同乘共轭」，并记住 (√a − √b)(√a + √b) = a − b。本题也可用等价无穷小 (1 + x)1/2 − 1 ~ x/2，一步得 1/2。

例 3　求 limx→1 (1x − 1 − 2x² − 1)。

解　代入是 ∞ − ∞，先通分把它变成 0/0：
1x − 1 − 2(x − 1)(x + 1) = (x + 1) − 2(x − 1)(x + 1) = x − 1(x − 1)(x + 1)，
约去 x − 1 得 1x + 1 → 12。

「∞ − ∞」的第一反应永远是通分（分式减分式）或有理化（根式减根式），把它压成 0/0 或 ∞/∞，不要在两个无穷大上做文章。

例 4　求 limx→0 (1 + x)1/x。

解　这是 1∞。用 uv = ev ln u：
原式 = elimx→0 ln(1 + x)x。而 limx→0 ln(1 + x)x = 1（等价无穷小 ln(1 + x) ~ x），
故原式 = e1 = e。

写的时候别丢 e：不少同学算出指数上的极限是 1，就直接写答案 1。指数量是 e 的指数，不是结果本身。

易错提醒：① 拆项前先确认每一块极限都存在，否则 ∞ − ∞ 会被你算成 0；② 商法则要求分母极限非零；③ 幂指函数不能「底数极限的指数极限次方」直接算，那是把 1∞ 当成了 1。

一、有些极限，算术是算不出来的

前面所有方法都建立在「已知某些极限」和「四则运算」上。但 sin x / x 这种式子，分子分母都趋零，四则法则给不出答案（分母极限是 0，商法则直接作废）。这时候需要两条「存在性准则」：不直接算，而是证明它一定收敛，并且把它夹住。夹逼准则管「上下一夹」，单调有界准则管「一路往上但不越界」。而这两个准则各自带出一个必须背下来的重要极限。

二、夹逼准则

准则　若在某过程中（n > N 或 0 < |x − x0| < δ）有

g(x) ≤ f(x) ≤ h(x)，且 limx→x₀ g(x) = limx→x₀ h(x) = A，

则 limx→x₀ f(x) = A。最常用的特例是 A = 0 且 0 ≤ f ≤ h：只要能用一个趋零的量把 |f| 压住，f 就趋零。典型场景：n 项和（把每项都放大成最大项、缩小成最小项，得到上下界）与含 (−1)n、sin n 的震荡项（用 |·| ≤ 1 压住）。

三、单调有界准则

准则　单调增加且有上界的数列必有极限；单调减少且有下界的数列必有极限。它和夹逼准则的分工是：夹逼准则是「两边都已知」，单调有界准则是「只知道一边、且知道方向」。递推数列 an+1 = f(an) 的题只有这一条路可走，三步走法：① 归纳证有界（先猜界，通常由递推式解不动点猜出来）；② 作差或作商证单调；③ 设极限为 A，代入递推式解方程，舍去不合理的根。

四、第一个重要极限：sin x / x → 1

结论　limx→0 sin xx = 1，更一般地 limu→0 sin uu = 1，其中 u 可以是任何趋于 0 的式子。

几何证明思路（先看 0 < x < π/2）：在单位圆里，设圆心角为 x（弧度），比较三块面积——三角形 OAB 的面积 = 12 sin x，扇形 OAB 的面积 = 12 x，三角形 OAC（AC 为切线）的面积 = 12 tan x。图形上嵌套关系给出

sin x < x < tan x。

三边同除 sin x > 0 得 1 < xsin x < 1cos x，取倒数翻转得 cos x < sin xx < 1。因为 cos x → 1（x → 0），由夹逼准则 sin x / x → 1。x < 0 时用偶函数性质 sin(−x)/(−x) = sin x / x 化归。这个证明的意义远超结论本身：它是「弧度制」被定义成这样的原因——只有弧度制下弧长才等于 x，扇形面积才是 x/2。

三角型配套变形：见到 1 − cos x，先化 2sin²(x/2)；见到 tan x，先拆 sin x / cos x，再用 cos x → 1 收尾；见到 arcsin x、arctan x，令 t = arcsin x（或 t = arctan x）换元，把反三角转成正三角。

五、第二个重要极限：e 的诞生

结论　limx→∞ (1 + 1x)x = e，等价写法 limu→0 (1 + u)1/u = e，其中 e ≈ 2.718281828 是无理数。

证明思路（先看数列版）：展开 (1 + 1/n)n = Σ C(n,k)/nk，逐项可证它随 n 单调增加；再把每一项放大成 1/k!，得 (1 + 1/n)n < 1 + 1 + 1/2! + … + 1/n! < 3，有上界。于是由单调有界准则收敛，把这个极限定义为 e。所以 e 不是「先有数再求极限」，而是「先证极限存在，再给它起名」。这也解释了为什么 e 会出现在复利、人口增长、放射性衰变里——凡是「连续不断地按比例增长」的模型，极限都是这个式子。

六、1∞ 型速算公式

若 u(x) → 1、v(x) → ∞，则

limx→x₀ uv = elimx→x₀ v(u − 1)。

推导：uv = [(1 + (u − 1))1/(u−1)]v(u−1)。令 t = u − 1 → 0，方括号里的部分正是 (1 + t)1/t → e，剩下的指数 v(u − 1) 照算，由复合极限得 elim v(u−1)。用的时候只记两件事：底数减 1、乘上指数、取极限、放到 e 的肩上。

注意这个公式只对 1∞ 有效。先确认底数确实趋于 1、指数确实趋于 ∞，两者缺一，公式就不能用。

例 1　求 limx→0 sin 3xtan 5x。

解　拆开凑第一个重要极限：
sin 3xtan 5x = sin 3x3x · 5xtan 5x · 3x5x。
第一个因子 → 1，第二个因子 = 5xsin 5x · cos 5x → 1 · 1 = 1，第三个因子 = 3/5。
故原式 = 35。

口诀：缺什么补什么。要凑成 sin u / u，就把 3x 补到分母，再在分子补一个 3x 抵消。用等价无穷小 sin 3x ~ 3x、tan 5x ~ 5x 也能一步得 3/5，但先练熟「凑」的手法，等价替换才用得放心。

例 2　求 limx→0 1 − cos xx²。

解　用半角公式降次：1 − cos x = 2 sin²(x/2)，于是
1 − cos xx² = 2 sin²(x/2)x² = 12 · [sin(x/2)x/2]2。
方括号内 → 1，故原式 = 12。

这个结果要当公式记住：1 − cos x ~ x²/2。它是下一节等价替换表里唯一的「二阶」项，凡出现 1 − cos 就该条件反射。

例 3　求 limx→∞ (x² + 1x² − 1)x²。

解　底数 → 1、指数 → ∞，是 1∞。先算 u − 1：
u − 1 = x² + 1x² − 1 − 1 = 2x² − 1。
于是 v(u − 1) = x² · 2x² − 1 = 2x²x² − 1 → 2。
由速算公式，原式 = e2。

另一条路是凑标准形：u = 1 + 2/(x² − 1)，写成 [(1 + 2/(x²−1))(x²−1)/2]2x²/(x²−1)，方括号内 → e，指数 → 2，答案 e²。两条路都可以，但凑标准形更容易在考场上写清楚。

例 4　求 limn→∞ (1√(n² + 1) + 1√(n² + 2) + … + 1√(n² + n))。

解　共 n 项，每项分母都在 √(n² + 1) 与 √(n² + n) 之间。用最小的分母放大、最大的分母缩小：
n√(n² + n) ≤ 原式 ≤ n√(n² + 1)。
右端 = 1√(1 + 1/n²) → 1；左端 = 1√(1 + 1/n) → 1。
由夹逼准则，原式 = 1。

n 项和的夹逼定式：每项都替换成最大项得下界，替换成最小项得上界，两项数都乘 n。最后两个界必须趋于同一个值，否则夹逼失效，得改用定积分定义（那是第六章的事）。

易错提醒：① sin x / x → 1 只在 x → 0 时成立，x → ∞ 时是 0；② 1∞ 不能用「底的极限的指数极限次方」；③ 速算公式里是 u − 1 不是 u；④ 递推数列解出两个根，要结合有界性舍掉一个。

一、都在趋零，但快慢不一样

x、x²、x³ 当 x → 0 时都是无穷小。可 x = 0.01 时，x² = 0.0001，x³ = 0.000001——x³ 掉得快得多。既然都趋零，就不能用「谁更接近 0」来分，只能用它们相互的比值来分。这一节就是把「趋零的速度」做成一套可比大小的刻度，然后把刻度变成计算的捷径。它是本章性价比最高的一节：「等价无穷小替换」能让一道三行的题变成一行。

二、四个等级：用比值定性

设 α, β 是同一过程中的无穷小，且 α ≠ 0，考察 β/α：

  • limx→x₀ βα = 0：称 β 是 α 的高阶无穷小，记 β = o(α)，读作「β 比 α 掉得快」；
  • limx→x₀ βα = ∞：低阶；
  • limx→x₀ βα = c ≠ 0：同阶；
  • 特别地 c = 1，即 limx→x₀ βα = 1：称 α 与 β 等价，记 α ~ β。

四个等级里，等价最强：它不是「差不多」，而是「比值趋于 1」，意味着在乘除结构里可以互相顶替而不改变极限。还有一条补充记号：若 β/αk → c ≠ 0，则称 β 是 α 的 k 阶无穷小。x² 是 x 的二阶无穷小，1 − cos x 也是 x 的二阶无穷小——这个「阶」的概念，就是后面泰勒展开的雏形。

三、等价替换定理：为什么只能换乘除因子

定理　设 α ~ α′，β ~ β′，且 limx→x₀ β′α′ 存在，则 limx→x₀ βα = limx→x₀ β′α′。

证明：把比值拆成三段 βα = ββ′ · β′α′ · α′α。由等价定义，第一段 → 1，第三段也 → 1，中间那段就是我们要的。三段极限都存在，用乘积法则乘起来即可。这个证明同时暴露了限制：拆分只在乘除结构里成立。

为什么加减里不能换？看 limx→0 tan x − sin xx³。若把 tan x 和 sin x 都换成 x，分子变成 x − x = 0，答案 0——但正确结果是 1/2。错在哪？把两个都换掉，等于把它们的「差」当成 0 处理，而同阶项相减后剩下的正是那个被扔掉的二阶三阶小量。tan x − sin x ~ x³/2，这个 x³/2 恰恰是全部答案，却被 x − x 抹掉了。所以规则要背成一句狠话：乘除随便换，加减一个都不许换。

四、必须背下来的替换表（x → 0）

一阶（最常用）：

sin x ~ tan x ~ arcsin x ~ arctan x ~ ln(1 + x) ~ ex − 1 ~ x。

二阶：1 − cos x ~ x²2，x − ln(1 + x) ~ x²2，(1 + x)α − 1 ~ αx（注意这个是一阶的），ax − 1 ~ x ln a（一阶）。

三阶：x − sin x ~ x³6，tan x − x ~ x³3，tan x − sin x ~ x³2，arcsin x − x ~ x³6，x − arctan x ~ x³3。

背法建议：别硬背，记泰勒首项。sin x = x − x³/6 + …，所以 x − sin x ~ x³/6；tan x = x + x³/3 + …，所以 tan x − x ~ x³/3；两者相减 (x³/3) − (−x³/6) = x³/2，正是 tan x − sin x 的首项。会推就不用怕记错。

五、复合换元：内层是什么都行

替换表的条件是「括号里趋零」。所以 sin(x²) ~ x²、ln(1 + 3x) ~ 3x、esin x − 1 ~ sin x ~ x、1 − cos(2x) ~ (2x)²/2 = 2x²。规则一句话：若 u → 0 且 f(u) ~ u，则 f(g(x)) ~ g(x)，只要 g(x) → 0。整体替身，别只替一半：1 − cos(2x) 要整体换成 2x²，不能写成 1 − 2x 之类。

六、加减型的三条出路

遇到加减，不许直接换，但有三个合法动作：① 提公因式——把主导项提出来，剩下的变成加减但量级更低，再换；② 通分/有理化——把「分式减分式」「根式减根式」压成乘除；③ 合并同类项——先做代数化简，把能抵消的抵消掉。三条都走不通，就上泰勒，展到足够阶。判断展到几阶的标准是：分子分母同阶。这是最稳的后手，也是区分「会做」和「做得漂亮」的地方。

例 1　求 limx→0 1 − cos xx sin x。

解　分母 x sin x 是乘积，sin x ~ x，故分母 ~ x²；分子 1 − cos x ~ x²/2。都是乘除结构，直接换：
原式 = limx→0 x²/2x² = 12。

换的时候要确认「谁是因子」：分母是 x 乘 sin x，两个都是因子，sin x 可以换。如果分母写成 x + sin x，那就只能提出 x 变成 x(1 + sin x/x)，不能直接换 sin x。

例 2　求 limx→0 tan x − sin xx³。

解　不能把 tan x、sin x 都换成 x。正确做法是先提公因式：
tan x − sin x = sin x (1cos x − 1) = sin x · 1 − cos xcos x。
现在全是乘除结构：sin x ~ x，1 − cos x ~ x²/2，cos x → 1，于是
原式 = limx→0 x · (x²/2)x³ · 1 = 12。

「提公因式」是化加减为乘除的万能第一招。也可以直接用表：tan x − sin x ~ x³/2，但只有把推导走一遍才知道那张表为什么长这样。

例 3　求 limx→0 ex² − 11 − cos x。

解　分子：令 u = x² → 0，由 eu − 1 ~ u 得 ex² − 1 ~ x²。
分母：1 − cos x ~ x²/2。
原式 = limx→0 x²x²/2 = 2。

复合换元的关键是「整体」：ex² − 1 里的 x² 是一个整体 u，不能写成 ex − 1 那种半截替换。

例 4（提高）　求 limx→0 (1sin²x − 1x²)。

解　∞ − ∞ 型，先通分：
x² − sin²xx² sin²x。分母 x² sin²x ~ x4；分子用平方差：x² − sin²x = (x + sin x)(x − sin x)。
x + sin x ~ 2x，x − sin x ~ x³/6，故分子 ~ 2x · x³/6 = x4/3。
原式 = limx→0 x4/3x4 = 13。

这题的陷阱是「sin x ~ x，所以 1/sin²x − 1/x² → 0」。又是同阶相减被抹掉：sin²x 与 x² 的差是四阶的小量，正好是答案的全部。加减结构一律先变形，再换。

易错提醒：① 替换只在乘除因子中做，加减里做必错；② 复合要整体换，不能拆开一半；③ 表里所有式子都要求「括号内趋于 0」，sin x ~ x 在 x → 1 时不成立；④ 等价不是相等，写在等号链里时最好标注「~」而不是「=」。

一、笔不离纸：连续就是「不用抬笔」

画 y = x² 可以一笔画到底；画 y = 1/x 到 x = 0 附近，笔必须飞起来；画 y = sin(1/x) 靠近 0 的地方，笔抖得根本落不下去。三种「不连续」的样子，正好对应三种间断点。数学上不能靠「抬不抬笔」下定义，得用极限：函数在一点连续，说的是当 x 靠近这一点时，f(x) 靠近的正好是这一点处的函数值。注意这里「正好是」三个字，把极限值和函数值绑在了一起——这正是连续与「极限存在」的唯一区别。

二、连续的三条件与三种等价说法

定义　设 f 在 x0 的某邻域内有定义。若

limx→x₀ f(x) = f(x0)，

则称 f 在 x0 处连续。这个式子拆开是三条，缺一不可：① f 在 x0 处有定义（右边才写得出来）；② 极限存在（左边才存在）；③ 二者相等。三条里少一条，就叫间断。

等价说法有两种，考试都用。增量式：记 Δx = x − x0，Δy = f(x0 + Δx) − f(x0)，则连续 ⟺ limΔx→0 Δy = 0。这句话的物理味很浓：自变量的微小变化只引起函数值的微小变化。导数那一章就是从它出发，把 Δy/Δx 的极限定义成导数。ε–δ 式：对任意 ε > 0，存在 δ > 0，当 |x − x0| < δ 时 |f(x) − f(x0)| < ε。注意这里没有「去心」，x = x0 也被包含在内，这是与极限定义最直观的差别。

单侧连续：左连续 f(x0−) = f(x0)，右连续 f(x0+) = f(x0)。定理：连续 ⟺ 既左连续又右连续。这条在分段函数处至关重要：分界点要连续，必须左右两边的表达式算出的极限都等于该点的函数值，两个等式都要成立。

三、间断点：两类四种，判据是「左右极限在不在」

定义　若 f 在 x0 的某去心邻域内有定义而不连续，则称 x0 为间断点。分类只看一件事：左右极限存不存在。

  • 第一类（左右极限都存在）：
    • 若 f(x0−) = f(x0+) ≠ f(x0)，或 f 在 x0 无定义 —— 可去间断点。名字的由来：只要补充或修改 f(x0) 为那个公共极限值，就连续了，这个点是「可以去掉的缺陷」。
    • 若 f(x0−) ≠ f(x0+) —— 跳跃间断点。图形在这里断开一截，跳的高度是 |f(x0+) − f(x0−)|，无论怎么补定义都接不上。
  • 第二类（至少一侧极限不存在）：
    • 趋于无穷（一侧或两侧）—— 无穷间断点，如 1/x 在 0 处。
    • 来回震荡不趋于任何值 —— 振荡间断点，如 sin(1/x) 在 0 处。

四、判断流程：三步走，不要跳

第一步，找可疑点：分母的零点、对数的真数零点、偶次根号的边界、分段函数的分界点、取整函数与绝对值的折点。第二步，逐个算左右极限：注意在可疑点两侧要用各自那一支的表达式；含 |x − a| 的先去掉绝对值再算。第三步，按表定性并写出结论：先写「左右极限都存在/有一侧不存在」，再说「属于第几类、哪一种」。答题时把「因为 f(x0−) = …，f(x0+) = …，所以……」写全，过程分才拿得到。

含参的连续题：分段点连续 ⟺ 左极限 = 右极限 = 函数值，据此列方程解参数。若题目再要求可导，则还要左右导数相等——那是第二章的事，但连续是可导的前提，先把连续的条件用足。

例 1　讨论 f(x) = x² − 1x − 1 在 x = 1 处的连续性，并说明间断点类型。

解　f 在 x = 1 处无定义，所以一定不连续，x = 1 是间断点。
求极限（x ≠ 1 时可约分）：limx→1 (x − 1)(x + 1)x − 1 = limx→1 (x + 1) = 2。
左右极限都存在且都等于 2，故为可去间断点。补充定义 f(1) = 2 后，f 在 x = 1 处连续。

「可去」的判据是「左右极限相等」，不是「函数值等于极限」——这里函数值根本不存在，仍然可去。相反，若极限是 2 而 f(1) = 5，也是可去，把 f(1) 改成 2 即可。

例 2　讨论 f(x) = sin1x 在 x = 0 处的间断类型。

解　f 在 0 处无定义。取 xn = 12nπ + π/2 → 0，则 f(xn) = 1；取 yn = 1nπ → 0，则 f(yn) = 0。
两列点都趋于 0，但函数值趋于不同的数，故 x → 0 时极限不存在；且函数值在 [−1, 1] 内反复震荡，属于第二类振荡间断点。

「证明极限不存在」的通用手法：造两列趋于同一点但函数值趋于不同极限的点列。这个手法在第三节判左右极限、在第八节判振荡，都是主力。

例 3　讨论 f(x) = [x] 在整数点 x = n 处的间断类型。

解　左极限：x → n− 时 n − 1 < x < n，[x] = n − 1，故 f(n−) = n − 1。
右极限：x → n+ 时 n < x < n + 1，[x] = n，故 f(n+) = n。
左右极限都存在但相差 1，且 f(n) = n ≠ n − 1，故为第一类跳跃间断点，跳跃度为 1。

凡是「分段定义藏在符号里」的函数（取整、符号函数、绝对值商），都要按左右两套解析式分别算，不能把 x = n 直接代进去当极限。

例 4　设 f(x) = sin axx（x ≠ 0），f(0) = 3，问 a 取何值时 f 在 x = 0 处连续。

解　连续要求 limx→0 f(x) = f(0) = 3。
而 limx→0 sin axx = limx→0 sin axax · a = 1 · a = a。
令 a = 3，则极限等于函数值，f 在 0 处连续。

含参连续题的固定写法：左边算出极限（含参数），右边写出函数值，令二者相等。若分界点两侧解析式不同，就写「左极限 = 右极限 = 函数值」三个等式串起来。

易错提醒：① 连续的三条件缺一不可，别只算极限就说连续；② 可去间断点的判据是左右极限相等，与函数值无关；③ 第二类只要求「至少一侧不存在」，不必两侧都不存在；④ 求间断点前先求定义域，把无定义点也纳入可疑点。

一、为什么「直接代入」是合法的

第五节说「代入优先」，当时是当经验用的。这一节把它变成定理：初等函数在其定义区间内连续，所以只要代入点落在定义区间里，limx→x₀ f(x) = f(x0) 就是恒等式，不用算。这条定理的价值在于它把「求极限」这件难事，在绝大多数情况下降级成「代个数」。而它的证明路线是：先证基本初等函数连续，再证连续函数对四则、复合、求反函数都封闭，最后一层层搭出所有初等函数。本节就是走完这条路。

二、连续函数的四则、复合、反函数

四则：若 f, g 在 x0 处连续，则 f ± g、f · g 在 x0 处连续；若再有 g(x0) ≠ 0，则 f/g 也连续。证明就是第五节四则法则的直接翻译：lim (f ± g) = lim f ± lim g = f(x0) ± g(x0)，中间那步用了连续性。

复合：若 u = g(x) 在 x0 连续，y = f(u) 在 u0 = g(x0) 连续，则 f[g(x)] 在 x0 连续。这条的正确性来自「极限可以搬进连续函数」：lim f[g(x)] = f[lim g(x)] = f[g(x0)]。要强调条件：外层必须在 u0 处连续，不是「外层有极限」就行。

反函数：若 y = f(x) 在区间上严格单调且连续，则其反函数 x = f−1(y) 在对应区间上也连续。直观理由：严格单调连续函数的图形是一条「不断往上（或往下）走、中间不断」的曲线，把它关于 y = x 翻过来，仍然是不断的一条。这条定理保证了 arcsin、arccos、arctan、ln 的连续性——它们都是先有连续的原函数，才被定义出来的。

三、初等函数在「定义区间」内连续

定理　一切初等函数在其定义区间内连续。注意用词是「定义区间」，不是「定义域」。定义区间指定义域中一段一段的区间；而定义域可能包含孤立点，孤立点谈不上连续（连续要求邻域内有定义）。

经典反例：y = √(cos x − 1)。要求 cos x − 1 ≥ 0，而 cos x ≤ 1 恒成立，故只能 cos x = 1，即 x = 2kπ。定义域是一串孤立点，不含任何区间，所以这个函数处处不连续。若有人拿「初等函数都连续」硬套，就会得出「它在每个 2kπ 都连续」的荒谬结论。

由此得到求极限的标准动作：先看代入点是不是定义区间内的点。是，直接代；不是，才需要变形。端点是定义区间端点时，只能求单侧极限，用单侧连续性处理。

四、把 lim 搬进函数符号

定理（复合极限的连续性版本）　若 limx→x₀ g(x) = A，且 f 在 A 处连续，则

limx→x₀ f[g(x)] = f[limx→x₀ g(x)]。

用的时候要有意识：写这一步就是在用连续性。典型应用是 ln、e(·)、arctan、√ 这些「外面套一层」的结构：把它搬到外面，里面单独算。例如 limx→0 arctansin xx = arctan 1 = π4。反之，如果外层不连续（比如取整 [·]），就不能搬。

幂指函数的连续性：u(x)v(x) = ev(x) ln u(x)，要它有定义要 u(x) > 0；若 u, v 都连续且 u > 0，则幂指函数也连续。这条把第五节「幂指函数化到 e 的指数上」的做法升级成了合法性证明——你之所以能对 uv 直接取极限，是因为它在定义区间内连续。

例 1　求 limx→0 arctansin xx。

解　内层 g(x) = sin xx 当 x → 0 时极限为 1（第一个重要极限）；外层 arctan 在 u = 1 处连续。
故由「极限搬进连续函数」：
原式 = arctan(1) = π4。

答题时要写明「因为 arctan 在 1 处连续」，这是得分点。只写「= arctan 1」会被认为跳步。

例 2　求 limx→1 ln xx − 1。

解　代入得 0/0，不能直接代。令 t = x − 1 → 0，则 x = 1 + t：
ln(1 + t)t → 1。
所以原式 = 1。

这一步用了 ln(1 + t) ~ t，本质上是把「在 x = 1 处」平移成「在 t = 0 处」，让替换表能用。凡是在 x ≠ 0 的点上出现 ln、sin 的 0/0，都先平移。

例 3　求 limx→0 (1 + sin x)1/x。

解　这是 1∞。化为指数：
原式 = elimx→0 ln(1 + sin x)x。
指数上的极限：ln(1 + sin x) ~ sin x ~ x，故 ln(1 + sin x)x = ln(1 + sin x)sin x · sin xx → 1 · 1 = 1。
所以原式 = e。

这里连续用了两次连续性：e(·) 连续（把极限搬到指数上），ln 连续（在 u → 1 附近可展开）。两个「搬」都要有依据。

例 4　说明 y = √(cos x − 1) 在定义域内不连续。

解　先求定义域：要求 cos x − 1 ≥ 0，而 cos x − 1 ≤ 0 恒成立，故只能 cos x − 1 = 0，即 x = 2kπ（k ∈ Z）。
定义域是孤立点集 {2kπ}，不含任何区间。每个 2kπ 的任何去心邻域内都有无定义的点，谈不上极限，更谈不上连续。
所以该函数在定义域内处处不连续。

这题专治「初等函数都连续」的误用。正确表述是「初等函数在其定义区间内连续」，孤立点不算定义区间。判断题里出现这类「只在孤立点有定义」的构造，选「不连续」。

易错提醒：① 「初等函数在定义域内连续」是错的，应为「定义区间」；② 端点只能单侧连续，别写双侧；③ 把极限搬进函数前，确认外层在该点连续；④ 幂指函数要求底数 u > 0，否则 ln u 无意义。

一、为什么要「闭区间」加「连续」两个条件

这一节的四个定理，条件看起来啰嗦，其实每条都卡掉一类反例。闭区间卡的是端点：f(x) = 1/x 在 (0, 1) 上连续，但无界，也没有最大值——因为它跑到 1 附近就冲上无穷，开区间丢掉了端点这个「兜底」。连续卡的是断点：f(x) = 1/x 在 [0, 1] 上？不行，0 处根本没定义。再看 f(x) = x（0 ≤ x < 1），f = 1（x = 1），在 [0,1] 上有界却取不到最大值 1——跳跃让「取到」落空。所以：闭 + 连续，缺一不可。这一节的定理，是把「曲线是一条不断的、有头有尾的线」这句话翻译成四条可用的结论。

二、有界性与最值定理

定理 1（有界性）　若 f 在闭区间 [a, b] 上连续，则 f 在 [a, b] 上有界，即存在 M > 0 使 |f(x)| ≤ M 对一切 x ∈ [a, b] 成立。

定理 2（最值定理）　在同样条件下，f 在 [a, b] 上必能取到最大值 M 与最小值 m，即存在 ξ1, ξ2 ∈ [a, b] 使 f(ξ1) = M，f(ξ2) = m，且 m ≤ f(x) ≤ M。

证明思路：有界性用反证。若在 [a, b] 上无界，则对每个 n 都能找到 xn 使 |f(xn)| > n。由致密性定理，{xn} 有收敛子列 xnk → ξ ∈ [a, b]；由 f 连续得 f(xnk) → f(ξ) 是有限数，与 |f(xnk)| > nk → ∞ 矛盾。最值定理在上界的基础上再取一次极限：设 M = sup f，取 f(xn) → M，同样抽收敛子列，由连续性得 M = f(ξ)，即上确界被取到。

三、零点定理与介值定理

定理 3（零点定理）　若 f 在 [a, b] 上连续，且 f(a) · f(b) < 0，则存在 ξ ∈ (a, b) 使 f(ξ) = 0。

直观：曲线从 x 轴下方出发，最后落在上方，中间不断，就必须穿过 x 轴至少一次。这是证明「方程有根」的万能钥匙，用法固定：把方程整理成 f(x) = 0，找一个闭区间，验连续、验两端异号。

定理 4（介值定理）　若 f 在 [a, b] 上连续，μ 是介于 f(a) 与 f(b) 之间的任何数，则存在 ξ ∈ (a, b) 使 f(ξ) = μ。

证明只需对 F(x) = f(x) − μ 用零点定理：F(a) 与 F(b) 异号。所以零点定理是介值定理在 μ = 0 时的特例；而介值定理又是最值定理（取到 m 与 M）的推论——μ 介于 m 与 M 之间，必介于某两点的函数值之间。三者的逻辑链是：最值定理 ⟹ 介值定理 ⟹ 零点定理。考试里最常用的是最后一环，但证明「存在 ξ 使 f(ξ) 等于某个中间值」时，直接用介值定理更快。

四、方程有根：存在靠定理，唯一靠单调

「证明方程在 (a, b) 内有且仅有一个根」是每年必考的题型，套路固定为两段：

  • 存在性：令 f(x) = 左边 − 右边，验证 f 在 [a, b] 连续、f(a) 与 f(b) 异号，由零点定理得至少一根；
  • 唯一性：证 f 在 (a, b) 内严格单调（f′(x) > 0 或 < 0，或直接用单调性定义），故至多一根。两段合起来就是「有且仅有一根」。

如果区间端点不方便算函数值，可以先估计：利用连续性与极限，找两点使符号相反即可，不必是端点。若题目只问「至少有一个根」，那就只做存在性，别画蛇添足去证唯一。

例 1　证明方程 x = cos x 在 (0, 1) 内有且仅有一个根。

解　令 f(x) = x − cos x，它在 [0, 1] 上连续。
存在性：f(0) = 0 − 1 = −1 < 0，f(1) = 1 − cos 1 > 0（因 cos 1 < 1）。由零点定理，存在 ξ ∈ (0, 1) 使 f(ξ) = 0，即 ξ = cos ξ。
唯一性：f′(x) = 1 + sin x ≥ 0，且等号只在孤立点成立，故 f 在 [0, 1] 上严格单调增加，零点至多一个。
综上，方程在 (0, 1) 内有且仅有一个根。

唯一性这一步，1 + sin x 会取到 0（在 x = 3π/2），但那是区间外的孤立点，不影响 [0,1] 上的严格单调。写的时候要把这句补上，否则「≥ 0」推不出「严格」。

例 2　证明方程 x³ − 4x² + 1 = 0 在 (0, 1) 内至少有一个根。

解　令 f(x) = x³ − 4x² + 1，多项式在 [0, 1] 上连续。
f(0) = 1 > 0；f(1) = 1 − 4 + 1 = −2 < 0。
两端异号，由零点定理，存在 ξ ∈ (0, 1) 使 f(ξ) = 0，即方程在 (0, 1) 内至少有一个根。

注意题目只说「至少有一个」，所以只做存在性。算端点值时优先挑 0、1、−1 这种好算的点；若 f(0) 与 f(1) 同号，就换区间或换点，比如试 f(2)。

例 3　设 f 在 [0, 1] 上连续，f(0) = 0，f(1) = 1。证明存在 ξ ∈ [0, 1] 使 f(ξ) = 12。

解　1/2 介于 f(0) = 0 与 f(1) = 1 之间，且 f 在 [0, 1] 上连续。由介值定理，存在 ξ ∈ [0, 1] 使 f(ξ) = 1/2。

这题用介值定理一句话就完。若硬套零点定理，要构造 F(x) = f(x) − 1/2 再验异号，反而多写两步。看到「等于某个中间值」，先想介值。

例 4（提高）　证明方程 x · 2x = 1 在 (0, 1) 内有且仅有一个根。

解　令 f(x) = x · 2x − 1，在 [0, 1] 上连续。
存在：f(0) = −1 < 0，f(1) = 2 − 1 = 1 > 0，由零点定理至少一根。
唯一：f′(x) = 2x + x · 2x ln 2 = 2x(1 + x ln 2) > 0（x > 0），故 f 严格单调增加，零点至多一个。
所以 (0, 1) 内有且仅有一个根。

求导证单调前，先把 2x 提出来，符号一眼看出。若不想用导数，也可以说 x 与 2x 都单增，乘积单增——这在第一章更「合法」。

易错提醒：① 定理条件里的「闭区间」和「连续」缺一不可，答题时要写明「在 [a, b] 上连续」；② 零点定理给的是开区间 (a, b) 内的点，别写成闭区间；③ 「有且仅有一个」必须两段都做，只做存在性要扣一半分；④ 用导数证唯一时，注意 f′ ≥ 0 只在孤立点为 0 才够「严格」。
