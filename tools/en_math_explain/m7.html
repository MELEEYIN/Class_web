一、从"已知斜率求曲线"说起

给函数求导数是"顺着来"；反过来，已知曲线上每一点的切线斜率，要问这条曲线是什么，就是微分方程。比如"任一点处切线斜率等于该点的横坐标"，翻译过来就是 y′ = x。这里的未知量不再是数，而是一个函数。

物理里到处都是这种句式：落体 m dvdt = mg − kv、衰变 dNdt = −λN、单摆 θ″ + glθ = 0——已知的都是"变化率"，要求的都是函数本身。所以本章是微分运算的逆运算，手段是积分，每积一次冒出一个任意常数。

二、定义

定义 1　含有未知函数及其导数（或微分）的方程叫微分方程；未知函数是一元的叫常微分方程，含偏导数的叫偏微分方程。本章只讨论前者。

定义 2（阶）　方程中出现的最高阶导数的阶数。y″ + y = 0 是二阶；(y′)³ + y = 0 仍是一阶——阶只看导数的阶，与幂次无关。

定义 3（线性）　能写成

y(n) + a1(x) y(n−1) + … + an(x) y = f(x)

的称线性，即 y 及其各阶导数都只以一次方出现、彼此不相乘、不被复合；系数里出现 x 的函数不影响线性。故 y″ + y′ sin x = ex 是二阶线性，而 y′ + y² = 0、y y″ = 1、y″ + sin y = 0 都是非线性的。

定义 4（解、通解、特解）　代入后使方程成为恒等式的函数叫解；含独立任意常数且个数等于阶数的解叫通解；常数取定后的解叫特解。

定义 5（初始条件）　n 阶方程给 n 个条件：y(x0) = y0, y′(x0) = y′0, …, y(n−1)(x0) = y0(n−1)。带初始条件求解叫初值问题。

定义 6（积分曲线）　每个解对应 xOy 面上一条曲线，称为积分曲线；初始条件就是"曲线过某点"。

三、为什么通解恰有 n 个常数

每积分一次产生一个常数，n 阶方程要把 y(n) 积回 y，至少积 n 次，故有 n 个。严格依据是存在唯一性定理：若 f(x, y) 在 (x0, y0) 邻域内连续且对 y 满足李普希茨条件，则 y′ = f(x, y), y(x0) = y0 在该邻域内有且只有一个解。于是积分曲线族铺满平面而互不相交，一点定一条，定位参数正好 n 个。

这也解释了两条常识：初始条件多了会矛盾、少了定不下来；以及解完必须回代——积分变形（除、平方、取对数）可能添解或丢解。

四、例题

例 1　判阶与线性：x² y″ + x y′ − y = 0；y′ = x + y²；y″ + y′ sin x = ex；(y′)² + y = 0。

解　依次为：二阶线性（系数是 x 的函数不影响线性）；一阶非线性（出现 y²）；二阶线性（sin x 只是系数）；一阶非线性（阶看导数，y′ 被平方只影响线性）。

例 2　验证 y = C1 cos x + C2 sin x 是 y″ + y = 0 的通解，并求 y(0) = 1, y′(0) = 0 的特解。

解　y′ = −C1 sin x + C2 cos x，y″ = −C1 cos x − C2 sin x。两式相加得 y″ + y = 0，恒成立，故是解。
二阶方程而解含两个独立常数（cos x 与 sin x 之比不是常数），故是通解。
代条件：C1 = 1，C2 = 0，特解 y = cos x。

例 3　一曲线过 (1, 2)，且任一点处切线斜率等于 2x，求该曲线。

解　条件即 y′ = 2x。积分得 y = x² + C（一个常数，与一阶相符）。代入 y(1) = 2：2 = 1 + C，C = 1。故 y = x² + 1。

五、易错提醒与后文联系

  • 阶 ≠ 次数。看最高阶导数，不看幂次。
  • 线性 ≠ 简单。系数多复杂都不破坏线性；只有"y 与导数一次、不互乘、不复合"才是标准。
  • 通解常数的个数必须等于阶数且独立；写完全解先数一遍常数。
  • 初始条件个数也等于阶数；解完回代检验。

本节是全章的语言。后面判断特征根重数、数常数、判线性无关，本质都在回答同一个问题：这个方程该有几个常数、解该长什么样。

一、能"分离"的样子

一阶方程最理想的情形，是右端能拆成两个因子的乘积：一个只含 x，一个只含 y。

y′ = xy = x · y,　y′ = ex+y = ex · ey,　y′ = 1 + y²1 + x²

一旦拆开，就能把含 y 的连同 dy 挪到左边、含 x 的连同 dx 挪到右边，两边各只含一个变量，分别积分即可。这是本章最机械也最常用的一招——后面齐次方程、伯努利方程，归根到底都是化归到它。

二、定义与步骤

定义　形如 dydx = f(x) g(y) 的方程称可分离变量的微分方程（f, g 连续）。

  1. 分离：g(y) ≠ 0 时两边除以 g(y)、乘 dx，得 dyg(y) = f(x) dx。
  2. 积分：∫ dyg(y) = ∫ f(x) dx + C，常数只写一个。
  3. 化简：能解出 y 写显式解，解不出就保留隐式解，同样合格。
  4. 定常数：有初始条件时代入求 C。

三、为什么能两边各自积分

设 y = φ(x) 是解，则 φ′(x) = f(x) g(φ(x))。当 g(φ) ≠ 0 时两边除以 g(φ) 再对 x 积分：

∫ φ′(x)g(φ(x)) dx = ∫ f(x) dx

左端令 u = φ(x)，du = φ′(x) dx，正是 ∫ dug(u)。所以"分离后各自积分"不是把微分当分数乱乘，而是换元积分法的简写。

四、丢解：必须单独检查

分离时要求 g(y) ≠ 0。若 g(y0) = 0，则 y ≡ y0 也是解（此时 y′ = 0，右端也 = 0），但它被除掉了，可能不在通解中。

例：y′ = y²，分离得 −1y = x + C，即 y = −1x + C；而 y ≡ 0 也是解，却要 C → ∞ 才趋于它，须单独补上。规范做法：解完把所有使 g(y) = 0 的常数函数代回验证，成立的补列。

五、例题

例 1　求 y′ = xy 满足 y(0) = 1 的特解。

解　分离 dyy = x dx；积分 ln|y| = 12x² + C1；去对数 |y| = eC1 ex²/2，记 C = ±eC1，得 y = C ex²/2。
代 y(0) = 1 得 C = 1，故 y = ex²/2。
g(y) = y 在 y = 0 为零，y ≡ 0 对应 C = 0，已含在通解中，无须另列。

例 2　求 y′ = ex+y 的通解。

解　拆成 ex ey，分离 e−y dy = ex dx；积分 −e−y = ex + C，即 ex + e−y = C。也可解出 y = −ln(C − ex)，要求 C − ex > 0。因 ey 恒不为零，本题无丢解。

例 3　求 y′ = 1 + y²1 + x² 满足 y(0) = 1 的特解。

解　分离 dy1 + y² = dx1 + x²；积分 arctan y = arctan x + C；代 (0, 1) 得 C = π4。
两边取正切，用 tan(A + B) = tan A + tan B1 − tan A tan B，得 y = x + 11 − x，定义区间 (−∞, 1)。

六、常考套路与易错提醒

识别：右端能否写成纯乘积。能就一定可分离；不能则看是否同次齐次（第三节）或令 u = x + y 型整体代换。

  • 常数只写一个。两个积分常数合并进 C 即可。
  • 对数带绝对值：∫ dyy = ln|y|。
  • 去对数时把常数写成一整个新常数，允许它取 0 就顺手补上了丢解。
  • 必查 g(y) = 0，这是选择题最常见的区分点。
  • 隐式解不扣分，解不出 y 时保留 Φ(x, y) = C 即可。

本节是后面所有解法的终点：齐次方程、一阶线性、可降阶方程，最终都落回"分离 → 积分"。

一、斜率只跟比值有关

看 y′ = x + yx。它拆不成乘积，但分子分母都是 x, y 的一次齐次式，上下同除 x 后右端变成 1 + yx，只依赖 y/x。

几何含义很清楚：从原点出发的每条射线 y = kx 上，y/x 恒为 k，所以这条射线上所有点的切线方向相同。这类曲线像"从原点散开的一束花"。既然斜率只跟 y/x 有关，就把它当成新的未知函数。

二、定义

定义　形如

dydx = φ yx

的方程称齐次方程（注意与"线性齐次"含义不同）。判别常用微分形式：P dx + Q dy = 0，若 P, Q 是同次齐次函数（P(tx, ty) = tkP(x, y)），则方程齐次，因为 dydx = −PQ 除以 xk 后只剩 y/x。

实用判别：数每一项中 x 与 y 的幂次之和是否相同。x² + y²、xy、x³ − 2xy² 都是齐次式；x + y²、x² + 1 不是。

三、代换与推导

令 u = yx，即 y = ux。注意 u 是 x 的函数，求导必须用乘积法则：

y′ = u + x dudx

代入 y′ = φ(u)：u + x u′ = φ(u)，移项 x u′ = φ(u) − u，两边已分离：

duφ(u) − u = dxx

积分后把 u 换回 y/x 即得通解。五步流程：判齐次 → 令 u = y/x → 代入整理 → 分离积分 → 回代。

四、变体：一次分式型

形如 a1x + b1y + c1a2x + b2y + c2 时：

①两直线相交（a1/a2 ≠ b1/b2）：解出交点 (x0, y0)，令 X = x − x0, Y = y − y0，常数项消掉，化为关于 X, Y 的齐次方程。

②两直线平行（a1/a2 = b1/b2 = λ）：右端只是 a2x + b2y 的函数，令 u = a2x + b2y，则 u′ = a2 + b2y′，化为可分离方程。

另有一类 y′ = f(ax + by + c)，令 u = ax + by + c 即可，因 u′ = a + b f(u)。

五、例题

例 1　求 y′ = yx + tan yx 的通解。

解　令 u = y/x，y′ = u + x u′，代入得 u + x u′ = u + tan u，故 x u′ = tan u。
分离 cot u du = dxx；积分 ln|sin u| = ln|x| + C1；化简 sin u = Cx。
回代得 sin yx = Cx。tan u = 0 即 y = kπx 也是解，对应 C = 0，已含。

例 2　求 (x² + y²) dx − xy dy = 0 的通解。

解　P, Q 都是 2 次齐次式，故齐次。改写 dydx = xy + yx = 1u + u，令 u = y/x。
代入 u + x u′ = 1u + u，得 x u′ = 1u；分离 u du = dxx；积分 12u² = ln|x| + C。
回代：y² = 2x²(ln|x| + C)。

例 3　求 y′ = x + y − 2x − y 的通解。

解　先求交点：x + y − 2 = 0, x − y = 0 得 (1, 1)。令 X = x − 1, Y = y − 1，右端化为 X + YX − Y。
令 u = Y/X：u + X u′ = 1 + u1 − u，得 X u′ = 1 + u²1 − u，分离 1 − u1 + u² du = dXX。
积分：arctan u − 12ln(1 + u²) = ln|X| + C，再回代 u = (y − 1)/(x − 1)。

六、常考套路与易错提醒

识别顺序：能拆乘积 → 第二节；数次数同次 → 本节；含一次分式 → 平移或整体代换。

  • 头号错误：把 y′ 写成 u′。正确的是 y = ux ⟹ y′ = u + x u′，那个 u 项不能漏。
  • 漏掉 −u：必须得到 x u′ = φ(u) − u，直接写 x u′ = φ(u) 会积不出来。
  • 最后必回代，答案不能停在 u 上。
  • φ(u) − u = 0 的解要单独检查（对应 y = kx 型直线解）。
  • 平移后要换回 X = x − x0, Y = y − y0。
  • 别与"线性齐次"混。本节的齐次指 φ(y/x) 型。

"看结构 → 选代换 → 化归已知"这套思路，第五节 p = y′、第九节 x = et 都是它的升级版。

一、为什么这一类值得背公式

y′ + yx = 3x²、y′ − 2xy = ex² 都拆不成乘积，但 y 与 y′ 都是一次、系数只依赖 x。这类叫一阶线性微分方程，是一阶里唯一有通用求积公式的类型。RC 电路 RC u′ + u = E、牛顿冷却 T′ = −k(T − T0) 都是它。

二、标准形

定义　形如

y′ + P(x) y = Q(x)

的方程叫一阶线性方程；Q ≡ 0 为齐次，Q ≢ 0 为非齐次。

关键：系数必须是 1。否则先除：xy′ + 2y = x³ 先除 x 得 P = 2/x, Q = x²；y′ = xy + sin x 移项得 P = −x, Q = sin x。这一步错了后面全错，而且公式照样算得出来，不易察觉。

三、齐次解与通解公式

齐次：y′ + Py = 0 可分离，dyy = −P dx，得

y = C e−∫ P dx

常数变易法：设 y = C(x) e−∫P dx，求导

y′ = C′ e−∫P − C P e−∫P

代入 y′ + Py = Q，后两项正好抵消（这是设计好的），得 C′ e−∫P = Q，即 C′ = Q e∫P。再积一次 C = ∫ Q e∫P dx + C，于是

y = e−∫P dx [∫ Q e∫P dx dx + C]

积分因子法：两边乘 μ = e∫P dx，因 μ′ = Pμ，左端恰为 (μy)′，积分即得同式。这个视角更值钱：解一阶线性的全部技巧，就是找因子把左边凑成一个导数。考场记不清公式就现场凑。

四、例题

例 1　求 y′ − yx = x² (x > 0) 的通解。

解　P = −1/x, Q = x²，∫P dx = −ln x，故 e−∫P = x，e∫P = 1/x。
y = x [∫ x² · 1x dx + C] = x (12x² + C)，故 y = 12x³ + Cx。
验算：y′ − yx = 32x² + C − 12x² − C = x² ✓。

例 2　求 y′ + y = e−x 的通解。

解　P = 1，e−∫P = e−x，e∫P = ex。
y = e−x[∫ e−x ex dx + C] = e−x[∫1 dx + C]，故 y = (x + C) e−x。
右端恰好是齐次解的倍数，所以特解呈 x e−x 型——第八节"重根乘 x"的雏形。

例 3（以 x 为未知函数）　求 y′ = 1x + y 的通解。

解　对 y 非线性，但取倒数得 dxdy = x + y，即 dxdy − x = y，这是 P = −1, Q = y 的线性方程。
∫P dy = −y，e−∫P = ey，e∫P = e−y。
x = ey[∫ y e−y dy + C]，而 ∫ y e−y dy = −(y + 1) e−y，故

x = C ey − y − 1

验算：dx/dy = C ey − 1 = x + y ✓。

例 4（伯努利）　求 y′ + 1x y = y² ln x (x > 0) 的通解。

解　两边除 y²：y−2y′ + 1xy−1 = ln x。令 z = y−1，则 z′ = −y−2y′，代入得

z′ − 1x z = −ln x

P = −1/x，e−∫P = x，z = x[∫(−ln x)1xdx + C] = x[C − 12(ln x)²]。
回代 z = 1/y：y = 1x[C − (ln x)²/2]。又 y ≡ 0 也是解（除 y² 时丢掉），须补。

五、常考套路与易错提醒

伯努利方程 y′ + Py = Qyn（n ≠ 0, 1）：除 yn，令 z = y1−n，得

z′ + (1 − n) P z = (1 − n) Q

以 x 为未知函数：分母里出现 y 的一次式（如 y′ = 1/(x + y)）时，翻转 dx/dy 往往立刻变线性。

  • 先化标准形，系数必须是 1。
  • 指数位置：外负内正。外面 e−∫P 负责"除掉"，括号里乘 e∫P 负责"配上"。
  • ∫P dx 不加常数；积分常数只在括号里加一次。
  • 伯努利的 (1 − n) 别漏；n > 0 时 y ≡ 0 要另列。
  • 解完回代。

本节的"齐次解 + 特解"结构、积分因子"凑导数"思想，分别是第六节定理与第八节待定系数法的源头。

一、二阶不好解，但缺项就能降阶

二阶方程 y″ = f(x, y, y′) 一般没有初等解法。但如果右端缺了某个变量，就有统一的降阶办法：把 y′ 整体当成新的未知函数 p，把二阶方程拆成两个一阶问题，连做两次积分。好比爬两层楼太累，就在中间搭个平台。

关键只有一件事：y″ 怎么用 p 表示。这取决于方程缺的是 y 还是 x——因为 p 的自变量要跟着换。

二、三类可降阶方程

类型一　y(n) = f(x)。右端只含 x，连续积分 n 次即可，每次带一个常数，最后正好 n 个常数，符合第一节的结论。

类型二　缺 y：y″ = f(x, y′)。令 p = y′(x)，这里 p 仍是 x 的函数，故

y″ = dpdx

方程降为 dp/dx = f(x, p)，这是一阶方程。解出 p = p(x) 后再积一次：y = ∫ p(x) dx + C2。

类型三　缺 x：y″ = f(y, y′)。此时令 p = y′ 并把 p 看成 y 的函数，自变量从 x 换成 y。由链式法则

y″ = dpdx = dpdy · dydx = p dpdy

方程降为 p dpdy = f(y, p)。解出 p = p(y) 后，再由 dydx = p(y) 分离积分。

初始条件也要跟着翻译：缺 y 用 p(x0) = y′(x0)；缺 x 用 p(y0) = y′(x0)，注意括号里的自变量是 y0。

三、例题

例 1（类型一）　求 y‴ = x 满足 y(0) = 1, y′(0) = 0, y″(0) = 0 的特解。

解　第一次积分 y″ = 12x² + C1，由 y″(0) = 0 得 C1 = 0。
第二次 y′ = 16x³ + C2，由 y′(0) = 0 得 C2 = 0。
第三次 y = 124x⁴ + C3，由 y(0) = 1 得 C3 = 1。故 y = 124x⁴ + 1。
技巧：每积一次就把条件用掉一个，比最后一起代更省力。

例 2（缺 y）　求 x y″ + y′ = 0 (x > 0) 的通解。

解　方程里没有 y，令 p = y′，y″ = p′，得 x p′ + p = 0。
分离 dpp = −dxx，积分 ln|p| = −ln x + C1，得 p = C1x。
回代积分：y = C1 ln x + C2。
另解：注意到 x y″ + y′ = (x y′)′，直接得 x y′ = C1，更快。这类"凑成一个导数"的眼力值得练。

例 3（缺 x）　求 y y″ − (y′)² = 0 的通解。

解　方程里没有 x，令 p = y′(y)，y″ = p dpdy，代入得

y p dpdy − p² = 0

先看 p = 0：即 y′ = 0，y = C 是解（显然满足原方程）。
设 p ≠ 0，两边除 p：y dpdy = p，分离 dpp = dyy，积分 ln|p| = ln|y| + C1，得 p = C1 y。
再解 dydx = C1 y：分离积分得 y = C2 eC1x。取 C1 = 0 即常数解，故通解为 y = C2 eC1x。

四、易错提醒

  • 缺 y 用 p(x)，缺 x 用 p(y)。判断依据是方程里真正没出现的是哪个变量，选错基本算不下去。
  • 缺 x 时 y″ = p · dp/dy，那个乘在前面的 p 是链式法则带来的，不能丢。
  • 常数个数仍等于阶数：降阶只是换了自变量，不改变方程阶数对应的常数总量。
  • 解出 p 必须回代再积一次，不要停在 p 上。
  • 除掉的因子要交代（如 p = 0、y = 0）。

降阶思想在第九节还会以另一种面貌出现：欧拉方程用 x = et 换自变量，也是"换个视角把难题变简单"。

一、线性让"结构"代替"解法"

y″ + y = 0 有解 cos x 与 sin x，而 3 cos x − 2 sin x 也是解。为什么？因为求导是线性的：把 C1y1 + C2y2 代入，常数可以提出来，最后归并成 C1·0 + C2·0 = 0。

这说明齐次线性方程的解全体构成一个线性空间：能加、能乘常数。于是问题从"怎么解"变成"只要凑够一组基底"。这种"先看结构、再定系数"的思路是整章的主线。

二、齐次方程解的结构

本节讨论

y″ + p(x) y′ + q(x) y = f(x)

其中 p, q, f 在区间 I 上连续；f ≡ 0 为齐次，否则非齐次。

定理 1（叠加原理）　若 y1, y2 是齐次方程的解，则 C1y1 + C2y2 也是解。

定义（线性相关）　若存在不全为零的常数 k1, …, kn 使 k1y1 + … + knyn ≡ 0，称它们线性相关，否则线性无关。两个函数无关 ⟺ 比值不是常数（不成比例）。

定义（朗斯基行列式）　二阶为

W(x) = y1 y2′ − y1′ y2

n 阶为由 yi 及其 0 到 n−1 阶导数排成的 n 阶行列式。

定理 2（通解结构）　若 y1, y2 是二阶齐次方程的两个线性无关解，则 y = C1y1 + C2y2 是通解；若相关，则只是特解的一部分，不是通解。

定理 3（无关的判据）　对二阶齐次方程的两个解，W(x) ≠ 0 ⟺ 线性无关；且 W 要么处处非零、要么处处为零，因为

W(x) = W(x0) e−∫ p dx

所以只要在某一点算一下 W 就能判无关，这是考试里最省事的办法。

三、非齐次方程解的结构

定理 4　若 y* 是非齐次方程的一个特解，Y = C1y1 + C2y2 是对应齐次方程的通解，则

y = Y + y*

是非齐次方程的通解。证明两句话：①代入得 L[Y + y*] = L[Y] + L[y*] = 0 + f = f；②若 y 是任一解，则 L[y − y*] = f − f = 0，故 y − y* 是齐次解，即 y = Y + y*。几何上：非齐次解族是齐次解族整体平移。

定理 5（叠加）　若 y1*、y2* 分别是右端 f1、f2 的特解，则 y1* + y2* 是右端 f1 + f2 的特解。推论：非齐次方程两个特解之差是齐次方程的解。

四、已知一解求另一解（降阶）

把方程化为标准形 y″ + p y′ + q y = 0，设已知非零解 y1，令 y = y1 u 代入可降为一阶，解得

y2 = y1 ∫ e−∫ p dxy1² dx

记法：分子是"指数"，分母是 y1²。用之前务必先化标准形，否则 p 取错。

五、例题

例 1　验证 ex, e2x 是 y″ − 3y′ + 2y = 0 的无关解，并写通解。

解　代 ex：1 − 3 + 2 = 0 ✓；代 e2x：4 − 6 + 2 = 0 ✓。
无关：比值 ex/e2x = e−x 不是常数；或算 W = ex·2e2x − ex·e2x = e3x ≠ 0。
故通解 y = C1ex + C2e2x。

例 2　已知 y1 = x 是 x² y″ − 2x y′ + 2y = 0 的解，求通解。

解　先化标准形（除 x²）：y″ − 2xy′ + 2x²y = 0，故 p = −2/x，e−∫p dx = e2 ln x = x²。
y2 = x ∫ x²x² dx = x ∫1 dx = x · x = x²。
通解 y = C1x + C2x²（直接验证也对）。

例 3　已知 y* = x 是 y″ + y = x 的解，写通解并求 y(0) = 1, y′(0) = 0。

解　齐次解 cos x, sin x 无关（W = 1），故通解 y = C1cos x + C2sin x + x。
代条件：y(0) = C1 = 1；y′(0) = C2 + 1 = 0，C2 = −1。
故 y = cos x − sin x + x。

六、易错提醒

  • 无关 ≠ 不同。x 与 2x 是两个函数，但线性相关。
  • 对线性方程的解，算一点的 W 即可；但若给的不是解，W ≠ 0 才等价于无关（这是定理条件）。
  • 用刘维尔公式前先化标准形，y″ 的系数必须是 1。
  • 通解里的两个解必须无关，否则常数不够用。
  • 特解只要一个，不带任意常数；凑特解时越简单越好。
  • 叠加原理只对线性方程成立，非线性方程不能拆。

本节把"解方程"变成了"找齐基 + 找一个特解"，后两节正是分别解决这两件事：第七节给出齐次基，第八节给出特解的设法。

一、为什么可以"猜"

解 y″ + p y′ + q y = 0（p, q 为常数）时有个好消息：求导不改变函数的类型。erx 求导还是 erx 的倍数，代入后可以把 erx 整体提出来，只剩一个关于 r 的代数方程。于是微分方程变成了初中的一元二次方程。

二、特征方程

设 y = erx，则 y′ = r erx，y″ = r² erx。代入并除以 erx ≠ 0，得

r² + p r + q = 0

称为特征方程，其根叫特征根。作法就是逐项替换：y(k) → rk（y → 1）。

三、三种情形与通解

① Δ = p² − 4q > 0，相异实根 r1, r2。er1x 与 er2x 之比 e(r2−r1)x 非常数，无关，故

y = C1 er1x + C2 er2x

② Δ = 0，二重根 r1 = r2 = r = −p/2。只得到一个解 erx，不够。令 y = erx u 代入化简，得 u″ = 0，故 u = C1 + C2x，于是

y = (C1 + C2x) erx

也可以用第三节的刘维尔公式：p = −2r，e−∫p dx = e2rx，y2 = erx∫1 dx = x erx。结论要记死：重根时第二个解必须乘 x。

③ Δ < 0，共轭复根 r = α ± βi，其中 α = −p/2，β = 12√(4q − p²)。形式上得 e(α+iβ)x，用欧拉公式

e(α+iβ)x = eαx(cos βx + i sin βx)

取实部与虚部即得两个实解 eαxcos βx、eαxsin βx（比值 tan βx 非常数，无关），故

y = eαx(C1 cos βx + C2 sin βx)

直观：α 管幅值的增减（α < 0 衰减、α = 0 等幅、α > 0 发散），β 管振荡的快慢。弹簧阻尼、RLC 振荡全是这三行。

四、推广到 n 阶

特征方程 rn + a1rn−1 + … + an = 0 的每个根按下面规则产生解，最后全部相加，常数总数等于阶数：

  • 单实根 r：C erx。
  • k 重实根 r：(C1 + C2x + … + Ckxk−1) erx。
  • 单复根 α ± βi：eαx(C1cos βx + C2sin βx)。
  • k 重复根：上式的括号里再分别乘 1, x, …, xk−1。

五、例题

例 1　解 y″ − 5y′ + 6y = 0。

解　r² − 5r + 6 = 0，(r − 2)(r − 3) = 0，r = 2, 3。相异实根，y = C1e2x + C2e3x。

例 2　解 y″ + 4y′ + 4y = 0，y(0) = 2, y′(0) = 0。

解　r² + 4r + 4 = (r + 2)² = 0，r = −2（二重），故 y = (C1 + C2x)e−2x。
y(0) = C1 = 2。求导 y′ = [C2 − 2(C1 + C2x)]e−2x，故 y′(0) = C2 − 2C1 = C2 − 4 = 0，C2 = 4。
y = (2 + 4x)e−2x。提醒：求 y′ 要用乘积法则，别写成 C2e−2x。

例 3　解 y″ + 2y′ + 5y = 0。

解　r² + 2r + 5 = 0，r = −2 ± √(4 − 20)2 = −1 ± 2i，α = −1, β = 2。
y = e−x(C1cos 2x + C2sin 2x)。这是衰减振荡：振幅按 e−x 衰减，周期 π。

例 4　解 y‴ − y′ = 0。

解　r³ − r = r(r − 1)(r + 1) = 0，r = 0, 1, −1。三个单实根，
y = C1 + C2ex + C3e−x。注意 r = 0 给的是常数解，别漏。

六、易错提醒

  • 重根必乘 x。写成 C1erx + C2erx 等于只有一个常数。
  • 复根别丢实部：一定是 eαx(…)，α = 0 时才没有因子 eαx。
  • β 是虚部：r = 1 ± 3i 对应 cos 3x, sin 3x。
  • r = 0 对应常数解，照写不误。
  • 常数个数 = 阶数，写完数一遍。
  • 反向题也常见：给出通解求方程，用韦达 r1 + r2 = −p、r1r2 = q 拼回去。

本节解决"齐次"，下一节解决"非齐次"——两者拼起来就是第八节的完整流程。

一、只剩"找一个特解"

本节解 y″ + p y′ + q y = f(x)（p, q 为常数）。由第六节定理 4，通解 = 齐次通解 + 一个特解。齐次部分第七节已经解决，所以现在的任务只是：给一个 f(x)，把 y* 找出来。

直接积分行不通。但 eλx、多项式、cos βx 求导后不跑出各自的家族：指数还指数、m 次多项式还 m 次、三角还三角。所以可以"猜形状、定系数"——这就是待定系数法。

二、类型一：f(x) = Pm(x) eλx

设

y* = xk Qm(x) eλx

其中 Qm 是与 Pm 同次的待定多项式（各项系数全部待定），而

k = λ 作为特征根的重数：λ 不是根取 0，是单根取 1，是二重根取 2。

为什么乘 xk？若 λ 是特征根，eλx 本身就是齐次方程的解，代入左端得 0，而右端非零，得到"0 = 非零"的矛盾式，系数无论怎么取都解不出来。这就是共振：外力频率恰好等于系统固有频率，响应被放大成 x 倍。乘 xk 就是把猜测推出齐次解空间。口诀：λ 撞了几次，就补几个 x。

定系数：算出 y*, y*′, y*″（三个因子相乘，用乘积法则），代入方程，合并同类项，令 xjeλx 的系数逐一相等，解线性方程组。

三、类型二：f(x) = eλx[Pl(x)cos βx + Qn(x)sin βx]

设

y* = xk eλx[Rs(x)cos βx + Ss(x)sin βx]

其中 s = max(l, n)，Rs, Ss 都是 s 次待定多项式；k 取 0（λ ± βi 不是特征根）或 1（是特征根）。二阶方程复根成对出现，所以 k 最多是 1。

两个要点：①sin 与 cos 必须成对设，哪怕右端只出现一个；②次数取较大者，两端多项式都写全。

四、例题

例 1　解 y″ − 3y′ + 2y = ex。

解　特征方程 r² − 3r + 2 = 0，r = 1, 2，齐次通解 Y = C1ex + C2e2x。
λ = 1 是单根，故 k = 1，设 y* = A x ex。求导：
y*′ = A(1 + x)ex，y*″ = A(2 + x)ex。
代入左端：A ex[(2 + x) − 3(1 + x) + 2x] = A ex(−1) = −A ex。
令 −A ex = ex，得 A = −1。故
y = C1ex + C2e2x − x ex。

例 2　解 y″ + y = x²。

解　r² + 1 = 0，r = ±i，Y = C1cos x + C2sin x。
f = x²e0x，λ = 0 不是根，k = 0，设 y* = ax² + bx + c。则 y*″ = 2a。
代入：(ax² + bx + c) + 2a = x²，比较系数：a = 1，b = 0，c + 2a = 0 即 c = −2。
y = C1cos x + C2sin x + x² − 2。

例 3（共振）　解 y″ + y = cos x。

解　Y = C1cos x + C2sin x。右端 λ = 0, β = 1，λ ± βi = ±i 正是特征根，故 k = 1，设
y* = x(A cos x + B sin x)。
求导两次（乘积法则）：
y*″ = −2A sin x + 2B cos x − x(A cos x + B sin x)。
与 y* 相加，带 x 的两项抵消：
y*″ + y* = −2A sin x + 2B cos x。
令其 = cos x：2B = 1，−2A = 0，得 B = 1/2，A = 0。故
y = C1cos x + C2sin x + 12x sin x。
x sin x 说明振幅随 x 无限增大，正是共振现象。

例 4（重根）　解 y″ − 2y′ + y = ex。

解　r² − 2r + 1 = (r − 1)² = 0，Y = (C1 + C2x)ex。λ = 1 是二重根，故 k = 2，设 y* = A x² ex。
由算子式 (D − 1)²[A x² ex] = 2A ex，令 2A = 1 得 A = 1/2。故
y = (C1 + C2x)ex + 12x² ex。

五、流程与易错提醒

标准流程：①解特征方程；②写出齐次通解 Y；③从 f 读出 λ（及 β）与次数 m；④对照特征根定 k；⑤设 y* 并代入比较系数；⑥相加。

  • k 判错必得"0 = 非零"，这是最快的自检信号。
  • 次数不能降：右端是 x² 就设到二次三项，系数为 0 也要写全。
  • 三角型必须双设，R 与 S 用不同字母。
  • 三个因子相乘用乘积法则；eλx 每次提出来约掉。
  • 最后别忘了加齐次通解，只写 y* 不是通解。
  • 首项系数不是 1 先化标准形（先把首项系数除掉）。
  • 右端为和时用叠加原理分别求再相加。

本节是"非齐次"的收官，第九节化归后也停在这里。

一、幂次配阶数

看这个方程：

x² y″ + x y′ − y = 0

每一项都是"x 的幂 × 相应阶的导数"，而且幂次恰好等于阶数：二阶配 x²、一阶配 x、零阶配 x⁰ = 1。这种方程叫欧拉方程（欧拉–柯西方程）。

为什么值得单独一节？因为常系数方程的解法极好，而欧拉方程只差一步换元。令 x = et（即 t = ln x，先设 x > 0），相当于把"乘法尺度"换成"加法尺度"——乘积变求和，欧拉方程就变成常系数方程。

二、代换公式的推导

由 t = ln x 得 dtdx = 1x。记算子 D = ddt。

一阶：由链式法则 dydx = dydt · dtdx = 1xdydt，两边乘 x：

x y′ = dydt = D y

二阶：把 x y′ = Dy 再对 x 求导，左边用乘积法则 (x y′)′ = y′ + x y″，右边对 x 求导得 1x D² y，所以

y′ + x y″ = 1xD² y

两边乘 x：x y′ + x² y″ = D² y，把 x y′ = Dy 代入即得

x² y″ = D² y − D y = D(D − 1) y

同理可得 x³ y‴ = D(D − 1)(D − 2) y，一般地

xk y(k) = D(D − 1) … (D − k + 1) y

必记三个：x y′ = Dy，x² y″ = (D² − D) y，x³ y‴ = (D³ − 3D² + 2D) y。

三、解题步骤

  1. 确认"幂次与阶数逐一相等"，否则不是欧拉方程。
  2. 令 x = et，把每个 xky(k) 换成对应的算子式。未知函数仍是 y，但自变量变成了 t。
  3. 按第七、八节解这个常系数方程，得到 y(t)。
  4. 回代 t = ln x：用 et = x、e−t = 1/x、t et = x ln x。

x < 0 怎么办？令 x = −et，即 t = ln|x|，此时 dt/dx = 1/x 依然成立，整个推导不变，只需把最后的 ln x 全部写成 ln|x|。答案里统一用 ln|x| 最稳妥。

四、例题

例 1　解 x² y″ + x y′ − y = 0。

解　代入 x y′ = Dy、x² y″ = (D² − D)y：
(D² − D)y + Dy − y = 0，即 (D² − 1)y = 0。
特征方程 r² − 1 = 0，r = ±1，故 y = C1et + C2e−t。
回代：y = C1x + C2x。

例 2（非齐次）　解 x² y″ − x y′ + y = x (x > 0)。

解　左端化为 (D² − D)y − Dy + y = (D² − 2D + 1)y，即 (D − 1)² y。右端 x = et，方程成为
(D − 1)² y = et。
齐次：(r − 1)² = 0 二重根，Y = (C1 + C2t)et。
非齐次：λ = 1 是二重根，k = 2，设 y* = A t² et。由 (D − 1)²[A t² et] = 2A et，令 2A = 1 得 A = 1/2。
故 y = (C1 + C2t)et + 12t² et，回代 t = ln x：

y = (C1 + C2 ln x) x + 12 x (ln x)²

例 3　解 x² y″ + x y′ = 1。

解　(D² − D)y + Dy = D² y = 1。
积分两次：Dy = t + C1，y = 12t² + C1t + C2。
回代：y = 12(ln x)² + C1 ln x + C2。

五、易错提醒

  • 识别口诀"幂次配阶数"，不配对就不是欧拉方程（如 x²y″ + y′ = 0 不是）。
  • 变体 (ax + b)ny(n) + … 时令 ax + b = et，链式法则多一个 a。
  • 别忘链式法则：这是换自变量，不是简单把 x 替换成 t。
  • x² y″ = (D² − D)y，不是 D²y。漏掉 −D 是最常见错误。
  • 解出 y(t) 必须回代，答案里不能留 t 或 D。
  • 回代别留 eln x，直接写成 x。
  • 答案常含 xr、xrln x、xαcos(β ln x)，属正常形态。
  • x < 0 时用 ln|x|；非齐次右端也要先换成 t 的表达式。

本节把变系数化为常系数，用的仍是"换元化归"这一贯穿全章的思路，与第三节的 u = y/x 同源。

一、从单个方程到方程组

真实系统很少只含一个变量：捕食者与猎物、两个耦合回路、串联的弹簧，都要用方程组描述。本节只讨论常系数线性组：

dxdt = a11x + a12y + f1(t),　dydt = a21x + a22y + f2(t)

好消息是：不需要任何新理论。办法只有一个——想办法把它化成一个高阶方程，然后交给第七、八节。

二、消元法

  1. 由第一个方程解出另一个未知函数（例如 y = x′ − a11x − f1）。
  2. 对所得式子关于 t 求导，得到 y′ 的表达式。
  3. 把 y 与 y′ 一起代入第二式，得只含 x 的二阶方程。
  4. 解出 x = x(t, C1, C2)。
  5. 回代求 y（这一步不能省）。

第五步为什么关键？题目问的是"方程组的解"，两个函数都必须给出，而且它们共用同一组常数。若 y 的表达式里含 x′，必须真的把 x 求导算出来，不能把 x′ 当符号留着。

三、矩阵法（与特征值对应）

把未知函数写成向量 X = (x, y)T，方程组即 X′ = AX。仿照一阶方程 y′ = ay 的解 y = C eat，猜 X = ξ eλt，代入得

λ ξ = Aξ,　即 (A − λE)ξ = 0

所以 λ 是 A 的特征值，ξ 是对应的特征向量。若有两个线性无关的特征向量，则

X = C1ξ1eλ1t + C2ξ2eλ2t

重根时乘 t、复根时取实部虚部，与第七节的三种情形一一对应。这说明：方程组的"特征值"就是消元后那个二阶方程"特征根"。

四、初始条件

几个未知函数就要几个初始条件。二元组给 x(t0) = x0, y(t0) = y0，代入通解得两个关于 C1, C2 的方程。注意别把 x 的条件错代进 y 的式子。

五、例题

例 1　解 x′ = 2x + y, y′ = 4x − y。

解　由第一式 y = x′ − 2x，求导 y′ = x″ − 2x′。
代入第二式：x″ − 2x′ = 4x − (x′ − 2x) = 6x − x′，整理得

x″ − x′ − 6x = 0

特征根 r² − r − 6 = 0，r = 3, −2，故 x = C1e3t + C2e−2t。
回代：y = x′ − 2x = 3C1e3t − 2C2e−2t − 2C1e3t − 2C2e−2t，即

y = C1e3t − 4C2e−2t

用矩阵法核对：A = [2, 1; 4, −1]，|A − λE| = λ² − λ − 6，特征值 3, −2，与消元法完全一致；对应特征向量 (1, 1)T、(−1/4, 1)T，也与上式系数吻合。

例 2　解 x′ = y, y′ = −x，并说明轨线的几何意义。

解　由第一式 y = x′，代入第二式：x″ = −x，即 x″ + x = 0。
解得 x = C1cos t + C2sin t，回代 y = x′ = −C1sin t + C2cos t。
于是 x² + y² = C1² + C2² 为常数，轨线是圆。
几何意义：这正是一个无阻尼振子（如理想单摆、LC 回路）——位置在转，速度始终垂直于位置，做匀速圆周运动。矩阵法：A = [0, 1; −1, 0]，特征值 ±i，虚根对应"环绕中心"的闭轨。

例 3　求例 1 中满足 x(0) = 1, y(0) = 0 的特解。

解　通解为 x = C1e3t + C2e−2t，y = C1e3t − 4C2e−2t。
代入 t = 0：C1 + C2 = 1，C1 − 4C2 = 0。
解得 C1 = 4/5，C2 = 1/5。故

x = 45e3t + 15e−2t,　y = 45e3t − 45e−2t

六、易错提醒

  • 回代不能省，两个函数共用同一组常数。
  • 回代求 y 时记得对 x 求导，别把 x′ 原样留下。
  • 别为 y 另立一套常数（写成 D1, D2 就错了）。
  • 消元时两处 y 都要换掉（第一式的 y 和第二式的 y′）。
  • 初始条件个数 = 未知函数个数。
  • 矩阵法要写特征向量，只写特征值凑不出解。
