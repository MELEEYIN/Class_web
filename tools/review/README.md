# 知识点复习（错题卡）

站点入口：`site/acm/review.html`（顶部导航「复习」）

## 入口

- 算法站首页顶栏最左：**复习**（主色高亮，返回主站左边）
- 题练场 / 复习页的顶部导航也有「复习」
- 侧栏没有单独条目——它不属于学习材料，是每天要看的一页

## 背景与外观

不另做一套。`review.html` 直接读算法站存在本机的 `localStorage['acm.wall']`：

```js
{p:'aurora', img:'data:image/jpeg;base64,...', blur:4, op:70, dim:30}
```

- 在算法站「外观」面板换预设 / 传图片 / 调模糊压暗，**这边刷新就同步**
- 两页都开着时，在算法站改完切回来，`storage` 事件会立刻让这边跟着变
- 没设背景时用站点原本的渐变底；设了背景就把那层渐变隐掉（`body.has-bg`）

## 数据流

```
tools/review/cards.md          ← 手写，唯一数据源
        │  python tools/review/md2review.py
        ▼
site/acm/review-data.js        ← 自动生成，勿手改
        │
        ▼
site/acm/review.html           ← 页面，读 window.__REVIEW_CARDS
```

## 三级结构

```
大类（型）        小类（知）              卡片
坑点          →  取模与溢出          →  C02 负数取模在 C++ 里是负的
                                      C03 int 存不下就静默溢出
知识点        →  二分查找            →  C06 lower_bound 找不到时返回 end()
思路          →  贪心与堆优化        →  C07 新值单调 ⇒ 用两个有序队列代替堆
```

- 大类只有三种：`坑点` / `知识点` / `思路`
- 小类随便起名，**同名的会自动归到一组**，组内按日期倒序
- 小类按卡片数量从多到少排（同类问题反复出现，就浮到最上面）

## 加一张卡

1. 在 `cards.md` 末尾追加（格式照抄已有的）：

```markdown
## C10 一句话标题
- 题: 题号
- 型: 坑点 / 知识点 / 思路
- 知: 小类名（如 下标与边界）
- 记: 2026-11-11

**现象**

错误代码，或错误的实际输出。要具体到能复现。

**原因**

为什么错，最好带一个具体数字。

**修法**

改哪一行、改成什么。
```

2. 重新编译：

```bash
python tools/review/md2review.py
```

3. 刷新页面。

## 卡片写作的三条规矩

1. **一坑一卡**。三个坑塞一张，复习时会一起模糊。
2. **「现象」只写错的**。正面必须是能让你"想不起来"的东西，才有回忆的价值。
3. **只增不改**。同一个坑又错了，新开一张（C07b），在旧卡里写"又错了"——重复次数本身就是信号。

## 小类怎么起名

不要起太细（一人一类就失去意义），也不要太粗（一类几十张就翻不动）。
按**错误的形态**分，而不是按题目分：

| 好 | 差 |
| :--- | :--- |
| 下标与边界、取模与溢出、内存与数组、输入输出 | 「B2082 的坑」「第三章的错」 |
| 二分查找、分治与递归、贪心与堆优化 | 「算法」「数据结构」 |

目标：**10~20 个坑之后，能一眼看出自己最常栽在哪一类**。目前 6 张坑点卡里，「下标与边界 / 取模与溢出 / 内存与数组」已经占了大半——这就是最该先补的地方。
