# 错题卡

> 一张卡 = 一个坑。只记"当时真的错过的"，不记教科书定义。
> `型` 只有三种：坑点 / 知识点 / 思路；`知` 是更细的分类，同类的卡会归到一起。
> 来源：26 道题复盘（约 60 处错误）+ 2026-11 这轮对话。

## C01 容器大小算少一格
- 题: P1908 / P1706 / P1157 / P2615
- 型: 坑点
- 知: 容器与越界
- 记: 2026-11-11

**现象**

```text
stl_vector.h:1253: Assertion '__n < this->size()' failed.
```

或者更糟：不报错，直接 RE / 读到脏数据。

```cpp
vector<int> cnt(9);        // n = 9，1-based 用 cnt[9]
poi num[800];              // 但 n² = 1521
vector<int> vec;           // 空容器直接 vec[i]
```

**原因**

1-based 下标时，**最大下标是 n，不是 n−1**，所以容量要 `n + 1`。

空容器更彻底：`size()` 是 0，任何下标都越界。

**修法**

```cpp
vector<int> cnt(n + 1);            // 1-based
int g[45][45];                     // 二维按最大 n 开满
vector<int> v; v.assign(n + 1, 0); // 全局只声明，main 里再定大小
```

## C02 题面的"第 i 个"是 1 起，vector 下标是 0 起
- 题: 1306 / 1292
- 型: 坑点
- 知: 容器与越界
- 记: 2026-11-10

**现象**

样例整体错位一位：

```text
你的输出 6569 / -5440       正确 6569 / 4121
```

**原因**

```cpp
A.erase(A.begin() + ix);        // 删的是第 ix+1 个
B.insert(B.begin() + iy, v);    // 插在第 iy+1 个之前
```

**修法**

```cpp
A.erase(A.begin() + (ix-1));
B.insert(B.begin() + (iy-1), v);
```

## C03 0-based 和 1-based 必须整套改
- 题: P1036 / P1157 / P1706 / P1618
- 型: 坑点
- 知: 循环边界
- 记: 2026-11-11

**现象**

各种"差一"：最后一个元素没被处理、最后一个空没填就输出、剪枝太紧漏解。

| 错写成 | 应为 |
| :--- | :--- |
| `if(d == n)` 输出 | `if(d > n)` |
| `i < n`（1-based） | `i <= n` |
| `n - end - 1`（1-based） | `n - end` |

**原因**

改了一半。下标体系是一个整体，改一处不改其余，一定差一。

**修法**

四件套一起改：

| 项目 | 0-based | 1-based |
| :--- | :--- | :--- |
| 数组大小 | `n` | `n + 1` |
| 读入 | `i=0; i<n` | `i=1; i<=n` |
| 初始 `last` | `-1` | `0` |
| 剩余个数 | `n-last-1` | `n-last` |

## C04 循环变量被内层 while 吃掉
- 题: B2082 / 1296
- 型: 坑点
- 知: 循环边界
- 记: 2026-11-09

**现象**

```cpp
for(int i = L;i<=R;i++){
    while(i>0){ ...; i/=10; }   // i 被减到 0
}
```

程序死循环，一行输出都没有（3 秒超时）。

**原因**

`while` 把外层循环变量 `i` 拆到 0，`for` 的 `i++` 又把它变回 1，`1 <= R` 永远成立。

**修法**

```cpp
int t = i;
while(t > 0){ ... t /= 10; }
```

## C05 `!c=='+'` 恒为 false
- 题: B2052
- 型: 坑点
- 知: 条件与逻辑
- 记: 2026-11-11

**现象**

```cpp
else if(!c=='+'||!c=='-'||!c=='*'||!c=='/')   // 分支永远进不去
```

**原因**

`!c` 是"c 为假"（字符 `'\0'` 才算假），结果只有 0/1，再和 `'+'`（43）比，永远不等。

**修法**

```cpp
else if(c!='+' && c!='-' && c!='*' && c!='/')
```

## C06 "都不是"要用 `&&`
- 题: B2052
- 型: 坑点
- 知: 条件与逻辑
- 记: 2026-11-11

**现象**

写成 `c!='+' || c!='-'`，条件恒真，错误输入也被当合法。

**原因**

四个"不是"要**同时成立**才是"都不是"——那是交集，用 `&&`。`||` 表示并集，任意一个成立即可，恒真。

**修法**

```cpp
if(a != 1 && a != 2 && a != 3)        // 既不是 1 也不是 2 也不是 3
if(a == 1 || a == 2 || a == 3)        // 是 1 或 2 或 3
```

## C07 函数名和数组名不是它们的值
- 题: B2043 / P1008
- 型: 坑点
- 知: 条件与逻辑
- 记: 2026-11-11

**现象**

```cpp
if(q3 && q5 && q7)          // 恒真
if(num) continue;           // 恒真
```

**原因**

`q3` 是函数地址（非零），`num` 是数组首地址（非零），转成 bool 永远是 true。

**修法**

```cpp
if(q3(x) && q5(x) && q7(x))   // 加括号才是调用
if(cnt[d] > 1) continue;      // 数组要写下标
```

## C08 判断条件里塞副作用
- 题: B3707
- 型: 坑点
- 知: 条件与逻辑
- 记: 2026-11-11

**现象**

```cpp
if((x0 += dpx[i]) == x1 && (y0 += dpy[i]) == y1)
```

第一个条件不成立时，`&&` 短路，`y0` 没被加回去 —— 坐标永久跑偏。

**原因**

`&&` / `||` 是短路的，右侧可能不执行。把"改状态"写进条件里，执行与否就变得不确定。

**修法**

```cpp
int nx = x0 + dpx[i], ny = y0 + dpy[i];
if(nx == x1 && ny == y1){ ... }
```

## C09 int 在运算时就溢出了
- 题: P6033 / B2016 / P1223
- 型: 坑点
- 知: 类型与溢出
- 记: 2026-11-10

**现象**

`n=100000` 全是 `100000`：

```text
正确答案 166892800000
你的输出 138917061632
```

**原因**

`ans` 虽然是 `long long`，但 `x + y` 是 `int` 运算，超过 `2^31 ≈ 2.1e9` 就已经溢出了——**赋值时再转类型救不回来**。

**修法**

```cpp
long long x, y;         // 参与运算的量本身就得是 long long
ans += x + y;
```

类型选择顺序：

```text
先看约束 → 算最大值 → 选类型
10⁹  级 → int
10¹⁸ 级 → long long
超过  → __int128 或高精度
```

## C10 负数取模在 C++ 里是负的
- 题: 1305
- 型: 坑点
- 知: 类型与溢出
- 记: 2026-11-09

**现象**

```cpp
a[i] = (i==0?0:a[i-1]) + (int)(100*sin(n+i)) % 3;
```

生成出来的"有序数组"变成 `2 4 6 6 6 4 4`，中途掉下去，二分全错。

**原因**

C++ 的 `%` 向零取整：`-95 % 3 == -2`（数学上是 `1`）。增量变成负数，前缀和不再递增。实测 200 万项里 30.8% 是负的。

**修法**

```cpp
int r = (int)(100*sin(n+i)) % 3;
if(r < 0) r += 3;
```

## C11 ceil / floor 返回的是 double
- 题: B2016 / P1068
- 型: 坑点
- 知: 类型与溢出
- 记: 2026-11-11

**现象**

```text
cout << ceil(a)   →  -0    或  1e+15
int num = (m-1) * 1.5;   →  应该 4，得到 3
```

**原因**

`ceil/floor/round` 的返回类型是 `double`。`cout` 会按浮点格式输出（`-0`、`1e+15`）；赋给 `int` 时按数值截断，浮点误差会让 `3.9999` 变成 `3`。

**修法**

```cpp
cout << (long long)a;                  // 向零舍入，正负都对
int num = (m-1) * 3 / 2;               // 能用整数算就别沾浮点
int num = (int)ceil((m-1) * 1.5 + 1e-9);
```

## C12 标志变量声明在循环外，忘了重置
- 题: P1008
- 型: 坑点
- 知: 作用域与生命周期
- 记: 2026-11-11

**现象**

```cpp
int num1 = 0;                    // 只在程序开始时初始化一次
for(int i = 123; i <= 333; i++){
    if(重复) num1 = 1;           // 一旦置 1，再也没人清零
    if(num1) continue;           // 之后每一轮都被跳过
}
```

**原因**

变量的作用域是"整个 main"，但它的**生命周期语义**应该是"每轮一份"。

**修法**

```cpp
for(int i = 123; i <= 333; i++){
    bool dup = false;            // 声明在循环体内，每轮天然重置
    ...
}
```

## C13 局部变量遮蔽外层
- 题: P1008
- 型: 坑点
- 知: 作用域与生命周期
- 记: 2026-11-11

**现象**

```cpp
if(cnt[d] > 1) int num = 1;      // 新开了一个局部 num
if(num) continue;                // 判断的是外层的 num 数组名 → 恒真
```

**原因**

`if` 里那句 `int num = 1;` 声明的是**新的局部变量**，出了 `if` 就销毁；外层那个 `num` 根本没被改。

**修法**

```cpp
int dup = 0;
if(cnt[d] > 1) dup = 1;          // 赋值，不是声明
if(dup) continue;
```

## C14 全局 vector 用输入的 n 初始化
- 题: P1036
- 型: 坑点
- 知: 作用域与生命周期
- 记: 2026-11-11

**现象**

```cpp
int n;
vector<int> N(n);        // 此时 n 还是 0 → 空容器

int main(){
    cin >> n;            // 读到 4，但 N 不会变大
}
```

之后 `N[i]` 全部越界。

**原因**

全局对象的构造发生在 `main` 之前，那时 `n` 还是 0。

**修法**

```cpp
vector<int> N;           // 全局只声明
int main(){
    cin >> n;
    N.assign(n + 1, 0);  // 读到 n 之后再定大小
}
```

## C15 容器变长变短后仍用旧的 len
- 题: P1106
- 型: 坑点
- 知: 作用域与生命周期
- 记: 2026-11-11

**现象**

```cpp
int len = n.size();              // 定死
for(int i = 0; i < len; i++){
    n.erase(i);                  // n 变短了，i 还在按旧长度走
}
```

**原因**

`len` 是快照，容器的 `size()` 是实时值。中途 `erase/insert` 之后，两者就不一致了。

**修法**

```cpp
for(int i = 0; i < (int)n.size(); ){   // 每次重新问
    if(要删) n.erase(i); else i++;
}
```

## C16 多组数据要读到 EOF
- 题: 1291
- 型: 坑点
- 知: 输入输出
- 记: 2026-11-11

**现象**

判题给了两组数据，只输出了第一组。

```text
5 1
2
5 2
1
0        ← 第二组被整个忽略
```

**原因**

`main` 里没有循环，读完第一组就结束了。题面"**每组数据**第一行为…"就是信号。

**修法**

```cpp
int n, m;
while(cin >> n >> m){        // 读到 EOF 自动停
    ...
}
```

| :--- | :--- |
| 「每组数据第一行…」 | `while(cin>>n>>m)` |
| 「第一行 T，表示组数」 | `while(T--)` |
| 只有「输入一行…」 | 单组 |

## C17 报错那行的数据也要读干净
- 题: 1293
- 型: 坑点
- 知: 输入输出
- 记: 2026-11-11

**现象**

```text
14 4 19 1
error
14 4 19 1 19 7 6 35 19 3 11 14 15 1 1 1 0 5 13 16 5 8 8
```

从第二个 `error` 开始全乱。

**原因**

`if(i > size){ cout<<"error"; continue; }` 写在读入之前。那一行剩下的数没被读走，下一次 `cin` 把它们当成了 `i` 和 `m`。

```cpp
vector<int> v(m);

```

## C18 输出格式也是判分点
- 题: P1618 / P1068 / B2004 / P1706 / P2053
- 型: 坑点
- 知: 输入输出
- 记: 2026-11-11

**现象**

答案完全正确，就是过不了。

| 错 | 对 |
| :--- | :--- |
| `NO!!!` | `No!!!`（大小写） |
| `cout << real << ' ' << line` | 分数线在前 |
| `"    "` 四个空格 | `setw(5)` |

## C19 `i*i < a` 漏了等号
- 题: P1036
- 型: 坑点
- 知: 静默错误
- 记: 2026-11-11

**现象**

平方数（4、9、25、49…）被判成素数。

**原因**

判素数写到 `i*i < a` 就停了，`i*i == a` 那一步没检查，于是把"能被整除"漏掉了。

**修法**

```cpp
for(int i = 2; i*i <= a; i++)     // 必须有等号
    if(a % i == 0) return false;
return true;
```

## C20 方向数组错一个元素

## C22 补丁掩盖根因
- 题: P1157
- 型: 坑点
- 知: 自欺
- 记: 2026-11-11

**现象**

```cpp
dfs(d + 1, d);                  // ← 真正的 bug：d 是层号，不是选中的数
if(cnt[i]) continue;            // 补丁：挡住重复
if(num[d] < num[d-1]) continue; // 补丁：挡住逆序
```

两个 `if` 让输出"看起来对"，但参数传错一直没修。

```cpp
dfs(d + 1, i);                  // 传选中的数字，两个补丁都不需要了
```

## C23 `!cnt[x]` 没有赋值
- 题: P1161
- 型: 坑点
- 知: 状态数组
- 记: 2026-11-11

**现象**

```cpp
bool cnt[MAXN];
...
!cnt[(int)(a*j)];        // 只是算了一个值，然后扔掉
```

输出几万个垃圾数字（因为数组还没初始化，读到的是内存残留）。

**原因**

`!x` 是表达式，不是赋值。C++ 允许"只算不存"的语句，`-Wall` 也不报错。

**修法**

```cpp
cnt[id] = !cnt[id];
cnt[id] ^= 1;            // 等价
```

## C25 lower_bound 找不到时返回 end()
- 题: 1305
- 型: 知识点
- 知: 二分查找
- 记: 2026-11-10

**现象**

查询一个比所有元素都大的数，输出的是 `n`（数组长度），题面要求 `-1`。

**原因**

`lower_bound` 返回迭代器，减 `begin()` 得到下标；找不到时返回 `end()`，减出来正好是 `n`。

**修法**

```cpp
int p = lower_bound(a, a+n, x) - a;
if(p == n) p = -1;
```

两者的定义：

| 函数 | 返回第一个满足 | 没有时 |
| :--- | :--- | :--- |
| `lower_bound` | `a[i] >= x` | `end()` |
| `upper_bound` | `a[i] > x` | `end()` |

## C26 fread 快读：一次要一大桶
- 题: P6033
- 型: 知识点
- 知: 输入输出
- 记: 2026-11-11

**现象**

`n = 10⁷` 个数，`cin` 超 2 秒，`scanf` 约 1 秒，都过不了 700ms。

**原因**

每次"向系统要数据"都有固定开销。逐字符读 = 几千万次系统调用。

**修法**

```cpp
static char buf[1<<20];
static int idx = 0, sz = 0;
inline int gc(){
    if(idx == sz){ sz = fread(buf,1,sizeof(buf),stdin); idx = 0; if(sz<=0) return -1; }
    return buf[idx++];
}
inline int readInt(){
    int c = gc();
    while(c<'0'||c>'9'){ if(c==-1) return 0; c = gc(); }
    int x = 0;
    while(c>='0'&&c<='9'){ x = x*10 + (c-'0'); c = gc(); }
    return x;
}
```

实测 57MB 输入只触发 **57 次** `fread`，0.18 秒读完。

## C27 1-based 时容量是 n+1 不是 n
- 题: P1157 / P1706
- 型: 知识点
- 知: 容器与越界
- 记: 2026-11-11

**现象**

`n = 20`，开 `vector<int> cnt(10)`，用 `cnt[10..19]` 直接越界。

**原因**

把"有 n 个元素"和"下标最大是 n"混了。1-based 时合法下标是 `1..n`，共 `n` 个，但容量必须是 `n+1`（下标 0 空着）。

**修法**

```cpp
vector<int> cnt(n + 1);   // 1-based
vector<int> cnt(n);       // 0-based
```

顺带：`size()` 返回 `size_t`（无符号），`for(int i = size()-1; i >= 0; i--)` 在 `size()==0` 时会变成巨大正数。统一转 `int`：

```cpp
for(int i = (int)v.size()-1; i >= 0; i--)
```

## C28 memset 只能填 0 和 -1
- 题: —
- 型: 知识点
- 知: 内存初始化
- 记: 2026-11-11

**现象**

```cpp
int a[100];
memset(a, 0, sizeof(a));      // ✓ 全 0
memset(a, -1, sizeof(a));     // ✓ 全 -1
memset(a, 1, sizeof(a));      // ✗ 得到 16843009
```

**原因**

`memset` 是**按字节**填的。`int` 占 4 字节，填 1 等于把每字节都写成 `0x01`，
拼起来是 `0x01010101 = 16843009`。只有 `0x00` 和 `0xFF` 反复填满 4 字节后仍是 0 和 −1。

**修法**

```cpp
fill(a, a + 100, 1);              // 数组
vector<int> v(n, 1);              // 容器直接构造
memset(a, 0x3f, sizeof(a));       // 想要"大数"可以，0x3f3f3f3f ≈ 1.06e9，两两相加不溢出
```

## C29 向上取整用 (a+b-1)/b，别用 ceil

## C32 string::find 找不到返回 npos
- 题: P1308
- 型: 知识点
- 知: 字符串
- 记: 2026-11-11

**现象**

```cpp
if(s.find("ab") == -1) ...        // 编译能过，永远不成立
```

## C33 vector::erase 是 O(n)，还会让后面的迭代器失效
- 题: —
- 型: 知识点
- 知: 容器与越界
- 记: 2026-11-11

**要点**

```cpp
v.erase(v.begin() + i);              // 删第 i 个，后面整体前移：O(n)
v.erase(v.begin() + l, v.begin() + r);  // 删 [l, r)
```

边遍历边删，必须接住返回值：


## C34 前缀和 vs 差分：问得多用前者，改得多用后者
- 题: —
- 型: 知识点
- 知: 前缀和与差分
- 记: 2026-11-11

**两个工具**

| 需求 | 用什么 | 预处理 | 单次操作 |
| :--- | :--- | :--- | :--- |
| 多次问「区间和」 | 前缀和 | `s[i] = s[i-1] + a[i]` | 查询 O(1)：`s[r] - s[l-1]` |
| 多次「区间整体加 x」 | 差分 | 建 `d[i] = a[i] - a[i-1]` | 修改 O(1)：`d[l] += x; d[r+1] -= x` |

## C36 删数题：删第一个下降点，不是删最大的

```cpp
while(k-- && !st.empty()){
    while(!st.empty() && st.back() > c && k >= 0){ st.pop_back(); k--; }
    st.push_back(c);
}
```

## C40 汉诺塔：先锁定"最大盘搬家"的中间状态
- 题: 1290

- 知: 分治与递归
- 记: 2026-11-11

**修法**

```cpp
hanoi(n-1, from, via);   // 去仓库

hanoi(n-1, via, to);     // 出仓库
```

## C42 区间一律和 [0, size) 求交

- 知: 区间与下标

**修法**

```text

```

```cpp
if(s < (int)a.size()){

    if(s < e) a.erase(a.begin()+s, a.begin()+e);
}
if(l > (int)a.size()) l = a.size();
if(r > (int)a.size()) r = a.size();
if(l >= r) cout << "null";
```
