About

关于这个页面

纯静态 · 零构建

手写 HTML / CSS / JavaScript，没有打包步骤。推到 GitHub，Cloudflare 自动发布到全球 CDN，国内走自定义域名可直连。

数据只在本机

课表、事务、待办都存在浏览器 localStorage 里，背景图片存在 IndexedDB。没有后端，不上传任何个人数据。

可自由改造

配色集中在 css/base.css 顶部的变量里，入口链接是 index.html 里的卡片，改完刷新即可。

导入课表 / 事务

支持教务系统导出的 .xls、.xlsx、.csv，以及 .ics 日历文件和直接粘贴。

把课表文件拖到这里 或者点击选择文件 · 也可以按 Ctrl+V 直接粘贴 .xls .xlsx .csv .ics .json

在教务系统里：信息查询 → 学生个人课表 → 右上角「导出」或「打印」，得到 .xls 文件后拖进来即可。 所有解析都在你的浏览器里完成，文件不会被上传。

提示：直接粘贴网页表格时，粘贴板里会带上表格结构，识别率比纯文本更高。
为什么这里不能直接读教务系统？
教务系统在你登录后才返回课表，而且不允许别的网站跨域读取它的页面（浏览器安全策略）。 所以「自动抓取」用的是书签小工具：它运行在教务系统页面自己身上， 读到你自己的课表后，再跳回本页自动填好。

抓取本校课表
手机上不好拖书签？用这个办法：
  1. 桌面浏览器里新建一个书签，名称随便填（例如「抓课表」）。
  2. 把「网址」整段改成下面复制的代码。
  3. 打开教务系统的课表页面，等课表显示出来，再点这个书签。
  4. 它会自动跳回本页并把课表填进导入预览。

书签只在你的浏览器里跑，不联网、不上传。抓取到的内容会通过网址片段（#data=）传回本页，随后自动从地址栏清掉。 如果装不了书签，用「复制粘贴」也一样快。

说明

.ics 是通用日历格式。手机日历（iOS / Android）、Google 日历、Outlook 里都可以「导出」，把导出的内容贴到这里， 就会变成本页的事务。

数据存在哪里

  • 课表、事务、待办、倒数日与设置 → 浏览器 localStorage（键名前缀 cw.）
  • 自定义背景图片 → 浏览器 IndexedDB（数据库 cw-bg）
  • 换浏览器、换设备、清理浏览器数据都会丢，所以请定期用「数据与设置 → 导出全部数据」备份
  • 清除浏览器缓存不会丢数据，但「清除站点数据 / Cookie 及网站数据」会丢

域名与部署

  • 本站是纯静态页面，仓库根目录的 wrangler.jsonc 指定发布 site/ 目录
  • 绑定 leeyin.xyz 时在 Cloudflare 用 Custom Domain，它会自动加 DNS 记录和证书，不要手动去加 A 记录
  • 所有资源都是相对路径，换域名不用改代码
