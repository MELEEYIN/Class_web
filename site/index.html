① 把这个按钮拖到浏览器书签栏

抓取本校课表
手机上不好拖书签？用这个办法：
  1. 桌面浏览器里新建一个书签，名称随便填（例如「抓课表」）。
  2. 把「网址」整段改成下面复制的代码。
  3. 打开教务系统的课表页面，等课表显示出来，再点这个书签。
  4. 它会自动跳回本页并把课表填进导入预览。

书签只在你的浏览器里跑，不联网、不上传。抓取到的内容会通过网址片段（#data=）传回本页，随后自动从地址栏清掉。 如果装不了书签，用「复制粘贴」也一样快。

先说清楚这件事：密码存在哪里
密码只写进你这台设备的浏览器（localStorage 的 cw.jwAccount）， 本站没有后端也不会把它上传到任何服务器。
但请明白：浏览器里的密码是明文的，同一台电脑上能打开这个浏览器的人（或恶意脚本）都可能读到它。 公用电脑、机房的电脑上不要存。不放心就选「不保存密码」，每次由你亲手输一次。
密码可以留空 —— 留空时，书签会弹出输入框让你当场输入，不会保存任何密码。

① 把下面这个书签拖到浏览器书签栏

一键登录教务并抓课表
用法
  1. 先在上面填好学号和密码，点「保存到本机」（没存密码也可以，那就每次手输一次）。
  2. 把「一键登录教务并抓课表」这个按钮拖到书签栏（手机上做不到就点「复制书签代码」，新建一个书签把网址整段替换掉）。
  3. 随便在哪个页面点一下这个书签：它会打开教务系统、填好账号密码、登录、跳到课表页、把课表带回来并自动填进导入预览。
书签脚本只在你自己的浏览器里跑，不联网、不经过任何第三方。
如果教务系统有验证码，脚本会把密码填好并停下来，你手动补验证码再点登录即可 —— 之后的抓取仍然会自动完成。
如果登录页要求走统一身份认证（账号密码输入框不在教务系统自己的页面上）， 请先用上面的「登录教务系统」入口登录一次，再在课表页点这个书签，它会直接抓取。
手机上怎么用（不用装任何东西）：
· iPhone / iPad（Safari）：把本页「加入书签」，然后「书签 → 编辑」把这个书签的地址整段替换成下面复制的代码 （或者：分享 → 添加书签 → 编辑地址）。
· 安卓（Chrome / Edge）：打开任意一个网页，加一个书签，把它的地址整段替换成下面的代码。
· 之后登录教务系统（哪个页面都行），点一下这个书签，课表就会自动抓回来。
· 手机上没有「书签栏」也照样能用：Safari 在书签/收藏列表里点，Chrome 在地址栏输入书签名选中即可。
· 桌面版 Windows 上还有更省事的 tools\一键自动导入课表.bat（那个只能在电脑上用，手机跑不了）。

教务系统不允许别的网站跨域读它的页面（浏览器的同源策略），所以「自动导入」只能这样做： 脚本在教务系统自己的页面上运行，读完课表再跳回本页。抓到的内容通过网址片段传回，之后会自动从地址栏清掉。

只有一两门要补（实验课、调课、临时课），直接手填最快。 星期、节次、上课周次都可以点着选，不用背写法。

手动加一条事务

考试、交作业、社团活动。也可以在日程浮窗的月历上直接双击某一天。

下载 CSV 模板，批量填

想一次录一学期（比如整学期的实验课安排），下载这个模板，用 Excel 或记事本按列填好， 再回到「上传文件」把它拖进来就行。表头就是下面这一行：

课程,教师,教室,星期,节次,周次
高等数学B1,何俊锋,C-5-103,星期二,3-4,1-16
大学物理,李四,C-2-201,星期四,6-7,1-16周(双)

周次支持这些写法：1-16、2-3,5-6,9-18、1-16周(单)、 单周、双周。留空表示整学期每周都上。
周次里带逗号时必须用双引号包起来（写成 "2-3,5-6,9-18"），否则会被当成两列。
星期写 星期一…星期日（周一 也认）； 节次写 3-4 或 3,4。

数据存在哪里

  • 课表、事务、待办、倒数日与设置 → 浏览器 localStorage（键名前缀 cw.）
  • 自定义背景图片 → 浏览器 IndexedDB（数据库 cw-bg）
  • 换浏览器、换设备、清理浏览器数据都会丢，所以请定期用「数据与设置 → 导出全部数据」备份
  • 清除浏览器缓存不会丢数据，但「清除站点数据 / Cookie 及网站数据」会丢

域名与部署

  • 本站是纯静态页面，仓库根目录的 wrangler.jsonc 指定发布 site/ 目录
  • 绑定 leeyin.xyz 时在 Cloudflare 用 Custom Domain，它会自动加 DNS 记录和证书，不要手动去加 A 记录
  • 所有资源都是相对路径，换域名不用改代码
