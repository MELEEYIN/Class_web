访问统计

正在读取…

统计的是「页面被打开的次数」。访客身份用「IP + 浏览器标识 + 当天随机盐」的散列计算， 每天换盐、不种 cookie，所以只能看出今天有几个不同的人，无法跨天追踪同一个人。 后台页面本身不计入。

怎么让全班看到
绑定了 KV：点「发布到全站」即可，访客页面最迟 1 分钟内自动更新，不用刷新。
没绑 KV：把「导出 hosts.json」得到的文件覆盖到 site/data/hosts.json，再 git push，部署完成后全站生效。
