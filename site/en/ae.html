01

常用半导体器件第 1 章

4 节 · 2 道例题 · 器件特性是后面一切的地基

基础

模电的分析都从器件开始：二极管看伏安特性与等效模型，稳压管看击穿区，晶体管看「发射结正偏、集电结反偏」和电流分配，场效应管看转移特性与跨导。这一章计算题不多，但概念题年年有。

读完这一章你能做到

  • 1.1 PN 结与二极管的伏安特性
  • 1.2 稳压二极管
  • 1.3 晶体管的电流放大与特性曲线
  • 1.4 场效应管
1.1 PN 结与二极管的伏安特性必背

PN 结正偏导通、反偏截止；伏安特性 iD = Is(e^(uD/UT) − 1)，室温下 UT ≈ 26mV。

导通后 uD 变化很小，硅管约 0.7V、锗管约 0.3V；反偏时有很小的反向饱和电流，超过击穿电压会击穿。

等效模型：理想模型（导通即短路）、恒压降模型（0.7V 电池 + 理想二极管）、折线模型（再串一个动态电阻）；小信号时用微变电阻 rd = UT/ID。

模型正向反向用在什么时候
理想短路开路大信号、整流粗略分析
恒压降0.7V开路一般直流计算
折线0.7V + rd开路要求稍准的直流计算
微变rd = UT/ID—小信号动态分析
1.2 稳压二极管必背

稳压管工作在反向击穿区，正常工作时必须串限流电阻，保证 Izmin ≤ Iz ≤ Izmax。

参数：稳定电压 Uz、稳定电流 Iz、最大耗散功率 PZM = Uz·Izmax、动态电阻 rz（越小稳压越好）。

限流电阻范围：Rmin = (UI − Uz)/Izmax，Rmax = (UI − Uz)/(Izmin + IL)。

1.3 晶体管的电流放大与特性曲线必背

放大条件：发射结正偏、集电结反偏。三个电极电流关系 iC = βiB，iE = (1+β)iB。

输入特性像二极管正向特性；输出特性分放大区、饱和区、截止区。饱和时 uCE 很小（约 0.3V），此时 iC 不再随 iB 增大。

β 不是常数，随 iC 变化；温度升高时 ICBO 增大、UBE 下降，Q 点会漂移（后面用分压偏置稳定）。

1.4 场效应管必背

结型（JFET）与绝缘栅（MOSFET）两类；靠电场控制导电沟道，输入电阻极高。

转移特性 iD = IDSS(1 − uGS/UGS(off))²；跨导 gm = ΔiD/ΔuGS，是场效应管放大能力的指标。

MOSFET 分增强型与耗尽型，还要注意防止栅极静电击穿。

例题先做再展开
本章例题 · 2 题自编 · 按真题题型

  1. 硅二极管接在 5V 电源与 1kΩ 电阻串联回路中，用恒压降模型求回路电流。

    恒压降模型：二极管两端 0.7V，电阻上 5 − 0.7 = 4.3V。

    I = 4.3V / 1kΩ = 4.3mA。

  2. 稳压管 Uz=6V，输入 UI=12V，负载电流 IL 在 5–20mA 变化，Izmin=5mA、Izmax=30mA，求限流电阻范围。

    Rmin = (12−6)/30mA = 200Ω；Rmax = (12−6)/(5mA+5mA) = 600Ω。

    取 200–600Ω 之间的标准值，例如 510Ω；负载最重时也要保证 Iz ≥ 5mA。

易错点

  • 稳压管不能直接并在电源两端，必须串限流电阻。
  • 晶体管饱和时集电结正偏，别再用 iC = βiB 算电流。
02

基本放大电路第 2 章

4 节 · 2 道例题 · 共射、共集、共基三套公式

核心

这一章的核心是「先求 Q 点，再用微变等效电路求 Au、Ri、Ro」。三种组态的特点要能一句话说出来：共射反相放大、共集跟随、共基宽频带。

读完这一章你能做到

  • 2.1 放大电路的构成与性能指标
  • 2.2 静态工作点与微变等效电路
  • 2.3 三种基本组态
  • 2.4 场效应管放大与多级放大
2.1 放大电路的构成与性能指标必背

放大电路要有直流电源、偏置电路和耦合电容：直流保证 Q 点，交流信号才能不失真地放大。

指标：电压放大倍数 Au、输入电阻 Ri、输出电阻 Ro、通频带 BW、最大不失真输出电压。

Ri 越大对前级影响越小，Ro 越小带负载能力越强。

2.2 静态工作点与微变等效电路必背

Q 点：IBQ = (VCC − UBEQ)/Rb，ICQ = βIBQ，UCEQ = VCC − ICQ·Rc。

微变等效：晶体管用 rbe 替代，rbe = rbb' + (1+β)·26mV/IEQ（rbb' 约 200Ω）。

分析步骤：画直流通路求 Q 点 → 画交流通路 → 晶体管换 rbe → 求 Au、Ri、Ro。

2.3 三种基本组态必背

共射：Au = −β(Rc∥RL)/rbe，Ri = Rb∥rbe，Ro ≈ Rc；输出与输入反相，最常用。

共集（射极跟随器）：Au ≈ 1（略小于 1），Ri 很大，Ro 很小，用于缓冲、驱动负载。

共基：Au = β(Rc∥RL)/rbe（同相），Ri 很小，高频特性好，用于宽带放大。

Q 点稳定电路（分压偏置 + 射极电阻）用 Re 的直流负反馈稳住 ICQ；旁路电容 Ce 让 Re 对交流短路。

组态AuRiRo相位
共射−β(Rc∥RL)/rbeRb∥rbe（中）≈Rc（大）反相
共集≈1很大很小同相
共基β(Rc∥RL)/rbe很小≈Rc同相
2.4 场效应管放大与多级放大必背

场效应管放大电路同样先求 Q 点，再用 gm 求 Au ≈ −gm(Rd∥RL)；输入电阻极高。

多级放大：Au = Au1·Au2…，Ri 取第一级，Ro 取最后一级；后级输入电阻就是前级的负载。

级间耦合：阻容耦合（各级 Q 点独立）、直接耦合（可放大直流，但零点漂移）、变压器耦合。

例题先做再展开
本章例题 · 2 题自编 · 按真题题型

  1. 共射电路 VCC=12V、Rb=300kΩ、Rc=3kΩ、β=50，求 Q 点。

    IBQ = (12−0.7)/300k ≈ 37.7μA；ICQ = 50×37.7μA ≈ 1.88mA。

    UCEQ = 12 − 1.88mA×3kΩ ≈ 6.36V，工作在放大区。

  2. 上题若 RL=3kΩ、rbe=1kΩ，求 Au、Ri、Ro。

    Rc∥RL = 1.5kΩ；Au = −50×1.5k/1k = −75。

    Ri = Rb∥rbe ≈ 1kΩ；Ro ≈ Rc = 3kΩ。

易错点

  • 求 Au 时别忘了 RL 与 Rc 并联。
  • 共集的 Au 是正数且接近 1，不要写成负号。
03

多级与差分放大电路第 3 章

3 节 · 1 道例题 · 差分是运放的第一级

选学

多级放大解决增益，差分放大解决零点漂移与共模抑制。期末常考：差分电路的静态计算、Ad/Ac/CMRR、以及用恒流源提高共模抑制比。

读完这一章你能做到

  • 3.1 多级放大电路的动态分析
  • 3.2 差分放大电路的构成
  • 3.3 差分电路的分析
3.1 多级放大电路的动态分析必背

多级放大倍数等于各级相乘；计算时把后一级的 Ri 当作前一级的负载。

Ri 取第一级输入电阻，Ro 取最后一级输出电阻；中间级的 Ro 会影响后级增益。

直接耦合多级放大存在零点漂移，第一级用差分电路来抑制。

3.2 差分放大电路的构成必背

两个完全对称的共射电路，发射极接在一起；长尾电阻 Re 或恒流源提供大的共模负反馈。

差模信号：两输入大小相等、极性相反；共模信号：大小相等、极性相同。

四种接法：双端输入双端输出、双端输入单端输出、单端输入双端输出、单端输入单端输出，增益各差一半。

3.3 差分电路的分析必背

双端输出：Ad = −β(Rc∥RL/2)/rbe（带载时），Ac ≈ −Rc/(2Re)（长尾），CMRR = |Ad/Ac|。

恒流源替代长尾电阻，等效 Re 极大，Ac 趋近 0，CMRR 大幅提高。

单端输出时 Ad 减半，Ac 不为 0（与 Re 有关），共模抑制能力下降。

差分电路的 Q 点：IEE 由恒流源决定，每管 ICQ = IEE/2。

接法AdAc特点
双端入双端出最大≈0（长尾）CMRR 最高
双端入单端出减半不为 0常用作运放输入级
单端入双端出同双端同双端单端转双端
单端入单端出减半不为 0最简单
例题先做再展开
本章例题 · 1 题自编 · 按真题题型

  1. 差分电路 IEE=2mA，Rc=10kΩ，β=50，求每管 ICQ 与 UCEQ（VCC=12V，忽略 Re 压降）。

    ICQ = IEE/2 = 1mA。

    UCEQ = VCC − ICQ·Rc = 12 − 1mA×10kΩ = 2V（若考虑发射极电位则要减去 UEE 部分，题目给忽略就按此算）。

易错点

  • 长尾电阻 Re 越大，共模抑制越好；恒流源等效 Re 趋于无穷。
  • 双端输出时负载 RL 是两管各一半，公式里是 Rc∥(RL/2)，别写成 Rc∥RL。
04

集成运算放大电路第 4 章

2 节 · 1 道例题 · 电流源与有源负载

核心

集成运放内部就是「差分输入级 + 电流源偏置 + 有源负载 + 互补输出级」。这一章不要求画内部电路，但要会认电流源、算镜像电流、理解有源负载为什么能提高增益。

读完这一章你能做到

  • 4.1 电流源电路
  • 4.2 有源负载与运放结构
4.1 电流源电路必背

镜像电流源：IR = (VCC − UBE)/R，若两管对称则 IC1 ≈ IR，输出电流由 R 决定。

比例电流源：在发射极串不同电阻，IC2/IC1 ≈ R1/R2。

微电流源：在 T2 发射极串小电阻 Re，得到很小的电流；威尔逊电流源输出电阻更高。

电流源在运放里提供稳定的偏置电流，并作为有源负载。

4.2 有源负载与运放结构必背

用电流源替代集电极电阻 Rc，交流等效电阻极大，Au = −β(Rc∥RL)/rbe 中的 Rc 变成 rce，增益大幅提高。

典型运放：输入级差分（双端入单端出）、中间级有源负载共射、输出级互补（OCL）、偏置电路电流源。

集成运放特点：直接耦合、元件匹配好、功耗小、不能做大电容/电感。

例题先做再展开
本章例题 · 1 题自编 · 按真题题型

  1. 镜像电流源 VCC=15V、R=39kΩ、UBE=0.7V，求输出电流。

    IR = (15−0.7)/39kΩ ≈ 0.367mA。

    对称时 IC2 ≈ IR ≈ 0.37mA。

易错点

  • 镜像电流源的前提是两管参数一致、VBE 相同。
  • 有源负载提高的是交流等效电阻，不改变直流 Q 点。
05

放大电路的频率响应第 5 章

3 节 · 1 道例题 · 波特图 + 三个频段

核心

频率响应考「三个频段、两个截止频率、一个带宽」，以及混合 Π 模型和 fT。计算题通常只要求中频增益、fL、fH 和 BW，画波特图看斜率。

读完这一章你能做到

  • 5.1 频率响应与波特图
  • 5.2 混合 Π 模型与 fT
  • 5.3 多级放大电路的频率响应
5.1 频率响应与波特图必背

幅频特性：中频段增益最大，低频段因耦合电容、旁路电容下降，高频段因结电容、寄生电容下降。

下限频率 fL、上限频率 fH，通频带 BW = fH − fL（通常 fH ≫ fL，近似 BW ≈ fH）。

波特图：幅频每十倍频程 20dB，单极点处斜率 ±20dB/dec；相频在 fL/fH 处各贡献 ±45°，极限 ±90°。

5.2 混合 Π 模型与 fT必背

高频时晶体管用混合 Π 模型：rbb'、rbe、Cπ、Cμ、gm；Cμ 跨接输入输出，产生密勒效应。

共射电路上限频率 fH 主要受 Cπ 与密勒电容 (1+gmRc)Cμ 影响；减小 Rc 或选 fT 高的管子可提高 fH。

特征频率 fT：β 下降到 1 时的频率，衡量管子的高频能力；fT ≈ gm/(2π(Cπ+Cμ))。

5.3 多级放大电路的频率响应必背

多级放大：中频增益相乘；下限频率升高、上限频率降低，通频带变窄。

若各级 fL、fH 相同，n 级后 fL ≈ fL1/√(2^(1/n)−1)，fH ≈ fH1·√(2^(1/n)−1)。

增益带宽积在单级共射中近似为常数，提高增益必然牺牲带宽。

例题先做再展开
本章例题 · 1 题自编 · 按真题题型

  1. 单级共射 fL=20Hz、fH=200kHz，求通频带；两级相同电路级联后 fH 约为多少？

    BW = 200k − 20 ≈ 200kHz。

    两级：fH ≈ fH1·√(2^(1/2)−1) ≈ 200k×0.643 ≈ 129kHz，带宽变窄。

易错点

  • 波特图斜率看极点个数，不是看增益大小。
  • 密勒电容是高频性能变差的主因，共基电路没有密勒效应，所以频带宽。
06

反馈放大电路第 6 章

3 节 · 2 道例题 · 判断组态 + 深度负反馈计算

必考

反馈是模电的分水岭：先会判断「正/负、交流/直流、电压/电流、串联/并联」，再会用 Af = A/(1+AF) 与深度负反馈 Af ≈ 1/F。期末必有一道反馈判断题和一道深度负反馈计算题。

读完这一章你能做到

  • 6.1 反馈的判断方法
  • 6.2 负反馈放大电路的方块图与计算
  • 6.3 负反馈放大电路的稳定性
6.1 反馈的判断方法必背

瞬时极性法：假设输入为 +，沿信号路径标出各点极性，看反馈到输入端的信号是削弱还是增强输入——削弱为负反馈。

电压反馈与电流反馈：看输出端，反馈信号取自输出电压（并联在输出上）为电压反馈，取自输出电流（串在输出回路）为电流反馈；常用「输出短路法」判断。

串联与并联：看输入端，反馈信号与输入信号接在不同端为串联，接在同一端为并联。

四种组态：电压串联、电压并联、电流串联、电流并联；组态决定 Ri、Ro 的变化方向。

组态RiRo典型用途
电压串联增大减小稳定输出电压
电压并联减小减小电流-电压转换
电流串联增大增大电压-电流转换
电流并联减小增大稳定输出电流
6.2 负反馈放大电路的方块图与计算必背

闭环增益 Af = A/(1+AF)，其中 A 为开环增益、F 为反馈系数、AF 为环路增益。

深度负反馈（1+AF ≫ 1）：Af ≈ 1/F；串联负反馈时 Uf ≈ Ui，并联负反馈时 If ≈ Ii。

深度负反馈计算步骤：判断组态 → 写出 F 的表达式 → Af ≈ 1/F → 由输出反推输入。

负反馈对性能的影响：串联使 Ri 增大 (1+AF) 倍，并联使 Ri 减小为 1/(1+AF)；电压反馈使 Ro 减小，电流反馈使 Ro 增大；带宽扩展 (1+AF) 倍；非线性失真与噪声减小。

6.3 负反馈放大电路的稳定性必背

自激振荡条件：AF = −1，即幅值 |AF| = 1、附加相移 ±180°。

判断稳定：看环路增益的波特图，在相移 −180° 处的幅值若小于 1（0dB）则稳定；相位裕度一般要求 ≥ 45°。

消除自激：减小环路增益、加补偿电容（滞后/超前补偿）、在反馈网络中加校正。

负反馈在低频时改善性能，在高频可能因附加相移变成正反馈。

例题先做再展开
本章例题 · 2 题自编 · 按真题题型

  1. 某负反馈电路开环增益 A=10^4、反馈系数 F=0.01，求闭环增益 Af 与反馈深度。

    AF = 10^4×0.01 = 100；1+AF = 101。

    Af = A/(1+AF) = 10^4/101 ≈ 99，约等于 1/F = 100。

  2. 电压串联负反馈，反馈网络由 R1、R2 分压构成（F = R1/(R1+R2)），求深度负反馈下的电压放大倍数。

    深度负反馈 Af ≈ 1/F = (R1+R2)/R1。

    这就是同相比例运算电路的增益公式；若 R1=10kΩ、R2=90kΩ，则 Af ≈ 10。

易错点

  • 判断反馈组态先找反馈支路，再分别看输入/输出端连接方式。
  • 深度负反馈不是「增益变小」，而是「增益只由反馈网络决定」。
07

信号的运算与处理第 7 章

3 节 · 2 道例题 · 虚短虚断 + 运放电路

基础

运放线性应用的两条假设——虚短（u+ = u−）与虚断（i+ = i− = 0）——能推出所有基本运算电路。期末考反相/同相/加减/积分/微分，偶尔考仪表放大器。

读完这一章你能做到

  • 7.1 基本运算电路
  • 7.2 模拟乘法器与仪表放大器
  • 7.3 有源滤波电路
7.1 基本运算电路必背

反相比例：Au = −Rf/R1，输入电阻 R1，虚地。

同相比例：Au = 1 + Rf/R1，输入电阻极高；电压跟随器是 Rf=0、R1=∞ 的特例。

加法：反相加法器 uo = −(Rf/R1·u1 + Rf/R2·u2)；减法用差分电路或两级反相。

积分：uo = −1/(RC)∫ui dt；微分：uo = −RC·dui/dt。积分电路把方波变三角波，微分把三角波变方波。

7.2 模拟乘法器与仪表放大器必背

模拟乘法器实现 uo = K·ux·uy，可用于乘除、平方、开方、调幅。

仪表放大器由三个运放组成：前两级差分输入、增益高、输入电阻大；第三级差分输出。

仪表放大器共模抑制比高，常用于传感器信号放大（电桥、热电偶）。

7.3 有源滤波电路必背

有源滤波用运放 + RC 网络，不用电感；一阶低通 fH = 1/(2πRC)，高通同理。

二阶压控电压源（Sallen-Key）低通/高通是常见电路；带通由低通与高通串联。

滤波器按通带分低通、高通、带通、带阻；按逼近方式分巴特沃斯、切比雪夫等。

例题先做再展开
本章例题 · 2 题自编 · 按真题题型

  1. 反相比例电路 R1=10kΩ、Rf=100kΩ，输入 0.2V，求输出。

    Au = −100k/10k = −10。

    uo = −10×0.2V = −2V（在运放输出范围内）。

  2. 积分电路 R=10kΩ、C=0.1μF，输入 1V 阶跃，求 10ms 后的输出。

    uo = −ui·t/(RC) = −1×10ms/(10kΩ×0.1μF) = −1V。

    10ms 时输出 −1V，之后继续线性下降直到饱和。

易错点

  • 虚短虚断只在线性区成立，比较器/振荡器不能用。
  • 积分电路的输出方向与输入极性相反，注意符号。
08

波形的产生与信号的转换第 8 章

3 节 · 2 道例题 · 振荡条件 + 比较器阈值

必考

这一章分两块：正弦波振荡（RC、LC、石英）看起振条件与频率公式；电压比较器看阈值与传输特性。期末常考 RC 桥式振荡频率与起振条件、滞回比较器的阈值。

读完这一章你能做到

  • 8.1 正弦波振荡电路
  • 8.2 电压比较器
  • 8.3 锯齿波与波形转换
8.1 正弦波振荡电路必背

振荡条件：AF = 1，即幅值 |AF| = 1、相位 φA + φF = 2nπ（正反馈）。

起振条件：|AF| > 1，起振后靠非线性稳幅到 |AF| = 1。

RC 桥式振荡：f0 = 1/(2πRC)，反馈网络 F = 1/3，要求 Au > 3（同相放大 + 热敏电阻稳幅）。

LC 振荡：f0 = 1/(2π√(LC))；变压器反馈、电感三点、电容三点（考毕兹）。石英晶体振荡频率极稳，用于时钟。

8.2 电压比较器必背

比较器工作在非线性区：u+ > u− 输出高，u+ < u− 输出低；没有虚短。

单限比较器：一个阈值；过零比较器阈值 0V。

滞回比较器（施密特）：两个阈值 UT+、UT−，回差提高抗干扰；阈值由正反馈电阻分压决定。

窗口比较器：两个阈值，判断输入是否落在区间内。

8.3 锯齿波与波形转换必背

锯齿波：积分电路 + 比较器 + 复位开关，或由方波积分得到三角波。

波形转换：正弦 → 过零比较器 → 方波；方波 → 积分 → 三角波；三角波 → 微分 → 方波。

波形转换电路的本质是「比较器取极性、积分器做平滑」。

例题先做再展开
本章例题 · 2 题自编 · 按真题题型

  1. RC 桥式振荡 R=16kΩ、C=0.01μF，求振荡频率；起振时 Au 至少多少？

    f0 = 1/(2πRC) = 1/(2×3.14×16k×0.01μ) ≈ 995Hz。

    反馈系数 F=1/3，起振要求 Au > 3。

  2. 滞回比较器输出 ±6V，正反馈电阻 R1=10kΩ、R2=20kΩ，参考电压 0，求两个阈值。

    阈值 UT = ±(R1/(R1+R2))·Uo = ±(10/30)×6 = ±2V。

    即 UT+ = +2V、UT− = −2V，回差 4V。

易错点

  • 振荡电路是正反馈，别与负反馈的 Af 公式混用。
  • 比较器没有虚短，阈值要按正反馈分压算。
09

功率放大电路第 9 章

3 节 · 2 道例题 · 效率 + 交越失真

必考

功放考三件事：甲类/乙类/甲乙类的区别、OCL 与 OTL 的输出功率与效率、交越失真怎么消除。计算题通常是「给定 UCC、RL 求 Pom 与效率」。

读完这一章你能做到

  • 9.1 功率放大电路的特点与分类
  • 9.2 OCL 与 OTL 电路
  • 9.3 功放的计算
9.1 功率放大电路的特点与分类必背

功放要求输出功率大、效率高、失真小；管子工作在大信号状态。

甲类：Q 点在负载线中点，导通角 360°，效率最高 50%，失真小但功耗大。

乙类：Q 点在截止点，导通角 180°，效率高（78.5%）但有交越失真。

甲乙类：Q 点略高于截止，导通角 180°–360°，兼顾效率与失真，是最常用的功放。

9.2 OCL 与 OTL 电路必背

OCL：双电源互补对称（NPN + PNP），输出无电容，低频特性好；Pom = UCC²/(8RL)，效率 78.5%。

OTL：单电源，输出串大电容（约 RL 的容量），输出幅度受电容影响，Pom ≈ UCC²/(8RL)。

交越失真：乙类功放两管交替时死区造成，甲乙类通过给管子加少量偏置消除。

复合管（达林顿）：提高电流放大倍数，注意类型搭配与 UBE 叠加。

9.3 功放的计算必背

最大输出功率 Pom = (UCC − UCES)²/(2RL) ≈ UCC²/(8RL)（双电源，输出幅度 UCC/2）。

直流电源提供的功率 PV = 2UCC·Iom/π；效率 η = Pom/PV ≈ 78.5%。

选管：U(BR)CEO ≥ 2UCC，ICM ≥ UCC/RL，PCM ≥ 0.2Pom。

例题先做再展开
本章例题 · 2 题自编 · 按真题题型

  1. OCL 电路 UCC=15V、RL=8Ω，求最大输出功率与效率。

    Pom = UCC²/(8RL) = 225/64 ≈ 3.5W。

    理想效率 78.5%；实际因管压降略低。

  2. 上题若要求选功放管，U(BR)CEO、ICM、PCM 至少多少？

    U(BR)CEO ≥ 2UCC = 30V；ICM ≥ UCC/RL = 1.875A；PCM ≥ 0.2Pom ≈ 0.7W。

易错点

  • OCL 是双电源，OTL 是单电源，计算前先看清。
  • 乙类的交越失真是「零附近」的失真，不是削顶。

直流电源第 10 章

3 节 · 2 道例题 · 整流、滤波、稳压

核心

直流电源四步：变压 → 整流 → 滤波 → 稳压。期末常考整流输出平均值、电容滤波后的输出电压、三端稳压器的接法与输出电压。

读完这一章你能做到

  • 10.1 整流电路
  • 10.2 滤波电路
  • 10.3 稳压电路
10.1 整流电路必背

半波整流：Uo ≈ 0.45U2；桥式整流：Uo ≈ 0.9U2（U2 为变压器副边有效值）。

整流二极管要承受反向电压：桥式每管最大反向电压为 √2·U2。

桥式整流输出脉动频率是输入的两倍（50Hz 输入 → 100Hz 脉动）。

10.2 滤波电路必背

电容滤波：空载 Uo ≈ √2U2，带载 Uo ≈ 1.2U2；电容越大、负载越轻，滤波效果越好。

滤波电容的耐压要大于 √2U2；整流管导通角变小，冲击电流大。

电感滤波适用于大电流负载；RC/LC 滤波可进一步减小纹波。

10.3 稳压电路必背

稳压管稳压：简单，但输出电流小、效率低，需限流电阻。

串联型稳压：调整管 + 取样网络 + 基准电压 + 比较放大，输出电压 Uo = (1+R1/R2)·Uref。

三端稳压器 78xx（正压）/79xx（负压）：输出固定（7805 = 5V），输入输出压差至少 2–3V；可调型 LM317 用两只电阻设定输出。

例题先做再展开
本章例题 · 2 题自编 · 按真题题型

  1. 桥式整流变压器副边 U2=20V，求输出直流电压；电容滤波后约多少？

    整流输出 Uo = 0.9×20 = 18V。

    电容滤波带载约 1.2×20 = 24V（空载接近 28.3V）。

  2. 用 7805 构成 5V 稳压电源，输入 12V、负载 0.5A，求调整管功耗。

    压差 = 12−5 = 7V；P = 7V×0.5A = 3.5W。

    要加散热片，否则 7805 会过热保护。

易错点

  • 0.9U2 是整流后平均值，1.2U2 是电容滤波后的工程估算，别混。
  • 78xx 的压差不够会掉出稳压，输入要留 2–3V 余量。
