01

极限与等价无穷小第 1 组

6 张表　·　38 条

考场上真正在用的就这几张：两个重要极限、等价替换表、1^∞ 速算。先把它们背到条件反射，再谈技巧。

四则运算与存在性前提是各个极限都存在（分母极限不为 0）5 条

lim (f ± g) = lim f ± lim g加法可拆，前提两边极限都存在
lim (f · g) = lim f · lim g乘法同理
lim (f / g) = lim f / lim g要求 lim g ≠ 0
lim f(g(x)) = f(lim g(x))外层 f 在对应点连续时才成立
uv = ev ln u幂指函数一律这样转，1^∞、00、∞0 都走这条路

两个重要极限所有三角型与 1^∞ 型题目的源头4 条

lim(sin x / x) = 1　(x→0)推广：lim sin u / u = 1，只要 u→0
lim(1 + 1/x)x = e　(x→∞)等价写法：lim(1 + u)1/u = e（u→0）
1^∞ 型：lim uv = elim v(u−1)u→1、v→∞；比凑对数快，考试直接用
lim(1 + a/x)bx = eab上面的直接推论，见到就套

等价无穷小（x → 0）只能在乘除因子里替换；加减里替换会丢同阶项11 条

sin x ~ tan x ~ arcsin x ~ arctan x ~ x五个一阶等价，最常用的一行
ln(1 + x) ~ x
ex − 1 ~ x		对数与指数各一条
ax − 1 ~ x ln aa = e 时退化成上一条
(1 + x)α − 1 ~ αxα 任意实数；开方、根式都归到这里
1 − cos x ~ x² / 2二阶等价：分母是 x² 时用它
x − sin x ~ x³ / 6三阶，分子分母出现 sin x − x 时必用
tan x − x ~ x³ / 3同上，注意系数是 3 不是 6
x − ln(1 + x) ~ x² / 2二阶，和 1 − cos x 系数相同
arcsin x − x ~ x³ / 6
x − arctan x ~ x³ / 3		反三角的两个三阶等价
tan x − sin x ~ x³ / 2同阶相减的经典结果，直接记
(1 + x)1/x − e ~ −(e/2)xe 的定义式做差，考研常见

数列极限与常用结果n → ∞ 时可以直接用7 条

|q| < 1 时 qn → 0q = 1 时恒为 1；|q| > 1 发散
n1/n → 1
a1/n → 1 (a > 0)		开 n 次方一律趋于 1
nk / an → 0 (a > 1)指数增长快于任何多项式
(ln n)k / nε → 0 (ε > 0)对数增长最慢
(1 + 1/n)n → e，单调递增常用来证不等式 (1+1/n)n < e
n! ~ √(2πn)·(n/e)n斯特林公式，估阶乘的量级
lim (1 + 1/2 + … + 1/n − ln n) = γ欧拉常数 ≈ 0.5772，调和级数的渐近

无穷小的阶与判敛比较两个无穷小的快慢5 条

α/β → 0：α 是 β 的高阶无穷小，记 α = o(β)阶数更高 = 更快趋于 0
α/β → ∞：α 是 β 的低阶无穷小反过来写就是 o
α/β → c ≠ 0：同阶c = 1 时才是等价
α ~ β ⟺ α − β = o(β)等价的定义式，证明题常用
α ~ α′、β ~ β′ ⟹ α/β → α′/β′乘除可换，加减不可换

连续与间断判断类型的分界线6 条

连续：lim f(x) = f(x₀)（x→x₀）三个条件：有定义、有极限、相等
可去间断：左右极限存在且相等 ≠ f(x₀)补定义就能连续
跳跃间断：左右极限都存在但不相等跳跃度 = 右 − 左
无穷间断：至少一侧极限为 ∞如 1/x 在 0 处
振荡间断：极限不存在且不趋于 ∞如 sin(1/x) 在 0 处
闭区间连续 ⟹ 有界、有最值、介值定理零点定理是介值的特例

导数公式与求导法则第 2 组

4 张表　·　35 条

基本表要能默写（每一条都要），法则要会用（复合、隐函数、参数方程是三大高频）。

基本初等函数导数这一张必须一字不差地默写14 条

(C)′ = 0常数
(xμ)′ = μxμ−1μ 任意实数；μ = 1/2 时得 1/(2√x)
(ax)′ = ax ln a
(ex)′ = ex		底数为 e 时系数消失
(loga x)′ = 1/(x ln a)
(ln x)′ = 1/x		同上，底为 e 时最简
(sin x)′ = cos x
(cos x)′ = −sin x		余弦带负号，最容易漏
(tan x)′ = sec²x = 1/cos²x也可以用 1 + tan²x 表示
(cot x)′ = −csc²x = −1/sin²x带负号
(sec x)′ = sec x·tan x
(csc x)′ = −csc x·cot x		正号对：sec 对 tan
(arcsin x)′ = 1/√(1 − x²)|x| < 1
(arccos x)′ = −1/√(1 − x²)与 arcsin 差一个负号
(arctan x)′ = 1/(1 + x²)分母是加号
(arccot x)′ = −1/(1 + x²)分母同样是加号，带负号
(arsh x)′ = 1/√(x² + 1)
(arch x)′ = 1/√(x² − 1)		反双曲，|x| > 1 时用 arch
(arth x)′ = 1/(1 − x²)|x| < 1

求导法则复合与隐函数是考试的主体10 条

(u ± v)′ = u′ ± v′线性
(uv)′ = u′v + uv′乘积法则
(u/v)′ = (u′v − uv′)/v²商的法则，分子顺序不能反
[f(g(x))]′ = f′(g(x))·g′(x)链式法则：由外向内，一层一层乘
反函数：dy/dx = 1 / (dx/dy)先求反函数的导数再取倒数
隐函数：F(x, y) = 0 ⟹ y′ = −Fx / Fy多元写法；一元题直接两边对 x 求导
参数方程：dy/dx = y′(t) / x′(t)x′ ≠ 0
参数方程二阶：d²y/dx² = (y″x′ − y′x″) / (x′)³先对 t 求一次再除以 x′，别直接二次求导
对数求导：y = uv ⟹ (ln y)′ = (v ln u)′幂指函数、连乘连除时的标准操作
莱布尼茨：(uv)(n) = Σ C(n,k) u(k) v(n−k)高阶乘积公式，类比二项式

常用高阶导数n 阶导数的封闭形式，泰勒级数要靠它6 条

(eax)(n) = an eax指数型最省事
(sin ax)(n) = an sin(ax + nπ/2)每求一次相位加 π/2
(cos ax)(n) = an cos(ax + nπ/2)同上
(xm)(n) = m(m−1)…(m−n+1)xm−nn > m 时为 0（m 为正整数）
(ln x)(n) = (−1)n−1(n−1)!/xnn ≥ 1
(1/(1 + x))(n) = (−1)n n!/(1 + x)n+1展开式的直接来源

微分与近似dy 与 Δy 的关系是概念题的常客5 条

dy = f′(x) dx微分定义；Δx = dx
Δy = f(x₀ + Δx) − f(x₀) ≈ f′(x₀)Δx线性近似，误差是 o(Δx)
f(x) ≈ f(x₀) + f′(x₀)(x − x₀)一阶近似
一阶微分形式不变性复合函数可以直接乘，不用管中间变量
可微 ⟺ 可导（一元函数）多元函数里不成立

中值定理与泰勒展开第 3 组

4 张表　·　24 条

证明题的主战场。三个中值定理的条件差别、泰勒的两个余项形式，是失分最集中的地方。

三个中值定理条件逐级放宽，结论逐级具体5 条

罗尔：f 在 [a,b] 连续、(a,b) 可导、f(a)=f(b)⟹ 存在 ξ 使 f′(ξ) = 0
拉格朗日：连续 + 可导⟹ f(b) − f(a) = f′(ξ)(b − a)
柯西：f、g 都连续可导，g′ ≠ 0⟹ [f(b)−f(a)]/[g(b)−g(a)] = f′(ξ)/g′(ξ)
拉格朗日的推论f′ ≡ 0 ⟹ f 为常数；f′ > 0 ⟹ 严格单增
证明不等式的标准套路移项造 F(x) → 看端点值 → 用单调性或中值定理

泰勒公式两种余项：定性用佩亚诺，定量用拉格朗日4 条

f(x) = Σk=0n f(k)(x₀)(x−x₀)k/k! + Rn(x)在 x₀ 处展开
佩亚诺余项：Rn = o((x − x₀)n)求极限用这个
拉格朗日余项：Rn = f(n+1)(ξ)(x−x₀)n+1/(n+1)!估计误差、证不等式用这个
x₀ = 0 时称麦克劳林公式考试九成用的是这一种

常用麦克劳林展开前 3–4 项就要能直接写出来10 条

ex = 1 + x + x²/2! + x³/3! + …（x ∈ ℝ）收敛半径 ∞
sin x = x − x³/3! + x⁵/5! − …（x ∈ ℝ）只含奇次项，符号交替
cos x = 1 − x²/2! + x⁴/4! − …（x ∈ ℝ）只含偶次项
ln(1 + x) = x − x²/2 + x³/3 − …（−1 < x ≤ 1）端点 x = 1 收敛（交错），x = −1 发散
(1 + x)α = 1 + αx + α(α−1)x²/2! + …（|x| < 1）α 为任意实数；α = −1 退化成下一条
1/(1 − x) = 1 + x + x² + …（|x| < 1）几何级数，所有幂级数题的母本
1/(1 + x) = 1 − x + x² − …（|x| < 1）符号交替
arctan x = x − x³/3 + x⁵/5 − …（|x| ≤ 1）端点也收敛（条件收敛）
arcsin x = x + x³/6 + 3x⁵/40 + …（|x| < 1）系数是双阶乘比，少考但别写错
tan x = x + x³/3 + 2x⁵/15 + …（|x| < π/2）用于 tan x − x 的展开

洛必达与未定式先验证条件，再考虑换法5 条

只适用于 0/0 与 ∞/∞其他型先化成这两种
0·∞ 型：化成一个在分母写成 f/(1/g) 或 g/(1/f)
∞ − ∞ 型：通分或有理化常见于 1/x − 1/(ex−1)
1^∞、00、∞0：取对数转成 0·∞ 再转 0/0
洛必达失效的信号求导后更复杂、或振荡不存在（如 x/√(x²+1)、x + sin x）

不定积分基本表与方法第 4 组

5 张表　·　36 条

基本表 20 条要能默写；方法只有三类，但三角有理式的变形是分水岭。

基本积分表（一）幂、指数、对数型7 条

∫ xμ dx = xμ+1/(μ+1) + Cμ ≠ −1
∫ dx/x = ln|x| + Cμ = −1 的例外，别忘了绝对值
∫ ex dx = ex + C
∫ ax dx = ax/ln a + Ca > 0 且 a ≠ 1
∫ ln x dx = x ln x − x + C分部一次的结果，可以直接记
∫ dx/(1 + x²) = arctan x + C分母加号
∫ dx/√(1 − x²) = arcsin x + C分母根号减

基本积分表（二）三角型9 条

∫ sin x dx = −cos x + C
∫ cos x dx = sin x + C		符号别反
∫ sec²x dx = tan x + C
∫ csc²x dx = −cot x + C		与导数表对照记
∫ sec x tan x dx = sec x + C
∫ csc x cot x dx = −csc x + C		同上
∫ tan x dx = −ln|cos x| + C也写作 ln|sec x| + C
∫ cot x dx = ln|sin x| + C
∫ sec x dx = ln|sec x + tan x| + C经典结果，推导用凑微分
∫ csc x dx = ln|csc x − cot x| + C也写作 ln|tan(x/2)| + C
∫ sin²x dx = x/2 − sin 2x/4 + C降幂 (1 − cos 2x)/2
∫ cos²x dx = x/2 + sin 2x/4 + C降幂 (1 + cos 2x)/2

基本积分表（三）含 a 的四种标准形，换元题的终点6 条

∫ dx/(a² + x²) = (1/a)arctan(x/a) + C配方后都归到这里
∫ dx/√(a² − x²) = arcsin(x/a) + Ca > 0
∫ dx/(x² − a²) = (1/2a)ln|(x − a)/(x + a)| + C部分分式拆开
∫ dx/√(x² ± a²) = ln|x + √(x² ± a²)| + C两个符号都是这个结果
∫ √(a² − x²) dx = (x/2)√(a² − x²) + (a²/2)arcsin(x/a) + C圆面积的核心积分
∫ dx/(x² + a²)² = x/(2a²(x² + a²)) + (1/2a³)arctan(x/a) + C降次递推的结果

三大方法先看能不能凑微分，再考虑换元，最后分部8 条

第一类换元：∫ f(φ)φ′dx = ∫ f(u) du凑微分，最常见的入口
第二类换元：x = ψ(t)，dx = ψ′(t)dt根式、三角代换走这条
√(a² − x²)：令 x = a sin t用 1 − sin² = cos²
√(a² + x²)：令 x = a tan t用 1 + tan² = sec²
√(x² − a²)：令 x = a sec t用 sec² − 1 = tan²
√(ax + b)：令 t = √(ax + b)根式整体换元最省事
分部：∫ u dv = uv − ∫ v duu 的顺序按「反对幂指三」
分部循环型：∫ex sin x dx 连做两次回到自身移项解出，别忘 + C

有理函数与三角有理式拆项是唯一出路，但要拆得对6 条

真分式：P/Q 且 deg P < deg Q假分式先做多项式除法
Q 有单实根：A/(x − a)每个根一个一次项
Q 有重根：(A₁/(x−a) + A₂/(x−a)² + …)k 重根写 k 项
Q 有不可约二次： (Bx + C)/(x² + px + q)分子写一次式，再配方用 arctan
万能代换：t = tan(x/2)sin x = 2t/(1+t²)，cos x = (1−t²)/(1+t²)，dx = 2dt/(1+t²)
∫ R(sin x, cos x) dx 的对称技巧sin 奇次：凑 d(cos x)；cos 奇次：凑 d(sin x)

定积分与它的应用第 5 组

7 张表　·　39 条

定积分是「一个数」，所有性质都围绕这一点；应用题只有面积、体积、弧长三类，公式记住就不会错。

基本定理与变限积分微积分的心脏5 条

牛顿-莱布尼茨：∫ₐᵇ f(x)dx = F(b) − F(a)F 是 f 的任一原函数
d/dx ∫ₐx f(t)dt = f(x)变上限求导
d/dx ∫φ(x)ψ(x) f(t)dt = f(ψ)ψ′ − f(φ)φ′上下限都是函数时两项都要扣
∫ₐᵇ f = −∫ba f
∫ₐᵃ f = 0		交换上下限变号
∫ₐᵇ f = ∫ₐc f + ∫cb f区间可加，分段函数必用

定积分的性质估计与比较题的基础5 条

线性：∫(αf + βg) = α∫f + β∫g
保号：f ≥ 0 ⟹ ∫ₐᵇ f ≥ 0由此得单调性：f ≥ g ⟹ ∫f ≥ ∫g
估值：m(b − a) ≤ ∫ₐᵇ f ≤ M(b − a)m、M 是 f 在区间上的最小、最大值
|∫ₐᵇ f| ≤ ∫ₐᵇ |f|绝对值不能随便进出积分号
积分中值：∫ₐᵇ f = f(ξ)(b − a)ξ ∈ [a,b]，f 连续

对称性与周期性能省一半计算量的技巧5 条

∫−aa f = 0（f 为奇函数）奇函数在对称区间积分为 0

∫₀π/2 sinn x dx = ∫₀π/2 cosn x dx两者相等

偏导、全微分与链式法则把其他变量当常数7 条

z = f(x,y)：zx = ∂z/∂x对 x 求导时 y 视为常数

极值与条件极值先找驻点，再判类型5 条

曲线积分两类要分清：对弧长 / 对坐标5 条

收敛的必要条件与基准级数判断的第一步4 条

收敛的必要条件：un → 0不满足直接发散；满足未必收敛

正项级数判别法按「含什么」选方法5 条

比较判别：un ≤ vn，Σv 收敛 ⟹ Σu 收敛找已知敛散的对象比
极限比较：un/vn → c（0 < c < ∞）则同敛散最常用
比值：un+1/un → ρρ < 1 收敛，ρ > 1 发散，ρ = 1 失效

交错级数与任意项莱布尼茨是唯一工具4 条

莱布尼茨：un 单调递减且 → 0 ⟹ Σ(−1)n−1un 收敛两个条件都要验
绝对收敛：Σ|un| 收敛 ⟹ Σun 收敛反之不成立
条件收敛：Σun 收敛但 Σ|un| 发散如 Σ(−1)n/√n
判断顺序：先看绝对值级数，再看交错「收敛」与「绝对收敛」是两问
