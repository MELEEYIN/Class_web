========================================================================
  全章地图：这一章到底在讲什么
========================================================================

前面所有元件都是"各自独立"的：电阻就是电阻，电感就是电感，
互不影响。

这一章的第一个新东西是【互感】：两个线圈靠得近，一个的电流变化
会在另一个里感应出电压。从此两个线圈"拴在一起"，不能分开算。

第二个新东西是【理想变压器】：它只变换电压、电流和阻抗，
自己不耗能、不储能 —— 是工程上最常用的"变换器"。

这一章只回答三个问题：

    ① 两个线圈耦合了，方程怎么列？        → 同名端定符号
    ② 耦合太麻烦，能不能化简？            → 去耦等效（T 形）
    ③ 变压器怎么用？                      → 三个变换关系 + 阻抗变换

一共五件事：

   ① 互感与同名端：M 的正负怎么定              （10-1）
   ② 串联：顺串与反串                          （10-2）
   ③ 去耦等效：化成不含互感的 T 形网络          （10-2）
   ④ 变压器原理与理想变压器                    （10-4、10-5）
   ⑤ 阻抗变换：变比 n 的平方关系                （10-5）

时间表：

   0 - 5  min   第 1 站  互感与同名端
   5 - 11 min   第 2 站  顺串与反串（最容易记反的地方）
  11 - 17 min   第 3 站  去耦等效
  17 - 22 min   第 4 站  变压器与理想变压器
  22 - 26 min   第 5 站  阻抗变换与耦合电感的功率
  26 - 30 min   第 6 站  贯穿实例：把 8Ω 喇叭变成 800Ω


★★ 贯穿全章的实例（一个真实的工程场景）★★

    L₁ = 4H、L₂ = 1H、k = 0.5 的一对耦合线圈；
    再加一个 N₁ = 1000、N₂ = 100 的变压器。

    · 互感系数：M = k√(L₁L₂) = 0.5×2 = 1H
    · 顺串：L = 4+1+2 = 7H；反串：L = 4+1−2 = 3H
    · 去耦（同名端相连）：L₁−M = 3H、L₂−M = 0H、M = 1H
    · 变压器：n = 10，8Ω 喇叭 → 原边看到 800Ω

    最后这一条是真实用途：输出变压器把 8Ω 喇叭变换成电子管放大器
    需要的 800Ω —— 功率才能送得出去。


========================================================================
  第 1 站（0-5 min）  互感与同名端
                                对应教材 10-1
------------------------------------------------------------------------

【互感是什么】

    两个线圈放在一起，线圈 1 的电流 i₁ 产生的磁通有一部分穿过线圈 2。
    当 i₁ 变化时，穿过线圈 2 的磁通也变，于是在线圈 2 中感应出电压。

    这就是【互感】，用 M 表示（单位 H），和自感是同一个单位。

【伏安关系：多了一项】

        u₁ = L₁·di₁/dt + M·di₂/dt
        u₂ = M·di₁/dt + L₂·di₂/dt

    相量形式（和第 8 章一样，把 d/dt 换成 jω）：

        U̇₁ = jωL₁·İ₁ + jωM·İ₂
        U̇₂ = jωM·İ₁ + jωL₂·İ₂

    每一项都是"jω 乘以某个电感再乘以某个电流"，形状完全统一 ——
    所以相量法在这一章照样能用。

【M 的正负：全靠同名端】

    M 那一项前面的符号可正可负，判断依据是【同名端】：

        · 两个电流都从同名端流入（或都流出）→ 互感电压取【+】
        · 一个流入、一个流出                      → 互感电压取【−】

    同名端在电路图上用一个实心圆点标出，表示"这两个端子绕向相同"。
    点画在哪一端由线圈的绕法决定，做题时题目会给。



【M 的最大值：耦合系数 k】

        M = k·√(L₁L₂)        0 ≤ k ≤ 1

    k 叫耦合系数：
        k = 1    全耦合（磁通一点不漏，理想变压器就是这种）
        k = 0    完全没有耦合（离得很远）
        实际变压器 k 在 0.9 ~ 0.99；空心线圈只有 0.1 左右

    这条式子还有个用处：知道 M 和两个自感，就能算出 k。

【一条重要的提醒】

    互感不是"多了一个元件"，它只改变【伏安关系】。
    所以电路定理（KCL、KVL、节点法、网孔法、戴维南）全都不变，
    只是列方程时每个线圈的电压要多算一项 jωM·İ。

    这也是第 8 章那句话的延续：相量法一开，前面所有工具照搬。


========================================================================
  第 2 站（5-11 min）  顺串与反串：最容易记反的地方
                                对应教材 10-2
------------------------------------------------------------------------

    两个线圈串联，只有两种接法，等效电感差 4M。

【顺串：磁通相加】

        L = L₁ + L₂ + 2M

    接法特点：【异名端相连】——把线圈 1 的"无点端"接到线圈 2 的"有点端"。
    这样电流从线圈 1 的同名端流入、从线圈 2 的同名端流入，
    两个磁通方向相同，互相加强。

【反串：磁通相减】

        L = L₁ + L₂ − 2M

    接法特点：【同名端相连】——把两个"有点端"接在一起。
    这样电流从线圈 1 的同名端流入、却从线圈 2 的"无点端"流入，
    两个磁通方向相反，互相抵消。



【★ 记忆口诀（很多人背反，请务必记这条）】

        异名端相连 → 顺串 → +2M → 磁通相加 → 等效电感【变大】
        同名端相连 → 反串 → −2M → 磁通相减 → 等效电感【变小】

    怎么检查自己记没记反？用一个极端例子验证：

        若 k = 1 且 L₁ = L₂ = M，则某一种接法应得到 L = 0
        （磁通完全抵消，相当于两根线绕在一起互相抵消）
        代入：L₁+L₂−2M = 2L − 2L = 0 ✓ 这就是【同名端相连】
        所以"同名端相连 → 相减"是对的 ✓

【用贯穿实例算一遍】

    L₁ = 4H、L₂ = 1H、M = 1H：

        顺串（异名端相连）：L = 4 + 1 + 2 = 7H
        反串（同名端相连）：L = 4 + 1 − 2 = 3H

    差值 4M = 4H。工程上正是用这个性质测 M：
    两种接法各测一次电感，L_顺 − L_反 = 4M，就能反解出 M。


========================================================================
  第 3 站（11-17 min）  去耦等效：把 M 消掉
                                对应教材 10-2
------------------------------------------------------------------------

【为什么要去耦】

    含互感的电路列方程很别扭：两个线圈的电压互相牵扯。
    如果两线圈有一端连在一起，就能把它换成【不含互感的 T 形网络】，
    之后按普通电路算，M 彻底消失。

【两种情况的等效（记这两行）】

    ① 同名端相连 → T 形：L₁ − M、L₂ − M、M
    ② 异名端相连 → T 形：L₁ + M、L₂ + M、−M

    注意第二种会出现【负电感】，数学上完全允许，不用怕。



【为什么这两个等效是对的：用串联结果反推】

    拿贯穿实例（L₁=4、L₂=1、M=1）验证第 ① 种：

        T 形三个臂：L₁−M = 3H、L₂−M = 0H、M = 1H
        如果中间端空置、只用两端串联：
            L = (L₁−M) + (L₂−M) = 3 + 0 = 3H
        而第 2 站说"同名端相连 = 反串 = 3H" ✓ 一致

    再验证第 ② 种（异名端相连）：

        T 形：L₁+M = 5H、L₂+M = 2H、−M = −1H
        串联（中间端空置）：L = 5 + 2 = 7H
        与"异名端相连 = 顺串 = 7H" ✓ 一致

    两种去耦公式都能还原第 2 站的串联结论 ——
    这说明公式记对了，也说明第 2 站那个"最容易记反"的口诀是自洽的。

【去耦的适用条件（很重要）】

    · 必须【有一端相连】。完全隔离的两线圈之间无法去耦，
      只能在方程里保留 jωM·İ 那一项。
    · 去耦只对【外部等效】，内部的电流分布会变 ——
      和第 2 章"对外等效"、第 4 章戴维南"只对外等效"是同一个道理。

【含耦合电感的电路怎么算（通用步骤）】

    ① 标出同名端，据此刻 M 的正负
    ② 能去耦就先化成 T 形（有一端相连时）
    ③ 去耦后按第 8 章的方法：写阻抗、列 KCL/KVL、解复数方程
    ④ 回时域（如果需要）


========================================================================
  第 4 站（17-22 min）  变压器与理想变压器
                                对应教材 10-4、10-5
------------------------------------------------------------------------

【实际变压器】

    两个绕组套在同一个铁芯上，靠磁通耦合 —— 本质上就是 k 接近 1 的互感。
    所以实际变压器可以用"互感 + 自感 + 负载"的电路来建模。

【理想变压器：三条理想化】

    ① 无损耗（绕组电阻为零、铁芯无涡流损耗）
    ② 全耦合（k = 1，没有漏磁）
    ③ 自感、互感都趋于无穷（但比值有限）

    于是伏安关系变得极简单：

        u₁/u₂ = N₁/N₂ = n

    注意：理想变压器【不是】互感元件 ——
    它的电压比和频率无关、和负载无关，只是匝数比。



【三个变换关系（全章最该背的三条）】

        电压：U₁/U₂ = n = N₁/N₂        （电压跟着匝数【正比】）
        电流：I₁/I₂ = 1/n              （电流【反比】）
        阻抗：Zin = n²·ZL              （阻抗是【平方】）

    Zin 是"从原边看进去"的等效阻抗。

    记忆：只有阻抗带平方，电压电流都是一次方。
    为什么阻抗是平方？因为 Z = U/I，电压乘了 n，电流又除了 n，
    两次叠加就变成 n²。

【功率关系】

        P₁ = U₁I₁ = U₂I₂ = P₂

    理想变压器不耗能、不储能，只是"搬运"功率。
    所以它既不是耗能元件，也不是储能元件 —— 这是它和 R、L、C 的本质区别。


========================================================================
  第 5 站（22-26 min）  阻抗变换与耦合电感的功率
------------------------------------------------------------------------

【阻抗变换的用处：阻抗匹配】

    很多信号源（放大器、传感器、天线）都有一个"最佳负载"，
    负载不匹配，功率就送不出去、甚至反射回来。

    变压器的 Zin = n²·ZL 就是用来"造出"想要的负载：

        想要 800Ω，手上只有 8Ω 喇叭 → 选 n = √(800/8) = 10

    这就是老式电子管收音机输出变压器的作用。

【耦合电感的功率（了解即可）】

    · 两个耦合线圈之间通过磁场传递能量，但【不消耗】能量
    · 互感本身既不产生也不消耗功率，只是把能量在两个线圈间倒来倒去
    · 所以含耦合电感的电路，有功功率仍然只由电阻消耗

    考试里如果问"互感元件吸收的功率"，答案通常是 0（纯无功），
    或者说它只在两个线圈之间交换。

【变压器的实际限制（了解）】

    · 只能变换【交流】。直流时磁通不变，副边没有感应电压 ——
      变压器不能用于直流（这是变压器与开关电源的分界）
    · 实际变压器有损耗（铜损、铁损）、有漏磁（k < 1）
    · 频率越高，铁芯越要用铁氧体（避免涡流）


========================================================================
  第 6 站（26-30 min）  贯穿实例：把 8Ω 喇叭变成 800Ω
------------------------------------------------------------------------

【题目】

    一对耦合线圈：L₁ = 4H、L₂ = 1H、k = 0.5。
    一个变压器：N₁ = 1000、N₂ = 100。
    变压器副边接 8Ω 喇叭，原边接放大器（最佳负载 800Ω）。

【第 1 步：互感系数】

    M = k√(L₁L₂) = 0.5 × √(4×1) = 1H

【第 2 步：耦合线圈的等效电感（两种接法）】

    顺串（异名端相连）：L = 4 + 1 + 2×1 = 7H
    反串（同名端相连）：L = 4 + 1 − 2×1 = 3H

    注意：题目若问"哪种接法电感大"，答案是异名端相连（顺串）。

【第 3 步：去耦（若同名端相连）】

    化成 T 形：L₁−M = 3H、L₂−M = 0H、M = 1H
    校验：3 + 0 = 3H = 反串 ✓
    （L₂−M = 0 表示那一臂相当于导线，正常）

【第 4 步：变压器的阻抗变换】

    n = N₁/N₂ = 1000/100 = 10
    Zin = n²·ZL = 10² × 8 = 800Ω

    → 放大器看到的就是 800Ω，正好匹配 ✓



【第 5 步：算一算电压电流（假设原边 100V）】

    U₁ = 100V
    U₂ = U₁/n = 10V
    I₂ = U₂/ZL = 10/8 = 1.25A
    I₁ = I₂/n = 0.125A

    校验功率：
        P₁ = U₁I₁ = 100 × 0.125 = 12.5W
        P₂ = U₂I₂ = 10 × 1.25 = 12.5W     相等 ✓

    → 理想变压器确实不耗能。如果这 12.5W 全部进了喇叭，
      那么用 10:1 的变压器比直接接（8Ω 对 800Ω 严重失配）能多送上十几倍功率。

【结果一览】

        M = 1H
        顺串 7H / 反串 3H（异名端相连为顺串）
        去耦 T 形：3H、0H、1H
        n = 10，Zin = 800Ω，P₁ = P₂ = 12.5W

------------------------------------------------------------------------
  参考答案
------------------------------------------------------------------------

  1. 多了互感项 jωM·İ（或时域的 M·di/dt）。
  2. 由【同名端】决定：两电流都从同名端流入取 +，一进一出取 −。
  3. k = M/√(L₁L₂)，0 ≤ k ≤ 1；k = 1 表示全耦合、无漏磁。
  4. 顺串 L = L₁+L₂+2M；反串 L = L₁+L₂−2M。
  5. 异名端相连为顺串。因为这样两个电流都从各自的同名端流入，
     产生的磁通方向相同、互相加强，所以等效电感变大。
  6. L₁−M、L₂−M、M（三个臂构成 T 形）。
  7. 必须【有一端相连】；完全隔离的两线圈不能去耦。
  8. 无损耗、全耦合（k=1）、自感互感趋于无穷但比值有限。
  9. U₁/U₂ = n；I₁/I₂ = 1/n；Zin/ZL = n²。
 10. 因为 Z = U/I，电压乘了 n，电流又除了 n，两次叠加就是 n²。
 11. 不能。直流时磁通不变化，副边没有感应电压，变压器不工作。
 12. 顺串 4+1+2 = 7H；反串 4+1−2 = 3H。


========================================================================
  本章最容易犯的 6 个错
========================================================================

  1. 顺串/反串与同名端/异名端的对应关系记反
     正确：异名端相连 = 顺串 = +2M；同名端相连 = 反串 = −2M。
     用"k=1 时某接法得 L=0"去验证，就不会错。

  2. 互感电压的符号随手写
     必须先找到同名端，再判断"电流是从同名端流入还是流出"。

  3. 去耦公式用错场合
     同名端相连用 L₁−M、L₂−M、M；异名端相连用 L₁+M、L₂+M、−M。
     两套公式别混。

  4. 对完全隔离的两线圈去耦
     没有公共端就不能去耦，必须保留 jωM·İ。

  5. 阻抗比漏掉平方
     Zin = n²ZL，不是 n·ZL。电压电流是一次，阻抗是二次。

  6. 认为变压器可以变直流
     变压器靠磁通变化工作，直流时副边没电压。
