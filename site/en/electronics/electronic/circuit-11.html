========================================================================
  全章地图：这一章到底在讲什么
========================================================================

前面所有电路都是"单相"的：一个电源、两根线。

工业上用的却是【三相】：三个电源、三根线（有时四根）。
为什么？因为三相有两个单相比不了的好处：

    ① 同样体积的电机，三相的输出功率更大、转矩更平稳
    ② 输电时三根线的总损耗更低

这一章只回答一个问题：

    三根线上的电压电流，与每相内部的电压电流，是什么关系？

一共五件事：

   ① 对称三相电源：三个量之和为零                （12-1）
   ② 星形（Y）连接：线电压 = √3 相电压，超前 30° （12-2）
   ③ 三角形（Δ）连接：线电流 = √3 相电流，滞后 30°（12-2）
   ④ 对称三相电路的计算：只算一相                 （12-3）
   ⑤ 三相功率：√3·U_L·I_L·cosφ                   （12-5）

时间表：

   0 - 5  min   第 1 站  对称三相电源与相序
   5 - 11 min   第 2 站  星形连接：√3 与 +30°
  11 - 17 min   第 3 站  三角形连接：√3 与 −30°
  17 - 22 min   第 4 站  只算一相（本章唯一的技巧）
  22 - 26 min   第 5 站  三相功率与瞬时功率恒定
  26 - 30 min   第 6 站  贯穿实例 + 自测


★★ 贯穿全章的实例（数值特意配成 0.6/0.8）★★

    对称三相电源，相电压 U_P = 220V（线电压 U_L = 220√3 ≈ 381V）。
    对称星形负载，每相 Z = 30 + j40Ω。

    · |Z| = √(30²+40²) = 50Ω，φ = 53.13°，cosφ = 0.6
    · 相电流 = 线电流 = 220/50 = 4.4A
    · 三相有功 P = 3·220·4.4·0.6 = 1742.4W
    · 用线量算：√3·381·4.4·0.6 = 1742.4W ✓ 完全相同
    · 三相瞬时功率之和恒为 1742.4W（不随时间变）

    最后一条是三相电的精髓：单相功率是脉动的，三相叠加后
    脉动恰好抵消 —— 所以三相电机转起来是平稳的。


========================================================================
  第 1 站（0-5 min）  对称三相电源与相序
                                对应教材 12-1
------------------------------------------------------------------------

【什么是三相电源】

    三个电压源，满足三条：
        ① 幅值相等
        ② 频率相同
        ③ 相位互差 120°

    写作：
        u_A = √2·U_P·cos(ωt)
        u_B = √2·U_P·cos(ωt − 120°)
        u_C = √2·U_P·cos(ωt − 240°) = √2·U_P·cos(ωt + 120°)

    注意：B 滞后 A 120°，C 滞后 B 120°（也就是超前 A 120°）。

【相序】

    A → B → C 这个顺序叫【正序】。
    工程上规定：正序时三相电机的转向是"正转"。

    如果任意对调两根线（比如 A 和 B），相序就变成反序，电机反转 ——
    这就是为什么电工接线时"相序"必须核对。



【★ 最重要的一条：三个相量之和为零】

    U̇A + U̇B + U̇C = 0

    为什么？三个长度相等、互差 120° 的箭头，首尾相接正好闭合
    成一个等边三角形，所以合矢量为零。

    这一条是全章所有结论的根源：
        · 星形连接的中性点等电位 → 中线可以省掉
        · 三相电路可以"只算一相" → 计算量降到 1/3
        · 三相瞬时功率之和恒定 → 转矩平稳

    只要题目说"对称三相"，这三个结论就可以直接用。


========================================================================
  第 2 站（5-11 min）  星形连接：√3 与 +30°
                                对应教材 12-2
------------------------------------------------------------------------

【什么叫星形连接】

    三个负载各有一端接在一起（这个公共点叫【中性点 N】），
    另一端分别接 A、B、C 三根相线。

    电源侧也可以星形连接，同样有个中性点 N（零点）。

【四个量的定义（这四个字必须分清）】

    相电压 U_P：每相负载（或每相电源）两端之间的电压，即 A 到 N
    线电压 U_L：两根相线之间的电压，即 A 到 B
    相电流 I_P：流过每相负载的电流
    线电流 I_L：流过每根相线的电流

    ★ "相"指内部，"线"指外部。所有易错题根源都在这两个字的混淆。

【星形连接的两个关系】

    ① 电流：I_L = I_P
       因为一条相线上只串着一个负载，没有别的支路，
       流进线路的电流就是流过负载的电流。

    ② 电压：U_L = √3·U_P，且线电压【超前】对应的相电压 30°

       推导：U̇AB = U̇A − U̇B
       代入 U̇A = U_P∠0°、U̇B = U_P∠−120°：
           U̇AB = U_P(1 − ∠−120°) = U_P(1.5 + j0.866) = √3·U_P∠30°
       → 模是 √3 倍，角多了 30° ✓



【工程上的对应数值（记住）】

        U_P = 220V  →  U_L = 220√3 ≈ 381V（标称 380V）
        U_L = 380V  →  U_P = 380/√3 ≈ 220V

    所以"家用 220V、工业 380V"说的是同一个三相系统：
    220V 是相电压（一根线对零线），380V 是线电压（两根线之间）。

【一条常考的判断】

    星形连接时：线电压比相电压【大】（√3 倍）
    三角形连接时：线电压等于相电压

    一句话：星形的"线"比"相"大一点（√3）。


========================================================================
  第 3 站（11-17 min）  三角形连接：√3 与 −30°
                                对应教材 12-2
------------------------------------------------------------------------

【什么叫三角形连接】

    三个负载首尾相接成一个三角形，三个顶点分别接 A、B、C 三根相线。
    没有中性点。

【三角形连接的两个关系】

    ① 电压：U_L = U_P
       因为每个负载直接跨在两根相线之间，
       负载两端电压就是线电压 —— 没有中间环节。

    ② 电流：I_L = √3·I_P，且线电流【滞后】相电流 30°

       推导：İA = İAB − İCA
       代入相电流互差 120°：İA 的模是 √3 倍，角比 İAB 小 30°



【★ 星形与三角形对照（考试最爱考这张表）】

    连接方式      线电压 vs 相电压        线电流 vs 相电流
    -------------------------------------------------------------------
    星形 Y        U_L = √3 U_P（超前 30°）  I_L = I_P
    三角形 Δ      U_L = U_P                I_L = √3 I_P（滞后 30°）

    记忆法：
        星形 —— "线"电压大 √3（因为两相串联分压）
        三角 —— "线"电流大 √3（因为两相电流叠加）

    再记一条：两个 √3 都伴随 ±30°，Y 是 +30°，Δ 是 −30°。

【什么时候用哪种接法】

    星形：
        · 需要中性点（比如单相负载要从三相取电）
        · 高压电机（每相承受的电压低一些，绝缘要求低）
   三角形：
        · 不需要中性点
        · 大电流、低电压场合

    同一个负载，改成三角形接法后每相电压变成 √3 倍，
    功率变成 3 倍 —— 这就是"星-三角启动"能降低启动电流的原因
    （启动时先接星形，运行后切换成三角形）。


========================================================================
  第 4 站（17-22 min）  只算一相：本章唯一的技巧
                                对应教材 12-3
------------------------------------------------------------------------

【为什么能只算一相】

    对称三相电路有一个极强的性质：

        三个相电压之和为零  →  中性点 N 与电源零点等电位
        →  中线电流为零（中线可以省掉）
        →  三相之间【互不影响】

    既然互不影响，算 A 相就够了：
        B 相的结果只是把 A 相的相位减 120°
        C 相的结果只是把 A 相的相位加 120°
        模长完全一样



【标准解题四步】

    第 1 步  把负载化成星形（如果是三角形，先做 Δ→Y 变换）
    第 2 步  取 A 相，画单相等效电路（一个相电压 + 一个阻抗）
    第 3 步  算 A 相的电流（或电压）
    第 4 步  按相序写出 B、C 相的结果

    ★ Δ→Y 变换的公式（第 2 章的 Y-Δ 变换的逆）：
          Z_Y = Z_Δ / 3
      所以三角形负载 30+j40Ω 化成星形是 10+j13.33Ω。

【为什么"先化星形"】

    因为星形有中性点，单相等效电路才成立。
    三角形没有中性点，必须先变换。

【一条重要提醒】

    对称三相电路的中性线电流为零，所以中线接不接都一样（可以省掉）。
    但如果负载【不对称】，中线电流就不为零 —— 这时中线绝不能断开，
    否则中性点会漂移，三相电压全乱（这是 12-4 节不对称三相的内容）。


========================================================================
  第 5 站（22-26 min）  三相功率与瞬时功率恒定
                                对应教材 12-5
------------------------------------------------------------------------

【三相功率】

    三相总功率就是三个单相功率之和。用两种算法都行：

        用相量：P = 3·U_P·I_P·cosφ
        用线量：P = √3·U_L·I_L·cosφ

    两种完全等价（因为 U_L = √3U_P 时，3U_P I_P = √3·U_L·I_L）。

    同理：
        Q = 3·U_P·I_P·sinφ = √3·U_L·I_L·sinφ
        S = 3·U_P·I_P     = √3·U_L·I_L

    注意：cosφ 里的 φ 仍然是【每相】的阻抗角，不是线电压与线电流的夹角。

【★ 瞬时功率恒定：三相电最大的优点】

    单相电路的瞬时功率：
        p = ui = U_P I_P·cosφ + U_P I_P·cos(2ωt − φ)
        后半项以 2ω 脉动，功率时大时小。

    三相的三个脉动分量相位互差 120°×2 = 240°，
    它们加起来恰好为零，于是：

        p_total = p_A + p_B + p_C = 3·U_P·I_P·cosφ = P（恒定）

    贯穿实例：无论 ωt 取何值，p_total 恒为 1742.4W。



【为什么这很重要】

    · 单相电机：功率脉动 → 转矩脉动 → 振动、噪声
    · 三相电机：功率恒定 → 转矩平稳 → 安静、寿命长

    这就是工厂里的大功率电机几乎全是三相的原因。

【补充：三相功率的测量】

    三瓦特计法：三个功率表分别测三相，读数相加。
    两瓦特计法：三线制（无中线）时只用两个表，两读数之和就是总功率
    （这个方法对【不对称】负载也成立，是电气测量的常考点）。


========================================================================
  第 6 站（26-30 min）  贯穿实例：把整章算一遍
------------------------------------------------------------------------

【题目】

    对称三相电源 U_P = 220V，对称星形负载 Z = 30 + j40Ω。
    求：线电压、相电流、三相功率、瞬时功率。

【第 1 步：线电压】

    U_L = √3·U_P = √3 × 220 ≈ 381.05V（标称 380V）

【第 2 步：负载阻抗】

    |Z| = √(30² + 40²) = √2500 = 50Ω
    φ = arctan(40/30) = 53.13°
    cosφ = 30/50 = 0.6，sinφ = 40/50 = 0.8

【第 3 步：电流（星形：线电流 = 相电流）】

    I_P = U_P/|Z| = 220/50 = 4.4A
    I_L = I_P = 4.4A

    相量形式（以 A 相为基准）：
        U̇A = 220∠0°V，İA = 4.4∠−53.13°A（滞后 53.13°）
        İB = 4.4∠(−53.13° − 120°) = 4.4∠−173.13°A
        İC = 4.4∠(−53.13° + 120°) = 4.4∠66.87°A

    校验：三者之和 = 0 ✓（对称三相电流和为零）

【第 4 步：三相功率】

    用相量算：
        P = 3·U_P·I_P·cosφ = 3 × 220 × 4.4 × 0.6 = 1742.4W
        Q = 3·U_P·I_P·sinφ = 3 × 220 × 4.4 × 0.8 = 2323.2var
        S = 3·U_P·I_P = 3 × 220 × 4.4 = 2904VA

    用线量算（校验）：
        P = √3·U_L·I_L·cosφ = √3 × 381.05 × 4.4 × 0.6 = 1742.4W ✓

    校验视在功率：
        √(P² + Q²) = √(1742.4² + 2323.2²) = 2904VA ✓

【第 5 步：瞬时功率】

    p_total = 1742.4W，与 ωt 无关（恒为常数）。

    可以用任意时刻验证：ωt = 0° 时
        p_A + p_B + p_C = 1742.4W ✓

【第 6 步：如果负载改成三角形接法】

    Δ 连接：线电压 = 相电压 = 381.05V
    每相电流 = 381.05/50 = 7.62A
    线电流 = √3 × 7.62 = 13.2A
    三相功率 = 3 × 381.05 × 7.62 × 0.6 = 5227.2W

    对比星形的 1742.4W：正好 3 倍 ✓
    （因为每相电压变成 √3 倍，功率 ∝ U²，所以 3 倍）
    这就是"星-三角启动"能降低启动电流的原理。

【结果一览】

        U_L = 381V，I_P = I_L = 4.4A
        P = 1742.4W，Q = 2323.2var，S = 2904VA，cosφ = 0.6
        p_total ≡ 1742.4W（恒定）

========================================================================
  本章最容易犯的 6 个错
========================================================================

  1. 线量、相量混用
     "线"是外部两根线之间，"相"是内部每相。
     星形是 线电压 = √3 相电压；三角形是 线电流 = √3 相电流。
     两个 √3 不在同一个量上，千万别记串。

  2. ±30° 记反
     星形：线电压【超前】相电压 30°
     三角：线电流【滞后】相电流 30°

  3. 三角形负载直接算单相
     三角形没有中性点，必须先 Δ→Y（Z_Y = Z_Δ/3）才能用单相法。

  4. 功率公式里用了错误的 φ
     cosφ 里的 φ 是【每相】的阻抗角，不是线电压与线电流的夹角。

  5. 用 √3·U_L·I_L 时忘了乘 cosφ
     √3·U_L·I_L 是视在功率 S（单位 VA），不是有功 P（单位 W）。

  6. 认为中线可以随便断
     只有在【对称】时中线电流才为零。不对称负载断中线会出事故。
