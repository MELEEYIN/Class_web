========================================================================
  全章地图：这一章到底在讲什么
========================================================================

第 2 章教的是"技巧"：看到两个电阻并联就合并，看到 Y 形就转 Δ。
技巧靠眼力，眼睛看不到就没办法了。

第 3 章教的是"通用方法"：不管电路长什么样，照着步骤走一定能解出来。
代价是计算量 —— 但通用方法可以被机器执行，这是所有仿真软件的基础。

这一章只回答两个问题：

   ① 一个电路最少要列几个方程？        （只能列这么多，多了就线性相关）
   ② 同样的电路，怎么列方程数最少？    （决定你手算半小时还是一分钟）

一共五件事：

   ① 把电路抽象成"图"                   （3-1）      ← 数方程的依据
   ② 数独立方程：n-1 与 b-n+1            （3-2）      ← 全章的地基
   ③ 支路电流法：b 个方程                （3-3）      ← 方程最多，只作理解
   ④ 网孔 / 回路电流法：b-n+1 个方程     （3-4、3-5） ← 平面电路的首选
   ⑤ 节点电压法：n-1 个方程              （3-6）      ← 最常用，考试默认

时间表：

   0 - 4  min   第 1 站  电路的图：树、树支、连支
   4 - 8  min   第 2 站  独立方程数：n-1 和 b-n+1
   8 - 14 min   第 3 站  网孔电流法：一条口诀记三个规则
  14 - 21 min   第 4 站  节点电压法：最省事的那一个
  21 - 26 min   第 5 站  无伴电压源与受控源（考试重灾区）
  26 - 30 min   第 6 站  贯穿实例收尾 + 自测


★★ 贯穿全章的实例（第 2 章那张桥式电路，别换）★★

    还是它：R₁ = 1Ω、R₂ = 2Ω、R₃ = 3Ω、R₄ = 4Ω、R₅ = 5Ω，
    求 A、D 之间的等效电阻 R_AD。

    第 2 章用 Y-Δ 变换算出来是 2.0946Ω。
    这一章要用两种通用方法再算一遍 —— 三种方法得到同一个数，

    为什么还用它：它用串并联死活化简不了，必须动用通用方法；

========================================================================
  第 1 站（0-4 min）  电路的图：数方程之前先数 n 和 b
                                对应教材 3-1
------------------------------------------------------------------------

【为什么要把电路画成"图"】

    电路里有电阻、电压源、电流源，元件各不相同。
    但"要列几个方程"这件事，只和【连接方式】有关，和元件是什么无关。

    所以先把每个元件缩成一条线（叫支路 b），把连接点画成点（叫节点 n），
    得到一张纯粹的"图"。这张图只保留"谁和谁连着"。

【树、树支、连支】

    树（tree）：从图里挑一组支路，满足三个条件
                · 连通（任意两节点之间都有路）
                · 包含全部节点
                · 不含任何回路

    树支：被挑进树里的支路，个数恒为 n-1
    连支：没被挑进去的支路，个数 = b-(n-1) = b-n+1

    这两个数是本章所有公式的来源，必须记住：

        树支数 = n − 1
        连支数 = b − n + 1



    拿桥式电路验证：n = 4 个节点，b = 5 条支路
        → 树支 3 条（比如 A-B、B-D、A-C）
        → 连支 2 条（剩下 B-C、C-D）

    为什么连支数等于独立回路数？
    因为每加一条连支，就正好闭合成一个之前没有的新回路，
    而且这 b-n+1 个回路互相独立、能张成全部回路。这就是第 2 站的依据。

【一句话】

    数方程之前，先数 n 和 b。后面所有公式都只有这两个字母。


========================================================================
  第 2 站（4-8 min）  独立方程数：n-1 和 b-n+1
                                对应教材 3-2
------------------------------------------------------------------------

【独立 KCL 方程数 = n − 1】

    对每个节点列"流入电流之和 = 流出电流之和"，一共能列 n 个。
    但这 n 个方程加起来，左边恒等于 0、右边恒等于 0 ——
    其中任意一个都能由另外 n-1 个推出来。

    所以独立的只有 n-1 个。（规范说法：少的那一个是参考节点）

【独立 KVL 方程数 = b − n + 1】

    每个"独立回路"列一个 KVL，互不重复的回路正好有 b-n+1 个。

    总账：KCL (n-1) + KVL (b-n+1) = b 个独立方程
    而未知量正好是 b 个支路电流 —— 【方程数 = 未知量数】，一定能解。

【三种方法的方程数对比（用桥式电路 n=4、b=5）】

    方法              未知量              方程个数
    ------------------------------------------------------------------
    支路电流法        b 个支路电流         5 个
    网孔电流法        网孔电流             b-n+1 = 2 个
    节点电压法        节点电压             n-1   = 3 个

【选哪个？一条经验】

    · 节点少、网孔多（阶梯形电路、多个电压源接地） → 节点电压法
    · 网孔少、且是平面电路                        → 网孔电流法
    · 拿不准时                                     → 节点电压法

    为什么"拿不准选节点法"：
      ① 参考点可以随便选，选错了只是多算一步，不会列错
      ② 节点方程可以逐节点检查（每个节点的自导一定包含自己）
      ③ 含受控源时节点法最好补方程，考试最爱考
      ④ 仿真软件（SPICE）内部用的就是节点法


========================================================================
  第 3 站（8-14 min）  支路电流法：方程最多，只作理解
                                对应教材 3-3
------------------------------------------------------------------------

【思路】

    直接拿 n-1 个 KCL 和 b-n+1 个 KVL 联立 —— 就是第 2 站那本总账，
    一个字都不省。它的价值在于：它是另外两种方法的来源。

【四步走】

    ① 给每条支路标电流方向（随便标，最后算出来是负的就是实际反向）
    ② 选参考节点，对剩下 n-1 个节点列 KCL
    ③ 选 b-n+1 个独立回路，列 KVL
    ④ 解方程组

【为什么实际做题不推荐】

    桥式电路要列 5 个方程、5 个未知量，手算要解 5 元一次方程组。
    而网孔法只要 2 个方程、节点法只要 3 个。

    所以：支路电流法用来【理解原理】，做题请用后面两种。


========================================================================
  第 4 站（14-21 min）  网孔电流法：自阻正、互阻负
                                对应教材 3-4、3-5
------------------------------------------------------------------------

【核心想法：不设支路电流，设"环流"】

    在每个网孔里假设一个绕圈流动的假想电流（网孔电流 i₁、i₂…）。
    支路电流就等于"流过它的网孔电流的代数和"。

    好处：KVL 自动满足（绕一圈回到原点，电压降之和必然为 0），
    所以只需要按网孔列方程，方程数直接从 b 降到 b-n+1。

【方程长什么样（两个网孔）】

    R₁₁·i₁ + R₁₂·i₂ = u_s11
    R₂₁·i₁ + R₂₂·i₂ = u_s22

    三条规则 —— 背这三条就够了：

    --- 三条规则（背这三条就够了） -------------------------------------

    ① 自阻 R_ii：本网孔里全部电阻之和，【恒为正】

    ② 互阻 R_ij：相邻两网孔的公共支路上的电阻；两个网孔电流都取
       顺时针时，公共支路上方向相反 → 【取负】

    ③ 右端 u_sii：沿本网孔方向【电压升】的代数和
       从 − 走到 + 记正，从 + 走到 − 记负

    --------------------------------------------------------------------

    口诀：自阻正、互阻负、右端看压源



【例题逐句对一遍】

    R₁ = 4Ω、R₂ = 2Ω（公共支路）、R₃ = 4Ω；U₁ = 14V、U₂ = 6V

    网孔 1：
        自阻 = R₁ + R₂ = 4 + 2 = 6
        互阻 = −R₂ = −2            （公共支路上两个环流方向相反）
        右端 = +14                 （沿顺时针走 U₁ 是从 − 到 +，电压升）
        → 6i₁ − 2i₂ = 14

    网孔 2：
        自阻 = R₂ + R₃ = 2 + 4 = 6
        互阻 = −R₂ = −2
        右端 = +6                  （U₂ 的 + 端在下，顺时针走也是从 − 到 +）
        → −2i₁ + 6i₂ = 6

    解得：i₁ = 3A，i₂ = 2A
    公共支路（R₂）里的实际电流 = i₁ − i₂ = 1A，方向向下。

【适用条件：必须是平面电路】

    平面电路 = 能画在平面上、支路不交叉的电路。
    遇到非平面电路（比如三棱柱那种），网孔就不存在了，
    要改用【回路电流法】：用"树 + 连支"选 b-n+1 个独立回路，
    方程形状和三条规则完全一样，只是"网孔"换成"回路"。

    考试里 95% 的题都是平面电路，直接数网孔就行。


========================================================================
  第 5 站（21-26 min）  节点电压法：最省事的那一个
                                对应教材 3-6
------------------------------------------------------------------------

【核心想法：选定一个参考点，其余节点电压当未知量】

    把某个节点定成 0V（参考点），其余 n-1 个节点的电压就是未知量。
    因为支路电流可以用"两端电压差 ÷ 电阻"直接写出来，
    所以列 KCL 时全部换成电压，得到 n-1 个方程。

【方程长什么样】

    G₁₁·V₁ + G₁₂·V₂ + … = i_s11
    G₂₁·V₁ + G₂₂·V₂ + … = i_s22

    三条规则：

    --- 三条规则 ------------------------------------------------------

    ① 自导 G_ii：连到节点 i 的所有电导之和，【恒为正】

    ② 互导 G_ij：节点 i 与 j 之间的电导之和，【取负】

    ③ 右端 i_sii：注入节点 i 的电流源电流之和
       流入为正，流出为负；没有电流源就写 0

    --------------------------------------------------------------------

    口诀：自导正、互导负、右端是电流源注入

    注意：用的是【电导】G = 1/R，不是电阻。
    用电阻算会疯掉，因为并联是"取倒数再相加"。



【贯穿实例：用节点法算 R_AD】

    要求"输入电阻"，标准做法是【外加电源法】：
    在 A 注入 1A、从 D 抽出 1A，求出 V_A，则 R_AD = V_A / 1A。

    取 D 为参考点（V_D = 0）。先把五条支路换成电导：

        G_AB = 1/1 = 1      G_AC = 1/3
        G_BD = 1/2          G_CD = 1/4      G_BC = 1/5

    三个节点的自导：
        A：1 + 1/3 = 4/3
        B：1 + 1/2 + 1/5 = 17/10
        C：1/3 + 1/4 + 1/5 = 47/60

    互导（两两之间）：
        A-B：−1      A-C：−1/3      B-C：−1/5

    列方程（右端：A 注入 1A 记 +1，B、C 没有电流源记 0）：

        (4/3)V_A − V_B − (1/3)V_C = 1
        −V_A + (17/10)V_B − (1/5)V_C = 0
        −(1/3)V_A − (1/5)V_B + (47/60)V_C = 0

    解得：

        V_A = 155/74 ≈ 2.0946 V
        V_B = 51/37  ≈ 1.3784 V
        V_C = 46/37  ≈ 1.2432 V

    所以 R_AD = V_A / 1A = 2.0946Ω

    ★ 与第 2 章 Y-Δ 变换得到的 2.0946Ω 完全一致。
      两条完全不同的路得到同一个数 —— 这就是最好的验算。

【节点法为什么是考场首选】

    · 参考点随便选（一般选接地点或"连着最多支路的节点"）
    · 每个方程都能独立检查：自导一定最大、一定为正
    · 方程有规律，不容易漏项
    · 含受控源时最容易补方程（见第 6 站）


========================================================================
  第 6 站（26-30 min）  两个必考的特殊情况
                                对应教材 3-6 后半
------------------------------------------------------------------------

【情况一：无伴电压源（理想电压源没有串联电阻）】

    麻烦在哪：节点法要求右端是【电流源】。一个没有串联电阻的电压源，
    没法用"Us/R"转成电流源 —— 它叫"无伴"电压源。

    两种处理，任选其一：

    方案 A（首选）：把它的一端选成参考点
        参考点一接上去，另一端的电压就直接等于 Us，未知量当场少一个。
        所以"选参考点"不是随便选的，优先选电压源的一端。

    方案 B：超节点（supernode）
        把电压源两端的两个节点【合并成一个整体】，对整体列一条 KCL
        （两节点的注入电流之和 = 两节点流出的电流之和），
        再补一条电压约束方程：

            V_a − V_b = Us

        未知量没多，方程数也没多。



【情况二：含受控源】

    受控源（如 2u、3i）不能做电源等效变换，也不能直接当独立源用。
    标准三步：

        ① 先按独立源的方法照常列方程（右端先写着控制量，比如 2V_B）
        ② 再补一条：把控制量用节点电压（或网孔电流）表示出来
        ③ 把补充方程代进去，整理成标准形状

    一个自检窍门：
        不含受控源时，节点方程的电导矩阵是【对称的】（G12 = G21）。
        含受控源时通常不再对称。
        如果你列出来的矩阵"该不对称却对称了"，多半是漏了受控源那一项。

【三种方法总对照】

    方法          方程数          什么时候用              最大优点
    ----------------------------------------------------------------------
    支路电流法    b              只用来理解原理          不需要任何技巧
    网孔电流法    b-n+1          平面电路、网孔少        方程最少的常客
    节点电压法    n-1            节点少、含受控源        最通用、可编程

    做题顺序建议：
        第 1 步 数 n 和 b
        第 2 步 用公式算出两种方法的方程数，选少的那个
        第 3 步 数一样时选节点法（好检查、好补方程）

  2. 树支数和连支数的公式分别是什么？

  4. 支路电流法在桥式电路上要列几个方程？
  5. 网孔电流法的三条规则分别是什么？
  6. 为什么两个网孔电流都取顺时针时，互阻取负号？
  7. 网孔电流法对电路有什么前提要求？不满足怎么办？
  8. 节点电压法里，右端的电流源"流入"记正还是记负？
  9. 无伴电压源的两种处理方法是什么？
 10. 含受控源时，怎么用"矩阵是否对称"检查自己有没有漏项？

------------------------------------------------------------------------
  参考答案
------------------------------------------------------------------------

  1. KCL 3 个（n-1），KVL 2 个（b-n+1）。
  2. 树支 = n − 1，连支 = b − n + 1。
  3. 因为 n 个节点的 KCL 相加，左边和右边都恒等于 0，
     任意一个都能由另外 n-1 个推出来，所以独立的最多只有 n-1 个。
  4. 5 个（b = 5）。
  5. 自阻恒正；互阻取负（顺时针时公共支路方向相反）；右端为电压升的代数和。
  6. 因为两个环流在公共支路上方向相反，互相抵消的那部分要写成减号。
  7. 必须是平面电路（能画在平面上不交叉）。不满足时改用回路电流法，
     用"树 + 连支"选 b-n+1 个独立回路，规则完全一样。
  8. 流入（注入）记正，流出记负。
  9. ① 把它的一端选为参考点；② 用超节点：两节点合并列一条 KCL，
     再补一条电压约束 V_a − V_b = Us。
 10. 不含受控源时电导矩阵一定对称（G_ij = G_ji）；
     含受控源时一般不再对称。如果本该不对称却算成对称，说明受控源漏了。


========================================================================
  本章最容易犯的 8 个错
========================================================================

  1. 互阻忘了负号
     两个网孔电流都是顺时针时，公共支路上方向相反，互阻必须取负。
     忘了负号是最常见的失分点。

  2. 右端电压源的正负看反
     看的是"沿网孔方向是从 − 到 + 还是从 + 到 −"，不是看电源画在左边还是右边。

  3. 节点法里用电阻代替电导
     自导、互导都是【电导】(S)。G = 1/R，别把 2Ω 直接填成 2。

  4. 互导忘了取负
     自导正、互导负。这条和网孔法的互阻是同一个道理。

  5. 右端电流源的流向搞反
     注入该节点记正，流出记负。电压源转过来的电流源方向尤其容易错。

  6. 漏掉电压源串联电阻的那条支路
     节点法里它要先化成"电流源 ∥ 电导"再填，不能只写电压源。

  7. 无伴电压源硬套公式
     它没有串联电阻，Us/R 写不出来。必须用"选参考点"或"超节点"。

  8. 受控源忘了补控制量方程
     列完方程发现未知量比方程多，就是漏了这一步。
