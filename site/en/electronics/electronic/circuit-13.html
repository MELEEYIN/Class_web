========================================================================
  第 1 站（0-5 min）  拉普拉斯变换：只需要三条对应
                                对应教材 14-1、14-2
------------------------------------------------------------------------

【定义（知道就行，不用手算积分）】

        F(s) = ∫[0→∞] f(t)·e^(−st) dt

    s 是一个复数（s = σ + jω），叫【复频率】。

    你不需要会算这个积分 —— 考试用的都是现成的变换对。

【三条核心对应（这才是要背的）】

        ① f(t)          →  F(s)                    （定义）
        ② df/dt         →  s·F(s) − f(0⁻)          （求导 → 乘 s）
        ③ ∫f dt         →  F(s)/s                   （积分 → 除 s）

    ★ 第 ② 条是它最厉害的地方：求导变成乘法，
      而且 f(0⁻) 自动被带进来了 —— 初始条件不用另想办法。



【常用变换对（四个就够）】

        δ(t)  →  1
        ε(t)  →  1/s          （单位阶跃）
        e^(−at) → 1/(s+a)
        t     →  1/s²
        sin ωt → ω/(s²+ω²)
        cos ωt → s/(s²+ω²)

【用它的三步流程】

    ① 把电路"搬"到 s 域（微分方程变成代数方程）
    ② 在 s 域解出 U(s)（就是普通的代数运算）
    ③ 反过来变回时域 u(t)（查表 + 部分分式）

    第 2 站讲①，第 3 站讲②③。


========================================================================
  第 2 站（5-10 min）  运算电路：L、C 的 s 域模型
                                对应教材 14-2
------------------------------------------------------------------------

    把第 8 章的 jω 换成 s，就得到【运算阻抗】：

        Z_R = R
        Z_L = sL
        Z_C = 1/(sC)

    但还有一件事要处理：【初始条件】。

【L 和 C 的运算电路（记这两个）】

    电感（初始电流 i(0⁻)）：
        等效为  sL  串联一个电压源 L·i(0⁻)

    电容（初始电压 u(0⁻)）：
        等效为  1/(sC)  串联一个电压源 u(0⁻)/s

    ★ 关键理解：初始条件不是"额外的条件"，而是被【打包成了电路里的电源】。
      于是你就按普通电路算，不用再操心初始值。



【零初始条件时的简化】

    如果 i(0⁻) = 0 且 u(0⁻) = 0（最常见的情况），
    那两个附加电源就是 0（短路），运算电路里只剩阻抗：

        R、sL、1/(sC)  —— 和相量法完全一样，只是 jω 换成 s

    这时 s 域电路就是一个"用符号 s 组成的电阻电路"，
    节点法、分压、戴维南全都能用。

【直流稳态的校验（自检用）】

    s = 0 时：
        Z_L = 0     → 电感短路 ✓（第 6 章）
        Z_C → ∞     → 电容开路 ✓（第 6 章）

    所以"终值定理"给出的稳态与第 6 章的结论一致，
    说明这套方法自洽。


========================================================================
  第 3 站（10-17 min）  解题四步 + 部分分式
                                对应教材 14-3
------------------------------------------------------------------------

【四步】

    ① 画运算电路（L、C 换成阻抗 + 初始值电源）
    ② 用节点法/网孔法/戴维南在 s 域解出 U(s)
       得到的通常是【s 的有理式】（分子分母都是多项式）
    ③ 把 U(s) 做【部分分式展开】成若干简单项
    ④ 逐项查表反变换，得到 u(t)

【第 ③ 步是关键：部分分式】

    设 U(s) = N(s)/D(s)，把分母因式分解后拆成：

        U(s) = A/(s−p₁) + B/(s−p₂) + …

    系数怎么求（留数法，最快）：

        A = (s−p₁)·U(s) 在 s = p₁ 处的值

    每一项 A/(s−p) 反变换就是 A·e^(pt)，所以：

        u(t) = A·e^(p₁t) + B·e^(p₂t) + …

    ★ 分母有重根、有共轭复根时形式略有不同（了解即可，
      复根那一对反变换出来是"e^(−αt)·sin(ωt)"的形式，就是第 7 章的欠阻尼）。

【贯穿实例走一遍（这是本章唯一必会的计算）】

    电路：Us = 10V、R = 1kΩ、C = 1μF，求 uC(t)。

    ① 运算电路：电压源 Us/s，串 R 和 1/(sC)
    ② s 域分压：

        Uc(s) = (Us/s) · (1/sC) / (R + 1/sC)
              = (10/s) · [1/(sC)] / [R + 1/(sC)]
              = 10/s · 1/(1 + sRC)
              = 10 / [s(1 + 0.001s)]
              = 10000 / [s(s + 1000)]

    ③ 部分分式：设 = A/s + B/(s+1000)

        A = s·Uc(s) 在 s=0 处 = 10000/1000 = 10
        B = (s+1000)·Uc(s) 在 s=−1000 处 = 10000/(−1000) = −10

        所以 Uc(s) = 10/s − 10/(s+1000)

    ④ 反变换（查表：1/s → ε(t)，1/(s+a) → e^(−at)）：

        uC(t) = 10 − 10e^(−1000t) = 10(1 − e^(−t/τ))，τ = 1/1000 = 1ms

    ★ 与第 7 章三要素法的结果完全一致 ✓
      （我逐点验算过：t = 1τ 时两者都是 6.32121V）



【这个方法比三要素法强在哪】

    · 任意激励（正弦、指数、分段）都能算
    · 任意阶数（二阶、三阶）都能算
    · 初始条件自动带入，不用单独处理
    · 系统化的步骤，不需要"猜特解"

    代价是：要会因式分解和部分分式（就是代数功夫）。


========================================================================
  第 4 站（17-22 min）  网络函数与零极点
                                对应教材 14-4
------------------------------------------------------------------------

【网络函数】

    定义和相量法一样，只是把 jω 换成 s：

        H(s) = 响应的拉氏变换 / 激励的拉氏变换

    它是有理式 H(s) = N(s)/D(s)：
        N(s) = 0 的根叫【零点】
        D(s) = 0 的根叫【极点】

【极点的含义：形状 + 稳定性】

    H(s) 的极点 p = σ + jω 决定了响应的形态：

        实部 σ < 0（左半平面）→ e^(σt) 衰减 → 【稳定】
        实部 σ > 0（右半平面）→ e^(σt) 增长 → 【发散】
        实部 σ = 0（虚轴上）  → 等幅振荡    → 【临界】

        虚部 ω 决定振荡频率（ω=0 就是单调变化，不振荡）



【和前面章节的对应（这张表能把全书串起来）】

    一阶 RC：H(s) = 1/(1+sRC)，极点 s = −1/τ
             → 第 7 章的 τ，就是极点的倒数（取负）

    二阶 RLC：极点 = −α ± j√(ω0²−α²)
             → 第 7 章的 α、ω0 直接就是零极点的实部和虚部！

    ★ 所以"三要素法""二阶判别法""零极点图"是同三件事的三种说法。

【一阶系统的一个好记结论】

        τ = −1 / （极点的实部）

    贯穿实例：极点 s = −1000 ⟹ τ = 1/1000 = 1ms ✓ 与 RC = 1ms 一致


========================================================================
  第 5 站（22-27 min）  二端口网络
                                对应教材 16-1
------------------------------------------------------------------------

【什么是二端口】

    一个有四个端子的网络，分成两个端口：
        端口 1：电压 U̇1、电流 İ1
        端口 2：电压 U̇2、电流 İ2

    只关心这四个量之间的关系，【内部是什么完全不管】。

    判断标准：从端口 1 流进的电流 = 从端口 1' 流出的电流（端口条件成立）。

【四种参数（只是选了不同的自变量）】

    Z 参数（阻抗参数）：以 İ1、İ2 为自变量
        U̇1 = Z11·İ1 + Z12·İ2
        U̇2 = Z21·İ1 + Z22·İ2

    Y 参数（导纳参数）：以 U̇1、U̇2 为自变量（Z 的逆）
    T 参数（传输参数）：以 U̇2、İ2 为自变量（描述"传输"最方便）
    H 参数（混合参数）：以 İ1、U̇2 为自变量（晶体管最常用）

    ★ 四种参数描述的是同一个网络，可以互相转换。
      做题时看给的是什么，就用什么。



【两个必记的性质】

    ① 互易网络（不含受控源）：Z12 = Z21（其它参数也有对应关系）
       → 四个参数只剩三个独立

    ② 对称网络（左右一样）：Z11 = Z22
       → 只剩两个独立

    【校验技巧】算完 Z12 和 Z21，如果它们不相等而电路里没有受控源，
    说明算错了 —— 这是最快的自检。

【T 形网络的 Z 参数（最简单的例子，务必会）】

    串臂 Z1、Z2，并臂 Z3（组成 T 形，三个元件、三个节点）：

        Z11 = Z1 + Z3
        Z12 = Z21 = Z3
        Z22 = Z2 + Z3

    贯穿实例：Z1=10Ω、Z2=20Ω、Z3=30Ω
        Z11 = 40、Z12 = Z21 = 30、Z22 = 50

    校验（输出短路）：Zin = Z1 + Z2∥Z3 = 10 + 12 = 22Ω
        用 Z 参数算：Z11 − Z12²/Z22 = 40 − 900/50 = 40 − 18 = 22Ω ✓ 一致

------------------------------------------------------------------------
  参考答案
------------------------------------------------------------------------

  1. F(s) = ∫₀^∞ f(t)e^(−st)dt；s 是复频率（s = σ + jω）。
  2. df/dt → sF(s) − f(0⁻)。因为变换式里自动出现了 f(0⁻) 这一项。
  3. Z_L = sL，Z_C = 1/(sC)。
  4. 变成与电感串联的电压源 L·i(0⁻)（电容则是 u(0⁻)/s）。
  5. ① 画运算电路；② s 域求解；③ 部分分式展开；④ 查表反变换。
  6. 对极点 p，系数 A = (s−p)F(s) 在 s=p 处的值。
  7. 1/s → ε(t)（单位阶跃）；1/(s+a) → e^(−at)。
  8. 实部决定衰减/增长（稳定性），虚部决定振荡频率。
  9. τ = −1/Re(p) = 1/1000 = 1ms。
 10. U̇1 = Z11İ1 + Z12İ2，U̇2 = Z21İ1 + Z22İ2。
     互易：Z12 = Z21；对称：Z11 = Z22。
 11. Z11 = Z1+Z3，Z12 = Z21 = Z3，Z22 = Z2+Z3（T 形，串臂 Z1、Z2，并臂 Z3）。
 12. Uc(s) = 10000/[s(s+1000)] = 10/s − 10/(s+1000) → uC(t) = 10(1 − e^(−1000t)) V。


========================================================================
  本章最容易犯的 6 个错
========================================================================

  1. 忘了把初始条件放进运算电路
     i(0⁻)≠0 或 u(0⁻)≠0 时，必须加上那个附加电压源，否则结果全错。

  2. 部分分式系数算错
     用留数法（代入极点）最快，算完代回一个数验算。

  3. 反变换漏掉单位阶跃
     1/s 反变换是 ε(t)，不是常数 1。严格来说所有响应都乘 ε(t)（表示 t>0 才有）。

  4. 认为极点越靠近虚轴越稳定
     反过来：极点【越远离】虚轴（实部越负），衰减越快、越稳定。

  5. 二端口互易/对称混为一谈
     互易：Z12 = Z21（不含受控源才有）；对称：Z11 = Z22（左右一样才有）。
     对称一定互易，互易不一定对称。

  6. 用 jω 分析瞬态
     相量法（jω）只对【稳态正弦】有效。要算暂态必须用 s（拉普拉斯）。


========================================================================
  全书结束语
========================================================================

    十三周、十三章，其实只学了一件事：

        【把复杂的问题，换到一个更容易的世界里解决，再换回来。】

    直流 → 实数；正弦稳态 → 相量（复数）；暂态 → s 域（复频率）；
    任意周期信号 → 傅里叶（频率分解）。

    电路分析的所有技巧，无非是选对"换到哪个世界"。

    如果你现在能对着一个陌生的电路，先问自己三个问题：
        ① 它是直流、正弦还是任意波形？
        ② 是稳态还是暂态？
        ③ 用等效、用定理、还是列方程最省事？
    那这本书你就真的学进去了。
