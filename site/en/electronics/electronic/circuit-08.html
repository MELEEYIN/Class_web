========================================================================
  全章地图：这一章到底在讲什么
========================================================================

前面七章处理的都是【直流】——电压电流不随时间变。
这一章开始处理【正弦交流】：电压电流每秒变化 50 次。

直接列微分方程？那就完蛋了：
    u = L·di/dt，而 i 是正弦的，求导以后相位变了……
    整个电路要解微分方程组，比第 7 章还难十倍。

相量法就是来解决这个问题的：它把【微分方程】变成【复数代数方程】。
    求导 → 乘以 jω
    解正弦电路 → 解复数电路，用节点法、网孔法、戴维南定理照样干

一句话：这一章不是新知识，而是把前七章的全部工具【搬进复数域】。

一共五件事：

★★ 贯穿全章的实例（数值特意选成 3-4-5）★★

    R = 3Ω 与 L（感抗 XL = 4Ω）串联，接 u = 10√2·cos(ωt) V。

    · 阻抗：Z = 3 + j4 = 5∠53.13° Ω

========================================================================
  第 1 站（0-5 min）  复数与正弦量的三要素
------------------------------------------------------------------------

【复数：三种写法，两种运算】

    直角坐标：A = a + jb
    极坐标　：A = |A|∠θ
    换算　　：|A| = √(a² + b²)，θ = arctan(b/a)
              a = |A|cosθ，b = |A|sinθ

    运算规则（这是全部考点）：
        【加减】用直角坐标：实部加实部，虚部加虚部
        【乘除】用极坐标：模相乘除，角相加减

    所以做题时来回切换是常态，别嫌麻烦。

    几个常用值（背下来提速）：
        j = 1∠90°        −j = 1∠−90°        1/j = −j
        j² = −1          10∠53.13° = 6 + j8（3-4-5）

【正弦量的三要素】

    i(t) = Im · cos(ωt + φ)

        Im（幅值）   波峰有多高
        ω （角频率） 转多快，ω = 2πf = 2π/T
        φ （初相）   t = 0 时转到了哪个角度

    工频 50Hz：
        T = 1/50 = 20ms
        ω = 2π×50 = 314 rad/s



【有效值（RMS）：交流电的"等效直流量"】

    定义：一个交流电和多大的直流电在同样电阻上产生同样的热量，那个
    直流值就叫这个交流电的有效值。

        I = Im/√2 ≈ 0.707·Im

    所以家里的 220V 是【有效值】，它的幅值是：
        220 × √2 = 311V

    为什么非要搞出个有效值？
    因为功率计算要用它：P = I²R 里的 I 必须是有效值。
    交流电表、铭牌上的数，全是有效值。

    ★ 相量法里默认用【有效值相量】：
        u = 10√2·cos(ωt) V  ⇔  U̇ = 10∠0° V
      那个 √2 就是用来把幅值换成有效值的。

【相位差】

    两个【同频率】的正弦量才能比较相位：

        φ = φu − φi

        φ ＞ 0：电压【超前】电流（电路呈感性）
        φ ＜ 0：电压【滞后】电流（电路呈容性）
        φ = 0：同相（纯电阻）

    注意：不同频率的两个正弦量谈相位差没有意义。


========================================================================
  第 2 站（5-11 min）  相量法为什么成立
                                对应教材 8-3
------------------------------------------------------------------------

【一句话原理】

    一个长度 Im、初始角 φ 的箭头，以 ω 逆时针旋转，
    它在实轴上的投影就是 u(t) = Im·cos(ωt + φ)。

    所以"研究正弦量"可以换成"研究那个旋转箭头"。

【为什么能省掉 ω】

    同一个电路里，所有电压电流都是【同一个 ω】（电源的频率）。
    既然大家频率一样，就不必每次都写出来，只留【幅值】和【初相】即可。

    剩下的这两样（幅值、初相）正好就是一个【复数】：
        U̇ = U∠φ        （U 用有效值还是幅值都行，但全篇必须统一）

    这个复数就叫【相量】，字母上面加个点。



【三条翻译规则（全部相量法就这三条）】

    ① 时域 → 相量
       u = Um·cos(ωt+φ)  ⇒  U̇ = (Um/√2)∠φ

    ② 求导 → 乘 jω
       du/dt  ⇒  jω·U̇
       （这条最关键。因为 d/dt[e^(jωt)] = jω·e^(jωt)，
         再乘以 jω 就等于求一次导，而且相位信息自动处理好了）

    ③ 相量 → 时域
       U̇ = U∠φ  ⇒  u = √2·U·cos(ωt+φ)

【于是电路定律全部照搬】

    KCL：Σİ = 0        （和直流的 Σ I = 0 一样）
    KVL：ΣU̇ = 0        （和直流的 Σ U = 0 一样）

    这就是相量法最大的红利：前七章的方法一个字不用改，
    只要把"实数"换成"复数"、"R"换成"Z"。

【必须注意的三点】

    1. 相量不是正弦量。相量是个复数，正弦量是时间的函数。
       写成"İ = 5A"是错的，要写"İ = 5∠0° A"或"I = 5A（有效值）"。

    2. 相量法只适用于【线性】电路、且所有激励【同频率】。
       不同频率的源不能混在一个相量图里（第 12 章非正弦周期就是处理这个）。

    3. 只有正弦量的稳态才能用相量法。
       换路后的暂态（第 7 章）不归它管。




========================================================================
  第 3 站（11-17 min）  三个元件的相量形式与阻抗
                                对应教材 8-4
------------------------------------------------------------------------

【电阻 R】

    u = Ri  ⇒  U̇ = R·İ

    电压与电流【同相】。

【电感 L】

    u = L·di/dt  ⇒  U̇ = jωL·İ

    记 XL = ωL（感抗，单位 Ω），则 U̇ = jXL·İ。
    电压【超前】电流 90°。

    感抗随频率增大：频率越高，电感越"挡"。直流时 f = 0 ⇒ XL = 0（短路），
    和第 6 章"电感直流稳态相当于短路"完全一致 ✓

【电容 C】

    i = C·du/dt  ⇒  İ = jωC·U̇  ⇒  U̇ = İ/(jωC) = −j·İ/(ωC)

    记 XC = 1/(ωC)（容抗，单位 Ω），则 U̇ = −jXC·İ。
    电压【滞后】电流 90°。

    容抗随频率【减小】：频率越高，电容越"通"。直流时 f = 0 ⇒ XC → ∞（开路），
    和第 6 章"电容直流稳态相当于开路"完全一致 ✓



【阻抗 Z：把三个元件统一起来】

        Z = U̇ / İ

    于是三个元件可以写成统一形式：

        电阻：Z = R         （纯实数）
        电感：Z = jXL = jωL （纯虚数，正）
        电容：Z = −jXC = 1/(jωC) （纯虚数，负）

    阻抗也是复数，可以写成 Z = |Z|∠φ：
        |Z| 叫阻抗模，φ 叫阻抗角（就是电压超前电流的角度）

    导纳 Y = 1/Z = İ/U̇，单位 S（西门子）。
    并联电路用导纳算更方便（和直流的电导一样）。

【算两个数感受一下（f = 50Hz，ω = 314）】

    L = 0.1H  →  XL = ωL = 31.4Ω
    C = 10μF  →  XC = 1/(ωC) = 318.3Ω

    同样频率下，10μF 的电容比 0.1H 的电感"更难通过"10 倍。
    而且注意：容抗的量级在低频时非常大 —— 这就是为什么工频电路里
    小电容基本等于开路。


========================================================================
  第 4 站（17-22 min）  阻抗串并联与相量图解法
------------------------------------------------------------------------

【串并联：公式和第 2 章一模一样】

    串联：Z = Z₁ + Z₂ + …            （直接相加，复数相加）
    并联：1/Z = 1/Z₁ + 1/Z₂ + …      （倒数和）

    分压：U̇₁ = U̇ · Z₁/(Z₁+Z₂)
    分流：İ₁ = İ · Z₂/(Z₁+Z₂)

    完全可以照第 2、3 章的做法，只是把 R 换成 Z、实数换成复数。

【相量图解法（考试常考，也是最快的检查手段）】

    把各电压相量按【首尾相接】画出来，合成相量就是总电压 ——
    这就是相量图的 KVL。

    串联电路特别有用，因为【电流相同】：
        以电流 İ 为基准（画成水平向右）
        电阻电压 U̇R 与 İ 同相 → 水平
        电感电压 U̇L 超前 İ 90° → 竖直向上
        电容电压 U̇C 滞后 İ 90° → 竖直向下

    于是 R-L 串联的电压三角形就是一个直角三角形：
        U = √(UR² + UL²)　　　φ = arctan(UL/UR)



【★ 最容易错的一点：电压不能直接相加】

    R-L 串联里 UR = 6V、UL = 8V，总电压【不是】14V，而是 10V。

    因为两个电压相位差 90°，必须在相量（复数）里相加：
        U̇R + U̇L = 6∠−53.13° + 8∠36.87° = 10∠0° ✓

    这就是为什么必须用相量法：它管住了相位。

    同理：串联电路里 U̇L 或 U̇C 完全可能【大于】总电压 U
    （RLC 串联谐振时可达几十倍，第 10 章会讲）。


========================================================================
  第 5 站（22-26 min）  正弦稳态功率
                                对应教材 9-5、9-6
------------------------------------------------------------------------

    交流电路里"功率"不止一个数，而是三个。这是考试重灾区。

【三个功率】

    有功功率 P（单位 W，瓦）
        真正做功、发热的功率，就是平均功率
        P = U·I·cosφ = I²R

    无功功率 Q（单位 var，乏）
        在电源和储能元件之间来回交换、不做功的那部分
        Q = U·I·sinφ = I²X

    视在功率 S（单位 VA，伏安）
        电压有效值乘电流有效值，是"设备容量"
        S = U·I = √(P² + Q²)

【三者的关系：功率三角形】

        S² = P² + Q²
        cosφ = P/S        ← 这就是【功率因数】

    φ 就是阻抗角，也是电压超前电流的角度。
    所以相量图和功率三角形是【相似三角形】。

【正负号的含义】

    Q ＞ 0：感性电路（电感为主），电流滞后电压
    Q ＜ 0：容性电路（电容为主），电流超前电压
    Q = 0：纯电阻，P = S，cosφ = 1

【为什么工程上关心功率因数】

    S = UI 决定了设备（发电机、变压器）要多大。
    但用户真正用到的是 P。
    cosφ 越低，为了供同样的 P 就需要更大的 S —— 白白占用了设备容量，
    还在输电线上多烧了损耗。

    所以工厂都要"提高功率因数"（并联电容器），
    这是第 10 章谐振和工程实践的结合点。


========================================================================
  第 6 站（26-30 min）  贯穿实例：一个 3-4-5 电路算到底
------------------------------------------------------------------------

【题目】

    R = 3Ω 与 L（XL = 4Ω）串联，接 u = 10√2·cos(ωt) V（有效值 10V）。
    求：电流 İ、各元件电压、以及 P/Q/S。

【第 1 步：写阻抗】

    Z = R + jXL = 3 + j4
    |Z| = √(3²+4²) = 5Ω
    φ = arctan(4/3) = 53.13°
    → Z = 5∠53.13° Ω

【第 2 步：求电流】

    U̇ = 10∠0° V
    İ = U̇/Z = 10∠0° ÷ 5∠53.13° = 2∠−53.13° A

    读法：有效值 2A，比电压【滞后】53.13°（因为电路是感性的）。
    注意：极坐标除法是"模相除、角相减"。

【第 3 步：各元件电压（乘法要模相乘、角相加）】

    U̇R = R·İ = 3 × 2∠−53.13° = 6∠−53.13° V     （UR = 6V）
    U̇L = j4·İ = 4∠90° × 2∠−53.13° = 8∠36.87° V  （UL = 8V）

    校验 KVL（复数相加）：
        U̇R + U̇L = (3.6 − j4.8) + (6.4 + j4.8) = 10 + j0 = 10∠0° ✓
        恰好等于 U̇，说明没算错。

    校验电压三角形：
        √(6² + 8²) = 10 ✓

【第 4 步：功率】

    有功：P = I²R = 2² × 3 = 12W
          或 P = UIcosφ = 10 × 2 × 0.6 = 12W ✓ 两种算法一致

    无功：Q = I²XL = 2² × 4 = 16var
          或 Q = UIsinφ = 10 × 2 × 0.8 = 16var ✓

    视在：S = UI = 10 × 2 = 20VA

    校验功率三角形：
        P² + Q² = 144 + 256 = 400 = 20² = S² ✓

    功率因数：cosφ = P/S = 12/20 = 0.6

【第 5 步：回时域】

    İ = 2∠−53.13° A  ⇒  i(t) = 2√2·cos(ωt − 53.13°) A

    记住乘回 √2 —— 因为相量用的是有效值。

【结果一览】

        Z = 5∠53.13° Ω        感性
        I = 2A（滞后 53.13°）
        UR = 6V，UL = 8V，U = 10V（6²+8²=10²）
        P = 12W，Q = 16var，S = 20VA，cosφ = 0.6

    三组数都是 3-4-5，这就是教科书偏爱它的原因。

  参考答案

  1. 幅值 Im、角频率 ω、初相 φ。50Hz 时 ω = 2π×50 ≈ 314 rad/s，T = 20ms。
  2. I = Im/√2；220V 有效值 → 幅值 220√2 ≈ 311V。

  4. 乘以 jω（所以电感的 u = L·di/dt 变成 U̇ = jωL·İ）。
  5. 电阻 U̇ = Rİ；电感 U̇ = jωL·İ；电容 U̇ = İ/(jωC) = −jXC·İ。
  6. XL = ωL（随频率增大），XC = 1/(ωC)（随频率减小）。
  7. 直流 f = 0：XL = 0 → 电感相当于短路；XC → ∞ → 电容相当于开路。
  8. Z = U̇/İ；|Z| 叫阻抗模（电压电流有效值之比），φ 叫阻抗角（电压超前电流的角度）。
  9. U = √(6²+8²) = 10V。因为 UL 与 UR 相位差 90°，必须在相量上相加，
     不能直接加数值。
 10. P = UIcosφ（W）、Q = UIsinφ（var）、S = UI（VA），且 S² = P² + Q²。
 11. cosφ = P/S = R/|Z|。cosφ 低则同样 P 需要更大 S，设备容量被浪费，
     线路损耗也更大，所以工厂并联电容补偿。
 12. |Z| = 5Ω，I = 10/5 = 2A，φ = 53.13°（电流滞后），P = I²R = 12W，
     Q = I²XL = 16var，S = UI = 20VA（校验 S² = P²+Q²）。


========================================================================
  本章最容易犯的 8 个错
========================================================================

  1. 电压/电流直接相加
     UR = 6V、UL = 8V 就以为总电压 14V。必须用相量（复数）相加。

  2. 相量里混用幅值和有效值
     全篇必须统一。标准做法用有效值相量（U = Um/√2）。

  3. 把相量写成"等于正弦量"
     相量是复数，正弦量是时间函数。回去时要写 i = √2·I·cos(ωt+φ)。

  4. 乘除时用直角坐标
     极坐标乘除最方便：模相乘除、角相加减。加减才用直角坐标。

  5. 电容的阻抗漏掉负号
     Z_C = −jXC，不是 +jXC。漏负号会让相量图整个反了。

  6. 认为 UL 或 UC 不能大于 U
     串联谐振时 UL、UC 可以是 U 的几十倍。这是第 10 章的重点。

  7. 无功功率当成"没用的功率"
     Q 不做功，但它在电源和储能元件之间来回交换，是客观存在的物理量，
     单位是 var 不是 W。

  8. 功率因数用错角度
     cosφ 里的 φ 是【阻抗角】，也就是电压超前电流的角度，
     不是电压或电流自己的初相。

      本章的阻抗概念直接升级成"运算阻抗"。
    · 第 16 章（二端口）：端口参数都是复数（Z 参数、Y 参数）。

    一句话：从这一章开始，后面的所有分析都在【复数域】里做。
    相量法不是一种"技巧"，而是交流电路唯一的工作语言。
