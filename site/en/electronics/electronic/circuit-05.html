========================================================================
  全章地图：这一章到底在讲什么
========================================================================

前四章的电路，元件都是电阻和电源。
这一章闯进来一个新东西：运算放大器（运放）。

好消息是：运放内部的晶体管电路你这门课不用管，
         课本直接给你一个"三角形"，只要求你会【用】它。

这一章只回答一个问题：

    电路里出现一个三角形，方程该怎么写？

答案是：只需要两条法则 —— 虚短、虚断。
有了它们，运放电路就退化成一个普通的节点法问题。

一共五件事：

   ① 运放是什么：三个端子 + 三条理想假设      （5-1）
   ② 虚短与虚断：全章唯一的工具              （5-2）   ← 核心
   ③ 三个基本型：反相、同相、跟随            （5-3）   ← 必须背
   ④ 加法器与减法器：比例电路的组合          （5-3）   ← 应用题
   ⑤ 积分器与微分器：把 R 换成 C             （5-3 后半，了解）

时间表：

   0 - 4  min   第 1 站  运放与理想化：三条假设从哪来
   4 - 9  min   第 2 站  虚短与虚断：推导 + 使用前提
   9 - 16 min   第 3 站  三个基本型：反相、同相、跟随
  16 - 21 min   第 4 站  加法器与减法器

========================================================================
  第 1 站（0-4 min）  运放与理想化：三条假设从哪来
                                对应教材 5-1
------------------------------------------------------------------------

【先看符号】

    一个三角形，三条引线：
        −（反相输入端，inverting）
        +（同相输入端，non-inverting）
        uo（输出端）

    真实运放还有两个电源端（+Vcc、−Vee），图上常常省略。
    但它们是真实存在的 —— 输出不可能超过电源电压，这一点第 5 站要用。

【真实的三个参数】

    开环增益 A      ：10⁵ ~ 10⁸（非常大）
    输入电阻 Rin    ：MΩ 级（非常大）
    输出电阻 Ro     ：几十 Ω（非常小）

    运放的基本关系只有一个：

        uo = A · (u+ − u−)

    就这么一条式子。后面所有结论都从这里推。

【"大"和"小"能当无穷大用吗？】

    能。因为输出 uo 有上限 —— 它最多等于电源电压（比如 ±15V）。
    于是：

        u+ − u− = uo / A ≤ 15 / 10⁵ = 0.15mV ≈ 0

    两个输入端之间的电压几乎为零，这就是【虚短】的来历。

    同理，输入端的电流：

        i = (u+ − u−) / Rin ≈ 0.15mV / MΩ ≈ 0.15nA ≈ 0

    几乎不取电流，这就是【虚断】的来历。



【题外话：为什么必须加负反馈】

    开环（输出不接回输入端）时，A = 10⁵：
    输入端只要差 0.15mV，输出就顶到 15V 饱和了。
    这么灵敏的东西没法直接用。

    办法是【负反馈】——把输出接回 − 端。
    这样电路自己会调整，使 u+ 与 u− 的差恰好落在
    "A 倍之后刚好等于所需输出"的位置上。

    所以：虚短虚断的成立前提是【有负反馈】。这条第 2 站会再强调一次。


========================================================================
  第 2 站（4-9 min）  虚短与虚断：推导 + 使用前提
                                对应教材 5-2
------------------------------------------------------------------------

【两条法则】

    虚短：u+ = u−
        （两个输入端电位几乎相等，但没有真的短接 —— 所以叫"虚"短）

    虚断：i+ = i− = 0
        （两个输入端几乎不取电流，但没有真的断开 —— 所以叫"虚"断）

【两个名字的来历，别记反】

    虚短 —— 电位相等，像短路，但输入电阻极大，没有真的电流通路。
    虚断 —— 电流为零，像断路，但两端电位是一样的。
    一句话记：虚短管电压，虚断管电流。

【三条使用前提（缺一不可）】

    ① 运放工作在【线性区】—— 输出没饱和
    ② 电路有【负反馈】—— 输出通过元件接回了 − 端
    ③ 不是正反馈、不是开环比较器

    违反任意一条，两条法则立即失效，算出来的全是错的。
    考试里凡是"判断运放工作状态"的题，考的就是这一条。

【解题只有两步】

    第一步 用虚断：输入端电流为 0
           → 与输入端相连的支路，电流必须由别的路"给"，于是可以列 KCL
    第二步 用虚短：u− = u+（或 u+ = u−）
           → 把未知的输入端电位换成已知量

    然后就是普通的电阻电路求解了。

【例题：反相比例电路（把这个推导背下来）】

    输入 ui 经 R₁ 接到 − 端，+ 端接地，Rf 从 − 端接到输出。

    第 1 步  + 端接地 ⇒ u+ = 0
    第 2 步  虚短 ⇒ u− = u+ = 0
             ← 这一点叫【虚地】：它不是真的接地，但电位是 0
    第 3 步  虚断 ⇒ i− = 0，所以流进 R₁ 的电流全部流进 Rf：
                 (ui − 0) / R₁ = (0 − uo) / Rf
    第 4 步  解出 uo = −(Rf / R₁) · ui

    代入 R₁ = 10kΩ、Rf = 100kΩ、ui = 0.5V：
        uo = −10 × 0.5 = −5V

    负号的意思是：输出与输入反相（相位差 180°）。



【为什么这一步能省掉一大堆计算】

    不用虚短虚断，你得把运放内部当成一个受控源（A 倍的电压控制源），
    列节点方程时会出现 A = 10⁵ 这样的系数，方程极其难解。
    用了两条法则，运放直接"消失"，只剩下电阻网络。


========================================================================
  第 3 站（9-16 min）  三个基本型：反相、同相、跟随
                                对应教材 5-3
------------------------------------------------------------------------

    这三个电路必须背下来，考试直接套。判断方法是【看输入接哪个端】：

        输入接 − 端 → 反相比例（输出带负号）
        输入接 + 端 → 同相比例（输出为正）
        输出直接接回 − 端 → 电压跟随器

【型一：反相比例】

    uo = −(Rf / R₁) · ui

    · 输入电阻约等于 R₁（比较小，几十 kΩ）
    · 输出与输入反相
    · 最适合做"反向放大"

【型二：同相比例】

    uo = (1 + Rf / R₁) · ui

    · 放大倍数永远是 1 或更大，不可能小于 1
    · 输入电阻极高（几乎不取电流）→ 适合接传感器
    · 输出与输入同相

【型三：电压跟随器】

    uo = ui

    · 放大倍数恰好是 1
    · 作用不是放大，而是【隔离】：输入侧几乎不取电流，
      输出侧却能提供较大的电流驱动后级
    · 典型用法：传感器输出很弱，先过一级跟随器再往后送



【把三个公式放一起记的方法】

    三个公式里都有 (Rf / R₁)，设 k = Rf / R₁，则：

        反相：uo = −k · ui
        同相：uo = (1 + k) · ui
        跟随：uo = ui        （相当于 k = 0，且输入接 + 端）

    所以只需要记住"反相带负号、同相是 1+k"，第三个是特例。

【一个容易混的点】

    同相比例的公式里是 (1 + Rf/R₁)，不是 Rf/R₁。
    那个 1 是因为输入直接加在 + 端，而 − 端要跟着它走，
    相当于 R₁ 上也有一份电压 —— 所以是"1 加"。

    很多人考试就漏掉这个 1，一个 10 倍的放大器被写成 9 倍。


========================================================================
  第 4 站（16-21 min）  加法器与减法器
                                对应教材 5-3
------------------------------------------------------------------------

【加法器（反相输入）】

    两路输入 u₁、u₂ 各经一个电阻接到同一个 − 端（这个点仍是虚地）。

    因为 − 端是 0V，两路电流互不影响，各自算各自的：

        (u₁ − 0)/R₁ + (u₂ − 0)/R₂ = (0 − uo)/Rf

    解出：

        uo = −( Rf/R₁ · u₁ + Rf/R₂ · u₂ )

    例：R₁ = R₂ = 10kΩ、Rf = 20kΩ、u₁ = 1V、u₂ = 2V
        uo = −(2×1 + 1×2) = −4V

    如果 R₁ = R₂ = Rf，就成了 uo = −(u₁ + u₂)，即纯加法（带负号）。

【减法器（差分放大）】

    这是本章最实用的电路。四电阻桥式接法：

        u₁ 经 R₁ 接 − 端，Rf 从 − 端接输出
        u₂ 经 R₂ 接 + 端，R₃ 从 + 端接地

    当 R₁ = R₂ 且 Rf = R₃ 时：

        uo = (Rf / R₁) · (u₂ − u₁)

    推导（两行）：
        u+ = u₂ · R₃/(R₂+R₃)      ← 分压
        u− = u+                    ← 虚短，再对 − 端列 KCL 整理即可



【为什么减法器这么重要】

    传感器（应变片、热电偶、电桥）输出的都是"两个点之间的电压差"，
    而且通常很小、还带着很大的共模电压。
    差分放大器的特点正是：
        · 只放大两者的差
        · 把两者共同的部分（共模）抵消掉

    所以「电桥 + 差分放大」是测量电路的标准组合 —— 第 6 站就用它。


========================================================================
  第 5 站（21-25 min）  积分器、微分器 + 五个常见错误
                                对应教材 5-3 后半
------------------------------------------------------------------------

【积分器：把反馈电阻 Rf 换成电容 C】

    uo = −(1 / RC) · ∫ ui dt

    输入恒定值时，输出是一条斜线（线性上升/下降）。
    用途：波形发生、模数转换（双积分 ADC）、把方波变三角波。

【微分器：把输入电阻 R₁ 换成电容 C】

    uo = −RC · dui / dt

    输入是斜线时输出是常数；输入是方波时输出是尖峰。
    用途：边缘检测、把三角波变方波。

    例：RC = 1ms，ui 以 1V/ms 上升 → uo = −1V
        （积分器同样参数、ui = 1V 恒定积分 2ms → uo = −2V）

【五个常见错误】

  1. 在开环或正反馈电路上用虚短虚断
     这两条法则的前提是有负反馈。开环比较器里 u+ 和 u− 根本不相等。

  2. 把"虚地"当成真的接地
     反相端的电位是 0，但它和地之间没有导线相连。
     如果把它当成真接地去分析别的支路，会得出错误结论。

  3. 同相比例漏掉那个 1
     写成 Rf/R₁ 而不是 (1 + Rf/R₁)。

  4. 反相/同相接反
     看输入接在哪个端：接 − 端输出反相，接 + 端输出同相。

  5. 输出饱和了还在套公式
     算出 |uo| 超过电源电压（比如 15V）时，实际输出就卡在电源电压上，
     公式已经不成立。考试里常拿这个设陷阱。

【再补一条和第 4 章呼应的】

    运放本身是【受控源】。用叠加定理时，受控源不能置零，
    必须每个分电路里都保留。第 4 章那条规则在这里照样适用。


========================================================================
  第 6 站（25-30 min）  贯穿实例：把电桥信号放大 10 倍
------------------------------------------------------------------------

【任务】

    把第 2~4 章那张桥式电路当作传感器电桥：
    在 A、D 之间接 10V 电源（A 为 +），R₁=1Ω、R₂=2Ω、R₃=3Ω、R₄=4Ω、R₅=5Ω。

    现在要从 B、C 两个节点之间取出电压差，放大 10 倍后输出。

【第 1 步：先算出电桥的差分电压】

    第 4 章已经算过（R₅ 接在电路里时）：
        V_B = 204/31 ≈ 6.5806V
        V_C = 184/31 ≈ 5.9355V

    差分电压 = V_B − V_C = 20/31 ≈ 0.6452V

【第 2 步：接上差分放大器】

    取 R₁ = R₂ = 10kΩ、Rf = R₃ = 100kΩ，则放大倍数 = Rf/R₁ = 10。

    uo = 10 × (V_B − V_C) = 10 × 20/31 = 200/31 ≈ 6.4516V



【第 3 步：验算（用虚短虚断从头算一遍，不能只信公式）】

    u+ = V_C · R₃/(R₂ + R₃) = (184/31) × 100/110 = 1840/3410 = 184/341
    u− = u+ = 184/341                      ← 虚短
    − 端 KCL（虚断 ⇒ 两路电流相等）：
        (V_B − u−)/R₁ = (u− − uo)/Rf
        (204/31 − 184/341)/10k = (184/341 − uo)/100k
    两边乘 100k：
        10 × (204/31 − 184/341) = 184/341 − uo
    uo = 184/341 − 10 × (204/31 − 184/341)

    通分计算（204/31 = 2244/341）：
        uo = 184/341 − 10 × (2244/341 − 184/341)
           = 184/341 − 10 × (2060/341)
           = (184 − 20600)/341
           = −20416/341
    咦，得到负数而且不等于 200/31 —— 说明我把方向弄反了。

    【修正】差分公式 uo = (Rf/R₁)(u₂ − u₁) 里，u₂ 接在 + 端一侧、
    u₁ 接在 − 端一侧。所以要放大的是 V_B − V_C 时，必须让
    【V_B 走 + 端一侧、V_C 走 − 端一侧】，即 u₂ = V_B、u₁ = V_C：

        uo = 10 × (V_B − V_C) = 10 × 20/31 = 200/31 ≈ 6.4516V ✓

    这个"谁接 + 谁接 −"的坑非常典型 ——
    接反了结果是负的（−200/31），幅值一样但符号反了。
    实际接线时把两根线对调就正过来了。

【第 4 步：检查有没有饱和】

    200/31 ≈ 6.45V，只要电源电压大于 7V 左右就没问题（一般用 ±15V 或 ±12V）。
    如果放大倍数取 100，uo 会到 64.5V —— 远超电源电压，
    这时运放饱和，实际输出就卡在电源电压上，公式失效。

------------------------------------------------------------------------
  参考答案
------------------------------------------------------------------------

  1. A→∞（推出虚短 u+=u−）、Rin→∞（推出虚断 i+=i−=0）、Ro→0
     （推出输出是理想电压源）。
  2. 虚短管电压（两端电位相等），虚断管电流（输入端电流为零）。
  3. ① 运放工作在线性区；② 有负反馈；③ 不是开环/正反馈。
  4. 反相端电位为 0，但它与地之间没有导线连接。
     当成真接地会导致支路分析错误。
  5. 反相：uo = −(Rf/R₁)ui；同相：uo = (1 + Rf/R₁)ui。
     判据：输入接 − 端为反相，接 + 端为同相。
  6. 放大倍数为 1（uo = ui）。作用是隔离/缓冲：输入侧不取电流，
     输出侧能带负载。
  7. uo = −(20/10×1 + 20/20×2) = −(2 + 2) = −4V。
  8. 当 R₁ = R₂ 且 Rf = R₃ 时。
  9. uo = −(1/RC)∫ui dt。输入恒定时输出是一条斜坡（线性变化）。
 10. 实际输出卡在 ±15V（饱和）。公式不再成立。


========================================================================
  本章最容易犯的 6 个错
========================================================================

  1. 开环/正反馈还用虚短虚断        → 前提不成立，全错
  2. 同相比例写成 Rf/R₁             → 漏了那个 1
  3. 反相/同相接反                  → 输出符号相反
  4. 差分放大器 +/− 接反            → 结果为负，幅值对符号错
  5. 把虚地当真接地                 → 其它支路分析出错
  6. 输出饱和了还套公式             → 实际输出被电源电压卡住
