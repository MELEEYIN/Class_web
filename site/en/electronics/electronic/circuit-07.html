========================================================================

这一章不一样：因为有了电容和电感，换路之后电压电流要【慢慢过渡】。
中间这段过程叫【暂态】，怎么描述它，就是这一章的全部内容。

这一章只回答一个问题：

    换路以后，uC(t)、iL(t) 随时间怎么变？

   ④ 二阶电路：RLC 的三种情况                    （7-3）

★★ 贯穿全章的实例（接第 6 章那个 RC 电路）★★

    Us = 10V、R = 1kΩ、C = 1μF，t = 0 时合上开关给电容充电。

    第 6 章用【恒流源】充过这个电容，得到了 10V 和 50μJ。
    这一章换成【恒压源 + 电阻】，看看过程有什么不同。

    核心结论预告：
        τ = RC = 1ms
        uC(t) = 10(1 − e^(−t/τ))，永远到不了 10V，只能无限接近
        电源总共供出 100μJ，电容只存下 50μJ —— 另一半烧在电阻上了


========================================================================
  第 1 站（0-5 min）  换路定则：三个时刻
                                对应教材 7-1
------------------------------------------------------------------------

【什么叫换路】

    开关动作、元件参数突变、电源接入或断开 —— 都叫换路，记在 t = 0。

    换路把时间轴分成三段：
        0⁻   换路【前】的一瞬间（旧稳态）
        0⁺   换路【后】的一瞬间
        ∞    再过很久（新稳态）

【换路定则：只有两条】

        uC(0⁺) = uC(0⁻)        电容电压不能跃变
        iL(0⁺) = iL(0⁻)        电感电流不能跃变

    为什么？第 6 章讲过了：
        u 跃变 → du/dt 无穷大 → i = C·du/dt 无穷大 → 需要无穷大功率，做不到。
        i 跃变 → di/dt 无穷大 → u = L·di/dt 无穷大 → 同样做不到。

【这两个初始值是全章的地基】

    换路以后，电路的"历史"就被压缩成这两个数。
    只要知道 uC(0⁺)、iL(0⁺)，后面的过程就完全确定了。

    注意：不是所有量都不能跃变。
        能跃变的：电阻电流、电容电流、电感电压、电源电流
        不能跃变：只有电容电压、电感电流这两个

【三个时刻，三种算法】

    t = 0⁻  按【稳态】算：C 开路、L 短路 → 得 uC(0⁻)、iL(0⁻)
    t = 0⁺  用【换路定则】搬过来 → 得 uC(0⁺)、iL(0⁺)
            再画 0⁺ 等效电路：
               电容换成"电压值为 uC(0⁺) 的电压源"
               电感换成"电流值为 iL(0⁺) 的电流源"
            于是 0⁺ 时刻就是一个纯电阻电路，其它量全能用节点法算出来
    t = ∞   再按【稳态】算一遍：C 又开路、L 又短路 → 得新稳态值



【这一站要练到三个数随手能报】

    拿贯穿实例走一遍：
        t = 0⁻：电容没充过电，uC(0⁻) = 0；电容开路所以 i(0⁻) = 0
        t = 0⁺：定则给 uC(0⁺) = 0，但此时开关已合、
                相当于电容瞬间是短路 → i(0⁺) = 10V/1kΩ = 10mA
        t = ∞ ：电容充满相当于开路 → uC(∞) = 10V、i(∞) = 0

    三个时刻都算出来了，第 2 站就能一步写出表达式。


========================================================================
  第 2 站（5-13 min）  三要素法：一条公式打天下
                                对应教材 7-2
------------------------------------------------------------------------

【公式（背下来，全章都用它）】

    f(t) = f(∞) + [ f(0⁺) − f(∞) ] · e^(−t/τ)

    三个要素：
        f(0⁺)  初始值（第 1 站算）
        f(∞)   稳态值（C 开路、L 短路后算）
        τ      时间常数

【适用范围（很重要，不能乱用）】

    · 一阶电路：只含【一个】独立储能元件（一个 C 或一个 L）
    · 直流激励（多个直流源也可以）
    · 换路后电路结构不再变化

    二阶电路（两个独立储能元件）不能用这个公式，见第 4 站。

【时间常数 τ】

        RC 电路：τ = R·C
        RL 电路：τ = L/R          ← 注意是【除】

    其中 R 是"从储能元件两端看进去的等效电阻"：
    把其它独立源置零、把储能元件拿掉，看进去的电阻。

    量纲检查：Ω·F = s ✓，H/Ω = s ✓（对不上就是记错了）

【τ 的物理意义（不背也能推）】

    τ 是"衰变到初始变化量的 1/e = 36.8%"所需的时间。
    常用记忆点：
        1τ → 变化了 63.2%
        3τ → 95%
        5τ → 99.3%（工程上认为过程结束）

    注意：τ 只由电路结构和参数决定，和电源电压【无关】。
    换个电源，曲线形状不变，只是纵轴刻度变了。



【三步走（照这个顺序做，不会乱）】

    第 1 步  求 f(0⁺)
            先按稳态算 uC(0⁻) 或 iL(0⁻)；
            用换路定则搬到 0⁺；
            画 0⁺ 等效电路（C→电压源、L→电流源）求目标量。

    第 2 步  求 f(∞)
            把 C 当开路、L 当短路，重新算一遍电路。

    第 3 步  求 τ
            从储能元件看进去求 R_eq，再 τ = R_eq·C 或 L/R_eq。

    然后套公式，完事。

【贯穿实例走一遍】

    求 uC(t)：
        f(0⁺) = uC(0⁺) = 0
        f(∞)  = uC(∞) = 10V
        τ     = RC = 1kΩ × 1μF = 1ms

        uC(t) = 10 + (0 − 10)e^(−t/τ) = 10(1 − e^(−t/τ)) V

    代入几个时刻：
        t = 1τ = 1ms → uC = 10(1 − 0.368) = 6.32V
        t = 3τ = 3ms → uC = 9.50V
        t = 5τ = 5ms → uC = 9.93V

    注意：数学上 uC 永远到不了 10V（指数只趋近），
    工程上认为 5τ 以后就算充满了。

    求 i(t)（电流）：i(t) 也可以直接用三要素法：
        i(0⁺) = 10mA
        i(∞)  = 0
        τ     = 1ms
        i(t) = 0 + (10 − 0)e^(−t/τ) = 10e^(−t/τ) mA

    ★ 三要素法对【任何】一个一阶电路的【任何】一个量都成立，
      不只是 uC 和 iL。只要它能用同一个 τ，就能套这个公式。


========================================================================
  第 3 站（13-18 min）  三种响应的分解
                                对应教材 7-2 后半
------------------------------------------------------------------------

    同样一条曲线，可以按两种方式拆开。两种拆法都对，看题目要什么。

【拆法一：按"谁引起的"拆】

    零输入响应：没有电源，只靠电容/电感的初始储能
                f(t) = f(0⁺)·e^(−t/τ)         （最终归零）

    零状态响应：初始储能为零，只靠电源
                f(t) = f(∞)·(1 − e^(−t/τ))    （最终到稳态）

    全响应 = 零输入 + 零状态
           = f(0⁺)e^(−t/τ) + f(∞)(1 − e^(−t/τ))
           = f(∞) + [f(0⁺) − f(∞)]e^(−t/τ)   ← 就是三要素公式

    所以三要素公式本身就是"零输入 + 零状态"合并的结果。

【拆法二：按"变化快慢"拆】

    强制分量（稳态分量）：f(∞)，由电源决定，一直存在
    自由分量（暂态分量）：[f(0⁺) − f(∞)]e^(−t/τ)，由初始差值决定，逐渐消失

    两种拆法只是分类角度不同，数值完全一致。

【举个全响应的例子（第 6 站会用到）】

    设 uC(0⁻) = 4V（电容已经有电），合上开关接 10V 电源：
        f(0⁺) = 4V，f(∞) = 10V，τ = 1ms
        uC(t) = 10 + (4 − 10)e^(−t/τ) = 10 − 6e^(−t/τ)

        t = 0    → 4V（从 4V 开始）
        t = 1τ   → 10 − 6×0.368 = 7.79V
        t = 3τ   → 10 − 6×0.0498 = 9.70V

    拆开看：
        零输入 = 4e^(−t/τ)（4V 那部分在放电）
        零状态 = 10(1 − e^(−t/τ))（电源在充电）
        加起来正好是全响应 ✓



【一句话】

    全响应可以随便拆成两部分之和，但【不能把功率拆开算】
    （和第 4 章叠加定理"功率不能叠加"是同一个道理）。


========================================================================
  第 4 站（18-24 min）  二阶电路：振不振看 R
                                对应教材 7-3
------------------------------------------------------------------------

【什么叫二阶】

    电路里有【两个】独立的储能元件（一个 C 加一个 L），
    列出来的方程是二阶微分方程，所以叫二阶电路。

【RLC 串联的零输入响应】

    设 L、C 已储能，t = 0 后没有电源，只有 R 消耗能量。

    方程：LC·uC″ + RC·uC′ + uC = 0

    特征方程：s² + (R/L)s + 1/(LC) = 0

    记两个量：
        α  = R / (2L)          衰减系数（决定"消耗多快"）
        ω0 = 1 / √(LC)         谐振角频率（决定"想振多快"）

【四种情况：只比较 α 和 ω0】

    α ＞ ω0   过阻尼      两个不等负实根        不振荡，慢慢回零
    α ＝ ω0   临界阻尼    两个相等负实根        最快回到零且不振荡
    α ＜ ω0   欠阻尼      一对共轭复根          振荡着衰减
    α ＝ 0    无阻尼      一对纯虚根            等幅振荡（R = 0）

    R = 0 时没有电阻消耗能量，能量在 L 和 C 之间来回倒，永远振下去。



【临界阻尼对应的电阻（常考）】

    α = ω0  ⇒  R/(2L) = 1/√(LC)
            ⇒  R = 2√(L/C)

    记忆：2 倍根号（L 除以 C）。是这个电阻值，阻尼恰好临界。

【贯穿数值：L = 1H、C = 1F、uC(0) = 10V】

    ω0 = 1/√(1×1) = 1 rad/s
    α = R/(2×1) = R/2

        R = 4Ω → α = 2 ＞ 1  过阻尼   s₁ = −0.268, s₂ = −3.732
        R = 2Ω → α = 1 ＝ ω0 临界     s₁ = s₂ = −1
        R = 1Ω → α = 0.5 ＜ 1 欠阻尼  s = −0.5 ± j0.866
        R = 0Ω → α = 0        无阻尼  s = ±j1

    校验临界值：2√(L/C) = 2√(1/1) = 2Ω ✓ 与 R = 2Ω 对应。

【做题只要三步】

    ① 算出 α 和 ω0
    ② 比较大小，判断属于哪种情况
    ③ 写出对应形式的解（考试通常只要求判断类型和写特征根）

    注意：二阶电路的初始条件要用【两个】——
    一个 uC(0⁺)，一个 iL(0⁺)（或者 duC/dt(0⁺)）。
    因为二阶方程需要两个初始条件才能定解。


========================================================================
  第 5 站（24-27 min）  阶跃响应与冲激响应
                                对应教材 7-4
------------------------------------------------------------------------

    这一站内容少，考得也少，知道概念即可。

【单位阶跃 ε(t)】

        ε(t) = 0 （t ＜ 0）
        ε(t) = 1 （t ＞ 0）

    就是"t = 0 时从 0 跳到 1"。乘以 U 就是"t = 0 接入一个 U 的直流源"。

    阶跃响应 s(t)：电路对单位阶跃的零状态响应。
    因为一阶电路的三要素法本来就在处理"突然接入"，所以阶跃响应
    其实就是三要素公式在 f(0⁺) = 0 时的特例：
        s(t) = f(∞)(1 − e^(−t/τ))·ε(t)

【单位冲激 δ(t)】

    一个面积等于 1、宽度趋于 0 的极窄脉冲。
    物理意义：给电容瞬间注入电荷，或给电感瞬间建立电流
    （相当于"猛地撞一下"）。

    冲激响应 h(t)：电路对单位冲激的零状态响应。

【两者的关系（一句话）】

        h(t) = ds(t)/dt

    冲激是阶跃的导数，所以冲激响应是阶跃响应的导数。
    记住这一条，两者就不用分开背了。

【时不变性（也常考）】

    如果激励延迟了 t0 才加上，响应也整体延迟 t0，形状不变：
        激励 ε(t − t0) → 响应 s(t − t0)
    这叫"线性时不变电路"的基本性质。


========================================================================
  第 6 站（27-30 min）  贯穿实例：能量去哪了
------------------------------------------------------------------------

【先看过程】

    Us = 10V、R = 1kΩ、C = 1μF、τ = 1ms

        uC(t) = 10(1 − e^(−t/τ)) V
        i(t)  = 10e^(−t/τ) mA

    t = 0⁺    uC = 0，i = 10mA（电流最大，因为电容还像短路）
    t = 1τ    uC = 6.32V，i = 3.68mA
    t = 5τ    uC = 9.93V，i ≈ 0.07mA（基本充满）

    曲线是"电流一路衰减、电压一路升高"，两者恰好互补。

【再算能量账（本章最漂亮的一个结论）】

    电容最终储存：W_C = ½CU² = ½ × 1μF × (10V)² = 50μJ

    电容上的总电荷：Q = CU = 1μF × 10V = 10μC

    电源供出的能量：W_s = Us × Q = 10V × 10μC = 100μJ
    （电源一直输出 10V，总共送出 10μC 电荷，所以作功 100μJ）

    电阻烧掉的能量：W_R = W_s − W_C = 100 − 50 = 50μJ



【结论：效率永远是 50%】

    不管 R 取 100Ω、1kΩ 还是 10kΩ，
    电容最后都存 50μJ，电阻都烧 50μJ。

    R 只决定充得【多快】（τ = RC），不决定充【多少】。

    这一点很反直觉：以为"电阻小一点损耗就小"，其实不会。
    要减少损耗只有一条路 —— 不用电阻充电（恒流源、开关电源）。

【和第 6 章那个恒流充电对比】

    第 6 章：10mA 恒流源充 1ms → uC = 10V，储能 50μJ
             电源只供出 50μJ，效率 100% ✓
    第 7 章：10V 恒压源串 1kΩ  → uC → 10V，储能 50μJ
             电源供出 100μJ，效率 50%

    同样把电容充到 10V，恒流源比恒压源省一半能量。
    这就是为什么高效充电电路都用恒流/开关方式。

  4. RCT 电路 τ = RC；RL 电路 τ = L/R。
  5. 衰减到初始变化量的 1/e（36.8%）所需的时间；3τ 到 95%，5τ 到 99.3%。

  7. ① 零输入响应 + 零状态响应；② 强制分量（稳态）+ 自由分量（暂态）。
  8. 因为功率与电流/电压是二次关系，而叠加定理只对一次（线性）量成立。
  9. 比较 α = R/(2L) 与 ω0 = 1/√(LC)。
 10. R = 2√(L/C)。
 11. h(t) = ds(t)/dt，冲激响应是阶跃响应的导数。
 12. τ = RC = 1kΩ × 1μF = 1ms；uC(1τ) = 10(1 − e⁻¹) = 6.32V；
     电源供出 W_s = Us·C·Us = 100μJ（其中 50μJ 存进电容，50μJ 烧在电阻上）。


========================================================================
  本章最容易犯的 8 个错
========================================================================

  1. 把 τ = RC 套到 RL 电路上
     RL 是 τ = L/R（除）。量纲对不上就是记错了。

  2. 求 τ 时忘了"从储能元件看进去"
     不是随便挑一个电阻，要把其它源置零、元件拿掉再求。

  3. 0⁺ 等效电路画错
     电容要换成【电压源】（不是短路），电感换成【电流源】（不是开路）。
     只有 uC(0⁺) = 0 时电容才可以当短路，iL(0⁺) = 0 时电感才可以当开路。

  4. 用三要素法算二阶电路
     二阶电路有两个储能元件，公式不成立。

  5. 以为 uC 真的能到 Us
     指数只是趋近，永远达不到。工程上 5τ 后算充满。

  6. 忘记 τ 与电源无关
     τ 只由 R、L、C 决定。换电源只改变 f(∞)，不改变 τ。

  7. 二阶电路只给一个初始条件
     二阶方程需要两个：uC(0⁺) 和 iL(0⁺)（或 duC/dt(0⁺)）。

  8. 把"功率"也拆开叠加
     零输入功率 + 零状态功率 ≠ 全响应的功率。
