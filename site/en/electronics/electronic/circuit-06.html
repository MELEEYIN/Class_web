========================================================================
      邱关源《电路》第 6 版 · 第 6 章
      储能元件（电容与电感）—— 30 分钟速通
========================================================================

适用对象：学完第 1~5 章（前五章全是电阻，这章第一次出现「动态元件」）
预计用时：30 分钟（这章内容少，但要为第 7 章打好底）
教材对应：第 6 章 6-1 ~ 6-3 全部小节


========================================================================
  全章地图：这一章到底在讲什么
========================================================================

前五章的元件只有两种脾气：电阻（u = Ri）、电源。
它们都是【即时】的 —— 此刻的电压只取决于此刻的电流，跟过去无关。

这一章闯进来两个有【记忆】的元件：电容和电感。
它们的电压/电流取决于"之前积累了多少"，所以要出现积分和导数。

好消息是：这一章不要求解微分方程。
         它只讲【元件的脾气】，动态电路留给第 7 章。

这一章五件事：

   ① 电容：q = Cu、i = C·du/dt、W = ½Cu²          （6-1）
   ② 电感：ψ = Li、u = L·di/dt、W = ½Li²          （6-2）
   ③ 串并联：电容与电阻【相反】，电感与电阻【相同】 （6-3）
   ④ 两个「不能跃变」+ 直流稳态                   （伏笔，第 7 章要用）
   ⑤ 对偶关系：把 u 与 i、C 与 L 对调就互相变身

时间表：

   0 - 6  min   第 1 站  电容：唯一的重点是 du/dt
   6 - 12 min   第 2 站  电感：把 u 和 i 换个位置就是它
  12 - 18 min   第 3 站  串并联与分压（最容易记反的地方）
  18 - 22 min   第 4 站  两个「不能跃变」与直流稳态
  22 - 26 min   第 5 站  对偶关系：一张表串起两章
  26 - 30 min   第 6 站  贯穿实例：同样的 1ms，同样的 50μJ


========================================================================
  第 1 站（0-6 min）  电容：唯一的重点是 du/dt
                                对应教材 6-1
------------------------------------------------------------------------

【电容是什么】

    两块金属板中间夹一层绝缘介质，就是电容。
    加电压以后两块板上会积累等量异号的电荷：

        q = C · u          C 是电容（单位 F，法拉）

    常用单位是 μF（10⁻⁶）、nF（10⁻⁹）、pF（10⁻¹²）。

【伏安关系：这一个式子决定全部】

    对 q = Cu 两边求导：

        i = dq/dt = C · du/dt

    注意它说的是【电压的变化率】，不是电压本身：
        · 电压不变（哪怕是 100V）→ i = 0
        · 电压变得快 → i 大

    这就是电容和电阻最根本的区别：
        电阻看"现在有多高"，电容看"变化有多快"。



【反过来写：积分形式】

    u(t) = (1/C) ∫[t0→t] i dt + u(t0)

    这个式子说明电容是【记忆元件】：
    要算现在的电压，必须知道"之前充到多少了"（即 u(t0)）。

    考试里两种小题：
        · 已知 u(t) 的波形 → 求导得 i(t)
        · 已知 i(t) 的波形 → 积分得 u(t)，别忘加上初值 u(t0)

【储能】

    W_C = ½ C u²

    只和电压有关，和怎么充上来的无关。
    充电时吸收能量，放电时把能量还回去 —— 所以叫【储能元件】。

【两条推论】

    ① 电压不能跃变
       如果 u 能在 0 时间内跳变，du/dt 就是无穷大，i 也就无穷大。
       实际电路给不出无穷大电流，所以电压只能连续变化。

    ② 直流稳态时相当于【开路】
       u 不变 → du/dt = 0 → i = 0。
       所以第 7 章求稳态值时，把电容当成断开就行。


========================================================================
  第 2 站（6-12 min）  电感：把 u 和 i 换个位置就是它
                                对应教材 6-2
------------------------------------------------------------------------

【电感是什么】

    导线绕成线圈，通电流以后内部建立磁场，磁链随电流成正比：

        ψ = L · i           L 是电感（单位 H，亨利）

    常用单位 mH（10⁻³）、μH（10⁻⁶）。

【伏安关系】

        u = L · di/dt

    同样只看【电流的变化率】：
        · 电流不变（哪怕是 10A）→ u = 0
        · 电流变得快 → u 大

    积分形式：

        i(t) = (1/L) ∫[t0→t] u dt + i(t0)

    同样是记忆元件。



【储能】

    W_L = ½ L i²

【两条推论】

    ① 电流不能跃变
       如果 i 能跳变，di/dt 无穷大，u 就无穷大（会产生很高的感应电压）。
       这就是为什么断开电感回路时会打火 —— 电感会拼命维持电流。

    ② 直流稳态时相当于【短路】
       i 不变 → di/dt = 0 → u = 0。
       所以第 7 章求稳态值时，把电感当成一根导线。

【三个必须分清的点】

    1. 电容的电压不能跃变；电感的电流不能跃变。
       不要背成"电压不能跃变、电流也不能跃变" —— 说反了另一半。

    2. 电容的电流可以跃变（只要 du/dt 有限即可）；
       电感的电压可以跃变（只要 di/dt 有限即可）。

    3. 单位：C 用 F，L 用 H。
       1μF = 10⁻⁶F，1mH = 10⁻³H —— 换算出错是这类题最大的失分点。


========================================================================
  第 3 站（12-18 min）  串并联与分压：最容易记反的地方
                                对应教材 6-3
------------------------------------------------------------------------

    【警告】这一站的公式和第 2 章的电阻公式【方向相反】，
    每年都有人在这里丢分。

【电容】

    串联：1/C = 1/C₁ + 1/C₂ + …        （倒数和，像电阻的【并联】）
          C = C₁C₂/(C₁+C₂)

    并联：C = C₁ + C₂ + …              （直接相加，像电阻的【串联】）

    为什么？因为串联时两块电容上的电量相同（q 相同），电压相加，
    由 u = q/C 得 1/C 相加。

【电感】

    串联：L = L₁ + L₂ + …              （直接相加，像电阻的【串联】）
    并联：1/L = 1/L₁ + 1/L₂ + …        （倒数和，像电阻的【并联】）

    完全就是电阻的公式，把 R 换成 L 即可。



【电容分压（和电阻相反）】

    两个电容串联接在电压 U 上：

        u₁ = U · C₂/(C₁ + C₂)
        u₂ = U · C₁/(C₁ + C₂)

    注意分子是【另一个】电容 —— 也就是说：
        【容量大的分压小，容量小的分压大】

    和电阻正好相反（电阻大的分压大）。

    例：C₁ = 2μF、C₂ = 4μF 串联接 12V
        u₁ = 12 × 4/6 = 8V
        u₂ = 12 × 2/6 = 4V
        校验：电量 q = C₁u₁ = 2μF × 8V = 16μC
                  C₂u₂ = 4μF × 4V = 16μC  ✓ 相等（串联电荷相同）

【一句话记法】

    把公式里的 C（或 L）当成 R 代进去：
        · 电感的公式和电阻【一模一样】
        · 电容的公式和电阻【上下颠倒】（串联↔并联、分压的分子↔分母）

    所以只有电容需要特别小心，电感照着电阻写就行。


========================================================================
  第 4 站（18-22 min）  两个「不能跃变」与直流稳态
------------------------------------------------------------------------

【为什么专门讲这个】

    第 7 章整章都建立在这两句话上，现在背下来，第 7 章能省一半时间。

【换路瞬间的两个定则（第 7 章的换路定则）】

    u_C(0+) = u_C(0−)        电容电压不能跃变
    i_L(0+) = i_L(0−)        电感电流不能跃变

    读法：换路后一瞬间的值 = 换路前一瞬间的值。
    所以只要算出换路前电容的电压、电感的电流，就有了初始条件。

    注意：其它量（电阻电流、电容电流、电感电压）都可以跃变，不能套这个。

【直流稳态（t → ∞）】

    · 电容：u 不变 → i = C·du/dt = 0 → 【开路】
    · 电感：i 不变 → u = L·di/dt = 0 → 【短路】

    所以求稳态值时，电路退化成纯电阻电路，
    用第 2、3、4 章的方法算就行。



【三个时刻的完整图景（第 7 章会用）】

    t = 0−   换路前：按稳态处理（C 开路、L 短路）
    t = 0+   换路瞬间：用换路定则得 uC(0+)、iL(0+)
    t → ∞    新稳态：再把 C 开路、L 短路算一遍

    三个点定下来，加上时间常数 τ，就是第 7 章的「三要素法」。
    现在先把这三个点弄清楚，第 7 章会非常轻松。


========================================================================
  第 5 站（22-26 min）  对偶关系：一张表串起两章
------------------------------------------------------------------------

    把电容和电感的公式摆在一起看，会发现它们【逐字对调】就能互换：

        电容                          电感
        ------------------------------------------------
        q = C·u                       ψ = L·i
        i = C·du/dt                   u = L·di/dt
        u = (1/C)∫i dt + u(t0)        i = (1/L)∫u dt + i(t0)
        W = ½Cu²                      W = ½Li²
        电压不能跃变                  电流不能跃变
        直流稳态 → 开路               直流稳态 → 短路
        串联用倒数和                  串联直接相加
        并联直接相加                  并联用倒数和

    对调规则：【u ↔ i】【C ↔ L】【q ↔ ψ】【串联 ↔ 并联】【开路 ↔ 短路】

【这个表有什么用】

    ① 少背一半公式：记住电容的，电感照对调规则推
    ② 检查答案：算完电容题，把答案里 u 换 i、C 换 L，
       如果量纲和数值都合理，说明没算反
    ③ 第 7 章的一阶电路：RC 和 RL 的公式也是对偶的，
       时间常数 τ = RC ↔ τ = L/R（注意后者是除不是乘）

    最后这条要特别注意：RC 是乘，RL 是除。
    因为 τ 的量纲必须是秒：R·C = Ω·F = s ✓；L/R = H/Ω = s ✓。


========================================================================
  第 6 站（26-30 min）  贯穿实例：同样的 1ms，同样的 50μJ
------------------------------------------------------------------------

【任务】

    用两组元件做同一件事，看结果：

        电容：C = 1μF，用 10mA 【恒流源】充电 1ms
        电感：L = 1H，加 10V 【恒压源】1ms

    求各自最终的电压/电流，以及储能。

【第 1 步：电容】

    恒流充电时 i 不变，用积分形式最简单：

        uC = (1/C) ∫i dt = I·t/C
           = (10mA × 1ms) / 1μF
           = (10⁻² × 10⁻³) / 10⁻⁶
           = 10 V

    储能：W = ½Cu² = ½ × 10⁻⁶ × 10² = 5 × 10⁻⁵ J = 50 μJ



【第 2 步：电感】

    恒压通流时 u 不变：

        iL = (1/L) ∫u dt = U·t/L
           = (10V × 1ms) / 1H
           = 10 × 10⁻³
           = 10 mA

    储能：W = ½Li² = ½ × 1 × (10⁻²)² = 5 × 10⁻⁵ J = 50 μJ

【第 3 步：看结果】

        电容：10 V，储能 50 μJ
        电感：10 mA，储能 50 μJ

    电压 10V 和电流 10mA 在数值上都是"10"，储能完全相同。
    这不是巧合，正是第 5 站那张对偶表的直接体现：
    同样"10 乘以 1ms 再除以元件值"，一个得电压一个得电流。

【第 4 步：加一句实用提醒】

    · 电容的 10V 是电压，可以一直保持（断开电源也不丢，只是慢慢漏电）
    · 电感的 10mA 是电流，一旦断开回路，电感会为了维持这个电流
      产生很高的感应电压（可能击穿开关）
    · 实际电路里断开电感要加【续流二极管】—— 这就是第 2 站"电流不能
      跃变"带来的工程后果


========================================================================
  自测：10 题检验这一章
========================================================================

  1. 电容的伏安关系式是什么？它看的是电压本身还是变化率？
  2. 电感的伏安关系式是什么？
  3. 为什么说电容、电感是「记忆元件」？
  4. 直流稳态时，电容和电感各相当于什么？
  5. 两个电容 C₁、C₂ 串联的等效电容公式？并联呢？
  6. 两个电感 L₁、L₂ 串联的等效电感公式？并联呢？
  7. C₁ = 2μF、C₂ = 4μF 串联接 12V，各自的电压是多少？
  8. 电容的电压能不能跃变？电感的电流能不能跃变？
  9. 已知 C = 2μF，电压从 0 线性升到 6V 用 3ms，充电电流是多少？
 10. L = 0.5H，电流从 0 升到 2A 用 0.1s，电感两端电压是多少？

------------------------------------------------------------------------
  参考答案
------------------------------------------------------------------------

  1. i = C·du/dt。看的是电压的【变化率】—— 电压不变时电流为零。
  2. u = L·di/dt。
  3. 因为它们的电压/电流要用【积分】形式表示：
     u = (1/C)∫i dt + u(t0)，i = (1/L)∫u dt + i(t0)，
     必须知道历史初值 u(t0) 或 i(t0)。
  4. 电容相当于【开路】，电感相当于【短路】。
  5. 串联：1/C = 1/C₁ + 1/C₂，即 C = C₁C₂/(C₁+C₂)；并联：C = C₁ + C₂。
  6. 串联：L = L₁ + L₂；并联：1/L = 1/L₁ + 1/L₂。
  7. u₁ = 12 × 4/6 = 8V（2μF 上电压大），u₂ = 12 × 2/6 = 4V。
     校验：q = 2μF×8V = 16μC = 4μF×4V ✓
  8. 电容的电压不能跃变；电感的电流不能跃变。
     （电容的电流、电感的电压都可以跃变。）
  9. i = C·du/dt = 2μF × 6V/3ms = 4mA（恒定）。
 10. u = L·di/dt = 0.5H × 2A/0.1s = 10V（恒定）。


========================================================================
  本章最容易犯的 6 个错
========================================================================

  1. 把电容的串并联公式套成电阻的
     电容串联是倒数和。记反了整题全错。

  2. 电容分压时分子写错
     u₁ = U·C₂/(C₁+C₂) —— 分子是【另一个】电容。
     结论是"容量小的分压大"，和电阻相反。

  3. 积分形式忘了加初值 u(t0) / i(t0)
     u = (1/C)∫i dt 只是"变化量"，不是"总值"。

  4. 单位没统一就代入
     10mA 要写成 0.01A，1μF 要写成 10⁻⁶F。这类题九成错误出在单位。

  5. 说"电压和电流都不能跃变"
     只有电容电压、电感电流不能跃变。另外两个都可以。

  6. 用 τ = RC 的公式去算 RL 电路
     RC 是乘，RL 是除（τ = L/R）。量纲对不上就是记错了。


========================================================================
  这一章和后面的关系
========================================================================

    · 第 7 章（一阶/二阶电路）：整章都建立在【换路定则 + 稳态】上，
      所以第 4 站那两句话必须背下来。
    · 第 8 章以后（正弦稳态）：把 du/dt 换成 jω，
      电容的阻抗是 1/(jωC)，电感的阻抗是 jωL —— 对偶关系继续成立。
    · 第 11 章（频率响应）：电容电感随频率变化的特性，
      正是滤波器能工作的原因。

    一句话：这一章公式少、题也简单，
    但它是【动态电路的入口】—— 第 7 章的难度，取决于这一章的理解深度。
