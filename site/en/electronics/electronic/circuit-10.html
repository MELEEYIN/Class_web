========================================================================
  全章地图：这一章到底在讲什么
========================================================================

前面所有章节都把频率当成"常数"——电源 50Hz 就是 50Hz。
这一章把频率当成【变量】，看电路在不同频率下表现怎么变。

一旦频率变成变量，就会出现一个特别有趣的状态：

    感抗和容抗恰好相等、互相抵消 —— 这叫【谐振】

谐振时的现象很反直觉：
    · 阻抗最小，电流最大
    · 电感上的电压可能是电源电压的几十倍（！）

这一章只回答三个问题：

    ① 一个电路对不同频率的响应怎么描述？   → 网络函数
    ② 什么时候谐振？谐振时有什么现象？     → ωL = 1/(ωC)
    ③ 谐振峰有多尖？怎么衡量？             → 品质因数 Q 与带宽

一共五件事：

   ① 网络函数与频率响应                      （11-1）
   ② 串联谐振的条件与四个结论                （11-2）
   ③ 品质因数 Q 与「谐振升压」               （11-2）
   ④ 谐振曲线、通频带与选择性                （11-3）
   ⑤ 并联谐振与四种滤波器                    （11-3、11-4）

时间表：

   0 - 5  min   第 1 站  网络函数：把频率当变量
   5 - 11 min   第 2 站  串联谐振：ωL = 1/(ωC)
  11 - 17 min   第 3 站  品质因数 Q（三个公式与谐振升压）
  17 - 22 min   第 4 站  谐振曲线、带宽、选择性

★★ 贯穿全章的实例（数值特意配成 Q = 10）★★

    L = 1H、C = 1μF、R = 100Ω，接 U = 10V 的正弦电源。

    · 谐振频率：ω0 = 1/√(LC) = 1000 rad/s（f0 = 159.2Hz）
    · 谐振时阻抗最小：Z = R = 100Ω
    · 谐振时电流最大：I0 = U/R = 0.1A
    · 品质因数：Q = ω0L/R = 1000×1/100 = 10
    · 谐振时 UL = UC = Q·U = 100V（是电源的 10 倍！）
    · 通频带：BW = ω0/Q = 100 rad/s

    最后那一条是本章最反直觉、也是考试最爱考的地方：
    电源只有 10V，线圈和电容上却有 100V —— 这叫【谐振升压】。


========================================================================
  第 1 站（0-5 min）  网络函数：把频率当变量
                                对应教材 11-1
------------------------------------------------------------------------

【网络函数 H(jω)】

    在正弦稳态下，把所有激励看成一个整体，某个响应与激励的比值：

        H(jω) = 响应相量 / 激励相量

    它是个复数，所以有两部分信息：

        |H(jω)|  幅频特性 —— 各频率的"放大倍数"
         φ(ω)   相频特性 —— 各频率的"相位移动"

    把 |H| 对 ω 画出来，就是本章所有的曲线。



【为什么要专门研究这个】

    因为实际信号很少是单一频率的：
        · 语音、音乐是无数频率的叠加
        · 方波含有基波和各次谐波

    电路对不同频率"态度不同"，这件事决定了两大类应用：
        · 想保留某些频率 → 滤波器
        · 想选出某个频率 → 谐振（选频）

【本章的核心结构】

    所有内容都围绕一个量：RLC 串联电路的阻抗

        Z = R + j(ωL − 1/(ωC))

    其中：
        ωL 叫感抗 XL（随 ω 增大）
        1/(ωC) 叫容抗 XC（随 ω 减小）

    这两项一个随频率变大、一个随频率变小 ——
    在某个频率上它们必然相等，那一刻就是【谐振】。


========================================================================
  第 2 站（5-11 min）  串联谐振：ωL = 1/(ωC)
                                对应教材 11-2
------------------------------------------------------------------------

【谐振条件】

        ωL = 1/(ωC)     ⇒     ω0 = 1/√(LC)

        谐振频率：f0 = ω0/(2π)

    贯穿实例：L = 1H、C = 1μF
        ω0 = 1/√(1×10⁻⁶) = 1000 rad/s
        f0 = 1000/(2π) ≈ 159.2 Hz



【谐振时的四个结论（背下来）】

    ① 阻抗最小：Z = R（虚部为零，只剩电阻）
    ② 电流最大：I0 = U/R
    ③ 电压与电流同相：φ = 0，cosφ = 1
    ④ 感抗与容抗相等：XL = XC，两者电压大小相等、方向相反

    第 ④ 条是重点：UL 和 UC 【不是零】，而是大小相等、相位相反。
    它们互相抵消，所以电源"看到"的只有 R 上的 10V。

【谐振时的相量图】

    以电流 İ 为基准（水平向右）：
        U̇R 与 İ 同相 → 水平向右
        U̇L 超前 90°  → 竖直向上
        U̇C 滞后 90°  → 竖直向下
        U̇L 与 U̇C 长度相等 → 恰好抵消
        合成电压 U̇ = U̇R，与 İ 同相 ✓



【一句话总结】

    谐振 = 电感与电容"互相抵消"，电路退化成纯电阻。
    但它们在抵消之前，各自承受了很大的电压。


========================================================================
  第 3 站（11-17 min）  品质因数 Q 与谐振升压
                                对应教材 11-2 后半
------------------------------------------------------------------------

【Q 的三个等价公式（串联电路）】

        Q = ω0L / R = 1/(ω0CR) = (1/R)·√(L/C)

    三个式子数值完全相等，考试用哪个方便就用哪个：
        · 已知 L、R → 用 ω0L/R
        · 已知 C、R → 用 1/(ω0CR)
        · 只给 L、C、R → 用 (1/R)√(L/C)

    贯穿实例：Q = 1000×1/100 = 10
    校验：1/(1000×1e-6×100) = 1/0.1 = 10 ✓
          (1/100)√(1/1e-6) = (1/100)×1000 = 10 ✓

【★ 谐振升压：本章最重要的现象】

    谐振时电流 I0 = U/R，于是

        UL = I0·ω0L = (U/R)·ω0L = U·(ω0L/R) = Q·U

    同理 UC = Q·U。也就是说：

        谐振时，电感和电容上的电压是电源电压的 Q 倍！

    贯穿实例：Q = 10、U = 10V → UL = UC = 100V

    工程含义：
        · 电力系统中要避免谐振 —— 100V 的电源可能在设备上产生
          上千伏电压，直接击穿绝缘
        · 无线电里又需要谐振 —— 收音机的天线回路靠它把微弱信号
          放大到可处理的幅度

【Q 的物理意义】

    Q 越大：
        · 谐振峰越尖（选择性越好）
        · 通频带越窄
        · 谐振升压倍数越高

    一个数同时描述这三件事，这就是 Q 的妙处。


========================================================================
  第 4 站（17-22 min）  谐振曲线、通频带与选择性
                                对应教材 11-3
------------------------------------------------------------------------

【归一化谐振曲线】

        I/I0 = 1 / √( 1 + Q²(ω/ω0 − ω0/ω)² )

    · ω = ω0 时，括号内为 0，I/I0 = 1（最大值）
    · ω 偏离 ω0 时，分母变大，电流下降
    · Q 越大，同样的偏离造成的下降越剧烈 → 曲线越尖



【通频带 BW】

    定义：电流降到最大值的 1/√2 ≈ 0.707 倍时，
          两个频率之间的宽度。

        BW = ω0 / Q

    为什么是 0.707？因为功率 P = I²R，电流降到 1/√2 时功率恰好减半，
    所以这两个点叫【半功率点】。

    贯穿实例：BW = 1000/10 = 100 rad/s
        精确半功率点：ω1 = 951.25、ω2 = 1051.25 rad/s
        （近似就是 ω0 ± BW/2 = 950 与 1050，Q 大时很接近）

    校验：半功率点处 |Z| = √2·R = 141.4Ω
          实际 |Z(951.25)| = 141.421 ✓

【选择性：Q 的两难】

    Q 高 → 峰尖、带窄 → 能"选台"，但稍有漂移就失谐
    Q 低 → 峰平、带宽 → 不易失谐，但选不出台

    收音机选台就是调电容改变 ω0，让带通的中心对准电台频率。
    中波收音机的 Q 一般在几十到一百多。

【不同 Q 对应的电阻（同一个 ω0）】

    Q = 1   → R = ω0L/Q = 1000Ω，BW = 1000 rad/s（很宽）
    Q = 10  → R = 100Ω，    BW = 100 rad/s
    Q = 100 → R = 10Ω，     BW = 10 rad/s（很尖）

    注意：L、C 不变，只改 R 就能改 Q。R 越小 Q 越高。


========================================================================
  第 5 站（22-26 min）  并联谐振与滤波器
                                对应教材 11-3、11-4
------------------------------------------------------------------------

【并联谐振：把串联的结论"倒过来"】

    把 R、L、C 并联，用导纳分析：

        Y = 1/R + j(ωC − 1/(ωL))

    谐振条件完全相同：ωC = 1/(ωL) ⇒ ω0 = 1/√(LC)

    但现象正好相反：
        串联谐振：Z 最小 → 电流最大 → 相当于【短路】
        并联谐振：Y 最小 → 电压最大 → 相当于【开路】

    ★ 记忆：串联看阻抗最小，并联看导纳最小。

【并联的品质因数】

        Q_并 = R/(ω0L) = ω0CR = R√(C/L)

    和串联的 Q 串 = ω0L/R 正好【互为倒数】的形式：
    串联是"分子带 L、分母带 R"，并联是"分子带 R、分母带 L"。

    所以同样是 R = 100Ω、L = 1H、ω0 = 1000：
        串联：Q = 1000/100 = 10
        并联：Q = 100/1000 = 0.1
    并联时 R 越大 Q 越高 —— 因为并联电路里 R 是"耗能支路"，
    R 越大耗能越少，Q 越高。

【滤波器：谐振的工程应用】

    滤波器就是"让某些频率通过、把另一些挡掉"的网络。
    用网络函数描述，就是看 |H(jω)| 的形状：

        低通 LPF：低频通、高频挡（一个 R 加一个 C）
        高通 HPF：高频通、低频挡（电容和电阻换个位置）
        带通 BPF：只有 ω0 附近通（RLC 串联，输出取 R 上的电压）
        带阻 BSF：只有 ω0 附近挡（RLC 串联，输出取 LC 上的电压）

    带通/带阻的中心频率就是谐振频率 ω0，带宽就是 BW = ω0/Q。



【为什么收音机能选台】

    天线收到的是所有电台信号的叠加（不同频率）。
    调谐回路是一个带通滤波器：
        转动电容 → C 变化 → ω0 = 1/√(LC) 变化
        → 带通中心移到某个电台的频率
        → 只有那个电台的信号能通过

    这就是"选频"的全部原理。


========================================================================
  第 6 站（26-30 min）  贯穿实例：把整章算一遍
------------------------------------------------------------------------

【题目】

    R = 100Ω、L = 1H、C = 1μF 串联，接 U = 10V 的正弦电源。
    求谐振频率、谐振时的电流与各电压、品质因数、通频带。

【第 1 步：谐振频率】

    ω0 = 1/√(LC) = 1/√(1×10⁻⁶) = 1000 rad/s
    f0 = ω0/(2π) = 1000/6.283 ≈ 159.2 Hz

【第 2 步：谐振时的阻抗与电流】

    Z(jω0) = R + j(ω0L − 1/(ω0C)) = 100 + j(1000 − 1000) = 100Ω
    I0 = U/R = 10/100 = 0.1A（最大）

【第 3 步：谐振时各元件电压】

    UR = I0·R = 0.1 × 100 = 10V      ← 等于电源电压 ✓
    UL = I0·ω0L = 0.1 × 1000 = 100V  ← 是电源的 10 倍！
    UC = I0/(ω0C) = 0.1/10⁻³ = 100V  ← 也是 10 倍

    相量校验：
        U̇R = 10∠0°，U̇L = 100∠90°，U̇C = 100∠−90°
        U̇R + U̇L + U̇C = 10 + j100 − j100 = 10∠0° ✓ 等于电源

    ★ 这就是"谐振升压"：电感电压 100V、电容电压 100V，
      但两者相位相反，加起来为零。电源只"看到" 10V。

【第 4 步：品质因数（三种算法互相校验）】

    Q = ω0L/R = 1000×1/100 = 10
    Q = 1/(ω0CR) = 1/(1000×10⁻⁶×100) = 1/0.1 = 10 ✓
    Q = (1/R)√(L/C) = (1/100)×√(10⁶) = 1000/100 = 10 ✓

    三种算法都得 10，说明理解没错。

【第 5 步：通频带】

    BW = ω0/Q = 1000/10 = 100 rad/s
    精确半功率点：ω1 = 951.25、ω2 = 1051.25 rad/s
    校验 |Z| = √(100² + 100²) = 141.4Ω = √2·R ✓

【第 6 步：如果改成 Q = 100（把 R 改成 10Ω）】

    R = ω0L/Q = 1000/100 = 10Ω
    BW = ω0/Q = 10 rad/s（窄了 10 倍）
    此时 UL = UC = Q·U = 100×10 = 1000V（！）

    这说明：Q 越高，选择性越好，但升压倍数也越吓人。
    实际电路设计必须在"选择性"和"耐压"之间折中。

【结果一览】

        ω0 = 1000 rad/s（f0 ≈ 159.2Hz）
        Z = 100Ω，I0 = 0.1A
        UR = 10V，UL = UC = 100V
        Q = 10
        BW = 100 rad/s（951.25 ~ 1051.25）

------------------------------------------------------------------------
  参考答案
------------------------------------------------------------------------

  1. H(jω) = 响应相量/激励相量；|H| 是幅频特性，辐角 φ 是相频特性。
  2. ωL = 1/(ωC)；ω0 = 1/√(LC)，f0 = ω0/(2π)。
  3. Z = R 最小；I = U/R 最大；电压与电流同相（φ = 0）。
  4. 不是零。UL = UC = Q·U，两者大小相等、相位相反（差 180°），
     相量相加后为零，所以只剩 UR。
  5. Q = ω0L/R = 1/(ω0CR) = (1/R)√(L/C)。
  6. UL = UC = Q·U。因为谐振时 I0 = U/R，而 XL = ω0L，
     所以 UL = I0·XL = (U/R)·ω0L = Q·U。
  7. BW = ω0/Q；定义是电流降到 0.707I0 的两个频率之差。
     因为 P = I²R，I 降到 1/√2 时功率恰好减半。
  8. 峰变尖、带宽变窄、升压倍数变大（三者同向变化）。
  9. 串联：阻抗最小、电流最大，相当于短路；
     并联：导纳最小、端电压最大，相当于开路。
 10. Q_并 = R/(ω0L) = ω0CR = R√(C/L)。
 11. 低通用 R 和 C（输出取 C 上的电压）；高通也是 R 和 C（输出取 R 上）；
     带通用 RLC 谐振（输出取 R 上）。
 12. ω0 = 1/√(1×10⁻⁶) = 1000 rad/s；Q = ω0L/R = 10；
     BW = ω0/Q = 100 rad/s；UL = Q·U = 10×10 = 100V（设 U = 10V）。


========================================================================
  本章最容易犯的 6 个错
========================================================================

  1. 认为谐振时 UL = UC = 0
     它们不是零，是 Q·U，只是相位相反互相抵消。这是本章第一大坑。

  2. 三个 Q 公式混用
     串并用 ω0L/R，并并用 R/(ω0L)。记法：谁是"耗能支路"，
     谁就带着 R 出现在分子的位置。

  3. 通频带和半功率点搞混
     BW 是两个半功率点的【差】，不是某一个点。

  4. 认为 Q 越高越好
     Q 高选择性好，但升压倍数高（可能击穿）、带宽窄（容易失谐）。

  5. 并联谐振也写成"阻抗最小"
     并联是【导纳】最小，对应阻抗最大、端电压最大。

  6. 用 f0 和 ω0 搞混
     公式里全都是 ω（rad/s），算完 f = ω/(2π) 才是 Hz。差 2π 倍。
