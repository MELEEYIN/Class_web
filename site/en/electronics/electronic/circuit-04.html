========================================================================
  全章地图：这一章到底在讲什么
========================================================================

前三章的路子是"把方程列对，然后解"。
这一章换了个路子：不列方程，靠几个定理直接看出来。

差别在哪？
    节点法解一个五节点电路，要解 4 元一次方程组；
    用戴维南定理，可能只要求一个开路电压、除一下，就完了。

代价是：定理有【适用条件】。用错了条件，答案会错得很自然
—— 看起来算得挺顺，结果全错，这是本章最大的坑。

这一章五件事：

   ① 叠加定理：多个源 → 拆成一个一个算         （4-1）   ← 每年必考
   ② 替代定理：已知的电压/电流 → 换成源        （4-2）   ← 会用就行
   ③ 戴维南 / 诺顿定理：含源单口塌缩成两个元件 （4-3）   ← 全章核心
   ④ 最大功率传输：负载取多大最划算           （4-4）   ← 选择题高频
   ⑤ 特勒根 / 互易 / 对偶：了解概念即可        （4-5~4-7）

★★ 贯穿全章的实例（还是那张桥式电路）★★

    这一章给它加一个电源：
    在 A、D 之间接一个 10V 电压源（A 端为 +），R₁=1Ω、R₂=2Ω、
    R₃=3Ω、R₄=4Ω、R₅=5Ω，求【R₅ 中的电流】。

    为什么换成这个问题：
    第 2 章用 Y-Δ、第 3 章用节点法，求的都是"等效电阻"；
    这一次求的是某一条支路的电流 —— 这正是戴维南定理最擅长的题型。

    答案预告：I₅ = 4/31 ≈ 0.1290A。
    后面会用【戴维南定理】和【直接节点法】两条路分别算，必须相等。


========================================================================
  第 1 站（0-4 min）  叠加定理：三个禁令比公式更重要
                                对应教材 4-1
------------------------------------------------------------------------

【定理本身，一句话】

    线性电路中，多个独立源共同作用时在某处产生的响应（电压或电流），
    等于各独立源【单独作用】时在该处产生的响应的【代数和】。

    数学上就是：把一个多源电路拆成 n 个单源电路，分别求解，然后相加。

【三个禁令 —— 这才是考点】

    ① 只能用于【线性】电路
       电路里有非线性元件（二极管、非线性电阻）就不能用。

    ② 不作用的源必须【置零】，不是"拿掉"
       电压源置零 = 用【导线】代替（短路）
       电流源置零 = 用【开路】代替（断开）
       这一步做错，后面全错。判断口诀：源的"特性"是什么就让它变成什么
       —— 电压源电压为 0 就是两端等电位，即导线；
          电流源电流为 0 就是没有电流通过，即断开。

    ③ 【功率不能叠加】
       因为 P = I²R、P = U²/R 都是二次的，线性关系不成立。

    ④ 补充一条（也是考点）：【受控源不能置零】
       受控源不是独立源，它在每个分电路里都要原样保留。

【例题：拆开算一遍】

    U₁ = 12V 串 R₁ = 3Ω，U₂ = 6V 串 R₂ = 6Ω，两者共同接到 R₃ = 2Ω 上。

    U₁ 单独作用（U₂ 短路 → 把 U₂ 换成导线）：
        V_A′ = 12 × (6∥2) / (3 + 6∥2) = 12 × 1.5 / 4.5 = 4V

    U₂ 单独作用（U₁ 短路）：
        V_A″ = 6 × (3∥2) / (6 + 3∥2) = 6 × 1.2 / 7.2 = 1V

    叠加：V_A = 4 + 1 = 5V     （直接用节点法校验：(12/3 + 6/6)/1 = 5 ✓）

    但功率不能叠加：
        真实功率 P = V_A²/R₃ = 25/2 = 12.5W
        两分量的功率之和 = 4²/2 + 1²/2 = 8 + 0.5 = 8.5W  ≠ 12.5W



【什么时候用它】

    · 电路里有多个源、且要求某一处的响应
    · 想单独看"某个源对这个量贡献了多少"（灵敏度分析）
    · 电路对称、拆开以后每一半都很好算

    不适合：源很多（拆成 5 个电路更累）、含非线性元件。


========================================================================
  第 2 站（4-7 min）  替代定理：三句话讲完
                                对应教材 4-2
------------------------------------------------------------------------

    ① 如果已知某条支路的电压 Uk，那么这条支路可以整个换成一个
       电压为 Uk 的【独立电压源】，电路其它部分的电压电流全都不变。

    ② 同理，已知某支路电流 Ik，可换成电流为 Ik 的【独立电流源】。

    ③ 前提：替代之后电路仍然【有唯一解】。

    【为什么要它】
    它常常和叠加定理、戴维南定理配合使用 ——
    把"不好处理的支路"换成一个源，整个电路就变成"纯源 + 电阻"的
    标准形状，后面怎么算都方便。

    【注意】
    替代定理对线性和非线性电路都成立（这是它比叠加定理更广的地方），
    但替代源的方向、大小必须和原来完全一致（包括参考方向）。


========================================================================
  第 3 站（7-15 min）  戴维南定理：本章的发动机
                                对应教材 4-3
------------------------------------------------------------------------

【定理本身】

    任何一个【含源线性单口网络】，对外都可以等效为：
        一个电压源 Uoc（等于端口开路电压）【串联】一个电阻 Req
        （Req = 把内部独立源全部置零后的端口等效电阻）

    换成诺顿定理就是：并联形式 ——
        一个电流源 Isc（等于端口短路电流）【并联】同一个 Req
        （Isc = Uoc / Req）

    两个定理是同一件事的两种写法，做题时任选一个。



【三步走（背下来）】

    第 1 步  求 Uoc：把负载拿掉，算端口上的开路电压
    第 2 步  求 Req：把内部独立源置零，算端口的等效电阻
    第 3 步  画等效电路，接上负载，算你要的量

【必须理解的一句话】

    戴维南等效【只是对外等效】。
    外部看到的 U-I 关系一模一样，但内部的电流分布、各电阻的功率
    完全变了。所以：
        · 求外部负载的电流电压 → 可以用等效电路
        · 求内部某个电阻消耗的功率 → 必须回到原电路

    这一点和 2.3 节"对外等效 ≠ 对内等效"是同一句话，别忘。

【例题：把桥式电路塌缩成两个元件】

    拿掉 R₅，求 B、C 之间的戴维南等效。

    第 1 步 求 Uoc（此时 B、C 之间开路）
        A、D 之间是 10V。上支路 A—R₁—B—R₂—D 是一条串联分压：
            V_B = 10 × R₂/(R₁+R₂) = 10 × 2/3 = 20/3 ≈ 6.667V
        下支路 A—R₃—C—R₄—D 同理：
            V_C = 10 × R₄/(R₃+R₄) = 10 × 4/7 = 40/7 ≈ 5.714V
        所以 Uoc = V_B − V_C = 20/3 − 40/7 = 20/21 ≈ 0.9524V

    第 2 步 求 Req（把 10V 源置零 = A、D 短接）
        从 B 看进去：R₁ 到 A、R₂ 到 D，而 A、D 现在是同一个点，
                    所以 R₁ 与 R₂ 并联。
        从 C 看进去：R₃ 与 R₄ 并联。
        两部分串联：
            Req = (1∥2) + (3∥4) = 2/3 + 12/7 = 50/21 ≈ 2.381Ω



    第 3 步 接上 R₅ = 5Ω
        I₅ = Uoc / (Req + R₅) = (20/21) / (50/21 + 5)
           = (20/21) / (155/21) = 20/155 = 4/31 ≈ 0.1290A

    ★ 用第 3 章的节点法直接算这个电路：
        V_B = 204/31 ≈ 6.5806V，V_C = 184/31 ≈ 5.9355V
        I₅ = (V_B − V_C)/5 = (20/31)/5 = 4/31 ✓ 完全一致
      一条路是"塌缩成两个元件"，一条路是"解 2 元方程组"，
      得到同一个 4/31，说明定理用对了。

【戴维南定理最典型的三种考法】

    ① 只求某一条支路的电流/电压（像上面这样）
    ② 含受控源的电路求等效电路（必须用外加电源法求 Req）
    ③ 最大功率传输（求 Req 再套公式，见第 5 站）

    第 ③ 种几乎每年出选择题，且计算量小，是性价比最高的得分点。


========================================================================
  第 4 站（15-20 min）  求等效电阻 Req 的三种方法
                                对应教材 4-3 后半
------------------------------------------------------------------------

    三种方法选错，答案就错。判断标准只有一个：电路里有没有受控源。

【方法一：置零法（源置零后串并联）】

    适用：纯电阻电路（不含受控源）
    做法：把独立源置零，然后串并联、Y-Δ 一路化简下去。
    例：（上面那个）Req = (1∥2) + (3∥4) = 50/21Ω

【方法二：外加电源法】

    适用：任何情况，含受控源时必须用它
    做法：内部独立源置零（受控源保留），在端口外加一个电压 U，
          求出端口电流 I（或反过来外加电流求电压），则
              Req = U / I
    为什么必须用到它：受控源不能置零，所以没法"纯串并联化简"，
          只能外加电源硬算。

【方法三：开路短路法】

    适用：任何情况
    做法：Req = Uoc / Isc
          Uoc 是端口开路电压，Isc 是端口短路电流。
    优点：两个量都是"实测"式的，不容易绕晕。
    缺点：要算两次；如果短路电流恰为 0（比如对称电桥），就失效。



【用三种方法核对同一个 Req（50/21Ω）】

    置零法：   (1∥2) + (3∥4) = 2/3 + 12/7 = 50/21 ≈ 2.3810Ω
    开路短路法：把 B、C 短接，两节点并成一点 V = 32/5 = 6.4V
               Isc = (10−6.4)/1 − 6.4/2 = 3.6 − 3.2 = 0.4A
               Req = Uoc/Isc = (20/21)/0.4 = (20/21)×(5/2) = 50/21 ✓
    外加电源法：留给你自己练（答案同样是 50/21）

    三种方法收敛到同一个数，是检查 Req 有没有算错的最好办法。


========================================================================
  第 5 站（20-26 min）  诺顿定理 + 最大功率传输
                                对应教材 4-3、4-4
------------------------------------------------------------------------

【诺顿定理】

    同一个含源单口网络，也可以等效为【电流源 Isc 并联 Req】。
        Isc = Uoc / Req          （就是端口的短路电流）
        Req 和戴维南的 Req 是【同一个】电阻

    什么时候用诺顿：负载是并联结构、或者题目直接给的是电流源时更好算。
    戴维南和诺顿之间可以随时互换 —— 这就是第 2 章的"电源等效变换"，
    只不过这里的"内阻"是 Req。

【最大功率传输定理】

    一个含源单口网络接上可变负载 R_L，当
            R_L = Req
    时，负载获得的功率最大，最大值为
            P_max = Uoc² / (4 Req)

    用贯穿实例的数：Uoc = 20/21V、Req = 50/21Ω
        P_max = (20/21)² / (4 × 50/21) = (400/441) × (21/200) = 2/21
              ≈ 0.0952W



【三个必须说清的点（选择题就考这些）】

    ① 最大功率 ≠ 效率最高
       匹配时 R_L = Req，两者各分一半电压，各消耗一半功率，
       所以【效率只有 50%】。要求高效率就不能匹配（比如电力系统）。

    ② 公式里的 Req 是"从负载两端看进去"的等效电阻，不是随便一个电阻。

    ③ 如果 R_L 不可变（固定负载），想让它拿到最大功率，
       就要反过来改【内阻】—— 让 Req = R_L（这叫"模匹配"，考试少见）。

    ④ P_max = Uoc²/(4Req) 只在"负载可调、内阻固定"时直接用。


========================================================================
  第 6 站（26-30 min）  贯穿实例收尾 + 常见错误
------------------------------------------------------------------------

【把整条链路串一遍】

    要求：桥式电路 + 10V 电源，求 I₅

    第 1 步  识别：只有一个负载支路 R₅ 是我们关心的 → 想到戴维南
    第 2 步  拿掉 R₅，求 Uoc：
             上支路分压 V_B = 20/3，下支路分压 V_C = 40/7
             Uoc = 20/3 − 40/7 = 20/21 ≈ 0.9524V
    第 3 步  源置零（A、D 短接），求 Req：
             Req = (R₁∥R₂) + (R₃∥R₄) = 2/3 + 12/7 = 50/21 ≈ 2.381Ω
    第 4 步  接上负载：I₅ = Uoc/(Req + R₅) = 4/31 ≈ 0.1290A
    第 5 步  验算：节点法得 V_B = 204/31、V_C = 184/31，
             I₅ = 4/31 ✓

【本章最容易犯的 8 个错】

  1. 不作用的源"拿掉"而不是"置零"
     电压源要换成导线，电流源要断开。拿掉电压源 = 断路，错。

  2. 用叠加定理算功率
     功率不能叠加。只能先用叠加求电压/电流，再用 P = I²R 算功率。

  3. 把受控源也置零
     受控源不是独立源，不能置零，每个分电路里都要保留。

  4. 求 Req 时忘了把独立源置零
     不置零算出来的是"带源"的等效电阻，数值必然错。

  5. 认为戴维南等效"对内也等效"
     只对外等效。求内部功率必须回原电路。

  6. 开路短路法里 Isc 的方向搞反
     Req 是正数。若算出负数，多半是 Isc 的参考方向和 Uoc 不一致。

  7. 最大功率公式里用了错的 Req
     必须是从负载两端看进去的 Req，不是电路里随便哪个电阻。

  8. 认为"最大功率传输"时效率最高
     效率只有 50%，一半功率消耗在内阻上。

【三种方法怎么选（一张表记完）】

    工具            什么时候用                    方程量级
    --------------------------------------------------------------------
    叠加定理        多个独立源、求某处响应          n 个单源电路
    替代定理        已知某支路电压/电流            配合其它定理
    戴维南/诺顿     只关心某一条支路                1 次开路 + 1 次求 Req
    最大功率        负载可调、问功率最值            建立在戴维南之上
    节点法/网孔法   源多、要全部支路电流            第 3 章那套

  自测：10 题检验这一章
========================================================================

  1. 叠加定理里，不作用的电压源和电流源分别怎么处理？
  2. 为什么功率不能叠加？举一个数字例子。
  3. 受控源在叠加定理的各分电路里怎么处理？
  4. 替代定理的前提条件是什么？
  5. 戴维南等效电路的两个参数分别是什么？怎么求？
  6. 戴维南等效是"对外等效"还是"对内等效"？这对做题有什么影响？
  7. 含受控源的电路，求 Req 为什么不能用置零法？
  8. 诺顿等效的 Isc 和戴维南的 Uoc 是什么关系？
  9. 负载获得最大功率时，效率是多少？
 10. 用贯穿实例的数算出 P_max（Uoc = 20/21V、Req = 50/21Ω）。

------------------------------------------------------------------------
  参考答案
------------------------------------------------------------------------

  1. 电压源置零 = 用导线短路；电流源置零 = 断开（开路）。
  2. 因为 P = I²R 是电流的二次函数，不满足线性关系。
     例：U₁、U₂ 单独作用时 R₃ 上功率是 8W 和 0.5W，同时作用为 12.5W，
     而 8 + 0.5 = 8.5 ≠ 12.5。
  3. 受控源不能置零，在每个分电路里都原样保留。
  4. 替代后的电路必须有唯一解（一般线性电路都满足）。
  5. Uoc（端口开路电压）和 Req（内部独立源置零后的端口等效电阻）。
  6. 只对外等效。求外部负载的电压电流可以用等效电路；
     求内部元件的功率、电流分布必须回到原电路。
  7. 因为受控源不能置零，电路无法化简成纯串并联，只能外加电源法
     （或开路短路法）。
  8. Isc = Uoc / Req，两者对应同一个 Req。
  9. 50%（另一半消耗在 Req 上）。
 10. P_max = Uoc²/(4Req) = (20/21)²/(4×50/21) = 2/21 ≈ 0.0952W。
