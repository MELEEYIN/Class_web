========================================================================
  第 1 站（0-4 min）  "等效"是"对外等效"
                                对应教材 2-1 引言、2-2 电路的等效变换
------------------------------------------------------------------------

【2.1 什么是等效】

如果两个电路（或者电路的一部分）对外部而言，端口上的电压—电流关系完全
相同，就说它们互相等效。

★ 关键词是"对外"：

    等效 = 对外等效 ≠ 对内等效

    内部长什么样、内部电流怎么分配、内部消耗多少功率，
    等效前后可以完全不一样！

【2.2 一句话理解】

    你把一个复杂网络接到电源上，电源"看见"的只有端口上的 U 和 I。
    只要 U 和 I 的关系一致，电源根本不在乎里面是一个电阻还是十个电阻。



【2.3 这条为什么是考点】

    因为"等价交换"是有边界的：你可以用等效电路算【外部】的量，
    但一旦要算【内部某个电阻消耗的功率】，就必须回到原电路。

    典型判断题：
      原电路内部某个电阻消耗 2W，化简以后整体变成一个电阻。

      ✔ 用化简后的电路算"电源输出的总功率"  ——  对
      ✘ 用化简后的电路算"那个内部电阻消耗的功率"  ——  错

★ 记忆：等效电路是"从外面看的一个黑洞"，黑洞里面的账不能拿它算。


========================================================================
  第 2 站（4-10 min）  串联分压、并联分流
                                          对应教材 2-3 电阻的串联和并联
------------------------------------------------------------------------

【2.4 串联】

电阻首尾相接，流过【同一个电流】。

    R_eq = R₁ + R₂ + … + Rₙ

分压公式（串联分压）：

    U₁ = U · R₁ / (R₁ + R₂)

★ 记忆："电阻大的分到的电压多"（成正比，直观好记）。

【2.5 并联】

电阻接在同一对节点之间，承受【同一个电压】。

    1 / R_eq = 1/R₁ + 1/R₂ + … + 1/Rₙ

两个电阻并联的快捷公式（必背）：

    R_eq = R₁ · R₂ / (R₁ + R₂)          记忆口诀："积除以和"

分流公式（并联分流）：

    I₁ = I · R₂ / (R₁ + R₂)

★★★ 这是全书最容易记反的地方 ★★★

    分子上放的是【另一个】电阻 R₂，不是 R₁。

    记忆："电阻小的分到的电流多"。
    R₁ 越小 → I₁ 应该越大 → 分子必须放 R₂（大的那个），这样才对。

    一秒自检法：令 R₁ → 0（相当于把 R₁ 短路）。
    物理上全部电流都走 R₁，所以应该有 I₁ = I。
    代入公式：I · R₂/(0 + R₂) = I ✓
    如果分子写成 R₁，则得到 I₁ → 0，明显错误。

【2.6 两个心算极限】

    · R₁ >> R₂ 时：并联结果 ≈ R₂（小的那个说了算）
    · R₁ = R₂ = R 时：并联结果 = R / 2

【2.7 例题】R₁ = 6Ω 与 R₂ = 3Ω 并联，总电流 I = 3A，求各支路电流



    第 1 步  求并联等效电阻
             R_eq = 6 × 3 / (6 + 3) = 18 / 9 = 2Ω

    第 2 步  求端电压（并联部分两端电压相同）
             U = I · R_eq = 3 × 2 = 6V

    第 3 步  各支路电流
             I₁ = U / R₁ = 6 / 6 = 1A
             I₂ = U / R₂ = 6 / 3 = 2A

    第 4 步  用分流公式验算
             I₁ = I · R₂/(R₁+R₂) = 3 × 3/9 = 1A   ✓
             I₂ = I · R₁/(R₁+R₂) = 3 × 6/9 = 2A   ✓

    ★ 6Ω 只分到 1A，3Ω 分到 2A —— 电阻小的电流大，验证成功。

    ★ 再用 KCL 检查一遍：I₁ + I₂ = 1 + 2 = 3A = I ✓
      两步互检都过，说明算对了。考试时这一步最多花 10 秒，非常值。


========================================================================
  第 3 站（10-16 min）  Y-Δ 变换：一条口诀记住六个公式
                        对应教材 2-4 电阻的 Y 形连接和 Δ 形连接的等效变换
------------------------------------------------------------------------

【2.8 为什么需要它】

串并联能解决大部分电路，但有一类电路死活化简不了，最典型的就是桥式电路：

    上支路 A—R₁—B—R₂—D      下支路 A—R₃—C—R₄—D      中间 B—R₅—C

从 A 到 D：你找不出哪两个电阻是串联的（没有流过同一个电流），
也找不出哪两个是并联的（没有接在同一对节点之间）。串并联公式一个都用不上。

这时候必须把"三个电阻的 Y 形"整块换成"三个电阻的 Δ 形"，或者反过来。
换完之后新的并联关系就冒出来了。

【2.9 两种连接的样子】

    Y 形（又叫星形、T 形）：三个电阻有一个公共节点，向外引出 3 个端子。
    Δ 形（又叫三角形、Π 形）：三个电阻首尾相接成三角形，3 个顶点引出端子。



★ 关键：这是【三端网络】，对外只有 3 个端子。
  只要这 3 个端子两两之间的等效电阻分别相同，两种连接就对外等效。

【2.10 Δ → Y 的公式】

设 Δ 形三个电阻为 R₁₂、R₂₃、R₃₁（下标 = 它接在哪两个端子之间），
变换后 Y 形的三个电阻为 R₁、R₂、R₃（分别接在端子 1、2、3 上）：

    R₁ = R₁₂ · R₃₁ / (R₁₂ + R₂₃ + R₃₁)
    R₂ = R₁₂ · R₂₃ / (R₁₂ + R₂₃ + R₃₁)
    R₃ = R₂₃ · R₃₁ / (R₁₂ + R₂₃ + R₃₁)

★ 记忆："分子 = 夹着该端子的两个电阻之积，分母 = 三个之和"

  自检 R₁：端子 1 夹在边 R₁₂ 和边 R₃₁ 之间 → 分子取 R₁₂ · R₃₁ ✓

【2.11 Y → Δ 的公式】

先算一个中间量 S：

    S = R₁R₂ + R₂R₃ + R₃R₁          （两两乘积之和）

然后：

    R₁₂ = S / R₃
    R₂₃ = S / R₁
    R₃₁ = S / R₂

★ 记忆："分子 = 两两积之和 S，分母 = 对面那条臂的电阻"

  自检 R₁₂：边 1-2 的对面是端子 3，端子 3 上的臂是 R₃ → S / R₃ ✓

★★ 别硬背六个公式，用一句话统一理解 ★★

    Y → Δ：先用"对面的臂"定出"除以谁"，剩下除以 S 的前缀都一样。
    Δ → Y：分母是三个之和（固定），分子是"夹着自己的两个"。

    易混点只有一个：Δ→Y 的分母是【三个之和】，不是 S。
    （S 是两两乘积之和，只在 Y→Δ 里出现，别搞混。）

【2.12 对称时的简化结论（省时间用）】

    三个电阻都相等（都等于 R）时：

        R_Δ = 3 · R_Y            Y 变 Δ，变三倍
        R_Y = R_Δ / 3            Δ 变 Y，变三分之一

    这个结论在对称电路里用得极多，能省下大量计算。

【2.13 例题：桥式电路求等效电阻】

参数：R₁ = 1Ω、R₂ = 2Ω、R₃ = 3Ω、R₄ = 4Ω、R₅ = 5Ω，求 A、D 间等效电阻。

    原电路（＝开头那张图 1，放在这里方便和下面的等效电路对照）：



    第 1 步  找到那个 Y 形。
             节点 B 上汇聚了三个电阻：R₁（指向 A）、R₂（指向 D）、R₅（指向 C）。
             正好是一个 Y 形，把它整块换成 Δ 形（端子是 A、D、C）。

    第 2 步  算中间量 S。
             S = R₁R₂ + R₂R₅ + R₅R₁ = 1×2 + 2×5 + 5×1 = 2 + 10 + 5 = 17

    第 3 步  算 Δ 的三条边（分母 = 对面那条臂）：
             R_AD = S / R₅ = 17 / 5 = 3.4Ω     （边 A-D 对面是端子 C，臂是 R₅）
             R_DC = S / R₁ = 17 / 1 = 17Ω      （边 D-C 对面是端子 A，臂是 R₁）
             R_CA = S / R₂ = 17 / 2 = 8.5Ω     （边 C-A 对面是端子 D，臂是 R₂）

    第 4 步  替换之后，电路变成：
             · A—D 之间直接有一个 3.4Ω
             · A—C 之间：原来的 R₃ = 3Ω 与新来的 8.5Ω 并联
             · C—D 之间：原来的 R₄ = 4Ω 与新来的 17Ω 并联
             （B 点消失了 —— R₁、R₂、R₅ 已经被这三个新电阻整体替掉）



    第 5 步  算两段并联（用"积除以和"）：
             A—C：3 × 8.5 / (3 + 8.5) = 25.5 / 11.5 = 2.2174Ω
             C—D：4 × 17  / (4 + 17)  = 68 / 21    = 3.2381Ω

    第 6 步  这两段是串联的（电流从 A 出发，只能经 C 到 D，一条路）：
             2.2174 + 3.2381 = 5.4555Ω

    第 7 步  再与 A—D 之间那条 3.4Ω 并联：
             R_AD = 3.4 × 5.4555 / (3.4 + 5.4555)
                  = 18.5487 / 8.8555
                  = 2.0946Ω

    答：R_AD ≈ 2.09Ω

    ★ 验算：用节点法（第 3 章才学）独立算这个桥式电路，结果同样是
      2.0946Ω。两条完全不同的路得到同一个数，说明变换没错。

【2.14 平衡电桥：能省掉一大半计算的特殊情况】

如果桥式电路满足

    R₁ / R₂ = R₃ / R₄        （上支路两电阻之比 = 下支路两电阻之比）

那么中间支路 R₅ 中【没有电流】，B 与 C 电位相等，称为"电桥平衡"。

此时 R₅ 可以：直接拿走（视为断路），或者直接短路，两种做法算出的等效电阻
完全相同。于是

    R_AD = (R₁ + R₂) ∥ (R₃ + R₄)         （∥ 表示并联）

例：R₁ = 2Ω、R₂ = 4Ω、R₃ = 3Ω、R₄ = 6Ω
    检验：2/4 = 0.5，3/6 = 0.5，相等 → 平衡
    于是：R_AD = (2+4) ∥ (3+6) = 6 ∥ 9 = 6×9/(6+9) = 54/15 = 3.6Ω

★ 为什么平衡时 R₅ 里没有电流：
  B、C 电位相等 → R₅ 两端电压为 0 → 由欧姆定律，电流为 0。
  而既然流过它的电流恒为 0，把它换成任何阻值都不影响外部，
  所以"断路"和"短路"两种极端做法都对。

★ 做题顺序：看到桥式电路，先花 10 秒检验是否平衡。
  平衡就直接秒杀；不平衡才动 Y-Δ。


========================================================================
  第 4 站（16-21 min）  电源的两种模型与等效互换
                            对应教材 2-5 电压源与电流源的串联和并联
                                      2-6 实际电源的两种模型及其等效变换
------------------------------------------------------------------------

【2.15 先记一条极实用的规则】

    · 与【理想电压源】并联的电阻  →  直接划掉
      因为不管这个电阻怎么变，端口电压都被理想电压源钳死，
      它不改变对外特性（内部会多消耗功率，但不影响外部）。

    · 与【理想电流源】串联的电阻  →  直接换成导线
      同理，该支路电流被理想电流源钳死。

★ 化简题里这两条能一步去掉一个元件，别傻算。

【2.16 实际电源的两种模型】

真实电源（比如电池）有内阻，它有两种等价的画法：

    (1) 电压源模型：理想电压源 Us 串联内阻 Rs
    (2) 电流源模型：理想电流源 Is 并联内阻 Rs



【2.17 互换条件】

    电压源模型 → 电流源模型：   Is = Us / Rs
    电流源模型 → 电压源模型：   Us = Is · Rs
    两种情况下：内阻 Rs 都保持不变

★★★ 方向！方向！方向！ ★★★

    Is 的箭头方向规定为：从 Us 的"−"端 指向 "+"端。
    换句话说：Is 流出电流的那一端，对应 Us 的"+"端。

    这是最常见的失分点，而且写错了电路照样能算下去，只是电流符号全反，
    最后答案差一个负号。

【2.18 例题】

    (1) 12V 电压源串联 4Ω 内阻
        换成电流源模型：Is = 12 / 4 = 3A 的电流源，并联 4Ω

    (2) 2A 电流源并联 6Ω
        换成电压源模型：Us = 2 × 6 = 12V 的电压源，串联 6Ω

【2.19 三条必须记住的限制】

    1. 理想电压源（内阻 = 0）不能等效成电流源
       —— Is = Us / 0 = ∞，无穷大电流源没有物理意义。

    2. 理想电流源（内阻 = ∞）不能等效成电压源
       —— Us = Is × ∞，同理。

    3. 只有"跟着的那个电阻"参与变换：
       · 与电压源【串联】的电阻 → 这才是 Rs，参与变换
       · 与电流源【并联】的电阻 → 这才是 Rs，参与变换
       配置别记反：电压源配串联，电流源配并联。

【2.20 电源串并联速查】

    电压源串联：可直接相加（注意极性）        Us = Us1 + Us2
    电压源并联：只有电压相等且极性一致才允许，并联后电压不变
    电流源并联：可直接相加（注意方向）        Is = Is1 + Is2
    电流源串联：只有电流相等且方向一致才允许

    ★ 另外：与理想电压源并联的元件、与理想电流源串联的元件，都可忽略。


========================================================================
  第 5 站（21-26 min）  输入电阻：外加电源法
                                              对应教材 2-7 输入电阻
------------------------------------------------------------------------

【2.21 什么叫输入电阻】

    从某个端口看进去，端口电压 U 与端口电流 I 的比值：

        R_in = U / I

    不含受控源时，它就是串并联算出来的那个等效电阻。
    含受控源时串并联失效，必须改用"外加电源法"。

【2.22 外加电源法三步】

    第 1 步  在端口外加一个电压源 U（或电流源 I）
             一般选电压源，因为 U 是已知量，代入方便。

    第 2 步  列方程，把端口电流 I 用 U 表示出来（或反过来）

    第 3 步  R_in = U / I

★ 为什么含受控源就不能用串并联：
  受控源的值依赖于电路中某个电流或电压，而那个量又依赖于你外加的电源。
  这是一个"自己依赖自己"的方程组，必须先解方程才能算出比值。

【2.23 例题】

电路：端口外加电压 U，端口电流 I 流入端口。
      端口 经 R₁ = 1Ω 到节点 A；
      节点 A 经 R₂ = 1Ω 到地；
      另有受控电流源 2I，从地流入节点 A。

求：端口的输入电阻 R_in。



    第 1 步  设节点 A 的电位为 Va，端口电位为 U，地电位为 0。

    第 2 步  由端口支路写电流：
             I = (U − Va) / R₁ = (U − Va) / 1 = U − Va         ……（式 1）

    第 3 步  对节点 A 列 KCL（统一以【流出 A 为正】）：
             (Va − U)/1  +  Va/1  −  2I  =  0
             └经 R₁ 流向端口┘ └经 R₂ 流向地┘ └受控源流入 A，流出取负┘

    第 4 步  把（式 1）代入：
             Va − U + Va − 2(U − Va) = 0
             2Va − U − 2U + 2Va = 0
             4Va − 3U = 0
             Va = 0.75U

    第 5 步  求端口电流：
             I = U − Va = U − 0.75U = 0.25U

    第 6 步  求输入电阻：
             R_in = U / I = U / (0.25U) = 4Ω

    答：R_in = 4Ω

【2.24 这个结果说明了什么】

    如果没有那个受控源，从端口往下看就是 R₁ 与 R₂ 串联（R₂ 通到地，
    而地的电位与端口的回流端相同，所以确实是串联）：

        R_in = R₁ + R₂ = 1 + 1 = 2Ω

    受控源把它变成了 4Ω ——【放大】了等效电阻。

    ★ 这不是数学游戏：运算放大器电路正是靠受控源把输入阻抗做大，
      从而"不从信号源吸取电流"。第 5 章会详细讲这个思路。

【2.25 受控源方向的威力（进阶）】

    把受控源的系数和方向改一改，等效电阻可以是 0，甚至是负数。

    设受控源为 c·I（c > 0 表示"从地流入 A"），
    同样列 KCL 可以解出通式：

        R_in = R₂ · (1 + c) + R₁

    代入本例的 R₁ = R₂ = 1Ω：

        c = +2   →   R_in = 1×(1+2) + 1 = 4Ω      （本题）
        c = −2   →   R_in = 1×(1−2) + 1 = 0Ω      （改成 2I 从 A 流出，端口被"短路"）
        c = −3   →   R_in = 1×(1−3) + 1 = −1Ω     （负电阻！）

    ★ 负电阻意味着"电压升高时电流反而减小"，数学上完全合法。
      振荡电路能自己起振，根子就在这里。

    ★ 注意：光把 2I 的方向反过来会得到 0Ω（不是负的）。
      想拿到 −1Ω，系数得取到 −3。这属于容易想当然的地方，务必算一遍。

【2.26 综合演练：电源互换 + 串并联】

    电路：节点 1 与地之间接了三条支路
          ① 12V 电压源串联 4Ω
          ② 2A 电流源并联 6Ω
          ③ 3Ω 电阻
    求：3Ω 电阻上的电流

    第 1 步  把支路①换成电流源模型
             Is = 12 / 4 = 3A
             方向：电流源的输出端接节点 1（与电压源"+"端一致）
             于是变成：3A 电流源并联 4Ω

    第 2 步  现在节点 1 与地之间是三条【并联】支路：
             3A ∥ 4Ω 、 2A ∥ 6Ω 、 3Ω
             两个电流源方向一致 → 相加：      Is = 3 + 2 = 5A
             三个电阻并联 → 1/R = 1/4 + 1/6 + 1/3
                                 = 3/12 + 2/12 + 4/12 = 9/12
                                 所以 R = 12/9 = 4/3 Ω ≈ 1.3333Ω

    第 3 步  求节点电压
             U = Is · R = 5 × 4/3 = 20/3 ≈ 6.6667V

    第 4 步  求 3Ω 上的电流
             I = U / 3 = 20/9 ≈ 2.2222A

    答：约 2.22A

    ★ 验算（直接用节点法列 KCL，不走等效变换）：
        (12 − U)/4 + 2 − U/6 = U/3
        两边乘 12：3(12 − U) + 24 − 2U = 4U
        36 − 3U + 24 − 2U = 4U
        60 = 9U   →   U = 20/3 ✓
      与等效变换得到的完全一致。

    ★ 这道题把第 2 站（并联）、第 4 站（电源互换）全用上了。
      注意第一步的方向：如果 Is 方向搞反，后面会变成 3 − 2 = 1A，
      答案差得很远 —— 这就是第 4 站反复强调方向的原因。


========================================================================
  本章常见错误清单
========================================================================

  1. 分流公式记反（写成 I₁ = I · R₁/(R₁+R₂)）
     → 分子放【另一个】电阻。自检：R₁ → 0 时应得 I₁ = I。

  2. 把"等效"当成"完全一样"
     → 等效仅指对外等效；内部电流分布和内部功率完全不同。

  3. 电源互换时电流源方向搞反
     → Is 从 Us 的"−"端指向"+"端。

  4. 用串并联去算含受控源的电路
     → 受控源的值依赖电路中的未知量，必须先列方程解出来。

  5. Y-Δ 六个公式记混
     → Δ→Y：分母是【三个之和】，分子是"夹着自己的两个之积"。
       Y→Δ：分母是【对面那条臂】，分子是两两积之和 S。

  6. 桥式电路忘了先检查是否平衡，白算半天
     → 先花 10 秒算 R₁/R₂ 是否等于 R₃/R₄，相等就直接秒杀。

  7. 把"与理想电压源并联的电阻"也拿去参与化简
     → 那个电阻不影响对外特性，可以直接划掉。


========================================================================
  速查卡（截图存手机，做题前扫一眼）
========================================================================

【串联】
    R_eq = R₁ + R₂ + … + Rₙ
    U₁ = U · R₁/(R₁+R₂)              电阻大的分压多

【并联】
    R_eq = R₁R₂/(R₁+R₂)              积除以和
    1/R_eq = 1/R₁ + 1/R₂ + …
    I₁ = I · R₂/(R₁+R₂)              ★ 分子是另一个电阻
    R₁ >> R₂ 时 ≈ R₂；两个相等时 = R/2

【Δ → Y】（分母都是三个之和）
    R₁ = R₁₂R₃₁ / (R₁₂+R₂₃+R₃₁)
    R₂ = R₁₂R₂₃ / (R₁₂+R₂₃+R₃₁)
    R₃ = R₂₃R₃₁ / (R₁₂+R₂₃+R₃₁)

【Y → Δ】S = R₁R₂ + R₂R₃ + R₃R₁
    R₁₂ = S/R₃      R₂₃ = S/R₁      R₃₁ = S/R₂

【对称】
    R_Δ = 3·R_Y        R_Y = R_Δ/3

【电源互换】
    Is = Us/Rs          Us = Is·Rs        Rs 不变
    方向：Is 从 Us 的"−"指向"+"

【可忽略的元件】
    与理想电压源并联的电阻  → 划掉
    与理想电流源串联的电阻  → 换成导线

【电桥平衡】
    R₁/R₂ = R₃/R₄  时，中间支路无电流
    R_AD = (R₁+R₂) ∥ (R₃+R₄)

【输入电阻】
    R_in = U/I       外加电源法：加 U → 求 I → 相除
    含受控源通式（本页例题）：R_in = R₂(1+c) + R₁


========================================================================
  自测题（答案在下面，先自己做）
========================================================================

  1. R₁ = 4Ω 与 R₂ = 12Ω 串联接在 16V 电压上，求各电阻的电压。

  2. R₁ = 4Ω 与 R₂ = 12Ω 并联，总电流 4A，求各支路电流。

  3. 对称 Y 形连接的三个电阻各为 9Ω，等效的 Δ 形每个电阻是多少？

  4. 一个 10V 电压源串联 5Ω，等效成电流源模型，参数是多少？

  5. 桥式电路 R₁ = R₂ = R₃ = R₄ = 10Ω、中间 R₅ = 20Ω，求 R_AD。
     （提示：先判断是否平衡）

  6. 第 5 站的例题里，如果把受控源改成"3I 从 A 流出"，R_in 是多少？

------------------------------------------------------------------------
  答案与解析
------------------------------------------------------------------------

  1. R_总 = 16Ω，I = 16/16 = 1A，U₁ = 1×4 = 4V，U₂ = 1×12 = 12V
     检验：4 + 12 = 16V ✓（KVL）

  2. R_eq = 4×12/16 = 3Ω，U = 4×3 = 12V
     I₁ = 12/4 = 3A，I₂ = 12/12 = 1A
     检验：3 + 1 = 4A ✓；电阻小的 4Ω 分到 3A，符合"电阻小电流大"

  3. R_Δ = 3 · R_Y = 3 × 9 = 27Ω

  4. Is = Us/Rs = 10/5 = 2A，并联 5Ω
     方向：从 10V 电压源的"−"端指向"+"端

  5. 先判断平衡：10/10 = 1，10/10 = 1，相等 → 平衡
     所以 R₅ 中无电流，可以直接拿走：
     R_AD = (10+10) ∥ (10+10) = 20 ∥ 20 = 10Ω
     ★ 注意不要"看到 20Ω 就往上加"，平衡时它是断路。

  6. c = −3，代入通式 R_in = R₂(1+c) + R₁ = 1×(1−3) + 1 = −1Ω
     ★ 负电阻是合法结果，说明该端口对外表现为"负阻"。

  下一章预告：第 3 章 电阻电路的一般分析

第 2 章靠"眼力和技巧"化简电路，但你也感觉到了：桥式电路要是不平衡，
就得做 Y-Δ，而 Y-Δ 只有三端网络能用，四端、五端呢？

第 3 章给的是【万能方法】—— 不再需要眼力，直接列方程：

    · 支路电流法：最原始，方程多
    · 网孔电流法：对平面电路，方程数 = 网孔数
    · 节点电压法：方程数 = 独立节点数（最常用）

学完第 3 章你会发现：本页那个桥式电路，用节点法两步就出答案
（所以我在第 3 站提了一句"用节点法独立验算也是 2.0946Ω"）。

本章的化简功夫也不是白学 —— 第 4 章的戴维南定理、最大功率传输，
全都建立在"等效"这个概念之上。
