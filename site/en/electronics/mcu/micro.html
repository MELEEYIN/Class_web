1 第 1 章 · 数制、编码与运算基础

1.1 这一章要解决什么

计算机只认 0 和 1。这一章就是把「现实世界的东西」和「01 串」之间的翻译规则讲透 —— 后面所有章节都建立在这上面。
要翻译的东西变成规则名
正数 1000110 0100二进制 / 位权
负数 −51111 1011补码
十进制数（参与运算）25H、48HBCD 码
字母 'A'0100 0001 = 41HASCII
汉字「啊」B0A1HGB2312 机内码

1.2 位权：二进制怎么读

和十进制唯一的不同是「满几进一」。十进制满 10 进 1，二进制满 2 进 1，于是位权变成 2 的幂：

位号b7b6b5b4b3b2b1b0
位权1286432168421
0110 0100  =  0×128 + 1×64 + 1×32 + 0×16 + 0×8 + 1×4 + 0×2 + 0×1
           =  64 + 32 + 4
           =  100
速算技巧：只有写 1 的那几位才「出钱」，把它们的位权加起来就行，不用真的做乘法。

1.3 十六进制：程序员的速记法

16 位二进制写起来太长，用十六进制一位顶 4 位：

二进制十六进制二进制十六进制
0000010008
0001110019
001021010A
001131011B
010041100C
010151101D
011061110E
011171111F
写法约定（考试会扣分）
十六进制末尾加 H；若首位是字母，前面补 0：0FFH 不能写 FFH
二进制末尾加 B：1010B

1.4 负数：为什么用补码

以 8 位为例，−7 的三种表示：
  原码  1 0000111   ← 最高位当符号位，其余是绝对值
  反码  1 1111000   ← 负数：符号位不变，其余取反
  补码  1 1111001   ← 负数：反码 + 1

★ 正数的原码 = 反码 = 补码，三码合一

为什么计算机只用补码

原因说明
减法能当加法算硬件只需一个加法器：7 − 5 = 7 + (−5)
没有 +0 和 −0原码有 00000000 和 10000000 两个零，浪费一个编码
表示范围最大8 位补码能表示 −128 ~ +127
模运算解释：8 位计数器数到 255 再加 1 就回到 0，「256」这个数被丢掉了。
所以 −5 和 +251 在 8 位里是同一个编码：251 = 256 − 5 ✓
这就是「补码」名字的由来 —— 补到模数上去了。

1.5 溢出怎么判断

两个 8 位数相加，结果超出 −128~+127 就是溢出（OF=1）

  +100 + +50 = +150  ✗ 超出 +127 → 溢出
  −100 + −50 = −150  ✗ 低于 −128 → 溢出
  +100 + −50 =  +50  ✓ 一正一负永远不会溢出
现象结论
正 + 正 = 负溢出
负 + 负 = 正溢出
符号不同相加永不溢出
OF（溢出）和 CF（进位）是两回事
CF 看的是「无符号数」有没有超过 255；OF 看的是「有符号数」有没有超出范围。
0FFH + 01H：CF=1（无符号超了），OF=0（有符号没超）。

1.6 BCD 码与 DAA

用 4 位二进制表示一位十进制数，叫 BCD 码。但硬件按 16 进制加，所以算完要调整：

   25H         0010 0101   ← BCD 的 25
 + 37H         0011 0111   ← BCD 的 37
 --------     ---------
 = 5CH         0101 1100   ✗ 这不是合法 BCD（C 不是十进制数字）
   06H         加 6 调整
 --------
 = 62H         0110 0010   ✓ 正确的 62

★ 这就是 DAA（十进制调整）指令存在的理由

1.7 ASCII 与汉字编码

字符ASCII（十六进制）
'0' ~ '9'30H ~ 39H
'A' ~ 'Z'41H ~ 5AH
'a' ~ 'z'61H ~ 7AH
★ 差值规律（做题常用）
  'A' 和 'a' 差 20H → 大写转小写：+20H
  '0' 到 '9' 连续，差 30H 就是数字本身：'5' − '0' = 5

汉字怎么进计算机

区位码   → 国标码    ：+ 2020H
国标码   → 机内码    ：+ 8080H（两个字节最高位都置 1）

★ 为什么加 8080H：让两字节都 ≥ 80H，和 ASCII（00~7FH）彻底分开，
  计算机一看最高位是 1 就知道「这是汉字」，不会误当两个字母

1.8 本章易错点

① 补码求值忘记「取反加一」是两步 —— 先全位取反，再 +1。
② 把 OF 和 CF 混为一谈。
③ 十六进制首位字母前忘补 0。
④ BCD 加法后忘了 DAA。

1.9 小结

概念一句话
位权2 的幂，从 b0 的 1 开始往左翻倍
补码负数 = 反码 + 1，让减法变加法
表示范围8 位补码：−128 ~ +127
OF vs CFOF 管有符号，CF 管无符号
BCD + DAA4 位表示一位十进制，算完要调整

2 第 2 章 · 8086 结构与寄存器

2.1 8086 的规格

项目参数意味着什么
数据总线16 位一次能搬 2 个字节
地址总线20 位能寻址 2²⁰ = 1MB
内部寄存器16 位只能直接表示 64KB 的范围
主频5 / 8 / 10 MHz—
封装40 脚 DIP—
矛盾点：地址总线 20 位能到 1MB，但寄存器只有 16 位只能表示 64KB。
这个矛盾就是第 3 章「分段」要解决的核心问题。

2.2 内部结构：BIU 和 EU 两个部门

部门全称负责包含
BIU总线接口单元取指令、读写内存段寄存器、IP、指令队列、地址加法器
EU执行单元译码、执行、算数ALU、通用寄存器、FLAGS
为什么要分两个：取指令和执行指令可以同时进行。
BIU 提前把后面几条指令取到 6 字节的「指令队列」里，EU 直接从这里拿 —— 不用每次等内存。
这就是 8086 比 8080 快得多的原因。

2.3 14 个寄存器

类别寄存器用途
通用AX累加器，乘除法专用，I/O 专用
BX基址寄存器，可做内存寻址
CX计数寄存器，循环和串操作专用
DX数据寄存器，乘除法高位、I/O 端口地址
指针变址SP堆栈指针，配合 SS
BP基址指针，配合 SS
SI源变址，配合 DS
DI目的变址，配合 ES
段CS代码段
DS数据段
SS堆栈段
ES附加段
控制IP
FLAGS		指令指针
标志位
★ 记忆口诀
  通用四个：A B C D  （累加、基址、计数、数据）
  指针四个：S B S D  （SP BP SI DI）
  段寄存器：C D S E  （代码、数据、堆栈、附加）

2.4 16 位寄存器可以拆成两个 8 位用

    AX (16 位)  =  AH (高 8 位) + AL (低 8 位)

  例：AX = 1234H
      AH = 12H
      AL = 34H

★ 四个通用寄存器都有这个特性：AX/BX/CX/DX → AH/AL、BH/BL、CH/CL、DH/DL
★ SP/BP/SI/DI 只能整体使用，不能拆
注意：修改 AH 不会影响 AL，改 AL 也不会影响 AH，它们是同一寄存器的两半。

2.5 FLAGS：9 个标志位

位标志名称什么时候为 1
0CF进位无符号运算有进位/借位
2PF奇偶结果低 8 位中 1 的个数为偶数
4AF辅助进位bit3 向 bit4 有进位（BCD 用）
6ZF零结果为 0
7SF符号结果最高位为 1（负数）
8TF陷阱单步调试用
9IF中断允许允许可屏蔽中断
10DF方向串操作时地址递减
11OF溢出有符号运算超出范围
★ 常用对照表（做题记这个）
  CF = 0001H      ZF = 0040H
  PF = 0004H      SF = 0080H
  AF = 0010H      OF = 0800H

2.6 本章易错点

① 把 IP 当成通用寄存器 —— 它不能直接用 MOV 修改。
② 忘记 SP/BP/SI/DI 不能拆成 8 位。
③ 段寄存器不能直接用立即数赋值，必须经通用寄存器中转。
④ FLAGS 的位号记混（CF 在 bit0，OF 在 bit11）。

  2. BIU 和 EU 各负责什么？分开有什么好处？
  3. AX = 5678H 时 AH 和 AL 各是多少？
  4. FLAGS 中 CF 和 OF 的区别？
  5. 四个段寄存器分别配合哪个指针寄存器使用？
📖 参考答案

  2. BIU 取指令/读写内存，EU 译码执行；分开可取指执行并行

3 第 3 章 · 存储器组织与分段

3.1 存储器就是一排抽屉

概念说明
存储单元一个字节（8 位），每个有唯一地址
地址从 00000H 开始编号
字（word）2 个字节，低地址存低字节（小端）
★ 小端规则：一个 16 位数 1234H 存在 2000H 处
   2000H: 34H   ← 低字节在低地址
   2001H: 12H   ← 高字节在高地址

读的时候要反过来拼：1234H

3.2 分段：16 位怎么凑出 20 位

物理地址 = 段基址 × 16 + 偏移量
         = 段基址 << 4 + 偏移量

例：CS = 2000H，IP = 0100H
    物理地址 = 2000H × 16 + 0100H
             = 20000H + 0100H
             = 20100H
为什么要 ×16：段基址左移 4 位后，最低 4 位自动是 0。
这样一个 16 位的段基址就能覆盖到 1MB 的任意一个 16 字节边界上 —— 20 位地址 = 16 位段 + 4 位（隐含的 0）+ 16 位偏移的低 4 位。

3.3 四个段寄存器各自的搭档

段寄存器配合取什么物理地址
CSIP指令CS×16 + IP
DSBX / SI / DI / 直接地址数据DS×16 + 偏移
SSSP / BP堆栈数据SS×16 + SP
ESDI串操作目标ES×16 + DI
最容易错的一条：[BX] 默认用 DS，但 [BP] 默认用 SS！这是考题常客。

3.4 段可以重叠

同一个物理地址 20100H，有无数种写法：

  CS=2000H  IP=0100H     → 20000H + 0100H = 20100H
  CS=2010H  IP=0000H     → 20100H + 0000H = 20100H
  CS=1FFFH  IP=0110H     → 1FFF0H + 0110H = 20100H

★ 所以「段」不是物理上切开的空间，只是一种寻址方式

3.5 1MB 空间的分布

地址范围用途
00000H ~ 003FFH中断向量表（1KB，256 个向量）
00400H ~ 9FFFFH用户可用区（内存条）
A0000H ~ BFFFFH显存（显卡）
C0000H ~ FFFFFHROM / BIOS
0 号中断为什么能直接调用：INT 21H 会去 21H × 4 = 0084H 处取服务程序地址。
而 BIOS 在开机时已经把各个服务程序的地址填进了这张表。

3.6 堆栈：倒着长的抽屉

8086 的堆栈是【向下生长】的 —— 这和 51 相反！

  PUSH AX：SP = SP − 2，然后把 AX 存入 SP 指向处
  POP  AX：从 SP 指向处取出给 AX，然后 SP = SP + 2

初始：SP = 0100H
PUSH AX 后：SP = 00FEH
再 PUSH BX 后：SP = 00FCH
POP  BX 后：SP = 00FEH
PUSH 和 POP 必须成对，且顺序相反（后进先出）。
PUSH AX / PUSH BX / POP BX / POP AX ✓

3.7 本章易错点

① 物理地址算错 —— 忘记段基址要 ×16（或左移 4 位）。
② 以为段是物理切分 —— 段可以重叠。
③ 搞反小端顺序 —— 低字节在低地址。
④ 以为堆栈向上长 —— 8086 是向下长的。
⑤ 忘记 [BP] 默认用 SS。

3.8 练习

  1. CS = 1000H、IP = 2345H，物理地址是多少？
  2. 物理地址 12345H，段基址 1200H 时偏移量是多少？
  3. 为什么段基址要左移 4 位？
  4. PUSH AX 执行时 SP 怎么变？POP 呢？
  5. 16 位数 1234H 存在 2000H，2000H 和 2001H 各是什么？
📖 参考答案
  1. 1000H×16 + 2345H = 12345H
  2. 12345H − 12000H = 345H
  3. 为了能用 16 位段基址覆盖 20 位地址空间（左移 4 位后低 4 位为 0）
  4. PUSH：SP−2 再存；POP：先取再 SP+2
  5. 2000H = 34H，2001H = 12H（小端）

4 第 4 章 · 寻址方式

4.1 操作数只可能在三个地方

位置写法例速度
指令内部立即数MOV AX, 1234H最快
寄存器寄存器名MOV AX, BX快
存储器[ ] 括起来MOV AX, [BX]慢

4.2 七种寻址方式

方式写法EA 怎么算特点
立即寻址MOV AX,1234H无 EA数据就在指令里
寄存器寻址MOV AX,BX无 EA最快
直接寻址MOV AX,[2000H]EA = 2000H地址写在指令里
寄存器间接MOV AX,[BX]EA = BX只能 BX/BP/SI/DI
寄存器相对MOV AX,[BX+8]EA = BX+8数组用
基址变址MOV AX,[BX+SI]EA = BX+SI二维数组
相对基址变址MOV AX,[BX+SI+8]EA = BX+SI+8最灵活

4.3 方括号里能放什么

合法组合 = 一个基址 + 一个变址 + 一个常数

  基址：BX 或 BP
  变址：SI 或 DI
  常数：0~65535

✓ [BX]        ✓ [BX+SI]      ✓ [BP+DI+6]
✓ [SI+4]      ✓ [BX+DI+100H]
✗ [AX]        ✗ [BX+CX]      ✗ [SI+DI]   ← 两个变址不行
✗ [BX+BP]                                  ← 两个基址不行

4.4 默认段：不同寄存器不同段

寻址用的寄存器默认段能不能改
BX、SI、DI、直接地址DS可以，加段超越前缀
BP、SPSS可以
串操作 DIES不能改
; 段超越前缀的写法
MOV AX, ES:[BX]     ; 强制用 ES 而不是 DS

4.5 EA 和物理地址

EA（有效地址）= 偏移量，只是公式里的一部分
物理地址 = 段基址 × 16 + EA

例：DS = 2000H，指令 MOV AX,[BX+10H]，BX = 0050H
    EA = 0050H + 10H = 0060H
    物理地址 = 2000H×16 + 0060H = 20060H

4.6 ModR/M 字节：寻址方式编码

字段位含义
Mod7-6操作数是寄存器还是内存，以及偏移长度
Reg5-3寄存器编号
R/M2-0另一个操作数（寄存器号或内存寻址方式）
Mod = 00：内存寻址，无偏移（除 R/M=110 时是直接寻址）
Mod = 01：内存寻址，8 位偏移
Mod = 10：内存寻址，16 位偏移
Mod = 11：两个都是寄存器

4.7 本章易错点

① 写成 [BX+CX] 或 [SI+DI] —— 非法组合。
② 把 EA 当成物理地址 —— 还要加段基址。
③ 忘记 [BP] 默认用 SS。
④ 段超越前缀位置写错 —— 应在冒号前。

  5. Mod 字段的作用是什么？
📖 参考答案
  1. 3000H×16 + 2000H = 32000H
  2. 都合法。BX 是基址，SI/DI 是变址，各取一个
  3. SS 段
  4. EA = 0100H+0020H+8 = 0128H；物理地址 = 20000H+0128H = 20128H

5 第 5 章 · 数据传送与算术运算

5.1 指令分五类

类别代表指令作用
数据传送MOV、PUSH、POP、XCHG搬数据
算术运算ADD、SUB、CMP、MUL、DIV算数
逻辑运算AND、OR、XOR、NOT、SHL位运算
串操作MOVS、LODS、STOS整串搬
控制转移JMP、JZ、CALL、RET跳转

5.2 MOV 的三条铁律

① 两个操作数不能都是存储器：MOV [BX],[SI] ✗（必须经寄存器中转）
② 两个操作数必须等长：MOV AX,BL ✗
③ 类型必须明确：MOV [BX],1 ✗（不知道是字节还是字，要写 MOV BYTE PTR [BX],1） 
; 正确的各种搬法
MOV AX, BX          ; 寄存器 ← 寄存器
MOV AX, 1234H       ; 寄存器 ← 立即数
MOV AX, [2000H]     ; 寄存器 ← 存储器（直接寻址）
MOV [2000H], AX     ; 存储器 ← 寄存器
MOV [BX], AL        ; 存储器 ← 寄存器（间接）

; 存储器 ← 立即数，必须指明长度
MOV BYTE PTR [BX], 12H
MOV WORD PTR [BX], 1234H

5.3 ADD / SUB 与标志位

指令作用影响标志
ADD加法CF ZF SF OF AF PF
ADC带进位加（多字节用）同上
SUB减法同上
SBB带借位减同上
INC / DEC加 1 / 减 1不影响 CF
; 多字节加法：低字节用 ADD，高字节用 ADC
MOV AX, 1234H
MOV BX, 0FFFFH
ADD AX, BX          ; 低 16 位相加，产生进位
ADC DX, ...         ; 高位要带进位

5.4 CMP：只减不存

CMP AX, BX     ; 做减法，但结果不存回 AX，只更新标志位

★ 判断大小靠组合：
  CMP A,B 后：
    A = B  → ZF = 1
    A > B  → CF = 0 且 ZF = 0（无符号）
    A < B  → CF = 1（无符号）

有符号数要用 SF 和 OF 组合判断，不能只看 CF

5.5 乘除法：结果放哪

指令操作数结果
MUL BLAL × BLAX（8位×8位→16位）
MUL BXAX × BXDX:AX（16×16→32位）
DIV BLAX ÷ BLAL = 商，AH = 余数
DIV BXDX:AX ÷ BXAX = 商，DX = 余数
最容易记混的地方：除数只有一个操作数，另一个是隐含的累加器。
8 位除法：被除数永远在 AX，商在 AL，余数在 AH。

5.6 CBW 和 CWD：运算前的准备

CBW：把 AL 的符号位扩展到 AH（8 位 → 16 位）
     AL = 80H (−128) → AX = FF80H
     AL = 7FH (+127) → AX = 007FH

CWD：把 AX 的符号位扩展到 DX（16 位 → 32 位）
     AX = 8000H → DX = FFFFH

★ 有符号除法前必须 CWD，否则 DX 是垃圾值导致溢出

5.7 例题：两个多字节数相加

; 求 32 位 + 32 位，结果存 DX:AX
; 设数 1 在 BX:AX，数 2 在 [SI+2]:[SI]
ADD AX, [SI]        ; 低 16 位相加
ADC BX, [SI+2]      ; 高 16 位带进位
MOV DX, BX          ; 结果高位移到 DX

5.8 易错点与练习

① 存储器到存储器直接 MOV。② 长度不匹配。③ 忘了 BYTE/WORD PTR。④ CMP 后以为 AX 变了。⑤ 有符号除法前忘 CWD。
  1. MOV [BX],[SI] 为什么非法？怎么改？
  2. INC AX 会影响 CF 吗？为什么这样设计？
  3. DIV BL 时商和余数分别在哪？
  4. CMP AX,BX 后 CF=1 说明什么？
  5. AL = 0F0H 时执行 CBW 后 AX = ？
📖 参考答案
  1. 非法，两个操作数不能都是存储器。需经寄存器中转
  2. 不影响。设计上为了让循环计数不干扰进位判断
  3. 商在 AL，余数在 AH
  4. 说明 AX < BX（无符号比较）
  5. AL=0F0H 最高位为 1 → AX = FFF0H

6 第 6 章 · 逻辑移位与汇编程序设计

6.1 逻辑运算：逐位独立

指令作用典型用途
AND与清零某些位（掩码）
OR或置位某些位
XOR异或取反某些位、清零自己
NOT取反全部取反
TEST与但不存结果只测某位
AND AL, 0FH      ; 只保留低 4 位，高 4 位清 0
OR  AL, 80H      ; 最高位置 1
XOR AL, 0FFH     ; 全部取反（等于 NOT）
XOR AX, AX       ; 清零 AX（比 MOV AX,0 快）
TEST AL, 01H     ; 测最低位，看 ZF

6.2 八种移位

指令移入的是什么移出的去哪
SHL补 0→ CF
SHR补 0→ CF
SAR补符号位→ CF
ROL循环，最高位回最低位→ CF（同时）
ROR循环，最低位回最高位→ CF（同时）
RCL经 CF 循环左移→ CF
RCR经 CF 循环右移→ CF
★ 左移 n 位 = 乘 2^n；右移 n 位 = 除 2^n（对无符号数）
★ SHL 和 RCL 的区别：SHL 移出的位进 CF 就丢了；RCL 会把 CF 带回来

6.3 串操作：一条指令搬一串

MOVS：搬（DS:SI → ES:DI）
LODS：从 DS:SI 取到 AL/AX
STOS：把 AL/AX 存到 ES:DI
CMPS：比较 DS:SI 和 ES:DI
SCAS：扫描比较 AL 和 ES:DI

配套三件套：
  SI / DI 自动增减（由 DF 决定方向）
  CX 控制次数，配合 REP
  DF = 0 递增，DF = 1 递减

; 例：复制 100 个字节
CLD                     ; DF=0，地址递增
MOV CX, 100
MOV SI, OFFSET SRC
MOV DI, OFFSET DST
REP MOVSB               ; 重复搬 CX 次

6.4 CALL 和 RET：靠堆栈记住来路

CALL 地址：
  ① SP = SP − 2
  ② 把【下一条指令】的地址压栈
  ③ 跳到目标地址

RET：
  ① 从栈顶弹出地址 → IP
  ② SP = SP + 2
  ③ 回到调用处的下一条

★ 所以子程序可以不写「返回哪」——硬件靠堆栈自动记住
堆栈不平衡是跑飞的头号原因：子程序里 PUSH 了没 POP，RET 就会弹出错误地址。

6.5 一个完整的汇编程序

DATA    SEGMENT
        BUF  DB  10 DUP(0)      ; 定义 10 字节缓冲区
        MSG  DB  'Hello', '$'
DATA    ENDS

CODE    SEGMENT
        ASSUME CS:CODE, DS:DATA
START:  MOV AX, DATA           ; 初始化 DS（不能直接 MOV DS,DATA）
        MOV DS, AX

        MOV CX, 10             ; 循环 10 次
        MOV SI, OFFSET BUF
        MOV AL, 0
LOOP1:  MOV [SI], AL           ; 存一个字节
        INC SI
        INC AL
        LOOP LOOP1             ; CX 减 1，非 0 就跳

        MOV AH, 4CH            ; 返回 DOS
        INT 21H
CODE    ENDS
        END START

结构说明

部分作用
SEGMENT / ENDS定义段的开始和结束
ASSUME告诉汇编器哪个段配哪个段寄存器
DB / DW定义字节 / 字数据
OFFSET取标号的偏移地址
END START结束，并指定程序入口

6.6 易错点与练习

① 串操作前忘 CLD 设方向。② REP 必须配 CX。③ 子程序 PUSH 没 POP。④ DS 不能直接赋立即数。⑤ LOOP 用的是 CX，不是别的寄存器。
  1. AND AL,0FH 的作用是什么？
  2. SHL 和 RCL 的区别？
  3. 用一条指令把 AX 清零。
  4. REP MOVSB 需要事先准备哪些寄存器？
  5. CALL 执行时堆栈怎么变？
📖 参考答案
  1. 只保留低 4 位，高 4 位清 0
  2. SHL 移入 0；RCL 经 CF 循环，把 CF 带回来
  3. XOR AX,AX 或 SUB AX,AX
  4. CLD 设方向、CX 设次数、SI 设源、DI 设目标
  5. SP−2，把下一条指令地址压栈

7 第 7 章 · 存储器系统与地址译码

7.1 存储芯片的四类引脚

类别信号作用
地址线A0~An选单元（n+1 根 → 2^(n+1) 个单元）
数据线D0~D7传数据（8 根 = 一次 1 字节）

电源VCC、GND—
★ 容量 = 2^(地址线条数) × 数据线条数

  例：6264 = 13 根地址线 × 8 根数据线
      = 2^13 × 8 bit = 8192 × 8 = 8KB

7.2 位扩展与字扩展

方式做什么怎么接
位扩展增加数据位宽地址线并联，数据线分开，片选同时有效
字扩展增加存储单元数数据线并联，用译码器分配片选
字位同时扩展两个方向都要组合上面两种

7.3 例题：32K×8 系统

用 6264（8K×8）芯片组成 32K×8：
  需要 32K / 8K = 4 片
  地址线：A0~A12 接所有芯片（片内 8K）
  A13、A14 接 74LS138 译码器产生 4 个片选

片选分配：
  000 → 第 0 片（0000H~1FFFH）
  001 → 第 1 片（2000H~3FFFH）
  010 → 第 2 片（4000H~5FFFH）
  011 → 第 3 片（6000H~7FFFH）

7.4 三种地址译码方式

方式特点地址空间优缺点
线选法高位地址线直接做片选不连续，有重叠简单但浪费
部分译码只用部分高位线译码有地址重叠省器件，但地址不唯一
全译码所有高位线都参与译码连续且唯一标准做法

7.5 8086 的双体结构

8086 有 16 根数据线，但存储器按字节组织，所以分成两个体：

  偶体（BHE=0, A0=0）：存低字节 D0~D7
  奇体（BHE=1, A0=1）：存高字节 D8~D15

读写规则：
  A0  BHE   操作
   0   0    读/写 16 位（一次两个字节）
   0   1    只读/写低字节
   1   0    只读/写高字节
   1   1    不操作

★ 这就是为什么 8086 访问 16 位数据只要一个总线周期

7.6 易错点与练习

① 容量算错 —— 2^地址线 × 数据线。② 位扩展和字扩展搞反。③ 双体中 A0 和 BHE 的作用记混。④ 忘了 6264 是 13 根地址线。

  2. 用 8K×8 芯片组 32K×8 需要几片？
  3. 位扩展和字扩展分别怎么接？
  4. A0=0、BHE=1 时 8086 读什么？
  5. 全译码比线选法好在哪？
📖 参考答案
  1. 13 根地址线，8K×8 = 8KB
  2. 32K/8K = 4 片
  3. 位扩展：地址线并联、数据线分开；字扩展：数据线并联、用译码器分片选
  4. A0=0 只读写低字节；BHE=1 表示不动高字节体
  5. 全译码地址连续且唯一，没有重叠

8.4 硬件中断的完整过程

① 外设拉高 INTR
② CPU 执行完当前指令，检查 IF=1 就响应
③ CPU 发中断响应信号 INTA
④ 外设把中断类型号送上数据线（0~255）

⑥ 查中断向量表：类型号 × 4 → 取出 CS:IP
⑦ 跳到服务程序执行
⑧ 遇到 IRET：弹回 IP、CS、FLAGS

★ 5 个字节的「现场」要压栈，所以中断比 CALL 慢但更安全

D4    = PA 方向：1=输入 0=输出
D3    = PC 高 4 位方向
D2 D0 = B 组方式：0=方式0  1=方式1
D1    = PB 方向
D0    = PC 低 4 位方向

; 例：PA 输出、PB 输入、方式 0
MOV AL, 10000010B    ; = 82H
OUT 0283H, AL

10.5 同一个地址，两种控制字

D7控制字作用
1方式选择控制字设定各端口方向和工作方式
0PC 口按位置位/复位单独控制 PC 口某一位
; 把 PC3 置 1（D7=0，D3~D1=位号，D0=置/复位）
MOV AL, 00000111B    ; 位号 3，D0=1 置位
OUT 0283H, AL

★ 记住：看 D7 就能分辨是哪种控制字

10.6 易错点与练习

① 忘记 D7 是标志位。② A1A0 端口分配搞错。③ 方式 0 下 PC 口可以随便用，方式 1/2 下 PC 口被占用做联络信号。
  1. 8255A 有几个端口？占几个地址？
  2. D7 是什么作用？怎么靠它区分两种控制字？
  3. 要让 PA 输出、PB 输入、方式 0，控制字写什么？
  4. 把 PC5 清 0 的控制字是什么？
  5. PC 口有什么特别之处？
📖 参考答案
  1. 3 个 8 位端口（PA/PB/PC）+ 1 个控制口，占 4 个地址
  2. D7 是标志位：D7=1 方式选择控制字，D7=0 为 PC 口按位置位/复位
  3. PA 输出、PB 输入、方式 0 → 10000010B = 82H
  4. D7=0，位号 5，D0=0 → 00001010B = 0AH
  5. PC 口可拆成两个 4 位，做联络/握手信号

11 第 11 章 · 8253 定时器与 8251A 串口

11.1 8253：三个独立计数器

计数器地址（A1A0）特点
计数器 000常用于定时
计数器 101常用于定时
计数器 210常用于发声（接扬声器）
控制口11写控制字，只写不读
★ 每个计数器都是 16 位减法计数器
  写初值 → 每来一个时钟减 1 → 减到 0 输出信号

11.2 控制字：一个字节定四件事

D7 D6 = 选哪个计数器（00=0, 01=1, 10=2）
D5 D4 = 读写方式（11 = 先低后高，最常用）
D3 D2 D1 = 工作方式（000=方式0 … 101=方式5）
D0    = 计数码（0=二进制，1=BCD）

; 例：计数器 0、先低后高、方式 2、二进制
MOV AL, 00110100B    ; = 34H
OUT 43H, AL

11.3 算初值、写初值

初值 = 输入频率 ÷ 输出频率

; 例：2MHz 时钟，要 1kHz 方波
初值 = 2000000 / 1000 = 2000

; 写入（先低后高）
MOV AL, 34H          ; 控制字
OUT 43H, AL
MOV AL, 2000 MOD 256 ; 低字节
OUT 40H, AL
MOV AL, 2000 / 256   ; 高字节
OUT 40H, AL

★ 初值 0 表示 65536，不是 0！
两个必错点：① 初值写 0 意味着 65536 次。② 必须按控制字约定的顺序写（先低后高就别写反）。

11.4 六种工作方式的波形

方式名称输出特点
0计数结束产生中断计到 0 输出变高，一直保持
1可编程单稳触发后输出一个负脉冲
2频率发生器周期性方波，自动重装
3方波发生器周期方波，占空比 50%
4软件触发选通写入初值后输出一个负脉冲
5硬件触发选通外部触发后输出一个负脉冲
★ 最常用：方式 2 和方式 3（都是周期输出，但占空比不同）
  方式 2：输出高电平 (n−1) 个时钟，低 1 个
  方式 3：高 n/2、低 n/2

11.5 8251A：串行帧

一帧 10 位（8N1 最常见）：
  起始位(1) + 数据位(8) + 校验位(0) + 停止位(1)

传输速率 = 波特率 × 每帧位数
例：9600 波特、8N1 → 每秒传 9600 位 ≈ 960 个字节

★ 波特率由外部时钟分频得到：8251A 的 CLK 通常是波特率的 16 或 64 倍

11.6 易错点与练习

① 初值 0 当 65536。② 写初值顺序与控制字不符。③ 8253 控制口只写不读。④ 8251A 初始化前要先发复位命令。
  1. 8253 有三个计数器，各占什么地址？
  2. 2MHz 输入要 500Hz 输出，初值是多少？
  3. 方式 2 和方式 3 的输出有什么区别？
  4. 初值写 0 表示多少？
  5. 8N1 一帧几位？9600 波特每秒多少字节？
📖 参考答案
  1. 计数器 0/1/2 分别占 00、01、10，控制口 11
  2. 初值 = 2000000/500 = 4000
  3. 方式 2 占空比不是 50%（高 n−1 低 1）；方式 3 是标准方波（高 n/2 低 n/2）
  4. 65536
  5. 8N1 = 10 位；9600/10 = 960 字节/秒

12 第 12 章 · A/D、D/A 与总线技术

12.1 数字世界与模拟世界

方向器件作用
模拟 → 数字A/D（ADC）采样传感器电压
数字 → 模拟D/A（DAC）输出波形、控制电机

12.2 D/A：输出是一条楼梯

分辨率 = 满量程电压 ÷ 2^n

例：8 位 D/A，满量程 5V
  最小步进 = 5 / 256 ≈ 19.5 mV
  输入 10000000B (128) → 输出 128 × 19.5mV ≈ 2.5V

★ 位数越高，"楼梯"越细，越接近真正的模拟量

12.3 A/D 三步

步骤做什么注意
采样隔固定时间取一个瞬时值采样频率要 ≥ 2 倍信号最高频率（奈奎斯特）
量化把电压归到最近的离散等级产生量化误差（≤ 半个步进）
编码把等级变成二进制数—
★ 采样定理：信号最高频率 fmax，采样率必须 ≥ 2×fmax
  否则会出现「混叠」—— 波形看起来变成另一个频率

12.4 ADC0809：8 个通道共用一套转换

引脚作用
IN0~IN78 路模拟输入
ADDA~ADDC通道选择地址（3 位选 8 路）
START启动转换
EOC转换结束（可作为中断或查询信号）
OE输出允许
CLK时钟（典型 640kHz）
D0~D7数字输出
转换时间 ≈ 100 μs（640kHz 时钟时）

; 查询方式读 ADC0809
OUT 通道地址, AL      ; 选通道并启动
WAIT: IN AL, 状态口
      TEST AL, 80H    ; 测 EOC
      JZ WAIT
IN AL, 数据口         ; 读结果（OE 自动有效）

12.5 8086 的一个总线周期

一个基本的存储器读写周期 = 4 个时钟（T1~T4）

  T1：CPU 送出地址，AD0~AD15 上出现地址
  T2：地址锁存（ALE 下降沿），总线由地址转数据
  T3：数据稳定，读写信号有效
  T4：完成读写，撤信号

★ 地址和数据共用 AD0~AD15 引脚 → 必须外接地址锁存器（如 74LS373）
★ ALE 信号就是用来锁存地址的

12.6 易错点与练习

① AMD 混淆 A/D 的转换步骤。② 忘记采样定理。③ ADC0809 的 EOC 是「转换结束」不是「开始」。④ 总线周期 T1 和 T2 各干什么记混。
  1. 8 位 D/A 满量程 5V，输入 128 时输出多少？
  2. A/D 转换的三个步骤是什么？
  3. 采样定理的内容？不满足会怎样？
  4. ADC0809 有几个模拟输入通道？EOC 引脚作用？
  5. 8086 为什么必须外接地址锁存器？
📖 参考答案
  1. 128 × 5/256 = 2.5V
  2. 采样 → 量化 → 编码
  3. 采样率必须 ≥ 2 倍信号最高频率；否则产生混叠失真
  4. 8 个通道；EOC 表示转换结束，可用于查询或中断
  5. 因为 AD0~AD15 是地址与数据复用引脚，必须用 ALE 锁存地址（如 74LS373）
