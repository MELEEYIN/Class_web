第一节 函数p.001 · 7 条
  1. 定义域按顺序卡：分母 ≠ 0 → 偶次根号内 ≥ 0 → 对数真数 > 0 → arcsin/arccos 括号内 ∈ [−1, 1] → tan 的角 ≠ π/2 + kπ，最后取交集。
  2. 两个函数相同定义域相同 且 对应法则相同，两者缺一不可。ln x² 与 2ln x 不同（定义域一个是 x≠0，一个是 x>0）。
  3. 复合与分解y = f[g(x)] 由外向内拆；复合的条件是内层的值域要落在外层的定义域内。
  4. 反函数求法：由 y = f(x) 解出 x = f−1(y)，再交换字母。y = f(x) 与 y = f−1(x) 的图形关于 y = x 对称。
  5. 奇偶性f(−x) = f(x) 为偶，f(−x) = −f(x) 为奇。奇函数若在 0 有定义，则 f(0) = 0；奇×奇 = 偶，奇×偶 = 奇，偶×偶 = 偶。
  6. 周期性f(x + T) = f(x) 的最小正 T 是周期。sin x、cos x 为 2π，tan x、cot x 为 π；周期只能缩小（sin 2x 周期 π），不能放大。
  7. 有界性存在 M 使 |f(x)| ≤ M。sin x、cos x、arctan x 在 R 上有界；1/x 在 (0, 1) 内无界。
第二节 数列的极限p.023 · 5 条
  1. ε–N 定义∀ε > 0，∃N，当 n > N 时 |an − a| < ε。几何意义：a 的 ε 邻域外只有有限项。
  2. 收敛数列的四条性质唯一性、有界性、保号性（极限 > 0 则从某项起 an > 0）、子列同极限（任一子列都收敛到同一值）。
  3. 无穷小 × 有界若 {an} 是无穷小、{bn} 有界，则 {anbn} 是无穷小。典型：(1/n)·sin n → 0。
  4. 单调有界准则单增且有上界（或单减且有下界）的数列必收敛。这是递推数列求极限的唯一通用入口。
  5. 常用结论|q| < 1 时 qn → 0；n1/n → 1；a1/n → 1 (a > 0)；nk/an → 0 (a > 1)。
第三节 函数的极限p.029 · 4 条
  1. 两种定义x → x₀：∀ε > 0, ∃δ > 0，0 < |x − x₀| < δ 时 |f(x) − A| < ε；x → ∞：∀ε > 0, ∃X，|x| > X 时成立。注意「去心」邻域。
  2. 左右极限limx→x₀ f 存在 ⟺ 左极限 = 右极限。分段函数在接缝处、含 |x − a|、含取整 [x] 的题，必须两边都算。
  3. 局部保号与局部有界若 lim f = A > 0，则在 x₀ 的某去心邻域内 f > 0；极限存在 ⟹ 局部有界。
  4. x → ∞ 的抓大头有理式看分子分母最高次：同次取系数比，分子低次则 → 0，分子高次则 → ∞。根式先同除最高次再取极限。
第四节 无穷小与无穷大 曲线的渐近线p.042 · 6 条
  1. 无穷小以 0 为极限的变量。0 是唯一的「常数无穷小」；有限个无穷小的和、积仍是无穷小。
  2. 无穷大绝对值无限增大的变量，记 lim = ∞，它不是数，不能参与四则运算。f 是无穷大 ⟺ 1/f 是无穷小（f ≠ 0）。
  3. 无界 ≠ 无穷大x sin x 在 (0, +∞) 上无界，但不是无穷大（会不断回到 0）。
  4. 垂直渐近线limx→a⁺ f(x) = ∞ 或 −∞ ⟹ x = a 是垂直渐近线。出现位置：分母零点、对数真数零点。
  5. 水平渐近线limx→+∞ f(x) = b 或 limx→−∞ = b ⟹ y = b（两侧可以不同）。
  6. 斜渐近线k = limx→∞ f(x)/x（k ≠ 0 且有限），b = limx→∞ [f(x) − kx]，则 y = kx + b。k = 0 时退化为水平渐近线。
第五节 极限运算法则p.055 · 5 条
  1. 四则运算和、差、积、商的极限等于极限的和、差、积、商，前提是每个极限都存在且分母极限 ≠ 0。
  2. 代入优先初等函数在定义点处连续，所以先直接代入；得到非零数 / 非零数就直接结束，只有 0/0、∞/∞ 才需要变形。
  3. 0/0 的有理式因式分解约去零因子；含根号先有理化（乘共轭）；含 sin/tan 的考虑等价无穷小。
  4. 复合函数极限外层连续时 lim f(g(x)) = f(lim g(x))，即「极限可以搬进函数里」。
  5. 幂指函数uv = ev ln u，把 1∞、00、∞0 统一化成指数上的乘积极限。
第六节 极限存在准则 两个重要极限p.068 · 6 条
  1. 第一个重要极限limx→0 sin x / x = 1，推广成 limu→0 sin u / u = 1（u 可以是任何趋于 0 的式子）。
  2. 三角型配套1 − cos x 型先化 2sin²(x/2)；tan x 型先拆 sin x / cos x；arcsin x、arctan x 型令 t = arcsin x 换元。
  3. 第二个重要极限limx→∞ (1 + 1/x)x = e，等价写法 limu→0 (1 + u)1/u = e。
  4. 1^∞ 型速算若 lim u = 1、lim v = ∞，则 lim uv = elim v(u−1)。凑成 (1 + (u−1))1/(u−1) 再补指数，一步到位。
  5. 夹逼准则0 ≤ an ≤ bn 且 bn → 0，则 an → 0。常用于含 n 项和、含 (−1)n 的放缩。
  6. 递推数列两步走① 数学归纳证有界；② 作差 an+1 − an（或作商）证单调；③ 设极限为 A 代入递推式解方程，舍去不合理的根。
第七节 无穷小的比较p.078 · 6 条
  1. 四个等级β/α → 0 为高阶（β = o(α)）；→ ∞ 为低阶；→ c ≠ 0 为同阶；→ 1 为等价，记 α ~ β。
  2. 等价替换定理在乘除因子里可以把无穷小换成它的等价无穷小，极限不变；加减里换会丢项，必错。
  3. 基本替换表（x→0）sin x ~ tan x ~ arcsin x ~ arctan x ~ ln(1 + x) ~ ex − 1 ~ x。
  4. 二阶与三阶替换1 − cos x ~ x²/2；(1 + x)α − 1 ~ αx；ax − 1 ~ x ln a；x − sin x ~ x³/6；tan x − x ~ x³/3；x − ln(1 + x) ~ x²/2；tan x − sin x ~ x³/2。
  5. 复合换元若 u → 0 且 f(u) ~ u，则 f(g(x)) ~ g(x)（只要 g(x) → 0）。例：sin(x²) ~ x²。
  6. 加减型怎么办先通分、提公因式、有理化或合并同类项，把加减化成乘除再用替换；实在不行上泰勒展到足够阶。
第八节 函数的连续性与间断点p.087 · 6 条
  1. 连续的定义limx→x₀ f(x) = f(x₀)。三个条件：在 x₀ 有定义、极限存在、二者相等。
  2. 单侧连续左连续 f(x₀⁻) = f(x₀)，右连续 f(x₀⁺) = f(x₀)；连续 ⟺ 既左连续又右连续。
  3. 第一类间断点左右极限都存在：相等 ⟹ 可去间断点；不相等 ⟹ 跳跃间断点。
  4. 第二类间断点至少一侧极限不存在：趋于 ∞ 为无穷间断点；来回振荡（如 sin(1/x)）为振荡间断点。
  5. 判断流程先找可疑点：分母零点、无定义点、分段接缝 → 分别算左右极限 → 按上表定性，最后写出结论。
  6. 含参连续题分段点连续 ⟹ 左极限 = 右极限 = 函数值，列方程解参数；要可导则再要求左右导数相等。
第九节 连续函数的运算与初等函数的连续性p.095 · 4 条
  1. 四则与复合连续函数的和、差、积、商（分母 ≠ 0）、复合仍连续；反函数在对应区间上也连续。
  2. 初等函数一切初等函数在其定义区间内连续，所以求极限可直接代入（端点按单侧处理）。
  3. 极限搬进函数f 在 A 处连续、lim g(x) = A ⟹ lim f(g(x)) = f(A)。这是「先算内层再代入外层」的依据。
  4. 幂指函数连续uv 的连续性看 ev ln u：要求 u > 0 且 u、v 连续。
第十节 闭区间上连续函数的性质p.101 · 4 条
  1. 有界性与最值定理f 在 [a, b] 上连续 ⟹ f 在 [a, b] 上有界，且一定能取到最大值与最小值（开区间不成立）。
  2. 零点定理f 在 [a, b] 连续且 f(a)·f(b) < 0 ⟹ ∃ξ ∈ (a, b)，f(ξ) = 0。证明方程有根的万能钥匙。
  3. 介值定理μ 介于 f(a) 与 f(b) 之间 ⟹ ∃ξ ∈ (a, b)，f(ξ) = μ。零点定理是 μ = 0 的特例。
  4. 根的个数「有且仅有一个根」= 零点定理（存在）+ 单调性（唯一）。单调性用 f′ > 0 或 < 0 证。

M4易错点与综合提高扣分常从这里开始

易错点
  • 等价替换只在乘除因子里成立。加减里替换会丢掉同阶项，sin x − x 换成 0 就必错；要先通分、提公因式或上泰勒。
  • x→∞ 与 x→+∞ 不是一回事。根号里带平方、含 |x| 的式子两个方向结果往往不同，要分开算。
  • 分段点求极限必须左右都算。左右不相等 ⟹ 极限不存在，不能只代一侧的函数式。
  • 间断点先找可疑点：分母为零、无定义、分段接缝。再算左右极限定类型——左右都存在且相等是可去，不等是跳跃，有一个是 ∞ 就是无穷间断。
  • 1∞ 不能把底数当 1。它是不定式，必须凑 e；写成 elim u·v 是最快的路子。
综合提高（讲义每章末的题型）
  1. 递推数列 an+1 = √(2 + an)，a₁ = √2，证收敛并求极限
    思路：先证有界（数学归纳法 an < 2），再证单调（an+1 − an 的符号），单调有界 ⟹ 收敛；设极限为 A 代入递推式解 A² = 2 + A。
  2. 求 limx→∞ ((x²+1)/(x²−1))x²
    思路：标准 1∞：底数写成 1 + 2/(x²−1)，指数乘除凑 e，答案 e²。别用洛必达硬做。
  3. 证明方程 x = cos x 在 (0,1) 内有且仅有一个根
    思路：零点定理证存在：令 f(x) = x − cos x，f(0) < 0、f(1) > 0；再用 f′(x) = 1 + sin x > 0 证单调 ⟹ 唯一。

第一节 导数概念p.119 · 5 条
  1. 定义式f′(x₀) = limΔx→0 [f(x₀ + Δx) − f(x₀)]/Δx = limx→x₀ [f(x) − f(x₀)]/(x − x₀)。用定义求导时先写出这个式子再化简。
  2. 几何与物理意义切线斜率 k = f′(x₀)；瞬时速度 v = s′(t)；瞬时变化率。切线方程 y − f(x₀) = f′(x₀)(x − x₀)。
  3. 可导与连续可导 ⟹ 连续，连续 ⇏ 可导。反例：y = |x| 在 0 点连续但左右导数分别为 −1、1。

第一节 微分方程的基本概念p.379 · 4 条
  1. 阶方程中出现的最高阶导数的阶数。y″ + y = 0 是二阶。
  2. 通解与特解通解含与阶数相同个数的独立任意常数；由初始条件定出常数后得到特解。
  3. 线性与非线性未知函数及其各阶导数都是一次的叫线性；出现 y²、yy′、sin y 就是非线性。
  4. 积分曲线解 y = y(x) 是平面上的一条曲线，初始条件就是「过某点」。
第二节 可分离变量的微分方程p.383 · 4 条
  1. 标准形dy/dx = f(x)g(y)。把含 y 的移到一边、含 x 的移到另一边：dy/g(y) = f(x)dx。
  2. 求解步骤分离 → 两边积分 → 化简成显式或隐式解 → 有初始条件就代进去定 C。
  3. 丢解除以 g(y) 时，g(y) = 0 对应的常数解可能被丢掉，最后要单独检查并补上。
  4. 常见形式y′ = xy、y′ = ex+y、y′ = (1 + y²)/(1 + x²) 都属于这一类。
第三节 齐次方程p.387 · 4 条
  1. 识别能写成 dy/dx = φ(y/x) 的形状，即分子分母同次齐次。
  2. 代换令 u = y/x，则 y = ux，y′ = u + x·du/dx，方程化为可分离变量的 u 与 x。
  3. 回代解出 u 关于 x 的表达式后，把 u = y/x 代回，得到 y 与 x 的关系。
  4. 变体形如 dy/dx = (a₁x + b₁y + c₁)/(a₂x + b₂y + c₂) 时，先平移消去常数项再按齐次处理。
第四节 一阶线性微分方程p.394 · 5 条
  1. 标准形y′ + P(x)y = Q(x)。系数必须是 1，否则先除过去。
  2. 通解公式y = e−∫P dx[∫Q·e∫P dxdx + C]。背不住就用常数变易法现场推。
  3. 常数变易法先解齐次 y′ + Py = 0 得 y = Ce−∫P dx，再令 C = C(x) 代回原方程求 C(x)。
  4. 以 x 为未知函数遇到 y′ = 1/(x + y) 这类，把 x 看成 y 的函数改写 dx/dy + P(y)x = Q(y)，往往立刻变成线性。
  5. 伯努利方程y′ + P(x)y = Q(x)yn（n ≠ 0, 1），令 z = y1−n 化为一阶线性。
第五节 可降阶的高阶微分方程p.402 · 4 条
  1. y(n) = f(x)连续积分 n 次，每次加一个常数。
  2. 缺 y：y″ = f(x, y′)令 p = y′，则 y″ = dp/dx，方程降为一阶 p 与 x 的方程。
  3. 缺 x：y″ = f(y, y′)令 p = y′，则 y″ = p·dp/dy，方程降为一阶 p 与 y 的方程（自变量换成 y）。
  4. 怎么选看方程里缺谁：缺 y 用 p(x)，缺 x 用 p(y)。选错了会算不下去。
第六节 高阶线性微分方程p.406 · 4 条
  1. 齐次解的结构二阶齐次的两个线性无关解 y₁、y₂ ⟹ 通解 y = C₁y₁ + C₂y₂。
  2. 非齐次解的结构通解 = 对应齐次的通解 + 非齐次的一个特解。
  3. 线性无关判别朗斯基行列式 W(y₁, y₂) ≠ 0 ⟹ 线性无关；两个解不成比例就是无关。
  4. 叠加原理非齐次右端为 f₁ + f₂ 时，可分别求特解再相加。
第七节 常系数齐次线性微分方程p.409 · 5 条
  1. 特征方程y″ + py′ + qy = 0 ⟹ r² + pr + q = 0，根的情况决定通解形式。
  2. 两个相异实根r₁ ≠ r₂：y = C₁er₁x + C₂er₂x。
  3. 二重实根r₁ = r₂ = r：y = (C₁ + C₂x)erx，第二个解要乘 x。
  4. 共轭复根r = α ± βi：y = eαx(C₁cos βx + C₂sin βx)。
  5. 高阶推广n 阶就把每个根对应的解加起来，k 重根对应 erx 乘 1, x, …, xk−1。
第八节 常系数非齐次线性微分方程p.412 · 4 条

    思路：取 Σ 为该平面被截出的三角形，旋度为 (1,1,1) 形式，化成二重积分算面积。

第一节 常数项级数的概念与性质p.236 · 4 条
  1. 部分和Sn = Σk=1nuk；级数收敛 ⟺ 部分和数列 Sn 有极限，极限值就是级数的和。
  2. 收敛的必要条件收敛 ⟹ 通项 un → 0。反过来不成立（Σ1/n 通项趋 0 却发散）。
  3. 性质线性；去掉或增加有限项不改变敛散性；收敛级数可以任意加括号。
  4. 几何级数与 p-级数Σqn 收敛 ⟺ |q| < 1；Σ1/np 收敛 ⟺ p > 1。这两个是所有比较法的标尺。
第二节 正项级数p.245 · 5 条
  1. 比较判别法un ≤ vn：大收敛则小收敛，小发散则大发散。常与 p-级数、几何级数比。
  2. 极限比较法lim un/vn = c（0 < c < ∞）⟹ 同敛散；= 0 且 v 收敛则 u 收敛；= ∞ 且 v 发散则 u 发散。
  3. 比值法lim un+1/un = ρ：ρ < 1 收敛，ρ > 1 发散，ρ = 1 失效。含 n!、an 时首选。
  4. 根值法lim n√un = ρ：判据同上。含 n 次方、整体 n 次幂时首选。
  5. 积分判别法un = f(n) 且 f 单调递减非负，则 Σun 与 ∫1∞f(x)dx 同敛散。
第三节 任意项级数p.255 · 4 条
  1. 交错级数Σ(−1)nun（un > 0）：un 单调递减且 → 0 ⟹ 收敛（莱布尼茨判别法），且余项 |Rn| ≤ un+1。
  2. 绝对收敛Σ|un| 收敛 ⟹ Σun 必收敛，且称绝对收敛。
  3. 条件收敛Σun 收敛但 Σ|un| 发散，称条件收敛。典型：Σ(−1)n/n。
  4. 判敛流程先看通项是否 → 0；再判绝对值级数（用正项级数的方法）；绝对值发散再看是否交错、能否用莱布尼茨。
第四节 幂级数p.262 · 5 条
  1. 收敛半径R = lim|an/an+1|（或 R = 1/lim n√|an|）；在 |x| < R 内绝对收敛，|x| > R 发散。
  2. 收敛域先求 R 得开区间，再把两个端点分别代入化回常数项级数判敛，最后写收敛域。
  3. 端点必查这是幂级数题最固定的送分点：漏判端点就少一半分。
  4. 性质收敛区间内可逐项求导、逐项积分，收敛半径不变（端点可能变）。
  5. 缺项幂级数Σanx2n 这类不能直接套公式，要令 t = x² 或直接用比值法对整项求极限。
第五节 函数展开成幂级数p.272 · 5 条
  1. 直接法在 x₀ 处按泰勒系数 an = f(n)(x₀)/n! 展开，并验证余项趋于 0。
  2. 间接法利用已知展开式做代换、四则运算、逐项求导或积分。考试九成用间接法。
  3. 常用展开1/(1 − x) = Σxn；ex、sin x、cos x、ln(1 + x)、(1 + x)α 五条要脱口而出。
  4. 区间限制展开式只在收敛区间内成立，写答案时要注明 (|x| < 1) 之类的条件。
  5. 技巧求 ln(1 + x) 可以对 1/(1 + x) 逐项积分；求 arctan x 可以对 1/(1 + x²) 积分。
第六节 幂级数的应用p.280 · 4 条
  1. 求和函数常用套路：先求收敛域 → 逐项求导或积分凑成几何级数 → 求和 → 再积分/求导还原。
  2. 逐项求导的典型Σn xn = x/(1 − x)²，来自对 Σxn 求导再乘 x。
  3. 近似计算取前几项算近似值，误差用余项（莱布尼茨型或拉格朗日余项）估计。
  4. 微分方程的幂级数解设 y = Σanxn 代入方程比较系数，适合变系数方程。
第七节 傅里叶级数p.285 · 6 条
  1. 狄利克雷条件周期为 2π 的函数在一个周期内连续或只有有限个第一类间断点、且只有有限个极值点 ⟹ 可展成傅里叶级数。
  2. 系数公式a₀ = (1/π)∫−ππf dx；an = (1/π)∫−ππf cos nx dx；bn = (1/π)∫−ππf sin nx dx。
  3. 和函数的值连续点处等于 f(x)；间断点处等于左右极限的平均值 [f(x⁻) + f(x⁺)]/2。
  4. 奇偶简化奇函数只含 sin 项（bn），偶函数只含 cos 项（an），能省一半积分。
  5. 正弦级数与余弦级数定义在 (0, π) 上的函数做奇延拓得正弦级数，做偶延拓得余弦级数。
  6. 周期为 2l把 1/π 换成 1/l，cos nx 换成 cos(nπx/l)，积分区间换成 [−l, l]。

易错点
  • 通项趋于 0 只是收敛的必要条件。Σ1/n 通项 → 0 但发散，别拿它当判据。
  • 比值 / 根值法 ρ = 1 时失效，必须换比较法或积分判别法。
  • 幂级数的端点必须单独判。求出 |x| < R 只是开区间，端点代入后可能收敛也可能发散。
  • 求和函数时别忘写收敛域。和函数只在收敛域内成立。
  • 傅里叶系数公式里的 1/π 与区间长度有关：周期为 2l 时是 1/l，别照搬 1/π。
综合提高（讲义每章末的题型）
  1. 判断 Σ (−1)n/√n 的敛散性（是否绝对收敛）
    思路：un = 1/√n 递减且 → 0，莱布尼茨 ⟹ 收敛；但 Σ1/√n 是 p = 1/2 的 p-级数发散 ⟹ 条件收敛。
  2. 求 Σ n xn 的和函数
    思路：先求 R = 1；对 Σxn = 1/(1−x) 逐项求导再乘 x，得 x/(1−x)²，（|x| < 1）。
  3. 把 f(x) = x（0 < x < π）展开成正弦级数
    思路：奇延拓后 an = 0，bn = (2/π)∫0π x sin nx dx = 2(−1)n+1/n，得 Σ [2(−1)n+1/n] sin nx。
