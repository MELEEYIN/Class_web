第一节 函数p.001 · 7 条
  1. 定义域按顺序卡：分母 ≠ 0 → 偶次根号内 ≥ 0 → 对数真数 > 0 → arcsin/arccos 括号内 ∈ [−1, 1] → tan 的角 ≠ π/2 + kπ，最后取交集。
  2. 两个函数相同定义域相同 且 对应法则相同，两者缺一不可。ln x² 与 2ln x 不同（定义域一个是 x≠0，一个是 x>0）。
  3. 复合与分解y = f[g(x)] 由外向内拆；复合的条件是内层的值域要落在外层的定义域内。
  4. 反函数求法：由 y = f(x) 解出 x = f−1(y)，再交换字母。y = f(x) 与 y = f−1(x) 的图形关于 y = x 对称。
  5. 奇偶性f(−x) = f(x) 为偶，f(−x) = −f(x) 为奇。奇函数若在 0 有定义，则 f(0) = 0；奇×奇 = 偶，奇×偶 = 奇，偶×偶 = 偶。
  6. 周期性f(x + T) = f(x) 的最小正 T 是周期。sin x、cos x 为 2π，tan x、cot x 为 π；周期只能缩小（sin 2x 周期 π），不能放大。
  7. 有界性存在 M 使 |f(x)| ≤ M。sin x、cos x、arctan x 在 R 上有界；1/x 在 (0, 1) 内无界。
练 1先自己做，再展开答案

求函数 y = √(x − 1) + 1x − 3 + ln(5 − x) 的定义域。

展开答案与解析

解　三个限制条件逐个卡：
偶次根号内不小于零，得 x ≥ 1；
分母不为零，得 x ≠ 3；
对数真数大于零，得 x < 5；
三条同时成立，取交集得定义域 [1, 3) ∪ (3, 5)。

定义域永远是「列条件 → 取交集」；最容易丢的是 x = 3 这个洞，以及端点的开闭（1 取得到，5 取不到）。

练 2先自己做，再展开答案

判断 f(x) = ln1 − x1 + x 的奇偶性，并写出它的定义域。

展开答案与解析

解　先看定义域：真数大于零，即 1 − x1 + x > 0，解得 −1 < x < 1，区间关于原点对称，可以谈奇偶性；
再算 f(−x) = ln1 + x1 − x，它正好是 ln1 − x1 + x 的倒数，而倒数的对数等于对数的相反数，所以 f(−x) = −f(x)；
结论：f 是 奇函数，定义域 (−1, 1)。

判奇偶第一步永远是看定义域是否关于原点对称，不对称就直接下结论「非奇非偶」，不用再算 f(−x)。

第二节 数列的极限p.023 · 5 条
  1. ε–N 定义∀ε > 0，∃N，当 n > N 时 |an − a| < ε。几何意义：a 的 ε 邻域外只有有限项。
  2. 收敛数列的四条性质唯一性、有界性、保号性（极限 > 0 则从某项起 an > 0）、子列同极限（任一子列都收敛到同一值）。
  3. 无穷小 × 有界若 {an} 是无穷小、{bn} 有界，则 {anbn} 是无穷小。典型：(1/n)·sin n → 0。
  4. 单调有界准则单增且有上界（或单减且有下界）的数列必收敛。这是递推数列求极限的唯一通用入口。
  5. 常用结论|q| < 1 时 qn → 0；n1/n → 1；a1/n → 1 (a > 0)；nk/an → 0 (a > 1)。
练 1先自己做，再展开答案

用数列极限的定义证明 limn→∞ 3n + 12n − 1 = 32。

展开答案与解析

解　先算出差的绝对值并放大：
|an − 32| = |6n + 2 − 6n + 32(2n − 1)| = 54n − 2 ≤ 52n（n ≥ 1 时成立）；
对任意 ε > 0，取 N = ⌊52ε⌋ + 1，则当 n > N 时 52n < ε，从而 |an − 32| < ε；
由定义得 limn→∞ 3n + 12n − 1 = 32。

证定义的套路是「先放大、再解 n」：把含 n 的部分放大成好解的形式，N 只要能找到一个就行，不必求最小的那个。

练 2先自己做，再展开答案

求 limn→∞ (1√(n² + 1) + 1√(n² + 2) + … + 1√(n² + n))。

展开答案与解析

解　和式一共 n 项，每项的分母都在 √(n² + 1) 与 √(n² + n) 之间，于是
n√(n² + n) ≤ Sn ≤ n√(n² + 1)；
两端分子分母同除 n：左端 = 1√(1 + 1/n) → 1，右端 = 1√(1 + 1/n²) → 1；
由夹逼准则得原式 = 1。

含 n 项和先数清项数（这里是 n 项，所以放缩后要乘 n）；两端都能直接算出极限才叫夹逼，若只一端收敛就没法用。

第三节 函数的极限p.029 · 4 条
  1. 两种定义x → x₀：∀ε > 0, ∃δ > 0，0 < |x − x₀| < δ 时 |f(x) − A| < ε；x → ∞：∀ε > 0, ∃X，|x| > X 时成立。注意「去心」邻域。
  2. 左右极限limx→x₀ f 存在 ⟺ 左极限 = 右极限。分段函数在接缝处、含 |x − a|、含取整 [x] 的题，必须两边都算。
  3. 局部保号与局部有界若 lim f = A > 0，则在 x₀ 的某去心邻域内 f > 0；极限存在 ⟹ 局部有界。
  4. x → ∞ 的抓大头有理式看分子分母最高次：同次取系数比，分子低次则 → 0，分子高次则 → ∞。根式先同除最高次再取极限。
练 1先自己做，再展开答案

求 limx→−∞ (√(x² + x + 1) + x)。

展开答案与解析

解　先有理化：同乘 √(x² + x + 1) − x，分子变成 (x² + x + 1) − x² = x + 1，
原式 = x + 1√(x² + x + 1) − x；
因为 x < 0，开方要带负号：√(x² + x + 1) = −x√(1 + 1/x + 1/x²)，分子分母同除 x 得
原式 = 1 + 1/x−√(1 + 1/x + 1/x²) − 1；
x → −∞ 时 1/x → 0，所以原式 → 1−1 − 1 = −12。

x → −∞ 时 √(x²) = −x，不是 x；这一处符号错了，答案会正好差一个负号。同除之前先确认 x 的符号。

第四节 无穷小与无穷大 曲线的渐近线p.042 · 6 条
  1. 无穷小以 0 为极限的变量。0 是唯一的「常数无穷小」；有限个无穷小的和、积仍是无穷小。
  2. 无穷大绝对值无限增大的变量，记 lim = ∞，它不是数，不能参与四则运算。f 是无穷大 ⟺ 1/f 是无穷小（f ≠ 0）。
  3. 无界 ≠ 无穷大x sin x 在 (0, +∞) 上无界，但不是无穷大（会不断回到 0）。
  4. 垂直渐近线limx→a⁺ f(x) = ∞ 或 −∞ ⟹ x = a 是垂直渐近线。出现位置：分母零点、对数真数零点。
  5. 水平渐近线limx→+∞ f(x) = b 或 limx→−∞ = b ⟹ y = b（两侧可以不同）。
  6. 斜渐近线k = limx→∞ f(x)/x（k ≠ 0 且有限），b = limx→∞ [f(x) − kx]，则 y = kx + b。k = 0 时退化为水平渐近线。
练 1先自己做，再展开答案

求曲线 y = x² + 1x − 1 的所有渐近线。

展开答案与解析

解　① 垂直：分母零点 x = 1，此处分子 1 + 1 = 2 ≠ 0，limx→1 f(x) = ∞，故 x = 1 是垂直渐近线；
② 斜：k = limx→∞ f(x)x = limx→∞ x² + 1x² − x = 1，b = limx→∞ [f(x) − x] = limx→∞ x + 1x − 1 = 1，故 y = x + 1；
③ 水平：x → ∞ 时 f(x) → ∞，水平渐近线不存在；
所以两条渐近线是 x = 1 与 y = x + 1。

先做一次多项式除法 f(x) = x + 1 + 2x − 1，斜渐近线和垂直渐近线一眼可见；水平渐近线与斜渐近线不可能同时存在。

练 2先自己做，再展开答案

求曲线 y = 2x² + 3x² − 1 的所有渐近线。

展开答案与解析

解　分母 x² − 1 有两个零点 x = 1 与 x = −1，分子在这两点都等于 5 ≠ 0，
所以 x = 1 与 x = −1 都是垂直渐近线（两条，不能只查一条）；
再算无穷远处：limx→±∞ 2x² + 3x² − 1 = 2，两侧是同一条水平渐近线 y = 2；
又因 k = limx→∞ f(x)x = 0，不存在斜渐近线。答案：x = 1、x = −1、y = 2。

分母有几个零点就逐个查几个；本题的陷阱是只查出 x = 1 就收手。另外分子分母同次，水平渐近线两侧相同，不必分开算。

第五节 极限运算法则p.055 · 5 条
  1. 四则运算和、差、积、商的极限等于极限的和、差、积、商，前提是每个极限都存在且分母极限 ≠ 0。
  2. 代入优先初等函数在定义点处连续，所以先直接代入；得到非零数 / 非零数就直接结束，只有 0/0、∞/∞ 才需要变形。
  3. 0/0 的有理式因式分解约去零因子；含根号先有理化（乘共轭）；含 sin/tan 的考虑等价无穷小。
  4. 复合函数极限外层连续时 lim f(g(x)) = f(lim g(x))，即「极限可以搬进函数里」。
  5. 幂指函数uv = ev ln u，把 1∞、00、∞0 统一化成指数上的乘积极限。
练 1先自己做，再展开答案

求 limx→2 x² − 4x² − 5x + 6。

展开答案与解析

解　直接代入得 00，说明 x − 2 是分子分母的公因子；
因式分解：x² − 4x² − 5x + 6 = (x − 2)(x + 2)(x − 2)(x − 3) = x + 2x − 3（x ≠ 2）；
约完再代入：原式 = 4−1 = −4。

0/0 才需要变形，其它情况直接代入就结束；约掉的因子是「x → 2 但 x ≠ 2」，所以约分这一步是合法的。

练 2先自己做，再展开答案

求 limn→∞ 2n + 3n2n − 3n+1。

展开答案与解析

解　指数型要除的是底数大的那一项，不是 n 的最高次：分子分母同除 3n；
原式 = (2/3)n + 1(2/3)n − 3（因为 3n+1/3n = 3）；
|2/3| < 1，故 (2/3)n → 0，原式 → 1−3 = −13。

两个陷阱：一是「抓大头」在指数式里抓的是底数最大项；二是 3n+1 除完剩下 3，别漏掉那个指数上的 1。

第六节 极限存在准则 两个重要极限p.068 · 6 条
  1. 第一个重要极限limx→0 sin x / x = 1，推广成 limu→0 sin u / u = 1（u 可以是任何趋于 0 的式子）。
  2. 三角型配套1 − cos x 型先化 2sin²(x/2)；tan x 型先拆 sin x / cos x；arcsin x、arctan x 型令 t = arcsin x 换元。
  3. 第二个重要极限limx→∞ (1 + 1/x)x = e，等价写法 limu→0 (1 + u)1/u = e。
  4. 1^∞ 型速算若 lim u = 1、lim v = ∞，则 lim uv = elim v(u−1)。凑成 (1 + (u−1))1/(u−1) 再补指数，一步到位。
  5. 夹逼准则0 ≤ an ≤ bn 且 bn → 0，则 an → 0。常用于含 n 项和、含 (−1)n 的放缩。
  6. 递推数列两步走① 数学归纳证有界；② 作差 an+1 − an（或作商）证单调；③ 设极限为 A 代入递推式解方程，舍去不合理的根。
练 1先自己做，再展开答案

求 limx→0 1 − cos 2xx · sin x。

展开答案与解析

解　先化分子：由 1 − cos 2x = 2sin²x，原式 = 2sin²xx · sin x；
x ≠ 0 时可约掉一个 sin x，得原式 = 2 · sin xx；
再由第一个重要极限 limx→0 sin xx = 1，得原式 = 2。

看到 1 − cos 型先上二倍角化成 sin²，再凑 sin u / u；分子化成 sin²x 后一定要和分母的 sin x 约，别停在中间那步。

练 2先自己做，再展开答案

求 limx→0 (1 + tan x)1/sin x。

展开答案与解析

解　x → 0 时底数 → 1、指数 → ∞，是 1∞ 型，用 elim v(u−1)：
取 u = 1 + tan x，v = 1sin x，则 v(u − 1) = tan xsin x = 1cos x；
x → 0 时 cos x → 1，故极限 = e1 = e。

1∞ 千万别把底数当 1 算成 1；写成 elim v(u−1) 最稳，tan x 拆成 sin x / cos x 后约掉 sin x 只剩 1 / cos x。

第七节 无穷小的比较p.078 · 6 条
  1. 四个等级β/α → 0 为高阶（β = o(α)）；→ ∞ 为低阶；→ c ≠ 0 为同阶；→ 1 为等价，记 α ~ β。
  2. 等价替换定理在乘除因子里可以把无穷小换成它的等价无穷小，极限不变；加减里换会丢项，必错。
  3. 基本替换表（x→0）sin x ~ tan x ~ arcsin x ~ arctan x ~ ln(1 + x) ~ ex − 1 ~ x。
  4. 二阶与三阶替换1 − cos x ~ x²/2；(1 + x)α − 1 ~ αx；ax − 1 ~ x ln a；x − sin x ~ x³/6；tan x − x ~ x³/3；x − ln(1 + x) ~ x²/2；tan x − sin x ~ x³/2。
  5. 复合换元若 u → 0 且 f(u) ~ u，则 f(g(x)) ~ g(x)（只要 g(x) → 0）。例：sin(x²) ~ x²。
  6. 加减型怎么办先通分、提公因式、有理化或合并同类项，把加减化成乘除再用替换；实在不行上泰勒展到足够阶。
练 1先自己做，再展开答案

求 limx→0 tan x − sin xx³，并指出 tan x − sin x 是 x 的几阶无穷小。

展开答案与解析

解　分子是加减型，先提公因式化成乘除：tan x − sin x = tan x · (1 − cos x)；
tan x ~ x，1 − cos x ~ x²2，两个都是乘除因子，可以各自替换，得 tan x − sin x ~ x³2；
所以原式 = limx→0 x³/2x³ = 12，且 tan x − sin x 是 x 的 三阶无穷小。

最容易错的是直接把 tan x、sin x 都换成 x，分子变成 0，等于把三阶项整个丢掉了；加减型必须先提公因式、通分或有理化，变成乘除才准换。

练 2先自己做，再展开答案

求 limx→0 e2x − 1 − 2xx²。

展开答案与解析

解　分子是加减型，用 e2x − 1 ~ 2x 只能得到一阶信息，而这一阶正好被后面的 2x 减光，必须往二阶看；
展开 e2x = 1 + 2x + 2x² + o(x²)，于是分子 = 2x² + o(x²)；
所以原式 = limx→0 2x² + o(x²)x² = 2。

被减项刚好抵消时，等价无穷小给的信息不够，要展到第一个不被抵消的阶；这一步用泰勒最保险。

第八节 函数的连续性与间断点p.087 · 6 条
  1. 连续的定义limx→x₀ f(x) = f(x₀)。三个条件：在 x₀ 有定义、极限存在、二者相等。
  2. 单侧连续左连续 f(x₀⁻) = f(x₀)，右连续 f(x₀⁺) = f(x₀)；连续 ⟺ 既左连续又右连续。
  3. 第一类间断点左右极限都存在：相等 ⟹ 可去间断点；不相等 ⟹ 跳跃间断点。
  4. 第二类间断点至少一侧极限不存在：趋于 ∞ 为无穷间断点；来回振荡（如 sin(1/x)）为振荡间断点。
  5. 判断流程先找可疑点：分母零点、无定义点、分段接缝 → 分别算左右极限 → 按上表定性，最后写出结论。
  6. 含参连续题分段点连续 ⟹ 左极限 = 右极限 = 函数值，列方程解参数；要可导则再要求左右导数相等。
练 1先自己做，再展开答案

求 f(x) = x² − 1x² − 3x + 2 的间断点，并指出它们的类型。

展开答案与解析

解　分母分解为 (x − 1)(x − 2)，可疑点是 x = 1 与 x = 2；
x = 1：约分后 f(x) = x + 1x − 2，limx→1 f(x) = 2−1 = −2，极限存在，故 x = 1 是可去间断点（补充定义 f(1) = −2 即可连续）；
x = 2：分子为 3 ≠ 0、分母趋于 0，limx→2 f(x) = ∞，故 x = 2 是无穷间断点（第二类）。

分子分母同时为零的点先约分再看极限，别一见到分母为零就判无穷间断；可去与无穷的差别就在约分后极限是否存在。

第九节 连续函数的运算与初等函数的连续性p.095 · 4 条

第十节 闭区间上连续函数的性质p.101 · 4 条
  1. 有界性与最值定理f 在 [a, b] 上连续 ⟹ f 在 [a, b] 上有界，且一定能取到最大值与最小值（开区间不成立）。
  2. 零点定理f 在 [a, b] 连续且 f(a)·f(b) < 0 ⟹ ∃ξ ∈ (a, b)，f(ξ) = 0。证明方程有根的万能钥匙。
  3. 介值定理μ 介于 f(a) 与 f(b) 之间 ⟹ ∃ξ ∈ (a, b)，f(ξ) = μ。零点定理是 μ = 0 的特例。
  4. 根的个数「有且仅有一个根」= 零点定理（存在）+ 单调性（唯一）。单调性用 f′ > 0 或 < 0 证。
练 1先自己做，再展开答案

证明方程 x³ + x − 1 = 0 在区间 (0, 1) 内有且仅有一个根。

展开答案与解析

解　令 f(x) = x³ + x − 1，它是多项式，在闭区间 [0, 1] 上连续；
端点值 f(0) = −1 < 0，f(1) = 1 + 1 − 1 = 1 > 0，f(0)·f(1) < 0，由零点定理，存在 ξ ∈ (0, 1) 使 f(ξ) = 0，即根存在；
又 x³ 与 x 在 [0, 1] 上都严格单调增加，故 f(x) 严格单调增加，最多只有一个零点，即根唯一；
综上，方程在 (0, 1) 内有且仅有一个根。

「有且仅有」必须写两步：零点定理管存在，单调性管唯一；只算出 f(0)·f(1) < 0 只能得一半分。

易错点
  • 等价替换只在乘除因子里成立。加减里替换会丢掉同阶项，sin x − x 换成 0 就必错；要先通分、提公因式或上泰勒。

例 1题目

求 limx→0 (1 − cos x) / (x sin x)。

解　分母 x·sin x 里 sin x ~ x，所以分母 ~ x²；
分子 1 − cos x ~ x²/2；
原式 = lim (x²/2)/x² = 1/2。

分子分母都是乘除结构，直接上等价无穷小；若写成 (1 − cos x)/(x·x) 再换，答案一样但更容易看清「谁是因子」。

例 2题目

求 limx→∞ (√(x² + x) − x)。

解　有理化：乘 (√(x² + x) + x)/(√(x² + x) + x)，
分子变成 (x² + x) − x² = x，
原式 = lim x/(√(x² + x) + x) = 1/(1 + 1) = 1/2。

根式相减一律先有理化；有理化后分子分母同除最高次幂，别停在中间那一步。

第一节 导数概念p.119 · 5 条
  1. 定义式f′(x₀) = limΔx→0 [f(x₀ + Δx) − f(x₀)]/Δx = limx→x₀ [f(x) − f(x₀)]/(x − x₀)。用定义求导时先写出这个式子再化简。
  2. 几何与物理意义切线斜率 k = f′(x₀)；瞬时速度 v = s′(t)；瞬时变化率。切线方程 y − f(x₀) = f′(x₀)(x − x₀)。
  3. 可导与连续可导 ⟹ 连续，连续 ⇏ 可导。反例：y = |x| 在 0 点连续但左右导数分别为 −1、1。
  4. 左右导数f′₋(x₀)、f′₊(x₀) 都存在且相等 ⟺ f′(x₀) 存在。分段点必须这样判。
  5. 用定义求分段点导数把 f(x₀)、f(x₀ + Δx) 代进真正的表达式（可能是分段里另一支），再取极限，不能直接用两侧的导函数代值。
练 1先自己做，再展开答案

设 f(x) = x2，用导数定义求 f′(2)，并写出曲线 y = x2 在点 (2, 4) 处的切线方程。

展开答案与解析

解　先算函数增量：Δy = f(2 + Δx) − f(2) = (2 + Δx)2 − 4 = 4Δx + (Δx)2；
再算差商并取极限：ΔyΔx = 4 + Δx，所以 f′(2) = limΔx→0 (4 + Δx) = 4；
切线斜率 k = f′(2) = 4，切线为 y − 4 = 4(x − 2)，即 y = 4x − 4。

定义法固定三步：写增量、算差商、取极限；Δx 没约掉之前不能令 Δx = 0。

展开答案与解析

第三节 高阶导数p.148 · 4 条
  1. 记号y″、y‴、y(n)；d²y/dx² 表示对 x 求两次导数，不是 (dy/dx)²。

第五节 函数的微分p.168 · 5 条
  1. 微分定义Δy = AΔx + o(Δx) 时称可微，dy = AΔx = f′(x)dx。一元函数可微 ⟺ 可导。
  2. 微分形式不变性dy = f′(u)du 无论 u 是自变量还是中间变量都成立，这是凑微分（换元积分）的理论依据。
  3. 微分公式与法则d(u ± v) = du ± dv；d(uv) = udv + vdu；d(u/v) = (vdu − udv)/v²。
  4. 近似计算f(x₀ + Δx) ≈ f(x₀) + f′(x₀)Δx；误差估计 |Δy| ≈ |f′(x₀)|·|Δx|。
  5. 用于求极限Δy = f(x₀ + Δx) − f(x₀) ≈ f′(x₀)Δx，可把「函数值之差」换成「导数乘增量」。
练 1先自己做，再展开答案

设 y = ln(1 + x2)，求 dy；并求 x = 1、Δx = 0.01 时 dy 的值。

展开答案与解析

解　先求导：y′ = 2x1 + x2；
所以 dy = y′dx = 2x1 + x2dx；
取 x = 1、dx = Δx = 0.01，得 dy = 1 × 0.01 = 0.01。

dx 与 Δx 在微分里取同一个值，但 dy 只是 Δy 的线性主部，二者相差 o(Δx)。

展开答案与解析

解　V = 43πr3，求微分得 dV = 4πr2dr；

相对误差 dVV = 3drr = 3 × 0.0510 = 1.5%。

  • 可导必连续，连续不一定可导。y = |x| 在 0 点连续但左右导数不相等。

  1. f(x) = x² sin(1/x)（x ≠ 0），f(0) = 0，求 f′(0)

  2. 参数方程 x = t − sin t, y = 1 − cos t，求 d²y/dx²

例 2题目

参数方程 x = t − sin t，y = 1 − cos t，求 d²y/dx²。

解　dy/dx = (dy/dt)/(dx/dt) = sin t/(1 − cos t)；

所以 d²y/dx² = [−1/(1 − cos t)] ÷ (1 − cos t) = −1/(1 − cos t)²。

第一节 中值定理p.187 · 5 条
  1. 费马引理若 f 在 x₀ 取极值且可导，则 f′(x₀) = 0。它是三大中值定理的证明工具。
  2. 罗尔定理f 在 [a,b] 连续、(a,b) 可导、f(a) = f(b) ⟹ ∃ξ ∈ (a,b)，f′(ξ) = 0。
  3. 拉格朗日定理f(b) − f(a) = f′(ξ)(b − a)。用于证明不等式、估计差值、证明「存在 ξ 使 …」。
  4. 柯西定理[f(b) − f(a)]/[g(b) − g(a)] = f′(ξ)/g′(ξ)（g′ ≠ 0）。两个函数「同一点」的导数比，是洛必达的理论来源。
  5. 做辅助函数要证 f′(ξ) + kf(ξ) = 0，就构造 F(x) = ekxf(x)；要证 ξf′(ξ) + f(ξ) = 0，构造 F(x) = xf(x)。看到 ξ 与 f 的组合先想这一步。
练 1先自己做，再展开答案

设 f(x) 在 [0,1] 上连续，在 (0,1) 内可导，且 f(0) = f(1) = 0。证明：存在 ξ ∈ (0,1)，使得 f′(ξ) + 2f(ξ) = 0。

展开答案与解析

解　第一步，构造辅助函数 F(x) = e2xf(x)，它在 [0,1] 上连续、在 (0,1) 内可导，且 F(0) = 0、F(1) = e2f(1) = 0，两端相等；
第二步，由罗尔定理，存在 ξ ∈ (0,1) 使 F′(ξ) = 0；
第三步，F′(x) = e2x[f′(x) + 2f(x)]，而 e2ξ 恒不为零，于是 f′(ξ) + 2f(ξ) = 0。

看到「f′ + k f」就先想 ekxf(x)：乘一个恒正的因子不改变零点，只把待证式凑成一个乘积的导数。

练 2先自己做，再展开答案

设 0 < a < b，证明：b − ab < lnba < b − aa。

展开答案与解析

解　第一步，取 f(x) = ln x，它在 [a,b] 上连续、在 (a,b) 内可导，由拉格朗日定理，存在 ξ ∈ (a,b) 使 ln b − ln a = b − aξ；
第二步，由 a < ξ < b 得 1b < 1ξ < 1a，两边同乘正数 b − a 得 b − ab < b − aξ < b − aa；
第三步，把中间的 (b − a)/ξ 换回 lnba，即得所证。

拉格朗日只告诉你 ξ 存在、不告诉你在哪，所以两边界的来源是「a < ξ < b」这个夹逼；想直接解出 ξ 是走不通的。

第二节 洛必达法则p.194 · 5 条
  1. 适用型只有 0/0 与 ∞/∞ 能直接用；用前必须先验证分子分母都趋于 0 或都趋于 ∞。
  2. 使用步骤求导一次 → 化简 → 判断是否仍是未定式，是则再用；一旦出现循环或越导越复杂，立刻换方法。
  3. 其他型的转化0·∞ 化成分式（把其中一个写进分母）；∞ − ∞ 先通分或提公因式；1∞、00、∞0 取对数化成 0·∞。
  4. 与等价替换配合先用等价无穷小把乘除因子换掉，再对剩下的部分用洛必达，计算量能减一半。
  5. 失效情形求导后极限不存在（如含 sin x、振荡项）时不能用洛必达下结论，改用夹逼或泰勒。
练 1先自己做，再展开答案

求 limx→0 ex − 1 − xx2。

展开答案与解析

解　第一步，x → 0 时分子、分母都趋于 0，是 0/0 型，且两函数在 0 的去心邻域内可导，可用洛必达；
第二步，求导一次得 ex − 12x，仍为 0/0 型，继续用；
第三步，再求导得 ex2，此时已不是未定式，直接代入 x = 0，极限为 12。

洛必达每用一次都要回头确认「现在还是未定式吗」；这题也能用 ex = 1 + x + x2/2 + o(x2) 一步出答案，两种方法都该会。

求 limx→+∞ x1/x。

展开答案与解析

第四节 函数的单调性与曲线的凹凸性p.209 · 4 条
  1. 单调判定在区间内 f′ > 0 ⟹ 严格单增；f′ < 0 ⟹ 严格单减。求单调区间的步骤：定义域 → 求 f′ → 找 f′ = 0 与不存在点 → 分区间判号。
  2. 凹凸判定f″ > 0 为凹（下凸，曲线在切线之上）；f″ < 0 为凸（上凸）；用的是二阶导的符号。
  3. 拐点凹凸性改变的点叫拐点，必须是 f″ 变号的点；f″ = 0 只是嫌疑，还要看两侧符号。拐点是曲线上的点，写成 (x₀, f(x₀))。
  4. 常见用途证明不等式（构造函数判单调）、比较大小、确定方程根的个数。
练 1先自己做，再展开答案

求 f(x) = x3 − 3x2 + 1 的单调区间、凹凸区间与拐点。

展开答案与解析

解　第一步，定义域为全体实数，f′(x) = 3x2 − 6x = 3x(x − 2)，令 f′ = 0 得 x = 0 与 x = 2；
第二步，分区间判号：x < 0 时 f′ > 0，0 < x < 2 时 f′ < 0，x > 2 时 f′ > 0，所以单增区间为 (−∞,0) 与 (2,+∞)，单减区间为 (0,2)；
第三步，f″(x) = 6x − 6，令 f″ = 0 得 x = 1；x < 1 时 f″ < 0（凸），x > 1 时 f″ > 0（凹），f″ 在 x = 1 两侧变号，故拐点在 x = 1；
第四步，f(1) = 1 − 3 + 1 = −1，拐点为 (1,−1)。

拐点是曲线上的点，必须写成坐标 (1,−1)，只答 x = 1 要扣分；f″ = 0 只是「嫌疑点」，还得验证两侧确实变号。

第五节 函数的极值和最值p.217 · 5 条
  1. 必要条件可导点取极值 ⟹ f′ = 0。所以极值只可能在驻点或不可导点，两者都要查。
  2. 第一充分条件f′ 在 x₀ 左正右负 ⟹ 极大；左负右正 ⟹ 极小；不变号 ⟹ 不是极值。
  3. 第二充分条件f′(x₀) = 0 且 f″(x₀) < 0 ⟹ 极大；f″(x₀) > 0 ⟹ 极小；f″(x₀) = 0 时失效，回到第一条件。
  4. 闭区间最值比较三类点：驻点、不可导点、两个端点，取最大最小，一个都不能漏。
  5. 应用题先写出目标函数与约束，化成单变量（用约束消元），再求导定最值；别忘了检查定义域端点与实际意义。
练 1先自己做，再展开答案

求 f(x) = x − 32x2/3 的极值。

展开答案与解析

解　第一步，定义域为全体实数，f′(x) = 1 − x−1/3 = x1/3 − 1x1/3：x = 1 时 f′ = 0 是驻点，x = 0 时 f′ 不存在但 f 连续，两类点都要查；
第二步，判号：x < 0 时 f′ > 0，0 < x < 1 时 f′ < 0，x > 1 时 f′ > 0，故在 x = 0 处左正右负，取极大值 f(0) = 0；
第三步，在 x = 1 处左负右正，取极小值 f(1) = 1 − 32 = −12（也可用第二充分条件：f″(x) = 13x−4/3，f″(1) = 13 > 0，故为极小）。

极值点未必是驻点：x = 0 处导数不存在，却是极大值点。只解 f′ = 0 会漏掉它，这是本题最大的坑。

练 2先自己做，再展开答案

求内接于半径为 R 的圆的矩形面积的最大值。

展开答案与解析

解　第一步，设矩形在第一象限的顶点为 (x,y)，则 x2 + y2 = R2（x,y > 0），面积 S = (2x)(2y) = 4xy；
第二步，由约束消元得 y = √(R2 − x2)，于是 S(x) = 4x√(R2 − x2)，0 < x < R；
第三步，S′(x) = 4(R2 − 2x2)√(R2 − x2)，令 S′ = 0 得 x = R√2，此时 y = R√2，矩形为正方形；
第四步，x 越过 R/√2 后 S′ 由正变负，故为最大值，Smax = 4 · R√2 · R√2 = 2R2。

应用题先把目标函数写成单变量再求导；最后要回代约束看实际意义（这里是正方形），别只报一个 R/√2 就结束。

  • 洛必达用一次要回头看是否还是未定式；若求导后振荡或变复杂（如 x→∞ 时的 sin x），立刻换方法。
  • f″ = 0 的点不一定是拐点，必须左右两侧 f″ 变号；反过来，f″ 不存在的点也可能是拐点。
  • 极值不能只看 f′ = 0。驻点不一定是极值（x³ 在 0），极值也可能出现在不可导点（|x| 在 0）。
  • 闭区间求最值：比较驻点、不可导点、两个端点的函数值，缺一不可。
  • 泰勒展开的阶要「够用」：分母是 xn 就展到 xn，少一阶结论就错。
综合提高（讲义每章末的题型）
  1. 证明 x > 0 时 ln(1 + x) < x
    思路：令 f(x) = x − ln(1+x)，f(0) = 0，f′(x) = x/(1+x) > 0，故 f 单调增 ⟹ f(x) > 0。也可用拉格朗日在 [0,x] 上做。
  2. 求 limx→0 (1/x² − 1/(x tan x))
    思路：先通分，再用 tan x = x + x³/3 + … 展开到 x³，或用等价无穷小 tan x − x ~ x³/3，答案 1/3。
  3. 求 f(x) = x³ − 3x 在 [−2, 2] 上的最值
    思路：f′ = 3x² − 3 = 0 ⟹ x = ±1；比较 f(±1) = ∓2 与端点 f(±2) = ±2，最大 2，最小 −2。

练 1先自己做，再展开答案

求 ∫ ( 3/x − 2/(1 + x²) + 5ex − 4 sin x )dx。

展开答案与解析

解　被积函数是四项之和，先用线性性质拆成四个积分、把常数提到积分号外：
原式 = 3∫dx/x − 2∫dx/(1 + x²) + 5∫exdx − 4∫sin x dx；
逐条查基本积分表：∫dx/x = ln|x|，∫dx/(1 + x²) = arctan x，∫exdx = ex，∫sin x dx = −cos x，代回并合并常数：
原式 = 3ln|x| − 2arctan x + 5ex + 4cos x + C。
验算：对结果求导得 3/x − 2/(1 + x²) + 5ex − 4 sin x，与被积函数完全一致。

四项积分各自会冒出一个常数，最后只写一个 C；∫dx/x 的结果是 ln|x| 而不是 ln x，因为 x < 0 时也要成立，这是最容易被扣的一分。

第二节 换元积分法p.252 · 6 条
  1. 第一类（凑微分）∫f(φ(x))φ′(x)dx = ∫f(u)du。关键是看出「谁的导数在旁边」，如 ∫x ex²dx、∫ln x/x dx。
  2. 常见凑法x dx = ½d(x²)；dx/x = d(ln x)；exdx = d(ex)；sec²x dx = d(tan x)；dx/√x = 2d(√x)。
  3. 第二类（换元）令 x = φ(t) 把根式或复杂结构换掉，积完再回代。三角代换是主力。
  4. 三种三角代换√(a² − x²) 用 x = a sin t；√(a² + x²) 用 x = a tan t；√(x² − a²) 用 x = a sec t。
  5. 回代技巧画一个直角三角形，把 sin t、cos t、tan t 直接读成 x 的表达式，比套反三角公式快。
  6. 倒代换分母次数高、形如 1/(x√(x² + 1)) 时令 x = 1/t 往往一步到位。
练 1先自己做，再展开答案

求 ∫ x²√(x³ + 1) dx。

展开答案与解析

解　看到 x²，就想到它是内层函数 x³ + 1 的导数差一个常数倍，用第一类换元（凑微分）：
由 d(x³ + 1) = 3x²dx 得 x²dx = 13d(x³ + 1)，于是令 u = x³ + 1，
原式 = 13∫√u du = 13 · 23u3/2 + C；
回代 u = x³ + 1，得 29(x³ + 1)3/2 + C。

凑微分的判据只有一句：被积函数里有没有「某个内层函数的导数」这个因子；系数必须配平，漏掉 1/3 就全错。

练 2先自己做，再展开答案

求 ∫ x²/√(1 − x²) dx。

展开答案与解析

解　被积函数含 √(1 − x²)，这是 √(a² − x²) 型，用正弦代换：
令 x = sin t，t ∈ (−π/2, π/2)，则 dx = cos t dt，且 √(1 − x²) = cos t（该区间上 cos t > 0，开方不必加绝对值）；
原式 = ∫ sin²t dt = ∫ (1 − cos 2t)/2 dt = t/2 − (sin 2t)/4 + C；
回代：t = arcsin x，sin 2t = 2 sin t cos t = 2x√(1 − x²)，故
原式 = 12arcsin x − 12x√(1 − x²) + C。

三角代换永远是「换元 → 积完 → 回代」三步；回代时画个直角三角形把 sin t、cos t 直接读成 x 的式子最快，而漏写 t 的范围就会在去根号时丢绝对值。

第三节 分部积分法p.280 · 5 条
  1. 公式∫u dv = uv − ∫v du。选 u 的原则：求导后变简单，v 容易求出。
  2. u 的选择顺序「反对幂指三」：反三角 → 对数 → 幂 → 指数 → 三角。排在前面的当 u。
  3. 循环型∫exsin x dx 这类两次分部后会回到原积分，移项解方程得结果。
  4. 只含对数/反三角把 dv 取成 dx，直接把 ln x、arctan x 当 u。
  5. 降次型∫xnexdx、∫xnsin x dx 反复分部，每次把幂次降一。
练 1先自己做，再展开答案

求 ∫ x ln x dx。

展开答案与解析

解　按「反对幂指三」，ln x 是对数、排在幂函数之前，所以取它作 u：
令 u = ln x，dv = x dx，则 du = dx/x，v = x²/2；
分部积分：原式 = (x²/2)ln x − ∫ (x²/2)·(1/x)dx = (x²/2)ln x − (1/2)∫x dx；
算出剩下的积分：原式 = (x²/2)ln x − x²/4 + C。

u 选错就原地打转：若取 u = x、dv = ln x dx，v 反而更难求。分部一次后剩下的积分立刻能算，就是选对了的信号。

练 2先自己做，再展开答案

求 ∫ ex sin x dx。

展开答案与解析

解　幂、指、三角混合且次数不再下降，属于循环型，记 I = ∫ ex sin x dx：
第一次分部，取 u = sin x，dv = exdx，得 I = ex sin x − ∫ ex cos x dx；
第二次分部仍把三角函数取作 u，得 ∫ ex cos x dx = ex cos x + ∫ ex sin x dx，代回：
I = ex sin x − ex cos x − I，移项得 2I = ex(sin x − cos x)，所以
I = 12ex(sin x − cos x) + C。

两次分部的 u 必须取同一类型（都取三角或都取指数），否则会绕回原式、得到恒等式；最后移项除以 2 之后再补 C。

第四节 有理函数的积分p.290 · 5 条
  1. 先看次数分子次数 ≥ 分母次数时先做多项式除法，拆成「多项式 + 真分式」，多项式部分直接积。
  2. 部分分式分解分母分解成一次因子与不可约二次因子的乘积；每个 (x − a)k 对应 A₁/(x−a) + … + Ak/(x−a)k。
  3. 对应的积分A/(x − a) → A ln|x − a|；(Ax + B)/(x² + px + q) → 配方后拆成 ln 与 arctan 两项。
  4. 可化为有理式含 √(ax + b) 的令 t = √(ax + b)；含 (ax + b)1/n 的令 t = (ax + b)1/n。
  5. 注意分解前必须确认分母已经分解到实系数不可约，否则系数解不出来。
练 1先自己做，再展开答案

求 ∫ (x² + 1)/(x(x − 1)) dx。

展开答案与解析

解　分子分母同为二次，先看次数：分子次数不小于分母，必须做多项式除法把它降成真分式。
除法：x² + 1 = (x² − x)·1 + (x + 1)，所以 (x² + 1)/(x(x − 1)) = 1 + (x + 1)/(x(x − 1))；
拆真分式：设 (x + 1)/(x(x − 1)) = Ax + Bx − 1，去分母得 x + 1 = A(x − 1) + Bx，令 x = 0 得 A = −1，令 x = 1 得 B = 2；
逐项积分：原式 = ∫dx − ∫dx/x + 2∫dx/(x − 1) = x − ln|x| + 2ln|x − 1| + C。

假分式不先除，直接设 A、B 去解系数永远解不出来；求 A、B 用「代特殊值」比展开比较系数快得多。

第一节 定积分的概念与性质p.314 · 5 条
  1. 定义分割 → 近似 → 求和 → 取极限：∫abf dx = limλ→0 Σ f(ξi)Δxi。几何意义是代数和（x 轴下方为负）。
  2. 可积条件闭区间上连续 ⟹ 可积；有有限个第一类间断点也仍可积。
  3. 基本性质线性、区间可加（∫ab = ∫ac + ∫cb）、保号性、估值（m(b−a) ≤ ∫ ≤ M(b−a)）。
  4. 积分中值定理f 连续 ⟹ ∃ξ ∈ [a,b]，∫abf dx = f(ξ)(b − a)，即「平均值 × 长度」。
  5. 和式极限转积分lim (1/n)Σf(k/n) = ∫01f(x)dx。识别标志：出现 1/n 与 k/n 的结构。
练 1先自己做，再展开答案

求极限 limn→∞( 1n + 1 + 1n + 2 + … + 12n )。

展开答案与解析

解　每一项都提出 1n 当 Δx：1n + k = 1n · 11 + k/n，于是原式 = limn→∞1nΣk=1n11 + k/n；
这是 f(x) = 11 + x 在 [0, 1] 上的和式极限，其中 Δx = 1/n、xk = k/n，所以它等于定积分 ∫01dx1 + x；
原函数是 ln(1 + x)，由牛顿-莱布尼茨公式 ∫01dx1 + x = ln 2 − ln 1 = ln 2，所以结果是 ln 2。

认和式极限只看两个特征：能不能凑出 1/n 当 Δx、k/n 当 x。分母是 n + k 时先把 1/n 提出来写成 1/(1 + k/n)，不提出来的话它既不是 Δx 也不是函数值。

练 2先自己做，再展开答案

设 I = ∫01 e−x² dx，证明 1e < I < 1，并证明存在 ξ ∈ (0, 1) 使 I = e−ξ²。

展开答案与解析

解　f(x) = e−x² 在 [0, 1] 上连续且单调递减，所以最小值 m = e−1 = 1e、最大值 M = e0 = 1；
由估值定理 m(b − a) ≤ ∫ab f dx ≤ M(b − a)，取 a = 0、b = 1 得 1e ≤ I ≤ 1；又 f 不是常数，两端等号都取不到，故 1e < I < 1；
由积分中值定理，存在 ξ ∈ [0, 1] 使 I = f(ξ)(1 − 0) = e−ξ²；而 f 严格递减、I 严格介于 1/e 与 1 之间，对应的 ξ 只能落在开区间内，即 ξ ∈ (0, 1)。

估值定理给的是「最小值 × 区间长」到「最大值 × 区间长」这个夹子，不是平均值；中值定理里的 ξ 就是让 f(ξ) 正好等于平均高度的那一点，先求出 f(ξ) 的范围才定得出 ξ 的范围。

第四节 反常积分p.343 · 5 条
  1. 两类反常无穷限（上限/下限为 ∞）与无界函数（瑕点在端点或内部），都用极限定义：先算正常积分再取极限。
  2. p-积分（无穷限）∫1∞dx/xp 收敛 ⟺ p > 1；p = 1 发散。
  3. p-积分（瑕点）∫01dx/xp 收敛 ⟺ p < 1；p = 1 发散。两个结论方向相反，别记混。
  4. 比较判别法非负函数与已知敛散性的 p-积分比：小于收敛者则收敛，大于发散者则发散；极限比较看同阶。

绕 x 轴旋转用垫圈法，外半径 R = x + 2，内半径 r = x²：

第一节 微分方程的基本概念p.379 · 4 条
  1. 阶方程中出现的最高阶导数的阶数。y″ + y = 0 是二阶。
  2. 通解与特解通解含与阶数相同个数的独立任意常数；由初始条件定出常数后得到特解。
  3. 线性与非线性未知函数及其各阶导数都是一次的叫线性；出现 y²、yy′、sin y 就是非线性。
  4. 积分曲线解 y = y(x) 是平面上的一条曲线，初始条件就是「过某点」。
练 1先自己做，再展开答案

判断方程 y″ + 4y = 0 是几阶、是否线性，并验证 y = C1cos 2x + C2sin 2x 是它的通解；再求满足 y(0) = 0、y′(0) = 2 的特解。

展开答案与解析

解　方程里最高阶的导数是 y″，所以是二阶方程；
未知函数和各阶导数都只以一次方出现（没有 y·y′、sin y 这类项），所以是二阶线性方程；
求导得 y′ = −2C1sin 2x + 2C2cos 2x，y″ = −4C1cos 2x − 4C2sin 2x = −4y，代回左边恒等于 0，且含两个独立常数（个数正好等于阶数），故它是通解；
代入初始条件：y(0) = C1 = 0，y′(0) = 2C2 = 2 得 C2 = 1，所以特解是 y = sin 2x。

认定「通解」只看两条：代进方程恒成立、独立常数的个数等于阶数。个数凑对了但常数不独立（比如写成 (C1 + C2)sin 2x），仍然不是通解。

第二节 可分离变量的微分方程p.383 · 4 条
  1. 标准形dy/dx = f(x)g(y)。把含 y 的移到一边、含 x 的移到另一边：dy/g(y) = f(x)dx。
  2. 求解步骤分离 → 两边积分 → 化简成显式或隐式解 → 有初始条件就代进去定 C。
  3. 丢解除以 g(y) 时，g(y) = 0 对应的常数解可能被丢掉，最后要单独检查并补上。
  4. 常见形式y′ = xy、y′ = ex+y、y′ = (1 + y²)/(1 + x²) 都属于这一类。
练 1先自己做，再展开答案

求可分离变量方程 y′ = ex+y 满足 y(0) = 0 的特解，并写出解成立的区间。

展开答案与解析

解　把右端拆开：y′ = ex·ey，两边同除 ey（它恒不为 0，不会丢解）得 e−ydy = exdx；
两边积分：−e−y = ex + C，常数只写一个；
代入 y(0) = 0：−1 = 1 + C，得 C = −2，即 e−y = 2 − ex；
取对数化成显式：y = −ln(2 − ex)，由 2 − ex > 0 得 x < ln 2。

除的是 ey 这种恒正的因子，所以不丢解；若除的是 y、1 − y 这类会取零的因子，必须单独检查被除式 = 0 对应的常数解。最后别忘了写出 x < ln 2 这个区间。

第三节 齐次方程p.387 · 4 条
  1. 识别能写成 dy/dx = φ(y/x) 的形状，即分子分母同次齐次。
  2. 代换令 u = y/x，则 y = ux，y′ = u + x·du/dx，方程化为可分离变量的 u 与 x。
  3. 回代解出 u 关于 x 的表达式后，把 u = y/x 代回，得到 y 与 x 的关系。
  4. 变体形如 dy/dx = (a₁x + b₁y + c₁)/(a₂x + b₂y + c₂) 时，先平移消去常数项再按齐次处理。
练 1先自己做，再展开答案

求齐次方程 y′ = x² + y²xy 满足 y(1) = 1 的特解。

展开答案与解析

解　分子分母都是二次齐次，令 u = y/x，即 y = ux，则 y′ = u + x·dudx，右端化为 (1 + u²)/u = 1u + u；
代回得 u + xu′ = 1u + u，即 xu′ = 1u，分离变量得 u du = dxx；
积分得 u²/2 = ln x + C1，即 u² = 2ln x + C；
回代 u = y/x 得 y² = 2x²ln x + Cx²，代入 y(1) = 1 定出 C = 1，所以 y² = x²(2ln x + 1)，即 y = x√(2ln x + 1)。

齐次方程的标志是「分子分母同次」，而不是「式子里有 y/x」；令 u = y/x 之后一定要记得 y′ = u + xu′ 里的 xu′ 那一项，丢掉它就退化成可分离变量了。

第四节 一阶线性微分方程p.394 · 5 条
  1. 标准形y′ + P(x)y = Q(x)。系数必须是 1，否则先除过去。
  2. 通解公式y = e−∫P dx[∫Q·e∫P dxdx + C]。背不住就用常数变易法现场推。
  3. 常数变易法先解齐次 y′ + Py = 0 得 y = Ce−∫P dx，再令 C = C(x) 代回原方程求 C(x)。
  4. 以 x 为未知函数遇到 y′ = 1/(x + y) 这类，把 x 看成 y 的函数改写 dx/dy + P(y)x = Q(y)，往往立刻变成线性。
  5. 伯努利方程y′ + P(x)y = Q(x)yn（n ≠ 0, 1），令 z = y1−n 化为一阶线性。
练 1先自己做，再展开答案

求一阶线性方程 y′ − 2xy = x ex² 的通解。

展开答案与解析

解　已是标准形 y′ + P(x)y = Q(x)，其中 P = −2x，Q = x ex²，故 ∫P dx = −x²，e−∫P dx = ex²；
套通解公式：y = ex²[ ∫ x ex²·e−x²dx + C ] = ex²[ ∫ x dx + C ]；
积分得 y = ( x²2 + C )ex²。

公式里乘在外面的因子是 e−∫P dx，被积的那一份才是 e∫P dx，两个别抄反。本题的 ex² 与 e−x² 正好抵消，是出题人故意凑的，不是巧合。

练 2先自己做，再展开答案

求方程 y′ = 1x + y 的通解（提示：把 x 看成 y 的函数）。

展开答案与解析

解　右端把 x、y 搅成一块，直接分离不了，两边取倒数得 dxdy = x + y，即 dxdy − x = y——这是以 x 为未知函数的一阶线性方程；
此时 P = −1，Q = y，∫P dy = −y，套公式 x = ey[ ∫ y e−ydy + C ]；
分部积分 ∫ y e−ydy = −(y + 1)e−y，所以 x = Cey − y − 1，即 x + y + 1 = Cey。

看到 y′ = 1/(x + y) 这种「y 被搅进分式」的题，别硬凑分离变量：把 x 当未知函数、两边取倒数，它立刻变成一阶线性。这是最常被漏掉的换元方向。

第五节 可降阶的高阶微分方程p.402 · 4 条
  1. y(n) = f(x)连续积分 n 次，每次加一个常数。
  2. 缺 y：y″ = f(x, y′)令 p = y′，则 y″ = dp/dx，方程降为一阶 p 与 x 的方程。
  3. 缺 x：y″ = f(y, y′)令 p = y′，则 y″ = p·dp/dy，方程降为一阶 p 与 y 的方程（自变量换成 y）。
  4. 怎么选看方程里缺谁：缺 y 用 p(x)，缺 x 用 p(y)。选错了会算不下去。
练 1先自己做，再展开答案

求可降阶方程 y″ = 2y³ 满足 y(0) = 1、y′(0) = 1 的特解。

展开答案与解析

解　方程里不显含 x，属「缺 x」型，令 y′ = p(y)，则 y″ = p·dpdy；
代入得 p·dpdy = 2y³，两边对 y 积分得 p² = y⁴ + C；
由 y(0) = 1、y′(0) = 1 得 1 = 1 + C，C = 0，于是 p² = y⁴；又 p(1) = 1 > 0，取 p = y²；
分离变量 dyy² = dx，积分得 −1y = x + C1，代入 y(0) = 1 得 C1 = −1，所以 y = 11 − x（x < 1）。

缺 x 时 y″ 要换成 p·dp/dy，写成 dp/dx 就降不下去；开方得 p = ±y² 时，符号由初值 y′(0) = 1 定，取反了答案会变成 y = 1/(1 + x)，代回原方程对不上初值。

第六节 高阶线性微分方程p.406 · 4 条

已知 y1 = x 是方程 y″ − 2xy′ + 2x²y = 0（x > 0）的一个解，求它的通解。

展开答案与解析

解　先验算：y1 = x 时 y1′ = 1，y1″ = 0，代入得 0 − 2x + 2x = 0，确实是解；
设 y = xu(x)，则 y′ = u + xu′，y″ = 2u′ + xu″，代入方程后含 u 的项全部抵消，只剩 xu″ = 0；
故 u″ = 0，u = C1 + C2x，回代得 y = C1x + C2x²；
再用朗斯基行列式确认线性无关：W = x·2x − 1·x² = x² ≠ 0，所以这确实是通解。

已知一个解求通解，标准做法是设 y = u(x)·y1 降阶，二阶降成一阶；直接猜出第二个解 x² 更快，但要验算并说明它与 y1 不成比例（W ≠ 0），否则只能算「一个解」。

求 y″ − 2y′ + y = ex 的通解。

求欧拉方程 x²y″ − 2xy′ + 2y = 0（x > 0）满足 y(1) = 1、y′(1) = 3 的特解。

展开答案与解析

解　令 x = et（t = ln x），由链式法则得 xy′ = dydt，x²y″ = d²ydt² − dydt；
代入原方程整理得 d²ydt² − 3dydt + 2y = 0，已是常系数齐次方程；

易错点
  • 先化标准形再套公式。y′ + P(x)y = Q(x) 里的系数必须是 1；否则 P、Q 都要先除。
  • 分离变量时除以含 y 的式子可能丢解。除完要单独检查被除式 = 0 是否为解。

第一节 向量及其线性运算p.001 · 4 条
  1. 坐标运算a = (a₁, a₂, a₃)：加减、数乘按分量算，全部是「对应分量各自运算」。
  2. 模与方向余弦|a| = √(a₁² + a₂² + a₃²)；cos α = a₁/|a|，cos β = a₂/|a|，cos γ = a₃/|a|，且 cos²α + cos²β + cos²γ = 1。
  3. 单位向量ea = a/|a|。把任何向量除以其模就得到同方向的单位向量。
  4. 定比分点M 分 AB 成 λ：OM = (OA + λOB)/(1 + λ)；中点 λ = 1。
练 1先自己做，再展开答案

已知点 A(1, −1, 2)、B(3, 2, 1)。(1) 求向量 AB 的模与三个方向余弦；(2) 求与 AB 同向的单位向量；(3) 求把 AB 分成 2 : 1（即 AM : MB = 2 : 1）的点 M 的坐标。

展开答案与解析

解　第一步，按分量作差：AB = (3 − 1, 2 + 1, 1 − 2) = (2, 3, −1)，于是 |AB| = √(2² + 3² + (−1)²) = √14；
第二步，方向余弦是各分量除以模：cos α = 2√14，cos β = 3√14，cos γ = −1√14，可验算 cos²α + cos²β + cos²γ = (4 + 9 + 1)/14 = 1，说明没算错；
第三步，单位向量 e = AB / |AB| = (2√14, 3√14, −1√14)；
第四步，定比分点取 λ = 2：OM = (OA + 2·OB)/(1 + 2) = ((1, −1, 2) + (6, 4, 2))/3 = (73, 1, 43)。

方向余弦的平方和恒为 1，写完立刻自检；定比分点的分母是 1 + λ，而 λ 是 AM : MB 的比值，若题目给的是 MB : AM 就要先取倒数。

第二节 数量积 向量积 混合积p.007 · 6 条
  1. 数量积a·b = |a||b|cos θ = a₁b₁ + a₂b₂ + a₃b₃，结果是数。a⊥b ⟺ a·b = 0。
  2. 向量积a×b 的结果是向量，方向由右手法则定，|a×b| = |a||b|sin θ = 平行四边形面积。
  3. 叉积的坐标式a×b = (a₂b₃ − a₃b₂, a₃b₁ − a₁b₃, a₁b₂ − a₂b₁)，用三阶行列式记最不容易错。
  4. 平行条件a∥b ⟺ a×b = 0 ⟺ 对应分量成比例。这是判断三点共线的利器。
  5. 混合积(a b c) = a·(b×c)，绝对值 = 平行六面体体积；三向量共面 ⟺ 混合积 = 0。
  6. 夹角公式cos θ = a·b/(|a||b|)；两向量夹角取 [0, π]。
练 1先自己做，再展开答案

已知 a = (1, 1, 2)，b = (2, −1, 1)。求 a·b、a×b、两向量的夹角 θ，以及以 a、b 为邻边的三角形的面积。

展开答案与解析

解　第一步，数量积按对应分量相乘再相加：a·b = 1×2 + 1×(−1) + 2×1 = 3；
第二步，|a| = √6，|b| = √6，故 cos θ = 3√6·√6 = 12，得 θ = π3；
第三步，叉积按坐标公式算：a×b = (1×1 − 2×(−1), 2×2 − 1×1, 1×(−1) − 1×2) = (3, 3, −3)；
第四步，|a×b| = √(9 + 9 + 9) = 3√3 是以 a、b 为邻边的平行四边形面积，三角形取一半，面积 = 3√32。

叉积的模是平行四边形面积，问三角形务必再除以 2；另外叉积不满足交换律，a×b 与 b×a 差一个负号。

练 2先自己做，再展开答案

已知三向量 a = (1, 2, −1)、b = (2, −1, 3)、c = (λ, 1, 1) 共面，求 λ 的值，并说明混合积的绝对值代表什么。

展开答案与解析

解　第一步，写出混合积 (a b c) = a·(b×c) 并按第一行展开：(a b c) = 1·(−1 − 3) − 2·(2 − 3λ) + (−1)·(2 + λ) = 5λ − 10；
第二步，三向量共面的充要条件是混合积为零，于是 5λ − 10 = 0，得 λ = 2；
第三步，|(a b c)| 等于以 a、b、c 为棱的平行六面体的体积；它为零就说明三个向量被压进同一张平面，也就是共面。

共面、行列式为零、平行六面体体积为零是同一件事；混合积对轮换不变号（a·(b×c) = b·(c×a)），但任意对调两个向量就要变号，展开时顺序别乱。

第三节 平面及其方程p.015 · 6 条
  1. 点法式过点 M₀(x₀,y₀,z₀)、法向量 n = (A,B,C)：A(x−x₀) + B(y−y₀) + C(z−z₀) = 0。
  2. 一般式Ax + By + Cz + D = 0，法向量就是 (A, B, C)，直接读出来。
  3. 截距式x/a + y/b + z/c = 1，三个截距一目了然，适合画图与求体积。
  4. 求平面方程的三条路① 已知一点 + 法向量；② 已知三点（两向量叉乘得法向量）；③ 已知一条直线与平面外一点。
  5. 点到平面距离d = |Ax₀ + By₀ + Cz₀ + D| / √(A² + B² + C²)。
  6. 两平面关系夹角用 |cos θ| = |n₁·n₂|/(|n₁||n₂|)（取锐角）；平行看 n₁∥n₂，垂直看 n₁·n₂ = 0。
练 1先自己做，再展开答案

求过三点 A(1, 0, 0)、B(0, 2, 0)、C(0, 0, 3) 的平面方程（写成截距式与一般式），并求原点到这个平面的距离。

展开答案与解析

解　第一步，用两条棱向量叉乘出法向量：AB = (−1, 2, 0)，AC = (−1, 0, 3)，n = AB×AC = (6, 3, 2)；
第二步，代点法式，取点 A：6(x − 1) + 3(y − 0) + 2(z − 0) = 0，整理得一般式 6x + 3y + 2z − 6 = 0；
第三步，因为三个截距 1、2、3 都不为零，可写成截距式 x1 + y2 + z3 = 1，与 A、B、C 的坐标一一对得上；
第四步，原点距离 d = |0 + 0 + 0 − 6|√(36 + 9 + 4) = 67。

三点求平面就两步——叉乘得法向量、代点法式；截距式只在三个截距都非零时成立，平面过原点时它直接失效，这时只能用一般式。

练 2先自己做，再展开答案

求过点 P(1, 2, 3) 且与平面 π: x − 2y + 2z + 5 = 0 平行的平面 π′ 的方程，并求 π 与 π′ 之间的距离；再求点 Q(2, 0, 1) 到 π 的距离。

展开答案与解析

解　第一步，平行就共用法向量 n = (1, −2, 2)，代点法式：(x − 1) − 2(y − 2) + 2(z − 3) = 0，即 x − 2y + 2z − 3 = 0；
第二步，|n| = √(1 + 4 + 4) = 3，两平行平面的距离 d = |−3 − 5|3 = 83；
第三步，点 Q 到 π 的距离 d = |2 − 0 + 2 + 5|3 = 93 = 3，所以为 3。

两平行平面求距离，必须先把两个方程的法向量系数化成完全相同，再用 |D₁ − D₂|/|n|；若系数不同（例如一个是 2x − 4y + 4z 形式），要先约分，否则算出来的不是真距离。

第四节 空间直线及其方程p.022 · 6 条
  1. 对称式(x − x₀)/m = (y − y₀)/n = (z − z₀)/p，方向向量 s = (m, n, p)。
  2. 参数式x = x₀ + mt, y = y₀ + nt, z = z₀ + pt，求交点时最好用这种。
  3. 一般式两个平面方程联立，方向向量 = 两法向量的叉乘。
  4. 线线角与线面角线线角用 |s₁·s₂|；线面角用 |s·n| 后取 arcsin（不是 arccos，别弄反）。
  5. 平行与垂直直线与平面：s·n = 0 平行，s∥n 垂直；两直线：s₁∥s₂ 平行，s₁·s₂ = 0 垂直。
  6. 距离点到直线距离 = |M₀M₁ × s|/|s|；异面直线距离 = |M₁M₂·(s₁×s₂)|/|s₁×s₂|。
练 1先自己做，再展开答案

把直线的一般式 L: x + y + z = 3，x − y = 1 化为对称式与参数式，并求 L 与平面 z = 0 的交点。

展开答案与解析

解　第一步，方向向量是两个法向量的叉乘：s = (1, 1, 1) × (1, −1, 0) = (1, 1, −2)；
第二步，令 y = 0 解方程组，得 x = 1、z = 2，取直线上一点 M₀(1, 0, 2)；
第三步，对称式 x − 11 = y1 = z − 2−2，参数式 x = 1 + t，y = t，z = 2 − 2t；
第四步，令 z = 0 得 t = 1，代回得交点 (2, 1, 0)，代入原方程组验证：2 + 1 + 0 = 3，2 − 1 = 1，成立。

一般式化对称式固定两步：叉乘得方向、令某个坐标为零解出一点；对称式的分子是 x − x₀，写 z − 2 时别把 −2 抄成 2。

练 2先自己做，再展开答案

求直线 L: x − 12 = y + 11 = z − 22 与平面 π: 2x − y + 2z = 3 的夹角 φ，并判断 L 与 π 的位置关系。

展开答案与解析

解　第一步，读出方向向量与法向量：s = (2, 1, 2)，|s| = 3；n = (2, −1, 2)，|n| = 3；
第二步，线面角满足 sin φ = |s·n||s||n| = |4 − 1 + 4|9 = 79，所以 φ = arcsin 79 ≈ 51.1°；
第三步，s·n = 7 ≠ 0 说明直线不平行于平面，再看 L 上的点 (1, −1, 2)：2 + 1 + 4 = 7 ≠ 3，点不在平面上，故 L 与 π 斜交于一点。

线与线用 arccos，线与面用 arcsin，两者相差 90°；这题若误用 arccos 会得到 38.9°，那其实是法向量与直线的夹角，不是线面角。

第五节 曲面及其方程p.032 · 6 条
  1. 柱面方程缺哪个字母，母线就平行于哪条轴：x² + y² = R² 是母线平行 z 轴的圆柱面。
  2. 旋转曲面把曲线方程里被旋转的那个变量换成 ±√(另两个变量的平方和)。例：y² = 2z 绕 z 轴转 ⟹ x² + y² = 2z。
  3. 椭球面x²/a² + y²/b² + z²/c² = 1，三个半轴 a、b、c，截痕都是椭圆。
  4. 抛物面z = x²/a² + y²/b² 是椭圆抛物面（碗）；z = y²/b² − x²/a² 是双曲抛物面（马鞍面）。
  5. 锥面与双曲面z² = x² + y² 是圆锥面；x²/a² + y²/b² − z²/c² = 1 是单叶双曲面，= −1 是双叶。
  6. 识别技巧看平方项的系数符号：三个正为椭球，两正一负为单叶双曲面，一正两负为双叶，缺一个为柱面/抛物面。
练 1先自己做，再展开答案

(1) 把 yOz 面上的曲线 y² = 2z 绕 z 轴旋转一周，求所得曲面方程并指出曲面类型；(2) 指出 x² + y² = 4 与 x²/4 + y²/9 = 1 各表示什么曲面。

展开答案与解析

解　第一步，绕 z 轴旋转时 z 不变，把被旋转的 y 换成 ±√(x² + y²)：(√(x² + y²))² = 2z，得 x² + y² = 2z；
第二步，它可写成 z = x² + y²2，是顶点在原点、开口朝 z 轴正向的 旋转抛物面；
第三步，x² + y² = 4 缺字母 z，母线平行于 z 轴，是 圆柱面（半径 2）；
第四步，x²/4 + y²/9 = 1 同样缺 z，是母线平行 z 轴的 椭圆柱面。

柱面只看「缺哪个字母」，母线就平行哪条轴；旋转面则看绕谁转——绕 z 轴才把 y 换成 √(x² + y²)，换成别的变量对就转错了轴。

练 2先自己做，再展开答案

判断下列方程各表示什么曲面：① x² + y²/4 − z²/9 = 1；② x² + y²/4 − z²/9 = −1；③ z = x²/4 − y²/9；④ x² + y² − z² = 0。

展开答案与解析

解　第一步，① 三个平方项系数两正一负、右端为 1，是 单叶双曲面（腰在 z 轴方向上张开）；
第二步，② 把负号项移到右边看，实质是「一正两负且右端为 1」，是 双叶双曲面，两张叶分别在上、下两侧；
第三步，③ 关于 z 是一次的、关于 x 与 y 是二次且符号相反，是 双曲抛物面（马鞍面）；
第四步，④ 移项得 x² + y² = z²，即 z = ±√(x² + y²)，是顶点在原点、半顶角 45° 的 圆锥面。

「两正一负」的符号法则只适用于三个平方项都齐、右端为非零常数的方程；③ 这种缺 z² 的一次方程是抛物面，④ 右端为 0 时退化成锥面，两者都不能套符号法则。

第六节 空间曲线及其方程p.040 · 4 条
  1. 参数方程x = x(t), y = y(t), z = z(t)，切向量是 (x′, y′, z′)。
  2. 一般式两个曲面方程联立，曲线是两张曲面的交线。
  3. 投影曲线投影到 xOy 面就消去 z，得到柱面方程，再与 z = 0 联立写出投影曲线。
  4. 投影柱面消去 z 后的方程就是投影柱面方程（不含 z，母线平行 z 轴）。
练 1先自己做，再展开答案

设曲线 Γ 是球面 x² + y² + z² = 9 与平面 x + z = 3 的交线。求 Γ 在 xOy 面上的投影柱面与投影曲线方程。

展开答案与解析

解　第一步，从平面方程解出 z = 3 − x，它就是消元的入口；
第二步，代入球面方程消去 z：x² + y² + (3 − x)² = 9，展开合并得 2x² + y² − 6x = 0，这个不含 z 的方程就是 投影柱面，母线平行于 z 轴；
第三步，配方看形状：2(x − 32)² + y² = 92，是椭圆柱面；
第四步，把它与 z = 0 联立，得投影曲线 2x² + y² − 6x = 0，z = 0，即 xOy 面上的一个椭圆。

投影到哪张坐标面就消哪个字母，得到的柱面方程一定不含该字母；写成投影曲线时必须再补上 z = 0，只交出一个椭圆方程那是柱面，不是平面曲线。

M4易错点与综合提高扣分常从这里开始

易错点
  • 叉积方向用右手法则，且 a×b = −b×a。算面积取模，算方向别弄反。
  • 平面的法向量由平面内两个不共线向量的叉积得到，别把两点连线当法向量。
  • 两平面夹角取锐角。用 |cos θ| 算，直接算可能得到钝角。
  • 投影曲线要消去一个变量：投影到 xOy 面就消 z，得到的是柱面方程而不是曲线方程。
综合提高（讲义每章末的题型）
  1. 求过三点 A(1,0,0)、B(0,1,0)、C(0,0,1) 的平面方程
    思路：两个方向向量叉乘得法向量 (1,1,1)，点法式得 x + y + z = 1。
  2. 判断直线 (x−1)/2 = y/1 = (z+1)/(−1) 与平面 x + y + 2z = 3 的位置关系
    思路：方向向量 s = (2,1,−1)，法向量 n = (1,1,2)，s·n = 3 ≠ 0 ⟹ 相交；再求交点。
  3. 求 z = x² + y² 与 z = 1 的交线在 xOy 面上的投影
    思路：交线为 x² + y² = 1, z = 1；投影到 xOy 面：x² + y² = 1（同时 z = 0）。

例 1题目

求过 A(1,0,0)、B(0,2,0)、C(0,0,3) 的平面方程。

解　截距式最快：x/1 + y/2 + z/3 = 1，即 6x + 3y + 2z = 6；
也可用 AB = (−1,2,0)、AC = (−1,0,3) 叉乘得法向量 (6,3,2)。

看到三个坐标轴上的截距就用截距式；一般式里的系数就是法向量，写完可以口算验一下点是否满足。

例 2题目

已知 a = (1,2,2)，b = (2,1,−2)，求以它们为邻边的平行四边形面积。

解　a × b = (2·(−2) − 2·1, 2·2 − 1·(−2), 1·1 − 2·2) = (−6, 6, −3)；
面积 = |a × b| = √(36 + 36 + 9) = 9。

叉积算完取模才是面积；另外 a·b = 0 说明两向量垂直，可用来快速验算。

第一节 多元函数的基本概念p.047 · 4 条
  1. 区域开区域、闭区域、有界区域；判断可导、连续、极值时都要先看定义域是不是开/闭。
  2. 二重极限P 以任意方式趋于 P₀ 时 f(P) 都趋于 A 才叫极限存在。只要找到两条不同路径极限不同，就能判定极限不存在。
  3. 连续的判定lim f(P) = f(P₀)。多元函数连续性的讨论大多落在分段函数的分界线上。
  4. 有界闭区域上的性质连续 ⟹ 有界、有最值（与一元闭区间定理对应）。
练 1先自己做，再展开答案

讨论二重极限 lim(x,y)→(0,0) xyx² + y² 是否存在。

展开答案与解析

解　先让点沿直线 y = kx 趋于原点，此时 f(x, kx) = kx²(1 + k²)x² = k1 + k²，极限值随 k 改变；
取 k = 1 得极限 12，取 k = 0（沿 x 轴）得极限 0，两条路径的结果不同；
所以这个二重极限不存在。

二重极限要求点以任意方式趋于定点时结果都相同，找到两条路径不同就能否定；但只验证几条路径相同，不能证明极限存在。

第二节 偏导数p.056 · 4 条
  1. 定义fx(x₀,y₀) = limΔx→0[f(x₀+Δx, y₀) − f(x₀,y₀)]/Δx，对 x 求偏导时把 y 当常数。
  2. 几何意义fx 是曲面被平面 y = y₀ 截出的曲线在该点的切线斜率。
  3. 高阶偏导fxy 与 fyx 都连续时相等，考试中一般可以直接相等。
  4. 分段点的偏导分界线上求偏导必须用定义，不能对分段表达式直接求导代入。
练 1先自己做，再展开答案

设 f(x,y) = x³ − y³x² + y²（(x,y) ≠ (0,0)），补充定义 f(0,0) = 0，求 fx(0,0) 与 fy(0,0)。

展开答案与解析

解　原点是分段点，只能回到偏导数的定义：
fx(0,0) = limΔx→0 f(Δx, 0) − f(0,0)Δx = limΔx→0 ΔxΔx = 1；
fy(0,0) = limΔy→0 f(0, Δy) − f(0,0)Δy = limΔy→0 −ΔyΔy = −1。

分界线上求偏导必须用定义：先把另一个变量固定为 0，写差商再取极限；把 (0,0) 直接代进求导后的表达式是错的做法，那里表达式根本没有定义。

第三节 全微分p.063 · 5 条
  1. 定义Δz = AΔx + BΔy + o(ρ)（ρ = √(Δx² + Δy²)）时，dz = AΔx + BΔy，且 A = zx、B = zy。
  2. 可微的必要条件可微 ⟹ 偏导存在；可微 ⟹ 连续。反之都不成立。
  3. 可微的充分条件两个偏导数在点附近连续 ⟹ 可微。判可微最常用的就是这一条。
  4. 判定不可微考察 [Δz − (zxΔx + zyΔy)]/ρ 的极限，若不为 0 或不存在，则不可微。
  5. 三者关系偏导连续 ⟹ 可微 ⟹ (连续 且 偏导存在)，箭头都不能反向。
练 1先自己做，再展开答案

设 z = x²ey + y²，求全微分 dz，并写出在点 (1,0) 处的全微分。

展开答案与解析

解　先求两个偏导：zx = 2xey，zy = x²ey + 2y；
按 dz = zxdx + zydy 得 dz = 2xeydx + (x²ey + 2y)dy；
在点 (1,0)：zx = 2，zy = 1，所以 dz = 2dx + dy。

代入的是两个偏导在该点的值，不是 z(1,0) = 1；全微分里 dx、dy 要保留，不能合并成一个数。

练 2先自己做，再展开答案

设 f(x,y) = xy√(x² + y²)（(x,y) ≠ (0,0)），补充定义 f(0,0) = 0，判断 f 在原点是否可微。

展开答案与解析

解　先由定义求偏导：fx(0,0) = limΔx→0 f(Δx, 0) / Δx = 0，同理 fy(0,0) = 0；
记 ρ = √(Δx² + Δy²)，则 Δz = ΔxΔyρ，考察 Δz − (0·Δx + 0·Δy)ρ = ΔxΔyρ²；
沿 Δy = Δx 该比值为 12，不趋于 0，故 f 在原点不可微。

偏导存在只是可微的必要条件；判不可微就靠这个比值是否趋于 0，取一条特殊路径得到非零极限即可否定。

第四节 多元复合函数的求导法则p.068 · 4 条
  1. 链式法则z = f(u, v)，u = u(x, y)，v = v(x, y)：zx = fuux + fvvx。有几个中间变量就有几项相加。
  2. 画树状图先画变量依赖树，一条路径对应一个乘积项，所有路径相加——比背公式稳。
  3. 全导数中间变量都是一元函数时（如 z = f(u, v), u = u(t), v = v(t)），得到 dz/dt。
  4. 抽象函数f 没有具体表达式时，导数写成 f₁′、f₂′（对第 1、2 个位置求偏导），高阶还要注意 f₁₂′ 的下标顺序。
练 1先自己做，再展开答案

设 z = u² + uv，其中 u = x + 2y，v = x − y，求 zx、zy，并求在点 (1,1) 处的值。

展开答案与解析

解　先对中间变量求偏导：zu = 2u + v，zv = u；
按链式法则，每个中间变量贡献一项：zx = (2u + v)·1 + u·1 = 3u + v，zy = (2u + v)·2 + u·(−1) = 3u + 2v；
在 (1,1) 处 u = 3，v = 0，所以 zx = 9，zy = 9。

照树状图数项数：u、v 两条路径各一项；vy = −1 的负号最容易丢，丢了会算成 3u + 3v。

第五节 隐函数的求导公式p.074 · 4 条
  1. 一个方程F(x, y, z) = 0 ⟹ zx = −Fx/Fz，zy = −Fy/Fz（Fz ≠ 0）。
  2. 记忆方法分子是「把要求的那个变量当因变量」的偏导，分母是 Fz，前面带负号。
  3. 方程组F(x,y,u,v) = 0, G(x,y,u,v) = 0 用雅可比行列式：ux = −J(u,x)/J(u,v)，其余同理。
  4. 二阶偏导先求出一阶，再对结果继续求导，注意代入一阶结果并保持链式完整。
练 1先自己做，再展开答案

设 z = z(x,y) 由方程 z³ − 3xyz = a³ 确定（a 为常数，z² − xy ≠ 0），求 zx 与 zy。

展开答案与解析

解　令 F(x,y,z) = z³ − 3xyz − a³，则 Fx = −3yz，Fy = −3xz，Fz = 3z² − 3xy；
代入隐函数求导公式 zx = −Fx / Fz：zx = 3yz3(z² − xy) = yzz² − xy；
同理 zy = −Fy / Fz = xzz² − xy。

负号别丢：分子是 F 对 x 求偏导再冠以负号，分母永远是 Fz；套公式时 F 里的 z 当独立变量处理，若改成两边直接求偏导，则要记住 z 是 x、y 的函数，3xyz 得按乘积求导。

第六节 多元函数微分学在几何上的应用p.080 · 4 条
  1. 空间曲线的切线参数方程 x = x(t)… 在 t₀ 处切向量 (x′, y′, z′)；切线 (x−x₀)/x′ = (y−y₀)/y′ = (z−z₀)/z′。
  2. 法平面过该点、以切向量为法向量：x′(x − x₀) + y′(y − y₀) + z′(z − z₀) = 0。
  3. 曲面的切平面F(x,y,z) = 0 在 P₀ 的法向量是梯度 (Fx, Fy, Fz)；切平面 Fx(x−x₀) + Fy(y−y₀) + Fz(z−z₀) = 0。
  4. 法线方向向量就是梯度，写成对称式即可。z = f(x, y) 时法向量取 (−fx, −fy, 1)。
练 1先自己做，再展开答案

求曲面 z = x² + y² 在点 (1,2,5) 处的切平面方程与法线方程。

展开答案与解析

解　令 F(x,y,z) = x² + y² − z，则 Fx = 2x，Fy = 2y，Fz = −1，在点 (1,2,5) 得法向量 (2, 4, −1)；
切平面：2(x − 1) + 4(y − 2) − (z − 5) = 0，整理得 2x + 4y − z = 5；
法线：x − 12 = y − 24 = z − 5−1。

先验证点确实在曲面上（1 + 4 = 5）；写成 z = f(x,y) 时也可取法向量 (−fx, −fy, 1) = (−2, −4, 1)，与 (2,4,−1) 只差一个符号，别混用两个方向写同一道题。

第七节 方向导数与梯度p.087 · 4 条
  1. 方向导数∂f/∂l = fxcos α + fycos β + fzcos γ，其中 (cos α, cos β, cos γ) 是单位方向向量。
  2. 梯度grad f = (fx, fy, fz)，方向导数 = grad f · el。
  3. 两个结论梯度方向是函数增长最快的方向；梯度的模就是最大方向导数。
  4. 注意给的向量不是单位向量时，先除以模再用，否则结果会大一个倍数。
练 1先自己做，再展开答案

设 f(x,y) = x² + xy + y²，求它在点 P(1,1) 处沿方向 l = (1,2) 的方向导数，并指出函数增长最快的方向与最大方向导数。

展开答案与解析

解　梯度 grad f = (fx, fy) = (2x + y, x + 2y)，在 P 点为 (3, 3)；
l 不是单位向量，先单位化：|l| = √5，el = (1/√5, 2/√5)，故方向导数 = grad f · el = 3 + 6√5 = 9√5 / 5；
沿梯度方向 (1,1)/√2 增长最快，最大方向导数就是 |grad f| = 3√2。

方向必须单位化，直接拿 (1,2) 去点乘会得到 9，正好大了 √5 倍；另外梯度给出的是方向与最大变化率，不是某点的函数值。

第八节 多元函数的极值及其求法p.094 · 5 条
  1. 必要条件极值点（可微处）必是驻点：fx = fy = 0。
  2. 充分条件A = fxx，B = fxy，C = fyy：AC − B² > 0 时 A > 0 为极小、A < 0 为极大；AC − B² < 0 不是极值；= 0 需另判。
  3. 条件极值构造 L = f + λφ，解 Lx = Ly = Lλ = 0，得到可疑点后再比较函数值。
  4. 两个约束有两个约束就引入两个乘数 λ、μ：L = f + λφ + μψ。
  5. 有界闭区域最值比较区域内部的驻点值与边界上的最值（边界化为一元问题或用拉格朗日）。
练 1先自己做，再展开答案

求函数 f(x,y) = x³ + y³ − 3xy 的极值。

展开答案与解析

解　令 fx = 3x² − 3y = 0，fy = 3y² − 3x = 0，得 y = x² 且 x = y²，联立解得驻点 (0,0) 与 (1,1)；
二阶偏导 A = fxx = 6x，B = fxy = −3，C = fyy = 6y；
在 (0,0)：AC − B² = −9 < 0，不是极值；在 (1,1)：AC − B² = 27 > 0 且 A = 6 > 0，取极小值 f(1,1) = −1。

两个驻点方程要联立，只解其中一个会漏点；AC − B² = 0 的情形判别法失效，需要另用定义或高阶项讨论。

练 2先自己做，再展开答案

求 f(x,y,z) = x + 2y + 3z 在球面 x² + y² + z² = 1 上的最大值与最小值。

展开答案与解析

解　构造拉格朗日函数 L = x + 2y + 3z + λ(x² + y² + z² − 1)，令 Lx = 1 + 2λx = 0、Ly = 2 + 2λy = 0、Lz = 3 + 2λz = 0；
三式说明 x : y : z = 1 : 2 : 3，设 x = t，y = 2t，z = 3t，回代约束得 14t² = 1，t = ±1/√14；
比较两点函数值：最大值为 √14，在 (1,2,3)/√14 处取到；最小值为 −√14，在反方向取到。

乘数法解出的可疑点必须回代约束方程，否则得到的是空间里的点而不是球面上的点；两个候选点都要算函数值再比较。

第九节 二元函数的泰勒公式p.102 · 3 条
  1. 形式f(x₀+h, y₀+k) = f + (h∂x + k∂y)f + ½(h∂x + k∂y)²f + …，按算子展开最省事。
  2. 用途近似计算与极值的高阶判别（AC − B² = 0 时用三阶、四阶项判断）。
  3. 一阶近似f(x₀+h, y₀+k) ≈ f(x₀,y₀) + fxh + fyk，就是全微分。
练 1先自己做，再展开答案

将 f(x,y) = ln(1 + x + y) 在点 (0,0) 处展开到二阶，并写出皮亚诺余项。

展开答案与解析

解　把 x + y 看成一个整体 u，用一元展开 ln(1 + u) = u − u²2 + o(u²)（u → 0）；
代入 u = x + y，u² = x² + 2xy + y²，且 ρ → 0 时 u → 0、u² 与 ρ² 同阶，所以 o(u²) 可写成 o(ρ²)；
故 f(x,y) = x + y − ½(x² + 2xy + y²) + o(ρ²)，其中 ρ = √(x² + y²)。

交叉项 2xy 不能漏：二阶项是 ½(h∂x + k∂y)²f，展开后 2hk·fxy 这一项总在；只分别按 x、y 展开一元式子就会把它丢掉。

M4易错点与综合提高扣分常从这里开始

易错点
  • 偏导存在 ≠ 连续 ≠ 可微。这三者的关系是一元的升级版，反例都出在分段函数上，考试就爱考这个。
  • 链式法则别漏项。先画变量依赖树：有几个中间变量就有几项相加。
  • 隐函数求导公式的分母是 Fz：zx = −Fx/Fz，zy = −Fy/Fz，负号别丢。
  • 条件极值必须同时解约束方程，只解 L 的偏导等于 0 得到的点可能不在约束曲面上。
  • 方向导数要求射线方向单位化。给的是向量 (a, b) 时先除以模。
综合提高（讲义每章末的题型）
  1. z = f(x² − y², exy)，求 zx
    思路：设 u = x²−y², v = exy：zx = fu·2x + fv·yexy。先写树状图再套，不会漏项。
  2. 判断 f(x,y) = xy/√(x²+y²)（原点补充定义为 0）在原点是否可微
    思路：偏导都为 0；考察 Δz 与 √(Δx²+Δy²) 的比，极限不为 0 ⟹ 不可微。
  3. 求原点到曲面 x² + y² + z² = 1 上一点距离的最大最小值（即求该点到平面 x + y + z = 0 的最值）
    思路：用拉格朗日乘数法设 L = (距离)² + λ(约束)，解方程组后比较各点函数值。

M5例题精讲先盖住解自己做，再对答案

例 1题目

z = x²y + y³，求 dz，并写出在点 (1,1) 处的全微分。

解　zx = 2xy，zy = x² + 3y²；
dz = 2xy dx + (x² + 3y²)dy；
在 (1,1)：dz = 2dx + 4dy。

全微分就是把两个偏导当系数；求某点的值时代入的是偏导，不是 z 本身。

例 2题目

求 z = x² + y² 在约束 x + y = 1 下的最小值。

解　构造 L = x² + y² + λ(x + y − 1)；
Lx = 2x + λ = 0，Ly = 2y + λ = 0 ⟹ x = y；
代入约束得 x = y = 1/2，最小值 1/2。

解出 λ 后要和约束方程一起用；只解偏导方程得到的点可能根本不在约束曲面上。

第一节 二重积分的概念与性质p.109 · 4 条
  1. 定义分割、近似、求和、取极限；几何意义是曲顶柱体的体积（f ≥ 0 时）。
  2. 性质线性、区域可加、保号、估值（mS ≤ ∬f ≤ MS）、中值定理（∬f = f(ξ,η)·S）。
  3. 比较大小同一区域上 f ≤ g ⟹ ∬f ≤ ∬g；被积函数含 sin、cos 时常用这个。
  4. 对称性区域关于 x 轴对称且 f 关于 y 为奇 ⟹ 积分为 0；关于 y 轴对称同理看 x 的奇偶性。
练 1先自己做，再展开答案

设 D = {(x, y) | x2 + y2 ≤ 4}，计算 ∬D(x3 + sin y + 3)dxdy。

展开答案与解析

解　D 关于 y 轴对称，而 x3 关于 x 为奇函数，故 ∬Dx3dxdy = 0；
D 关于 x 轴对称，而 sin y 关于 y 为奇函数，故 ∬Dsin y dxdy = 0；
只剩常数项，∬D3dxdy = 3SD = 3 · 4π = 12π。
所以结果是 12π。

先按线性拆成三项，再逐项看奇偶性：两个方向要分别判断，x3 看 x 的奇偶、sin y 看 y 的奇偶，最后只剩区域面积乘以常数。

第二节 二重积分的计算法p.115 · 6 条
  1. X 型区域a ≤ x ≤ b，y₁(x) ≤ y ≤ y₂(x)：∬f = ∫abdx∫y₁y₂f dy。
  2. Y 型区域c ≤ y ≤ d，x₁(y) ≤ x ≤ x₂(y)：先对 x 积再对 y 积，次序反过来。
  3. 交换次序必须重画区域：先由原上下限写出不等式，再换个方向描述；这是本章最高频的题型。
  4. 极坐标x = r cos θ, y = r sin θ，dxdy = r dr dθ（r 不能漏）；圆、扇形、环域优先用极坐标。
  5. 极坐标的限先定 θ 的范围（看区域张角），再对每个 θ 定 r 从哪到哪（从极点出发的射线穿入穿出）。
  6. 选坐标的原则被积函数含 x² + y² 或区域是圆 ⟹ 极坐标；其余用直角坐标。
练 1先自己做，再展开答案

展开答案与解析

解　内层 ∫ey²dy 不是初等积分，先把上下限翻译成区域：0 ≤ x ≤ 1，x ≤ y ≤ 1，重写成 0 ≤ y ≤ 1，0 ≤ x ≤ y；
交换次序后 原式 = ∫01dy∫0yey²dx = ∫01y ey²dy，内层对 x 积分把 ey² 当常数提出；
而 ∫y ey²dy = ½ey²，代入上下限得 ½(e − 1)。
所以结果是 e − 12。

交换次序必须先重画区域，不能把上下限直接对调；这里交换的目的就是让 ey² 先被对 x 的积分乘出 y，从而凑成可积的 y ey²。

第三节 三重积分p.138 · 6 条

第一节 对弧长的曲线积分p.166 · 4 条
  1. 定义与性质∫Lf ds，与方向无关（AB 与 BA 结果相同），可加性、线性。
  2. 参数化计算ds = √(x′² + y′²)dt，∫Lf ds = ∫αβf(x(t),y(t))√(x′²+y′²)dt，下限必须小于上限。
  3. 特殊形式y = y(x) 时 ds = √(1 + y′²)dx；极坐标 r = r(θ) 时 ds = √(r² + r′²)dθ。
  4. 物理意义线质量 m = ∫Lρ ds；质心、转动惯量都用它。
练 1先自己做，再展开答案

计算 ∫L √y ds，其中 L 是抛物线 y = x2 上从点 (0, 0) 到点 (1, 1) 的一段弧。

展开答案与解析

解　取 x 为参数：L 为 y = x2，x 从 0 到 1，y′ = 2x，故 ds = √(1 + 4x2) dx；
在 L 上 x ≥ 0，于是 √y = x，原式化为 ∫01 x√(1 + 4x2) dx；
令 u = 1 + 4x2，则 x dx = du / 8，原式 = 18∫15 u1/2 du = 112u3/2|15，所以结果是 5√5 − 112。

ds 里的 y′ 出现的是平方，ds 恒为正，这正是第一类曲线积分与方向无关的根源；另外把 √y 换成 x 时用到了 x ≥ 0，这一步别漏。

第二节 对坐标的曲线积分p.173 · 4 条
  1. 定义与方向∫LP dx + Q dy 与方向有关：反向走结果变号。
  2. 参数化∫LPdx + Qdy = ∫αβ[P x′(t) + Q y′(t)]dt，下限对应起点、上限对应终点。
  3. 闭合曲线沿闭曲线积分通常记 ∮，方向分正向（逆时针）与负向。
  4. 两类的关系∫Pdx + Qdy = ∫(P cos α + Q cos β)ds，其中 (cos α, cos β) 是切向量的方向余弦。
练 1先自己做，再展开答案

计算 ∫L (x + y) dx + (x − y) dy，其中 L 为抛物线 y = x2 上从点 O(0, 0) 到点 A(1, 1) 的一段弧。

展开答案与解析

解　取 x 为参数，y = x2，dy = 2x dx；起点 O 对应 x = 0、终点 A 对应 x = 1，下限配起点、上限配终点；
代入公式：原式 = ∫01 [(x + x2) + (x − x2)·2x] dx = ∫01 (x + 3x2 − 2x3) dx；
逐项积分得 12 + 1 − 12 = 1，所以结果是 1。

第二类曲线积分有方向：若把 L 改成从 A 走到 O，只把上下限对调，结果就变成 −1；第一类曲线积分则不会有这种变化。

第三节 格林公式及其应用p.184 · 6 条
  1. 公式∮LPdx + Qdy = ∬D(∂Q/∂x − ∂P/∂y)dxdy，L 是 D 的正向边界。
  2. 三个条件L 是分段光滑的闭曲线、取正向（逆时针）、P、Q 在 D 上有一阶连续偏导。
  3. 不闭怎么办补一段直线段使其闭合，用格林算完再减去补线上的积分。
  4. 有奇点怎么办在奇点周围挖一个小圆（或用别的闭曲线），用多连通区域的格林公式，注意内边界取顺时针。
  5. 路径无关单连通区域内，∫Pdx + Qdy 与路径无关 ⟺ ∂P/∂y = ∂Q/∂x。
  6. 求原函数路径无关时可用折线路径（先水平后竖直）计算，得到 u(x, y) 使 du = Pdx + Qdy。
练 1先自己做，再展开答案

计算 ∮L (2x − y + 4) dx + (5y + 3x − 6) dy，其中 L 是以 (0, 0)、(3, 0)、(3, 2) 为顶点的三角形边界，取正向。

展开答案与解析

解　P = 2x − y + 4，Q = 5y + 3x − 6，二者都是多项式，在平面上有一阶连续偏导；L 分段光滑、闭、取正向，格林公式的三个条件齐备；
先算偏导差：∂Q∂x − ∂P∂y = 3 − (−1) = 4，是常数，于是 原式 = ∬D 4 dxdy；
D 为直角三角形，面积 = 12 × 3 × 2 = 3，故原式 = 4 × 3 = 12。

被积函数是常数时，二重积分就是「常数 × 面积」，考的是能不能把面积算对；若 L 的方向是顺时针，最后还要补一个负号。

练 2先自己做，再展开答案

计算 ∮L x dy − y dxx2 + y2，其中 L 为椭圆 4x2 + y2 = 1 的正向。

展开答案与解析

解　P = −yx2 + y2，Q = xx2 + y2，在原点处无定义，L 的内部含这个奇点，直接套格林公式是错的；
以原点为心作足够小的圆 C: x2 + y2 = ε2（取逆时针），在 L 与 C 围成的环形区域上 ∂Q∂x = ∂P∂y，由多连通区域的格林公式得 ∮L − ∮C = 0，即 ∮L = ∮C；
在 C 上取 x = εcosθ，y = εsinθ，则 x dy − y dx = ε2dθ，x2 + y2 = ε2，被积函数恰为 1，故原式 = ∫02π dθ = 2π。

偏导相等只在单连通区域上才等价于「环积分为 0」：闭曲线不套住原点结果是 0，一套住就是 2π；挖洞时内边界取顺时针，符号就藏在这一步。

第四节 曲线积分的应用p.195 · 3 条
  1. 功变力 F = (P, Q) 沿曲线做的功 W = ∫LPdx + Qdy。
  2. 环流量沿闭曲线的环流量 ∮Pdx + Qdy，物理上表示流场沿闭合路径的循环强度。
  3. 质心与转动惯量用第一类曲线积分：m = ∫ρds，x̄ = (1/m)∫xρds。
练 1先自己做，再展开答案

一段半圆弧 L: x2 + y2 = a2（a > 0，y ≥ 0），线密度 ρ = 1，求它的质量与质心。

展开答案与解析

解　质量 m = ∫L ρ ds = ∫L ds，就是半圆弧长，m = πa；
由关于 y 轴的对称性得 x̄ = 0，只需算 ∫L y ds = ∫0π a sinθ · a dθ = a2∫0π sinθ dθ = 2a2；
于是 ȳ = 1m∫L y ds = 2a2πa，所以质心是 (0, 2aπ)。

  • 格林公式要求闭曲线且取正向（逆时针）。顺时针要加负号；不闭要补线，算完再减掉补上的部分。

展开答案与解析

解　取 un = 1n ln n = f(n)，其中 f(x) = 1x ln x 在 [2, +∞) 上非负且单调递减，可用积分判别法；

第三节 任意项级数p.255 · 4 条
  1. 交错级数Σ(−1)nun（un > 0）：un 单调递减且 → 0 ⟹ 收敛（莱布尼茨判别法），且余项 |Rn| ≤ un+1。
  2. 绝对收敛Σ|un| 收敛 ⟹ Σun 必收敛，且称绝对收敛。
  3. 条件收敛Σun 收敛但 Σ|un| 发散，称条件收敛。典型：Σ(−1)n/n。
  4. 判敛流程先看通项是否 → 0；再判绝对值级数（用正项级数的方法）；绝对值发散再看是否交错、能否用莱布尼茨。

判断级数 Σn=1∞ (−1)n√n 是绝对收敛、条件收敛，还是发散。

展开答案与解析

解　先判绝对值级数：Σn=1∞ 1√n 是 p = 12 ≤ 1 的 p-级数，发散，所以不绝对收敛；
再判原级数：un = 1√n 单调递减且趋于 0，由莱布尼茨判别法，交错级数收敛；
所以原级数 条件收敛。

顺序不能反：先算绝对值级数（用正项级数那一套），绝对值发散后再回头用莱布尼茨。如果绝对值级数本身就收敛，直接答绝对收敛，不必再看交错。

第四节 幂级数p.262 · 5 条
  1. 收敛半径R = lim|an/an+1|（或 R = 1/lim n√|an|）；在 |x| < R 内绝对收敛，|x| > R 发散。
  2. 收敛域先求 R 得开区间，再把两个端点分别代入化回常数项级数判敛，最后写收敛域。
  3. 端点必查这是幂级数题最固定的送分点：漏判端点就少一半分。
  4. 性质收敛区间内可逐项求导、逐项积分，收敛半径不变（端点可能变）。
  5. 缺项幂级数Σanx2n 这类不能直接套公式，要令 t = x² 或直接用比值法对整项求极限。
练 1先自己做，再展开答案

求幂级数 Σn=1∞ (x − 1)nn · 2n 的收敛域。

展开答案与解析

解　系数 an = 1n · 2n，由 R = limn→∞ |anan+1| 得 R = limn→∞ (n+1) · 2n+1n · 2n = 2；
由 |x − 1| < 2 得开区间 −1 < x < 3；
端点 x = 3：级数为 Σ 1n，调和级数发散；端点 x = −1：级数为 Σ (−1)nn，交错级数收敛；
所以收敛域为 [−1, 3)。

端点必须分别代入：两个端点常常一敛一散，写成一个区间就是错。注意 R 是相对中心 x = 1 而言的，区间要平移回去。

练 2先自己做，再展开答案

求幂级数 Σn=1∞ n x2n 的收敛域。

展开答案与解析

解　这是缺项幂级数（x 的幂次全为偶数），把整项记为 un，直接对整项求比值：
|un+1un| = (n+1) x2n+2n x2n = (1 + 1n) x2 → x2；
当 x2 < 1 即 |x| < 1 时绝对收敛，|x| > 1 时发散，故 R = 1；
端点 x = ±1：级数化为 Σ n，通项不趋于 0，发散；
所以收敛域为 (−1, 1)。

缺项时不能直接套 R = lim |an/an+1|，因为系数里有一半是 0；要么对整项求比值，要么令 t = x2 化成标准幂级数，最后再把 t 换回 x。

第五节 函数展开成幂级数p.272 · 5 条

  2. 间接法利用已知展开式做代换、四则运算、逐项求导或积分。考试九成用间接法。
  3. 常用展开1/(1 − x) = Σxn；ex、sin x、cos x、ln(1 + x)、(1 + x)α 五条要脱口而出。

练 2先自己做，再展开答案

把 ln(1 + x) 展开成 x 的幂级数（用间接法），并说明两个端点的收敛情况。

展开答案与解析

解　由 11 + x = Σn=0∞ (−1)n xn（|x| < 1），在收敛区间内可以逐项积分；
两边从 0 到 x 积分：ln(1 + x) = Σn=0∞ (−1)n xn+1n + 1 = Σn=1∞ (−1)n−1 xnn；
端点 x = 1：得交错级数 Σ (−1)n−1n，收敛；端点 x = −1：得 −Σ 1n，发散；
所以 ln(1 + x) = Σn=1∞ (−1)n−1 xnn，−1 < x ≤ 1。

积分下限取 0，是为了让常数项恰好等于 ln 1 = 0；逐项积分后收敛域可能扩大，端点一定要单独代回原级数判一次。

第六节 幂级数的应用p.280 · 4 条
  1. 求和函数常用套路：先求收敛域 → 逐项求导或积分凑成几何级数 → 求和 → 再积分/求导还原。
  2. 逐项求导的典型Σn xn = x/(1 − x)²，来自对 Σxn 求导再乘 x。
  3. 近似计算取前几项算近似值，误差用余项（莱布尼茨型或拉格朗日余项）估计。
  4. 微分方程的幂级数解设 y = Σanxn 代入方程比较系数，适合变系数方程。

求幂级数 Σn=1∞ n xn 的和函数 S(x)，并写出它的收敛域。

展开答案与解析

解　先求收敛域：R = limn→∞ |nn+1| = 1，端点 x = ±1 时通项分别为 n 与 (−1)nn，都不趋于 0，发散，故收敛域为 (−1, 1)；
在 (−1, 1) 内由几何级数 Σn=0∞ xn = 11 − x，两边逐项求导得 Σn=1∞ n xn−1 = 1(1 − x)2；

第七节 傅里叶级数p.285 · 6 条
  1. 狄利克雷条件周期为 2π 的函数在一个周期内连续或只有有限个第一类间断点、且只有有限个极值点 ⟹ 可展成傅里叶级数。
  2. 系数公式a₀ = (1/π)∫−ππf dx；an = (1/π)∫−ππf cos nx dx；bn = (1/π)∫−ππf sin nx dx。
  3. 和函数的值连续点处等于 f(x)；间断点处等于左右极限的平均值 [f(x⁻) + f(x⁺)]/2。
  4. 奇偶简化奇函数只含 sin 项（bn），偶函数只含 cos 项（an），能省一半积分。
  5. 正弦级数与余弦级数定义在 (0, π) 上的函数做奇延拓得正弦级数，做偶延拓得余弦级数。

练 1先自己做，再展开答案

设 f(x) = x（−π < x < π），以 2π 为周期，求它的傅里叶级数。

展开答案与解析

解　f(x) = x 是奇函数，奇函数在对称区间上的积分为 0，故 a0 = 0，an = 0，只算 bn；
bn = 1π ∫−ππ x sin nx dx = 2π ∫0π x sin nx dx，分部积分得 ∫0π x sin nx dx = (−1)n+1 πn，所以 bn = 2(−1)n+1n；
所以 x = Σn=1∞ 2(−1)n+1n sin nx = 2(sin x − sin 2x2 + sin 3x3 − …)，−π < x < π。

奇函数直接用「只含 sin 项」省掉两个积分；注意 (−1)n+1 的符号别丢，它决定级数在 x 接近 π 时的振荡形状。

易错点
  • 通项趋于 0 只是收敛的必要条件。Σ1/n 通项 → 0 但发散，别拿它当判据。
  • 比值 / 根值法 ρ = 1 时失效，必须换比较法或积分判别法。
  • 幂级数的端点必须单独判。求出 |x| < R 只是开区间，端点代入后可能收敛也可能发散。
  • 求和函数时别忘写收敛域。和函数只在收敛域内成立。
  • 傅里叶系数公式里的 1/π 与区间长度有关：周期为 2l 时是 1/l，别照搬 1/π。
综合提高（讲义每章末的题型）
