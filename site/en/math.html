函数与极限上册 · 第 1 章

讲义 p.001–118　·　10 节　·　3 组公式　·　5 条易错

上册

整门课的地基。极限不是「算出来大概是几」，而是「任意小都能做到」——后面导数、积分、级数全是在这个定义上长出来的。这一章真正要练熟的是三件事：等价无穷小替换、两个重要极限、间断点分类。

M3易错点与综合提高扣分常从这里开始

易错点
  • 等价替换只在乘除因子里成立。加减里替换会丢掉同阶项，sin x − x 换成 0 就必错；要先通分、提公因式或上泰勒。
  • x→∞ 与 x→+∞ 不是一回事。根号里带平方、含 |x| 的式子两个方向结果往往不同，要分开算。
  • 分段点求极限必须左右都算。左右不相等 ⟹ 极限不存在，不能只代一侧的函数式。
  • 间断点先找可疑点：分母为零、无定义、分段接缝。再算左右极限定类型——左右都存在且相等是可去，不等是跳跃，有一个是 ∞ 就是无穷间断。
  • 1∞ 不能把底数当 1。它是不定式，必须凑 e；写成 elim u·v 是最快的路子。
综合提高（讲义每章末的题型）
  1. 递推数列 an+1 = √(2 + an)，a₁ = √2，证收敛并求极限
    思路：先证有界（数学归纳法 an < 2），再证单调（an+1 − an 的符号），单调有界 ⟹ 收敛；设极限为 A 代入递推式解 A² = 2 + A。
  2. 求 limx→∞ ((x²+1)/(x²−1))x²
    思路：标准 1∞：底数写成 1 + 2/(x²−1)，指数乘除凑 e，答案 e²。别用洛必达硬做。
  3. 证明方程 x = cos x 在 (0,1) 内有且仅有一个根
    思路：零点定理证存在：令 f(x) = x − cos x，f(0) < 0、f(1) > 0；再用 f′(x) = 1 + sin x > 0 证单调 ⟹ 唯一。

M3易错点与综合提高扣分常从这里开始

易错点
  • 可导必连续，连续不一定可导。y = |x| 在 0 点连续但左右导数不相等。
  • 分段点必须用定义（或左右导数）判断可导性，不能把两侧表达式求导后直接代入 —— 那只说明导函数在两侧的极限，不等于该点导数存在。
  • 参数方程的二阶导数要再除一次 φ′(t)：d²y/dx² = (d/dt)(ψ′/φ′) / φ′(t)，很多人只算到 (d/dt)(ψ′/φ′) 就结束。
  • 幂指函数 u(x)v(x) 用对数求导：先取 ln 再求导，或写成 ev ln u。
综合提高（讲义每章末的题型）
  1. f(x) = x² sin(1/x)（x ≠ 0），f(0) = 0，求 f′(0)
    思路：在 0 点只能用定义：[f(x) − f(0)]/x = x sin(1/x) → 0，故 f′(0) = 0；注意 f′ 在 0 点不连续，这是经典反例。
  2. 参数方程 x = t − sin t, y = 1 − cos t，求 d²y/dx²
    思路：dy/dx = sin t/(1 − cos t)；再对 t 求导后除 (1 − cos t)，化简得 −1/(1 − cos t)²。
  3. y = (sin x)x，求 y′
    思路：取对数 ln y = x ln sin x，两边求导：y′ = (sin x)x(ln sin x + x cot x)。

M3易错点与综合提高扣分常从这里开始

易错点
  • 洛必达前必须先确认型。不是 0/0 或 ∞/∞ 就不能用；0·∞、∞−∞ 要先化成分式，1∞、00、∞0 要先取对数。
  • 洛必达用一次要回头看是否还是未定式；若求导后振荡或变复杂（如 x→∞ 时的 sin x），立刻换方法。
  • f″ = 0 的点不一定是拐点，必须左右两侧 f″ 变号；反过来，f″ 不存在的点也可能是拐点。
  • 极值不能只看 f′ = 0。驻点不一定是极值（x³ 在 0），极值也可能出现在不可导点（|x| 在 0）。
  • 闭区间求最值：比较驻点、不可导点、两个端点的函数值，缺一不可。
  • 泰勒展开的阶要「够用」：分母是 xn 就展到 xn，少一阶结论就错。
综合提高（讲义每章末的题型）
  1. 证明 x > 0 时 ln(1 + x) < x
    思路：令 f(x) = x − ln(1+x)，f(0) = 0，f′(x) = x/(1+x) > 0，故 f 单调增 ⟹ f(x) > 0。也可用拉格朗日在 [0,x] 上做。
  2. 求 limx→0 (1/x² − 1/(x tan x))
    思路：先通分，再用 tan x = x + x³/3 + … 展开到 x³，或用等价无穷小 tan x − x ~ x³/3，答案 1/3。
  3. 求 f(x) = x³ − 3x 在 [−2, 2] 上的最值
    思路：f′ = 3x² − 3 = 0 ⟹ x = ±1；比较 f(±1) = ∓2 与端点 f(±2) = ±2，最大 2，最小 −2。

M2核心公式考试要能默写的那几条

∫ xα dx = xα+1α + 1 + C （α ≠ −1）；∫ dxx = ln|x| + C∫ dx1 + x² = arctan x + C；∫ dx√(1 − x²) = arcsin x + C∫ sec x dx = ln|sec x + tan x| + C；∫ tan x dx = −ln|cos x| + C∫ sec²x dx = tan x + C；∫ ex dx = ex + C

∫ u dv = uv − ∫ v du；u 的优先顺序：反三角 → 对数 → 幂 → 指数 → 三角遇到「只含 ln 或反三角」的，把 dv 取成 dx

M3易错点与综合提高扣分常从这里开始

易错点
  • 忘写 + C。不定积分的结果是函数族，漏 C 直接扣分。
  • 换元后必须回代。不定积分没有积分限可换，最后一定要把 t 换回 x。
  • 假分式先做多项式除法（分子次数 ≥ 分母次数），否则部分分式分解不成立。
  • 分部积分的 u 选错会越算越长。幂函数乘指数/三角取幂作 u，乘对数/反三角取对数/反三角作 u。
  • 1/(x² − a²) 这类要拆成部分分式，不能直接套 arctan 的公式（那是加号）。
综合提高（讲义每章末的题型）
  1. 求 ∫ dx/(x² + a²)
    思路：直接套表：= (1/a) arctan(x/a) + C。别漏 1/a。
  2. 求 ∫ √(a² − x²) dx
    思路：令 x = a sin t，化简得 a²∫cos²t dt，用半角公式降幂，再画三角形回代，结果 (a²/2)arcsin(x/a) + (x/2)√(a² − x²) + C。
  3. 求 ∫ x arctan x dx
    思路：反三角优先作 u：u = arctan x，dv = x dx；一次分部后化成有理函数再拆项。
  4. 求 ∫ dx/(x² − 3x + 2)
    思路：分母分解为 (x−1)(x−2)，拆成 1/(x−2) − 1/(x−1)，积分得 ln|x−2| − ln|x−1| + C。

    思路：极坐标：∫02πdθ ∫0a e−r² r dr = π(1 − e−a²)。
  3. 求上半球体 x² + y² + z² ≤ a², z ≥ 0 的质心（密度均匀）

曲线积分下册 · 第 11 章

讲义 p.166–202　·　4 节　·　2 组公式　·　4 条易错

下册

两类曲线积分：第一类对弧长（无方向），第二类对坐标（有方向）。格林公式把第二类曲线积分换成二重积分，是这一章的核心工具。

节（页码）必须会通常怎么考

第二节 对坐标的曲线积分p.173定义、方向性、参数化计算算做功型积分（注意方向）
第三节 格林公式及其应用p.184格林公式、使用条件、路径无关、全微分求积用格林公式；判断路径无关并求原函数
第四节 曲线积分的应用p.195质量、质心、功、环流量求功与环流量

M2核心公式考试要能默写的那几条

第一类：∫L f ds，ds = √(x′² + y′²) dt（无方向）第二类：∫L P dx + Q dy = ∫αβ [P x′(t) + Q y′(t)] dt（有方向）两类关系：∫ P dx + Q dy = ∫ (P cos α + Q cos β) ds
∮L P dx + Q dy = ∬∬D (∂Q∂x − ∂P∂y) dxdy条件：L 是分段光滑的**正向**闭曲线（逆时针），P、Q 在 D 上有一阶连续偏导路径无关（单连通区域内）⟺ ∂P∂y = ∂Q∂x

M3易错点与综合提高扣分常从这里开始

易错点
  • 第一类没有方向，第二类有方向。第二类沿反方向走，结果整体变号。
  • 格林公式要求闭曲线且取正向（逆时针）。顺时针要加负号；不闭要补线，算完再减掉补上的部分。
  • 有奇点要挖洞。P、Q 在区域内有奇点时，用小圆挖去，用多连通区域的格林公式。
  • 路径无关的前提是单连通区域（中间没有洞），否则偏导相等也不一定无关。
综合提高（讲义每章末的题型）
  1. 计算 ∮L (x² − y) dx + (y² + x) dy，L 为椭圆 x²/a² + y²/b² = 1 的正向
    思路：Qx − Py = 1 − (−1) = 2，格林公式得 2·(椭圆面积) = 2πab。
  2. 判断 (2xy) dx + (x²) dy 是否与路径无关，并求原函数
    思路：Py = 2x = Qx，在全平面（单连通）无关；原函数 u = x²y + C。
  3. 计算 ∫L (ex sin y − y) dx + (ex cos y − 1) dy，L 为上半圆周从 A 到 B
    思路：补一条直线段使成闭曲线，用格林公式算整体，再减去补线上的积分。

M3易错点与综合提高扣分常从这里开始

易错点
  • 侧与法向量方向必须统一。取上侧则 cos γ > 0，投影到 xOy 面取正号；取下侧取负号。
  • 高斯公式要求闭曲面 + 外侧。内侧要加负号；曲面不闭先补面（常补平面），再减。
  • 斯托克斯的方向与右手法则一致，方向搞反整题变号。
  • 投影时要判断该投到哪个坐标面。法向量与哪个轴夹角小，就往那个面投。

    思路：高斯公式：∭(1+1+1)dV = 3·(4/3)πa³ = 4πa³。
  2. 计算 ∮Σ x dydz + y dzdx + z dxdy，Σ 为上半球面 z = √(a²−x²−y²) 的上侧

    思路：取 Σ 为该平面被截出的三角形，旋度为 (1,1,1) 形式，化成二重积分算面积。
