第 5 章 · 字符串

Python 的 str 是不可变的 Unicode 码点序列——不是 char[]，不是字节数组。每一次"修改"都在造新对象，所以循环里用 + 拼字符串是 O(n²)；而每一次格式化都该用 f-string，它比 % 和 .format 都快且更短。

读完这一章你能做到

  • 熟练用 split / join / strip / replace / find 处理一行文本；
  • 说清 len(s) 数的是字符还是字节，并在读写文件时不踩编码坑；
  • 用 f-string 写出对齐、补零、千分位、百分比、进制、日期、调试输出；
  • 知道为什么循环里 s += x 慢，并改成 "".join(...)；
  • 区分"找不到"的两种 API：find 返回 -1，index 抛 ValueError。

5.1 字面量、转义与不可变性

四种写法：

>>> 'single', "double", 'contains "quote"'
('single', 'double', 'contains "quote"')
>>> "a" "b"          # 相邻字面量自动拼接（编译期完成）
'ab'
>>> r"C:\new\table"  # raw：反斜杠不当转义
'C:\\new\\table'
>>> """第一行
... 第二行"""
'第一行\n第二行'

常用转义：\n 换行、\t 制表、\\ 反斜杠本身、\'、\"、\0 空字符、\x41（十六进制字节）、\u4e2d（Unicode 码点，即"中"）。路径优先用 pathlib 或 /，别跟反斜杠搏斗（第 17 章）。

str 不可变，意味着：

>>> s = "abc"
>>> s.upper()
'ABC'
>>> s
'abc'
>>> try:
...     s[0] = "x"
... except TypeError as e:
...     print(type(e).__name__, e)
TypeError 'str' object does not support item assignment

所有"修改"类方法（upper、replace、strip、zfill…）都返回新串，原串不动。这和 C++ 的 std::string 完全不同——那边 s.append() 是原地改。

5.2 长度是字符，不是字节

>>> len("中文")
2
>>> len("中文".encode("utf-8"))
6
>>> "中文".encode("utf-8")
b'\xe4\xb8\xad\xe6\x96\x87'
  • len(str) = 码点个数（不是"看起来几个字"，emoji 组合字符可能算多个）；
  • len(s.encode("utf-8")) = 字节数，中文一个字 3 字节；
  • str 与 bytes 之间用 encode / decode 转换，不能直接相加（"a" + b"b" 报 TypeError）。
>>> b"abc".decode("utf-8")
'abc'
>>> try:
...     b"\xff".decode("utf-8")
... except UnicodeDecodeError as e:
...     print(type(e).__name__, e)
UnicodeDecodeError 'utf-8' codec can't decode byte 0xff in position 0: invalid start byte

这类报错 90% 来自"文件是 GBK，你按 UTF-8 读"。修法不是 try/except，而是找到正确的编码：中文 Windows 导出的 CSV 常见 encoding="gbk"，网页与代码一律 UTF-8。

5.3 常用方法分四组

组 方法 要点
清洗strip / lstrip / rstrip / replace不带参数时去所有空白（空格、\t、\n）；带参数时按字符集合逐个剥离，"xxhixx".strip("x") 得 'hi'
切分split / rsplit / splitlines / partition无参数 split() 按任意连续空白切且丢空串；split(",") 会保留空串；partition 总是返回三元组
查询find / rfind / index / count / startswith / endswith / infind 找不到返回 -1，index 抛 ValueError；startswith 可传 tuple 试多个前缀
变形upper / lower / capitalize / title / swapcase都是返回新串；title() 会把 "it's" 变成 "It'S"，别用于人名
排版zfill / center / ljust / rjust补零 zfill 会保留符号："-42".zfill(5) 得 '-0042'

判断"是不是数字"要分清：s.isdigit() 只认十进制数字字符，"１２".isdigit()（全角）也为真；"1.5".isdigit() 为假。要判断字符串能否转 int，最稳的是 try: int(s) except ValueError——这叫 EAFP（第 16 章）。

5.4 拼接：+ 为什么慢

str 不可变，所以 s = s + x 每次都要新建一个更长的串并复制全部旧内容。拼接 n 次总代价是 O(n²)：

第 1 次复制 1 个字符，第 2 次复制 2 个……第 n 次复制 n 个 → n(n+1)/2

10 万次 += 就是约 50 亿字符复制，妥妥 TLE。正确做法是收集到列表再一次 join（join 先算总长度，一次分配一次复制，O(n)）：

>>> parts = [str(i) for i in range(4)]
>>> "".join(parts)
'0123'
>>> "-".join(parts)
'0-1-2-3'
>>> "".join([])
''

同样的道理，构造大量行时用 "\n".join(lines)，别在循环里 print 十次（print 有 IO 开销，第 17 章会讲用 sys.stdout.write 或一次性 join）。

5.5 f-string：日常首选

格式说明符的完整语法是 {值:填充符 对齐 宽度 . 精度 类型}，记住高频的十来个就够：

写法 结果 用途
{x:.2f}3.14保留 2 位小数（四舍五入，不是银行家舍入）
{x:>6} {x:<6} {x:^6}右/左/居中，宽度 6表格对齐
{x:06d}000042编号补零（注意 0 是填充符的简写）
{x:,}1,234,567千分位
{x:.1%}25.6%百分比（自动乘 100 加 %）
{x:#x} {x:#b} {x:o}0xff 0b101 10进制
{x!r}'小明'带引号的 repr，调试看清类型
{x=}score=92.4567调试语法，连变量名一起打印（3.8+）
{x:>{w}}宽度取自变量列宽动态
{d:%Y-%m-%d}2024-01-05日期格式化

三个必知限制：

  1. f-string 的引号冲突：3.12 之前，f"{d["k"]}" 是非法的（同种引号嵌套），要写 f"{d['k']}"；3.12+ 放开了；
  2. f-string 不能在表达式里放反斜杠（3.12 起放宽），f"{'\n'.join(xs)}" 在旧版要拆成两步；
  3. f-string 在定义处就求值，不像模板那样延后——写日志时如果格式化开销大，用 logging 的 %s 惰性风格（第 21 章）。

f"{score:.2f}" 与 round(score, 2) 行为不同：格式化是"按显示精度四舍五入（half-even 一半）"，round 返回 float。判题输出一律用格式化，别用 round 再 print（round(2.5) 得 2，输出会错）。

5.8 练习

1.（清洗） 读一行形如 " 姓名 : 小明 , 分数 : 92 " 的文本，输出 ('小明', 92)。

验收：split(",") + split(":") + strip() + int()，输入里有多余空格也能正确解析。

2.（对齐表格） 给定 [("小明", 92.4567), ("张三", 8.5)]，输出两列左对齐、分数保留 2 位小数、总宽 20 字符的表格。

验收：两行的分数列右对齐且小数点对齐，姓名列左对齐。

3.（拼接性能） 写两个函数：by_plus(words) 用 += 拼接，by_join(words) 用 join，对 20000 个短词各跑一次，打印两个结果是否相等（不要打印耗时）。

验收：两者结果相等，并说明为什么 by_plus 的复杂度是 O(n²)。

4.（变式） 实现 truncate(s, n)：超过 n 个字符时截断并加 "…"，保证总长不超过 n；中文按字符算。

验收：truncate("abcdef", 4) == "abc…"、truncate("中文测试", 10) == "中文测试"、truncate("中文测试", 3) == "中文…"。

5.（挑战） 实现 word_count(text)：统计英文单词出现次数，返回按次数降序、次数相同按字母升序的列表，并处理大小写与标点。

验收：word_count("The cat, the CAT!") 得 [("the", 2), ("cat", 2)]（顺序：次数相同按字母序）。

5.9 小结

  1. str 不可变：所有方法是"返回新串"，按下标赋值必然 TypeError。
  2. len 数字符、encode 数字节，读写文件一律显式 encoding="utf-8"。
  3. 格式化用 f-string，拼接用 join；+= 在循环里是 O(n²)，是 TLE 的常见来源。
