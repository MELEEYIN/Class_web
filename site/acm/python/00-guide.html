0.3 两条路线

六周标准路线（每周 5 天，每天 1～2 小时）：每周一段 + 周末做该段练习的综合题。适合零基础与转语言。

三周速通路线（每天 2 章，只做每章前 3 道练习）：第 1 周 01～09，第 2 周 10～18，第 3 周 19～26。适合已有编程经验、要在项目里马上用的人。速通时不要跳过 03、06、10、18 四章——它们解释了 Python 与你原有语言差异最大的地方。

0.4 每一章怎么读

  1. 先读"本质"和"读完这章你能做到"（10 秒）。前者是一句话的模型，后者是验收标准。
  2. 手打代码，不要复制。pycon 块（>>> 开头）请逐行敲进 REPL，边敲边对输出——打错时的报错本身就是学习内容。
  3. 跑整段脚本。带 # 示例：examples/xxx.py 的块都是完整脚本，在 examples/ 下有同名文件，直接 python examples/xxx.py 就能复现文中的输出。
  4. 做完 5 道练习再看"小结"。练习分基础×3、变式×1、挑战×1，每题给了"验收"标准，能自己判断对错。
  5. 过一遍"易错点清单"，把不确定的条目记下来，下次写代码前回看。

每章的"与 C++ 的差别"表不是给你背的，是给你改习惯的。会 C++ 的人写 Python 最常见的错法，都是把 C++ 的语义搬过来——比如以为 b = a 会复制、以为 for 变量出了循环就没了、以为 is 是 ==。

0.5 环境准备（10 分钟）

  1. 装 Python 3.10 以上（本教程示例在 CPython 3.14 实测，标注了版本的新特性需要对应版本）。命令行执行：
python --version

应输出 Python 3.10.x 或更高。Windows 上如果提示找不到命令，装的时候要勾选 "Add python.exe to PATH"。

  1. 进交互式解释器试一行：
python -c "print(2 ** 100)"
  1. 建一个练习目录 + 虚拟环境（第 23 章详讲，现在先会用）：
mkdir py-learn
cd py-learn
python -m venv .venv

激活：Windows 用 .venv\Scripts\activate，macOS/Linux 用 source .venv/bin/activate。看到提示符前面出现 (.venv) 就对了。

  1. 建议装两个工具（可选，但强烈推荐）：
python -m pip install --upgrade pip
python -m pip install mypy pytest

mypy 配合第 20 章，pytest 配合第 24 章。

不要用 pip install，用 python -m pip install。裸 pip 可能指向另一个 Python，装完在当前的解释器里 import 不到——这是第 23 章的第一条坑。

0.6 卡住了怎么办

症状 先查哪一章
IndentationError / TabError02（缩进四种错误）
TypeError: can only concatenate str...05、26（无隐式转换）
'NoneType' object is not subscriptable03（函数没 return）
列表改一处全变了03、26（别名与浅拷贝）
函数结果一次比一次长10、26（可变默认参数）
UnboundLocalError14（LEGB）
UnicodeDecodeError / 乱码17（编码）
cannot import name ...19（循环导入）
程序卡住不动22（死锁/阻塞事件循环）、25（断点）
数据一大就慢25（剖析）、26（性能反模式）

排查顺序永远是三步：读 traceback 最后一行 → 定位自己写的那一帧 → 用最小可复现例子验证。第 25 章 25.1 节有完整的四步读法。

0.7 学完的标志

不用考试，用这五件事自测。能做到，说明这套内容真的学进去了：

  1. 给一段 50 行的陌生 Python 代码，能说出每行在做什么、哪些地方藏着可变对象共享的隐患。
  2. 让你写一个"读大文件、按字段分组统计、输出 JSON"的脚本，你会自然地用生成器逐行读、dict 分组、json.dump 写出，而不是全读进内存。
  3. 程序报错时，你先看 traceback 最后一行，而不是从头往下读。
  4. 设计一个函数签名时，你会主动用 * 分隔仅关键字参数，并给可变容器加 None 哨兵。
  5. 交付前，你会跑测试、过一遍第 26 章的自查表。
