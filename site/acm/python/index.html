这份教程怎么用

  • 按顺序读，别跳。后面章节默认你会前面那些语法，跳着看容易卡在「这个符号是什么意思」。
  • 每段代码都自己敲一遍。复制粘贴跑通 ≠ 学会了；手敲能立刻暴露拼写和缩进问题。
  • 卡住先看报错最后一行。Python 的报错信息写得比大多数语言都清楚，最后一行就是出错原因。
  • 每章末尾的自测题做完再走。做不出来就回看对应小节，比继续往下读省时间。
