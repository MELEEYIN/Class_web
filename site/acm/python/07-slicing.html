第 7 章 · 切片

切片 x[a:b:c] 描述的是一段半开区间 [a, b) 上"按下标序列取元素"的规则。它永远不报越界错，因为端点先被夹到合法范围里；而对 list 赋值时它又能改变长度——所以切片既是"取一段"，也是"批量改一段"。

  • 解释为什么 s[100] 报 IndexError 而 s[100:200] 只返回空串；

  • 说清 b = a[:] 是浅拷贝，内层对象仍然共享；
  • 用 slice() 给"魔法数字切片"起名字。

7.1 半开区间与省略端点

四条规则：

  1. [a:b) 左闭右开，len(s[a:b]) == max(0, b - a)（无步长时）；
  2. 省略端点：a 省略即 0，b 省略即 len，两边都省 [:] 是"整个副本"；
  3. 端点不检查合法性：s[0:100]、s[-100:2] 都不报错，端点被夹到 [0, len]；
  4. 单下标才严格：s[100] 抛 IndexError，因为那是在取一个具体元素。

这条"切片宽容、下标严格"的分工非常有用：写循环时用切片就不用判边界。

>>> s = "Python"
>>> s[1:3]
'yt'
>>> s[3:1]
''
>>> "abc"[::-1]
'cba'

注意 s[3:1] 不是 IndexError 而是空串——这对"区间可能倒挂"的代码是天然的安全网：s[i:j] 在 i >= j 时得 ''，不必特判。

7.2 负下标与负端点

负下标从右往左数，-1 是最后一个：

下标：   0    1    2    3    4    5
字符：   P    y    t    h    o    n
负下标：-6   -5   -4   -3   -2   -1
>>> s = "Python"
>>> s[-1], s[-6]
('n', 'P')
>>> s[-3:]
'hon'
>>> s[:-3]
'Pyt'
>>> s[-3:-1]
'ho'

要点：负下标只是"加上 len"的简写（s[-2] == s[len(s)-2]），不会越出 [0, len] 的夹取规则。所以 s[-100:2] 里 -100 被夹到 0，结果等于 s[0:2]。

7.3 步长：第三个参数

步长的语义是：从 a 开始，每次加 c，只要还在 b 那一侧就继续取。

  • c > 0：要求 a < b，否则空串；a 省略为 0，b 省略为 len；
  • c < 0：方向反过来，要求 a > b；a 省略时不是 0 而是 len-1，b 省略时不是 len 而是 -len-1（也就是一直取到开头）；
  • c == 0 抛 ValueError: slice step cannot be zero。

这就是 s[::-1] 能反转的原因：a 默认从最后一个开始，一路往左取到开头。

s[::-1] 是反转，s[:-1] 是"去掉最后一个"，s[-1:] 是"只要最后一个"。三者的区别在于有没有第二个冒号，别混。

"abc"[::-1] 是 Python 反转序列的惯用法，但它会新建一个对象（O(n) 复制）。如果你只是要倒序遍历，用 reversed(xs) 更好——它返回迭代器，不复制，且对 dict/set 也适用（第 15 章）。

7.4 切片赋值：list 的独门能力

写法 效果 长度限制
a[i:j] = seq用 seq 替换 [i, j)长度任意，可以变长变短
a[i:j:k] = seq逐位替换，步长版长度必须相等，否则 ValueError
a[i:j] = []删除一段—
del a[i:j] / del a[i:j:k]同上—
a[i:i] = [x]在 i 处插入—

只有 list 能切片赋值（str、tuple 不可变，bytes 也不行）。a[i:j] = "abc" 是合法的——右边只要是可迭代的就行，会把 "abc" 拆成 'a'、'b'、'c' 三个元素。

7.5 b = a[:] 是浅拷贝

切片总是新建一个容器对象，但只复制"引用"：

a      ──► [ ● , ● ]
             │    │
             ▼    ▼
           [1]   [2]     ← 内层列表只有一份
b = a[:] ──► [ ● , ● ]   ← 外层是新格表，指向同样的内层

所以 d[0].append(99) 会同时反映在 inner 和 d 上；要完全独立必须 copy.deepcopy（第 3 章已详述）。

切片拷贝 vs 其他拷贝写法：

>>> a = [1, 2]
>>> a[:] == a.copy() == list(a)
True
>>> a[:] is a
False

三者都是浅拷贝，选哪个都行；a.copy() 语义最直白，a[:] 最老派，list(a) 还能顺便把元组/生成器转成列表。

7.6 slice 对象：别写魔法数字

a[0:8] 里的 0:8 在语法上就是一个 slice(0, 8, None) 对象。显式构造它的价值是起名字、传参、复用：

>>> HEAD = slice(0, 4)
>>> "2024-05-01"[HEAD]
'2024'
>>> parts = {"year": slice(0, 4), "month": slice(5, 7)}
>>> d = "2024-05-01"
>>> d[parts["year"]], d[parts["month"]]
('2024', '05')

slice 是不可变对象，有 start / stop / step 三个属性；s.indices(len) 能把它换算成"夹取后的三元组"，写区间算法时很好用：

>>> slice(2, None).indices(5)
(2, 5, 1)
>>> slice(None, None, -1).indices(5)
(4, -1, -1)

最后一行最值得注意：C++ 的 string_view 是"零拷贝视图"，Python 的切片一定复制。所以对超长字符串做"反复切片找子串"时，Python 会有额外的复制开销——这时用 re 或 find 定位下标、只切一次。

7.9 练习

1.（基本切片） 输入形如 "2024-05-01" 的日期串，输出 2024、05、01 三段。

验收：只用切片，不用 split；再补一个用 split 的版本，确认结果一致。

2.（反转与步长） 给定 nums = list(range(10))，输出：反转、偶数位、"从右往左每两个取一个"。

验收：第三项结果为 [9, 7, 5, 3, 1]。

3.（掐头去尾） 写 shrink(xs, n)：去掉首尾各 n 个元素；若 2n >= len(xs) 返回空序列（同类型）。

验收：shrink("abcdef", 2) == "cd"、shrink([1, 2], 5) == []，且不抛异常。

4.（变式） 用切片把 [1, 2, 3, 4, 5, 6] 变成 [6, 5, 1, 2, 3, 4]（把最后两个搬到最前），并写出通用的 rotate_right(xs, k)。

验收：rotate_right(list(range(5)), 2) == [3, 4, 0, 1, 2]；k 大于长度也能正确循环。

5.（挑战） 实现 chunk(xs, n)：把序列按每 n 个切成若干段，返回列表；最后一段可以不足 n。

验收：chunk([1, 2, 3, 4, 5], 2) 得 [[1, 2], [3, 4], [5]]；对字符串输入返回字符串列表，说明为什么最后一段不会越界。

7.10 小结

  1. [a:b) 半开区间，端点自动夹取，s[3:1] 是空串而不是错误。
  2. 步长为负就是反向，s[::-1] 反转；[:-1] 是另一个意思。
  3. 切片一定复制（浅拷贝），改内层仍会互相影响——要彻底独立用 deepcopy。
