1 · 入门篇

这 10 项的共性：它们不是「知识点」，而是思维动作。后面所有算法的代码都建立在它们的组合之上，务必练到不用想就能写。

1. 枚举

入门★暴力做例题 →

本质：把所有可能的答案候选一个个试过去。难点从来不是「枚举」，而是枚举什么与如何压缩枚举量。

复杂度：O(状态数 × 单次验证代价)。优化方向：换一个维度枚举（枚举答案而非枚举方案）、子集枚举、配合前缀和/哈希把验证降到 O(1)。

题单 洛谷 P1008 三连击 · P1036 选数 · P1157 组合的输出 · P1618 三连击（升级版）· P1706 全排列问题；CF 800~1000 分段题目。

资料 《算法竞赛入门经典（第 2 版）》第 1~2 章；OI-Wiki「枚举」。

2. 模拟

入门★实现做例题 →

本质：把题目描述直译成代码。它考察的是把自然语言规则无损翻译成状态机的能力，是「代码量失败」的主要来源。

要点：①写前先用文字/流程图把规则列全；②明确状态变量含义与初值；③时间推进类问题按「事件」跳跃而不是逐时刻模拟；④注意取模、边界、多测清空。

题单 洛谷 P1042 乒乓球 · P1563 玩具谜题 · P1067 多项式输出 · P1328 生活大爆炸版石头剪刀布 · P4924 魔法少女小Scarlet；CF 1100~1300 分模拟题。

资料 OI-Wiki「模拟」；Codeforces 上 Div.3 的 A/B 题基本都是高质量模拟训练。

3. 递归

入门★思维做例题 →

本质：把规模为 n 的问题化为规模更小的同类问题。三要素：参数含义（函数定义要写清）、边界条件、递推关系。递归是 DP、分治、搜索、树形结构的共同语言。

复杂度：由递归树节点数决定；不加记忆化常常指数级，加记忆化后转化为 DP。递归深度过大需改写成显式栈或增加栈空间。

题单 洛谷 P1255 数楼梯 · P1036 选数 · P1464 Function（记忆化）· P1028 数的计算 · P1228 地毯填补问题（分治式递归）。

资料 OI-Wiki「递归 & 分治」；《算法竞赛进阶指南》0x03 节。

4. 前缀和与差分

入门★★高频做例题 →

本质：前缀和把「区间求和」变成「两次单点查询」；差分把「区间修改」变成「两次单点修改」。二者互为逆运算，是离线区间操作的第一把钥匙。

复杂度：预处理 O(n)，单次询问/修改 O(1)。进阶延伸：二维差分、树上差分（点差分/边差分）、差分约束。

题单 洛谷 P1114 最大子段和变形 · P1387 最大正方形 · P1719 最大加权矩形 · P2367 语文成绩 · P3406 海底高铁 · P4231 三步必杀（二阶差分）· P3258 松鼠的新家（树上差分）。

资料 OI-Wiki「前缀和 & 差分」；AcWing「算法基础课」第一章。

5. 尺取法（双指针 / 滑动窗口）

入门★★高频做例题 →

本质：当「区间的可行性关于包含关系单调」时，右端点右移只会让左端点单调右移，于是两个指针总共走 O(n) 步。经典形态：同向双指针（最长/最短满足条件的子段）、相向双指针（有序数组两数之和）、快慢指针（链表）。

复杂度：O(n)（每个元素最多进出窗口一次）。前提必须验证单调性，否则不成立 —— 这也是最常见的误用。

题单 洛谷 P1638 逛画展 · P1147 连续自然数和 · P1381 单词背诵 · P3143 Diamond Collector（排序+双指针）· P3144 关闭农场？不作推荐，改：P2032 扫描（单调队列）；CF 1200~1600 双指针题；LeetCode 3、76、209、438。

资料 OI-Wiki「双指针」；《挑战程序设计竞赛》第 2 版「尺取法」一节。

6. 排序算法的原理理解

入门★★必背做例题 →

本质：排序是「用比较换信息」。真正要掌握的不是会写快排，而是：稳定性、是否原地、比较次数下界 O(n log n)、以及非比较排序（计数/基数/桶）何时能突破下界。

7. 二分与三分

入门★★★必背做例题 →

本质：二分 = 在单调的判定函数上找分界点。写对二分的唯一诀窍是明确「check(mid) 为真时答案落在哪一半」，然后让循环不变式保持不变。三分 = 在单峰/单谷函数上比较两侧导数。

复杂度：O(log n)，实数二分按精度迭代约 60~100 次即可达到 1e-15。二分答案的总复杂度是 O(log V × check)。

题单 洛谷 P2249 查找 · P1102 A-B 数对 · P1873 砍树 · P1182 数列分段 Section II · P2678 跳石头 · P1414 又是毕业季II · P3382 三分法 · P1024 一元三次方程求解；AcWing「二分」专题。

资料 OI-Wiki「二分」「三分」；《算法竞赛进阶指南》0x04 节。

8. 分治

入门★★思维做例题 →

本质：把问题切成互不相交的子问题分别求解再合并。复杂度由主定理给出：T(n) = aT(n/b) + f(n)。分治的难点在 merge，不在 divide。

复杂度：归并/快速排序 O(n log n)；快速幂 O(log n)；CDQ 分治 O(n log² n)。

题单 洛谷 P1908 逆序对 · P1010 幂次方 · P1228 地毯填补问题 · P1966 火柴排队（排序+逆序对）· P1429 平面最近点对（分治经典，也是计算几何入门）。

资料 OI-Wiki「递归 & 分治」「CDQ 分治」；《算法竞赛进阶指南》0x05 节。

9. 贪心

入门★★★思维做例题 →

本质：每步取局部最优，且能证明它不劣于任何最优解。常用的三种证明武器：交换论证（任意最优解可交换为我们的选择）、归纳法、反证 + 界。贪心没有通用模板，只有可证明的贪心才是贪心。

复杂度：通常 O(n log n)（因为多数贪心要排序或用堆）。

题单 洛谷 P1090 合并果子 · P1223 排队接水 · P1803 线段覆盖 · P5019 铺设道路 · P1080 国王游戏 · P1631 序列合并 · P1094 纪念品分组 · P4447 分组。

资料 OI-Wiki「贪心」；《算法竞赛进阶指南》0x07 节；《挑战程序设计竞赛》「贪心」一章。

10. 简单搜索（DFS / BFS）

入门★★★必背做例题 →

本质：搜索 = 枚举状态空间。DFS 用栈（递归）走到底再回头，适合求所有方案 / 判定存在性 / 需要维护路径；BFS 用队列逐层扩散，适合无权图最短路 / 最少步数 / 层序性质。核心是状态的表示 + 剪枝。

复杂度：O(状态数 × 转移代价)。剪枝（可行性剪枝、最优性剪枝、去重、启发式排序）是把指数级压到能过的唯一办法。

题单 洛谷 P1219 八皇后 · P1605 迷宫 · P1443 马的遍历 · P2404 自然数的拆分 · P1019 单词接龙 · P1032 字串变换 · P1379 八数码难题（BFS/双向 BFS/IDA*）。

资料 OI-Wiki「DFS（搜索）」「BFS（搜索）」；《算法竞赛进阶指南》0x21~0x25 节。

入门篇通关标准：能在 30 分钟内独立、无 Bug 地写出「二分答案 + check」「滑动窗口」「DFS 回溯 + 剪枝」「BFS 最短路」四个模板，并且知道每个算法在什么信号下被触发。

原文把基础篇分为数据结构、动态规划、图论、数学四个方向，这里沿用。注意：原文写「上述十二种数据结构」但实际列了 13 条，应为十三种（详见第 4 节勘误）。

2.1 基础数据结构（13 项）

这一层的关键不是「会用 STL」，而是知道每个数据结构在维护什么不变量。STL 只是实现，思想才是可迁移的。

1. 栈

基础★LIFO做例题 →

本质：后进先出。它维护的不变量是「最近未处理的元素」。凡是「最近相关性」的场景都在用它：括号匹配、表达式求值、DFS、单调栈、回溯撤销。

题单 洛谷 P1449 后缀表达式 · P1739 表达式括号匹配 · P1981 表达式求值 · P1044 栈（卡特兰数，栈的计数问题）。

资料 OI-Wiki「栈」；CP-Algorithms: Stack 相关章节。

2. 队列

基础★FIFO做例题 →

本质：先进先出，保证处理的「层次性」——这正是 BFS 能得到最短路的原因。双端队列 deque 允许两端进出，是单调队列和 0-1 BFS 的容器。

题单 洛谷 P1996 约瑟夫问题 · P1886 滑动窗口（单调队列）· P2952 牛的旅行？改：P1443 马的遍历（BFS 模板）。

资料 OI-Wiki「队列」「双端队列」。

3. 链表

基础★实现做例题 →

本质：用指针/下标把不连续的内存串起来，支持 O(1) 插入删除。竞赛里几乎不用 new，一律用数组模拟（静态链表）。

题单 洛谷 P1160 队列安排 · P1996 约瑟夫问题（可用链表）· P2280 装箱？改：P1540 机器翻译（队列模拟）。

资料 OI-Wiki「链表」；《算法竞赛进阶指南》0x13 节。

4. 堆 / 优先队列

基础★★高频做例题 →

本质：一棵满足「父 ≤ 子」的完全二叉树，用数组存储，支持 O(log n) 插入/删除、O(1) 取最值。竞赛中的堆多半是用来做「动态取最值 + 反悔」。

题单 洛谷 P3378 堆模板 · P1090 合并果子 · P1631 序列合并 · P2085 最小函数值 · P1168 中位数（对顶堆）· P1801 黑匣子。

资料 OI-Wiki「堆」；CP-Algorithms「Binary Heap」。

5. HASH 表

基础★★高频做例题 →

本质：用函数把「大值域」压到「小值域」，用 O(1) 期望时间做判重/查找。关键永远是冲突处理：开放寻址、拉链法，或者对字符串用「多项式哈希 + 双模数」把冲突概率压到可忽略。

题单 洛谷 P3370 字符串哈希 · P1102 A-B 数对（哈希优化）· P2580 于是他错误的点名开始了 · P3449? 改：CF 上多道「字符串哈希 + 二分 LCP」题。

资料 OI-Wiki「哈希」；《算法竞赛进阶指南》0x14 节。

6. 二叉树

基础★基础做例题 →

本质：二叉树是「分治的结构化表达」。要掌握的核心是三种遍历的关系：前序定根、中序分左右、后序定根；以及完全二叉树的数组编号（i 的孩子是 2i、2i+1）。

题单 洛谷 P1305 新二叉树 · P1030 求先序排列 · P1827 美国血统 · P1087 FBI树 · P4715 淘汰赛 · P4913 二叉树深度。

资料 OI-Wiki「二叉树 & 哈夫曼树」；《算法竞赛进阶指南》0x21 节。

7. Trie 树（字典树）

基础★★字符串做例题 →

本质：把字符串按字符逐层挂在树上，用「公共前缀」共享存储。它把「前缀匹配」从 O(len) 次哈希比较变成 O(len) 的树上走步，天然支持前缀查询、前缀计数。

题单 洛谷 P8306 Trie字符串统计 · P2580 于是他错误的点名开始了 · P4551 最长异或路径（01-Trie 上的树形 DP）· P4735 最大异或和（可持久化 01-Trie）。

资料 OI-Wiki「字典树 (Trie)」；CP-Algorithms「Trie」。

8. set 和 map 的用法

基础★★STL相关练习 →

本质：set/map 是基于红黑树的有序容器，提供 O(log n) 的插入、删除、查找，以及前驱/后继（这是数组做不到的）。unordered_* 是哈希表，O(1) 期望但无序。

题单 洛谷 P1097 统计数字 · P3879 阅读理解（map）· P2234 营业额统计（set 前驱后继）· P5250 木材仓库 · CF 上的「set 维护区间」题。

资料 cppreference「std::set / std::map」；OI-Wiki「STL 容器」。

9. 并查集

基础★★★必背做例题 →

本质：维护「等价关系」的划分。两个优化缺一不可：路径压缩（查询后把节点直接挂到根上）+ 按秩/按大小合并，合起来使单次操作近似 O(α(n))，比 log 还小。

复杂度：均摊 O(α(n)) ≈ O(1)。注意：并查集不支持删除，只能加边 —— 所以「删边」类问题要离线倒序处理（删边变加边）。

题单 洛谷 P3367 并查集模板 · P1551 亲戚 · P1525 关押罪犯 · P2024 食物链（种类并查集）· P1197 星球大战（倒序加边）· P1196 银河英雄传说（带权并查集）· P1955 程序自动分析。

资料 OI-Wiki「并查集」；CP-Algorithms「Disjoint Set Union」。

10. KMP 算法

基础★★★必背做例题 →

本质：模式串失配时，利用已匹配部分的最长相等前后缀跳过不可能的位置，使匹配过程不回退主串指针，从而 O(n+m)。next[i]（或 π 数组）= 「s[1..i] 的最长真前缀 == 真后缀」的长度。

题单 洛谷 P3375 KMP字符串匹配 · P4391 Radio Transmission（最小循环节）· P4824 删字符串 · P5410 扩展KMP · P2375 动物园（border 计数）。

资料 OI-Wiki「前缀函数与 KMP」；CP-Algorithms「Prefix function. Knuth–Morris–Pratt」；《算法竞赛进阶指南》0x15 节。

11. 单调栈

基础★★高频做例题 →

本质：维护一个单调的栈，被弹出者的"答案"在弹出瞬间确定。它一次扫描就能求出每个元素的「第一个更小/更大元素」（NGE 问题），是 O(n²) 枚举的经典替代。

题单 洛谷 P5788 单调栈模板 · P1901 发射站 · P4147 玉蟾宫 · P1950 长方形 · P1886 滑动窗口（单调队列）· P2216 理想的正方形（二维单调队列）· P2949 Work Scheduling。

资料 OI-Wiki「单调栈」「单调队列」；《算法竞赛进阶指南》0x59 节。

12. 树状数组（BIT）

基础★★★必背做例题 →

本质：用 i += lowbit(i) 的倍增结构把「前缀」切成 log n 段，实现单点修改 + 前缀查询 O(log n)，常数远小于线段树。它只支持可减的运算（和、异或、计数），不支持最值（其实可以，但只能用于单点修改+前缀最值且无逆运算时需另想）。

题单 洛谷 P3374 树状数组1 · P3368 树状数组2（差分）· P1908 逆序对 · P1966 火柴排队 · P2345 奶牛集会 · P1972 HH的项链（离线+树状数组，也属莫队经典）· P3332? 改：P4396 作业（二维数点）。

资料 OI-Wiki「树状数组」；CP-Algorithms「Fenwick Tree」；《算法竞赛进阶指南》0x42 节。

13. 线段树

基础★★★必背做例题 →

本质：把区间二分成树，每个节点维护一段区间的合并信息。区间修改靠 懒标记（lazy tag）延迟下发，保证 O(log n)。它是「区间信息维护」的通用武器，进阶篇的主席树、树链剖分、李超树全是它的变形。

复杂度：建树 O(n)，区间修改/查询 O(log n)，空间 4n（编号法）或 2n（zkw）。

2.2 基础动态规划（6 项）

DP 的通用解题模板是四步：① 定义状态（dp 数组的每一维在说什么）→ ② 写转移方程 → ③ 定边界与答案位置 → ④ 想清楚遍历顺序（保证用到的状态已算好）。写不出 DP，99% 是第一、二步的问题。

1. 路径搜索 DP

基础★★入门DP做例题 →

本质：状态 = 位置（可能还带阶段），转移 = 从相邻位置走过来。这类 DP 是理解「无后效性」的最好载体。

5. 三种最短路之一：Floyd

基础★★全源最短路做例题 →

本质：动态规划。dp[k][i][j] 表示「只允许经过前 k 个点中转时 i→j 的最短路」，压掉 k 维后就是三重循环。能处理负权，不能处理负环。

6. 三种最短路之二：Dijkstra

基础★★★必背做例题 →

2. 强连通分量（SCC）

3.4 进阶数学（21 项）

原文说数学「要依靠积累」，这里补一句更实用的：进阶数学的知识块之间耦合极强——原根 → NTT → 多项式全家桶；φ → 莫比乌斯 → 杜教筛 → Min_25。所以它的学习方式与数据结构不同，必须整块推进，不能东一榔头西一棒。

原文表述订正：「多项式变化」应为「多项式变换 / 多项式运算（求逆、ln、exp、开方）」；「牛顿迭代」指「多项式牛顿迭代」（用于求逆/开方/exp）；「调和」大概率指「调和级数 / 数论分块（整除分块）」；「定积分的求解」实际是「数值积分，参赛时用自适应辛普森」。详见第 4 节。

3.5 计算几何（10 项）

计算几何的特点是理论简单、实现极难：全部难点在精度、边界与特殊情况的处理。核心建议：① 能用整数/叉积就不用浮点；② 每个函数都先想清楚退化情况；③ 写完后用随机数据 + 暴力对拍。

3.6 博弈论（6 项）

博弈论是最"性价比高"的一块：结论少、模板短、题目识别度高。核心心法：先判断是不是「公平组合博弈」（双方操作相同、无随机、无法行动者负），是的话就求 SG 值异或和；不是的话找必胜/必败态的规律（多为等差数列/模 k 分类）。

1. 巴什博弈（Bash Game）

进阶★★入门博弈做例题 →

本质：n 个石子，每次取 1~m 个，取完者胜。n mod (m+1) != 0 则先手必胜：先手取 n mod (m+1) 个，此后对手取 k 个自己就取 m+1−k 个，始终把局面压回 m+1 的倍数。
