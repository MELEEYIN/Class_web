15.1 for 的三步展开

for 的等价展开就是示例里那段 while：

_it = iter(obj)              # ① 要一个迭代器
while True:
    try:
        x = next(_it)        # ② 一个一个取
    except StopIteration:    # ③ 取完了就退出
        break
    ...循环体...

由此可以推出几条实用结论：

  1. for 不要求有索引。任何交出迭代器的对象都能被遍历——文件对象、生成器、dict 的键、re.finditer 的结果都一样。这就是 Python 的"鸭子类型迭代协议"。
  2. 迭代器遍历到一半就是"半耗尽"状态，继续 for 会从断点接着走，而不是从头。示例里 list(e) 第二次是 []，因为 e 已经走到底了。
  3. list、tuple、dict、str 是可迭代对象但不是迭代器：它们没有 __next__，每次都 iter() 出一个新的迭代器，所以能反复遍历。而生成器、enumerate、zip、map、filter、文件对象本身就是迭代器，因此一次性。

[*Countdown(3)] 是"可迭代解包"——[*x] 等价于 list(x)，* 后跟任何可迭代对象都行。第二遍 list(c) 为空，正说明 Countdown 实例自己就是迭代器。

边遍历边删是另一类经典 bug：for n in nums 背后是一个按索引推进的列表迭代器，remove 让列表变短、后面的元素整体前移，迭代器却已经走到下一个位置，于是 3 被跳过。结果 [1, 3, 4] 里的 3 还在。修法有两种：遍历副本 nums2[:]，或用推导式重建 nums2 = [n for n in nums2 if n != 2]（后者更符合 Python 习惯）。

>>> it = iter([1, 2])
>>> next(it)
1
>>> try:
...     while True:
...         _ = next(it)
... except StopIteration:
...     print("取完了")
取完了
>>> list(iter("abc"))
['a', 'b', 'c']

15.2 生成器：yield 就是"暂停点"

生成器的执行模型与普通函数完全不同：

阶段 普通函数 生成器函数
调用 counter(3)立即执行函数体什么都不做，只创建生成器对象
第一次 next()已经算完了从头执行到第一个 yield，吐出值并挂起
再次 next()无从挂起处继续，局部变量全部保留
走到结尾返回值抛 StopIteration（return x 把 x 放进 e.value）

关键点是"挂起时局部变量不销毁"。示例里 i、n 在两次 next 之间一直活着，这就是"状态机"的物理含义——不需要类、不需要保存中间状态的字段。

send 让通道变成双向：x = yield total 中，total 是吐出去的值，x 是送进来的值。注意必须先 next(acc) 或 acc.send(None) 把生成器"预激"到第一个 yield，否则 TypeError: can't send non-None value to a just-started generator。

yield from inner() 把整个子生成器的迭代权交出去，并且能拿到子生成器的 return 值——这是协程（asyncio）的语法基础，22 章会再利用它。

惰性有多实在？pipeline 只取两行时，read_rows 里的"真正读取"也只打印了两次。对于 10 GB 的日志文件，这意味着内存里永远只有正在处理的那一行。

生成器表达式写成函数调用的唯一实参时，括号可省：sum(x*x for x in data)。写成 sum((x*x for x in data)) 也没错，只是多余。

15.3 itertools：把流水线拼起来

三组最常用的工具：

类别 函数 用途 注意
无限count/cycle/repeat生成无限序列必须配 islice/zip 截断
拼接chain/chain.from_iterable/zip_longest串联多个可迭代对象zip 以最短为准，zip_longest 补 fillvalue
组合combinations/permutations/product枚举组合（DFS 题的现成工具）结果数是阶乘级，别盲目 list()
累积accumulate/pairwise/groupby前缀和、相邻对、分组groupby 要求先按同一 key 排序

groupby 是所有新手都踩过的坑：它只把相邻的同 key 元素归到一组，跟 SQL 的 GROUP BY 语义不同。sorted(..., key=...) 之后再 groupby 才对。

pairwise 是 3.10 新增的，等价于 zip(s, s[1:]) 但不需要切片（因此能用于生成器）。示例输出 [('a', 'b'), ('b', 'c'), ('c', 'd')]。

流水线是生成器最实用的形态：parse 负责解析、scaled 负责变换、sum 负责汇总，三层各司其职，中间没有任何列表落地。数据量从 4 行变成 4000 万行，代码一个字都不用改。

>>> import itertools
>>> list(itertools.islice(itertools.count(), 3))
[0, 1, 2]
>>> list(itertools.chain("ab", [1]))
['a', 'b', 1]
>>> list(itertools.accumulate([1, 2, 3]))
[1, 3, 6]
>>> def g():
...     yield 1
...     return "done"
>>> gg = g()
>>> next(gg)
1
>>> try:
...     next(gg)
... except StopIteration as e:
...     print("return 值：", e.value)
return 值： done

15.4 什么时候用生成器，什么时候用列表

判据 生成器 列表
数据量大/无限/流式小、需要反复访问
是否需要 len()、索引、切片不行（len 会 TypeError）可以
是否需要遍历多次不行（一次性）可以
是否需要 sort/reverse不行可以
内存O(1)O(n)
调试print 一次就消耗了，不方便随时看

一句话判据："只需要按顺序过一遍"就用生成器，"需要反复访问或随机访问"就用列表。拿不准时先用列表，等内存/延迟真的成问题时再换。

15.5 与 C++ 的差别

维度 C++ Python
迭代协议begin()/end() 迭代器对__iter__/__next__ + StopIteration
取值方式*it / it->next(it)
结束判断it != end异常 StopIteration
协程式产出C++20 协程 / 手写状态机yield 一行搞定
惰性求值ranges / views生成器表达式
一次性迭代器可以拷贝复用迭代器共享状态，耗尽就是耗尽

begin/end 与 iter(next) 最大的差异在结束信号：C++ 靠比较哨兵位置，Python 靠抛异常。抛异常看起来"重"，但 CPython 对 StopIteration 有专门优化，for 循环的开销主要来自逐次函数调用而非异常。

15.7 练习

1.（基础） 写生成器 countdown(n)，从 n 递减到 1；再用它求 sum(countdown(5))。

验收：list(countdown(3)) == [3, 2, 1]，sum(countdown(5)) == 15。

2.（基础） 写一个 Fib 类，实现 __iter__/__next__，能无限产出斐波那契数列的前 n 项（Fib(6) 得到 [0, 1, 1, 2, 3, 5]）。

验收：list(Fib(6)) 正确；同一实例第二次 list() 为空（迭代器特性）。

3.（生成器） 写生成器 read_numbers(path)：逐行读文件、跳过空行与 # 注释、把每行转成 float，遇到无法转换的内容打印警告后跳过。用你自己造的一个小文件测试。

验收：合格行全部产出，坏行有警告、不中断整体处理，且文件不需要一次性读进内存。

4.（变式） 用 itertools 与生成器搭一条流水线：从 1..100 中筛出 3 的倍数，平方，取前 5 个，求和。要求不出现任何中间列表。

验收：结果为 3²+6²+9²+12²+15² = 495，且 type 检查显示中间对象是生成器。

5.（挑战） 写生成器 chunked(iterable, size)，把任意可迭代对象切成固定大小的块（最后一块可以更小），并用它实现一个"每 1000 条写一次数据库"的批处理框架骨架（用 print 代替写库）。再用 send 实现一个可以随时"暂停/继续"的处理循环。

验收：list(chunked(range(7), 3)) == [[0,1,2],[3,4,5],[6]]；对生成器输入也能工作；批处理打印的次数等于 ceil(总数/1000)。

15.8 小结

  1. for = iter() + 反复 next() + 捕 StopIteration；可迭代对象交迭代器，迭代器记位置。
  2. yield 把函数变成状态机，挂起时局部变量保留；send 双向通信，yield from 委托。
  3. 生成器 O(1) 内存、一次性；需要反复访问或随机访问就换列表。
