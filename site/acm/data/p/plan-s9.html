这一章不是教学章，是地图。进阶内容有 78 项，全学不可能，也不需要。你需要知道的是：每一项解决什么问题、前置是什么、值不值得现在学。 学进阶的正确姿势：先被一道具体的题卡住，再回来查这一章，然后只学那一项。

9.1 什么时候可以进入进阶

进阶★★★★★选学

不要用「学完了基础篇」作为标准，用下面三条：

  • ☐ 能在 20 分钟内，从零写出线段树（区间加 + 区间和）并一次通过。
  • ☐ 能独立完成一道「普及+/提高−」难度的 DP 或图论题，不看题解。
  • ☐ 洛谷累计 AC 不少于 150 题，且「提高−」以上不少于 50 题。

三条都满足再进。少一条就回去刷基础题——进阶算法的价值在于「用它替代一个本来就很慢的正确解法」，基础算法写不对的人学进阶只会更乱。

平衡树（FHQ Treap）split + merge 两个操作实现有序序列的增删查改，O(log n)递归、随机数W11
AC 自动机Trie + 失配指针，多模式串匹配 O(text{总长度})；fail 树常配树状数组Trie、KMPW11
后缀数组对所有后缀排序，配合 height 把子串比较变成区间 RMQ倍增、基数排序W12

树套树线段树套平衡树，处理带修的区间第 k 小线段树、平衡树选学
可持久化并查集用主席树维护 fa 数组，支持回退到历史版本主席树、并查集选学

建议顺序：ST 表 → LCA → 树链剖分 → 分块 → 莫队 → 主席树 → FHQ Treap → AC 自动机 → 后缀数组。这条线每一环都是下一环的直接前置，跳着学必卡。

9.3 进阶动态规划（9 项）

进阶★★★★★选学
项一句话本质前置
DAG 上 DP按拓扑序递推，天然满足依赖（6.3 节已讲，这里是系统化）拓扑排序
数位 DP按位填数 + 记忆化，处理区间内计数（5.9 节已讲）记忆化搜索
计数 DP状态值是「方案数」，转移用加法/乘法，常配组合数与容斥组合数
单调队列优化 DP转移区间随 i 单调滑动时，用单调队列把内层 O(k) 降到 O(1)单调队列
斜率优化 DP转移式能化成 y = kx + b 时，用凸包维护最优决策点单调队列、凸包
四边形不等式 / 决策单调性最优决策点单调时，用分治或指针单调移动优化区间 DP
插头 DP / 轮廓线 DP逐格推进，用二进制记录「跨轮廓线的连通性」状压 DP
动态 DP把转移写成矩阵，用树链剖分 + 线段树动态维护矩阵快速幂、树链剖分
树上 DP 进阶换根 DP、长链剖分、线段树合并，处理「所有点为根」类问题树形 DP、线段树
💡 提示

进阶 DP 的唯一主线是优化：先把 O(n^2) 写对，再想办法降到 O(nlog n) 或 O(n)。顺序永远是「先暴力 AC，再优化」，反过来一定写不出来。

网络流是进阶图论的分水岭。判断一道题能不能网络流，看它是否有「分配/匹配/切割」的味道。

9.5 进阶数学（21 项）

进阶★★★★★选学
项一句话本质前置
中国剩余定理（CRT / exCRT）多个模方程合并成一个；exCRT 允许模数不互质exgcd
Lucas / exLucas大 n 小 p 的组合数，按 p 进制拆位组合数
二次剩余 / Cipolla解 x^2 equiv a，模素数时有解判定与开方算法快速幂、勒让德符号
原根 / 阶 / 离散对数 BSGS求 a^x equiv b，以 √ m 为步长做「大小步」快速幂、逆元
线性基异或空间的高斯消元，20 行解决最大/第 k 大异或和位运算
高斯消元 / 矩阵树定理解线性方程组；矩阵树定理用行列式数生成树矩阵、逆元
莫比乌斯反演用 μ 把「和式」翻转成「倍数和式」，配数论分块数论函数、线性筛
狄利克雷卷积(f*g)(n) = Σ_d| n f(d)g(n/d)，反演的抽象形式数论函数
杜教筛用卷积构造 S(n) = Σ f(i) 的递推，O(n^2/3) 求积性函数前缀和莫比乌斯反演
Min_25 筛更强的积性函数前缀和，O(n^3/4)杜教筛
FFT把多项式乘法从 O(n^2) 降到 O(nlog n)，用单位根做点值变换复数
NTT在模 998244353 下用原根替代单位根，避免浮点误差原根
多项式全家桶求逆、ln、exp、开方，全部基于牛顿迭代NTT
牛顿迭代用 x arrow x - f(x)/f'(x) 逼近零点，多项式算法的统一框架微积分基础
拉格朗日插值由 n+1 个点唯一确定 n 次多项式，O(n^2) 或 O(n)多项式
母函数（OGF / EGF）把组合问题变成多项式系数问题组合数
群论 / Burnside / Polya在「旋转/翻转视为相同」时数染色方案组合数、群的定义
数论分块 / 调和级数⌊ n/i ⌋ 只有 O(√ n) 种取值，可批量处理整除
线性规划 / 单纯形在约束下最大化线性目标，竞赛里多是模板题高斯消元
构造题没有固定算法，靠手玩小样本找规律、打表耐心
自适应辛普森积分数值求定积分，误差可控微积分
📌 重点

优先级建议：线性基、CRT、Lucas、莫比乌斯反演、FFT/NTT 这五项性价比最高，其余按题目需要学。

9.7 博弈论（6 项）

进阶★★★★★选学
项一句话本质判据
巴什博弈n 个石子，每次取 1~ m 个先手必败 ⇔ n mod (m+1) = 0
威佐夫博弈两堆，可任取一堆或两堆同取必败态满足 frac{√5+1}{2} 相关的 Beatty 序列
Nim 游戏多堆石子，每次取一堆任意个异或和为 0 则先手必败
斐波那契博弈每次取不超过前次两倍石子数为斐波那契数则必败
公平组合博弈（ICG）有向图游戏，局面可分解SG 定理：多个子游戏 SG 值异或
SG 函数mathrm{SG}(x) = mathrm{mex}{mathrm{SG}(y) : x→ y}SG 为 0 则必败
💡 提示

博弈论的关键是先手玩小数据找规律，再看能不能用 SG 定理分解成子游戏。能分解就能赢一半。

9.10 一个反直觉的建议

进阶★★★★★选学

不要按目录顺序学进阶。 正确做法是：

  1. 找一道「提高+/省选−」的题，先自己硬写，写到卡住。
  2. 看题解，发现自己缺的是哪一项（比如「区间第 k 小」→ 主席树）。
  3. 回来只学那一项，学完立刻回去把那道题 AC。
  4. 记进错题本：「这个场景该用 X」。

这样学一次，胜过按目录刷十章。
