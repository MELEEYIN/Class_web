周主题必做内容验收标准
W1入门篇上半枚举、模拟、递归、前缀和与差分、尺取法能默写前缀和/差分/滑动窗口三套模板；洛谷绿题 15 道
W2入门篇下半排序原理、二分/三分、分治、贪心、简单搜索二分两套模板不写错；归并求逆序对独立写出；BFS/DFS 各 5 道
W3基础数据结构（上）栈、队列、链表、堆、哈希、二叉树、Trie、set/mapSTL 常用容器 API 熟练；Trie 与 01-Trie 独立实现
W4基础数据结构（下）并查集、KMP、单调栈、树状数组、线段树线段树三种标记（加/乘/赋值）能盲写；树状数组求逆序对
W5基础 DP路径 DP、背包（五种）、区间 DP背包五种类型能识别并选对顺序；AtCoder DP Contest 前 15 题
W6基础 DP（续）+ 图论（上）树形 DP、状压 DP、概率 DP；建图、遍历、拓扑、欧拉路树形背包复杂度会分析；拓扑 + DAG DP 熟练
W7基础图论（下）Floyd、Dijkstra、SPFA/负环、差分约束、Prim/Kruskal三种最短路适用边界清楚；能识别差分约束建模
W8基础数学位运算、快速幂、线性筛、高精度、组合数、矩阵快速幂、gcd/exgcd、费马、逆元组合数预处理 + 逆元三种求法熟练；矩阵快速幂能构造转移矩阵
W9进阶图论（一）Tarjan（SCC/割点/桥）、LCA、树链剖分树剖能盲写；LCA 四种方法知道各自适用场景
W10进阶图论（二）二分图匹配、2-SAT、Dinic、最小割建模、费用流最小割建模三模型能独立完成；Dinic 模板无 bug
W11进阶数学（主干）CRT/exCRT、Lucas、原根、莫比乌斯反演、杜教筛、NTT莫反套路（换序 + 整除分块）能独立推导；NTT 模板可用
W12选一个方向钻深 + 综合从「字符串（SA/SAM/PAM）」「DP 优化（斜率/决策单调/WQS）」「数据结构（主席树/树套树/莫队）」中选一个方向专项突破该方向模板全通 + 3 场模拟赛 + 复盘文档

每周固定动作（比内容更重要）

  • 周一：学新知识点（看书/OI-Wiki → 手推 → 写模板）
  • 周二~周四：刷题（裸题 2 道 → 变形 2 道 → 组合 1 道），每道写考点与错因
  • 周五：模板盲测（随机抽 3 个已学算法，关资料默写并过题）
  • 周六：打一场比赛（CF/AtCoder/洛谷）
  • 周日：复盘 + 补题 + 更新模板库与错题本

判断该不该进入下一阶段：随机抽 5 个学过的算法，其中 ≥4 个能在 20 分钟内从零写对并通过模板题——就到下一阶段。否则回头补。

最后一句建议：原文强调"从广到深"，这个方向是对的，但请把"广"理解为每一层都要有能落地的模板，而不是"每个名字都听过"。算法学习里最贵的成本不是"没学过"，而是"学过但写不出来"。所以本手册里所有代码模板的价值，都取决于你有没有关掉屏幕重写一遍。
