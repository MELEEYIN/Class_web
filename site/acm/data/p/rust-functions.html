Rust 的函数没什么惊喜，但有两个细节和 C 很不一样：表达式有值（不加分号就是返回值），以及 if/loop/match 本身都是表达式，可以直接赋值。

一、函数与返回值

fn add(a: i32, b: i32) -> i32 {
    a + b            // 注意：没有分号，这一行的值就是返回值
}

fn nothing() {       // 没有 ->，返回 ()
    println!("hi");
}

fn main() {
    let s = add(1, 2);   // 3
    nothing();
}
写法结果
a + b（无分号）表达式的值作为返回值
a + b;（有分号）变成语句，函数返回 ()，类型不匹配就报错
return a + b;显式提前返回，用于循环里跳出
新手最常见的编译错误就是「少写/多写分号」：expected `i32`, found `()` 基本等于“你把返回值那一行的分号加上了”。

二、if 是表达式

let n = 7;
let kind = if n % 2 == 0 { "偶数" } else { "奇数" };   // 直接赋值

// 条件必须是 bool，不能用 0/1
// if n { ... }        // 编译错误

因为 if 有值，两个分支的类型必须一致；else 不能省（除非整体是 ()）。Rust 没有三元运算符 ? :，用 if/else 就够。

三、三种循环

// loop：无限循环，靠 break 带值退出
let mut i = 0;
let result = loop {
    i += 1;
    if i == 5 { break i * 2; }
};

// while
while i > 0 { i -= 1; }

// for：最常用，遍历迭代器
for k in 0..5 { println!("{}", k); }        // 0 1 2 3 4
for k in (0..5).rev() { }                   // 逆序
for x in &vec![1, 2, 3] { }                 // 借用遍历，不移动

loop { break value; } 是 Rust 独有的写法，比“先声明一个变量再 while 赋值”干净得多。

四、常见坑

  1. 返回值那行加了 ;，函数返回 ()，报类型不匹配。
  2. if 条件写数字：Rust 不做隐式布尔转换，必须写 n != 0。
  3. for k in 0..=5 与 0..5 差一个右端点：..= 含 5。
  4. 在 for x in v 之后再访问 v：v 已被移动，改成 &v。
  5. 函数参数没写类型：Rust 要求函数签名必须标注类型（函数体内可以推断）。

五、小结

表达式优先是 Rust 的表达风格：能用一个表达式算出来的，就不要先声明变量再赋值。下一章把这些表达式装进结构体，开始写“有类型的数据”。
