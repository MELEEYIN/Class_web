0.1 先说清楚一个前提

入门★★★必读

你不需要先学完「所有 C++ 语法」再来学算法。竞赛用到的语法只占 C++ 的很小一部分，本文第 1 章会把它们一次性补齐——够用就行，剩下的在写题中长大。

同样，你不需要按顺序学完 200 个算法名词。这份计划只做一件事：让你在正确的时间，用正确的难度，学到正确的那个知识点。

0.2 唯一的主线：看到约束 → 想到算法

入门★★★必读

整份计划有一条贯穿始终的主线，也是所有竞赛选手真正的核心竞争力：

看到题目的数据范围，立刻反推出允许的复杂度，进而反推出该用什么算法。

看到 n 的范围允许复杂度该想什么
n ≤ 10O(n!)全排列、暴力搜索
n ≤ 20O(2^n)子集枚举、状压 DP
n ≤ 300O(n^3)Floyd、区间 DP、高斯消元
n ≤ 5000O(n^2)朴素 DP、朴素最短路
n ≤ 2×10^5O(nlog n)排序、二分、树状数组、线段树、堆
n ≤ 10^7O(n)前缀和、双指针、单调栈、线性筛
n ≤ 10^9 或 10^18O(log n) / O(√ n)快速幂、二分答案、数位 DP、整除分块

这张表现在看不懂没关系，第 2.3 节会详细解释每一行。但从今天起，每读一道题，先看数据范围——这个动作要坚持 8 周。

0.4 每天 3 小时的标准节奏

入门★★★必读
时段时长做什么
第 1 段25 分钟读一个知识点，把模板手敲一遍（不许复制粘贴，不许看着屏幕抄）
第 2 段15 分钟对着模板做 1 道「模板题」，确认每一行都真的懂
第 3 段90 分钟做 3 道配套题，每题卡 30 分钟；到点没思路就看题解
第 4 段30 分钟把没做出来的题关掉题解重写一遍，写 3 行笔记：关键一步是什么

0.5 三个必须戒掉的坏习惯

入门★★★必读
  • 看题解 = 抄代码。 看懂和写出来之间隔着一道鸿沟。正确做法：看懂 → 关掉题解 → 自己写 → 写不出来再看 → 立刻关掉再写第二遍。
  • 只做会做的题。 一直做会做的题等于一直不进步。健康比例：70% 需要想 10~30 分钟的题 + 20% 要看题解的题 + 10% 巩固题。
  • 不写对拍。 「样例过了」不等于「对了」。第 2.5 节会讲怎么用随机数据 + 暴力程序验证自己的解法。
✅ 小结

这份计划的重点不是「读完」，而是「关掉屏幕能重写出来」。算法学习里最贵的成本不是没学过，而是学过但写不出来。

0.6 本文的排版约定

入门★★★必读

每一节都按同一个模子写，认识下面这几个标记，能省掉一半阅读时间。

  • 本质（灰底引用块）　这一节的算法用一句话说完。先读它，读不懂再往下看。
  • 类比　用生活里的事情解释它为什么这样做。类比只负责建立直觉，不负责严谨。
  • 模板（代码块）　考场上能直接敲出来的写法。建议手抄三遍，直到不看屏幕也能默写。
  • 易错　所有人都会在这一步踩的坑。考前复习只看这些，比重新学一遍快十倍。
  • 小结　这一节真正需要记住的一句话。
  • 题单　按难度排好的洛谷题号。看完正文立刻去做，做不出来再回来看。

代码块里的注释也用两套符号：✓ 表示「应该这样写」，✗ 表示「这样写会错」。
