6.1 四种容器一览

容器 字面量 可变 有序 元素要求 in / 按名查 典型用途
list[1, 2]✅✅ 按位置任意O(n)序列、栈、队列（尾部）
tuple(1, 2)❌✅ 按位置任意O(n)固定记录、字典键、函数多返回值
dict{"a": 1}✅✅ 插入序键必须可哈希O(1)按名字查、计数、缓存
set{1, 2}✅❌必须可哈希O(1)去重、集合运算

三句话选型：要按下标/顺序 → list；要按名字查 → dict；只要"在不在" → set；一组值打包后不再改 → tuple。

{} 是空字典不是空集合；空集合只能写 set()。(1) 是整数 1，单元素元组要写 (1,)。

6.2 列表：增删改查

四个操作对应的复杂度：append / pop() 尾部 O(1)；insert(0, x) / pop(0) 头部 O(n)（整表后移）；remove(x) / index(x) / in O(n)。所以不要用 list 当队列——头部弹出是 O(n)，collections.deque 才是 O(1)（第 21 章）。

sort 与 sorted 的分工是本节的第二个重点：

>>> a = [3, 1, 2]
>>> a.sort()                      # 原地，返回 None
>>> a
[1, 2, 3]
>>> sorted(a, reverse=True)       # 返回新列表
[3, 2, 1]
>>> sorted(["bb", "a", "ccc"], key=len)
['a', 'bb', 'ccc']

排序是稳定的，所以多关键字排序可以用"从次要关键字到主要关键字依次 sort"，也可以像示例里那样返回元组 key=lambda w: (len(w), w)。sort(key=...) 每个元素只调用一次 key 函数，不是比较时反复调用——这就是 Python 排序比 C++ 手写比较器快的原因（Timsort + 键提取）。

切片赋值（c[1:4] = ["x"]）能一次替换多段并改变长度，这是 list 独有的能力；list[i:j] = [] 就是"删除一段"。步长不为 1 时长度必须一致：c[::2] = ["a"] 会报 ValueError。

6.3 元组：不可变 + 解包

要点：

  • a, b = b, a 一步交换，底层是先把右值打包成元组再解包，不需要临时变量；
  • first, *rest = ... 的星号只能有一个，head, *mid, tail 也能用（3.0+）；
  • 元组可哈希所以能当字典键/集合元素，列表不行；若要键里含可变内容，用 tuple(lst) 转换；
  • namedtuple 是"带字段名的元组"，p.x 与 p[0] 等价，仍然不可变、仍可哈希，比手写 class 轻得多（dataclass 见第 18 章）。

元组的"不可变"是浅的：t = (1, [2]); t[1].append(3) 是合法的，因为改的是列表内部。这一点与 list 的别名问题同源（第 3 章）。

6.4 字典：按名字 O(1) 查

必须记住的四条：

  1. d[k] 缺键抛 KeyError，d.get(k) 返回 None。判断"有没有"用 k in d，不用 d.get(k)——d.get(k) 在"值是 None"时分不清。
  2. 插入序 = 遍历序（3.7 起是语言保证，不是实现细节）。所以 print(d) 的输出是确定性的，可以直接比对。
  3. update 改自己，| 造新字典；同名键右边覆盖左边。d |= other 是 3.9+ 的原地版本。
  4. 键必须可哈希：str、int、float、tuple、frozenset、None 可以，list、dict、set 不行。

计数是最常见的字典用法，两种写法都行，但更快的是 collections.Counter：Counter("abca") 直接得 {'a': 2, 'b': 1, 'c': 1}，还自带 most_common()（第 21 章）。

遍历字典时增删键会抛 RuntimeError: dictionary changed size during iteration。要改就先 list(d) 或 list(d.items()) 复制一份再遍历。

6.5 集合：去重与集合运算

  • set 无序：print({3, 1, 2}) 的输出顺序取决于哈希值，不同进程都可能不同。要做稳定输出就 sorted(s)，想"去重且保留原顺序"用 list(dict.fromkeys(xs))（利用字典的插入序）。
  • discard 删不存在的元素不报错，remove 会抛 KeyError——不确定在不在就用 discard。
  • 集合运算的运算符版要求两边都是集合：a & [1] 报 TypeError，得写 a & set([1]) 或用方法版 a.intersection([1])（方法接受任何可迭代对象）。
  • frozenset 是不可变集合，能作字典键/集合元素。

6.9 练习

1.（列表基本操作） 给定 nums = [3, 1, 4, 1, 5, 9, 2, 6]，输出：去重后保序的列表、升序列表、最大值及其下标、总和与平均值（保留 2 位小数）。

验收：不用第三方库；去重结果顺序与原列表首次出现顺序一致。

2.（字典计数） 统计一段文本里每个单词出现次数，按次数降序、次数相同按单词升序输出前 3 名。

验收："the cat the dog the bird cat" 输出 the 3、cat 2、bird 1（各占一行）。

3.（集合运算） 给定两个班级的花名册（列表），输出去重后的并集（有序）、交集、只在一班的人。

验收：三行输出都用 sorted 保证顺序稳定。

4.（变式） 实现 two_sum(nums, target)，返回第一个满足 nums[i] + nums[j] == target（i < j）的下标对；要求对 10^5 规模不超时。

验收：two_sum([2, 7, 11, 15], 9) == (0, 1)，并说明时间复杂度为什么是 O(n)。

5.（挑战） 实现 group_anagrams(words)：把字母异位词分到一组，组内按字典序、组间按首词字典序输出。

验收：["eat", "tea", "tan", "ate", "nat", "bat"] 分成 3 组，["ate", "eat", "tea"] 一组；只能用内置类型（提示：排序后的字符串当字典键）。

6.10 小结

  1. list 按下标、dict 按名字、set 判存在、tuple 打包不变——选型就是选复杂度。
  2. 原地方法返回 None，sort/append/extend 都别接收返回值。
  3. [[0]*m]*n 是 n 个别名，二维表一律用推导式建。
