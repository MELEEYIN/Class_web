动态规划是入门阶段最大的分水岭。它不考记忆，考的是「能不能把一个问题描述成"状态 + 转移"」。这一章会按「从一维到多维、从线性到树上」的顺序推进，每一节只加一个新维度。

5.1 DP 到底是什么

基础★★★★★必考

本质：DP = 递推 + 记录。 把一个大问题拆成若干子问题，子问题之间有重叠，于是把子问题的答案存起来复用。它成立的前提是无后效性——后面的决策只依赖于当前状态，与「怎么走到这里」无关。

🎨 生活类比

你要从家到学校，路线有无数条。但只要你站在「第 3 个路口」这个位置，接下来怎么走最省时间，和你是从哪条路走来的完全无关——这就是无后效性。于是你只需要算「每个路口到学校的最短时间」，存进表里，从终点倒推回来即可。

与递归、贪心的区别

递归贪心DP
核心把问题变小每步取局部最优记录所有子问题的答案
缺点大量重复计算不一定全局最优状态设计难、空间大
关系加记忆化就变成 DPDP 的特例（每步只有一种最优选择）在 DAG 上求最短路/路径计数
💡 提示

一句话理解 DP：DP 本质上就是在「状态转移图」（一个 DAG）上求最短路或路径条数。这句话在第 9 章会反复出现。

5.2 状态设计四步法

基础★★★★★必考

这是本课程最重要的一节。所有 DP 题都按这四步走：

步骤要回答的问题例子（数字三角形）
① 定状态f[...] 里的每个维度代表什么？f[i][j] = 走到第 i 行第 j 列的最大和
② 写转移f[当前] 由哪些 f[更小] 得到？f[i][j] = a[i][j] + max(f[i-1][j-1], f[i-1][j])
③ 定初值最小的状态是什么？f[1][1] = a[1][1]
④ 定顺序按什么顺序枚举，保证用到的都已算好？外层 i 从小到大，内层 j 从左到右

第 ④ 步最容易错。 判断方法：转移式右边出现的下标，必须在左边之前被算出来。

三个自检问题

  1. 状态数是多少？转移代价是多少？乘起来会不会超时？
  2. 有没有后效性？即「同样的状态，不同的到达路径会导致不同答案」？
  3. 空间能不能压？只依赖上一行就用滚动数组。

5.3 线性 DP 与路径 DP

基础★★★★★必考P1216P1115P1434

本质：状态 = 位置（可能还带阶段），转移 = 从相邻位置走过来。这类 DP 是理解「无后效性」的最好载体。

三个必会模型

① 数字三角形（P1216）

② 最大子段和（P1115）

③ 最长上升子序列（LIS）

💡 提示

LIS 的 O(nlog n) 版本是「DP 的转移能用二分加速」的第一个例子，第 9 章的 DP 优化都源于同一思路。

空间压缩：滚动数组

如果 f[i] 只依赖 f[i-1]，就把第一维去掉，用一个变量或一维数组滚动。

⚠️ 易错

去掉第一维后，枚举顺序变得至关重要（背包的倒序就是这个道理）。

题单　P1216 数字三角形　·　P1115 最大子段和　·　P1434 滑雪（记忆化）　·　P1020 导弹拦截（LIS）　·　P1439 最长公共子序列　·　P1002 过河卒　·　P2196 挖地雷

5.4 背包问题（五种）

基础★★★★★必考P1048P1049P1616

本质：一堆物品，每件有代价与收益，选一个子集使收益最大。所有背包的差别只在「每件物品可选几次」和「依赖关系」，而枚举顺序决定了同一维数组能否复用。

🎨 生活类比

你去超市有 20 元的预算，货架上每件商品有价格和你的喜爱程度。你怎么买最开心？——这就是 0-1 背包。如果每件商品可以无限买——就是完全背包。

💡 提示

为什么方向决定次数？ 倒序时 f[j-w] 还是「上一轮」的值（没选过 i）；正序时 f[j-w] 已经是「这一轮」更新过的值（可能已经选过 i）——所以允许重复。

多重背包的二进制拆分

为什么对？ 任何 0 ~ c 的整数都能用 1,2,4,8,dots 的二进制组合表示。

⚠️ 易错

把「容量 m」写成「物品数 n」；f 数组没初始化为 0 或 -INF（求「恰好装满」时要初始化为 -INF，除 f[0] = 0）。

5.5 区间 DP

基础★★★★★必考P1880P1063P1220

本质：状态是一段区间 dp[l][r]，转移是「枚举断点把区间分成两半」。因此枚举顺序必须是区间长度从小到大，否则用到的短区间还没算出来。

🎨 生活类比

把一排石子合并成一堆，每次只能合并相邻两堆。你想知道「从第 3 堆到第 8 堆合并成一堆的最小代价」——这必须先知道「3~5 堆」和「6~8 堆」各自的最小代价。于是按区间长度从短到长推。

模板（石子合并）

复杂度 O(n^3)，所以 n ≤ 300 左右才能用。

环形问题：断环成链

圆形操场上的石子合并，做法是把数组复制一份接在后面，长度变成 2n，然后对长度 n 的区间求答案。

⚠️ 易错

三层循环的顺序（长度 → 起点 → 断点）写反就全错；f 要初始化为 INF，但 f[i][i] 要为 0。

题单　P1880 石子合并　·　P1063 能量项链　·　P1220 关路灯　·　P4170 涂色　·　P3205 合唱队　·　P4302 字符串折叠

5.6 树形 DP

基础★★★★★必考P1352P2014P2015

本质：在树上做 DP，靠 DFS 后序遍历保证「孩子算完再算父亲」。状态里通常带一个「选/不选当前点」或「与父亲的关系」的维度。

🎨 生活类比

公司要办年会，邀请员工来热闹，但规定「上司和直接下属不能同时来」。你要选出一个总快乐值最大的名单——这必须从最底层的员工往上一层层算。

模板（没有上司的舞会，P1352）

树形背包（依赖背包）

dp[u][j] = 以 u 为根的子树里选 j 个节点的最大价值。合并孩子时用类似背包的方式累加，复杂度 O(n^2)（合并两个大小为 a, b 的子树代价是 a× b，总和恰为 O(n^2)）。

⚠️ 易错

递归传父节点防止回头（否则死循环）；答案可能在某个子树里而不是根，要全局取 max；深度大时要考虑爆栈。

题单　P1352 没有上司的舞会　·　P2014 选课　·　P2015 二叉苹果树　·　P1122 最大子树和　·　P3478 STA-Station（换根 DP）

5.7 状压 DP

基础★★★★★必考P1896P1879P2704

本质：当状态是「一个集合」（谁被选了、哪些位置放了棋子）且元素个数 n ≤ 20 时，用一个整数的二进制位表示这个集合，整数就是状态。

🎨 生活类比

你有 8 个开关，每个要么开要么关。8 个开关的所有组合恰好是 0 ~ 255——一个字节就能表示全部状态。

通用骨架

三个常用优化

优化做法
预处理合法状态把所有「本行自身合法」的 s 提前筛出来存成数组，循环只跑这些
枚举子集for (int t = s; t; t = (t - 1) & s) 遍历 s 的所有子集
滚动数组dp[i][s] 只依赖 dp[i-1][t]，第一维压掉
⚠️ 易错

2^20 × 20 已经接近 2×10^7，再乘一个 n 就超时；1 << m 在 m ≥ 31 时溢出（用 1LL）。

题单　P1896 互不侵犯　·　P1879 玉米田　·　P2704 炮兵阵地　·　P1171 售货员的难题　·　P1433 吃奶酪

5.8 概率与期望 DP

基础★★★★★必考P1654P4316P1850

本质：把「概率/期望」当成 DP 的值。三个关键技巧：期望的线性性（E[X+Y] = E[X]+E[Y]，无需独立）、倒推（从终点往起点算）、全概率公式。

期望的线性性为什么重要

因为「和的期望等于期望的和」不需要独立性。所以求「总代价的期望」时，可以拆成「每一步代价的期望」再相加，这往往能把问题大幅简化（P1654 OSU! 的拆贡献就是这个思想的极致）。

倒推的理由

如果状态转移是「从当前走向下一步」，那么下一步的期望是已知的，当前可以立刻算出来。所以期望 DP 通常从终点往起点推。

⚠️ 易错

概率 DP 里「除以出度」还是「除以入度」取决于推的方向；浮点误差到 10^-9 一般可接受。

题单　P4316 绿豆蛙的归宿　·　P1850 换教室　·　P1654 OSU!　·　P4550 收集邮票

5.9 数位 DP

基础★★★★★必考P2602P2657P4124

本质：统计「[L, R] 区间内有多少数满足某性质」。做法是从高位到低位逐位填数，用状态记录「是否卡上界、是否还在前导零、当前数位性质」，用记忆化避免重复计算。

🎨 生活类比

数 1 到 1000 里有多少个数字含 3。你不是一个个数，而是按位分类：百位是 3 的一类、十位是 3 的一类、个位是 3 的一类，再用容斥去重。

记忆化骨架

答案 = dfs(R) - dfs(L-1)。

⚠️ 易错

limit 为真时不能记忆化（状态不完整）；前导零的处理决定了很多题的成败；L-1 可能是 0，要特殊判。

题单　P2602 数字计数　·　P2657 windy 数　·　P4124 手机号码　·　P4999 烦人的数学作业

5.10 记忆化搜索：DP 的另一种写法

基础★★★★★必考

当你想不清枚举顺序时，就写记忆化搜索——它自动帮你处理顺序问题（递归到哪算到哪），代价是常数更大、可能爆栈。

什么时候用记忆化而不是递推：

用记忆化用递推
状态转移依赖关系不清晰转移顺序很明显
很多状态根本不会访问到（稀疏）状态密集
想在 DFS 中顺便记录路径需要极致常数
💡 提示

记忆化搜索和 DP 不是两种算法，是同一个东西的两种实现。会了其中一个，另一个就只是写法差异。
