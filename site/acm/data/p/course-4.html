本节出现的新函数 / 新语法（先看懂再用）
  • 一维数组 —— 连续内存 + 从 0 编号，随机访问 O(1)
  • sizeof —— 算字节数与数组长度，编译期求值
  • 范围 for（range-based for） —— 不用下标遍历全数组，改元素要加 &

前三节都是“读一个、算一个、扔掉”。这一节解决回头访问：先把 n 个数存起来，再按编号取。10 个数能起 10 个变量名，10⁵ 个不行。数组 = 一块连续内存 + 从 0 开始的编号，编号叫下标，写 a[i]。

数组不检查下标。写错一个 1 不报错，只会悄悄改坏隔壁变量——本地能过、评测机 RE。
例题 · 陶陶摘苹果洛谷 P1046入门去洛谷做这题 ↗

陶陶家的苹果树结了 10 个苹果。她有一个 30 厘米高的板凳，手够不到就踩上去再试。已知 10 个苹果到地面的高度和陶陶把手伸直时能达到的最大高度，求她最多能摘到几个苹果（碰到就掉下来）。

输入两行：第一行 10 个 100~200 的整数（厘米），表示各苹果的高度；第二行 1 个 100~120 的整数（厘米），表示把手伸直时能达到的最大高度。

输出一行一个整数，表示能摘到的苹果数。

输入： 100 200 150 140 129 134 167 198 200 111 110 输出： 5

输入顺序是关键：10 个高度在前，手的高度在后。要判断够不够得到，必须先拿到手的高度，而它在最后。所以这 10 个数非存不可——数组存在的第一个理由。

本节只有三样新东西。

新函数拆解 · 一维数组
类型 名字[长度]; // int a[100005];
组成含义 / 格式要求
int a[100005];下标 0~100004。长度必须是编译期常量，不能是读进来的 n。
a[0] … a[长度-1]长度 10 的数组，最后一个元素是 a[9]，没有 a[10]。
a[i]i 可以是变量或表达式（如 a[i*2+1]），只要结果在范围内。
全局 / 局部main 外：自动全 0、不占栈。main 里：随机值，大数组还会爆栈。
内存布局a[i] 的地址 = 起始地址 + i×4，连续存放，随机访问 O(1)。
最小可运行示例
示例
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;           // 长度写成常量，改一处就够
int a[N];                       // 全局：默认全 0，占 400KB，不放栈上

int main() {
    int n; cin >> n;
    for (int i = 0; i < n; ++i) cin >> a[i];        // 只填前 n 个格子
    for (int i = n - 1; i >= 0; --i) cout << a[i] << " ";
    cout << "\n";
    return 0;
}
注意

长度只能开大不能开小：n ≤ 10⁵ 就开 100005，多留 5 格防差一。

局部 int a[1000005]; 占 4MB 栈，栈上限常只有 1~8MB，直接 RE。挪到 main 外。

下标从 0 开始：a[i] 的地址是 base + i×4，索引 0 正好落在起始地址。

新函数拆解 · sizeof
sizeof(表达式或类型) // 占多少字节，类型是 size_t
组成含义 / 格式要求
sizeof(a)整个数组的字节数。int a[10] 得 40。
sizeof(a[0])单个元素：int 4、long long 8、char 1、double 8。
sizeof(a)/sizeof(a[0])数组长度，换元素类型不用改公式。
编译期求值是运算符不是函数，没有运行时开销。
数组退化后失效传进函数后 a 变成指针，sizeof(a) = 8，公式作废。
最小可运行示例
示例
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a[10];
    cout << sizeof(a) << "\n";                 // 40 = 10 × 4
    cout << sizeof(a[0]) << "\n";              // 4
    cout << sizeof(a) / sizeof(a[0]) << "\n";  // 10，就是长度
    return 0;
}
注意

竞赛里更常见的是直接用读入的 n，别依赖 sizeof——数组传进函数后它会骗你。

sizeof 是无符号数，与 int 比较会有警告，写成 (int)(sizeof(a)/sizeof(a[0])) 最干净。

新函数拆解 · 范围 for（range-based for）
for (元素类型 变量 : 数组) { ... }
组成含义 / 格式要求
for (int x : a)从头到尾取每个元素，复制给 x。不写下标，不会写错边界。
int &x引用即别名，改 x 就是改数组。要修改元素时用它。
走多少格整个数组长度，一格不少。不能只走前 n 个，不能倒序或跳跃。
什么时候不能用需要下标（问“第几个”）、倒序、或数组开大了只读 n 个数时。
版本C++11 起，C++17 当然支持。
最小可运行示例
示例
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a[5] = {3, 1, 4, 1, 5}, s = 0;
    for (int x : a) s += x;         // 副本：s = 14，a 没变
    for (int &x : a) x *= 2;        // 引用：a 变成 6 2 8 2 10
    for (int x : a) cout << x << " ";
    cout << "\n" << s << "\n";
    return 0;
}
注意

最大的坑：int a[100005]; 只读了 5 个数，for (int x : a) 会把后面 100000 个 0 也算进去，答案大出一截。

范围 for 拿不到下标。答案要输出“位置”的题，老实写普通 for。

把题目翻译成 3 步

判断规则一句话：苹果高度 ≤ 可及高度就摘得到，而可及高度 = 手伸直高度 + 30。

  1. 把 10 个高度读进 h[0..9]，再读入手的高度 reach；
  2. 算出 can = reach + 30，把 30 只加一次；
  3. 扫一遍数组，h[i] <= can 就 ++ans。

第 3 步是通用骨架：答案变量归零 → 遍历 → 满足条件就更新。计数、求和、求最值、找位置，都只是换一行循环体。

完整代码（可直接提交 P1046）
#include <bits/stdc++.h>
using namespace std;

int main() {
    int h[10];
    for (int i = 0; i < 10; ++i) cin >> h[i];   // ① 先全部读入：手的高度还没出现

    int reach;
    cin >> reach;                                // ② 再读手能到达的高度
    int can = reach + 30;                        // ③ 踩上 30cm 板凳后，把 30 只加一次

    int ans = 0;                                 // ④ 计数器必须从 0 开始
    for (int i = 0; i < 10; ++i)
        if (h[i] <= can) ++ans;                  // 碰到就掉，计一个

    cout << ans << "\n";
    return 0;
}
逐行拆解
代码片段含义与理由
int h[10];10 个格子，合法下标 0~9。只有 40 字节，开在 main 里也无所谓。
for (int i = 0; i < 10; ++i) cin >> h[i];循环 10 次，第 i 次读的数放进 h[i]。cin 自动跳过空格换行，数据分几行写都行。
cin >> reach;第 11 个数正好是第二行那个高度。顺序不能反。
int can = reach + 30;题目给的高度不含板凳。先加进 can，循环里就只剩一次判断。
int ans = 0;必须显式初始化。局部变量不初始化是随机值，可能输出 1245123。
for (int i = 0; i < 10; ++i)0 到 9 正好 10 个。写成 i <= 10 就会访问 h[10]，越界。
if (h[i] <= can) ++ans;等于也算，题目说碰到就掉，别写成小于。
cout << ans << "\n";只输出数字，不加提示文字。

把骨架换几行循环体，就得到四种统计。只有求最值有一个必须想清楚的细节：初值怎么选。

最值 + 求和的标准骨架
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int a[N];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; ++i) cin >> a[i];     // 先全部读入

    int mx = a[0], mn = a[0];                    // 初值取第一个元素，不是 0
    long long sum = 0;                           // n 大、值大时必须 long long
    for (int i = 0; i < n; ++i) {
        if (a[i] > mx) mx = a[i];                // 严格大于才换，相等时保留先出现的
        if (a[i] < mn) mn = a[i];
        sum += a[i];
    }

    cout << mx << " " << mn << " " << sum << "\n";
    return 0;
}
初值为什么取 a[0]
代码片段含义与理由
int mx = a[0];a[0] 是真实数据，不可能比最大值大，结果无条件正确。
int mx = 0;只在全 ≥ 0 时对。输入 -5 -9 时 mx 停在 0，输出 0 —— WA。
int mx = INT_MIN;同样永远正确，需 <climits>（bits 已含），但看不出含义。
if (a[i] > mx)用 > 不用 >=：相等时不覆盖，保留“第一次出现”的信息。
sum += a[i];同一循环顺手算完，不必多扫一遍数组。
目的初始化循环体写错会怎样
求和0（用 long long）sum += a[i];用 int 溢出 → 输出负数
计数0if (条件) ++cnt;没初始化 → 随机数
最大值a[0] 或 INT_MINif (a[i] > mx) mx = a[i];初值 0 → 全负数时 WA
最小值a[0] 或 INT_MAXif (a[i] < mn) mn = a[i];初值 0 → 全正数时 WA
第一次位置-1if (a[i]==x) { pos=i; break; }初值 0 → 没找到时错答 1
什么时候必须“先全部读入”

必须存：需要回头访问。如本题（手的高度在后面）、两两比较、统计频率、按原顺序输出。

可以不存：求和、计数、求最值。只用“当前元素”和“已有答案”，内存 O(1)。n = 10⁶ 个 int 要 4MB，老题内存常只给 8~16MB。

口诀：答案里出现“前 i 个”就不用数组；出现“第几个 / 后面还要用”就必须存。

6 个高频错，都带症状

越界：int a[10] 却写 i<=10。症状：本地正常，洛谷 RE 或偶发 WA。

数组开小：n ≤ 10⁵ 却开 a[1000]。症状：RE 与随机 WA 交替，重交结果还不同——数组题最典型的指纹。

最值初值取 0：数据 -5 -9 时输出 0。症状：样例过、一交就 WA，只错在负数数据点。

局部大数组爆栈：int a[1000005]; 写在 main 里占 4MB 栈。症状：一启动就 RE，一行输出都没有。

求和用 int：n = 10⁵、每数 10⁹，总和 10¹⁴ 超上限。症状：输出负数。

范围 for 扫了没读过的尾巴：只读 5 个数却 for (int x : a)。症状：答案大出一截。

数学补给 · 循环不变式：为什么“边扫边更新”一定对

求最大值那个 if 凭什么正确？可以用数学归纳法证明。方法是给循环写一条循环不变式：关于“第 k 轮开始时什么成立”的断言。

第 k 轮开始时，mx = a[0..k-1] 中的最大值。
  1. 初始化：k = 1 时只比较过 a[0]，mx = a[0] = max(a[0..0])，成立。
  2. 保持：设第 k 轮前成立。这一轮执行 if (a[i] > mx) mx = a[i];（i = k-1）。若 a[k-1] 更大则 mx 换成它，否则不变，两种情形下 mx = max(a[0..k-1]) 仍成立。
  3. 终止：循环结束时 k = n，mx = max(a[0..n-1])，正是所求。

三步就是全部。以后学前缀和、单调栈、DP，证明正确性用的都是同一套话，只是不变式内容不同。养成习惯：任何“维护一个答案变量”的循环，先用一句话说清不变式。

推论 1（数个数）：区间 [l, r] 内整数个数 = r − l + 1。长度 n 的数组合法下标是 0..n−1，个数 = (n−1) − 0 + 1 = n，所以循环条件永远是 i < n。所有差一错误都能用这个公式当场算穿。

推论 2（别乱排序）：求最值一遍遍历 O(n)，排序后取端点 O(n log n)。

n一遍遍历 ≈ n 次排序 ≈ n·log₂n 次倍数
10³1 000约 10 00010×
10⁵100 000约 1.7×10⁶17×
10⁶1 000 000约 2×10⁷20×

结论：能在读入时顺手维护的信息（和、最值、计数），不要为了“先存后算看着清楚”多存一个数组、多排一次序。

举一反三 · 想清楚这些再往下走
先自己写出答案，再点开核对——方向对不对，比答案本身更重要
  1. 给 10⁵ 个数要求“有多少个数大于平均数”。你至少要扫几遍？内存只够存 10³ 个数时怎么办？
    想好了？点开核对思路与解析
    至少要两遍（或等价地：先把所有数过一遍，再做判断）。第一遍只累加 sum 和计数 n 算出平均数，第二遍才知道每个数和它的大小关系——平均数依赖全部数据，所以不可能边读边判。
    内存只够 10³ 个数时，第一遍根本不存、只留 sum 和 n；第二遍必须重新拿到数据，所以要么自己 freopen 输入文件再读一遍（本地调试可以，评测机上不知道文件名），要么先把数据分块落到临时文件里再读回来——本质都是“不保存全部，只保存聚合量”。常见错路是边读边跟“当前前 i 个的平均数”比，那个平均值不是全体平均，答案会偏。
  2. 数组开 100005 但只用前 n 个，求最大值时后面的 0 会捣乱吗？给出两种写法：一种靠下标循环避开，一种靠哨兵初值绕开。
    想好了？点开核对思路与解析
    会捣乱，但只在真实数据可能全为负的时候：没读过的格子是 0，而 0 比任何负数都大，一旦被算进最大值，答案就变成 0。两种写法：① 用下标循环 for (int i = 0; i < n; ++i)，后面 100005 − n 个格子根本不进循环；② 初值取 INT_MIN（或 a[0]）当哨兵，让 0 赢不了——它对非负数据（本题高度 100~200）绝对安全，但数据全负时仍然会错，真正稳的还是 ①。
    常见错路是用范围 for for (int x : a) 图省事，它固定走完 100005 格，尾部的 0 一个不落地算进去。
  3. 要输出“最大值第一次出现的位置”和“最后一次出现的位置”，一个循环够吗？为什么求第一次能 break，求最后一次不能？
    想好了？点开核对思路与解析
    一个循环就够：if (a[i] == x) { if (first == -1) first = i; last = i; }，一遍同时维护两个位置。求第一次能 break，是因为从左往右第一个命中的下标就是最小的；求最后一次不能 break，因为“最后一次”要等扫完才知道，中途 break 拿到的仍然是第一次。
    常见错路是找到就 break 还指望 last 也对——那 last 会等于 first；或者初值写 0 而不是 −1，没找到时会把“第 0 个”当成答案。
  4. 已知 10⁵ 个人的年龄（0~120），要统计每个年龄的人数。不开 10⁵ 个格子，只开 121 个，能做到吗？这时下标代表什么？（下一节内容，先想）
    想好了？点开核对思路与解析
    能。开 int cnt[121]，下标就是年龄本身（0~120），读到一个年龄就 ++cnt[age]，最后 for (int a = 0; a <= 120; ++a) 输出 a 与 cnt[a]。这时下标代表值，不是“第几个人”，所以 10⁵ 个人也只占 121 个格子——这就是第 6 节的桶计数。
    常见错路是开 10⁵ 的数组按人存再排序统计，白花 400KB 还多一个 log；或者把下标当成人的编号，数组大小由人数决定，值域反而没人管。
  5. 如果要求“输入顺序 = 输出的逆序”，而内存只给 1MB、n = 10⁶，你还能用数组吗？有没有不用数组的办法？
    想好了？点开核对思路与解析
    不能。10⁶ 个 int 要 4MB，已经超过 1MB 内存；就算换成文本形式，10⁶ 个数加分隔符至少 7MB，更占地方。不用数组的干净办法是把数先写进临时文件，再从文件末尾往前读（seek 定位、倒着解析）；理论上还能用递归“读到末尾、回溯时输出”，但 10⁶ 层递归在 1MB 栈上必爆。
    所以这题的现实答案是：内存给成这样，出题人不会让你逆序输出，或者你必须用外存——它考的是“数组 = 用内存换随时访问”。常见错路是以为换成 char 就省了，10⁶ 个多位数每个至少两位，反而更占。

挑战题 · 旗鼓相当的对手
洛谷 P5728普及-去洛谷做这题 ↗

有 N 名同学参加期末考试，每人有语文、数学、英语三科成绩，均为不超过 150 的自然数。

如果两名同学三科成绩两两之间的差距都不超过 5 分，且总分差距不超过 10 分，就称这两个同学是一对“旗鼓相当的对手”。求一共有多少对。

输入格式：第一行一个整数 N（2 ≤ N ≤ 1000）；接下来 N 行，每行三个整数，表示一名同学的三科成绩。

输出格式：一行一个整数，表示“旗鼓相当的对手”的对数。

引导性提示（先只看这里）

先想清楚“一对”怎么数才不重不漏：i、j 都从 0 跑到 n−1 的话，每对会被数两次。

三科差和总分差是四条独立判断，缺一条答案就偏大。

N = 1000 时一共有多少对？先估这个数量级，再决定二重循环够不够。

想看思路了？点开完整思路

用平行数组存三科：ch[i]、ma[i]、en[i] 属于同一个人。

读入时把总分算好存进 tot[i]，避免内层循环里重复加三次。

二重循环：外层 i 从 0 到 n−1，内层 j 从 i+1 到 n−1，每对 (i, j) 恰好检查一次。

四个条件全满足才计数：三个单科差 ≤ 5，总分差 ≤ 10，用 abs 取绝对值。

复杂度 O(n²)，n = 1000 时约 5×10⁵ 次比较，1 秒内轻松跑完。

还是不会？点开题解代码与拆解
参考代码
#include <bits/stdc++.h>
using namespace std;

const int N = 1005;                     // n ≤ 1000，多留 5 格防差一
int ch[N], ma[N], en[N], tot[N];        // 平行数组 + 总分，全局默认全 0

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; ++i) {
        cin >> ch[i] >> ma[i] >> en[i];
        tot[i] = ch[i] + ma[i] + en[i];  // 总分只依赖本人，读入时算一次就够
    }

    int ans = 0;
    for (int i = 0; i < n; ++i)
        for (int j = i + 1; j < n; ++j) {            // j 从 i+1 起：每对只数一次
            if (abs(ch[i] - ch[j]) <= 5 &&
                abs(ma[i] - ma[j]) <= 5 &&
                abs(en[i] - en[j]) <= 5 &&
                abs(tot[i] - tot[j]) <= 10) ++ans;
        }

    cout << ans << "\n";
    return 0;
}
关键片段拆解
片段作用
int ch[N], ma[N], en[N], tot[N];四个平行数组，同一下标 i 指向同一个人。写 main 外：默认全 0，不占栈。
tot[i] = ch[i] + ma[i] + en[i];总分读入时算一次。放进内层循环会重复算 n 遍。
for (int j = i + 1; j < n; ++j)关键一行。保证 (i,j) 与 (j,i) 只被算一次；写成 j = 0 答案必翻倍。
abs(ch[i] - ch[j]) <= 5abs 取绝对值，两个方向的差都变正。成绩 ≤ 150，int 足够。
&& 连四个条件短路求值：前一个不成立就不再判断后面的，既对又快。
这题最容易错的地方
  • 内层写成 for (j = 0; ...)，答案正好是正确值的 2 倍。样例若是 0 就看不出，交上去必 WA。
  • 漏掉总分条件，或把“总分差 ≤ 10”写成“三科差之和 ≤ 10”，答案偏大。
  • 循环条件写成 i <= n，下标取到 n，越界写坏 tot 后面的内存，随机 WA。
  • 把三科读入顺序与题面对调。本题三科对称换了也能 AC，换个题就错，养成按题面顺序读的习惯。
