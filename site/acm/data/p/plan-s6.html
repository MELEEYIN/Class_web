6.3 拓扑排序

基础★★★★★必考P1113P1807P4017

本质：给 DAG（有向无环图）排一个线性序，使所有边都从前指向后。它是 DAG 上 DP 的通用引擎——只要按拓扑序递推，依赖就一定满足。同时还能检测环（排序后的长度小于 n 说明有环）。

🎨 生活类比

选课有先修关系。「高数 → 线代 → 概率论」，你必须按这个顺序修。拓扑排序就是给你一个合法的修课顺序。

6.4 Floyd：全源最短路

基础★★★★★必考P1119P2419P6175

本质：动态规划。f[k][i][j] = 只允许经过前 k 个点中转时，i 到 j 的最短路。压掉第一维后就是那个三重循环。O(n^3)，但代码只有五行，n ≤ 500 时首选。

初始化

三个用途

用途做法
传递闭包（可达性）把 min 换成或运算：f[i][j] |= f[i][k] && f[k][j]
最小环在 Floyd 过程中，用 f[i][j] + w(i,k) + w(k,j) 更新答案
带增量（P1119 灾后重建）按时间顺序逐个加入中转点
⚠️ 易错

k 必须在最外层（这是 DP 的阶段，写在内层就全错了）；0x3f3f3f3f 相加两个会超过 int 吗？不会（1.06×10^9 × 2 = 2.1×10^9 刚好在 int 内，但用 long long 更安全）。

6.5 Dijkstra：单源最短路（非负权）

基础★★★★★必考P4779P3371P1629

本质：贪心。每次取出「当前距离最小的未确定节点」，它的距离就确定下来了（因为边权非负，绕路不可能更短），然后拿它去松弛邻居。用堆优化后是 O(mlog n)。

🎨 生活类比

往水里丢石子，波纹先到近的地方再到远的地方，第一次到达就是最短距离。（这其实就是 BFS 的加权版。）

模板（堆优化）

三个必须知道的限制

  1. 不能有负权边。有负权请用 Bellman-Ford/SPFA。
  2. 不能直接求最长路（把边权取负会得到负权图）。
  3. 稠密图用朴素版 O(n^2)（不加堆），反而更快。

6.6 SPFA 与负环

基础★★★★★必考P3385P3371P5960

本质：Bellman-Ford 的队列优化版：只有「距离被更新过」的点才需要继续松弛别人。能做负权、能判负环，但最坏复杂度 O(nm)，在构造数据下比 Dijkstra 慢几个数量级。

使用建议

场景选谁
全是非负权Dijkstra（永远优先）
有负权但没有负环SPFA（或 Bellman-Ford）
判负环SPFA + 计数，或 Bellman-Ford 跑 n-1 轮
有负权且要用 DijkstraJohnson 算法（先跑一遍 Bellman-Ford 重赋权）
💡 提示

「能非负权就别用 SPFA」是必须建立的直觉。很多同学用 SPFA 过了所有题，然后在正式比赛上被卡到 TLE。

6.7 最小生成树：Kruskal 与 Prim

基础★★★★★必考P3366P1546P2330

本质：在连通无向图中选 n-1 条边，使总权最小。Kruskal 是贪心加边（按边权排序 + 并查集判环），Prim 是贪心加点（类似 Dijkstra）。两者都是拟阵贪心，都可证明。

🎨 生活类比

要给 n 个村子铺路，使所有村子连通、总长度最短。Kruskal 的做法是「从最短的路开始铺，只要不形成环就铺」。

Kruskal 模板（更常用，好写）

复杂度 O(mlog m)（排序主导）。

两者怎么选

KruskalPrim
复杂度O(mlog m)O(n^2) 或 O(mlog n)（堆优化）
适合稀疏图稠密图
代码短（要并查集）类似 Dijkstra
⚠️ 易错

忘记判「不连通」（cnt < n-1）；无向图要存两次边；ans 用 long long。

6.8 欧拉路

基础★★★★★必考P1341P2731P7771

本质：能否不重不漏地走完每条边。判定条件只看度数：

  • 欧拉回路（回到起点）：所有点度数为偶数，且图连通。
  • 欧拉路（不要求回起点）：恰好 0 个或 2 个奇度点。

构造用 Hierholzer：走到走不动再回溯，出栈序即为答案。

⚠️ 易错

图必须连通（忽略孤立点）；有向图的判定是「每个点入度 = 出度」或「恰有一个点出度比入度大 1，一个点入度比出度大 1」。

6.9 差分约束

基础★★★★★必考P5960P1250P1993

本质：把一组形如 x_v - x_u ≤ w 的不等式，变成图上的「边 u → v，权 w」，然后跑最短路（求上界）或最长路（求下界）。有负环则无解。

为什么最短路的松弛 dist[v] > dist[u] + w 恰好对应不等式？ 因为收敛后 dist[v] <= dist[u] + w 恒成立——这正是约束。
