6.3 工具链（决定效率）

  • 编辑器：VS Code + C/C++ 扩展（推荐配置：format on save、tasks.json 一键编译运行、launch.json 支持调试）。竞赛老手也有用 Vim/Emacs 的，选顺手的即可。
  • Competitive Companion：浏览器插件，一键把 Codeforces/AtCoder 等平台的题目样例抓成本地测试文件，省去手工造数据。
  • cf-tool / cf-toolkit：命令行工具，自动拉题、编译、对拍、提交，Codeforces 重度用户必备。
  • 对拍脚本：务必自己配一份「数据生成器 + 暴力标准解 + 待测程序」三方对拍脚本（Windows 用 .bat，Linux 用 .sh），这是本地调试最有效的手段。
  • 模板库：KACTL（ICPCOpen 团队模板）、jiangly 的比赛模板都是开源的高质量参考；但最终要整理成自己的，否则考场上找不到。
  • 在线编译：godbolt.org（看汇编/优化）、wandbox.org（快速试代码）。
  • 复杂度估算：本地 clock() 计时 + chrono 高精度计时，跑一遍最坏数据再决定是否卡常。
  • 调试手段：gdb / 打印变量 / -fsanitize=address,undefined 编译。竞赛中最实用的是"对拍 + 二分注释法"。

6.4 赛事与练习节奏

  • 日常：Codeforces Div.2/Div.3（每周）、AtCoder ABC（每周六）、洛谷月赛、牛客练习赛。
  • 进阶：AtCoder ARC/AGC、Codeforces Div.1、ICPC/CCPC 网络赛与区域赛、各校集训队选拔赛。
  • 复盘比刷题重要：每场比赛后 ① 补完没做出的题 ② 写出题解（讲清"卡在哪一步"）③ 把新学到的技巧归档进模板库。
  • 难度梯度参考：入门篇 ≈ 洛谷 普及−/普及/提高−；基础篇 ≈ 提高/提高+；进阶篇 ≈ 省选/NOI/ICPC 区域赛中上。
