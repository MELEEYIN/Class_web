7.1 位运算进阶

基础★★★★常考P1469P1100P1466

本质：把整数看成 01 向量，用硬件级并行做集合运算。位运算的价值有三：压状态（状压 DP）、压常数（替代取模与除法）、提供数学性质（异或的自反、按位独立）。

异或的四条性质（必背）

a ⊕ a = 0,　 a ⊕ 0 = a,　 a ⊕ b = b ⊕ a,　 (a ⊕ b) ⊕ c = a ⊕ (b ⊕ c)

推论：一堆数异或起来，出现偶数次的会全部消掉。 这就是「找唯一落单的数」的解法（P1469 找筷子）。

常用内置函数（GCC，O(1)）

为什么它们快？ 编译器直接生成一条 CPU 指令（POPCNT），比循环数位快几十倍。

按位独立：一个重要的思维方式

很多位运算题的解法是「对每一位单独算，再合并」。因为位与位之间互不影响，所以可以把一个 O(2^30) 的问题拆成 30 个独立的 O(1) 问题。

题单　P1100 高低位交换　·　P1466 集合 Subset Sums　·　P2114 起床困难综合症　·　P1554 梦中的统计　·　P1469 找筷子

7.2 快速幂

基础★★★★常考P1226P3197P1962

本质：求 a^b mod m 时，把指数折半：a^b = (a^b/2)^2，偶数直接平方，奇数多乘一个 a。O(log b)。

三个必须注意的点

  1. r = 1 % m 而不是 r = 1：当 m = 1 时答案应为 0，写 1 会得到 1。
  2. a %= m 要写在循环外：a 可能本来就是负数。
  3. 乘法可能溢出：m 接近 10^18 时 a * a 会溢出 long long，要用 __int128 或「快速乘（龟速乘）」。
💡 提示

快速幂是所有数论算法的地基：逆元、矩阵快速幂、莫比乌斯反演、多项式运算全都建立在它上面。

题单　P1226 快速幂模板　·　P3197 越狱　·　P1962 斐波那契数列（矩阵加速）

7.3 筛法：一次筛出所有素数

基础★★★★常考P3383P1835P5736

本质：埃氏筛：每个合数被它的质因子筛掉，O(nloglog n)。欧拉筛（线性筛）：让每个合数只被它的最小质因子筛一次，因此 O(n)，并且能顺带求出积性函数。

线性筛模板（背下来）

p > v[i] 这一句是关键：它保证每个合数只被最小的那个质因子筛到一次，所以总复杂度是 O(n)。

三个常用推论

需求怎么改
判素数v[i] == i 即为素数
分解质因数不断取 v[x] 并 x /= v[x]，O(log x)
欧拉函数 φ在筛的过程中顺手递推（见下节）

7.4 数论函数与积性

基础★★★★常考P2158P2568P3383

这一节是为第 9 章的「莫比乌斯反演 / 杜教筛」铺路。直接跳到反演会一头雾水，所以先在这里把符号认识清楚。

四个基本数论函数

函数定义含义
φ(n)（欧拉函数）1~ n 中与 n 互质的数的个数容斥或积性递推求
μ(n)（莫比乌斯函数）n 有平方因子 → 0；否则 (-1)^k，k 为质因子个数反演的系数
d(n)n 的约数个数积性，可线性筛
sigma(n)n 的约数之和积性，可线性筛

积性函数

若 gcd(a,b)=1 时 f(ab) = f(a)f(b)，则 f 是积性函数。上面四个都是。

为什么重要：积性函数可以线性筛——因为 n = p^k 时取值容易算，而任何数都能唯一分解为素数幂的乘积。

线性筛求欧拉函数

两个恒等式（先记住，第 9 章要用）

Σ_d | n φ(d) = n, 　　 Σ_d | n μ(d) = [n = 1]

✅ 小结

数论函数看起来抽象，但它们只是"对每个 n 给一个值"的表。 先用线性筛把表算出来，再看题目要什么。

题单　P2158 仪仗队　·　P2568 GCD　·　P3383 线性筛素数

7.5 gcd、exgcd 与裴蜀定理

基础★★★★常考P1082P4549P5656

本质：辗转相除求最大公约数；扩展欧几里得不仅能求 gcd，还顺带求出 ax + by = gcd(a,b) 的一组整数解——这是解线性同余方程、求逆元、解不定方程的万能工具（理论依据是裴蜀定理）。

gcd

exgcd 模板（背下来）

调用后 g 是 gcd(a,b)，x, y 满足 ax + by = g。

裴蜀定理

ax + by = c 有整数解 当且仅当 gcd(a,b) | c。

推论：a 在模 m 下有逆元 ⇔ gcd(a,m) = 1。

解同余方程 ax equiv b ±od m

⚠️ 易错

m/g 是模数（不是 m）；最后一步必须转成非负。

7.6 费马小定理、欧拉定理与逆元

基础★★★★常考P3811P2613P5431

三个定理

定理内容条件
费马小定理a^p-1 equiv 1 ±od pp 是素数，gcd(a,p)=1
欧拉定理a^φ(m) equiv 1 ±od mgcd(a,m)=1
扩展欧拉定理a^b equiv a^b mod φ(m) + φ(m) ±od mb ≥ φ(m)

逆元：模意义下的「除法」

为什么需要它：模意义下没有除法。要把「除以 a」变成「乘以 a 的逆元」。逆元 x 满足 ax equiv 1 ±od p。

三种求法（对应三种场景）

用费马小定理却传了个非素数的模（比如 10^9+9 是素数，但 10^8 不是）；线性递推只对素数模成立。

7.7 组合数

基础★★★★常考P3414P3807P1044

本质：C(n,m) = dfrac{n!}{m!(n-m)!}，模意义下要用阶乘 + 阶乘逆元来算，这样单次 O(1)。

什么时候 O(n) 预处理不够用

情形用什么
n ≤ 10^7，p 是素数上面这套（预处理 O(n)）
n 很大（10^18），p 很小（10^5）Lucas 定理：按 p 进制拆位
p 不是素数exLucas（第 9 章）
只要 C(n,0) 到 C(n,n) 一行递推 C(n,k) = C(n,k-1)·frac{n-k+1}{k}

四个必背的组合恒等式

C(n,m) = C(n-1,m) + C(n-1,m-1), 　　 Σ_k=0^n C(n,k) = 2^n

C(n,m) = C(n, n-m), 　　 Σ_k=0^n (-1)^k C(n,k) = 0 (n ≥ 1)

7.8 容斥原理

基础★★★★常考P1450P3172P4707

本质：求「至少满足一个条件」的个数时，加单数、减双数、加三数……。更常用的表述是「总数 − 一个都不满足」。

|A ∪ B ∪ C| = |A| + |B| + |C| - |A∩ B| - |A∩ C| - |B∩ C| + |A∩ B∩ C|

两种实现

经典模型：硬币购物（P1450）

4 种硬币，每次问「用 d_i 枚以内凑出 s 的方案数」。做法：先做完全背包求「无限量」的方案数，再用容斥减去「某种硬币超量」的情况。2^4 = 16 个状态枚举，正负号按超量种数的奇偶决定。

⚠️ 易错

容斥项数多时，符号和「一个都不满足」的反向容易搞反；写之前先在小数据上把公式验一遍。

7.9 高精度

基础★★★★常考P1601P2142P1303

本质：手写十进制大整数。竞赛里通常用 vector<int> 倒序存（低位在前便于进位），或用压位（每 9 位存一个 int）提速。C++ 没有现成大整数，必须会写。

判断要不要写高精度

只有一种信号：答案的绝对值超过 9.2× 10^18（即 long long 装不下）。典型场景：n!、大斐波那契、2^k、超长整数乘法。

💡 提示

能用取模的题一律取模，不要写高精度。题目问「答案对 10^9+7 取模」就是在告诉你「别写高精」。

题单　P1601 A+B Problem（高精）　·　P2142 高精度减法　·　P1303 A*B Problem　·　P1480 A/B Problem　·　P1045 麦森数

7.10 矩阵快速幂

基础★★★★常考P3390P1962P1939

本质：把线性递推写成「向量 × 矩阵」的形式，然后用快速幂把 O(n) 次递推压到 O(k^3log n)（k 是转移矩阵阶数）。凡是「第 n 项 + n 巨大 + 转移只线性依赖前几项」都可以套。

构造转移矩阵的诀窍

  1. 写出递推式，确认它依赖前面的几项（几项 → 矩阵几阶）。
  2. 把「状态向量」定好顺序，逐行写「新值 = 哪些旧值的线性组合」。
  3. 常数项也要放进状态（比如 f(n) = f(n-1) + c 需要第三维常数 1）。

题单　P3390 矩阵快速幂模板　·　P1962 斐波那契数列　·　P1939 矩阵加速　·　P4159 迷路
